## API Anahtarları

Model çağrıları ve özel kaynaklar API anahtarı gerektirir. `GET /v1/models` ve `GET /v1/models/{model}` gibi genel uç noktalar anahtarsız çalışır. Keşif sorgusunun başarılı olması anahtarın çalıştığını doğrulamaz; hızlı başlangıçtaki adımlarla bir model isteği gönderin. Listedeki önek yerine kaydettiğiniz tam anahtarı kullanın.

OpenAI uyumlu endpoint'ler için bunu şu şekilde gönderin:

```bash
Authorization: Bearer sk-your-api-key
```

Anthropic uyumlu `/v1/messages` istekleri için şunu da kullanabilirsiniz:

```bash
x-api-key: sk-your-api-key
```

## Yönetim tokenları

Yönetim API uç noktaları ayrı bir token türü kullanır:

```bash
Authorization: Bearer mt-your-management-token
```

Yönetim tokenlarını yalnızca `/v1/management/*` uç noktalarıyla kullanın. Seçili çalışma alanında token oluşturmak veya değiştirmek için [API → Tokens](https://tokenlab.sh/dashboard/api?tab=tokens) sayfasını açın. Tam token oluşturma veya değiştirme sonrasında yalnızca bir kez gösterilir; bu sırada güvenli bir yere kaydedin.

<Note>
Yönetim tokenları model çıkarımı için, normal `sk-...` API anahtarları ise Yönetim API için kullanılamaz.
</Note>

## API Anahtarınızı Alma

1. [TokenLab Dashboard](https://tokenlab.sh/dashboard) hesabınıza giriş yapın
2. **API Keys** bölümünü açın
3. Yeni bir anahtar oluşturun
4. Buna açıklayıcı bir ad verin
5. Hemen kopyalayın çünkü yalnızca bir kez gösterilir

<Warning>
- API anahtarlarını asla istemci tarafı kodunda açığa çıkarmayın
- API anahtarlarını asla sürüm kontrolüne commit etmeyin
- Ortam değişkenleri veya bir secret manager kullanın
- Anahtarları periyodik olarak döndürün
- Kullanılmayan anahtarları silin
</Warning>

## API Anahtarlarını Kullanma

Ortam değişkenleri ve ilk tam istek için [hızlı başlangıca](/tr/quickstart) bakın. Seçilen [API biçimine](/tr/guides/api-formats) uygun SDK kullanın ve anahtarları sunucuda tutun.

## API Anahtarı Özellikleri

### Kullanım Limitleri

Her API anahtarı için bir kullanım limiti ayarlayabilirsiniz:

| Ayar | Açıklama |
|---------|-------------|
| **No Limit** | Anahtar, hesabınızın bakiyesini kısıtlama olmadan kullanır |
| **Fixed Limit** | Anahtar, belirtilen tutara ulaştıktan sonra çalışmayı durdurur |

### Anahtar Öneki

Tüm TokenLab API anahtarları `sk-` ile başlar.

## Hata Yanıtları

| Durum Kodu | Tür | Kod | Açıklama |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | API anahtarı eksik, geçersiz, etkin değil veya iptal edilmiş |
| 401 | `expired_api_key` | `expired_api_key` | API anahtarının süresi doldu |
| 402 | `insufficient_balance` | `insufficient_balance` | Hesap bakiyesi yetersiz |
| 402 | `quota_exceeded` | `quota_exceeded` | API anahtarı kullanım limitine ulaşıldı |

Örnek:

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
