## Kurulumu ajanıma bırak

Bu görevi bilgisayarınızda zaten çalışan bir ajana kopyalayın:

```text
Bu kılavuzu oku ve OpenClaw ile TokenLab bağlantısını kurmama yardım et:
https://docs.tokenlab.sh/tr/guides/tokenlab-provider
Önce kurulu sürümümü ve etkin yapılandırmayı kontrol et.
Mevcut hesapları, sağlayıcıları, izinleri ve diğer ayarları koru.
Yerel dosyaları yedekle ve önerilen değişiklikleri göster.
Gereken API anahtarlarını yerel olarak benim girmemi sağla; bunları sohbette isteme, görüntüleme veya yapıştırma.
Önce yapılandırmanın yüklenebildiğini doğrula.
Ücretli istek içeren her testin maliyetini çalıştırmadan önce ayrıca açıkla.
```

<Note>
Bu kılavuz, TokenLab'yı AI sağlayıcısı olarak bağlamak isteyen **self-hosted OpenClaw** kullanıcıları içindir.
</Note>

## Önerilen: eklentiyi yükleyin

İsteğe bağlı olarak yayımlanmış sağlayıcı eklentisi **0.1.0** sürümünü kurun. `TOKENLAB_API_KEY` değerini aşağıdaki Gateway ortamında sağlayın ve modeli yalnızca oturum için seçin. Kurulum sihirbazı varsayılan modeli değiştirir; bu yüzden bu kılavuz `openclaw onboard` çalıştırmaz. Mevcut eklenti ve izinleri koruyun; istekten önce eklenti yüklemesini ve model listesini kontrol edin.

Yükleyicinin istediği yetenekleri inceleyip istemcinin onay adımlarını izleyin. İlgisiz izinler vermeyin veya mevcut eklentilerin izinlerini değiştirmeyin.

```bash
openclaw plugins install @tokenlabai/openclaw-provider@0.1.0
openclaw plugins list
openclaw models list --provider tokenlab
```

```text
/model tokenlab/claude-sonnet-5 -s
/model default -s
```

## Manuel sağlayıcı yapılandırması

Aşağıdaki manuel `models.providers` girdilerini yalnızca ayrı **Responses API**, **Claude native**, **Gemini native** veya **MiniMax native** rotalarına açıkça ihtiyaç duyduğunuzda kullanın.

Manuel yapılandırmayı seçerseniz yalnızca `tokenlab`yı yapılandırmak yeterlidir. Diğer sağlayıcıları yalnızca açıkça **Responses API**, **Claude native**, **Gemini native** veya **MiniMax native** davranışına ihtiyaç duyduğunuzda ekleyin.

| Sağlayıcı | OpenClaw `api` | En uygun | baseUrl |
|----------|----------------|----------|---------|
| `tokenlab` | `openai-completions` | GPT, DeepSeek, Qwen ve çoğu OpenAI-uyumlu çağrı | `https://api.tokenlab.sh/v1` |
| `tokenlab-responses` | `openai-responses` | `/v1/responses` semantiğini bekleyen OpenAI Responses iş akışları | `https://api.tokenlab.sh/v1` |
| `tokenlab-claude` | `anthropic-messages` | Claude için yerel Messages API'si | `https://api.tokenlab.sh` |
| `tokenlab-gemini` | `google-generative-ai` | Gemini için yerel API formatı | `https://api.tokenlab.sh` |
| `tokenlab-minimax` | `anthropic-messages` | MiniMax için yerel yönlendirme | `https://api.tokenlab.sh` |

<Warning>
Sadece `openai-completions` ve `openai-responses` için `/v1` son ekini kullanın.

`anthropic-messages` ve `google-generative-ai` gibi yerel sağlayıcılar `https://api.tokenlab.sh`'yi `/v1` olmadan kullanmalıdır; aksi takdirde OpenClaw yanlış üst akış yolunu oluşturabilir.
</Warning>

## Önkoşullar

- Bir self-hosted OpenClaw örneği
- OpenClaw **2026.9.4**, Node.js `>=24.16.0 <25 || >=26.1.0` gerektirir ([sürüm gereksinimleri](https://github.com/openclaw/openclaw/blob/v2026.9.4/package.json)). Diğer OpenClaw sürümleri için ilgili sürümün gereksinimlerini kontrol edin.
- Bir TokenLab API Key — [Get one here](https://tokenlab.sh/dashboard/api?tab=keys)

## Yapılandırma

OpenClaw yapılandırmanızı düzenleyin:

- **Kendi barındırılan**: `~/.openclaw/openclaw.json`

TokenLab sağlayıcılarını `models.providers` altında ekleyin:

Çalışan Gateway ile aynı profil, `OPENCLAW_STATE_DIR` ve `OPENCLAW_CONFIG_PATH` değerlerini kullanıp ayarları yedekleyin. `TOKENLAB_API_KEY` değerini bu örneğin güvenilir genel `.env` dosyasına veya hizmet ortamına koyun. Terminal export veya proje `.env` dosyası arka plana ulaşmayabilir. [Ortam açıklamasına](https://docs.openclaw.ai/help/environment) bakın.

Etkin yapılandırmayı yedekleyin. Yalnızca TokenLab girdisini ekleyip mevcut sağlayıcıları, hesapları, varsayılan modeli ve izinleri koruyun. Ad kullanımdaysa başka bir ad seçip komutları güncelleyin. Geri almak için yalnızca eklediğiniz girdiyi kaldırın veya önceki yedeğini yükleyin.

```json5
{
  models: {
    mode: "merge",
    providers: {
      tokenlab: {
        api: "openai-completions",
        baseUrl: "https://api.tokenlab.sh/v1",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gpt-5.6-terra", name: "GPT-5.6 Terra" },
          { id: "deepseek-reasoner", name: "DeepSeek Reasoner" },
          { id: "qwen3-coder-flash", name: "Qwen 3 Coder Flash" }
        ]
      },
      "tokenlab-responses": {
        api: "openai-responses",
        baseUrl: "https://api.tokenlab.sh/v1",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gpt-5.6-terra", name: "GPT-5.6 Terra (Responses)" },
          { id: "gpt-5.2", name: "GPT-5.2 (Responses)" }
        ]
      },
      "tokenlab-claude": {
        api: "anthropic-messages",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "claude-sonnet-5", name: "Claude Sonnet 5" },
          { id: "claude-opus-5", name: "Claude Opus 5" }
        ]
      },
      "tokenlab-gemini": {
        api: "google-generative-ai",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gemini-3.5-flash", name: "Gemini 3.5 Flash" },
          { id: "gemini-2.5-pro", name: "Gemini 2.5 Pro" }
        ]
      },
      "tokenlab-minimax": {
        api: "anthropic-messages",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "minimax-m3", name: "MiniMax M3" }
        ]
      }
    }
  }
}
```

<Info>
Tüm 5 sağlayıcı **aynı API Key'i** kullanır. Sadece bir TokenLab hesabına ihtiyacınız var.
</Info>

<Info>
Yukarıdaki `models` dizileri sadece yaygın örnekleri gösterir. Gerektikçe her sağlayıcıya daha fazla model ID'si ekleyin.
</Info>

## Modellerin Kullanımı

OpenClaw hâlâ modelleri `provider/model` formatıyla referans gösterir:

**OpenClaw 2026.9.4** içinde `-s` ile modeli yalnızca mevcut oturum için seçin. `agents.defaults.model`, ajan varsayılanları ve izinleri koruyun. Oturumu yapılandırılmış varsayılana döndürmek için `/model default -s` kullanın.

```text
/model tokenlab-claude/claude-sonnet-5 -s
/model default -s
```

### Model Örnekleri

| Sağlayıcı | Model referansı | Açıklama |
|----------|-----------------|-------------|
| `tokenlab` | `tokenlab/gpt-5.6-terra` | OpenAI-uyumlu rota |
| `tokenlab-responses` | `tokenlab-responses/gpt-5.6-terra` | Responses API rotası |
| `tokenlab-claude` | `tokenlab-claude/claude-sonnet-5` | Claude Messages için yerel rota |
| `tokenlab-gemini` | `tokenlab-gemini/gemini-3.5-flash` | Gemini için yerel rota |
| `tokenlab-minimax` | `tokenlab-minimax/minimax-m3` | MiniMax için yerel rota |

Mevcut tüm modellere göz atın: [tokenlab.sh/models](https://tokenlab.sh/tr/models).

## Hangi Sağlayıcı Ne Zaman Kullanılmalı

- `tokenlab`: çoğu genel amaçlı ajan ve sohbet kullanım durumu için varsayılan seçim.
- `tokenlab-responses`: OpenClaw iş akışınız açıkça OpenAI Responses semantiğine bağımlıysa kullanın.
- `tokenlab-claude`: Claude'un yerel Messages davranışını istiyorsanız kullanın.
- `tokenlab-gemini`: Gemini'ye özgü istek/yanıt formatlaması veya mevcut Gemini tarzı entegrasyonlar istiyorsanız kullanın.
- `tokenlab-minimax`: MiniMax'i yerel rotasında kullanmak istiyorsanız tercih edin.

Gemini'ye özgü davranışa ihtiyacınız yoksa, Gemini modellerini yine de OpenAI-uyumlu rota üzerinden `tokenlab/gemini-*` ile çağırabilirsiniz.

## Yaygın Hatalar

<AccordionGroup>
  <Accordion title="Hâlâ eski üst düzey providers dizisini mi kullanıyorsunuz?">
    Güncel OpenClaw dokümantasyonu `models.providers` kullanır. Eski üst düzey `providers` dizi formatını kullanmaya devam ederseniz, OpenClaw yapılandırmayı yok sayabilir veya sağlayıcı ön eklerini beklenildiği gibi çözemeyebilir.
  </Accordion>
  <Accordion title="`tokenlab-responses` için /v1'i unutmak">
    `openai-responses` TokenLab'nın `/v1/responses` yoluna eşlenir, bu nedenle `tokenlab-responses` `https://api.tokenlab.sh/v1` kullanmalıdır.
  </Accordion>
  <Accordion title="`tokenlab-claude`, `tokenlab-gemini` veya `tokenlab-minimax`'e /v1 eklemek">
    `anthropic-messages` ve `google-generative-ai` `/v1` olmadan `https://api.tokenlab.sh` kullanmalıdır. `/v1` eklemek yanlış istek yolları üretebilir.
  </Accordion>
  <Accordion title="OpenClaw hâlâ native Gemini'yi destekliyor mu?">
    Evet. Güncel OpenClaw dokümantasyonu hâlâ dahili `google` sağlayıcısını içerir ve ayrıca `api: "google-generative-ai"` kullanan özel sağlayıcıları da destekler. Bu yüzden `tokenlab-gemini` OpenClaw kullanıcıları için geçerli bir native Gemini rotası olmaya devam eder.
  </Accordion>
</AccordionGroup>

## Kurulumu Doğrulama

Aynı örneği yeniden başlatıp model ve sağlayıcıyı kontrol edin. `--probe` olmadan `models status` model çağrısı testi değildir. Canlı denemeler ve mesajlar token tüketebilir. Yanıtı TokenLab kaydıyla karşılaştırın. Geri almak için eski modeli seçip yalnızca eklenen girdileri kaldırın.

```bash
openclaw gateway restart
openclaw models status
```
