## TokenLab Sağlayıcı Seçimi

### Seçim Stratejileri

| Strateji | Davranış | En iyi kullanım |
|----------|---------|----------------|
| **PRIORITY** | En yüksek öncelikli mevcut sağlayıcıyı kullanır | Güvenilirlik |
| **COST** | En düşük maliyetli mevcut sağlayıcıyı kullanır | Maliyet optimizasyonu |

### Otomatik Yeniden Deneme

```
İstek: claude-sonnet-4-6
  → Sağlayıcı A (birincil): 503 hatası
  → Sağlayıcı B (yeniden deneme): ✓ Başarılı
```

### Yerel API Biçimleri

Seçilen model yerel bir API biçimini desteklediğinde, TokenLab uyumluluğu artırmak için bu biçimi kullanabilir:

| Model Ailesi | API Biçimi | Temel URL |
|-------------|------------|----------|
| Claude | Anthropic Mesajları | `https://api.tokenlab.sh` |
| GPT | OpenAI Yanıtları | `https://api.tokenlab.sh/v1` |
| Gemini | Gemini Yerel API | `https://api.tokenlab.sh` veya `https://api.tokenlab.sh/v1beta` istemci yoluna bağlı olarak |
| DeepSeek | OpenAI Sohbet | `https://api.tokenlab.sh/v1` |

Claude Code güçlü bir Anthropic-native yoldur. Gemini-native API’ler de vardır, ancak Gemini CLI’nin kendisi hâlâ best-effort bir uyumluluk yoludur ve uzun vadeli olarak kararlı bir iş akışı gibi sunulmamalıdır.
