Tek TokenLab bakiyesi tüm modeller için geçerlidir. Abonelik veya asgari harcama yoktur; ücret model ve kaydedilen kullanıma göre hesaplanır.

## Fiyatlar ve teslim seçenekleri

Güncel fiyatı model sayfasından, `GET /v1/models/{model}/pricing` veya Pricing API’den okuyun. Kopyalanmış fiyat tablosunu sabitlemeyin. Metin ve embedding girdi, çıktı veya önbellek tokenlarıyla; medya görüntü, saniye, dakika, istek veya iş başına fiyatlanabilir.

`TokenLab Verified` açık TokenLab fiyatlarını, `Official` model üreticisinin açık fiyatlarına dayalı Official katmanını kullanır. `Auto` önce Verified, gerektiğinde Official seçer; sonucu teslim eden seçenek için bir kez ücret alınır. Console ücretli üretimi onaylamadan önce en yüksek tahmini, tamamlandıktan sonra Runs ve Usage’da son tutarı gösterir.

[Pricing API](/tr/api-reference/pricing/get-pricing)

## Asenkron faturalama ve kayıtlar

Bazı işler oluşturulurken tahmini maliyeti ayırır. Kimliği ve `poll_url` değerini kaydedip `completed` veya `failed` olana kadar sorgulayın. Başarılı iş bir kez ücretlendirilir ve kalan rezerv bırakılır; başarısız işte bekleyen tutar serbest bırakılır veya iade edilir.

Akışsız OpenAI uyumlu yanıtlar faturalama sonrası `billing_transaction_id` veya `X-Billing-Transaction-ID` içerebilir. Yerel biçimler yalnız başlık kullanabilir. Asenkron ve akış sonuçları mali kayıttan önce gelebilir; kimlik yoksa Usage’a bakın.

Usage model, anahtar, maliyet ve kullanımı gösterir. Token sayımı modele, dile ve medyaya bağlıdır; karakter tahmini son faturanın yerini tutmaz. Akış ücretli token sayısını azaltmaz. Aynı görevlerin son maliyetini karşılaştırıp desteklenen çıktı sınırını kullanın.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Console kullanımı

Console → Billing’de tutarı ve sunulan ödeme yöntemini seçin. Ödeme hizmeti onayladıktan sonra bakiye güncellenir.

Console → API Keys’de anahtar oluştururken veya düzenlerken harcama sınırı belirleyin. Sınıra ulaşıldığında `402 Payment Required` döner.

Bakiye uyarılarını Console → Settings’den ayarlayın. Faturalama sorularında Request ID ve iş kimliğini support@tokenlab.sh adresine gönderin, API anahtarını göndermeyin.
