Çoğu araç, API anahtarı ve temel URL değiştirilerek TokenLab’e bağlanabilir. Tam yapılandırma, aracın kullanabildiği API biçimine bağlıdır.

| API biçimi | Temel URL | Yaygın istemciler |
| --- | --- | --- |
| Chat Completions (OpenAI uyumlu) | `https://api.tokenlab.sh/v1` | OpenAI SDK’ları, birçok sohbet uygulaması ve framework |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | Responses istemcileri ve Responses olaylarını kullanan araçlar |
| Anthropic Messages | `https://api.tokenlab.sh` | Anthropic SDK’ları ve Claude odaklı araçlar |
| Gemini | `https://api.tokenlab.sh` | Özel sunucu adresine izin veren Gemini REST ve SDK istemcileri |

Seçilen modelin `accepted_request_formats` alanında aynı biçim yer almalıdır. Akış ve araç çağrıları ayrıca modelin yeteneklerine ve istemcinin desteğine bağlıdır. Örnekler için [API biçimleri](/tr/guides/api-formats) sayfasına bakın.

## Uyumluluk etiketleri

| Etiket | Anlamı |
| --- | --- |
| **Uyumlu** | Bağlantı verilen sayfadaki TokenLab kurulumu, istemcinin belgelenmiş yapılandırma seçeneklerini kullanır |
| **Sınırlamalarla uyumlu** | Yapılandırma belirli özellikler veya kimlik doğrulama yöntemleri için geçerlidir; sağlayıcının diğer hizmetleri kendi koşullarını korur |

Bu etiketler, bağlantı verilen sayfadaki yapılandırmayı açıklar. Kullanılabilir özellikler seçilen modele ve istemci sürümüne de bağlıdır.

## Akış yanıtlarında kullanım bilgisi

Chat Completions akışları `stream_options: { include_usage: true }` seçeneğini kabul eder ve akış kapanmadan önce son bir kullanım parçası ekler. Responses API’sinde `include_usage` bulunmaz; Responses akışları kullanım bilgisini son olayda bildirir.

## Özel API anahtarının yerine geçmediği hizmetler

Bazı ürünler model çağrılarını sağlayıcının barındırdığı özelliklerle birleştirir. TokenLab anahtarı, BYOK ayarlarında sunulan model isteklerini karşılayabilir; ancak diğer aboneliklerin, otomatik tamamlama hizmetlerinin, hesap özelliklerinin veya özel uzantıların yerine geçmez.

Araç güncellemesi yapılandırmayı değiştirirse eski ortam değişkeni örneklerini kopyalamak yerine güncel entegrasyon sayfasını kullanın.

## Bir özelliğe güvenmeden önce

- Aracın gerekli API biçimi için özel temel URL’ye izin verdiğini doğrulayın.
- Modelin `accepted_request_formats` alanında bu biçimi listelediğini doğrulayın.
- İş akışınız gerektiriyorsa akışı ve araç çağrılarını deneyin.
- API anahtarını güvenilir bir cihazda veya sunucuda saklayın.
- Hata bildirirken istek kimliğini kaydedin.
