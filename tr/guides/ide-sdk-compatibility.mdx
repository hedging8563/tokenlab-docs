## Genel Bakış

TokenLab, yaygın kodlama araçlarının, SDK'ların ve framework'lerin minimum "glue code" (yapıştırıcı kod) ile entegre olabilmesi için birden fazla API formatı sunar.

Bu sayfa, bir pazarlama matrisinden kasıtlı olarak daha dar kapsamlı tutulmuştur:

- **Desteklenen (Supported)**: Somut bir kurulum yolunu belgelediğimiz ve TokenLab'in bu yolun beklediği protokol yapısını sunduğu anlamına gelir.
- **Güçlü yerel yol (Strong native path)**: Deponun ayrıca o protokol ailesi için doğrudan adaptör veya istek formatı kanıtına sahip olduğu anlamına gelir.
- **En iyi çaba (Best-effort)**: Entegrasyonun çalışabileceği, ancak yukarı yönlü istemcinin bu özel ağ geçidi iş akışını kararlı bir sözleşme olarak görmediği anlamına gelir.

<Note>
  Desteklenmeyen alanlar tek tip bir şekilde ele alınmaz. Uyumluluk rotalarında bazı alanlar göz ardı edilir veya normalleştirilir. `/v1/responses` rotasında, desteklenmeyen alanlar, rotanın talep edilen davranışı garanti edemediği durumlarda açık `400` veya `503` hataları döndürebilir.
</Note>

## Desteklenen API Formatları

| Endpoint | Format | Kullanım Durumu |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | Evrensel uyumluluk |
| `/v1/responses` | OpenAI Responses | Durumlu (stateful) konuşmalar |
| `/v1/messages` | Anthropic Messages | Claude yerel özellikleri |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini yerel özellikleri |

## IDE & CLI Uyumluluğu

### Belgelenmiş Araç Yolları

| Araç | Destek Seviyesi | Format | Notlar |
|------|---------------|--------|-------|
| **Cursor** | Sınırlı destek | OpenAI uyumlu | BYOK standart sohbet/editör akışları için çalışır, Tab Completion gibi Cursor tarafından yönetilen özelliklerin yerine geçmez |
| **Claude Code CLI** | Güçlü yerel yol | Anthropic | Düşünme (thinking) ve `tool_choice` için adaptör kapsamına sahip yerel `/v1/messages` rotası |
| **Codex CLI** | Model/yol sınırlamalarıyla desteklenir | OpenAI Responses | `/v1/responses` rotasını Codex'e özgü iş akışları için gelişmiş bir yol olarak değerlendirin; yalnızca Responses'a özgü bazı alanlar her modelde ve rotada garanti edilmez |
| **Gemini CLI** | En iyi çaba / deneysel | Gemini | Özel TokenLab temel URL akışı, resmi bir Gemini CLI entegrasyonu değildir |
| **OpenCode** | Desteklenir | OpenAI uyumlu | Varsayılan olarak OpenAI uyumlu bir sağlayıcı kullanın; yalnızca açıkça ihtiyaç duyduğunuzda Responses tabanlı bir sağlayıcıya geçin |
| **OpenHands** | Desteklenir | OpenAI uyumlu | `openai/<model>` ve TokenLab'in `/v1` temel URL'si ile LiteLLM/OpenAI uyumlu yolunu kullanın |

<Note>
  Diğer OpenAI uyumlu editörler ve ajan araçları genellikle aynı temel URL yapısıyla çalışır; üretim ortamında kullanmadan önce aracın kendi özel sağlayıcı desteğini kontrol edin.
</Note>

## Chat Completions Parametreleri

### Temel Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı (gerekli) |
| `messages` | array | Konuşma mesajları (gerekli) |
| `max_tokens` | integer | Maksimum çıktı token'ı |
| `temperature` | number | Örnekleme sıcaklığı (0-2) |
| `top_p` | number | Nucleus örnekleme (0-1) |
| `stream` | boolean | Akışı etkinleştir |

### Araç Çağırma (Tool Calling)

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Araç Seçimi (Tool Choice) Seçenekleri

| Format | Örnek | Açıklama |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Basit seçim |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | Belirli fonksiyonu zorla |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic yerel formatı |

### Gelişmiş Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `stream_options` | object | Yalnızca Chat Completions: Token sayıları için `{ include_usage: true }` |
| `reasoning_effort` | string | Akıl yürütme özellikli GPT-5 modelleri için `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` veya `"default"` |
| `seed` | integer | Deterministik çıktılar |
| `logprobs` | boolean | Log olasılıklarını döndür |
| `top_logprobs` | integer | En iyi log olasılıklarının sayısı (0-20) |
| `logit_bias` | object | Token yanlılık haritası (-100 ila 100) |
| `frequency_penalty` | number | Tekrar cezası (-2 ila 2) |
| `presence_penalty` | number | Konu cezası (-2 ila 2) |
| `stop` | string/array | Durdurma dizileri |
| `n` | integer | Tamamlama sayısı (1-128) |
| `user` | string | İzleme için kullanıcı tanımlayıcısı |

### OpenAI Gelişmiş Özellikleri

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `modalities` | array | Çok modlu (multimodal) için `["text", "audio"]` |
| `audio` | object | Ses çıkış yapılandırması (ses, format) |
| `prediction` | object | Daha hızlı tamamlama için tahmin edilen çıktı |
| `metadata` | object | İzleme için anahtar-değer çiftleri |
| `store` | boolean | Daha sonra geri almak için sakla |

### Sağlayıcıya Özgü Seçenekler

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Anthropic Messages Parametreleri

### Temel Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı |
| `messages` | array | Konuşma mesajları |
| `max_tokens` | integer | Maksimum çıktı (128000'e kadar) |
| `system` | string/array | Sistem istemi |
| `stream` | boolean | Akışı etkinleştir |

### Araç Çağırma (Tool Calling)

```json
{
  "tools": [
    {
      "name": "get_weather",
      "description": "Get weather",
      "input_schema": {
        "type": "object",
        "properties": {
          "location": { "type": "string" }
        }
      }
    }
  ],
  "tool_choice": {
    "type": "auto",
    "disable_parallel_tool_use": false
  }
}
```

### Genişletilmiş Düşünme (Extended Thinking)

```json
{
  "model": "claude-opus-4-6",
  "thinking": {
    "type": "enabled",
    "budget_tokens": 10000
  }
}
```

## Responses API Parametreleri

### Temel Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `model` | string | Model tanımlayıcısı |
| `input` | string/array | Girdi içeriği |
| `instructions` | string | Sistem talimatları |
| `max_output_tokens` | integer | Maksimum çıktı token'ı |
| `previous_response_id` | string | Konuşmayı devam ettir |

### Gelişmiş Parametreler

| Parametre | Tip | Açıklama |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` veya `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Akıl yürütme modelleri için |
| `service_tier` | string | Öncelik katmanı |

### Araç Formatı

Hem OpenAI hem de Anthropic araç formatlarını destekler:

```json
// OpenAI formatı
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic formatı (Cursor uyumluluğu)
{ "name": "fn", "input_schema": {...} }
```

## Akış (Streaming)

Chat Completions ve Responses dahil olmak üzere `stream: true` değerini sunan üretim endpoint'leri, Server-Sent Events (SSE) kullanır:

```bash
# Chat Completions
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# Chat Completions kullanım takibi
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Hata Yönetimi

TokenLab, OpenAI uyumlu hata yanıtları döndürür:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Ayrıntılar için [Hata Yönetimi Rehberi](/guides/error-handling) bölümüne bakın.
