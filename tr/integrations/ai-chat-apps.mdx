## Genel Bakış

Çoğu genel AI sohbet uygulaması, TokenLab'e standart OpenAI uyumlu sohbet yolu üzerinden bağlanır.

Uygulamada bu şu anlama gelir:
- Uygulama açıkça tam bir uç nokta (endpoint) URL'si istemediği sürece temel URL olarak `https://api.tokenlab.sh/v1` kullanın
- TokenLab API anahtarınızı OpenAI tarzı API anahtarı olarak kullanın
- Uygulamanın standart bir sohbet iş akışında kullanabileceği modelleri seçin

<Note>
Genel sohbet uygulamaları genellikle **chat-completions odaklıdır**, Codex Responses WebSocket istemcileri değildir. Responses'a özgü davranış gerektiren Codex CLI/App, Cursor veya diğer kodlama araçları için bunun yerine özel entegrasyon kılavuzlarını kullanın.
</Note>

<Note>
**Tür**: Sohbet Uygulaması

**Birincil Yol**: OpenAI uyumlu chat-completions

**Destek Güveni**: Desteklenen yol
</Note>

## Desteklenen Uygulamalar

| Uygulama | Platform | Notlar |
|-------------|----------|-------|
| Open WebUI | Web, Self-hosted | OpenAI uyumlu bağlantılara sahip popüler self-hosted seçeneği |
| LibreChat | Web, Self-hosted | Özel OpenAI uç noktalarına sahip çok sağlayıcılı sohbet çalışma alanı |
| LobeChat | Web, Masaüstü, Self-hosted | Güçlü özel sağlayıcı desteği |
| Cherry Studio | Windows, macOS, Linux | İyi OpenAI uyumlu sağlayıcı akışı |
| Chatbox | Windows, macOS, Linux | Basit OpenAI uyumlu kurulum |
| DeepChat | Windows, macOS, Linux | OpenAI uyumlu sağlayıcı ayarlarına sahip masaüstü istemcisi |
| Jan | Masaüstü, Self-hosted | Uzak OpenAI uyumlu sağlayıcılara sahip yerel öncelikli uygulama |
| TypingMind | Web, Masaüstü | Özel bir uç nokta stili kullanır |
| NextChat | Web, Self-hosted | Temel URL geçersiz kılma özellikli, hafif ChatGPT tarzı istemci |
| ChatWise | Windows, macOS | Standart özel sağlayıcı modeli |

## Varsayılan Bağlantı Değerleri

| Alan | Değer |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| API türü | OpenAI uyumlu |

Bir uygulama temel URL yerine **tam uç nokta URL'si** isterse şunları kullanın:
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## Örnek Uygulama Kurulumları

<Tabs>
  <Tab title="LobeChat">
**Kendi sunucunuzda barındırılan LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. **Settings** → **AI Service Provider** kısmını açın
    2. **OpenAI** seçeneğini seçin
    3. TokenLab API anahtarınızı girin
    4. Özel uç noktayı `https://api.tokenlab.sh/v1` olarak ayarlayın
  </Tab>

  <Tab title="Cherry Studio">
    1. **Settings** → **Model Provider** kısmını açın
    2. Bir **OpenAI-compatible** sağlayıcı ekleyin
    3. Şunları girin:
       - **Name**: TokenLab
       - **API Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. Kullanmak istediğiniz modelleri ekleyin
  </Tab>

  <Tab title="Chatbox">
    1. **Settings** → **AI Model** kısmını açın
    2. **OpenAI API Compatible** seçeneğini seçin
    3. Şunları girin:
       - **API Host**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini` veya `claude-sonnet-5`
  </Tab>

  <Tab title="TypingMind">
    1. **Settings** kısmını açın
    2. **Custom Endpoint** seçeneğini seçin
    3. Şunları girin:
       - **Endpoint URL**: `https://api.tokenlab.sh/v1/chat/completions`
       - **API Key**: `sk-your-tokenlab-key`
    4. Kullanıma açmak istediğiniz modelleri yapılandırın
  </Tab>

  <Tab title="Open WebUI">
    1. **Admin Settings** → **Connections** kısmını açın
    2. Bir **OpenAI-compatible** bağlantı ekleyin
    3. Şunları girin:
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. Kaydedin ve kullanıma açmak istediğiniz modelleri seçin
  </Tab>

  <Tab title="DeepChat">
    1. **Settings** -> **Model Provider** kısmını açın
    2. Bir OpenAI-compatible sağlayıcı ekleyin
    3. Şunları girin:
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini`
    4. Kaydedin ve bir test sohbeti çalıştırın
  </Tab>

  <Tab title="Jan">
    1. **Settings** -> **Providers** kısmını açın
    2. Uzak bir OpenAI-compatible sağlayıcı ekleyin
    3. Şunları girin:
       - **Provider name**: TokenLab
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. `gpt-5.4-mini` veya başka bir TokenLab modelini seçin
  </Tab>

  <Tab title="LibreChat">
    LibreChat sağlayıcı yapılandırmanıza OpenAI uyumlu bir uç nokta ekleyin ve şuraya yönlendirin:

    ```yaml
    customEndpoints:
      - name: TokenLab
        apiKey: '${OPENAI_API_KEY}'
        baseURL: 'https://api.tokenlab.sh/v1'
        models:
          default: ['gpt-5.4-mini', 'gpt-5.4', 'claude-sonnet-5']
          fetch: false
    ```
  </Tab>
</Tabs>

## İpuçları

<AccordionGroup>
  <Accordion title="Uygulama destekliyorsa temel URL'yi tercih edin">
    Çoğu uygulama, tam bir uç nokta URL'si yerine temel URL olarak `https://api.tokenlab.sh/v1` sağladığınızda daha kolay yapılandırılır ve daha az hata verir.
  </Accordion>

  <Accordion title="Önce daha küçük modelleri kullanın">
    Günlük sohbetler için `gpt-5.4-mini` veya `deepseek-v4-flash` ile başlayın, ardından daha ağır akıl yürütme görevleri için `gpt-5.4` veya `claude-opus-4-8` modellerine geçin.
  </Accordion>

  <Accordion title="Kodlama araçlarını ayrı tutun">
    Genel sohbet uygulamaları ve kodlama aracıları genellikle farklı uç nokta davranışlarına ihtiyaç duyar. Codex/Cursor tarzı araçları kendi özel entegrasyon sayfalarında tutun.
  </Accordion>
</AccordionGroup>

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı Hatası">
    - Temel URL'nin tam olarak `https://api.tokenlab.sh/v1` olduğunu doğrulayın
    - Uygulama otomatik olarak yol ekliyorsa sondaki eğik çizgileri (/) kaldırın
    - Uygulama tam bir uç nokta URL'si istiyorsa `https://api.tokenlab.sh/v1/chat/completions` kullanın
  </Accordion>

  <Accordion title="401 Unauthorized (Yetkisiz)">
    - API anahtarınızı tekrar kontrol edin
    - Anahtarın TokenLab panelinde aktif olduğunu onaylayın
    - Fazladan boşluk veya satır başı olmadığından emin olun
  </Accordion>

  <Accordion title="Model Kullanılamıyor">
    - Model adını tam olarak doğrulayın
    - `gpt-5.4-mini`, `deepseek-v4-flash` veya `claude-sonnet-5` gibi yaygın olarak desteklenen bir varsayılanı deneyin
    - TokenLab belgelerinden veya panelinden mevcut durumu kontrol edin
  </Accordion>
</AccordionGroup>
