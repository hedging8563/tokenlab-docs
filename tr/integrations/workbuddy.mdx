## Genel Bakış

<Note>
**Tür**: masaüstü kodlama ve görev ajanı

**Birincil yol**: OpenAI uyumlu Chat Completions

**Destek**: resmi özel model yolu
</Note>

[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model), OpenAI uyumlu modeller için görsel bir düzenleyici sunar; yerel model dosyasını elle düzenlemek gerekmez.

## TokenLab'i yapılandırma

**Settings → Model** bölümünü açın, model ekleyin ve **Custom** seçin.

| Alan | Değer |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key'iniz |
| Model name | `kimi-k3` |
| Custom Protocol | **Kapalı** |

<Warning>
Custom Protocol kapalı kalmalıdır. Standart mod Base URL'yi doğrular ve `/chat/completions` ekler. Açıkken yalnızca `/v1` girilirse istek yanlış yola gönderilir.
</Warning>

Araçları, görüntüleri, akıl yürütmeyi ve sınırları modelin güncel TokenLab ayrıntılarına göre ayarlayın. Hepsini açmayın veya başka modelin 1M/128K sınırlarını kopyalamayın. Gösterilen model kimliğini kullanın.

Kaydedip `kimi-k3` seçin ve salt okunur klasör incelemesiyle test edin. Ekran görüntüsü paylaşmadan önce Key ve özel endpoint'leri gizleyin.

Kaydetmek ve seçmek yalnızca yerel ayarı doğrular. Metin veya araç görevleri TokenLab bakiyesini kullanır; yanıtı [istek kaydıyla](https://tokenlab.sh/dashboard/runs?section=requests) karşılaştırın. Geri almak için önceki modeli seçip yalnızca eklenen TokenLab girdisini kaldırın.

Resmî uygulama macOS ve Windows için sunulur. [Resmî model düzenleyicisini](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) kullanın; Linux sürümü veya doğrudan yazılabilir dosya biçimi varsayılmaz.

[MCP API araçları](/tr/integrations/tokenlab-mcp-server) ve [Skill yönergeleri](/tr/integrations/coding-agent-skill) ayrı kurulur ve ana modeli değiştirmez.
