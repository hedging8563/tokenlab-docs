## Kapsam

Bu kılavuz macOS, Windows ve Linux üzerindeki **Cursor masaüstü düzenleyicisi** içindir. Resmî OpenAI BYOK desteği standart, akıl yürütmesiz sohbet modellerini kapsar; Tab tamamlama Cursor modellerini kullanmaya devam eder. OpenAI Base URL değişikliği tüm TokenLab modellerini veya Cursor özelliklerini açmaz. [Resmî sınırları](https://cursor.com/help/models-and-usage/api-keys) inceleyin.

Yalnızca görsel, video veya diğer API araçlarına ihtiyacınız varsa mevcut sohbet sağlayıcınızı koruyup [MCP](/tr/integrations/tokenlab-mcp-server) ekleyin. [Skill](/tr/integrations/coding-agent-skill), API kullanım talimatları sağlar; ana modeli değiştirmez.

## Mevcut ajanınıza verilecek görev

```text
https://docs.tokenlab.sh/tr/integrations/cursor adresini oku, kurulu sürümümü ve işletim sistemimi kontrol et.
TokenLab ana modeli, MCP araçları veya API Skill seçeneklerinden hangisine ihtiyacım olduğunu doğrula.
Mevcut hesapları, sağlayıcı ayarlarını ve izinleri koru; değişikliklerin nasıl geri alınacağını açıkla.
Sohbette API anahtarı isteme. Anahtarı yerel olarak girip gerekli arayüz adımlarını ben uygulayacağım.
Küçük bir doğrulama isteğinin maliyetini açıkla. Yalnızca bu testi açıkça seçtikten sonra çalıştırmaya ve TokenLab kaydıyla eşleştirmeye yardım et.
```

## Doğru ayarları açın

1. Masaüstü düzenleyicisini [Cursor Downloads](https://cursor.com/downloads) üzerinden kurun veya güncelleyin. Bu adımlar CLI ya da Cloud Agents için değildir.
2. Komut paletinden **Cursor Settings** açın veya `Cmd/Ctrl + Shift + J` kullanın. `Cmd/Ctrl + ,` genel düzenleyici ayarlarını açar.
3. **Models** bölümünde mevcut OpenAI yapılandırmasını geri yükleyebilmek için not edin. Diğer sağlayıcıları koruyun.
4. TokenLab anahtarını yerel olarak **OpenAI API Key** alanına girip kaydedin. Sohbete göndermeyin veya git’e eklemeyin.
5. **Override OpenAI Base URL** seçeneğini açıp şu adresi girin:

```text
https://api.tokenlab.sh/v1
```

BYOK istekleri de istemi oluşturmak için Cursor sunucularından geçer. Düzenleyici TokenLab’e doğrudan bağlanmaz.

## Model seçin

Güncel [TokenLab kataloğundan](https://tokenlab.sh/tr/models) tam model kimliğini kopyalayın ve Cursor’ın OpenAI BYOK desteğini kontrol edin. TokenLab’de chat kategorisinde olması Cursor uyumluluğunu kanıtlamaz.

İlk metin testi için hâlâ sunuluyorsa akıl yürütmesiz bir örnek olarak `gpt-4.1-mini` kullanılabilir. **Models** içindeki mevcut kaydı etkinleştirin; yoksa **Add model** ile ekleyip sohbette seçin. Yerleşik modeli farklı yazımla tekrar eklemeyin; Claude veya Gemini’nin OpenAI override kullandığını varsaymayın. [Cursor açıklamasına](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488) bakın.

## Küçük bir istekle doğrulayın

Seçilen modelle yeni sohbet açıp şunu gönderin:

```text
Yalnızca TOKENLAB_CONNECTION_OK yanıtını ver. Araç kullanma ve dosya değiştirme.
```

Bu istek ücretlidir. Yanıtı ve [TokenLab istek kayıtlarındaki](https://tokenlab.sh/dashboard/runs?section=requests) model, zaman ve durumu karşılaştırın. Modelin görünmesi veya eşleşen kayıt olmadan yanıt alınması bu yolu doğrulamaz.

## Hata durumunda

- **Model yok veya reddediliyor:** kimliği ve BYOK desteğini kontrol edin; varsa yerleşik kaydı kullanın. Yeniden başlatmak uyumsuzluğu çözmez.
- **Kimlik doğrulama hatası:** OpenAI alanındaki TokenLab anahtarını ve Base URL’yi kontrol edin. Bakiye veya kota hatası geçersiz anahtardan farklıdır.
- **TokenLab kaydı yok:** sohbet modelini, override ayarını ve Cursor hatasını kontrol edin. Tab tamamlama bu bağlantıyı sınamaz.
- **Başka sağlayıcı çalışmıyor:** önceki OpenAI ayarlarını geri yükleyin veya override seçeneğini kapatıp yeni sohbet açın.

## MCP ve Skills öğelerini ayrı ekleyin

[MCP](/tr/integrations/tokenlab-mcp-server), Cursor MCP ayarları veya `.cursor/mcp.json` üzerinden çağrılabilir araçlar ekler. Önce araç keşfini kontrol edin, ardından yalnızca gereken ücretli üretimleri çalıştırın. MCP ana modeli değiştirmez.

[Skills](/tr/integrations/coding-agent-skill), API talimatları sunar. `SKILL.md` ve başvuru dosyalarıyla birlikte tüm klasörü `.cursor/skills/tokenlab-api-integration/` konumuna koyun ve **Customize → Skills** bölümünü kontrol edin. Skill anahtar sağlamaz veya MCP sunucusu kurmaz. Sürümünüze ait resmî [MCP](https://cursor.com/docs/mcp) ve [Skills](https://cursor.com/docs/skills) kılavuzlarına bakın.
