## Genel Bakış

OpenAI Agents SDK, OpenAI uyumlu bir istemci ve `OpenAIChatCompletionsModel` aracılığıyla TokenLab'i kullanabilir.

<Note>
**Tür**: Python Agent SDK

**Birincil Yol**: OpenAI uyumlu chat completions

**Destek Güveni**: Desteklenen chat-completions yolu
</Note>

## Ortam

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
export TOKENLAB_MODEL="gpt-5.4-mini"
```

## Örnek

```python
import asyncio
import os

from openai import AsyncOpenAI

from agents import Agent, OpenAIChatCompletionsModel, Runner, set_tracing_disabled

client = AsyncOpenAI(
    base_url=os.getenv("TOKENLAB_BASE_URL", "https://api.tokenlab.sh/v1"),
    api_key=os.environ["TOKENLAB_API_KEY"],
)

set_tracing_disabled(disabled=True)


async def main():
    agent = Agent(
        name="Assistant",
        instructions="You are concise and practical.",
        model=OpenAIChatCompletionsModel(
            model=os.getenv("TOKENLAB_MODEL", "gpt-5.4-mini"),
            openai_client=client,
        ),
    )

    result = await Runner.run(agent, "Explain custom model providers in one paragraph.")
    print(result.final_output)


asyncio.run(main())
```

## Kapsam

Bu yol, Chat Completions uyumluluğunu kullanır. TokenLab'in yerel Responses uç noktası `https://api.tokenlab.sh/v1/responses` adresinde mevcuttur, ancak OpenAI'a özgü Responses semantiğine bağlı SDK özellikleri, üretim ortamında kullanımdan önce tam model ve iş akışı ile doğrulanmalıdır.
