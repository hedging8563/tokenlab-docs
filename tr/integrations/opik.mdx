## Genel Bakış

Opik, TokenLab'in OpenAI uyumlu uç noktasına işaret eden bir OpenAI istemcisini sarmalayarak (wrap) TokenLab çağrılarını günlüğe kaydedebilir.

<Note>
**Tür**: Gözlemlenebilirlik (Observability)

**Birincil Yol**: OpenAI SDK izleme sarmalayıcısı

**Destek Güveni**: Desteklenen OpenAI uyumlu izleme yolu
</Note>

## Kurulum

```bash
pip install opik openai
```

## Ortam

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export OPIK_PROJECT_NAME="tokenlab-integration-demo"
```

## OpenAI İstemcisini Sarmalama

Örneği çalıştırmadan önce Opik’i yapılandırın: Opik Cloud için `OPIK_API_KEY` ve gerektiğinde `OPIK_WORKSPACE` gerekir. Mevcut bir kendi sunucunuzda barındırılan dağıtım için `OPIK_URL_OVERRIDE` değerini `http://localhost:5173/api` gibi API URL’sine ayarlayın. [Opik yapılandırma kılavuzuna](https://www.comet.com/docs/opik/tracing/advanced/sdk_configuration) bakın.

```python
import os

from openai import OpenAI
from opik.integrations.openai import track_openai

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

openai_client = track_openai(client)
```

## Sohbet Tamamlama (Chat Completion) Günlüğü

```python
completion = openai_client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[
        {"role": "user", "content": "Summarize why LLM observability matters."}
    ],
)

print(completion.choices[0].message.content)
```

## Uç Nokta Notları

Bu kurulum, OpenAI uyumlu SDK yolunu izler. OpenAI SDK dışında TokenLab yerel uç noktalarını kullanıyorsanız, ilgili istemciyi veya iş akışını ayrıca izleyin (instrument).
