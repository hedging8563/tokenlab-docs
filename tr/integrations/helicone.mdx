## Genel Bakış

Helicone, TokenLab'in OpenAI uyumlu isteklerini Helicone Gateway üzerinden yönlendirerek ve TokenLab'i hedef alarak proxy yapabilir ve gözlemleyebilir.

<Note>
**Tür**: Gözlemlenebilirlik (Observability) Gateway

**Birincil Yol**: Helicone Gateway üzerinden OpenAI uyumlu sohbet tamamlama (chat completions)

**Destek Güveni**: Desteklenen gözlemlenebilirlik yolu
</Note>

## Ortam

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## Kapsam

Bu kurulum, OpenAI uyumlu `/v1` trafiği içindir. TokenLab ayrıca yerel (native) Responses, Anthropic Messages ve Gemini uyumlu uç noktalar da sunar; gözlemlenebilirlik proxy'niz açıkça desteklemediği sürece bu yerel formatlar için doğrudan TokenLab rotalarını kullanın.
