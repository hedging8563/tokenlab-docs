## Genel Bakış

CrewAI, model, API anahtarı ve base URL'yi ortam değişkenleri veya `LLM` sınıfı üzerinde ayarlayarak OpenAI uyumlu LLM'leri destekler.

<Note>
**Tür**: Ajan Çerçevesi (Agent Framework)

**Birincil Yol**: OpenAI uyumlu sohbet tamamlama (chat completions)

**Destek Güveni**: Desteklenen özel uç nokta yolu
</Note>

## Ortam Değişkenleri

```python
import os

os.environ["OPENAI_API_KEY"] = "sk-your-tokenlab-key"
os.environ["OPENAI_API_BASE"] = "https://api.tokenlab.sh/v1"
os.environ["OPENAI_MODEL_NAME"] = "openai/claude-sonnet-5"
```

## LLM Sınıfı

```python
from crewai import Agent, LLM

llm = LLM(
    model="claude-sonnet-5",
    custom_openai=True,
    base_url="https://api.tokenlab.sh/v1",
    api_key="sk-your-tokenlab-key",
)

agent = Agent(
    role="Research analyst",
    goal="Summarize technical tradeoffs clearly",
    backstory="You produce concise implementation notes.",
    llm=llm,
)
```

## Model Önerileri

Rutin görevler için `gpt-5.4-mini`, planlama ağırlıklı ajanlar için `claude-sonnet-5` veya `gpt-5.4` ve daha hızlı, düşük maliyetli yinelemeler için `deepseek-v4-flash` kullanın.

## Uç Nokta Notları

CrewAI'nin OpenAI uyumlu yolu, Chat Completions tarzı ajan çağrıları için en uygun olanıdır. TokenLab yerel uç noktalarını yalnızca seçtiğiniz araç veya SDK bu yerel protokolleri desteklediğinde doğrudan kullanın.
