## Skill ne yapar

- TokenLab chat, image, audio, video, translation ve diğer API aileleri için minimum çalıştırılabilir örnekler üretir.
- OpenAI uyumlu client’lar için `https://api.tokenlab.sh/v1` kullanır ve native Anthropic veya Gemini route’larına ne zaman geçileceğini açıklar.
- Eskimiş listelerden tahmin etmek yerine `/v1/models`, `/llms.txt` ve `recommended_for` kısa listeleriyle modelleri keşfeder.
- Non-chat istekleri tekrar denemeden önce modelin model details bilgisini okur; desteklenmeyen alanlar sessizce atılmaz.
- `did_you_mean`, `suggestions`, `retry_after`, `recommended_request` gibi Agent-First hata ipuçlarını işler.

## Önerilen Agent iş akışı

Güncel model listesini, ardından seçilen modelin `tokenlab.accepted_request_formats` ve açık istek alanlarını okuyun. Konuşma ve araç çağrılarında aynı biçimi koruyun; alanlar biçimler arasında otomatik dönüştürülmez. Hata olduğunda seçilmiş modeli veya protokolü kendiliğinizden değiştirmeyin.

## Minimum chat örneği

Bu örnek OpenAI Python SDK ile TokenLab base URL kullanır:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "Hello!"}],
)

print(response.choices[0].message.content)
```

Şununla çalıştırın:

```bash
pip install openai
export TOKENLAB_API_KEY="sk-your-api-key"
python app.py
```

## Model keşfi ve model details’lar

Eskimiş paket listeleri yerine canlı keşfi tercih edin:

```bash
# Makine tarafından okunabilir API özeti
curl https://api.tokenlab.sh/llms.txt

# Modelleri listele
curl "https://api.tokenlab.sh/v1/models" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?category=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Sıralı non-chat kısa listeleri
curl "https://api.tokenlab.sh/v1/models?recommended_for=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=video" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=translation" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Non-chat isteği tekrar denemeden önce tek modelin model details bilgisini oku
curl "https://api.tokenlab.sh/v1/models/gpt-image-2" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Yalnızca fiyat ayrıntısı
curl "https://api.tokenlab.sh/v1/models/gpt-image-2/pricing" -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Native protokol seçimi

Yaygın chat, image, embedding, audio ve rerank örnekleri için OpenAI uyumlu `/v1` varsayılan yoldur. Native protokol kullanılabilirliğini model ya da sağlayıcı adından veya Chat yanıt başlıklarından çıkarmayın. `GET /v1/models/{model}` isteğini okuyun ve yalnızca model ayrıntılarında ilan edilen bir istek biçimini kullanın.

Okunacak alan `tokenlab.accepted_request_formats` değeridir.

Protokol uç noktaları Chat Completions için `/v1/chat/completions`, Responses için `/v1/responses`, Messages için `/v1/messages` ve Gemini için `/v1beta/models/{model}:generateContent` şeklindedir.

## Agent-First hata toparlama

Hatalar, coding agent’ların dokümanı kazımadan ayrıştırabileceği alanlar içerir:

Önce HTTP durumunu ve hata `code` alanını kullanın. Yanlış ad için `did_you_mean` yol gösterebilir; kullanıcı seçmeden modeli değiştirmeyin. `429` için `Retry-After` veya `retry_after` değerine uyun; yalnızca hata izin verdiğinde ve yeniden deneme açıkça seçildiğinde tekrar deneyin. Doğrulama, kimlik doğrulama, bakiye ve izin hatalarını önce düzeltin. Oluşturma isteği zaman aşımına uğrarsa tekrar göndermeden önce mevcut görevi kontrol edin.

## Desteklenen API aileleri

| Aile | Birincil yol |
|---|---|
| Chat ve Responses | `/v1/chat/completions`, `/v1/responses` |
| Claude-yerel mesajlar | `/v1/messages` |
| Gemini-native istekler | `/v1beta/models/{model}:generateContent` |
| Görseller | `/v1/images/generations`, `/v1/images/edits` |
| Video | `/v1/videos/generations` |
| Müzik | `/v1/music/generations` |
| Worlds | `/v1/worlds/generations` ve world status ile media asset endpoint’leri |
| 3D | `/v1/3d/generations` |
| Ses | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| Realtime | `/v1/realtime?model={model}` |
| Embeddings ve rerank | `/v1/embeddings`, `/v1/rerank` |
| Metin çevirisi | `/v1/translations` |
