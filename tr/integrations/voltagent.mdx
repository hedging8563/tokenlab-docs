## Genel Bakış

VoltAgent, AI SDK dil modellerini doğrudan kabul eder. OpenAI uyumlu bir AI SDK sağlayıcısını TokenLab'in `/v1` temel URL'si ile yapılandırın ve seçilen modeli ajanıza aktarın.

<Note>
**Tür**: TypeScript ajan çerçevesi

**Birincil Yol**: AI SDK aracılığıyla OpenAI uyumlu Sohbet Tamamlama (Chat Completions)

**Destek Güveni**: Desteklenen OpenAI uyumlu yol
</Note>

## Kurulum

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## Ortam

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Doğrudan AI SDK Sağlayıcısı

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## Model Yönlendirici (Router) Yolu

VoltAgent kayıt defteri anlık görüntünüz `models.dev` adresinden bir TokenLab sağlayıcı girişi içeriyorsa, şunları yapılandırın:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

Ardından kayıt defteri model dizgisini kullanın, örneğin `tokenlab/claude-sonnet-5`.

## Uç Nokta Notları

Doğrudan AI SDK yolu en açık kurulumdur. TokenLab yerel Yanıtlarını, Anthropic Mesajlarını veya Gemini uç noktalarını yalnızca seçtiğiniz AI SDK sağlayıcısı/istemcisi bu protokol için yapılandırıldığında kullanın.
