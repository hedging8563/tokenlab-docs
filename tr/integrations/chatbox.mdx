## Genel Bakış

Chatbox, TokenLab'i OpenAI uyumlu API ayarları aracılığıyla kullanabilir.

<Note>
**Tür**: Sohbet Uygulaması

**Birincil Yol**: OpenAI uyumlu sohbet tamamlamaları

**Destek Güveni**: Desteklenen yol
</Note>

## Chatbox Yapılandırması

1. **Settings** -> **Model Provider** -> **Add** -> **Add Custom Provider** kısmını açın
2. **Name** değerini TokenLab, **API Mode** değerini **OpenAI API Compatible** olarak ayarlayın ve **Add** düğmesine tıklayın.
3. Şunları girin:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Path**: `/chat/completions`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. Kaydedin ve kısa bir test mesajı gönderin.

## Önerilen Modeller

| Kullanım Durumu | Model |
|----------|-------|
| Günlük sohbet | `gpt-5.4-mini` |
| Daha güçlü muhakeme | `gpt-5.4` veya `gpt-5.5` |
| Claude tarzı çıktı | `claude-sonnet-5` |
| Hızlı yedekleme | `deepseek-v4-flash` |

## Notlar

Eğer Chatbox sürümünüzde TokenLab yerleşik bir sağlayıcı olarak zaten listeleniyorsa, doğrudan onu seçin. Değilse, yukarıdaki OpenAI uyumlu sağlayıcı yolu en güvenli yedek yöntemdir.
