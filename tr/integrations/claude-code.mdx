## Genel Bakış



<Note>
**Tür**: Kodlama aracı

**Birincil yol**: Anthropic-native

**Destek seviyesi**: Güçlü native path
</Note>

[Claude Code](https://code.claude.com/docs/en/setup), AI destekli kodlama için Anthropic'in resmi CLI aracıdır. API sağlayıcısı olarak TokenLab'yı kullanacak şekilde yapılandırabilirsiniz.

## Kurulum

Anthropic artık yerel yükleyiciyi önermektedir. npm kurulumu uyumluluk için hâlâ mevcuttur, ancak upstream tarafta kullanımdan kaldırılmıştır.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Özellikle npm paketine ihtiyacınız varsa, şunu kullanın:

```bash
npm install -g @anthropic-ai/claude-code
```

<Warning>
Claude Code için `sudo npm install -g` kullanmayın.
</Warning>

## Yapılandırma

### Ortam Değişkenleri

Aşağıdaki ortam değişkenlerini ayarlayın:

```bash
export ANTHROPIC_API_KEY="sk-your-tokenlab-key"
export ANTHROPIC_BASE_URL="https://api.tokenlab.sh"
```

Kalıcı olması için bunları shell profilinize (`~/.bashrc`, `~/.zshrc` vb.) ekleyin.

<Note>
TokenLab için `ANTHROPIC_BASE_URL` değerini `/v1` son eki olmadan `https://api.tokenlab.sh` olarak tutun. Bu, Claude Code tarafından belgelenen Anthropic tarzı endpoint yapısı ve birleşik gateway deseni ile eşleşir.
</Note>

### Yapılandırma Dosyası

Alternatif olarak, `~/.claude/settings.json` dosyasını oluşturun veya düzenleyin:

Hesapları veya izinleri değiştirmeden ayarları yedekleyip birleştirin. `ANTHROPIC_API_KEY`, `X-Api-Key`; `ANTHROPIC_AUTH_TOKEN` ise Bearer token gönderir. Bir kimlik doğrulama yolu seçin. `/status` model ve ayar kaynağını gösterir, ücretli istek başarısını kanıtlamaz. Kısa testten sonra yanıtı TokenLab kaydıyla karşılaştırın. Geri almak için yalnızca eklediklerinizi kaldırın. [Öncelik sırasına](https://code.claude.com/docs/en/settings) bakın.

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  }
}
```

## Kullanım

Yapılandırmadan sonra Claude Code'u normal şekilde kullanın:

```bash
# Start an interactive session
claude

# Run a single command
claude "Explain this code" < main.py

```

Gerekirse kurulumu doğrulayın:

```bash
claude --version
claude doctor
```

## Kullanılabilir Modeller

TokenLab tüm Claude modellerini destekler:

| Model | Açıklama |
|-------|-------------|
| `claude-opus-4-6` | En yetenekli, karmaşık akıl yürütme |
| `claude-sonnet-4-6` | Dengeli performans, kodlama için mükemmel |
| `claude-haiku-4-5` | En hızlı, maliyet açısından verimli |

## Model Seçimi

`--model` bayrağı ile bir model belirtin:

```bash
claude --model claude-sonnet-4-6 "Review this PR"
```

Veya yapılandırmanızda varsayılan bir model ayarlayın:

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  },
  "model": "claude-sonnet-5"
}
```

## Genişletilmiş düşünme

Karmaşık akıl yürütme görevleri için extended thinking özellikli modelleri kullanın:

```bash
claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı hataları">
    Base URL'nin tam olarak `https://api.tokenlab.sh` olduğunu doğrulayın (Anthropic tarzı istekler için `/v1` son eki olmadan).
  </Accordion>

  <Accordion title="Geçersiz API key">
    TokenLab API key'inizin `sk-` ile başladığından ve yeterli bakiyeye sahip olduğundan emin olun.
  </Accordion>

  <Accordion title="Gateway Authorization bearer token gerektiriyor">
    Claude Code'un gateway modu `ANTHROPIC_AUTH_TOKEN` desteği de sunar. Gateway kimlik doğrulama davranışınızı bilerek değiştirmediğiniz sürece standart TokenLab kurulumu için `ANTHROPIC_API_KEY` kullanmaya devam edin.
  </Accordion>

  <Accordion title="Model bulunamadı">
    Model adının doğru olduğunu kontrol edin. `claude-sonnet-4-6` biçimini kullanın.
  </Accordion>
</AccordionGroup>
