## Genel Bakış



<Note>
**Tür**: Kodlama aracı

**Birincil yol**: Anthropic-native

**Destek seviyesi**: Güçlü native path
</Note>

[Claude Code](https://code.claude.com/docs/en/setup), AI destekli kodlama için Anthropic'in resmi CLI aracıdır. API sağlayıcısı olarak TokenLab'yı kullanacak şekilde yapılandırabilirsiniz.

## Kurulum

Anthropic artık yerel yükleyiciyi önermektedir. npm kurulumu uyumluluk için hâlâ mevcuttur, ancak upstream tarafta kullanımdan kaldırılmıştır.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Özellikle npm paketine ihtiyacınız varsa, şunu kullanın:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
Claude Code için `sudo npm install -g` kullanmayın.
</Warning>

## Yapılandırma

[Hızlı başlangıç](/tr/quickstart) içindeki macOS, Linux, WSL veya Windows PowerShell adımlarıyla anahtarı komut geçmişine yazmadan `TOKENLAB_API_KEY` değerini ayarlayın. Claude Code’u aynı terminalden başlatın. Sürekli kullanım için yerel bir sır yöneticisi kullanın; shell profiline düz metin anahtar eklemeyin.

Bu değişkenler yalnızca bu başlatma için geçerlidir; kayıtlı hesap, varsayılan model ve izinler korunur. Önceki yapılandırma için bu değişkenler olmadan normal başlatın. Bunları kabuk profiline kaydetmeyin.

Bu oturum yolu Claude Code **2.1.263** ve `ANTHROPIC_AUTH_TOKEN` üzerinden Bearer kimlik doğrulaması kullanır. Base URL sonuna `/v1` eklemeyin. Kayıtlı `env` değerleri, kimlik yardımcıları, bulut seçenekleri veya yönetilen politikalar kimlik doğrulamayı etkileyebilir; başlamadan kontrol edin. Çakışma varsa hesapları silmek ya da politikaları gevşetmek yerine aşağıdaki yardımcıyı kullanın. Model ve izinleri `/status` ile kontrol edin.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

İsteğe bağlı: Python 3.11+ ile [geri alınabilir Claude Code yapılandırma yardımcısı](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md) önizleme, uygulama ve özgün dosyayı geri yükleme sunar. Kurulu eklenti veya bağımsız Skill için [README güncelleme adımlarını](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) izleyip betiğin bulunduğunu doğrulayın. Bu sayfadaki elle yapılandırma yardımcı olmadan da tamamlanabilir.

Ayarları kaydetmek veya modelleri listelemek anahtarı ya da tamamlanmış bir isteği doğrulamaz. İstem TokenLab bakiyesini kullanır. Araçları denemeden önce yanıtı ve ilgili [istek kaydını](https://tokenlab.sh/dashboard/runs?section=requests) kontrol edin; yardımcı istekler de ücretlendirilebilir.

## Kullanım

Yapılandırmadan sonra Claude Code'u normal şekilde kullanın:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Gerekirse kurulumu doğrulayın:

```bash
claude --version
claude doctor
```

## Kullanılabilir Modeller

TokenLab tüm Claude modellerini destekler:

| Model | Açıklama |
|-------|-------------|
| `claude-opus-4-6` | En yetenekli, karmaşık akıl yürütme |
| `claude-sonnet-4-6` | Dengeli performans, kodlama için mükemmel |
| `claude-haiku-4-5` | En hızlı, maliyet açısından verimli |

## Model Seçimi

`--model` bayrağı ile bir model belirtin:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Genişletilmiş düşünme

Karmaşık akıl yürütme görevleri için extended thinking özellikli modelleri kullanın:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı hataları">
    Base URL'nin tam olarak `https://api.tokenlab.sh` olduğunu doğrulayın (Anthropic tarzı istekler için `/v1` son eki olmadan).
  </Accordion>

  <Accordion title="Geçersiz API key">
    TokenLab API key'inizin `sk-` ile başladığından ve yeterli bakiyeye sahip olduğundan emin olun.
  </Accordion>


  <Accordion title="Model bulunamadı">
    Model adının doğru olduğunu kontrol edin. `claude-sonnet-4-6` biçimini kullanın.
  </Accordion>
</AccordionGroup>
