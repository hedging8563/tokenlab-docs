## Genel Bakış

TokenLab’i Portkey’de OpenAI uyumlu özel bir host olarak yapılandırın. Responses’ı yalnızca Portkey sürümünüz özel bir Responses uç noktasını destekliyorsa kullanın.

<Note>
**Tür**: AI Gateway

**Birincil Yollar**: OpenAI uyumlu sohbet tamamlama ve Responses

**Destek Güveni**: Desteklenen yol
</Note>

## Sağlayıcı Değerleri

| Alan | Değer |
|-------|-------|
| Provider | `openai` |
| Custom Host | `https://api.tokenlab.sh/v1` |
| API key | `sk-your-tokenlab-key` |
| Model | Şu anda kullanılabilen bir TokenLab model kimliği |

## Sohbet Tamamlama (Chat Completions)

OpenAI uyumlu sohbet istekleri için TokenLab kullanın:

Bu örnek, çalışan ve kendi sunucunuzda barındırılan bir Portkey Gateway gerektirir. Gateway URL’sini dağıtımınızın URL’siyle değiştirin. Portkey Cloud için Portkey API anahtarınızı ayrıca `x-portkey-api-key` başlığında gönderin. [Portkey yapılandırma kılavuzuna](https://portkey.ai/docs/api-reference/inference-api/headers) bakın.

```bash
curl https://your-portkey-gateway.example/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-portkey-provider: openai" \
  -H "x-portkey-custom-host: https://api.tokenlab.sh/v1" \
  -H "Authorization: Bearer sk-your-tokenlab-key" \
  -d '{
    "model": "gpt-5.6-luna",
    "messages": [{"role": "user", "content": "Say hello from TokenLab."}]
  }'
```

## Responses

Portkey sürümünüz özel bir Responses URL’sini destekliyorsa [modeller sayfasından](https://tokenlab.sh/tr/models) şu anda kullanılabilen ve Responses destekleyen bir model seçip `/v1/responses` kullanın.

## Yerel Uç Nokta (Native Endpoint) Notu

Anthropic Messages ve Gemini, yalnızca Portkey sürümünüz bu biçimler için özel URL’leri destekliyorsa Portkey üzerinden kullanılabilir.
