## Genel Bakış

<Note>
**Tür**: kodlama ajanı CLI

**Birincil yol**: OpenAI uyumlu Chat Completions

**Destek**: resmi BYOK yolu
</Note>

[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models), OpenAI Chat Completions uyumlu herhangi bir endpoint'e bağlanabilir.

## Kurulum ve yapılandırma

```bash
npm install -g @github/copilot@1.0.85
copilot --version
```

npm kurulumu Node.js 22 veya üstünü gerektirir.

[Hızlı başlangıç](/tr/quickstart) içindeki macOS, Linux, WSL veya Windows PowerShell adımlarıyla anahtarı komut geçmişine yazmadan `TOKENLAB_API_KEY` değerini ayarlayın. Copilot CLI’u aynı terminalden başlatın. Sürekli kullanım için yerel bir sır yöneticisi kullanın; shell profiline düz metin anahtar eklemeyin.

Bu değişkenler yalnızca bu başlatma için geçerlidir; kayıtlı hesap, varsayılan model ve izinler korunur. Önceki yapılandırma için bu değişkenler olmadan normal başlatın. Bunları kabuk profiline kaydetmeyin.

<CodeGroup>
```bash macOS / Linux / WSL
COPILOT_PROVIDER_TYPE=openai COPILOT_PROVIDER_BASE_URL=https://api.tokenlab.sh/v1 COPILOT_PROVIDER_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" copilot --model kimi-k3
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['COPILOT_PROVIDER_TYPE'] = [Environment]::GetEnvironmentVariable('COPILOT_PROVIDER_TYPE', 'Process')
$previous['COPILOT_PROVIDER_BASE_URL'] = [Environment]::GetEnvironmentVariable('COPILOT_PROVIDER_BASE_URL', 'Process')
$previous['COPILOT_PROVIDER_API_KEY'] = [Environment]::GetEnvironmentVariable('COPILOT_PROVIDER_API_KEY', 'Process')
try {
  $env:COPILOT_PROVIDER_TYPE = 'openai'
  $env:COPILOT_PROVIDER_BASE_URL = 'https://api.tokenlab.sh/v1'
  $env:COPILOT_PROVIDER_API_KEY = $env:TOKENLAB_API_KEY
  copilot --model kimi-k3
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Model hem akışı hem de araç çağrısını desteklemelidir. `kimi-k3` araç kullanımını ve GitHub'ın önerdiği 128K'dan büyük bağlamı destekler.

Dosyaları değiştirmeyen salt okunur bir görevle başlayın. Model bulunamazsa [güncel TokenLab kataloğundaki](https://tokenlab.sh/tr/models) model kimliğini sağlayıcı öneki olmadan kullanın.

<Warning>
API Key'leri Git tarafından izlenen dosyalarda saklamayın. Terminal geçmişinde, ekran görüntüsünde veya loglarda görünen Key'leri yenileyin.
</Warning>

Ayarları kaydetmek veya modelleri listelemek anahtarı ya da tamamlanmış bir isteği doğrulamaz. İstem TokenLab bakiyesini kullanır. Araçları denemeden önce yanıtı ve ilgili [istek kaydını](https://tokenlab.sh/dashboard/runs?section=requests) kontrol edin; yardımcı istekler de ücretlendirilebilir.
