## Genel Bakış

<Note>
**Tür**: IDE ve CLI kodlama ajanı

**Birincil yol**: OpenAI uyumlu Chat Completions

**Destek**: resmi özel sağlayıcı yolu
</Note>

[Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible), VS Code uzantısında ve CLI'da OpenAI uyumlu sağlayıcıları destekler.

## Kurulum ve arayüz

VS Code'da **Kilo Code** ön sürüm kanalını veya CLI'ı kurun:

```bash
npm install -g @kilocode/cli
kilo --version
```

**Settings → Providers → Custom provider** bölümünü açın.

| Alan | Değer |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | TokenLab API Key'iniz |
| Model | `kimi-k3` |

Kilo modelleri `/v1/models` üzerinden otomatik algılar. Kaydettikten sonra `tokenlab/kimi-k3` seçin.

## CLI yapılandırması

Key'i ortam değişkeninde saklayın ve güvenilir genel dosya `~/.config/kilo/kilo.jsonc` içinde yapılandırın:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

Kilo'yu yeniden başlatıp `kilo models` çalıştırın. `{env:...}` yalnızca güvenilir genel veya yönetilen yapılandırmada çözülür. Gerçek Key'i Git'e gidebilecek proje yapılandırmasına yazmayın.
