## Genel Bakış

Open WebUI, özel OpenAI uyumlu API bağlantılarını destekler. TokenLab'i uzak bir OpenAI uyumlu uç nokta olarak ekleyin ve model listesini yenileyin.

<Note>
**Tür**: Web Sohbet Uygulaması

**Birincil Yol**: OpenAI uyumlu sohbet tamamlamaları

**Destek Güveni**: Desteklenen sohbet uygulaması yolu
</Note>

## Yönetici Bağlantısı

1. **Admin Panel** -> **Settings** -> **Connections** yolunu izleyin.
2. OpenAI API bağlantısı alanında bir bağlantı ekleyin.
3. Temel URL'yi (base URL) `https://api.tokenlab.sh/v1` olarak ayarlayın.
4. API anahtarını TokenLab anahtarınız olarak ayarlayın.
5. Bağlantıyı kaydedin ve modelleri yenileyin.

## Değerler

| Alan | Değer |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Örnek model | `gpt-5.4-mini` |

## Önerilen Modeller

- Genel sohbet için `gpt-5.4-mini`
- Yazma ve mantık yürütme için `claude-sonnet-5`
- Kod ağırlıklı sohbet için `deepseek-v4-pro`
- Hızlı ve çok modlu iş akışları için `gemini-3.5-flash`

Model kimliklerini elle belirtmek için bu bağlantıyı düzenleyip **Advanced** → **Model IDs (Filter)** bölümünü açın. TokenLab model kimliklerini tam olarak ekleyin ve kaydedin.
