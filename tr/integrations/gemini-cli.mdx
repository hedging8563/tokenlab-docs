## Genel Bakış

Gemini CLI **0.60.0**, API anahtarı kimlik doğrulaması için `GOOGLE_GEMINI_BASE_URL` değişkenini belgeler. TokenLab’in yerel Gemini uç noktasını `gemini_generate_content` destekleyen güncel bir modelle kullanın. [Resmî yapılandırmaya](https://geminicli.com/docs/reference/configuration/) ve [kimlik doğrulama kılavuzuna](https://geminicli.com/docs/get-started/authentication/) bakın. Bu kurulum Google aboneliğini TokenLab üzerinden yönlendirmez.

## Kurulum

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## Yapılandırma

[Hızlı başlangıç](/tr/quickstart) içindeki macOS, Linux, WSL veya Windows PowerShell adımlarıyla anahtarı komut geçmişine yazmadan `TOKENLAB_API_KEY` değerini ayarlayın. Gemini CLI’u aynı terminalden başlatın. Sürekli kullanım için yerel bir sır yöneticisi kullanın; shell profiline düz metin anahtar eklemeyin.

Mevcut Google girişini ve yapılandırmayı koruyun. TokenLab için `~/.gemini-tokenlab` (PowerShell’de `$HOME`) gibi kullanılmayan bir kök seçip içinde `.gemini` oluşturun. Mevcut `.gemini/settings.json` ve gerekli politika dosyalarını karşılık gelen konumlara kopyalayın; izinleri, sandbox ve diğer ayarları koruyun. Aşağıdaki kimlik alanını yalnızca bu kopyaya birleştirin; dosya yoksa oluşturun. OAuth önbelleklerini kopyalamayın veya eski kimlik bilgilerini silmeyin. Yönetilen kimlik politikalarına uyun.

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## Kullanım

Aşağıdaki başlatma `~/.gemini-tokenlab/.gemini/settings.json` kullanır. Başka kök seçtiyseniz yolu değiştirin. Çalışma dizinini normal güven istemiyle onaylayın ve araç onay politikalarını koruyun. Model bu oturum için açıkça seçilir.

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Bu değişkenler yalnızca bu başlatma için geçerlidir; kayıtlı hesap, varsayılan model ve izinler korunur. Önceki yapılandırma için bu değişkenler olmadan normal başlatın. Bunları kabuk profiline kaydetmeyin.

## Doğrulama

Ayarları kaydetmek veya modelleri listelemek anahtarı ya da tamamlanmış bir isteği doğrulamaz. İstem TokenLab bakiyesini kullanır. Araçları denemeden önce yanıtı ve ilgili [istek kaydını](https://tokenlab.sh/dashboard/runs?section=requests) kontrol edin; yardımcı istekler de ücretlendirilebilir.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
