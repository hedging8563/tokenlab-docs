## Pi kurulumu ve yapılandırması

[Resmî kurulumu](https://pi.dev/) kullanın. npm paketi `@earendil-works/pi-coding-agent` adını taşır. Windows varsayılan olarak Git Bash kullanır; [kabuk ayarlarına](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md) bakın. Pi kuruluysa kurulumu atlayın.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi --version
```

Bunları `~/.pi/agent/models.json` dosyasına veya `PI_CODING_AGENT_DIR` dizinine birleştirin. Dosyayı yedekleyin ve diğer sağlayıcıları koruyun. `TOKENLAB_API_KEY` değişkenini yerel başlatma ortamında tanımlayın, sohbete yapıştırmayın. Yalnızca Base URL değişkeni sağlayıcıyı oluşturmaz.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

`"$TOKENLAB_API_KEY"` içindeki `$` zorunludur; olmazsa değer düz metin sayılır. Chat Completions ve araçları destekleyen güncel bir model seçin. Sınırları, görüntü ve akıl yürütme seçeneklerini model ayrıntılarına göre ayarlayın.

## Kontrol ve geri alma

`pi --list-models` komutunu çalıştırıp `/model` içinde `tokenlab/gpt-5.6-luna` seçin. Seçici `models.json` dosyasını yeniden yükler. Bu, model kaydını ve kimlik bilgilerinin varlığını kontrol eder; geçerliliği veya API başarısını kanıtlamaz.

Metin isteği TokenLab bakiyesini kullanır. Araçları denemeden önce yanıtı [istek kaydıyla](https://tokenlab.sh/dashboard/runs?section=requests) karşılaştırın. Geri almak için önceki sağlayıcıyı seçip yalnızca eklenen TokenLab girdisini kaldırın.

## Skills ve MCP

Pi [Skills desteğini yerleşik sunar](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). [TokenLab Skill](/tr/integrations/coding-agent-skill) yükleyebilirsiniz. MCP ayrı bir uzantı gerektirir; yapılandırmasını `models.json` içine koymayın.
