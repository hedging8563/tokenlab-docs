## Genel Bakış

Agno, ajanlar ve iş akışları için TokenLab'i OpenAI uyumlu bir model sağlayıcısı olarak kullanabilir.

<Note>
**Tür**: Ajan Çerçevesi (Agent Framework)

**Birincil Yol**: OpenAI uyumlu sohbet tamamlama (chat completions)

**Destek Güveni**: Desteklenen yol
</Note>

## Ortam

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## TokenLab Model Sarmalayıcısı

Eğer Agno sürümünüz TokenLab model sarmalayıcısını içeriyorsa:

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

Bazı Agno sürümleri model dizelerini de destekler:

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## OpenAI Uyumlu Geri Dönüş (Fallback)

Eğer sürümünüz henüz TokenLab içermiyorsa, Agno'nun OpenAI uyumlu model yolunu şununla kullanın:

- Base URL: `https://api.tokenlab.sh/v1`
- API key: `TOKENLAB_API_KEY`
- Model: `gpt-5.4-mini`

## Model Önerileri

Varsayılan ajanlar için `gpt-5.4-mini`, daha derin muhakeme gerektiren işlemler için `gpt-5.4` veya `claude-sonnet-5`, daha hızlı döngüler için ise `deepseek-v4-flash` kullanın.
