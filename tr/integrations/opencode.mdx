## Genel Bakış



<Note>
**Tür**: Kodlama aracı

**Birincil yol**: OpenAI ile uyumlu

**Destek seviyesi**: Desteklenen yol
</Note>

OpenCode, terminalinizde çalışan açık kaynaklı bir AI kodlama asistanıdır. Birden fazla LLM sağlayıcısını destekler ve yüzlerce modele erişim için TokenLab API'sini kullanacak şekilde yapılandırılabilir.

## Kurulum

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

Kurulumu doğrulayın:

```bash
opencode --version
```

## Yapılandırma

### Adım 1: Environment Variable'ları Ayarlayın

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

Kalıcı yapılandırma için, `~/.bashrc` veya `~/.zshrc` dosyanıza ekleyin:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### Adım 2: OpenCode'u Yapılandırın

OpenCode'un mevcut dokümantasyonu, sağlayıcıların `opencode.json` veya `opencode.jsonc` üzerinden yapılandırılmasını önerir. TokenLab için, yerleşik `openai` sağlayıcısını aşırı yüklemek yerine özel bir sağlayıcı kullanın:

Örnek desteklenen V1 biçimini kullanır. Sağlayıcıları ve izinleri koruyarak `~/.config/opencode/opencode.json` içine birleştirin. V2 desteklenen V1 ayarlarını okur; sağlayıcı içinde biçimleri karıştırmayın. [Resmî geçiş kılavuzuna](https://opencode.ai/v2/docs/migrate-v1/) bakın. `/models` kaydını kontrol edip ücretli testi TokenLab kaydıyla karşılaştırın. Geri almak için eski modeli seçip yalnızca bu girdiyi kaldırın.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
Sohbet tamamlama tarzı uyumluluk için `@ai-sdk/openai-compatible` kullanın. Özellikle `/v1/responses` üzerine kurulu bir sağlayıcı yoluna ihtiyacınız varsa, OpenCode'un sağlayıcı dokümantasyonu paketi `@ai-sdk/openai` olarak değiştirmenizi önerir.
</Note>

## Temel Kullanım

**Etkileşimli modu başlatın:**

```bash
opencode
```

**Bir prompt ile çalıştırın:**

```bash
opencode run "Explain this codebase"
```

**Model belirtin:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## Kullanılabilir Modeller

| Model | En Uygun Olduğu Alan |
|-------|----------|
| `gpt-5.6-terra` | Karmaşık görevler, kod mimarisi |
| `gpt-5.6-luna` | Hızlı düzeltmeler, basit sorgular |
| `claude-sonnet-4-6` | Kod inceleme, dokümantasyon |
| `claude-opus-4-6` | Karmaşık muhakeme |
| `gemini-3.5-flash` | Hızlı yanıtlar |

## Yaygın Komutlar

**Kodu analiz edin:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**Kod üretin:**

```bash
opencode run "Create a REST API with Express"
```

**Değişiklikleri inceleyin:**

```bash
git diff | opencode run "Review these changes"
```

**Hataları düzeltin:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## Etkileşimli Komutlar

| Komut | Açıklama |
|---------|-------------|
| `/help` | Kullanılabilir komutları göster |
| `/models` | Farklı bir modele geç |
| `/clear` | Konuşma geçmişini temizle |
| `/exit` | OpenCode'dan çık |

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı Hatası">
    - `options.baseURL` değerinin `https://api.tokenlab.sh/v1` olarak ayarlandığını doğrulayın
    - Ağ bağlantısını kontrol edin
    - Test etmek için `curl https://api.tokenlab.sh/v1/models` komutunu deneyin
  </Accordion>

  <Accordion title="Kimlik Doğrulama Başarısız Oldu">
    - `TOKENLAB_API_KEY` environment variable'ının ayarlandığını doğrulayın
    - `options.apiKey` değerinin `{env:TOKENLAB_API_KEY}` veya başka bir geçerli secret kaynağına başvurduğunu doğrulayın
    - Anahtarın `sk-` ile başladığını kontrol edin
    - Anahtarın TokenLab dashboard'unda aktif olduğundan emin olun
  </Accordion>

  <Accordion title="Model Bulunamadı">
    - Yapılandırmadaki model adının tam olarak eşleştiğini kontrol edin
    - Modelin kullanılabilirliğini [tokenlab.sh/en/models](https://tokenlab.sh/tr/models) adresinde doğrulayın
  </Accordion>
</AccordionGroup>
