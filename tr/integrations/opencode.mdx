OpenCode, terminalinizde çalışan açık kaynaklı bir AI kodlama asistanıdır. Birden fazla LLM sağlayıcısını destekler ve yüzlerce modele erişim için TokenLab API'sini kullanacak şekilde yapılandırılabilir.

## Kurulum

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

Kurulumu doğrulayın:

```bash
opencode --version
```

## Yapılandırma

### Adım 1: Environment Variable'ları Ayarlayın

[Hızlı başlangıç](/tr/quickstart) içindeki macOS, Linux, WSL veya Windows PowerShell adımlarıyla anahtarı komut geçmişine yazmadan `TOKENLAB_API_KEY` değerini ayarlayın. OpenCode’u aynı terminalden başlatın. Sürekli kullanım için yerel bir sır yöneticisi kullanın; shell profiline düz metin anahtar eklemeyin.

### Adım 2: OpenCode'u Yapılandırın

Aşağıdaki yapılandırma **OpenCode 1.18.31** ile doğrulanmıştır. Diğer sürümler kendi resmî belgelerine göre ayrıca doğrulanmalıdır.

Yapılandırmayı ayrı bir `~/.config/opencode/tokenlab.jsonc` dosyasına kaydedin. `XDG_CONFIG_HOME` tanımlıysa bu dizinin altındaki `opencode/tokenlab.jsonc` yolunu kullanın. Normal `opencode.json` / `opencode.jsonc` dosyalarını, hesapları, varsayılan modeli ve izinleri koruyun. Ayrı dosya yalnızca o başlatmada `OPENCODE_CONFIG` ile seçilirse yüklenir. Dosya veya sağlayıcı adı zaten kullanılıyorsa başka bir ad seçip komutları uyarlayın.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
Bu yapılandırma `@ai-sdk/openai-compatible` ile Chat Completions gönderir. Güncel model ayrıntılarından Chat Completions ve gereken araç desteğini kontrol edin. Bu örnek başka protokol veya sürümlerin uyumluluğunu kanıtlamaz.
</Note>

İsteğe bağlı: Python 3.11+ ile [geri alınabilir OpenCode yapılandırma yardımcısı](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md) önizleme, uygulama ve özgün dosyayı geri yükleme sunar. TokenLab Skills eklentisi **0.1.2** bu betikleri içerir; bağımsız Skill de betikleri içeren bir sürüme güncellendiğinde kullanılabilir. Kurulu eklenti veya bağımsız Skill için [README güncelleme adımlarını](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) izleyip betiğin bulunduğunu doğrulayın. Bu sayfadaki elle yapılandırma yardımcı olmadan da tamamlanabilir.

## Temel Kullanım

Hızlı başlangıca göre anahtarı ayarlayın; dosyayı yalnızca bu başlatma için yükleyip modeli açıkça seçin. Özel yol ve sağlayıcı adlarını komutlara yansıtın. Mevcut `OPENCODE_CONFIG` veya satır içi `OPENCODE_CONFIG_CONTENT` ayarlarını koruyup ayrı bir başlatma ortamı kullanın; proje ve yönetilen ayarlar yine öncelikli olabilir.

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

Model listesi yerel yüklemeyi kontrol eder, anahtar geçerliliğini veya gerçek istek başarısını kanıtlamaz. İstem göndermek TokenLab bakiyesini kullanır; OpenCode başlık oluşturma gibi ayrı ücretlendirilen yardımcı istekler de gönderebilir. Yanıtı ve ilgili [istek kayıtlarını](https://tokenlab.sh/dashboard/runs?section=requests) kontrol edin.

Normal ayarlarınız için bu dosyayı yüklemeden başlatın. Bu kılavuz için `OPENCODE_CONFIG` değerini kabuk profiline kaydetmeyin. Elle yapılan ayarı geri alırken yalnızca oluşturduğunuz ayrı dosyayı silin veya önceden var olan dosyanın yedeğini geri yükleyin.

## Kullanılabilir Modeller

| Model | En Uygun Olduğu Alan |
|-------|----------|
| `gpt-5.6-terra` | Karmaşık görevler, kod mimarisi |
| `gpt-5.6-luna` | Hızlı düzeltmeler, basit sorgular |
| `claude-sonnet-4-6` | Kod inceleme, dokümantasyon |
| `claude-opus-4-6` | Karmaşık muhakeme |
| `gemini-3.5-flash` | Hızlı yanıtlar |

## Yaygın Komutlar

**Kodu analiz edin:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**Kod üretin:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**Değişiklikleri inceleyin:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**Hataları düzeltin:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı Hatası">
    - `options.baseURL` değerinin `https://api.tokenlab.sh/v1` olarak ayarlandığını doğrulayın
    - Ağ bağlantısını kontrol edin
    - Test etmek için `curl https://api.tokenlab.sh/v1/models` komutunu deneyin
  </Accordion>

  <Accordion title="Kimlik Doğrulama Başarısız Oldu">
    - `TOKENLAB_API_KEY` environment variable'ının ayarlandığını doğrulayın
    - `options.apiKey` değerinin `{env:TOKENLAB_API_KEY}` veya başka bir geçerli secret kaynağına başvurduğunu doğrulayın
    - Anahtarın `sk-` ile başladığını kontrol edin
    - Anahtarın TokenLab dashboard'unda aktif olduğundan emin olun
  </Accordion>

  <Accordion title="Model Bulunamadı">
    - Yapılandırmadaki model adının tam olarak eşleştiğini kontrol edin
    - Modelin kullanılabilirliğini [tokenlab.sh/en/models](https://tokenlab.sh/tr/models) adresinde doğrulayın
  </Accordion>
</AccordionGroup>
