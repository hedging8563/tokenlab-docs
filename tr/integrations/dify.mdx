## Genel Bakış

Dify'ı TokenLab'e bağlamak için **OpenAI-API-compatible** model sağlayıcı eklentisini kullanın. Model türünü **LLM**, **Completion mode** değerini **Chat** ve **API Type** değerini **Chat Completions API** olarak ayarlayın. Bu kılavuz Chat Completions kullanır.

<Note>
**Tür**: Çerçeve veya Platform

**Birincil Yol**: OpenAI uyumlu sohbet yolu

**Destek Güveni**: Kapsam sınırlamalarıyla desteklenir
</Note>

## Ön Koşullar

- API erişimi olan bir TokenLab hesabı
- Dify Cloud veya kendi sunucunuzda barındırılan (self-hosted) Dify

## Yapılandırma Adımları

### Adım 1: API Anahtarınızı Alın

1. [TokenLab Dashboard](https://tokenlab.sh/dashboard) adresine giriş yapın
2. [API Keys](https://tokenlab.sh/dashboard/api) sayfasını açın
3. `sk-` ile başlayan bir API anahtarı oluşturun veya kopyalayın

### Adım 2: Sağlayıcıyı Yapılandırın

<Steps>
  <Step title="Model Sağlayıcılarını Açın">
    Dify içinde **Settings** → **Model Providers** kısmına gidin
  </Step>
  <Step title="OpenAI-API-compatible'ı seçin">
    **OpenAI-API-compatible** seçeneğini açın. Yoksa bu model sağlayıcı eklentisini Dify Marketplace'ten yükleyin. TokenLab ayarlarını girmek için **Add model** seçeneğini seçin.
  </Step>
  <Step title="TokenLab Ayarlarını Girin">
    Şu değerleri kullanın:

    | Alan | Değer |
    |-------|-------|
    | API Key | `sk-your-tokenlab-key` |
    | Model type | LLM |
    | Completion mode | Chat |
    | API Type | Chat Completions API |
    | API Base URL | `https://api.tokenlab.sh/v1` |
  </Step>
  <Step title="Modelleri Ekleyin">
    Kullanmak istediğiniz modelleri ekleyin, örneğin:
    - `gpt-5.4`
    - `gpt-5.4-mini`
    - `claude-sonnet-5`
    - `claude-opus-4-8`
    - `gemini-3.5-flash`
    - `gemini-3.1-flash-lite`
    - `deepseek-v4-flash`
  </Step>
</Steps>

### Adım 3: Bağlantıyı Test Edin

1. `gpt-5.4-mini` gibi eklediğiniz bir modeli seçin.
2. Bir test istemi (prompt) gönderin
3. Dify'ın geçerli bir yanıt aldığını doğrulayın

## Bilgi Bankaları için Embedding'ler

RAG ve bilgi bankası indeksleme için şu gibi bir embedding modeli ekleyin:
- `text-embedding-3-small`
- `text-embedding-3-large`

Ardından, ilgili bilgi bankası veya uygulama ayarlarında bunu varsayılan embedding modeli olarak ayarlayın.

## Önerilen Model Rolleri

| Kullanım Durumu | Önerilen Modeller |
|----------|------------------|
| Varsayılan sohbet | `gpt-5.4-mini`, `gpt-5.4`, `claude-sonnet-5` |
| Derin muhakeme | `gpt-5.5`, `gpt-5.4`, `claude-opus-4-8`, `deepseek-v4-pro` |
| Hızlı/ucuz | `gpt-5.4-mini`, `gemini-3.5-flash`, `deepseek-v4-flash` |
| Embedding'ler | `text-embedding-3-small`, `text-embedding-3-large` |

## En İyi Uygulamalar

<AccordionGroup>
  <Accordion title="Alternatif olarak OpenAI eklentisi">
    Ayrı bir eklenti olan **OpenAI**, kendi kataloğunda desteklenen modeller için kullanılabilir. Özel base URL değerini `https://api.tokenlab.sh/v1`, **API Protocol** değerini **Chat Completions** olarak ayarlayın; varsayılan değer Responses olabilir. Bu, OpenAI-API-compatible eklentisinin eski adı değildir ve her özel model kimliğini kabul etmez.
  </Accordion>

  <Accordion title="İterasyon için daha ucuz modeller kullanın">
    İterasyon yaparken `gpt-5.4-mini`, `gemini-3.5-flash` veya `deepseek-v4-flash` kullanın, ardından daha ağır iş akışlarını yalnızca gerektiğinde daha güçlü modellere geçirin.
  </Accordion>

  <Accordion title="Bu yapılandırma Chat Completions kullanır">
    Bu yapılandırmada **Completion mode = Chat** ve **API Type = Chat Completions API** ayarlarını koruyun. Responses ayrı bir API seçeneğidir; bu kılavuz onu veya WebSocket bağlantılarını yapılandırmaz.
  </Accordion>
</AccordionGroup>

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Bağlantı Hatası">
    - Base URL'nin tam olarak `https://api.tokenlab.sh/v1` olduğundan emin olun
    - Dify bunları çoğaltıyorsa sondaki eğik çizgileri (trailing slashes) kaldırın
    - Dify sunucusunun genel internet üzerinden TokenLab'e ulaşabildiğini doğrulayın
  </Accordion>

  <Accordion title="401 Yetkisiz">
    - API anahtarını tekrar kontrol edin
    - Anahtarın TokenLab panelinde aktif olduğunu doğrulayın
    - Dify'a yapıştırılan değerin fazladan boşluk veya satır sonu içermediğinden emin olun
  </Accordion>

  <Accordion title="Model Bulunamadı">
    - Model adını tam olarak doğrulayın
    - Sağlayıcı arayüzü eski bir değeri önbelleğe aldıysa model girişini yeniden ekleyin
    - TokenLab dokümanlarında veya panelinde mevcut model durumunu kontrol edin
  </Accordion>
</AccordionGroup>
