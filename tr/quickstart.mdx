## Adım 1: Deneme kredileriyle başlayın

<Steps>
  <Step title="Hesap oluşturun">
    E-posta, Gmail veya GitHub hesabınızla [tokenlab.sh](https://tokenlab.sh) üzerinden kaydolun.
  </Step>
  <Step title="Çalışma alanı bakiyesini kontrol edin">
    [Faturalandırma](https://tokenlab.sh/dashboard/billing) sayfasında bakiyeyi ve kullanılabilir deneme kredisini kontrol edin. İstek modelin güncel fiyatıyla ücretlendirilir; gerekirse bakiye ekleyin.
  </Step>
  <Step title="API anahtarı oluşturun ve kaydedin">
    Çalışma alanınızda [API Anahtarları](https://tokenlab.sh/dashboard/api?tab=keys) sayfasını açın. Bir anahtar oluşturun ve tam değerini hemen kaydedin; yalnızca bir kez gösterilir. Önceden kaydettiğiniz tam bir anahtar varsa o değeri kullanın. Listede gösterilen veya listeden kopyalanan önek, isteklerin kimliğini doğrulayamaz.
  </Step>
</Steps>

<Warning>
API anahtarınızı güvenli tutun. Asla istemci tarafı kodunda veya herkese açık depolarda paylaşmayın.
</Warning>

## Bu terminal için anahtarı ayarlayın

Bu komutlar anahtarı komut metnine yazmaz. Anahtar yalnızca mevcut terminal ve alt süreçlerinde geçerlidir. Dağıtılan uygulamalarda bir gizli bilgi yöneticisi kullanın.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## Adım 3: İlk İsteğinizi Yapın

Çoğu yeni entegrasyona başlarken, `POST /v1/chat/completions` üzerinde **Chat Completions** ile başlayın.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

Bir SDK örneğini `quickstart.py`, `quickstart.mjs`, `main.go` veya `quickstart.php` olarak kaydedip `python quickstart.py`, `node quickstart.mjs`, `go run .` ya da `php quickstart.php` çalıştırın. Python, JavaScript ve Go resmî OpenAI SDK’larını; PHP ise [topluluk istemcisini](https://github.com/openai-php/client) kullanır ve PHP 8.2+ gerektirir.

<Note>
Sadece açıkça Responses'a özgü davranış gerekliyse `POST /v1/responses` kullanın. Bazı yalnızca Responses için olan alanlar seçilen modele ve yönlendirilen yola bağlıdır.
</Note>
