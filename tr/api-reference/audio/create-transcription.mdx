## İstek Gövdesi

Transkripsiyon metni doğrudan döndürebilir veya HTTP `200`, `id` ve `status` ile asenkron bir görevi kabul edebilir. Kabul edilen görev için `poll_url` adresini izleyin ya da `/v1/tasks/{id}` sorgulayın. Uzun sesin senkron işlenmesinde en az `120s` zaman aşımı kullanın.

<ParamField body="file" type="file" required>
  Transkribe edilecek ses dosyası. Desteklenen formatlar: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. Maksimum dosya boyutu: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  Transkripsiyon model ID’si; örneğin `whisper-1` veya `gpt-4o-transcribe`. Güncel seçenekleri `GET /v1/models?recommended_for=stt` ile bulun.
</ParamField>

<ParamField body="language" type="string">
  Sesin dili, ISO-639-1 formatında (ör. `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  Modelin stilini yönlendirmek veya önceki bir segmenti devam ettirmek için isteğe bağlı metin.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Çıktı biçimi. Whisper `json`, `text`, `srt`, `verbose_json` ve `vtt` destekler; diğer modeller farklı seçenekler sunabilir. Model ayrıntılarını kontrol edin.
</ParamField>

<ParamField body="temperature" type="number">
  0 ile 1 arasında örnekleme sıcaklığı; yalnızca bu parametreyi destekleyen modeller için.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  Model destekliyorsa `word` ve/veya `segment`. Whisper için `response_format=verbose_json` gerekir. Multipart isteklerde birden fazla değer için `timestamp_granularities[]` alanını tekrarlayın.
</ParamField>

## Yanıt

Aşağıdaki alanlar JSON transkripsiyon veya çeviri yanıtlarını açıklar. `text`, `srt` ve `vtt`, JSON nesnesi yerine ham metin veya altyazı döndürür. Ek alanlar modele ve çıktı biçimine bağlıdır.

<ResponseField name="text" type="string">
  Transkribe edilen metin.
</ResponseField>

`verbose_json` için:

<ResponseField name="task" type="string">
  Döndürüldüğünde görev adı; örneğin `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  Algılanan dil.
</ResponseField>

<ResponseField name="duration" type="number">
  Ses süresi, saniye cinsinden.
</ResponseField>

<ResponseField name="segments" type="array">
  Zaman damgalarıyla birlikte transkripsiyon segmentleri.
</ResponseField>

<ResponseField name="words" type="array">
  Kelime düzeyinde zaman damgaları (istenirse).
</ResponseField>

Kabul edilen asenkron transkripsiyon görevi, metin yerine aşağıdaki alanları döndürür:

<ResponseField name="id" type="string">
  Görev ID'si.
</ResponseField>

<ResponseField name="task_id" type="string">
  Uygun olduğunda dönen asenkron görev kimliği takma adı.
</ResponseField>

<ResponseField name="status" type="string">
  Görev durumu: `pending`, `processing`, `completed` veya `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Oluşturma yanıtı sağladığında tercih edilen yoklama URL’si.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Çeviri

Sesi İngilizceye çevirmek için translations endpoint'ini kullanın:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
