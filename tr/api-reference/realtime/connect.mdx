## Genel bakış

Bu uç noktayı; akışlı konuşma tanıma, konuşma sentezi, konuşma çevirisi veya gerçek zamanlı çok modlu modeller gibi gerçek zamanlı oturumlar için kullanın. Normal bir `GET` isteği uç nokta meta verilerini döndürür, WebSocket yükseltme isteği ise seçilen model için gerçek zamanlı bir oturum açar.

## Desteklenen yüzey

TokenLab, metadata kontrolleri ve WebSocket upgrade istekleri için `GET /v1/realtime` üzerinde gerçek zamanlı bir WebSocket endpoint'i sunar. Bunu bir WebSocket subset olarak düşünün: desteklenen realtime model olaylarını iletir ve oturum oluşturma, `client_secrets`, `Calls` çağrı kontrol API'leri veya legacy beta session APIs gibi OpenAI Realtime REST yardımcı yüzeylerini desteklemez.

Tarayıcı veya mobil uygulamalarda uzun ömürlü API anahtarlarını sunucunuzda tutun. Bu endpoint kısa ömürlü Realtime client secret üretmez.

<Note>`/v1/models` listesinden güncel bir realtime modeli seçin, `/v1/models/{model}` ile doğrulayın ve `TOKENLAB_REALTIME_MODEL` değerini ayarlayın. Oturum olayları ve yapılandırması modele bağlıdır. Aşağıdaki JSON örneği normal bir HTTP GET yanıtıdır, WebSocket oturum olayı değildir.</Note>

## Bağlantı

<ParamField query="model" type="string" required>
  Gerçek zamanlı model ID’si. Genel sözleşmesinde realtime desteği bulunan bir model kullanın.
</ParamField>

<ParamField header="Authorization" type="string" required>
  Bearer API anahtarı. WebSocket istemcileri upgrade isteğinde `Authorization: Bearer sk-your-api-key` göndermelidir.
</ParamField>

<RequestExample>
```javascript JavaScript
import WebSocket from 'ws';

const model = process.env.TOKENLAB_REALTIME_MODEL;
const apiKey = process.env.TOKENLAB_API_KEY;
if (!model || !apiKey) {
  throw new Error('Set TOKENLAB_REALTIME_MODEL and TOKENLAB_API_KEY');
}

const url = new URL('wss://api.tokenlab.sh/v1/realtime');
url.searchParams.set('model', model);
const socket = new WebSocket(url, {
  headers: { Authorization: `Bearer ${apiKey}` }
});

socket.on('open', () => {
  console.log('Realtime connection open');
});

socket.on('message', (data) => {
  console.log('realtime event', data.toString());
});

socket.on('error', (error) => console.error(error.message));
socket.on('close', (code) => console.log('Realtime connection closed', code));
```

```bash cURL
curl "https://api.tokenlab.sh/v1/realtime" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Mesajlar

TokenLab, WebSocket mesajlarını istemciniz ile seçilen gerçek zamanlı model arasında aktarır. O modelin belgelerinde tanımlanan olay biçimini kullanın ve `model` değerini her olaya değil, sorgu dizesine ekleyin.

## Ücretlendirme ve kapatma

Oturumlar API anahtarınızın bakiyesinden ücretlendirilir: TokenLab başlangıçta bir tahmini tutar ayırır, ardından bitişte gerçek kullanımı hesaplar ve farkı iade eder.

Oturum tamamlandığında istemci soketini kapatın. Hizmet oturumu önce kapatırsa, TokenLab mümkün olduğunda istemcinize güvenli bir kapatma olayı/kodu gönderir.

## Önemli alanlar

<ResponseField name="object" type="string">Normal HTTP GET yanıtının nesne türüdür. Değeri her zaman `realtime.endpoint` olur.</ResponseField>
<ResponseField name="websocket_url" type="string">Normal HTTP GET isteğinin döndürdüğü göreli WebSocket bağlantı yoludur: `/v1/realtime?model={model}`. `{model}` yerine seçtiğiniz modelin ID’sini yazın.</ResponseField>
<ResponseField name="protocol" type="string">Normal HTTP GET isteğinin döndürdüğü protokol tanımlayıcısıdır. Değeri her zaman `tokenlab_realtime_proxy` olur.</ResponseField>

<ResponseField name="type" type="string">API tarafından dönen event veya message type.</ResponseField>
<ResponseField name="session.id" type="string">Realtime bağlantısı üzerinden alınan opak kimliktir. Hata ayıklama için destek loglarına ekleyin; REST session URL değildir.</ResponseField>
