---
title: "Batch İptal Et"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "Sıralı veya çalışan bir batch işini iptal eder."
---

Kuyrukta veya çalışmakta olan bir batch için iptal isteyin. Yanıt geçerli durumu içerir: iptal sürüyor veya tamamlanmış olabilir. Daha önce sona ermiş bir batch mevcut son durumunu korur. Döndürülen durum son durum değilse sonucu kontrol etmek için batch’i yeniden alın.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Sonraki çağrılar ve support için kullanılan identifier.</ResponseField>
<ResponseField name="status" type="string">Geçerli batch durumu. Başarılı bir iptal isteği her zaman `cancelling` döndürmez.</ResponseField>
