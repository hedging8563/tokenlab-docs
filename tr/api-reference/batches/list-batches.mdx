## Genel Bakış

Bu uç nokta, TokenLab'nın OpenAI uyumlu Parti API'sinin bir parçasıdır. Parti işleri, yüklenen JSONL dosyalarını kullanır, asenkron olarak çalışır ve daha sonra çıktı/hata dosyaları döndürebilir.

## Notlar

- Parti giriş dosyaları `purpose=batch` kullanmalıdır.
- `completion_window` şu anda `24h`dir.
- Çıktı sıralaması garanti edilmez; her zaman `custom_id` ile eşleştirin.
- Parti öğeleri içinde akış desteği yoktur.

## Örnek

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/batches?limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## İstek / Yanıt

Kesin şemayı almak için yukarıdaki etkileşimli OpenAPI panelini kullanın.

## Operasyonel İpuçları

- İdempotent aşağı akış uzlaşması için `custom_id` kullanın.
- Çalışan partiyi tamamladıktan sonra yalnızca `output_file_id` ve `error_file_id` bekleyin.

## Yanıt örneği

<ResponseExample>
```json 200 OK
{
  "object": "list",
  "data": [{ "id": "batch_abc123", "object": "batch", "status": "completed" }],
  "first_id": "batch_abc123",
  "last_id": "batch_abc123",
  "has_more": false
}
```
</ResponseExample>

## Önemli alanlar

<ResponseField name="object" type="string">Yanıtın object type değeri.</ResponseField>
<ResponseField name="data" type="array">Bu yanıtta dönen liste veya payload.</ResponseField>
<ResponseField name="status" type="string">Bu kaynağın güncel lifecycle durumu.</ResponseField>
<ResponseField name="has_more" type="boolean">`has_more` true ise başka sonuçlar vardır.</ResponseField>
