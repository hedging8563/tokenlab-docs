## Genel Bakış

Bu uç nokta, seçilen API anahtarı için tüketime dayalı faturalandırma toplamlarını döndürür. Buna toplam maliyet, toplam istek sayısı, faturalandırma birimine göre kullanım, `by_model`, `by_logical_model`, `by_model_vendor` ve `by_scene` kırılımları ile günlük maliyet eğilimi dahildir.

## Notlar

- Parasal alanlar yalnızca USD’yi destekler. `CNY` girişleri kullanımdan kaldırılmıştır ve `400 currency_retired` döndürür.

- Yükleme, fatura ve kuruluş düzeyindeki diğer finansal kayıtlar dahil değildir.

## Örnek

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Önemli alanlar

<ResponseField name="api_key" type="object">Listeleme, oluşturma ve güncelleme yanıtlarıyla aynı alanları kullanan API anahtarı özeti.</ResponseField>
<ResponseField name="summary" type="object">Seçilen filtreler için toplu toplamlar.</ResponseField>
<ResponseField name="breakdowns" type="object">Seçilen filtreler için toplu dökümler.</ResponseField>
<ResponseField name="summary.total_requests" type="number">Toplam istek sayısı.</ResponseField>
<ResponseField name="summary.total_cost" type="number">Görüntüleme için JSON sayısı olarak toplam USD maliyeti.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">Ondalık dize olarak kesin toplam USD maliyeti.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">Toplam istem token sayısı.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">Toplam tamamlama token sayısı.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">Toplam token sayısı.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">Kullanım birimine göre gruplanmış kullanım miktarı.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">İstenen genel modele göre döküm.</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">Mantıksal genel modele göre döküm.</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">Genel model sağlayıcısına göre döküm.</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">Genel istek sahnesine göre döküm.</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">Günlük maliyet eğilimi.</ResponseField>
