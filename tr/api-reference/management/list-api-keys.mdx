## Genel Bakış

Geçerli yönetim belirteciyle ilişkili kuruluştaki kullanıcı API anahtarlarını döndürür.

## Notlar

- Parasal alanlar yalnızca USD’yi destekler. `CNY` girişleri kullanımdan kaldırılmıştır ve `400 currency_retired` döndürür.

- Sistem tarafından yönetilen keyler sonuçlara dahil edilmez.

## Örnek

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Önemli alanlar

<ResponseField name="object" type="string">Her zaman `list`.</ResponseField>
<ResponseField name="data" type="array">API anahtarı nesneleri dizisi.</ResponseField>
<ResponseField name="pagination" type="object">`page`, `limit`, `total` ve `totalPages` değerlerini içeren sayfalama meta verileri.</ResponseField>
<ResponseField name="data[].id" type="string">Sonraki Yönetim API’si çağrılarında kullanılan API anahtarı tanımlayıcısı.</ResponseField>
<ResponseField name="data[].name" type="string">API anahtarının görünen adı.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">Görüntüleme ve destek için gizli olmayan anahtar öneki.</ResponseField>
<ResponseField name="data[].status" type="string">`active`, `inactive` veya `revoked` değerlerinden biri.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">Görüntüleme için JSON sayısı olarak USD harcama limiti. `null` sınırsız anlamına gelir.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">Ondalık dize olarak kesin USD harcama limiti. `null` sınırsız anlamına gelir.</ResponseField>
<ResponseField name="data[].used_amount" type="number">Görüntüleme için JSON sayısı olarak USD cinsinden birikmiş kullanım harcaması.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">Ondalık dize olarak USD cinsinden kesin birikmiş kullanım harcaması.</ResponseField>
<ResponseField name="data[].models" type="string[]">Anahtar başına izin verilen model listesi. Boş dizi, anahtar düzeyinde ek model kısıtlaması olmadığı anlamına gelir.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">Anahtarın süresinin dolduğu ISO zaman damgası veya süre sonu yoksa `null`.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">En son kullanımın ISO zaman damgası veya hiç kullanılmadıysa `null`.</ResponseField>
<ResponseField name="data[].created_at" type="string">Oluşturma ISO zaman damgası.</ResponseField>
