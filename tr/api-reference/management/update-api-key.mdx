## Genel Bakış

Mevcut bir kullanıcı API anahtarının adını, kullanım limitini, izinli modellerini, son kullanma süresini veya durumunu güncellemek için bu endpoint'i kullanın.

## İstek Gövdesi

En az bir alan verilmelidir.

| Alan | Tür | Varsayılan / Sınırlar | Notlar |
|------|-----|----------------------|--------|
| `status` | enum | - | `active`, `inactive`, `revoked` |
| `name` | string | uzunluk `1-50` | Güncellenmiş görünen ad |
| `limitAmount` | number \| null | minimum `0`, girdi üst sınırı `1000000` | `null` = limitsiz, `0` = sıfır kota. Pozitif değerler `100000` USD eşdeğerini aşamayacak şekilde depolama limiti olarak normalize edilir |
| `limitCurrency` | enum | varsayılan `USD` | Yalnızca USD. `CNY` gönderildiğinde `400 currency_retired` döner. |
| `models` | string[] | - | Güncellenmiş model allowlist'i |
| `expiresAt` | string \| null | RFC3339 datetime | `null` son kullanmayı kaldırır |

## Notlar

- Parasal alanlar yalnızca USD’yi destekler. `CNY` girişleri kullanımdan kaldırılmıştır ve `400 currency_retired` döndürür.

- Hard delete, Management API v1'de kasıtlı olarak desteklenmez.
- `revoked`, normal operasyonel kullanım için terminal bir durumdur; gelecekte bir un-revoke akışı beklemek yerine yeni bir anahtar oluşturun.

## Örnek

<RequestExample>
```bash cURL
curl -X PATCH "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>

## Önemli alanlar

<ResponseField name="id" type="string">Sonraki Yönetim API’si çağrılarında kullanılan API anahtarı tanımlayıcısı.</ResponseField>
<ResponseField name="name" type="string">API anahtarının görünen adı.</ResponseField>
<ResponseField name="key_prefix" type="string">Görüntüleme ve destek için gizli olmayan anahtar öneki.</ResponseField>
<ResponseField name="status" type="string">`active`, `inactive` veya `revoked` değerlerinden biri.</ResponseField>
<ResponseField name="limit_amount" type="number | null">Görüntüleme için JSON sayısı olarak USD harcama limiti. `null` sınırsız anlamına gelir.</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">Ondalık dize olarak kesin USD harcama limiti. `null` sınırsız anlamına gelir.</ResponseField>
<ResponseField name="used_amount" type="number">Görüntüleme için JSON sayısı olarak USD cinsinden birikmiş kullanım harcaması.</ResponseField>
<ResponseField name="used_amount_decimal" type="string">Ondalık dize olarak USD cinsinden kesin birikmiş kullanım harcaması.</ResponseField>
<ResponseField name="models" type="string[]">Anahtar başına izin verilen model listesi. Boş dizi, anahtar düzeyinde ek model kısıtlaması olmadığı anlamına gelir.</ResponseField>
<ResponseField name="expires_at" type="string | null">Anahtarın süresinin dolduğu ISO zaman damgası veya süre sonu yoksa `null`.</ResponseField>
<ResponseField name="last_used_at" type="string | null">En son kullanımın ISO zaman damgası veya hiç kullanılmadıysa `null`.</ResponseField>
<ResponseField name="created_at" type="string">Oluşturma ISO zaman damgası.</ResponseField>
