description: "TokenLab üzerinde mevcut olan modelleri listeler"
---

Model kataloğu herkese açıktır ve API anahtarı gerektirmez. Her öğe; mevcut yeteneklerin, fiyatların ve API formatlarının bir özetini içerir. Tam detaylara ihtiyaç duyduğunuzda tek bir modeli getirebilirsiniz.

## Sorgu Parametreleri

<ParamField query="category" type="string">
  `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank` veya `translation` değerlerine göre filtreleme yapar.
</ParamField>

<ParamField query="recommended_for" type="string">
  `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank` veya `translation` gibi bir görev için güncel önerileri döndürür.
</ParamField>

<ParamField query="provider" type="string">
  `openai`, `anthropic`, `google` veya `deepseek` gibi model üreticisine göre filtreleme yapar.
</ParamField>

<ParamField query="tag" type="string">
  `chat`, `image`, `video`, `embedding` veya `translation` gibi bir etikete göre filtreleme yapar.
</ParamField>

## Yanıt

<ResponseField name="object" type="string">Her zaman `list` değerini döndürür.</ResponseField>
<ResponseField name="data" type="array">`id`, `owned_by` ve bir `tokenlab` özeti içeren modeller.</ResponseField>

`tokenlab` altındaki yaygın liste alanları şunlardır:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` ve `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` ve `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial` ve `tokenlab.badges`
- `tokenlab.request_format_summary`
- `recommended_for` kullanıldığında `tokenlab.agent_preferences`

`recommended_for` kullanıldığında, sonuçlar ayrıca öneri durumunu ve güncelleme zamanını içerebilir. Sıralamayı sabitlemek yerine güncel yanıtı okuyun.

## Örnek

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```
