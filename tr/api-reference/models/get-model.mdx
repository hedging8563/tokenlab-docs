## Yol Parametresi

<ParamField path="model" type="string" required>
  `gpt-5.6-terra` veya `claude-sonnet-4-6` gibi Model ID.
</ParamField>

## Yanıt

<ResponseField name="id" type="string">Model kimliği.</ResponseField>
<ResponseField name="object" type="string">Her zaman `model`.</ResponseField>
<ResponseField name="owned_by" type="string">Model üreticisi.</ResponseField>
<ResponseField name="tokenlab" type="object">
  Yetenekler, fiyatlar, faturalandırma birimleri, bağlam sınırları, kabul edilen API formatları, işlemler ve yaşam döngüsü durumu dahil olmak üzere TokenLab model bilgileri.
</ResponseField>

Yaygın `tokenlab` alanları şunlardır:

- `capabilities`: metin, görsel, video, ses ve diğer yetenekler.
- `pricing`: güncel halka açık fiyatlar.
- `max_input_tokens` ve `max_output_tokens`: bağlam ve çıktı sınırları.
- `accepted_request_formats`: desteklenen API formatları.
- `supported_operations`: metinden görsele veya görselden videoya gibi işlemler.
- `lifecycle`: kullanılabilirlik, yayınlanma tarihi, kullanımdan kaldırılma tarihi veya yedek model.

Bazı medya modelleri ayrıca bir öneri durumu ve güncelleme zamanı içerir. Öneriler, kullanılabilirlik ve performansa göre değişebilir, bu nedenle sıralamalarını kodunuza sabit (hard-code) olarak yazmayın.

## Örnek

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.6-terra"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["coding", "json-mode", "prompt-cache", "reasoning", "tool-use", "vision"],
    "accepted_request_formats": ["openai_chat_completions", "openai_responses"]
  }
}
```

Bilinmeyen bir model `404 model_not_found` hatası döndürür.
