## Genel Bakış

create tarafından döndürülen `cgt-...` kimliğini kullanın. Görev `queued` veya `running` durumundayken birkaç saniyede bir sorgulama (poll) yapın. Görev `succeeded`, `failed`, `cancelled` veya `expired` durumuna geldiğinde durun.

<Warning>
Burada birleşik v1 görev enum veya yanıt yapısını yeniden kullanmayın. `/v1/tasks/{id}` uç noktası `pending`, `processing`, `completed` ve `failed` durumlarını kullanır; bu v3 uç noktası ise yukarıdaki resmi enum değerlerini kullanır. v3 JSON nesnesinde, `duration` mevcut olduğunda bir string'dir ve `error` isteğe bağlıdır ve varsa hata ayrıntılarını içerir. Katı bir Go istemcisi, `Duration` alanını `json:"duration,omitempty"` etiketiyle `string` olarak tanımlamalı ve her v3 terminal durumunda durmalıdır.
</Warning>

Ayrıca bkz. [Seedance 2.0 Video Modelleri](/tr/guides/seedance-2-video) ve [Video Oluşturma](/tr/guides/video-generation).

## Durum Değerleri

- `queued`: kabul edildi ve çalışmayı bekliyor.
- `running`: oluşturma işlemi devam ediyor.
- `succeeded`: sonuç hazır ve `content.video_url` mevcut.
- `failed`: oluşturma başarısız oldu; `error.code` ve `error.message` alanlarını inceleyin.
- `cancelled`: görev tamamlanmadan önce iptal edildi.
- `expired`: görev tamamlanmadan önce zaman aşımına uğradı.

## Yanıt Alanları

- `id`: `cgt-` ile başlayan uyumluluk görev kimliği.
- `model`: uyumluluk için yansıtılan model tanımlayıcısı.
- `status`: yukarıdaki durum değerlerinden biri.
- `content.video_url`: başarı durumunda nihai video URL'si.
- `content.last_frame_url`: yalnızca talep edildiğinde ve mevcut olduğunda bulunur.
- `usage`: mevcut olduğunda token kullanımı.
- `created_at` ve `updated_at`: görev zaman damgaları.
- `error`: Varsa isteğe bağlı hata ayrıntıları. `error.code` ve `error.message` alanlarını inceleyin; alanın varlığını yalnızca `status` değerinden çıkarmayın.

Yanıt, `progress`, `return_last_frame`, `watermark`, `priority` veya `camera_fixed` gibi TokenLab alanlarını asla eklemez.

## Örnek

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```json
{
  "id": "cgt-20260102030405-a1b2c",
  "model": "doubao-seedance-2.0",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  },
  "usage": {
    "completion_tokens": 123456
  }
}
```

```go Go
type SeedanceTask struct {
    ID       string `json:"id"`
    Status   string `json:"status"`
    Duration string `json:"duration,omitempty"`
}

func isTerminal(status string) bool {
    switch status {
    case "succeeded", "failed", "cancelled", "expired":
        return true
    default:
        return false
    }
}
```
