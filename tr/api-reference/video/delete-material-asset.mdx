title: "Materyal Varlığını Sil"
openapi: "/openapi/tr.json DELETE /v1/videos/assets/{assetId}"
description: "Mevcut organizasyona ait bir Seedance materyal varlığını siler."
---

Bir materyal varlığını siler. Bu işlem, içinde bulunduğu materyal grubunu silmez. Silme işleminden sonra, varlık kimliği (asset ID) artık `material_asset_id` olarak kullanılamaz.

`project_name`, kimliği doğrulanmış organizasyon içindeki kaynakları ayırır. Varsayılanı `default` değeridir; ilgili grup ve varlıklarda büyük/küçük harfe duyarlı aynı değeri kullanın. POST/PUT için JSON gövdesinde, GET/DELETE için sorgu parametresi olarak gönderin.

## Örnek İstek

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr?project_name=default" \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Örnek Yanıt

```json
{
  "deleted": true,
  "id": "asset-20260720123456-qn7wr"
}
```
