H5 görsel doğrulama akışından sonra bu Action çağrısını tekrarlayın. Başarılı sonuç, doğrulanan kişinin TokenLab materyal grubu kimliğini döndürür.

Oturumu oluşturan aynı doğrulanmış organizasyonu, kullanıcıyı ve büyük/küçük harfe duyarlı `ProjectName` değerini kullanın.

## Uç nokta ve kimlik doğrulama

```text
POST https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

[Görsel doğrulama oturumu oluştur](/tr/api-reference/video/create-visual-validation-session) tarafından döndürülen `BytedToken` değerini gönderin. Oluşturma sırasında `ProjectName` belirlediyseniz burada büyük/küçük harfe duyarlı aynı değeri gönderin; aksi halde alanı atlayın veya `default` kullanın.

Sonuç, tarayıcı callback işleminden hemen sonra hazır olmayabilir. `Result.GroupId` dönene veya 30 dakikalık `BytedToken` süresi dolana kadar aynı isteği tekrarlayın. Aynı token ile başarılı bir isteği tekrarlamak aynı `GroupId` değerini döndürür.

`liveness_face` materyalleri oluştururken döndürülen `GroupId` değerini `group_id` olarak kullanın.

## Örnek İstek

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"BytedToken":"ZXhhbXBsZS10b2tlbg","ProjectName":"default"}'
```

## Örnek Yanıt

```json
{
  "ResponseMetadata": {
    "RequestId": "req_def456",
    "Action": "GetVisualValidateResult",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "GroupId": "group-20260720123456-real1"
  }
}
```

Hatalar `ResponseMetadata.Error.Code` ve `ResponseMetadata.Error.Message` kullanır. Başarılı yanıt `ResponseMetadata` ve `Result` içerir; TokenLab’in diğer `/v1` API yanıt yapısını kullanmaz.
