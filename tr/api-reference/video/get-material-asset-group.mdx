Bir materyal grubunu getirir. `library_type` alanı, grubun sanal avatar grubu mu yoksa gerçek kişi grubu mu olduğunu belirtir.

Grubun hala mevcut olduğunu ve `status: "ACTIVE"` durumuna sahip olduğunu doğrulamanız gerekiyorsa, yükleme yapmadan önce bu endpoint'i kullanın.

`project_name`, kimliği doğrulanmış organizasyon içindeki kaynakları ayırır. Varsayılanı `default` değeridir; ilgili grup ve varlıklarda büyük/küçük harfe duyarlı aynı değeri kullanın. POST/PUT için JSON gövdesinde, GET/DELETE için sorgu parametresi olarak gönderin.

## Örnek İstek

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Örnek Yanıt

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
