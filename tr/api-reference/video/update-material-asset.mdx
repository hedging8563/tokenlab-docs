---
title: "Materyal Varlığını Güncelle"
openapi: "/openapi/tr.json PUT /v1/videos/assets/{assetId}"
description: "Mevcut organizasyona ait bir Seedance materyal varlığını günceller."
---

Materyal adını veya meta verilerini güncelleyin. Kaynak URL ve varlık türü oluşturulduktan sonra sabittir; kaynak dosya değiştiğinde yeni bir varlık oluşturun.

`project_name`, kimliği doğrulanmış organizasyon içindeki kaynakları ayırır. Varsayılanı `default` değeridir; ilgili grup ve varlıklarda büyük/küçük harfe duyarlı aynı değeri kullanın. POST/PUT için JSON gövdesinde, GET/DELETE için sorgu parametresi olarak gönderin.

## Örnek İstek

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"},"project_name":"default"}'
```

  "id": "asset-20260720123456-qn7wr",

  "ready": true,

}
