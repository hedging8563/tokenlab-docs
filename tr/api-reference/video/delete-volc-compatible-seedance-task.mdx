## Genel bakış

TokenLab Bearer API anahtarı ve `cgt-...` ID’siyle iptal isteyin. İptal için çaba gösterilir ve yalnızca görev hâlâ iptal edilebiliyorsa başarılı olur.

Ayrıca bkz. [Seedance 2.0 Video Modelleri](/tr/guides/seedance-2-video) ve [Video Oluşturma](/tr/guides/video-generation).

## Yanıt şekli

Başarılı iptal isteği HTTP 200 ve boş body döndürür. Son durumu doğrulamak istiyorsanız ardından görevi sorgulayın.

Görev tamamlandıysa, başarısız olduysa, süresi dolduysa veya artık iptal edilemiyorsa endpoint hata döndürür. Durumu doğrulamak için görevi sorgulayın. İptal edilen görevin video sonucu yoktur.

## Örnek

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
