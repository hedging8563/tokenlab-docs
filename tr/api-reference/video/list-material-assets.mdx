description: "Mevcut organizasyona ait Seedance materyal varlıklarını listeler."
---

Kimliği doğrulanmış organizasyona ait materyal varlıklarını listeleyin. Belirli bir üretim iş akışı için varlıkları bulmanız gerektiğinde `library_type`, `group_id` veya `status` parametrelerine göre filtreleme yapın.

Yalnızca `status` değeri `ACTIVE` olan varlıkları kullanın. Video oluştururken dönen TokenLab materyal varlığı `id` değerini kullanın.

`project_name`, kimliği doğrulanmış organizasyon içindeki kaynakları ayırır. Varsayılanı `default` değeridir; ilgili grup ve varlıklarda büyük/küçük harfe duyarlı aynı değeri kullanın. POST/PUT için JSON gövdesinde, GET/DELETE için sorgu parametresi olarak gönderin.

## Örnek İstek

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
