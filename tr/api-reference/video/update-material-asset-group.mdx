---
title: "Materyal Varlık Grubunu Güncelle"
openapi: "/openapi/tr.json PUT /v1/videos/assets/groups/{groupId}"
description: "Mevcut organizasyona ait bir Seedance materyal grubunu günceller."
---

Bir materyal grubunun görünen adını, açıklamasını veya meta verilerini güncelleyin. Yönetilen gerçek kişi grupları için, doğrulanmış kişi eşlemesi değişmeden kalır.

`project_name`, kimliği doğrulanmış organizasyon içindeki kaynakları ayırır. Varsayılanı `default` değeridir; ilgili grup ve varlıklarda büyük/küçük harfe duyarlı aynı değeri kullanın. POST/PUT için JSON gövdesinde, GET/DELETE için sorgu parametresi olarak gönderin.

## Örnek İstek

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos","project_name":"default"}'
```

## Örnek Yanıt

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
