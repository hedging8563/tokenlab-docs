description: "Mevcut organizasyona ait Seedance materyal gruplarını listeler."
---

Kimliği doğrulanmış organizasyona ait materyal gruplarını listeleyin. Sanal avatar gruplarını gerçek kişi gruplarından ayırmak için `library_type` ve `status` parametrelerine göre filtreleme yapın.

Materyal yüklerken dönen `id` değerini kullanın. Video oluşturma sırasında `group_id` değerini `material_asset_id` olarak göndermeyin; oluşturma işlemi bir materyal varlığı `id` değeri gerektirir.

`project_name`, kimliği doğrulanmış organizasyon içindeki kaynakları ayırır. Varsayılanı `default` değeridir; ilgili grup ve varlıklarda büyük/küçük harfe duyarlı aynı değeri kullanın. POST/PUT için JSON gövdesinde, GET/DELETE için sorgu parametresi olarak gönderin.

## Örnek İstek

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups?library_type=aigc_avatar&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Örnek Yanıt

```json
{
  "groups": [
    {
      "id": "group-20260720123456-vrt01",
      "object": "seedance.material_asset_group",

      "group_name": "Product references",
      "status": "ACTIVE",
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
