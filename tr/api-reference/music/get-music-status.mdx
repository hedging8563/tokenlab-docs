---
title: "Müzik Durumunu Al"
openapi: "GET /v1/tasks/{id}"
description: "Bir müzik oluşturma görevinin durumunu ve sonucunu getirir"
---

Müzik oluşturma görevinizin durumunu kontrol etmek için bu endpoint'i sorgulayın.

<Info>
Create yanıtı `poll_url` içeriyorsa, sorgulama için doğrudan o URL'yi kullanın. `id` ve `task_id` aynı asenkron görev kimliği olarak değerlendirilmelidir.


Süresi dolmuş veya kullanılamayan bir görev `404 async_task_not_found` döndürebilir. Geçerli API anahtarının görev sahipliği doğrulanamazsa yanıt `403 task_not_owned` olur.
</Info>

## Yol Parametreleri

<ParamField path="id" type="string" required>
  Müzik oluşturma görevi ID'si.
</ParamField>

## Yanıt

<ResponseField name="id" type="string">
  Görev ID'si.
</ResponseField>

<ResponseField name="task_id" type="string">
  Aynı asenkron görev ID’sinin takma adı; döndürüldüğünde mevcuttur.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Oluşturma yanıtı sağladığında tercih edilen yoklama URL’si.
</ResponseField>

<ResponseField name="status" type="string">
  Görev durumu: `pending`, `processing`, `completed` veya `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  İsteğe bağlı ilerleme değeri. Yalnızca gerçek bir ilerleme değeri varsa döner; tamamlanmayı belirlemek için `status` kullanın.
</ResponseField>

Sonuç alanları işleme bağlıdır. Müzik `audio_url` ve `audio_id`, yalnızca söz görevleri `lyrics`, kanal ayırma ise `data` içinde birden fazla dosya döndürebilir. `video_url`, başlık, ilerleme ve diğer meta veriler isteğe bağlıdır. Tamamlanmayı `status` ile kontrol edin ve gerçekten dönen alanları okuyun.

<ResponseField name="audio_id" type="string">
  Desteklenen sonraki işlemlerde bu görev ID’siyle kullanılabilecek isteğe bağlı ses ID’si.
</ResponseField>

<ResponseField name="data" type="array">
  `audio_url` veya `url` içeren ayrılmış ses dosyaları gibi isteğe bağlı çıktı dizisi.
</ResponseField>

<ResponseField name="audio_url" type="string">
  Ses dosyasını indirmek için URL (tamamlandığında).
</ResponseField>

<ResponseField name="video_url" type="string">
  Görselleştirici içeren video sürümünün URL'si (tamamlandığında).
</ResponseField>

<ResponseField name="title" type="string">
  Oluşturulan şarkı başlığı.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Oluşturulan veya sağlanan şarkı sözleri.
</ResponseField>

<ResponseField name="error" type="string | object">
  Hata mesajı (başarısız olduğunda).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
