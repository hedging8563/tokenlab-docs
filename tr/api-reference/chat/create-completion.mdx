## İstek Gövdesi

<Note>
Desteklenen isteğe bağlı parametreler, kabul edilen değerler ve varsayılanlar seçilen modele bağlıdır. Örnekleme, akıl yürütme veya araç seçeneklerini ayarlamadan önce [model ayrıntılarını](/tr/api-reference/models/get-model) kontrol edin.
</Note>

<ParamField body="model" type="string" required>
  Kullanılacak modelin ID'si. Mevcut seçenekler için [Models](https://tokenlab.sh/tr/models) sayfasına bakın.
</ParamField>

<ParamField body="messages" type="array" required>
  Konuşmayı oluşturan mesajların listesi.

  Her mesaj nesnesi şunları içerir:
  - `role` (string): `system`, `developer`, `user`, `assistant`, `tool`, `function`
  - `content` (string | array | null): Mesaj içeriği

  `tool_calls` içeren bir `assistant` mesajında `content` atlanabilir veya `null` olarak ayarlanabilir.

  `content` bir dizi olduğunda, TokenLab uyumlu modeller için yapılandırılmış multimodal blokları destekler:
  - text: `{ "type": "text", "text": "..." }`
  - image: `{ "type": "image_url", "image_url": { "url": "https://..." } }`
  - video: `{ "type": "video_url", "video_url": { "url": "https://..." } }`
  - audio: `{ "type": "audio_url", "audio_url": { "url": "https://..." } }`

  Multimodal girdi için herkese açık `https` URL’leri kullanın. Desteklenen medya türleri seçilen modele bağlıdır.
</ParamField>

<ParamField body="temperature" type="number">
  Örnekleme sıcaklığı. Destek, izin verilen değerler ve varsayılan değer seçilen modele bağlıdır. Modelin varsayılanını kullanmak için bu alanı atlayın.
</ParamField>

<ParamField body="max_tokens" type="integer">
  Üretilecek maksimum token sayısı.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Eğer true ise, kısmi mesaj deltaları SSE etkinleri olarak gönderilir.
</ParamField>

<ParamField body="stream_options" type="object">
  Akışlama için seçenekler. Token kullanımını akış parçalarında almak için `include_usage: true` olarak ayarlayın.
</ParamField>

<ParamField body="top_p" type="number">
  Nucleus örnekleme parametresi. Genellikle bunu veya temperature parametresini değiştirmenizi öneririz, her ikisini birden değil.
</ParamField>

<ParamField body="frequency_penalty" type="number">
  -2.0 ile 2.0 arasında bir sayı. Pozitif değerler tekrarlanan tokenleri cezalandırır.
</ParamField>

<ParamField body="presence_penalty" type="number">
  -2.0 ile 2.0 arasında bir sayı. Pozitif değerler metinde zaten bulunan tokenleri cezalandırır.
</ParamField>

<ParamField body="stop" type="string | array">
  Durdurma dizisi veya dizi listesi. Destek ve dizi sayısı sınırı seçilen modele bağlıdır.
</ParamField>

<ParamField body="tools" type="array">
  Modelin çağırabileceği (function calling) araçların listesi.
</ParamField>

<ParamField body="tool_choice" type="string | object">
  Modelin araçları nasıl kullandığını kontrol eder. Seçenekler: `auto`, `none`, `required`, veya belirli bir araç nesnesi.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean">
  Seçilen model destekliyorsa asistanın aynı turda birden fazla araç çağrısı yapmasına izin verir.
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  Tamamlama için maksimum token sayısı. `max_tokens` yerine kullanılabilecek bir alternatif, özellikle yeni akıl yürütme destekli model aileleri için faydalıdır.
</ParamField>

<ParamField body="reasoning_effort" type="string">
  Destekleyen modeller için akıl yürütme çabası. Kabul edilen değerler seçilen modele bağlıdır.
</ParamField>

<ParamField body="seed" type="integer">
  Destekleyen modeller için örnekleme tohumu. Aynı çıktının üretilmesi garanti edilmez.
</ParamField>

<ParamField body="n" type="integer">
  Oluşturulacak tamamlamaların sayısı (1-128).
</ParamField>

<ParamField body="logprobs" type="boolean">
  Log olasılıklarının döndürülüp döndürülmeyeceği.
</ParamField>

<ParamField body="top_logprobs" type="integer">
  Döndürülecek en iyi log olasılıklarının sayısı (0-20). `logprobs: true` gerektirir.
</ParamField>

<ParamField body="top_k" type="integer">
  Destekleyen modeller için Top-K örneklemesi.
</ParamField>

<ParamField body="response_format" type="object">
  Yanıt biçimi. JSON modu için `{"type": "json_object"}`, JSON şeması için `{"type": "json_schema", "json_schema": {...}}` kullanın. Destek seçilen modele bağlıdır.
</ParamField>

<ParamField body="logit_bias" type="object">
  Belirtilen tokenlerin ortaya çıkma olasılığını değiştirin. Token ID'lerini (string olarak) -100 ile 100 arasında bias değerlerine eşleyin.
</ParamField>

<ParamField body="user" type="string">
  Kötüye kullanım izleme için uç kullanıcınızı temsil eden benzersiz bir tanımlayıcı.
</ParamField>


## Yanıt

<ResponseField name="id" type="string">
  Tamamlamanın benzersiz kimliği.
</ResponseField>

<ResponseField name="object" type="string">
  Her zaman `chat.completion`.
</ResponseField>

<ResponseField name="created" type="integer">
  Tamamlamanın oluşturulduğu Unix zaman damgası.
</ResponseField>

<ResponseField name="model" type="string">
  Tamamlama için kullanılan model.
</ResponseField>

<ResponseField name="choices" type="array">
  Tamamlama seçeneklerinin listesi.

  Her seçenek şunları içerir:
  - `index` (integer): Seçeneğin indeksi
  - `message` (object): Üretilen mesaj
  - `finish_reason` (string): Modelin durma nedeni; örneğin `stop`, `length` veya `tool_calls`
</ResponseField>

<ResponseField name="usage" type="object">
  Token kullanım istatistikleri.

  - `prompt_tokens` (integer): Prompta ait tokenlar
  - `completion_tokens` (integer): Tamamlamadaki tokenlar
  - `total_tokens` (integer): Kullanılan toplam token sayısı
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "max_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="gpt-5.6-terra",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    max_tokens=1000
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ],
  max_tokens: 1000
});

console.log(response.choices[0].message.content);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/chat/completions');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-5.6-terra',
        'messages' => [
            ['role' => 'system', 'content' => 'You are a helpful assistant.'],
            ['role' => 'user', 'content' => 'Hello!']
        ],
        'max_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['choices'][0]['message']['content'];
```
</RequestExample>
