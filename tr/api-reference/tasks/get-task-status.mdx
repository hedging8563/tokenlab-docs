## Genel Bakış

Video, görsel, müzik ve 3D üretimi gibi görev türleri arasında birleşik async polling için bu endpoint'i kullanın.

Bir create yanıtı `poll_url` içeriyorsa, tam olarak o path'i çağırın. Daha yeni async workflow'lar için `poll_url`, `/v1/tasks/{id}` adresini işaret edebilir.

## Path Parametreleri

<ParamField path="id" type="string" required>
  Create isteğinden döndürülen görev kimliği.
</ParamField>

## Yanıt

<Note>
Sonuç, hata, zaman damgası ve model alanları görev için mevcut olduğunda döndürülür.
</Note>

<ResponseField name="id" type="string">
  Görev tanımlayıcısı.
</ResponseField>

<ResponseField name="task_id" type="string">
  Asenkron görev kimliği takma adı.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Oluşturma yanıtı sağladığında tercih edilen yoklama URL’si.
</ResponseField>

<ResponseField name="status" type="string">
  Görev durumu: `pending`, `processing`, `completed` veya `failed`. İptal edilen görevler `failed` ve `cancelled: true` olarak temsil edilir.
</ResponseField>

<ResponseField name="cancelled" type="boolean">
  Kuyruktaki bir asenkron görev yürütülmeden önce iptal edildiyse `true`.
</ResponseField>

<ResponseField name="cancellation_status" type="string">
  İptal işareti. İptal başarılı olduğunda `cancelled` olarak bulunur.
</ResponseField>

<ResponseField name="data" type="array">
  Tamamlanan görüntü görevleri için oluşturulan görüntü sonuçları burada döndürülür. Görüntü görevleri URL’leri `data[].url` içinde döndürür.
</ResponseField>

<ResponseField name="progress" type="number">
  İsteğe bağlı ilerleme değeri. Yalnızca gerçek bir ilerleme değeri varsa döner; tamamlanmayı belirlemek için `status` kullanın.
</ResponseField>

<ResponseField name="video_url" type="string">
  Görev tamamlandığında ve bir video ürettiğinde sonuç varlığının URL'si.
</ResponseField>

<ResponseField name="video" type="object">
  Mevcutsa `url`, `duration`, `width` ve `height` içeren tek video nesnesi.
</ResponseField>

<ResponseField name="videos" type="array">
  Üretim görevi birden fazla çıktı döndürdüğünde video dizisi görünebilir.
</ResponseField>

<ResponseField name="created" type="integer">
  Oluşturulma zaman damgası.
</ResponseField>

<ResponseField name="updated" type="integer">
  Son güncelleme zaman damgası.
</ResponseField>

<ResponseField name="model" type="string">
  Görevde kullanılan model.
</ResponseField>

<ResponseField name="error" type="string | object">
  Görev başarısız olduğunda hata mesajı.
</ResponseField>

## Hata Davranışı

Süresi dolmuş veya kullanılamayan bir görev `404 async_task_not_found` döndürebilir. Geçerli API anahtarının görev sahipliği doğrulanamazsa yanıt `403 task_not_owned` olur.

```json
{
  "error": {
    "message": "Task not found or no longer available.",
    "type": "invalid_request_error",
    "code": "async_task_not_found"
  }
}
```

## Örnekler

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

```python Python
import requests

poll_url = "/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
response = requests.get(
    f"https://api.tokenlab.sh{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
const response = await fetch(`https://api.tokenlab.sh${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
