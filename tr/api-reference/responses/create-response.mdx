Model ayrıntılarındaki `accepted_request_formats`, `openai_responses` içeriyorsa bu uç noktayı kullanın. İstekler ve yanıtlar Responses API biçimini kullanır. İsteğe bağlı alanlar ve desteklenen değerler seçilen modele bağlıdır.

## İstek Gövdesi

<ParamField body="model" type="string" required>
  Kullanılacak modelin ID'si. Mevcut seçenekler için [Models](https://tokenlab.sh/tr/models) sayfasına bakın.
</ParamField>

<ParamField body="input" type="string | array">
  İstek bunun yerine yeniden kullanılabilir bir `prompt` kullandığında veya `previous_response_id` ile saklanan bir yanıtı sürdürdüğünde input isteğe bağlıdır.

  Konuşmayı oluşturan giriş öğelerinin listesi.

  Her öğe şunlardan biri olabilir:
  - `message`: rol ve içerik içeren bir konuşma mesajı
  - `function_call`: bir fonksiyon çağrısı isteği
  - `function_call_output`: bir fonksiyon çağrısından gelen çıktı

  Multimodal giriş için, `message.content` ya düz bir string ya da içerik blokları dizisi olabilir. GPT-5.6 Terra gibi görsel işleme yeteneği olan modeller için resimleri doğrudan düz metin içine URL veya Base64 dizeleri yerleştirmek yerine `input_image` blokları olarak iletin.

  Örnek içerik blokları:
  - `{ "type": "input_text", "text": "Describe this image" }`
  - `{ "type": "input_image", "image_url": "https://example.com/image.jpg" }`
  - `{ "type": "input_image", "image_url": "data:image/png;base64,..." }`
</ParamField>

<ParamField body="instructions" type="string">
  Model için sistem talimatları (system message ile eşdeğer).
</ParamField>

<ParamField body="max_output_tokens" type="integer">
  Üretilmesi gereken maksimum token sayısı.
</ParamField>

<ParamField body="temperature" type="number">
  Örnekleme sıcaklığı. Desteklenen değerler ve varsayılanlar seçilen modele bağlıdır.
</ParamField>

<ParamField body="tools" type="array">
  Modelin çağırabileceği araçlar. Desteklenen türler ve birleşimler seçilen modele bağlıdır.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Eğer true ise, olayların bir akışını döndürür.
</ParamField>

<ParamField body="previous_response_id" type="string">
  Konuşmaya devam etmek için önceki bir yanıtın ID'si.
</ParamField>

<ParamField body="store" type="boolean" default="true">
  Yanıtın daha sonra alınmak üzere depolanıp depolanmayacağı.
</ParamField>

<ParamField body="background" type="boolean" default="false">
  Asenkron yürütme talep eder. Destek, seçilen modele bağlıdır.
</ParamField>

<ParamField body="prompt" type="object">
  Yeniden kullanılabilir bir istem şablonuna ve değişkenlerine başvuru.
</ParamField>

<ParamField body="metadata" type="object">
  İzleme amaçlı yanıtla iliştirilecek metadata.
</ParamField>

<ParamField body="text" type="object">
  Metin çıktı ayarları. `text.format` desteği seçilen modele bağlıdır.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  Birden fazla araç çağrısına paralel izin verilip verilmeyeceği.
</ParamField>

<ParamField body="top_p" type="number">
  Nucleus örnekleme parametresi (0-1).
</ParamField>

<ParamField body="reasoning" type="object">
  `effort` dahil akıl yürütme seçenekleri seçilen modele bağlıdır.
</ParamField>

## Yanıt

<ResponseField name="id" type="string">
  Yanıt için benzersiz tanımlayıcı.
</ResponseField>

<ResponseField name="object" type="string">
  Her zaman `response`.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Yanıtın oluşturulduğu zamanın Unix zaman damgası.
</ResponseField>

<ResponseField name="status" type="string">
  Yanıt durumu: `queued`, `in_progress`, `completed`, `incomplete`, `failed` veya `cancelled`. HTTP isteği başarılı olsa da bu alanı kontrol edin.
</ResponseField>

<ResponseField name="output" type="array">
  Model tarafından oluşturulan çıktı öğelerinin listesi.
</ResponseField>

<ResponseField name="usage" type="object">
  Token kullanım istatistikleri.
</ResponseField>

## İlgili uç noktalar

- `GET /v1/responses/{id}` kayıtlı bir yanıtı getirir ve `include`, `include_obfuscation`, `stream`, `starting_after` parametrelerini destekler.
- `DELETE /v1/responses/{id}` kayıtlı bir yanıtı siler. Üretimi iptal etmez.
- `POST /v1/responses/compact` bir `response.compaction` nesnesi döndürür.
- İptal, input-items ve input-tokens uç noktaları şu anda kullanılamaz.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "input": [
      {"type": "message", "role": "user", "content": "Hello!"}
    ],
    "max_output_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.responses.create(
    model="gpt-5.6-terra",
    input=[
        {"type": "message", "role": "user", "content": "Hello!"}
    ],
    max_output_tokens=1000
)

print(response.output)
```


```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-5.6-terra",
        "input": []map[string]interface{}{
            {"type": "message", "role": "user", "content": "Hello!"},
        },
        "max_output_tokens": 1000,
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/responses", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result["output"])
}
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/responses');

curl_setopt_array($ch, [

    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',

    ],
    CURLOPT_POSTFIELDS => json_encode([

        ],
        'max_output_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
print_r($data['output']);
```
## Görsel Girdi Örneği

Görsel işleme yeteneği olan modelleri, resimleri `message.content` içinde `input_image` blokları olarak yerleştirerek kullanın. `image_url` değeri ya herkese açık bir URL ya da Base64 veri URL'si olabilir.

```json
{
  "model": "gpt-5.6-terra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Please describe this image."
        },
        {
          "type": "input_image",
          "image_url": "https://example.com/demo.jpg"
        }
      ]
    }
  ]
}
```
