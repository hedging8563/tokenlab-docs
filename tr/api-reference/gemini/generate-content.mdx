---
title: "İçerik Oluştur"
openapi: "POST /v1beta/models/{model}:generateContent"
description: "Google Gemini API formatını kullanarak içerik oluşturur"
---

Gemini Models API tarafından döndürülen bir modelle Gemini istek ve yanıt biçimlerini kullanın. ProtoJSON lowerCamelCase ve karşılık gelen proto snake_case alan adları kabul edilir. Desteklenen isteğe bağlı alanlar ve değerler seçilen modele bağlıdır.

## Yol Parametreleri

<ParamField path="model" type="string" required>
  Model adı (örneğin, `gemini-2.5-pro`, `gemini-3.5-flash`).
</ParamField>

## Sorgu Parametreleri

<ParamField query="key" type="string">
  API anahtarı (header kimlik doğrulamasına alternatif).
</ParamField>

## Kimlik Doğrulama

Gemini uç noktaları birden fazla kimlik doğrulama yöntemini destekler:
- `?key=YOUR_API_KEY` sorgu parametresi
- `x-goog-api-key: YOUR_API_KEY` üst bilgisi
- `Authorization: Bearer YOUR_API_KEY` üst bilgisi

## İstek Gövdesi

<ParamField body="contents" type="array" required>
  `parts` ve isteğe bağlı `role` içeren konuşma içeriği. Medya için `inlineData` / `inline_data` veya `fileData` / `file_data` kullanılır. TokenLab’in oluşturduğu Files ve Cache ID’leri yalnızca sahibi olan Workspace içinde kullanılabilir.
</ParamField>

<ParamField body="systemInstruction" type="object">
  Model için sistem talimatı.
</ParamField>

<ParamField body="generationConfig" type="object">
  `temperature`, `topP`, `topK`, `maxOutputTokens`, `stopSequences`, `candidateCount`, `responseModalities`, `responseMimeType`, `responseSchema` ve `thinkingConfig` gibi üretim ayarları. Karşılık gelen snake_case adları da kabul edilir. Değerler ve kombinasyonlar modele bağlıdır.
</ParamField>

<ParamField body="safetySettings" type="array">
  Güvenlik filtresi ayarları.
</ParamField>

## Yanıt

<ResponseField name="candidates" type="array">
  Oluşturulan içerik adayları.
</ResponseField>

<ResponseField name="usageMetadata" type="object">
  Token kullanım bilgisi.
</ResponseField>

## Çok modlu giriş örnekleri

Gemini çok modlu isteklerinde medyayı `contents[].parts[]` içine yerleştirin ve satır içi byte ya da URL tabanlı dosya referansı kullanın.

Genel Gemini sözleşmesinde şu anda desteklenen medya kategorileri:
- görsel
- ses
- video

Satır içi medya için `inlineData` veya `inline_data` kullanın ve Base64 kodlanmış dosya baytlarını gönderin.

URL tabanlı medya için `fileData` veya `file_data` kullanın ve herkese açık bir `https` URL'i gönderin.

### Görsel giriş örneği

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Lütfen bu görseli açıklayın." },
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "/9j/4AAQSkZJRgABAQ..."
          }
        }
      ]
    }
  ]
}
```

### Ses giriş örneği

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Lütfen bu sesi yazıya dökün ve özetleyin." },
        {
          "file_data": {
            "mime_type": "audio/mpeg",
            "file_uri": "https://example.com/sample.mp3"
          }
        }
      ]
    }
  ]
}
```

### Video giriş örneği

```json
{
  "contents": [

}
```
