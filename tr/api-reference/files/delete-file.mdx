## Genel bakış

`/v1/files` üzerinden oluşturulan bir dosyayı siler. Batch dosyaları ve TokenLab tarafından oluşturulan görüntü referans dosyaları OpenAI uyumlu bir deleted nesnesi döndürür.

İstek Anthropic Files uyumluluk modunu kullandığında, aynı route bağlı workspace’ten Anthropic tarzı dosyayı siler.

## Notlar

- Bir dosyayı silmek, onu zaten referans alan Batch işlerini iptal etmez.
- Eksik veya yetkisiz file ids, yönlendirme durumunu açığa çıkarmadan herkese açık bir not-found hatası döndürür.
- Görüntü referans dosyalarını yalnızca bekleyen hiçbir görüntü düzenleme isteği onlara ihtiyaç duymadığında silin.

## Örnek

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
