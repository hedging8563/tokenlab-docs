## Genel Bakış

Bu endpoint, TokenLab'nın OpenAI uyumlu Batch API'sine hizmet eder; yüklenen batch girişlerini ve oluşturulan output veya error dosyalarını kapsar.

İstek Anthropic Files uyumluluk moduna geçtiğinde, aynı route bağlı workspace için kullanılabilen Anthropic tarzı dosyaları da listeleyebilir.


Anthropic başlıkları yoksa liste hem batch dosyalarını hem de TokenLab görüntü/referans dosyalarını içerebilir. Listeyi daraltmak için `purpose=batch`, `purpose=batch_output`, `purpose=user_data` veya `purpose=vision` kullanın.
## Notlar

- Batch giriş dosyaları `purpose=batch` kullanmalıdır.
- Oluşturulan output dosyalarına odaklanmak için `purpose=batch_output` kullanın.
- `completion_window` şu anda `24h`'dir.
- Output sırası garanti edilmez; her zaman `custom_id` ile eşleştirin.
- Streaming, batch öğelerinin içinde desteklenmez.

## Örnek

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files?purpose=batch&limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## İstek / Yanıt

Kesin şema için yukarıdaki etkileşimli OpenAPI panelini kullanın.

## Operasyonel İpuçları

- Downstream mutabakatı idempotent yapmak için `custom_id` kullanın.
- `output_file_id` ve `error_file_id` yalnızca worker batch'i tamamladıktan sonra beklenmelidir.

## Filtreler

- Batch ve görüntü referans dosyalarında `limit` 1–10000 arasındadır (varsayılan 10000); sayfalama için `after` kullanılır. Anthropic Files modunda aralık 1–1000’dir (varsayılan 20); `after_id` veya `before_id` kullanın, ikisini birlikte kullanmayın.
- `purpose` `batch`, `batch_output`, `user_data` veya `vision` olabilir.
- `user_data` ve `vision`, varsa TokenLab tarafından oluşturulan görüntü referans dosyalarını döndürür.
