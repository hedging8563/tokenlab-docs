## Paso 1: Empieza con créditos de prueba

<Steps>
  <Step title="Crear una cuenta">
    Regístrate en [tokenlab.sh](https://tokenlab.sh) con tu correo, Gmail o cuenta de GitHub.
  </Step>
  <Step title="Comprobar el saldo del espacio de trabajo">
    Revisa el saldo y los créditos de prueba disponibles en [Facturación](https://tokenlab.sh/dashboard/billing). La solicitud se cobra al precio actual del modelo; añade fondos si hace falta.
  </Step>
  <Step title="Crear y guardar una clave API">
    Abre [Claves API](https://tokenlab.sh/dashboard/api?tab=keys) en tu espacio de trabajo. Crea una clave y guarda su valor completo de inmediato; solo se muestra una vez. Si ya guardaste una clave completa, utiliza ese valor. El prefijo que aparece o se copia desde la lista no sirve para autenticar solicitudes.
  </Step>
</Steps>

<Warning>
Mantén segura tu clave de API. Nunca la expongas en código del lado del cliente ni en repositorios públicos.
</Warning>

## Configurar la clave para esta terminal

Estos comandos no incluyen la clave en el propio comando. Solo se aplica a la terminal actual y sus procesos hijos. Usa un gestor de secretos al desplegar la aplicación.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## Paso 3: Haz tu primera solicitud

Para la mayoría de las nuevas integraciones, empieza con **Chat Completions** en `POST /v1/chat/completions`.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

Guarda un ejemplo SDK como `quickstart.py`, `quickstart.mjs`, `main.go` o `quickstart.php` y ejecuta `python quickstart.py`, `node quickstart.mjs`, `go run .` o `php quickstart.php`. Python, JavaScript y Go usan SDK oficiales de OpenAI; PHP usa el [cliente comunitario](https://github.com/openai-php/client) y requiere PHP 8.2+.

<Note>
Usa `POST /v1/responses` solo cuando necesites explícitamente un comportamiento específico de Responses. Algunos campos exclusivos de Responses dependen del modelo seleccionado y de la ruta enrutada.
</Note>

## Comprobar el resultado

Una solicitud correcta devuelve una respuesta no vacía. Comprueba modelo, estado y uso en [Solicitudes](https://tokenlab.sh/dashboard/runs) del mismo espacio. Consulta [diagnóstico](/es/guides/observability-troubleshooting) para errores y la [guía SDK](/es/integrations/openai-sdk) para cambiar de modelo o usar streaming.
