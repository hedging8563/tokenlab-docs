---
title: "Crear grupo de activos de material"
openapi: "/openapi/es.json POST /v1/videos/assets/groups"
description: "Crea un grupo de material de avatar virtual de Seedance."
---

Cree un grupo de material con `library_type: "aigc_avatar"`. Utilice este endpoint para avatares virtuales, productos, estilos y otras referencias reutilizables que no requieran verificación de persona real.

Los nuevos grupos de material de personas reales se crean a través de la [Crear sesión de validación visual](/es/api-reference/video/create-visual-validation-session) y no pueden crearse directamente con este endpoint.

`project_name` aísla recursos dentro de la organización autenticada. El valor predeterminado es `default`; use el mismo valor, respetando mayúsculas y minúsculas, para los grupos y activos relacionados. Envíelo en el cuerpo JSON para POST/PUT y en la consulta para GET/DELETE.

## Ejemplo de solicitud

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots","project_name":"default"}'
```

## Ejemplo de respuesta

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
