---
title: "Obtener grupo de activos de material"
openapi: "GET /v1/videos/assets/groups/{groupId}"
description: "Recupera un grupo de material de Seedance mediante el ID de grupo de TokenLab."
---

Recupere un grupo de material. El campo `library_type` le indica si el grupo es un grupo de avatar virtual o un grupo de persona real.

Utilice este endpoint antes de realizar una carga si necesita confirmar que el grupo aún existe y tiene `status: "ACTIVE"`.

`project_name` aísla recursos dentro de la organización autenticada. El valor predeterminado es `default`; use el mismo valor, respetando mayúsculas y minúsculas, para los grupos y activos relacionados. Envíelo en el cuerpo JSON para POST/PUT y en la consulta para GET/DELETE.

## Ejemplo de solicitud

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Ejemplo de respuesta

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
