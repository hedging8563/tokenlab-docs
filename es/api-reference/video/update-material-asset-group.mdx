---
title: "Actualizar grupo de activos de material"
openapi: "/openapi/es.json PUT /v1/videos/assets/groups/{groupId}"
description: "Actualiza un grupo de material de Seedance propiedad de la organización actual."
---

Actualice el nombre para mostrar, la descripción o los metadatos de un grupo de material. Para grupos de personas reales gestionados, la asignación de persona verificada permanece sin cambios.

`project_name` aísla recursos dentro de la organización autenticada. El valor predeterminado es `default`; use el mismo valor, respetando mayúsculas y minúsculas, para los grupos y activos relacionados. Envíelo en el cuerpo JSON para POST/PUT y en la consulta para GET/DELETE.

## Ejemplo de solicitud

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos","project_name":"default"}'
```

## Ejemplo de respuesta

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
