---
title: "Obtener resultado de validación visual"
openapi: "POST /api/v3"
description: "Obtiene el grupo de materiales de persona real producido por la validación visual."
---

Consulte esta Action después del flujo de validación visual H5. Un resultado correcto devuelve el ID del grupo de materiales de TokenLab para la persona verificada.

Use la misma organización autenticada, el mismo usuario y el mismo `ProjectName`, respetando mayúsculas y minúsculas, que crearon la sesión.

## Endpoint y autenticación

```text
POST https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

Envíe el `BytedToken` devuelto por [Crear sesión de validación visual](/es/api-reference/video/create-visual-validation-session). Si definió `ProjectName` al crear la sesión, envíe aquí el mismo valor respetando mayúsculas y minúsculas; de lo contrario, omítalo o use `default`.

Es posible que el resultado no esté listo inmediatamente después del callback del navegador. Repita la misma solicitud hasta que se devuelva `Result.GroupId` o caduque el `BytedToken` de 30 minutos. Repetir una solicitud correcta con el mismo token devuelve el mismo `GroupId`.

Use el `GroupId` devuelto como `group_id` al crear materiales `liveness_face`.

## Ejemplo de solicitud

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"BytedToken":"ZXhhbXBsZS10b2tlbg","ProjectName":"default"}'
```

## Ejemplo de respuesta

```json
{
  "ResponseMetadata": {
    "RequestId": "req_def456",
    "Action": "GetVisualValidateResult",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "GroupId": "group-20260720123456-real1"
  }
}
```

Los errores utilizan `ResponseMetadata.Error.Code` y `ResponseMetadata.Error.Message`. Una respuesta correcta contiene `ResponseMetadata` y `Result`; no usa la estructura de respuesta de otras API `/v1` de TokenLab.
