---

## Resumen

Solicite la cancelación con una clave API TokenLab Bearer y el ID `cgt-...`. Se intenta cancelar la tarea, pero solo es posible mientras siga siendo cancelable.

Ver también [Modelos de video Seedance 2.0](/es/guides/seedance-2-video) y [Generación de video](/es/guides/video-generation).

## Forma de respuesta

Una cancelación exitosa devuelve HTTP 200 con cuerpo vacío. Consulta la tarea después si necesitas confirmar su estado final.

Si la tarea terminó, falló, expiró o ya no es cancelable, el endpoint devuelve un error. Consulte la tarea para confirmar su estado. Una tarea cancelada no tiene resultado de video.

## Ejemplo

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
