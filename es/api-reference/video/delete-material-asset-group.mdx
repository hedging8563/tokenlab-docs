---
title: "Eliminar grupo de activos de material"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "Elimina un grupo de material de Seedance propiedad de la organización actual."
---

Elimina un grupo de material y los activos de material de TokenLab contenidos en él. Esta acción no se puede deshacer.

Si la biblioteca de materiales de TokenLab no puede completar la eliminación debido a que el estado de autorización actual no lo permite, TokenLab devuelve un error neutral de la biblioteca de materiales. Tras la eliminación, el grupo y sus activos ya no podrán utilizarse en la generación de videos.

`project_name` aísla recursos dentro de la organización autenticada. El valor predeterminado es `default`; use el mismo valor, respetando mayúsculas y minúsculas, para los grupos y activos relacionados. Envíelo en el cuerpo JSON para POST/PUT y en la consulta para GET/DELETE.

## Ejemplo de solicitud

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Ejemplo de respuesta

```json
{
  "deleted": true,
  "id": "group-20260720123456-vrt01"
}
```
