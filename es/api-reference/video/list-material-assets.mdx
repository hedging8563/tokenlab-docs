---
title: "Listar activos de material"
openapi: "GET /v1/videos/assets"
description: "Enumera los activos de material de Seedance propiedad de la organización actual."
---

Enumera los activos de material propiedad de la organización autenticada. Filtre por `library_type`, `group_id` o `status` cuando necesite encontrar activos para un flujo de trabajo de generación específico.

Utilice únicamente activos cuyo `status` sea `ACTIVE`. Al crear videos, use el `id` del activo de material de TokenLab devuelto.

`project_name` aísla recursos dentro de la organización autenticada. El valor predeterminado es `default`; use el mismo valor, respetando mayúsculas y minúsculas, para los grupos y activos relacionados. Envíelo en el cuerpo JSON para POST/PUT y en la consulta para GET/DELETE.

## Ejemplo de solicitud

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Ejemplo de respuesta

```json
{
  "assets": [
    {
      "id": "asset-20260720123456-qn7wr",
      "object": "seedance.material_asset",
      "project_name": "default",
      "group_id": "group-20260720123456-vrt01",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
