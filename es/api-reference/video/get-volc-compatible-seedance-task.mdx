## Descripción general

Utilice el ID `cgt-...` devuelto por create. Realice consultas cada pocos segundos mientras la tarea esté en estado `queued` o `running`. Deténgase cuando la tarea esté en estado `succeeded`, `failed`, `cancelled` o `expired`.

<Warning>
No reutilice el enum de tarea unificado v1 ni la estructura de respuesta aquí. `/v1/tasks/{id}` utiliza `pending`, `processing`, `completed` y `failed`; este endpoint v3 utiliza el enum oficial anterior. En el objeto JSON v3, `duration` es una cadena cuando está presente y `error` es opcional y contiene los detalles de error disponibles. Un cliente Go estricto debe declarar `Duration` como `string` con la etiqueta JSON `duration,omitempty`, y detenerse en cada estado terminal v3.
</Warning>

Consulte también [Modelos de video Seedance 2.0](/es/guides/seedance-2-video) y [Generación de video](/es/guides/video-generation).

## Valores de estado

- `queued`: aceptada y esperando para ejecutarse.
- `running`: la generación está en progreso.
- `succeeded`: el resultado está listo y `content.video_url` está presente.
- `failed`: la generación falló; inspeccione `error.code` y `error.message`.
- `cancelled`: la tarea fue cancelada antes de completarse.
- `expired`: la tarea expiró antes de completarse.

## Campos de respuesta

- `id`: ID de la tarea de compatibilidad, que comienza con `cgt-`.
- `model`: identificador del modelo repetido para compatibilidad.
- `status`: uno de los valores de estado anteriores.
- `content.video_url`: URL final del video en caso de éxito.
- `content.last_frame_url`: presente solo cuando se solicita y está disponible.
- `usage`: uso de tokens cuando está disponible.
- `created_at` y `updated_at`: marcas de tiempo de la tarea.
- `error`: Detalles de error opcionales cuando están disponibles. Consulte `error.code` y `error.message`; no deduzca la presencia del campo solo a partir de `status`.

La respuesta nunca añade campos de TokenLab como `progress`, `return_last_frame`, `watermark`, `priority` o `camera_fixed`.

## Ejemplo

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```json
{
  "id": "cgt-20260102030405-a1b2c",
  "model": "doubao-seedance-2.0",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  },
  "usage": {
    "completion_tokens": 123456
  }
}
```

```go Go
type SeedanceTask struct {
    ID       string `json:"id"`
    Status   string `json:"status"`
    Duration string `json:"duration,omitempty"`
}

func isTerminal(status string) bool {
    switch status {
    case "succeeded", "failed", "cancelled", "expired":
        return true
    default:
        return false
    }
}
```
