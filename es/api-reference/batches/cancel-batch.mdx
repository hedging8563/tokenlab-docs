---
title: "Cancelar Lote"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "Cancela un trabajo de lote en cola o en ejecución."
---

Solicita la cancelación de un lote en cola o en ejecución. La respuesta contiene su estado actual: la cancelación puede seguir en curso o haber terminado. Un lote que ya terminó conserva su estado final. Si el estado devuelto no es final, consulta el lote de nuevo para comprobar el resultado.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Identificador para llamadas posteriores y soporte.</ResponseField>
<ResponseField name="status" type="string">Estado actual del lote. Una solicitud de cancelación correcta no siempre devuelve `cancelling`.</ResponseField>
