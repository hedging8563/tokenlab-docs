## Resumen

Este endpoint sirve principalmente a la API Batch compatible con OpenAI de TokenLab, incluyendo entradas de lote subidas y archivos de salida o error generados.

Cuando la solicitud entra en el modo de compatibilidad con Anthropic Files, la misma ruta también puede listar archivos estilo Anthropic disponibles para el workspace enlazado.


Sin encabezados Anthropic, la lista puede incluir archivos de lote y archivos de imagen/referencia de TokenLab. Usa `purpose=batch`, `purpose=batch_output`, `purpose=user_data` o `purpose=vision` para acotar la lista.
## Notas

- Los archivos de entrada del lote deben usar `purpose=batch`.
- Usa `purpose=batch_output` para centrarte en los archivos de salida generados.
- `completion_window` es actualmente `24h`.
- El orden de salida no está garantizado; siempre empareja por `custom_id`.
- No se admite streaming dentro de elementos del lote.

## Ejemplo

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files?purpose=batch&limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Solicitud / Respuesta

Usa el panel OpenAPI interactivo de arriba para ver el esquema exacto.

## Consejos operativos

- Usa `custom_id` para reconciliación descendente idempotente.
- Espera `output_file_id` y `error_file_id` solo después de que el worker finalice el lote.

## Filtros

- Para archivos de lote y referencias de imagen, `limit` admite 1–10000 (10000 por defecto), con `after` para paginar. En el modo Anthropic Files admite 1–1000 (20 por defecto); usa `after_id` o `before_id`, pero no ambos.
- `purpose` puede ser `batch`, `batch_output`, `user_data` o `vision`.
- `user_data` y `vision` devuelven archivos de referencia de imagen creados por TokenLab cuando están disponibles.

## Ejemplo de respuesta

<ResponseExample>
