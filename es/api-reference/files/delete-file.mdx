---
title: "Eliminar archivo"
openapi: "DELETE /v1/files/{file_id}"
description: "Elimina un archivo de lote, una vinculación de archivo de imagen/referencia o un archivo en modo Anthropic."
---

## Resumen

Elimina un archivo creado con `/v1/files`. Sin encabezados Anthropic, la ruta elimina archivos de lote de TokenLab o vinculaciones de archivos de imagen/referencia. Con `anthropic-beta: files-api-2025-04-14`, usa el modo Anthropic Files API para el workspace vinculado.

## Notas

- Eliminar un archivo de lote quita el registro almacenado e impide que futuros trabajos por lotes usen ese ID de archivo.
- Eliminar un archivo de imagen/referencia pide al proveedor seleccionado que borre el archivo y luego elimina la vinculación de TokenLab cuando el proveedor acepta.
- El modo Anthropic Files API requiere los mismos encabezados nativos de Anthropic usados para subir y recuperar.

## Ejemplo

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
