---
title: "Eliminar archivo"
openapi: "/openapi/es.json DELETE /v1/files/{file_id}"
description: "Elimina un archivo subido que pertenece a la organización actual."
---

## Resumen

Elimina un archivo creado con `/v1/files`. Los archivos Batch y los archivos de referencia de imagen creados por TokenLab devuelven un objeto deleted compatible con OpenAI.

Cuando la solicitud usa el modo de compatibilidad con Anthropic Files, la misma ruta elimina el archivo estilo Anthropic del workspace enlazado.

## Notas

- Eliminar un archivo no cancela los trabajos Batch que ya lo referencian.
- Los file ids inexistentes o no autorizados devuelven un error público not-found sin exponer el estado de enrutamiento.
- Elimina archivos de referencia de imagen solo cuando ninguna solicitud pendiente de edición de imagen los necesite.

## Ejemplo

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
