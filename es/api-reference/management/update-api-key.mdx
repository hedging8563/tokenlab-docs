---
title: "Actualizar API Key"
openapi: "PATCH /v1/management/api-keys/{keyId}"
description: "Actualiza una API Key de usuario existente para la organización actual."
---

## Resumen

Usa este endpoint para actualizar el nombre, el límite de uso, los modelos permitidos, la caducidad o el estado de una API Key existente.

## Cuerpo de la solicitud

Debe enviarse al menos un campo.

| Campo | Tipo | Valor predeterminado / límites | Notas |
|-------|------|-------------------------------|-------|
| `status` | enum | - | `active`, `inactive`, `revoked` |
| `name` | string | longitud `1-50` | Nombre visible actualizado |
| `limitAmount` | number \| null | mínimo `0`, máximo de entrada `1000000` | `null` = ilimitado, `0` = cuota cero. Los valores positivos se normalizan a un límite almacenado que no puede superar `100000` USD equivalente. |
| `limitCurrency` | enum | predeterminado `USD` | Solo USD. Enviar `CNY` devuelve `400 currency_retired`. |
| `models` | string[] | - | Lista actualizada de modelos lógicos permitidos |
| `expiresAt` | string \| null | datetime RFC3339 | `null` borra la caducidad |

## Notas

- Los campos monetarios solo admiten USD. Las entradas `CNY` están retiradas y devuelven `400 currency_retired`.

- La eliminación dura no está soportada a propósito en Management API v1.
- `revoked` es un estado terminal para el uso operativo normal; crea una nueva clave en lugar de esperar un futuro flujo de reactivación.

## Ejemplo

<RequestExample>
```bash cURL
curl -X PATCH "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>

## Campos importantes

<ResponseField name="id" type="string">Identificador de clave API usado en llamadas posteriores a la API de gestión.</ResponseField>
<ResponseField name="name" type="string">Nombre para mostrar de la clave API.</ResponseField>
<ResponseField name="key_prefix" type="string">Prefijo de clave no secreto para visualización y soporte.</ResponseField>
<ResponseField name="status" type="string">Uno de los valores `active`, `inactive` o `revoked`.</ResponseField>
<ResponseField name="limit_amount" type="number | null">Límite de gasto en USD como número JSON para visualización. `null` significa sin límite.</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">Límite de gasto exacto en USD como cadena decimal. `null` significa sin límite.</ResponseField>
<ResponseField name="used_amount" type="number">Gasto de uso acumulado en USD como número JSON para visualización.</ResponseField>
<ResponseField name="used_amount_decimal" type="string">Gasto de uso acumulado exacto en USD como cadena decimal.</ResponseField>
<ResponseField name="models" type="string[]">Lista de modelos permitidos por clave. Un array vacío significa que no hay una restricción adicional de modelos a nivel de clave.</ResponseField>
<ResponseField name="expires_at" type="string | null">Marca de tiempo ISO en la que vence la clave, o `null` si no caduca.</ResponseField>
<ResponseField name="last_used_at" type="string | null">Marca de tiempo ISO del uso más reciente, o `null` si nunca se ha usado.</ResponseField>
<ResponseField name="created_at" type="string">Marca de tiempo ISO de creación.</ResponseField>
