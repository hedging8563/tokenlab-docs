## Resumen

Devuelve las claves API de usuario de la organización asociada al token de administración actual.

## Notas

- Los campos monetarios solo admiten USD.

- Las claves gestionadas por el sistema se excluyen.

## Ejemplo

<ParamField query="page" type="integer" default="1">Número de página a partir de 1.</ParamField>
<ParamField query="limit" type="integer" default="50">Tamaño de página de 1 a 100.</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Campos importantes

<ResponseField name="object" type="string">Siempre `list`.</ResponseField>
<ResponseField name="data" type="array">Array de objetos de clave API.</ResponseField>
<ResponseField name="pagination" type="object">Metadatos de paginación con `page`, `limit`, `total` y `totalPages`.</ResponseField>
<ResponseField name="data[].id" type="string">Identificador de clave API usado en llamadas posteriores a la API de gestión.</ResponseField>
<ResponseField name="data[].name" type="string">Nombre para mostrar de la clave API.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">Prefijo de clave no secreto para visualización y soporte.</ResponseField>
<ResponseField name="data[].status" type="string">Uno de los valores `active`, `inactive`, `suspended` o `revoked`.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">Límite de gasto en USD como número JSON para visualización. `null` significa sin límite.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">Límite de gasto exacto en USD como cadena decimal. `null` significa sin límite.</ResponseField>
<ResponseField name="data[].used_amount" type="number">Gasto de uso acumulado en USD como número JSON para visualización.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">Gasto de uso acumulado exacto en USD como cadena decimal.</ResponseField>
<ResponseField name="data[].models" type="string[]">Lista de modelos permitidos por clave. Un array vacío significa que no hay una restricción adicional de modelos a nivel de clave.</ResponseField>
<ResponseField name="data[].delivery_policy" type="string | null">`auto`, `verified`, `official`, `null`. `null` hereda la política de entrega del espacio de trabajo.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">Marca de tiempo ISO en la que vence la clave, o `null` si no caduca.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">Marca de tiempo ISO del uso más reciente, o `null` si nunca se ha usado.</ResponseField>
<ResponseField name="data[].created_at" type="string">Marca de tiempo ISO de creación.</ResponseField>
