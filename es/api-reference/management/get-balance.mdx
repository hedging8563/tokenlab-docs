## Resumen

Este endpoint devuelve los totales actuales de saldo de la organización asociada al token de gestión. Usa la misma referencia actual de saldo de organización que la facturación y la liquidación.

## Notas

- Los campos monetarios solo admiten USD.

- Los campos monetarios se devuelven en USD. Usa `balance`, `total_recharge` y `total_used` para visualización; usa `balance_decimal`, `total_recharge_decimal` y `total_used_decimal` para conciliación exacta.

## Ejemplo

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Campos importantes

<ResponseField name="object" type="string">Siempre `organization_balance`.</ResponseField>
<ResponseField name="organization_id" type="string">Organización asociada al token de gestión actual.</ResponseField>
<ResponseField name="balance" type="number">Saldo actual de la organización en USD como JSON number para visualización.</ResponseField>

<ResponseField name="total_used" type="number">Gasto acumulado de uso de la organización en USD como JSON number para visualización.</ResponseField>
