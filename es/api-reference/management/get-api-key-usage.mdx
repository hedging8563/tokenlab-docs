title: "Obtener uso de API Key"
openapi: "GET /v1/management/api-keys/{keyId}/usage"
description: "Devuelve el detalle de uso paginado para una API Key de usuario."
---

## Resumen

Este endpoint devuelve el detalle de uso por API Key sin exponer metadata de routing físico.

## Parámetros de consulta

| Parámetro | Tipo | Valores por defecto / límites | Descripción |
|-----------|------|-------------------------------|-------------|
| `page` | integer | valor por defecto `1`, mínimo `1` | Número de página empezando en 1 |
| `limit` | integer | valor por defecto `50`, mínimo `1`, máximo `100` | Tamaño de página |
| `model` | string | longitud máxima `100` | Nombre del modelo solicitado |
| `modelVendor` | string | longitud máxima `100` | Proveedor público del modelo |
| `scene` | enum | - | `chat`, `image`, `audio`, `video`, `embedding`, `rerank`, `translation`, `music`, `3d`, `realtime` |
| `startDate` | string | - | Límite inferior inclusivo; acepta RFC3339 con zona horaria o `YYYY-MM-DD` |
| `endDate` | string | - | Límite superior inclusivo; acepta RFC3339 con zona horaria o `YYYY-MM-DD` |

Si `startDate` y `endDate` se envían a la vez, `startDate` debe ser anterior o igual a `endDate`.

## Notas

- Los campos monetarios solo admiten USD. Las entradas `CNY` están retiradas y devuelven `400 currency_retired`.

- La respuesta está paginada.
- La respuesta solo incluye campos públicos de facturación y reporting.
- Cada registro de uso también puede incluir `billing_transaction_id` una vez que la solicitud subyacente haya quedado liquidada. Úsalo junto con `request_id` para la conciliación a nivel de solicitud.
- La metadata de routing interno y de canales físicos permanece oculta de forma intencional.

## Ejemplo

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/usage?page=1&limit=20&scene=video&startDate=2026-03-01&endDate=2026-03-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Campos importantes

<ResponseField name="api_key" type="object">Resumen de la clave API con los mismos campos que las respuestas de listado, creación y actualización.</ResponseField>
<ResponseField name="items" type="array">Filas de uso paginadas.</ResponseField>
<ResponseField name="pagination" type="object">Metadatos de paginación con `page`, `limit`, `total` y `totalPages`.</ResponseField>
<ResponseField name="summary" type="object">Totales agregados para los filtros seleccionados.</ResponseField>
<ResponseField name="breakdowns" type="object">Desgloses agregados para los filtros seleccionados.</ResponseField>
<ResponseField name="items[].request_id" type="string | null">Identificador público de solicitud para soporte y conciliación.</ResponseField>
<ResponseField name="items[].billing_transaction_id" type="string | null">ID de transacción de facturación liquidada cuando esté disponible.</ResponseField>
<ResponseField name="items[].model" type="string">Nombre del modelo público solicitado.</ResponseField>
<ResponseField name="items[].logical_model" type="string">Modelo público lógico usado para informes.</ResponseField>
<ResponseField name="items[].model_vendor" type="string | null">Proveedor del modelo público.</ResponseField>
<ResponseField name="items[].scene" type="string | null">Escena de solicitud pública.</ResponseField>
<ResponseField name="items[].usage_unit" type="string">Unidad de uso de facturación, como `per_token`.</ResponseField>
<ResponseField name="items[].usage_quantity" type="number">Cantidad de uso como número JSON para visualización.</ResponseField>
<ResponseField name="items[].usage_quantity_decimal" type="string">Cantidad de uso exacta como cadena decimal.</ResponseField>
<ResponseField name="items[].prompt_tokens" type="number">Recuento de tokens de prompt.</ResponseField>
<ResponseField name="items[].completion_tokens" type="number">Recuento de tokens de finalización.</ResponseField>
<ResponseField name="items[].total_tokens" type="number">Recuento total de tokens.</ResponseField>
<ResponseField name="items[].cache_read_tokens" type="number">Recuento de tokens leídos de la caché.</ResponseField>
<ResponseField name="items[].cache_write_tokens" type="number">Recuento total de tokens escritos en la caché.</ResponseField>
<ResponseField name="items[].cache_write_tokens_5m" type="number">Recuento de tokens de escritura de caché de cinco minutos.</ResponseField>
<ResponseField name="items[].cache_write_tokens_1h" type="number">Recuento de tokens de escritura de caché de una hora.</ResponseField>
<ResponseField name="items[].cost" type="number">Coste en USD como número JSON para visualización.</ResponseField>
<ResponseField name="items[].cost_decimal" type="string">Coste exacto en USD como cadena decimal.</ResponseField>
<ResponseField name="items[].created_at" type="string">Marca de tiempo ISO de la fila de uso.</ResponseField>
<ResponseField name="summary.total_requests" type="number">Número total de solicitudes.</ResponseField>
<ResponseField name="summary.total_cost" type="number">Coste total en USD como número JSON para visualización.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">Coste total exacto en USD como cadena decimal.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">Recuento total de tokens de prompt.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">Recuento total de tokens de finalización.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">Recuento total de tokens.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">Cantidad de uso agrupada por unidad de uso.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">Desglose por modelo público solicitado.</ResponseField>
