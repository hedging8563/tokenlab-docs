---
title: "Crear una completación de chat"
openapi: "/openapi/es.json POST /v1/chat/completions"
description: "Crea una completación para el mensaje de chat"
---

## Cuerpo de la solicitud

<Note>
Los parámetros opcionales compatibles, sus valores permitidos y sus valores predeterminados dependen del modelo seleccionado. Consulte los [detalles del modelo](/es/api-reference/models/get-model) antes de configurar opciones de muestreo, razonamiento o herramientas.
</Note>

<ParamField body="model" type="string" required>
  ID del modelo a usar. Consulte [Models](https://tokenlab.sh/es/models) para las opciones disponibles.
</ParamField>

<ParamField body="messages" type="array" required>
  Una lista de mensajes que componen la conversación.

  Cada objeto de mensaje contiene:
  - `role` (string): `system`, `developer`, `user`, `assistant`, `tool`, `function`
  - `content` (string | array | null): El contenido del mensaje

  En un mensaje `assistant` que contenga `tool_calls`, se puede omitir `content` o establecerlo en `null`.

  Cuando `content` es un array, TokenLab admite bloques multimodales estructurados para modelos compatibles:
  - text: `{ "type": "text", "text": "..." }`
  - imagen: `{ "type": "image_url", "image_url": { "url": "https://..." } }`
  - video: `{ "type": "video_url", "video_url": { "url": "https://..." } }`
  - audio: `{ "type": "audio_url", "audio_url": { "url": "https://..." } }`

  Para entradas multimodales, use URL `https` de acceso público. Los tipos de medios compatibles dependen del modelo seleccionado.
</ParamField>

<ParamField body="temperature" type="number">
  Temperatura de muestreo. La compatibilidad, los valores permitidos y el valor predeterminado dependen del modelo seleccionado. Omita este campo para usar su valor predeterminado.
</ParamField>

<ParamField body="max_tokens" type="integer">
  Número máximo de tokens a generar.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Si es true, se enviarán deltas parciales del mensaje como eventos SSE.
</ParamField>

<ParamField body="stream_options" type="object">
  Opciones para streaming. Establezca `include_usage: true` para recibir el uso de tokens en fragmentos de la transmisión.
</ParamField>

<ParamField body="top_p" type="number">
  Parámetro de muestreo Nucleus. Recomendamos alterar esto o la temperatura, no ambos.
</ParamField>

<ParamField body="frequency_penalty" type="number">
  Número entre -2.0 y 2.0. Los valores positivos penalizan tokens repetidos.
</ParamField>

<ParamField body="presence_penalty" type="number">
  Número entre -2.0 y 2.0. Los valores positivos penalizan tokens que ya están en el texto.
</ParamField>

<ParamField body="stop" type="string | array">
  Secuencia de parada o lista de secuencias. La compatibilidad y el límite de secuencias dependen del modelo seleccionado.
</ParamField>

<ParamField body="tools" type="array">
  Una lista de herramientas que el modelo puede invocar (llamado de funciones).
</ParamField>

<ParamField body="tool_choice" type="string | object">
  Controla cómo el modelo usa las herramientas. Opciones: `auto`, `none`, `required`, o un objeto de herramienta específico.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean">
  Permite varias llamadas a herramientas en un mismo turno del asistente, si el modelo seleccionado lo admite.
</ParamField>

<ParamField body="max_completion_tokens" type="integer">
  Tokens máximos para la completación. Alternativa a `max_tokens`, útil para familias de modelos más nuevas con capacidad de razonamiento.
</ParamField>

<ParamField body="reasoning_effort" type="string">
  Esfuerzo de razonamiento para modelos compatibles. Los valores permitidos dependen del modelo seleccionado.
</ParamField>

<ParamField body="seed" type="integer">
  Semilla de muestreo para modelos compatibles. No se garantiza una salida idéntica.
</ParamField>

<ParamField body="n" type="integer">
  Número de completaciones a generar (1-128).
</ParamField>

<ParamField body="logprobs" type="boolean">
  Si se deben retornar las probabilidades logarítmicas.
</ParamField>

<ParamField body="top_logprobs" type="integer">
  Número de probabilidades logarítmicas superiores a retornar (0-20). Requiere `logprobs: true`.
</ParamField>

<ParamField body="top_k" type="integer">
  Muestreo Top-K para modelos compatibles.
</ParamField>

<ParamField body="response_format" type="object">
  Formato de respuesta. Use `{"type": "json_object"}` para el modo JSON o `{"type": "json_schema", "json_schema": {...}}` para un esquema JSON. La compatibilidad depende del modelo seleccionado.
</ParamField>

<ParamField body="logit_bias" type="object">
  Modifica la probabilidad de aparición de tokens especificados. Mapee IDs de tokens (como strings) a valores de sesgo de -100 a 100.
</ParamField>

<ParamField body="user" type="string">
  Un identificador único que representa a su usuario final para la monitorización de abuso.
</ParamField>


## Respuesta

<ResponseField name="id" type="string">
  Identificador único para la completación.
</ResponseField>

<ResponseField name="object" type="string">
  Siempre `chat.completion`.
</ResponseField>

<ResponseField name="created" type="integer">
  Marca de tiempo Unix de cuando se creó la completación.
</ResponseField>

<ResponseField name="model" type="string">
  El modelo usado para la completación.
</ResponseField>

<ResponseField name="choices" type="array">
  Lista de opciones de completación.

  Cada opción contiene:
  - `index` (integer): Índice de la opción
  - `message` (object): El mensaje generado
  - `finish_reason` (string): Motivo por el que se detuvo el modelo, por ejemplo `stop`, `length` o `tool_calls`
</ResponseField>

<ResponseField name="usage" type="object">
  Estadísticas de uso de tokens.

  - `prompt_tokens` (integer): Tokens en el prompt
  - `completion_tokens` (integer): Tokens en la completación
  - `total_tokens` (integer): Tokens totales utilizados
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/chat/completions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "max_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="gpt-5.6-terra",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    max_tokens=1000
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [
    { role: 'system', content: 'You are a helpful assistant.' },
    { role: 'user', content: 'Hello!' }
  ],
  max_tokens: 1000
});

console.log(response.choices[0].message.content);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/chat/completions');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-5.6-terra',
        'messages' => [
            ['role' => 'system', 'content' => 'You are a helpful assistant.'],
            ['role' => 'user', 'content' => 'Hello!']
        ],
        'max_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['choices'][0]['message']['content'];
```
