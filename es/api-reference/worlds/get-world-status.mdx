---
title: "Obtener estado del World"
openapi: "/openapi/es.json GET /v1/worlds/generations/{id}"
description: "Recupera el estado y resultado de una tarea de generación de mundo World Labs Marble"
---

Consulta este endpoint para comprobar el estado de una tarea de generación World Labs Marble. Si la respuesta de creación incluyó `poll_url`, prefiere llamar esa URL exacta.

<Info>
Una tarea pública caducada o no disponible puede devolver `404 async_task_not_found`. Si no se puede confirmar que pertenece a la clave API actual, devuelve `403 task_not_owned`.
</Info>

## Parámetros de ruta

<ParamField path="id" type="string" required>
  ID de la tarea de generación de mundo.
</ParamField>

## Respuesta

Solo `id` y `status` son obligatorios en una respuesta de estado correcta. Los alias de tarea, ID de operación, recursos del mundo, descripciones, costes y la cadena `error` se devuelven cuando están disponibles. Una tarea completada no garantiza que existan todas las URL de recursos.

<ResponseField name="id" type="string">
  ID público de tarea.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias del identificador de tarea asíncrona.
</ResponseField>

<ResponseField name="operation_id" type="string">
  ID de operación de World Labs en el servicio de origen.
</ResponseField>

<ResponseField name="status" type="string">
  Estado de la tarea: `pending`, `processing`, `completed`, `failed` o `timeout`.
</ResponseField>

<ResponseField name="world_id" type="string">
  ID del mundo de World Labs en el servicio de origen cuando finaliza.
</ResponseField>

<ResponseField name="world_marble_url" type="string">
  URL del mundo Marble generado cuando finaliza.
</ResponseField>

<ResponseField name="model_url" type="string">
  Alias de la URL principal del mundo/modelo generado.
</ResponseField>

<ResponseField name="glb_url" type="string">
  URL GLB de la malla collider si está disponible.
</ResponseField>

<ResponseField name="pano_url" type="string">
  URL de imagen panorámica si está disponible.
</ResponseField>

<ResponseField name="thumbnail_url" type="string">
  URL de miniatura si está disponible.
</ResponseField>

<ResponseField name="caption" type="string">
  Caption upstream del mundo generado.
</ResponseField>

<ResponseField name="cost" type="object">
  Detalles del coste de generación, si están disponibles, incluido `total_credits`. Consulta tus registros de uso para conocer el importe facturado.
</ResponseField>

<ResponseField name="error" type="string">
  Mensaje de error cuando la tarea falla.
</ResponseField>

<RequestExample>
```bash cURL
curl --fail-with-body "https://api.tokenlab.sh/v1/worlds/generations/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/worlds/generations/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"},
    )
    response.raise_for_status()
    result = response.json()
    if result["status"] in ["completed", "failed", "timeout"]:
        print(result)
        break
    time.sleep(10)
```
