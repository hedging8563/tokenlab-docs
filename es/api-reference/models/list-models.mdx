---
title: "Listar modelos"
openapi: "GET /v1/models"
description: "Listar los modelos disponibles actualmente en TokenLab"
---

El catálogo de modelos es público y no requiere una API key. Cada elemento incluye un resumen de las capacidades actuales, precios y formatos de API. Obtenga un modelo específico cuando necesite detalles completos.

## Parámetros de consulta

<ParamField query="category" type="string">
  Filtrar por `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank` o `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  Devolver las recomendaciones actuales para una tarea como `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank` o `translation`.
</ParamField>

<ParamField query="provider" type="string">
  Filtrar por el creador del modelo, como `openai`, `anthropic`, `google` o `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  Filtrar por una etiqueta como `chat`, `image`, `video`, `embedding` o `translation`.
</ParamField>

## Respuesta

<ResponseField name="object" type="string">Siempre `list`.</ResponseField>
<ResponseField name="data" type="array">Modelos con `id`, `owned_by` y un resumen de `tokenlab`.</ResponseField>

Los campos de lista comunes bajo `tokenlab` incluyen:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` y `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` y `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial` y `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` cuando se utiliza `recommended_for`

Cuando se utiliza `recommended_for`, los resultados también pueden incluir el estado de la recomendación y una hora de actualización. Lea la respuesta actual en lugar de fijar el orden.

## Ejemplo

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```

Consulte [Obtener un modelo](/api-reference/models/get-model) para obtener detalles completos.
