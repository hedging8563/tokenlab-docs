---
title: "Obtener estado de la música"
openapi: "GET /v1/tasks/{id}"
description: "Recupera el estado y el resultado de una tarea de generación de música"
---

Realice polling a este endpoint para verificar el estado de su tarea de generación de música.

<Info>
Si la respuesta de creación incluye `poll_url`, prioriza esa URL exacta para el polling. `id` y `task_id` deben tratarse como la misma identidad de tarea asíncrona.


Una tarea pública caducada o no disponible puede devolver `404 async_task_not_found`. Si no se puede confirmar que pertenece a la clave API actual, devuelve `403 task_not_owned`.
</Info>

## Parámetros de ruta

<ParamField path="id" type="string" required>
  El ID de la tarea de generación de música.
</ParamField>

## Respuesta

<ResponseField name="id" type="string">
  ID de la tarea.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias del mismo ID de tarea asíncrona, cuando se devuelve.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de sondeo preferida cuando la respuesta de creación la proporciona.
</ResponseField>

<ResponseField name="status" type="string">
  Estado de la tarea: `pending`, `processing`, `completed` o `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Valor de progreso opcional. Solo se devuelve cuando hay un progreso real disponible; usa `status` para determinar la finalización.
</ResponseField>

Los campos dependen de la operación. La música puede devolver `audio_url` y `audio_id`; las tareas de solo letras, `lyrics`; la separación, varios archivos en `data`. `video_url`, título, progreso y otros metadatos son opcionales. Comprueba `status` para determinar la finalización y lee los campos realmente devueltos.

<ResponseField name="audio_id" type="string">
  ID de audio opcional que puede usarse con este ID de tarea para operaciones posteriores compatibles.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de salidas opcional, como archivos de pistas separadas con `audio_url` o `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  URL para descargar el archivo de audio (cuando se haya completado).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL de la versión en video con visualizador (cuando se haya completado).
</ResponseField>

<ResponseField name="title" type="string">
  Título de la canción generada.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Letras generadas o proporcionadas.
</ResponseField>

<ResponseField name="error" type="string | object">
  Mensaje de error (cuando falle).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
