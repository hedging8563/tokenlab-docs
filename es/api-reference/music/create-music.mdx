---
title: "Crear música"
openapi: "/openapi/es.json POST /v1/music/generations"
description: "Crea una tarea de generación de música utilizando Suno"
---

Genera música y letras utilizando IA. Esta es una API asíncrona. La respuesta de creación devuelve una identidad de tarea y, cuando está disponible, también puede incluir un `poll_url` preferido.

## Cuerpo de la solicitud

<ParamField body="model" type="string" default="suno_music">
  ID del modelo musical, como `suno-music`. Para generar solo letras, elige un modelo cuyas operaciones públicas actuales incluyan `lyrics`.
</ParamField>

<ParamField body="prompt" type="string">
  Descripción musical o texto de reemplazo. Obligatorio para música, letras, upload-cover, upload-extend y replace-section; opcional para add-instrumental y separación de pistas.
</ParamField>

<ParamField body="title" type="string">
  Título para la canción generada.
</ParamField>

<ParamField body="tags" type="string">
  Etiquetas de estilo (por ejemplo, "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  Estilos que se deben evitar. Es obligatorio cuando `audio_operation` es `add-instrumental`.
</ParamField>

<ParamField body="action" type="string">
  Valor opcional `MUSIC` o `LYRICS`. Elige un modelo compatible con la operación pública correspondiente; este campo no añade generación de letras a un modelo que solo admite música.
</ParamField>

<ParamField body="mv" type="string">
  Selector de versión Suno. Obligatorio para generación, upload-cover, upload-extend, add-instrumental y reemplazo desde `audio_url`. Omítelo para letras, reemplazo desde `task_id` + `audio_id` y separación de pistas. Valores admitidos: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  Establécelo en `true` para generar una salida instrumental sin voces.
</ParamField>

<ParamField body="audio_url" type="string">
  URL de audio de referencia o subido que sea accesible públicamente. Si se envía sin `audio_operation`, TokenLab usa el flujo upload-cover.
</ParamField>

<ParamField body="audio_operation" type="string">
  Operación de audio: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation` y `advanced-split` requieren `task_id` + `audio_id`; `advanced-split` también requiere `stem_name`. `upload-extend` requiere `continue_at` mayor que 0. `add-instrumental` requiere `audio_url`, `title`, `tags` y `negative_tags`.

  `replace-section` requiere `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s` y `full_lyrics`. Elige exactamente una fuente: `task_id` + `audio_id`, o `audio_url` + `mv`. El intervalo reemplazado debe durar entre 6 y 60 segundos.
</ParamField>

<ParamField body="task_id" type="string">
  ID de una tarea fuente de tu organización, para reemplazar audio generado o separar pistas.
</ParamField>

<ParamField body="audio_id" type="string">
  ID de audio devuelto en el resultado de la tarea fuente. Obligatorio junto con `task_id` para reemplazar audio generado o separar pistas.
</ParamField>

<ParamField body="infill_start_s" type="number">
  Inicio del reemplazo en segundos, como mínimo 0. Obligatorio para `replace-section`.
</ParamField>

<ParamField body="infill_end_s" type="number">
  Fin del reemplazo en segundos. Obligatorio para `replace-section`, entre 6 y 60 segundos después de `infill_start_s`.
</ParamField>

<ParamField body="full_lyrics" type="string">
  Letra completa de la canción resultante. Obligatoria para `replace-section`.
</ParamField>

<ParamField body="stem_name" type="string">
  Nombre de la pista. Obligatorio para `advanced-split`.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  ID de un clip anterior desde el cual continuar.
</ParamField>

<ParamField body="continue_at" type="number">
  Punto de continuación en segundos. Obligatorio y mayor que 0 para `upload-extend`.
</ParamField>

<Note>
`prompt` admite hasta 5000 caracteres; `tags` y `negative_tags`, hasta 1000 cada uno. Las operaciones y parámetros admitidos dependen de los detalles actuales del modelo.
</Note>

## Respuesta

<ResponseField name="id" type="string">
  ID de la tarea para consultar el estado.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias del mismo ID de tarea asíncrona, cuando se devuelve.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling prioritaria cuando está disponible.
</ResponseField>

<ResponseField name="status" type="string">
  Estado de la tarea: `pending`, `processing`, `completed` o `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  Marca de tiempo Unix de creación de la tarea, cuando se devuelve.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
