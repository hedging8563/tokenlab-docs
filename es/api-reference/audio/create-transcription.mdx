---

## Cuerpo de la solicitud

La transcripción puede devolver el texto directamente o aceptar una tarea asíncrona con HTTP `200`, `id` y `status`. Para una tarea aceptada, sigue `poll_url` o consulta `/v1/tasks/{id}`. Para audio largo procesado de forma síncrona, permite al menos `120s` de espera.

<ParamField body="file" type="file" required>
  Archivo de audio para transcribir. Formatos compatibles: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. Tamaño máximo del archivo: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  ID del modelo de transcripción, como `whisper-1` o `gpt-4o-transcribe`. Consulta las opciones actuales con `GET /v1/models?recommended_for=stt`.
</ParamField>

<ParamField body="language" type="string">
  Idioma del audio en formato ISO-639-1 (p. ej., `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  Texto opcional para guiar el estilo del modelo o continuar un segmento anterior.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Formato de salida. Whisper admite `json`, `text`, `srt`, `verbose_json` y `vtt`; otros modelos pueden admitir un conjunto distinto. Consulta los detalles del modelo.
</ParamField>

<ParamField body="temperature" type="number">
  Temperatura de muestreo de 0 a 1, solo para modelos compatibles con este parámetro.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  `word` y/o `segment`, si el modelo los admite. Whisper requiere `response_format=verbose_json`. En multipart, repite `timestamp_granularities[]` para enviar varios valores.
</ParamField>

## Respuesta

Los campos siguientes describen respuestas JSON de transcripción o traducción. `text`, `srt` y `vtt` devuelven texto o subtítulos sin envolverlos en JSON. Los campos adicionales dependen del modelo y del formato.

<ResponseField name="text" type="string">
  El texto transcrito.
</ResponseField>

Para `verbose_json`:

<ResponseField name="task" type="string">
  Nombre de la tarea cuando se devuelve, como `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  Idioma detectado.
</ResponseField>

<ResponseField name="duration" type="number">
  Duración del audio en segundos.
</ResponseField>

<ResponseField name="segments" type="array">
  Segmentos de la transcripción con marcas de tiempo.
</ResponseField>

<ResponseField name="words" type="array">
  Marcas de tiempo a nivel de palabra (si se solicitan).
</ResponseField>

Una tarea asíncrona de transcripción aceptada devuelve los campos siguientes en lugar del texto:

<ResponseField name="id" type="string">
  ID de la tarea.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias del identificador de tarea asíncrona cuando está disponible.
</ResponseField>

<ResponseField name="status" type="string">
  Estado de la tarea: `pending`, `processing`, `completed` o `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de sondeo preferida cuando la respuesta de creación la proporciona.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```

## Traducción

Para traducir audio al inglés, utiliza el endpoint de traducciones:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
