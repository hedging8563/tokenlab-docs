## Claves API

Las llamadas a modelos y los recursos privados requieren una clave API. Los endpoints públicos como `GET /v1/models` y `GET /v1/models/{model}` funcionan sin ella. Una consulta de descubrimiento correcta no valida la clave; sigue el inicio rápido para enviar una solicitud al modelo. Usa la clave completa guardada, no el prefijo de la lista.

Para los endpoints compatibles con OpenAI, envíala como:

```bash
Authorization: Bearer sk-your-api-key
```

Para las solicitudes compatibles con Anthropic a `/v1/messages`, también puedes usar:

```bash
x-api-key: sk-your-api-key
```

## Tokens de gestión

Los endpoints de la API de gestión usan un tipo de token distinto:

```bash
Authorization: Bearer mt-your-management-token
```

Usa los tokens de gestión solo con `/v1/management/*`. Abre [API → Tokens](https://tokenlab.sh/dashboard/api?tab=tokens) en el espacio de trabajo seleccionado para crear o reemplazar un token. Guarda el token completo de forma segura; solo se muestra una vez después de crearlo o reemplazarlo.

<Note>
Los tokens de gestión no sirven para inferencia de modelos, y las claves API normales `sk-...` no sirven para la API de gestión.
</Note>

## Obtener tu clave API

1. Inicia sesión en tu [TokenLab Dashboard](https://tokenlab.sh/dashboard)
2. Abre **API Keys**
3. Crea una nueva clave
4. Asígnale un nombre descriptivo
5. Cópiala inmediatamente porque se muestra solo una vez

<Warning>
- Nunca expongas claves API en código del lado del cliente
- Nunca subas claves API al control de versiones
- Usa variables de entorno o un gestor de secretos
- Rota las claves periódicamente
- Elimina las claves sin usar
</Warning>

## Uso de claves API

Consulta el [inicio rápido](/es/quickstart) para las variables de entorno y una primera solicitud completa. Usa el SDK correspondiente al [formato API](/es/guides/api-formats) y guarda las claves en el servidor.

## Características de las claves API

### Límites de uso

Puedes establecer un límite de uso en cada clave API:

| Configuración | Descripción |
|---------|-------------|
| **Sin límite** | La clave usa el saldo de tu cuenta sin restricciones |
| **Límite fijo** | La clave deja de funcionar después de alcanzar la cantidad especificada |

### Prefijo de clave

Todas las claves API de TokenLab comienzan con `sk-`.

## Respuestas de error

| Código de estado | Tipo | Código | Descripción |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | La clave API falta, no es válida, está inactiva o fue revocada |
| 401 | `expired_api_key` | `expired_api_key` | La clave API ha caducado |
| 402 | `insufficient_balance` | `insufficient_balance` | El saldo de la cuenta es insuficiente |
| 402 | `quota_exceeded` | `quota_exceeded` | Se alcanzó el límite de uso de la clave API |

Ejemplo:

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
