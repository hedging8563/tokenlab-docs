Un saldo TokenLab sirve para todos los modelos. No hay suscripción ni gasto mínimo; se cobra según el modelo y el uso registrado.

## Precios y opciones de entrega

Consulta precios actuales en la página del modelo, `GET /v1/models/{model}/pricing` o Pricing API. No fijes una tabla copiada en tu aplicación. Texto y embeddings pueden cobrarse por tokens de entrada, salida o caché; los medios también por imagen, segundo, minuto, solicitud o tarea.

`TokenLab Verified` usa los precios públicos de TokenLab y `Official` la capa Official basada en los precios públicos del fabricante. `Auto` prioriza Verified y usa Official si hace falta; cobra una vez por la opción que entrega el resultado. Console muestra la estimación máxima antes de confirmar una generación de pago y el importe final en Runs y Usage.

[Pricing API](/es/api-reference/pricing/get-pricing)

## Facturación asíncrona y registros

Algunas tareas reservan el coste estimado al crearse. Guarda el ID y `poll_url` y consulta hasta `completed` o `failed`. Una tarea correcta se cobra una vez y se libera la reserva sobrante; si falla, el importe pendiente se libera o devuelve.

Las respuestas OpenAI compatibles sin streaming pueden incluir `billing_transaction_id` o `X-Billing-Transaction-ID` cuando termina la facturación. Los formatos nativos pueden usar solo el header. El resultado asíncrono o en streaming puede llegar antes del registro contable; consulta Usage si falta el identificador.

Usage muestra modelo, clave, coste y consumo. La tokenización depende del modelo, idioma y medios; contar caracteres no sustituye la factura final. El streaming no reduce tokens facturados. Compara el coste final de tareas iguales y usa límites de salida admitidos.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Uso de Console

En Console → Billing, elige importe y uno de los métodos mostrados al pagar. El saldo se actualiza cuando el servicio de pago confirma la operación.

Configura un límite de gasto al crear o editar una clave en Console → API Keys. Al alcanzarlo se devuelve `402 Payment Required`.

Configura alertas de saldo en Console → Settings. Para consultas, envía Request ID e ID de tarea a support@tokenlab.sh, nunca la clave API.
