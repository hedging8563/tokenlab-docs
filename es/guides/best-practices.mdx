## Modelos y coste

Consulta capacidades y precios actuales en la API o página del modelo. Compara tareas equivalentes y especifica el modelo en cada solicitud. No cambies de modelo sin avisar: pueden variar precio, calidad, herramientas y contexto.

Limita la salida según el formato y el modelo, y elimina contexto duplicado. El coste de medios puede depender de cantidad, duración o resolución; muestra la estimación disponible antes de confirmar una generación costosa.

## Streaming y reintentos

El streaming muestra texto antes, pero no reduce el coste de tokens. Conserva la salida parcial útil tras una desconexión sin marcarla como una respuesta completa.

En un 429 respeta `Retry-After` o `retry_after`; usa un retroceso breve ante 5xx transitorios. Los errores de autenticación, permisos, saldo, validación o contexto requieren cambios. Limita intentos y tiempo total y evita duplicar los reintentos del SDK.

- [Streaming](/es/guides/streaming)
- [429 / Retry-After](/es/guides/rate-limits)

## Claves y registros

Guarda las claves en el servidor o en un gestor de secretos, nunca en el navegador, una app distribuida, repositorios públicos o registros. Separa desarrollo, producción y aplicaciones, limita modelos y gasto y revoca las claves expuestas.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
)
```

Registra `request_id`, `task_id`, el `billing_transaction_id` recibido, modelo, endpoint y tu ID de trabajo. No registres credenciales, prompts privados completos, medios ni URL firmadas. Usa Usage de Console o la API de gestión para el importe final.

## Tareas asíncronas

Guarda el ID y `poll_url` al crear una tarea asíncrona y consulta hasta `completed` o `failed`. Un fallo de consulta no significa que la generación haya fallado. Tras un timeout o recarga, recupera la tarea guardada; usa idempotencia cuando el endpoint la admita.

[Trabajos Asíncronos y Polling](/es/guides/async-jobs-polling)

## Antes del lanzamiento

Antes del lanzamiento, comprueba el modelo y formato exactos, respuestas correctas y errores comunes, precios actuales, recargas y clics repetidos.
