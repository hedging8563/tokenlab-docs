La mayoría de las herramientas se conectan a TokenLab cambiando la clave de API y la URL base. La configuración exacta depende del formato de API que pueda usar la herramienta.

| Formato de API | URL base | Clientes habituales |
| --- | --- | --- |
| Chat Completions (Compatible con OpenAI) | `https://api.tokenlab.sh/v1` | SDK de OpenAI y muchas aplicaciones de chat y frameworks |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | Clientes de Responses y herramientas basadas en sus eventos |
| Anthropic Messages | `https://api.tokenlab.sh` | SDK de Anthropic y herramientas para Claude |
| Gemini | `https://api.tokenlab.sh` | Clientes REST y SDK de Gemini que permiten un host personalizado |

El modelo elegido debe incluir el mismo formato en `accepted_request_formats`. El streaming y las llamadas a herramientas también dependen de las capacidades del modelo y del cliente. Consulta los ejemplos en [Formatos de API](/es/guides/api-formats).

## Etiquetas de compatibilidad

| Etiqueta | Significado |
| --- | --- |
| **Compatible** | La configuración de TokenLab de la página enlazada utiliza las opciones documentadas del cliente |
| **Compatible con límites** | La configuración se aplica a funciones o métodos de autenticación específicos; los demás servicios del proveedor mantienen sus propios requisitos |

Estas etiquetas describen la configuración de la página enlazada. Las funciones disponibles también dependen del modelo elegido y de la versión del cliente.

## Consumo en respuestas de streaming

Los flujos de Chat Completions aceptan `stream_options: { include_usage: true }`, que añade un último fragmento de consumo antes de cerrar el flujo. La API Responses no ofrece `include_usage`; sus flujos incluyen el consumo en el evento final.

## Qué no sustituye una clave de API personalizada

Algunos productos combinan llamadas al modelo con funciones alojadas por su proveedor. Una clave de TokenLab permite realizar las solicitudes de modelo disponibles mediante BYOK, pero no sustituye otras suscripciones, servicios de autocompletado, funciones de cuenta ni extensiones propietarias.

Si una actualización cambia la configuración de una herramienta, consulta la página de integración actual en vez de copiar un fragmento antiguo de variables de entorno.

## Antes de depender de una función

- Confirma que la herramienta permite una URL base personalizada para el formato que necesitas.
- Confirma que el modelo incluye ese formato en `accepted_request_formats`.
- Prueba el streaming y las llamadas a herramientas si tu flujo de trabajo los requiere.
- Guarda la clave de API en un equipo o servidor de confianza.
- Anota el ID de solicitud al informar de un fallo.
