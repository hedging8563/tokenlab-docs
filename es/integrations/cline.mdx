## Descripción general

<Note>
**Tipo**: agente de programación para IDE

**Ruta principal**: Chat Completions compatible con OpenAI

**Compatibilidad**: ruta oficial del proveedor
</Note>

[Cline](https://docs.cline.bot/provider-config/openai-compatible) permite proveedores compatibles con OpenAI en la configuración del IDE.

## Configurar TokenLab

1. Instala **Cline** desde el mercado de extensiones y abre su panel.
2. Pulsa el engranaje y selecciona **OpenAI Compatible** en **API Provider**.
3. Introduce:

| Campo | Valor |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | Tu clave API de TokenLab |
| Model ID | `kimi-k3` |

4. Pulsa **Verify**.

En la configuración avanzada opcional, usa `1048576` como límite de entrada, `131072` como salida máxima y activa imágenes y herramientas / Computer Use.

Tras verificar, empieza con una tarea de solo lectura. Si aparece un 404, confirma que la Base URL termina en `/v1` y no contiene `/chat/completions`. El ID es `kimi-k3`, no `kimi/kimi-k3`.
