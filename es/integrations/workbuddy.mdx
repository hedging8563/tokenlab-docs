## Descripción general

<Note>
**Tipo**: agente de escritorio para código y tareas

**Ruta principal**: Chat Completions compatible con OpenAI

**Compatibilidad**: ruta oficial de modelo personalizado
</Note>

[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) ofrece un editor visual para modelos compatibles con OpenAI. No hace falta editar manualmente el archivo local.

## Configurar TokenLab

Abre **Settings → Model**, añade un modelo y elige **Custom**.

| Campo | Valor |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | Tu clave API de TokenLab |
| Model name | `kimi-k3` |
| Custom Protocol | **Desactivado** |

<Warning>
Mantén Custom Protocol desactivado. El modo estándar valida la Base URL y añade `/chat/completions`. Si lo activas y solo introduces `/v1`, la solicitud usa una ruta incorrecta.
</Warning>

En los ajustes avanzados, activa llamadas a herramientas, entrada de imágenes y razonamiento. Desactiva el modo solo razonamiento, deja el esfuerzo en Auto y usa `1048576` como entrada y `131072` como salida.

Guarda, selecciona `kimi-k3` y prueba primero una inspección de carpeta de solo lectura. Oculta claves y endpoints privados antes de compartir capturas.
