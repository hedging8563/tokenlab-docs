## Dejar que mi agente lo configure

Copia esta tarea en un agente que ya funcione en tu ordenador:

```text
Lee esta guía y ayúdame a conectar WorkBuddy con TokenLab:
https://docs.tokenlab.sh/es/integrations/workbuddy
Comprueba primero mi versión instalada y la configuración activa.
Conserva las cuentas, los proveedores, los permisos y los demás ajustes existentes.
Haz una copia de seguridad de los archivos locales y muestra los cambios propuestos.
Las claves API necesarias las introduciré localmente; nunca las pidas, muestres ni pegues en el chat.
Comprueba primero que la configuración se carga correctamente.
Explica por separado el coste de cualquier prueba con peticiones de pago antes de ejecutarla.
```

## Descripción general

[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) ofrece un editor visual para modelos compatibles con OpenAI. No hace falta editar manualmente el archivo local.

## Configurar TokenLab

Abre **Settings → Model**, añade un modelo y elige **Custom**.

| Campo | Valor |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | Tu clave API de TokenLab |
| Model name | `kimi-k3` |
| Custom Protocol | **Desactivado** |

<Warning>
Mantén Custom Protocol desactivado. El modo estándar valida la Base URL y añade `/chat/completions`. Si lo activas y solo introduces `/v1`, la solicitud usa una ruta incorrecta.
</Warning>

Configura herramientas, imágenes, razonamiento y límites según los detalles actuales del modelo en TokenLab. No actives todo ni copies límites 1M/128K de otro modelo. Usa el ID mostrado.

Guarda, selecciona `kimi-k3` y prueba primero una inspección de carpeta de solo lectura. Oculta claves y endpoints privados antes de compartir capturas.

Guardar y seleccionar solo confirma ajustes locales. Las tareas de texto o herramientas usan saldo TokenLab; comprueba la respuesta y su [registro](https://tokenlab.sh/dashboard/runs?section=requests). Para deshacer, selecciona el modelo anterior y elimina solo la entrada TokenLab añadida.

La aplicación oficial está disponible para macOS y Windows. Usa el [editor oficial](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model); no se presupone una versión Linux ni un formato de archivo editable directamente.

Las [herramientas API MCP](/es/integrations/tokenlab-mcp-server) y las [instrucciones Skill](/es/integrations/coding-agent-skill) se instalan por separado y no cambian el modelo principal.
