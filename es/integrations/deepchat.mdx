## Descripción general

DeepChat funciona con TokenLab a través de una configuración de proveedor estándar compatible con OpenAI.

<Note>
**Tipo**: Aplicación de chat

**Ruta principal**: Completado de chat compatible con OpenAI

**Nivel de soporte**: Ruta soportada
</Note>

## Configurar DeepChat

1. Abre **Settings** -> **Model Provider**
2. Añade o edita un proveedor compatible con OpenAI
3. Introduce:
   - **Provider name**: TokenLab
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Añade un modelo como `gpt-5.4-mini`
5. Guarda y prueba un chat.

## Opciones de modelos

Comienza con `gpt-5.4-mini` para una opción predeterminada de baja fricción. Utiliza `claude-sonnet-5`, `gpt-5.4` o `deepseek-v4-pro` cuando la conversación requiera un razonamiento más avanzado.

## Solución de problemas

- Utiliza la URL base, no la ruta completa `/chat/completions`, a menos que DeepChat solicite explícitamente una URL de endpoint completa.
- Elimina los espacios finales de la API key.
- Si un modelo no aparece en la lista, añade el ID del modelo de TokenLab exacto manualmente.
