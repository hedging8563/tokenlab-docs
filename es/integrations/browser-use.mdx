## Descripción general

Browser Use puede invocar a TokenLab a través de `ChatOpenAILike`, el wrapper de modelos de chat compatible con OpenAI.

<Note>
**Tipo**: Framework de agentes de automatización de navegador

**Ruta principal**: Chat Completions compatibles con OpenAI

**Nivel de soporte**: Ruta compatible con OpenAI soportada
</Note>

## Entorno

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Ejemplo

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## Notas sobre el endpoint

Utiliza esta página para flujos de trabajo de Browser Use que llamen a Chat Completions a través de un cliente compatible con OpenAI. Si tu flujo de trabajo requiere respuestas nativas de TokenLab, mensajes de Anthropic o endpoints de Gemini, utiliza una ruta de cliente en Browser Use que utilice ese protocolo directamente.
