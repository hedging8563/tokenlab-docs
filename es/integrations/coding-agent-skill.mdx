## Qué hace el skill

- Genera ejemplos mínimos ejecutables para chat, imagen, audio, video, traducción y otras familias de API de TokenLab.
- Usa `https://api.tokenlab.sh/v1` para clientes compatibles con OpenAI y explica cuándo cambiar a rutas nativas de Anthropic o Gemini.
- Descubre modelos con `/v1/models`, `/llms.txt` y listas `recommended_for` en lugar de adivinar desde listas obsoletas.
- Lee los detalles de un modelo antes de reintentar solicitudes que no sean de chat para no eliminar silenciosamente campos no compatibles.
- Gestiona pistas de error Agent-First como `did_you_mean`, `suggestions`, `retry_after` y `recommended_request`.

## Instalación

<Note>
Usa el comando canónico de instalación no interactiva:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-api-integration -y
```

Si tu herramienta no soporta el installer, copia `skills/tokenlab-api-integration/` del repositorio al directorio compartido de skills o rules de tu herramienta.
</Note>

## Flujo recomendado para Agent

Lee la lista actual y después `tokenlab.accepted_request_formats` y los campos públicos del modelo elegido. Mantén el mismo formato en la conversación y las llamadas a herramientas; los campos no se convierten automáticamente. No cambies por tu cuenta el modelo o protocolo ante un error.

## Ejemplo mínimo de chat

Este ejemplo usa el SDK Python de OpenAI con la base URL de TokenLab:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "Hello!"}],
)

print(response.choices[0].message.content)
```

Ejecútalo con:

```bash
pip install openai
export TOKENLAB_API_KEY="sk-your-api-key"
python app.py
```

## Descubrimiento de modelos y contratos

Prefiere descubrimiento en vivo antes que listas empaquetadas obsoletas:

```bash
# Resumen API legible por máquina
curl https://api.tokenlab.sh/llms.txt

# Listar modelos
curl "https://api.tokenlab.sh/v1/models" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?category=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Listas cortas clasificadas para no-chat
curl "https://api.tokenlab.sh/v1/models?recommended_for=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=video" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=translation" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Leer los detalles de un modelo antes de reintentar solicitudes que no sean de chat
curl "https://api.tokenlab.sh/v1/models/gpt-image-2" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Detalle solo de precios
curl "https://api.tokenlab.sh/v1/models/gpt-image-2/pricing" -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Selección del protocolo nativo

La ruta compatible con OpenAI `/v1` es la opción predeterminada para ejemplos comunes de chat, imagen, embedding, audio y rerank. No deduzcas la disponibilidad de un protocolo nativo por el nombre del modelo o proveedor ni por cabeceras de una respuesta de Chat. Consulta `GET /v1/models/{model}` y usa solo un formato de solicitud anunciado en los detalles del modelo.

El campo exacto es `tokenlab.accepted_request_formats`.

Los endpoints son `/v1/chat/completions` para Chat Completions, `/v1/responses` para Responses, `/v1/messages` para Messages y `/v1beta/models/{model}:generateContent` para Gemini.

## Recuperación de errores Agent-First

Los errores incluyen campos que los coding agents pueden analizar sin extraer la documentación:

Usa el estado HTTP y el `code` del error como señal principal. Consulta `did_you_mean` ante un nombre incorrecto, pero no cambies de modelo sin la elección del usuario. Para `429`, respeta `Retry-After` o `retry_after` y reintenta solo cuando el error lo permita y se haya elegido explícitamente. Corrige primero los errores de validación, autenticación, saldo o permisos. Tras un tiempo de espera al crear una solicitud, comprueba si ya existe una tarea antes de reenviarla.

## Familias de API compatibles

| Familia | Ruta principal |
|---|---|
| Chat y Responses | `/v1/chat/completions`, `/v1/responses` |
| Mensajes nativos Claude | `/v1/messages` |
| Solicitudes nativas Gemini | `/v1beta/models/{model}:generateContent` |
| Imágenes | `/v1/images/generations`, `/v1/images/edits` |
| Video | `/v1/videos/generations` |
| Música | `/v1/music/generations` |
| Worlds | `/v1/worlds/generations` más endpoints de estado world y media asset |
| 3D | `/v1/3d/generations` |
| Audio | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| Realtime | `/v1/realtime?model={model}` |
| Embeddings y rerank | `/v1/embeddings`, `/v1/rerank` |
| Traducción de texto | `/v1/translations` |
