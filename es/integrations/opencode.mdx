## Descripción general

OpenCode es un asistente de programación con AI de código abierto que se ejecuta en tu terminal. Es compatible con múltiples proveedores de LLM y se puede configurar para usar la API de TokenLab para acceder a cientos de modelos.

## Instalación

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

Verifica la instalación:

```bash
opencode --version
```

## Configuración

### Paso 1: Establecer variables de entorno

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

Para una configuración permanente, añade esto a `~/.bashrc` o `~/.zshrc`:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### Paso 2: Configurar OpenCode

La documentación actual de OpenCode recomienda configurar proveedores mediante `opencode.json` o `opencode.jsonc`. Para TokenLab, usa un proveedor personalizado en lugar de sobrecargar el proveedor integrado `openai`:

El ejemplo usa el formato V1 compatible. Combínalo en `~/.config/opencode/opencode.json` conservando proveedores y permisos. V2 lee los ajustes V1 admitidos; no mezcles formatos dentro de un proveedor. Consulta la [migración oficial](https://opencode.ai/v2/docs/migrate-v1/). Comprueba `/models` y después una prueba de pago con el registro TokenLab. Para deshacer, vuelve al modelo anterior y elimina solo esta entrada.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
Usa `@ai-sdk/openai-compatible` para compatibilidad con el estilo de chat-completions. Si específicamente necesitas una ruta de proveedor basada en `/v1/responses`, la documentación de proveedores de OpenCode recomienda cambiar el paquete a `@ai-sdk/openai`.
</Note>

## Uso básico

**Iniciar modo interactivo:**

```bash
opencode
```

**Ejecutar con un prompt:**

```bash
opencode run "Explain this codebase"
```

**Especificar modelo:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## Modelos disponibles

| Modelo | Mejor para |
|-------|----------|
| `gpt-5.6-terra` | Tareas complejas, arquitectura de código |
| `gpt-5.6-luna` | Correcciones rápidas, consultas simples |
| `claude-sonnet-4-6` | Revisión de código, documentación |
| `claude-opus-4-6` | Razonamiento complejo |
| `gemini-3.5-flash` | Respuestas rápidas |

## Comandos comunes

**Analizar código:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**Generar código:**

```bash
opencode run "Create a REST API with Express"
```

**Revisar cambios:**

```bash
git diff | opencode run "Review these changes"
```

**Corregir errores:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## Comandos interactivos

| Command | Descripción |
|---------|-------------|
| `/help` | Mostrar comandos disponibles |
| `/models` | Cambiar a un modelo diferente |
| `/clear` | Borrar el historial de conversación |
| `/exit` | Salir de OpenCode |

## Solución de problemas

<AccordionGroup>
  <Accordion title="Error de conexión">
    - Verifica que `options.baseURL` esté establecido en `https://api.tokenlab.sh/v1`
    - Comprueba la conectividad de red
    - Prueba `curl https://api.tokenlab.sh/v1/models` para verificar
  </Accordion>

  <Accordion title="Autenticación fallida">
    - Verifica que la variable de entorno `TOKENLAB_API_KEY` esté establecida
    - Verifica que `options.apiKey` haga referencia a `{env:TOKENLAB_API_KEY}` u otra fuente de secreto válida
    - Comprueba que la clave comience con `sk-`
    - Asegúrate de que la clave esté activa en el dashboard de TokenLab
  </Accordion>

  <Accordion title="Modelo no encontrado">
    - Comprueba que el nombre del modelo en la configuración coincida exactamente
    - Verifica la disponibilidad del modelo en [tokenlab.sh/en/models](https://tokenlab.sh/es/models)
  </Accordion>
</AccordionGroup>
