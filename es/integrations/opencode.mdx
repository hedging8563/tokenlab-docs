## Descripción general

OpenCode es un asistente de programación con AI de código abierto que se ejecuta en tu terminal. Es compatible con múltiples proveedores de LLM y se puede configurar para usar la API de TokenLab para acceder a cientos de modelos.

## Instalación

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

Verifica la instalación:

```bash
opencode --version
```

## Configuración

### Paso 1: Establecer variables de entorno

Sigue los pasos de terminal de [inicio rápido](/es/quickstart) para macOS, Linux, WSL o Windows PowerShell y define `TOKENLAB_API_KEY` sin dejar la clave en el historial. Inicia OpenCode desde esa terminal. Para uso persistente, utiliza un gestor local de secretos; no añadas la clave en texto plano al perfil del shell.

### Paso 2: Configurar OpenCode

La configuración siguiente se comprobó con **OpenCode 1.18.31**. Otras versiones requieren una verificación propia con su documentación oficial.

Guarda la configuración en un archivo independiente `~/.config/opencode/tokenlab.jsonc`. Si defines `XDG_CONFIG_HOME`, usa `opencode/tokenlab.jsonc` dentro de ese directorio. Conserva los archivos habituales `opencode.json` / `opencode.jsonc`, las cuentas, el modelo predeterminado y los permisos. Este archivo solo se carga en una ejecución que lo seleccione con `OPENCODE_CONFIG`. Si el archivo o el nombre del proveedor ya se usa, elige otro nombre y ajusta los comandos.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
Esta configuración envía Chat Completions mediante `@ai-sdk/openai-compatible`. Consulta los detalles actuales del modelo para comprobar Chat Completions y las herramientas necesarias. El ejemplo no demuestra compatibilidad con otros protocolos o versiones.
</Note>

## Uso básico

Configura la clave siguiendo el inicio rápido, carga el archivo solo para esta ejecución y selecciona el modelo explícitamente. Sustituye las rutas y nombres personalizados. Conserva cualquier configuración previa de `OPENCODE_CONFIG` o `OPENCODE_CONFIG_CONTENT` en un entorno de inicio separado; los ajustes de proyecto o administrados pueden tener prioridad.

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

La lista de modelos comprueba la carga local, no la validez de la clave ni una solicitud real correcta. Un prompt utiliza saldo TokenLab y OpenCode puede enviar solicitudes auxiliares facturadas por separado, como generar un título. Comprueba la respuesta y los [registros correspondientes](https://tokenlab.sh/dashboard/runs?section=requests).

Inicia sin este archivo para usar tu configuración habitual. No guardes `OPENCODE_CONFIG` en el perfil del shell para seguir esta guía. Para deshacer los pasos manuales, elimina solo el archivo independiente que creaste o restaura su copia si ya existía.

| Modelo | Mejor para |
|-------|----------|
| `gpt-5.6-terra` | Tareas complejas, arquitectura de código |
| `gpt-5.6-luna` | Correcciones rápidas, consultas simples |

| `gemini-3.5-flash` | Respuestas rápidas |

## Comandos comunes

**Analizar código:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**Generar código:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**Revisar cambios:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**Corregir errores:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## Comandos interactivos

| Command | Descripción |
|---------|-------------|
| `/help` | Mostrar comandos disponibles |
| `/models` | Cambiar a un modelo diferente |
| `/clear` | Borrar el historial de conversación |
| `/exit` | Salir de OpenCode |

## Solución de problemas

<AccordionGroup>
  <Accordion title="Error de conexión">
    - Verifica que `options.baseURL` esté establecido en `https://api.tokenlab.sh/v1`
    - Comprueba la conectividad de red
    - Prueba `curl https://api.tokenlab.sh/v1/models` para verificar
  </Accordion>

  <Accordion title="Autenticación fallida">
    - Verifica que la variable de entorno `TOKENLAB_API_KEY` esté establecida
    - Verifica que `options.apiKey` haga referencia a `{env:TOKENLAB_API_KEY}` u otra fuente de secreto válida
    - Comprueba que la clave comience con `sk-`
    - Asegúrate de que la clave esté activa en el dashboard de TokenLab
  </Accordion>

  <Accordion title="Modelo no encontrado">
    - Comprueba que el nombre del modelo en la configuración coincida exactamente
    - Verifica la disponibilidad del modelo en [tokenlab.sh/en/models](https://tokenlab.sh/es/models)
  </Accordion>
</AccordionGroup>
