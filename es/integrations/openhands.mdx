## Descripción general

OpenHands puede utilizar TokenLab a través de su configuración de modelos compatible con LiteLLM/OpenAI, especialmente para CLI y flujos de trabajo headless donde tú proporcionas el modelo, la API key y la base URL.

<Note>
**Tipo**: Agente de codificación

**Ruta principal**: Configuración de modelo compatible con OpenAI

**Nivel de soporte**: Ruta de endpoint personalizada soportada
</Note>

## Entorno

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Configuración del modelo

Usa:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

El prefijo `openai/` le indica a la ruta respaldada por LiteLLM que utilice una configuración de proveedor compatible con OpenAI.

## Configuración Headless

Si estás preparando valores predeterminados locales para uso en CLI o headless, ejecuta el flujo de configuración de OpenHands e ingresa:

```bash
make setup-config
```

Cuando se te soliciten los detalles del modelo, utiliza el ID del modelo de TokenLab con el prefijo `openai/` y la base URL `/v1` de TokenLab.

## Sugerencias de modelos

Usa `claude-sonnet-5` o `gpt-5.4` para la planificación de agentes de codificación, `gpt-5.4-mini` para bucles de rutina más rápidos y `deepseek-v4-pro` cuando desees una alternativa sólida de modelo de razonamiento.
