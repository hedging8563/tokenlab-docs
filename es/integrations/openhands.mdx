## Descripción general

Esta página se aplica a la interfaz OpenHands con LiteLLM y **Settings → LLM → Advanced**. Selecciona **OpenAI**, introduce un modelo personalizado con prefijo `openai/`, la clave TokenLab en el campo local y la Base URL siguiente. Anota la selección anterior y restáurala al terminar; conserva cuentas y permisos de herramientas. Consulta la [configuración oficial compatible con OpenAI](https://docs.openhands.dev/openhands/usage/llms/openai-llms). Las ediciones CLI, cloud y desde código fuente pueden tener otros pasos; sigue tu edición instalada. `make setup-config` no es un comando general de la CLI instalada.

## Configuración del modelo

Guarda localmente el proveedor, modelo y conexión actuales antes de editar. Estos controles cambian el modelo activo; restaura los valores anteriores al terminar. Conserva las cuentas iniciadas y los permisos de herramientas. No sobrescribas otra conexión compatible con OpenAI sin una copia recuperable.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

Guardar ajustes o listar modelos no verifica la clave ni una solicitud completada. Un prompt utiliza saldo TokenLab. Comprueba la respuesta y su [registro correspondiente](https://tokenlab.sh/dashboard/runs?section=requests) antes de probar herramientas; las solicitudes auxiliares también pueden facturarse.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
