## Descripción general

Open WebUI admite conexiones API personalizadas compatibles con OpenAI. Agrega TokenLab como un endpoint remoto compatible con OpenAI y actualiza la lista de modelos.

<Note>
**Tipo**: Aplicación de chat web

**Ruta principal**: Completado de chat compatible con OpenAI

**Nivel de soporte**: Ruta de aplicación de chat compatible
</Note>

## Conexión de administrador

1. Abre **Admin Panel** -> **Settings** -> **Connections**.
2. En el área de conexión de OpenAI API, agrega una conexión.
3. Establece la base URL en `https://api.tokenlab.sh/v1`.
4. Establece la API key con tu clave de TokenLab.
5. Guarda la conexión y actualiza los modelos.

## Valores

| Campo | Valor |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Modelo de ejemplo | `gpt-5.4-mini` |

## Modelos recomendados

- `gpt-5.4-mini` para chat general
- `claude-sonnet-5` para escritura y razonamiento
- `deepseek-v4-pro` para chat con uso intensivo de código
- `gemini-3.5-flash` para flujos de trabajo rápidos y compatibles con multimodal

Si la detección de modelos está deshabilitada o almacenada en caché en tu despliegue, agrega los IDs de los modelos manualmente en la configuración de modelos de Open WebUI.
