## Descripción general

Helicone puede actuar como proxy y observar las solicitudes compatibles con OpenAI de TokenLab enrutándolas a través de Helicone Gateway y apuntando a TokenLab.

<Note>
**Tipo**: Gateway de observabilidad

**Ruta principal**: Completado de chat compatible con OpenAI a través de Helicone Gateway

**Nivel de soporte**: Ruta de observabilidad soportada
</Note>

## Entorno

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## Alcance

Esta configuración es para tráfico `/v1` compatible con OpenAI. TokenLab también expone respuestas nativas, mensajes de Anthropic y endpoints compatibles con Gemini; utilice las rutas directas de TokenLab para esos formatos nativos a menos que su proxy de observabilidad los soporte explícitamente.
