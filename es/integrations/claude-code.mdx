## Descripción general

[Claude Code](https://code.claude.com/docs/en/setup) es la herramienta CLI oficial de Anthropic para programación asistida por AI. Puedes configurarla para usar TokenLab como proveedor de API.

## Instalación

Anthropic ahora recomienda el instalador nativo. La instalación con npm todavía existe por compatibilidad, pero está obsoleta en origen.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Si específicamente necesitas el paquete de npm, usa:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
No uses `sudo npm install -g` para Claude Code.
</Warning>

## Configuración

Sigue los pasos de terminal de [inicio rápido](/es/quickstart) para macOS, Linux, WSL o Windows PowerShell y define `TOKENLAB_API_KEY` sin dejar la clave en el historial. Inicia Claude Code desde esa terminal. Para uso persistente, utiliza un gestor local de secretos; no añadas la clave en texto plano al perfil del shell.

Estas variables se aplican solo a este inicio; se conservan la cuenta, el modelo predeterminado y los permisos guardados. Inicia normalmente sin ellas para usar tu configuración anterior. No las guardes en el perfil del shell.

Esta ruta usa Claude Code **2.1.263** y autenticación Bearer mediante `ANTHROPIC_AUTH_TOKEN`. La URL base no lleva `/v1`. Los valores `env` guardados, asistentes de credenciales, opciones de nube o políticas administradas pueden afectar la autenticación; revísalos antes de iniciar. Si hay conflictos, usa el asistente de abajo sin borrar cuentas ni reducir políticas. Comprueba modelo y permisos con `/status`.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Opcionalmente, el [asistente reversible de configuración de Claude Code](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md) permite previsualizar, aplicar y restaurar el archivo original con Python 3.11+. El plugin TokenLab Skills **0.1.2** incluye estos scripts; un Skill independiente también sirve si se actualiza a una versión que los contenga. Para plugins o Skills independientes ya instalados, sigue las [instrucciones de actualización del README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) y comprueba que el script esté presente. La configuración manual de esta página también funciona sin el asistente.

Guardar ajustes o listar modelos no verifica la clave ni una solicitud completada. Un prompt utiliza saldo TokenLab. Comprueba la respuesta y su [registro correspondiente](https://tokenlab.sh/dashboard/runs?section=requests) antes de probar herramientas; las solicitudes auxiliares también pueden facturarse.

## Uso

Después de la configuración, usa Claude Code normalmente:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Verifica la instalación si es necesario:

```bash
claude --version
claude doctor
```

## Modelos disponibles

TokenLab admite todos los modelos Claude:

| Modelo | Descripción |
|-------|-------------|
| `claude-opus-4-6` | El más capaz, razonamiento complejo |
| `claude-sonnet-4-6` | Rendimiento equilibrado, excelente para programación |
| `claude-haiku-4-5` | El más rápido, rentable |

## Selección de modelo

Especifica un modelo con la bandera `--model`:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Pensamiento extendido

Para tareas de razonamiento complejas, usa modelos con pensamiento extendido:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## Solución de problemas

<AccordionGroup>
  <Accordion title="Errores de conexión">
    Verifica que la URL base sea exactamente `https://api.tokenlab.sh` (sin el sufijo `/v1` para solicitudes de estilo Anthropic).
  </Accordion>

  <Accordion title="API key no válida">
    Asegúrate de que tu API key de TokenLab comience con `sk-` y tenga saldo suficiente.
  </Accordion>


  <Accordion title="Modelo no encontrado">
    Comprueba que el nombre del modelo sea correcto. Usa el formato `claude-sonnet-4-6`.
  </Accordion>
</AccordionGroup>
