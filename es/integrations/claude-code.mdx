## Descripción general

[Claude Code](https://code.claude.com/docs/en/setup) es la herramienta CLI oficial de Anthropic para programación asistida por AI. Puedes configurarla para usar TokenLab como proveedor de API.

## Instalación

Anthropic ahora recomienda el instalador nativo. La instalación con npm todavía existe por compatibilidad, pero está obsoleta en origen.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Si específicamente necesitas el paquete de npm, usa:

```bash
npm install -g @anthropic-ai/claude-code
```

<Warning>
No uses `sudo npm install -g` para Claude Code.
</Warning>

## Configuración

### Variables de entorno

Establece las siguientes variables de entorno:

```bash
export ANTHROPIC_API_KEY="sk-your-tokenlab-key"
export ANTHROPIC_BASE_URL="https://api.tokenlab.sh"
```

Agrégalas a tu perfil de shell (`~/.bashrc`, `~/.zshrc`, etc.) para que sean persistentes.

<Note>
Para TokenLab, mantén `ANTHROPIC_BASE_URL` en `https://api.tokenlab.sh` sin el sufijo `/v1`. Esto coincide con la forma del endpoint de estilo Anthropic y el patrón de gateway unificado documentado por Claude Code.
</Note>

### Archivo de configuración

Como alternativa, crea o edita `~/.claude/settings.json`:

Haz una copia y combina los ajustes sin sustituir cuentas o permisos. `ANTHROPIC_API_KEY` envía `X-Api-Key`; `ANTHROPIC_AUTH_TOKEN`, un token Bearer. Elige una vía de autenticación. `/status` muestra modelo y origen de configuración, no el éxito de una solicitud de pago. Tras una prueba corta, compara respuesta y registro TokenLab. Para restaurar, deshaz solo tus ajustes. Consulta la [prioridad](https://code.claude.com/docs/en/settings).

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  }
}
```

## Uso

Después de la configuración, usa Claude Code normalmente:

```bash
# Start an interactive session
claude

# Run a single command
claude "Explain this code" < main.py

```

Verifica la instalación si es necesario:

```bash
claude --version
claude doctor
```

## Modelos disponibles

TokenLab admite todos los modelos Claude:

| Modelo | Descripción |
|-------|-------------|
| `claude-opus-4-6` | El más capaz, razonamiento complejo |
| `claude-sonnet-4-6` | Rendimiento equilibrado, excelente para programación |
| `claude-haiku-4-5` | El más rápido, rentable |

## Selección de modelo

Especifica un modelo con la bandera `--model`:

```bash
claude --model claude-sonnet-4-6 "Review this PR"
```

O establece uno predeterminado en tu configuración:

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  },
  "model": "claude-sonnet-5"
}
```

## Pensamiento extendido

Para tareas de razonamiento complejas, usa modelos con pensamiento extendido:

```bash
claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## Solución de problemas

<AccordionGroup>
  <Accordion title="Errores de conexión">
    Verifica que la URL base sea exactamente `https://api.tokenlab.sh` (sin el sufijo `/v1` para solicitudes de estilo Anthropic).
  </Accordion>

  <Accordion title="API key no válida">
    Asegúrate de que tu API key de TokenLab comience con `sk-` y tenga saldo suficiente.
  </Accordion>

  <Accordion title="El gateway requiere Authorization bearer token">
    El modo gateway de Claude Code también admite `ANTHROPIC_AUTH_TOKEN`. Sigue usando `ANTHROPIC_API_KEY` para la configuración estándar de TokenLab, a menos que hayas cambiado intencionalmente el comportamiento de autenticación de tu gateway.
  </Accordion>

  <Accordion title="Modelo no encontrado">
    Comprueba que el nombre del modelo sea correcto. Usa el formato `claude-sonnet-4-6`.
  </Accordion>
</AccordionGroup>
