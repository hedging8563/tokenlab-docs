## Alcance

Esta guía se aplica al **editor de escritorio Cursor** en macOS, Windows y Linux. El soporte oficial de OpenAI BYOK cubre modelos de chat estándar sin razonamiento; el autocompletado Tab sigue usando modelos de Cursor. Cambiar OpenAI Base URL no habilita todos los modelos de TokenLab ni todas las funciones de Cursor. Consulta los [límites oficiales](https://cursor.com/help/models-and-usage/api-keys).

Si solo necesitas herramientas de imagen, vídeo u otras API, conserva tu proveedor de chat y añade [MCP](/es/integrations/tokenlab-mcp-server). Un [Skill](/es/integrations/coding-agent-skill) aporta instrucciones sin cambiar el modelo principal.

## Tarea para tu agente actual

```text
Lee https://docs.tokenlab.sh/es/integrations/cursor y comprueba mi versión instalada y sistema operativo.
Confirma si necesito TokenLab como modelo principal, herramientas MCP o un Skill API.
Conserva las cuentas, la configuración de proveedores y los permisos; explica cómo restaurar los cambios.
No pidas claves API en el chat. Yo las introduciré localmente y realizaré los pasos necesarios en la interfaz.
Explica el coste de una pequeña petición de verificación. Solo después de que elija expresamente esa prueba, ayúdame a ejecutarla y a cotejar su registro en TokenLab.
```

## Abre la configuración correcta

1. Instala o actualiza el editor desde [Cursor Downloads](https://cursor.com/downloads). Esta guía no configura CLI ni Cloud Agents.
2. Abre **Cursor Settings** desde la paleta de comandos o con `Cmd/Ctrl + Shift + J`. `Cmd/Ctrl + ,` abre los ajustes generales del editor.
3. En **Models**, anota la configuración OpenAI existente para poder restaurarla. Conserva los demás proveedores.
4. Introduce y guarda tu clave TokenLab localmente en **OpenAI API Key**. No la envíes al chat ni la subas a git.
5. Activa **Override OpenAI Base URL** e introduce:

```text
https://api.tokenlab.sh/v1
```

Las peticiones BYOK también pasan por los servidores de Cursor para construir el prompt. El editor no se conecta directamente a TokenLab.

## Elige un modelo

Copia el ID exacto del [catálogo actual de TokenLab](https://tokenlab.sh/es/models) y comprueba que Cursor lo admite por OpenAI BYOK. La categoría chat de TokenLab no demuestra esa compatibilidad.

Para la primera prueba de texto, `gpt-4.1-mini` sirve como ejemplo sin razonamiento si sigue disponible. Activa su entrada en **Models**, o usa **Add model** si falta, y selecciónala en el chat. No dupliques modelos integrados con otra escritura ni supongas que Claude o Gemini usan el override de OpenAI. Consulta la [explicación de Cursor](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488).

## Verifica una petición pequeña

Crea un chat nuevo con el modelo elegido y envía:

```text
Responde solo con TOKENLAB_CONNECTION_OK. No uses herramientas ni modifiques archivos.
```

Esta petición tiene coste. Comprueba la respuesta y el modelo, la hora y el estado en las [peticiones de TokenLab](https://tokenlab.sh/dashboard/runs?section=requests). Ver un modelo o recibir una respuesta sin su registro correspondiente no confirma esta ruta.

## Si algo falla

- **Modelo ausente o rechazado:** comprueba el ID y los límites BYOK; usa la entrada integrada si existe. Reiniciar no resuelve la incompatibilidad.
- **Error de autenticación:** revisa la clave TokenLab en el campo OpenAI y la Base URL. Un error de saldo o cuota es distinto de una clave inválida.
- **Sin registro en TokenLab:** revisa el modelo del chat, el override y el error de Cursor. Tab no verifica esta conexión.
- **Otro proveedor deja de funcionar:** restaura la configuración OpenAI anterior o desactiva el override y abre otro chat.

## Añade MCP y Skills por separado

[MCP](/es/integrations/tokenlab-mcp-server) añade herramientas mediante la configuración MCP de Cursor o `.cursor/mcp.json`. Comprueba primero su descubrimiento y ejecuta después solo las generaciones de pago que necesites. MCP no sustituye el modelo principal.

Los [Skills](/es/integrations/coding-agent-skill) proporcionan instrucciones API. Coloca la carpeta completa con `SKILL.md` y sus referencias en `.cursor/skills/tokenlab-api-integration/` y comprueba **Customize → Skills**. Un Skill no aporta una clave ni instala un servidor MCP. Consulta las guías oficiales de [MCP](https://cursor.com/docs/mcp) y [Skills](https://cursor.com/docs/skills) para tu versión.
