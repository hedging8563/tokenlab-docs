## Descripción general

<Note>
**Tipo**: agente de programación para IDE y CLI

**Ruta principal**: Chat Completions compatible con OpenAI

**Compatibilidad**: ruta oficial de proveedor personalizado
</Note>

[Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible) admite proveedores compatibles con OpenAI en la extensión de VS Code y la CLI.

## Instalación e interfaz

Instala el canal preliminar de **Kilo Code** en VS Code o la CLI:

```bash
npm install -g @kilocode/cli
kilo --version
```

Abre **Settings → Providers → Custom provider**.

| Campo | Valor |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | Tu clave API de TokenLab |
| Model | `kimi-k3` |

Kilo detecta modelos mediante `/v1/models`. Tras guardar, elige `tokenlab/kimi-k3`.

## Configuración de CLI

Guarda la clave en una variable de entorno y edita el archivo global de confianza `~/.config/kilo/kilo.jsonc`:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

Reinicia Kilo y ejecuta `kilo models`. `{env:...}` solo se resuelve en configuración global o administrada de confianza. No escribas la clave real en una configuración de proyecto que pueda llegar a Git.
