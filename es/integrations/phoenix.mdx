## Descripción general

Phoenix puede rastrear solicitudes de TokenLab mediante la auto-instrumentación del cliente de Python de OpenAI configurado con la URL base compatible con OpenAI de TokenLab.

## Instalación

```bash
pip install arize-phoenix openinference-instrumentation-openai openai
```

## Entorno

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Registrar Phoenix

Antes de ejecutar este ejemplo, inicia Phoenix localmente o usa un despliegue existente. De forma predeterminada, `register()` envía las trazas al collector OTLP/gRPC local en `http://localhost:4317`. Para otro despliegue, configura el endpoint del collector y la autenticación siguiendo la [guía de Phoenix](https://arize.com/docs/phoenix/sdk-api-reference/python/arize-phoenix-otel). Instalar el SDK no inicia el collector.

```python
from phoenix.otel import register

tracer_provider = register(
    project_name="tokenlab-app",
    auto_instrument=True,
)
```

## Llamar a TokenLab

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Write a short haiku."}],
)

print(response.choices[0].message.content)
```

## Notas sobre los endpoints

Phoenix rastrea la ruta de llamada del SDK de OpenAI. Utilice esta página para las llamadas a TokenLab de tipo Chat Completions. Otros endpoints nativos de TokenLab aún pueden rastrearse si la instrumentación de su aplicación captura el cliente que utiliza para esas solicitudes.
