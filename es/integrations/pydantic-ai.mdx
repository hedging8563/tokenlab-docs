## Descripción general

Pydantic AI puede utilizar TokenLab con `OpenAIChatModel` y `OpenAIProvider(base_url=...)`.

<Note>
**Tipo**: Framework de agentes

**Ruta principal**: Completado de chat compatible con OpenAI

**Nivel de soporte**: Ruta de proveedor compatible con OpenAI soportada
</Note>

## Entorno

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Agente básico

```python
import os

from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "claude-sonnet-5",
    provider=OpenAIProvider(
        base_url="https://api.tokenlab.sh/v1",
        api_key=os.environ["TOKENLAB_API_KEY"],
    ),
)

agent = Agent(model)
result = agent.run_sync("Explain one benefit of OpenAI-compatible gateways.")
print(result.output)
```

## Herramientas

```python
from pydantic_ai import Agent, RunContext

agent = Agent(model)

@agent.tool
def lookup_status(ctx: RunContext[None], service: str) -> str:
    return f"{service} is online"

result = agent.run_sync("Check the TokenLab status.")
print(result.output)
```

## Notas sobre el endpoint

Esta ruta apunta a la clase de modelo de Completado de Chat de OpenAI de Pydantic AI. Para un comportamiento de protocolo nativo de Responses o nativo del proveedor, elija una ruta de cliente que exponga ese protocolo directamente.
