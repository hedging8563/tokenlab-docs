## Dejar que mi agente lo configure

Copia esta tarea en un agente que ya funcione en tu ordenador:

```text
Lee esta guía y ayúdame a conectar Pi con TokenLab:
https://docs.tokenlab.sh/es/integrations/pi-coding-agent
Comprueba primero mi versión instalada y la configuración activa.
Conserva las cuentas, los proveedores, los permisos y los demás ajustes existentes.
Haz una copia de seguridad de los archivos locales y muestra los cambios propuestos.
Las claves API necesarias las introduciré localmente; nunca las pidas, muestres ni pegues en el chat.
Comprueba primero que la configuración se carga correctamente.
Explica por separado el coste de cualquier prueba con peticiones de pago antes de ejecutarla.
```

## Instalar y configurar Pi

Sigue la [instalación oficial](https://pi.dev/). El paquete npm es `@earendil-works/pi-coding-agent`. Windows usa Git Bash por defecto; consulta la [configuración del shell](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md). Omite la instalación si ya tienes Pi.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.85.1
pi --version
```

La configuración siguiente se comprobó con **Pi 0.85.1**. Otras versiones requieren una verificación propia con su documentación oficial.

Haz una copia de `~/.pi/agent/models.json` y añade `tokenlab` después de las entradas existentes de `providers`; crea el archivo solo si no existe. Un `PI_CODING_AGENT_DIR` no vacío selecciona el directorio de `models.json`. Conserva el orden de proveedores, `settings.json`, las cuentas, los campos de modelo predeterminado y los permisos. Si `tokenlab` ya existe en la configuración o las cuentas guardadas, usa otro nombre y cambia el comando de inicio. Define `TOKENLAB_API_KEY` localmente con el [inicio rápido](/es/quickstart) para macOS, Linux, WSL o Windows PowerShell; nunca en el chat.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

El `$` de `"$TOKENLAB_API_KEY"` es obligatorio; sin él se usa una cadena literal. Elige un modelo actual con Chat Completions y herramientas. Sus detalles determinan los límites y las opciones de imágenes y razonamiento.

Opcionalmente, el [asistente reversible de configuración de Pi](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/pi_setup.md) permite previsualizar, aplicar y restaurar el archivo original con Python 3.11+. El plugin TokenLab Skills **0.1.2** incluye estos scripts; un Skill independiente también sirve si se actualiza a una versión que los contenga. Para plugins o Skills independientes ya instalados, sigue las [instrucciones de actualización del README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) y comprueba que el script esté presente. La configuración manual de esta página también funciona sin el asistente.

## Comprobar y restaurar

Comprueba la carga desde el mismo terminal y directorio del agente; después selecciona TokenLab explícitamente para esta sesión. Sin `TOKENLAB_API_KEY`, el proveedor puede no aparecer. La lista confirma registro y presencia de credenciales, no su validez ni una llamada API completada.

```bash
pi --list-models tokenlab
pi --provider tokenlab --model gpt-5.6-luna
```

Un prompt utiliza saldo TokenLab. Comprueba la respuesta y su [registro](https://tokenlab.sh/dashboard/runs?section=requests) antes de probar herramientas. Para deshacer la configuración manual, elimina solo la entrada que añadiste y conserva los demás ajustes y cuentas.

## Skills y MCP

Pi admite [Skills de forma nativa](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). Instala el [Skill TokenLab](/es/integrations/coding-agent-skill). MCP requiere una extensión aparte; no pongas su configuración en `models.json`.
