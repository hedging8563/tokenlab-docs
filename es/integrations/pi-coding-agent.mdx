## Instalar y configurar Pi

Sigue la [instalación oficial](https://pi.dev/). El paquete npm es `@earendil-works/pi-coding-agent`. Windows usa Git Bash por defecto; consulta la [configuración del shell](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md). Omite la instalación si ya tienes Pi.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi --version
```

Combina estas entradas en `~/.pi/agent/models.json` o en el directorio `PI_CODING_AGENT_DIR`. Haz una copia y conserva otros proveedores. Define `TOKENLAB_API_KEY` localmente en el entorno de inicio, nunca en el chat. Una variable Base URL sola no crea el proveedor.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

El `$` de `"$TOKENLAB_API_KEY"` es obligatorio; sin él se usa una cadena literal. Elige un modelo actual con Chat Completions y herramientas. Sus detalles determinan los límites y las opciones de imágenes y razonamiento.

## Comprobar y restaurar

Ejecuta `pi --list-models` y selecciona `tokenlab/gpt-5.6-luna` en `/model`. El selector recarga `models.json`. Solo comprueba el registro y la presencia de credenciales, no su validez ni una llamada correcta.

Una solicitud de texto utiliza saldo TokenLab. Comprueba la respuesta y su [registro](https://tokenlab.sh/dashboard/runs?section=requests) antes de probar herramientas. Para restaurar, selecciona el proveedor anterior y elimina solo la entrada TokenLab añadida.

## Skills y MCP

Pi admite [Skills de forma nativa](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). Instala el [Skill TokenLab](/es/integrations/coding-agent-skill). MCP requiere una extensión aparte; no pongas su configuración en `models.json`.
