## Descripción general

Cherry Studio puede utilizar TokenLab a través de un proveedor personalizado compatible con OpenAI. Si tu versión de Cherry Studio incluye TokenLab en el registro de proveedores, selecciona TokenLab directamente.

<Note>
**Tipo**: Aplicación de chat

**Ruta principal**: Chat completions compatibles con OpenAI

**Rutas nativas**: Responses, Anthropic Messages, endpoints compatibles con Gemini cuando son expuestos por el cliente
</Note>

## Configurar como proveedor personalizado

1. Abre **Settings** -> **Model Provider**
2. Añade un proveedor compatible con OpenAI
3. Introduce:
   - **Name**: TokenLab
   - **API Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Añade un modelo como `gpt-5.4-mini`
5. Guarda y prueba el proveedor.

## Ruta del registro de proveedores

Cuando TokenLab aparezca como un proveedor integrado en Cherry Studio, prefiere esa opción. Puede incluir metadatos de endpoint para:

- Chat completions compatibles con OpenAI
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## Buenos modelos para empezar

Utiliza `gpt-5.4-mini` como modelo predeterminado, luego añade `claude-sonnet-5`, `gemini-3.5-flash` y `deepseek-v4-flash` para una mayor cobertura.
