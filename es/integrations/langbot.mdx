## Descripción general

LangBot puede llamar a TokenLab a través de un solicitante de LLM compatible con OpenAI.

<Note>
**Tipo**: Plataforma de bots

**Ruta principal**: Completado de chat compatible con OpenAI

**Nivel de soporte**: Soportado con límites de alcance
</Note>

## Solicitante de TokenLab

Si tu compilación de LangBot incluye un solicitante de **TokenLab**:

1. Abre la configuración del proveedor de modelos de LangBot.
2. Agrega un proveedor con el solicitante **TokenLab**.
3. Establece la API key con tu clave de TokenLab.
4. Selecciona o crea un modelo como `gpt-5.4-mini`.
5. Adjunta el modelo a la canalización o bot que deba utilizarlo.

## Alternativa compatible con OpenAI

Si TokenLab aún no aparece en la lista, utiliza el solicitante compatible con OpenAI:

| Campo | Valor |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Modelos recomendados

- `gpt-5.4-mini` para la mayoría de las interacciones de bots
- `claude-sonnet-5` para escritura y razonamiento más extensos
- `deepseek-v4-flash` para bucles rápidos de codificación y razonamiento
- `gemini-3.5-flash` para flujos de trabajo generales rápidos
