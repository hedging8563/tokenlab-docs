## Descripción general

Chatbox puede utilizar TokenLab a través de sus ajustes de API compatibles con OpenAI.

<Note>
**Tipo**: Aplicación de chat

**Ruta principal**: Completado de chat compatible con OpenAI

**Nivel de soporte**: Ruta soportada
</Note>

## Configurar Chatbox

1. Abre **Settings** -> **AI Model**
2. Elige **OpenAI API Compatible**
3. Introduce:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. Guarda y envía un mensaje de prueba corto.

## Modelos recomendados

| Caso de uso | Modelo |
|----------|-------|
| Chat cotidiano | `gpt-5.4-mini` |
| Razonamiento más avanzado | `gpt-5.4` o `gpt-5.5` |
| Salida estilo Claude | `claude-sonnet-5` |
| Alternativa rápida | `deepseek-v4-flash` |

## Notas

Si tu versión de Chatbox ya incluye a TokenLab como proveedor integrado, selecciónalo directamente. Si no, la ruta de proveedor compatible con OpenAI descrita anteriormente es la alternativa más segura.
