## Descripción general

Flowise puede llamar a TokenLab a través de un nodo de chat de TokenLab cuando esté disponible, o mediante un nodo de modelo de chat compatible con OpenAI apuntando a TokenLab.

## Nodo de TokenLab

Si tu compilación de Flowise incluye un nodo de modelo de chat de **TokenLab**:

1. Agrega **Chat Models** -> **TokenLab**
2. Crea una credencial de API de TokenLab
3. Establece **Model Name** en `gpt-5.4-mini`
4. Conéctalo a tu cadena, agente o flujo de trabajo
5. Ejecuta un prompt de prueba.

## Alternativa compatible con OpenAI

Si tu versión no incluye un nodo TokenLab, añade **Chat Models** → **OpenAI Custom Model**. En **Connect Credential**, crea una credencial **OpenAI API** con tu clave TokenLab. Configura **Model Name** y **Additional Parameters** → **Base Path** así:

| Campo | Valor |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

Conecta el nodo a tu cadena, agente o flujo de trabajo y envía un prompt de prueba.

## Modelos recomendados

- `gpt-5.4-mini` para la mayoría de las pruebas de flujo de trabajo
- `claude-sonnet-5` para una mejor redacción y razonamiento
- `gemini-3.5-flash` para flujos de trabajo rápidos compatibles con capacidades multimodales
- `deepseek-v4-flash` para iteraciones rápidas de código o razonamiento
