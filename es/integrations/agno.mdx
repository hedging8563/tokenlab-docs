## Descripción general

Agno puede utilizar TokenLab como un proveedor de modelos compatible con OpenAI para agentes y flujos de trabajo.

<Note>
**Tipo**: Marco de trabajo de agentes (Agent Framework)

**Ruta principal**: Completado de chat compatible con OpenAI

**Nivel de soporte**: Ruta soportada
</Note>

## Entorno

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Wrapper de modelos de TokenLab

Si tu versión de Agno incluye el wrapper de modelos de TokenLab:

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

Algunas compilaciones de Agno también admiten cadenas de modelos:

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## Alternativa compatible con OpenAI

Si tu versión aún no incluye TokenLab, utiliza la ruta de modelos compatible con OpenAI de Agno con:

- URL base: `https://api.tokenlab.sh/v1`
- API key: `TOKENLAB_API_KEY`
- Modelo: `gpt-5.4-mini`

## Sugerencias de modelos

Utiliza `gpt-5.4-mini` para agentes predeterminados, `gpt-5.4` o `claude-sonnet-5` para un razonamiento más profundo, y `deepseek-v4-flash` para bucles más rápidos.
