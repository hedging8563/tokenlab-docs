## Descripción general

VoltAgent acepta modelos de lenguaje de AI SDK directamente. Configura un proveedor de AI SDK compatible con OpenAI con la URL base `/v1` de TokenLab y pasa el modelo seleccionado a tu agente.

<Note>
**Tipo**: Framework de agentes en TypeScript

**Ruta principal**: Chat Completions compatibles con OpenAI a través de AI SDK

**Nivel de soporte**: Ruta compatible con OpenAI soportada
</Note>

## Entorno

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Proveedor directo de AI SDK

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab("claude-sonnet-5"),
});
```

## Ruta del Router de modelos

Si tu snapshot del registro de VoltAgent incluye una entrada de proveedor de TokenLab desde `models.dev`, configura:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

Luego, utiliza la cadena del modelo del registro, por ejemplo `tokenlab/claude-sonnet-5`.

## Notas sobre los endpoints

La ruta directa de AI SDK es la configuración más explícita. Utiliza las respuestas nativas de TokenLab, los mensajes de Anthropic o los endpoints de Gemini solo cuando tu proveedor/cliente de AI SDK seleccionado esté configurado para ese protocolo.
