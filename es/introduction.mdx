## ¿Qué es TokenLab?

TokenLab conecta tu aplicación o herramienta de programación con modelos de IA mediante una clave API y un saldo compartido. Elige un modelo y un formato API compatible; las solicitudes se cobran al precio publicado.

## Capacidades compatibles

Consulta el [catálogo de modelos](https://tokenlab.sh/es/models) para conocer los ID, la disponibilidad, los formatos y los precios actuales.

| Capacidad | Descripción |
|---|---|
| Chat y razonamiento | Generación de texto, planificación, herramientas |
| Visión y multimodal | Comprensión de imágenes y chat multimodal |
| Generación y edición de imágenes | Texto a imagen y edición de imágenes |
| Generación de video | Texto/imagen/referencia a video y control de movimiento |
| Audio y Realtime WebSocket | TTS, transcripción, traducción de audio y sesiones WebSocket en tiempo real |
| Embeddings y rerank | Vectorización de texto y reordenamiento |
| Traducción | Traducción de texto y traducción de voz por WebSocket |
| Música y 3D | Generación de música y assets 3D |
| Worlds | Generación de worlds, polling de estado y media assets |
