## 概要

ほとんどの汎用AIチャットアプリは、標準的なOpenAI互換のチャットパスを通じてTokenLabに接続します。

具体的には以下の通りです：
- アプリが完全なエンドポイントURLを明示的に要求しない限り、ベースURLとして `https://api.tokenlab.sh/v1` を使用してください
- OpenAI形式のAPIキーとして、TokenLabのAPIキーを使用してください
- アプリの標準的なチャットワークフローで使用可能なモデルを選択してください

<Note>
一般的なチャットアプリは通常 **chat-completions（チャット補完）向け**であり、Codex Responses WebSocketクライアントではありません。Codex CLI/App、Cursor、またはResponses固有の動作を必要とするその他のコーディングツールについては、専用の統合ガイドを参照してください。
</Note>

<Note>
**タイプ**: チャットアプリ

**主要パス**: OpenAI互換 chat-completions

**サポート状況**: サポート対象
</Note>

## サポートされているアプリケーション

| アプリケーション | プラットフォーム | 備考 |
|-------------|----------|-------|
| Open WebUI | Web, セルフホスト | OpenAI互換接続を備えた人気のセルフホスト型選択肢 |
| LibreChat | Web, セルフホスト | カスタムOpenAIエンドポイントを備えたマルチプロバイダーチャットワークスペース |
| LobeChat | Web, デスクトップ, セルフホスト | 強力なカスタムプロバイダーサポート |
| Cherry Studio | Windows, macOS, Linux | 優れたOpenAI互換プロバイダーフロー |
| Chatbox | Windows, macOS, Linux | シンプルなOpenAI互換セットアップ |
| DeepChat | Windows, macOS, Linux | OpenAI互換プロバイダー設定を備えたデスクトップクライアント |
| Jan | デスクトップ, セルフホスト | リモートOpenAI互換プロバイダーに対応したローカルファーストアプリ |
| TypingMind | Web, デスクトップ | カスタムエンドポイント形式を使用 |
| NextChat | Web, セルフホスト | ベースURLの上書きが可能な軽量ChatGPTスタイルクライアント |
| ChatWise | Windows, macOS | 標準的なカスタムプロバイダーパターン |

## デフォルトの接続値

| フィールド | 値 |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| API タイプ | OpenAI 互換 |

アプリがベースURLではなく**完全なエンドポイントURL**を要求する場合は、以下を使用してください：
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## アプリ設定例

<Tabs>
  <Tab title="LobeChat">
    **セルフホスト版 LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. **Settings** → **AI Service Provider** を開く
    2. **OpenAI** を選択
    3. TokenLab APIキーを入力
    4. カスタムエンドポイントに `https://api.tokenlab.sh/v1` を設定
  </Tab>

  <Tab title="Cherry Studio">
    1. **Settings** → **Model Provider** を開く
    2. **OpenAI-compatible** プロバイダーを追加
    3. 以下を入力：
       - **Name**: TokenLab
       - **API Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. 使用したいモデルを追加
  </Tab>

  <Tab title="Chatbox">
    1. **Settings** → **AI Model** を開く
    2. **OpenAI API Compatible** を選択
    3. 以下を入力：
       - **API Host**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini` または `claude-sonnet-5`
  </Tab>

  <Tab title="TypingMind">
    1. **Settings** を開く
    2. **Custom Endpoint** を選択
    3. 以下を入力：
       - **Endpoint URL**: `https://api.tokenlab.sh/v1/chat/completions`
       - **API Key**: `sk-your-tokenlab-key`
    4. 使用したいモデルを設定
  </Tab>

  <Tab title="Open WebUI">
    1. **Admin Settings** → **Connections** を開く
    2. **OpenAI-compatible** 接続を追加
    3. 以下を入力：
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. 保存し、使用したいモデルを選択
  </Tab>

  <Tab title="DeepChat">
    1. **Settings** -> **Model Provider** を開く
    2. OpenAI互換プロバイダーを追加
    3. 以下を入力：
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini`
    4. 保存してテストチャットを実行
  </Tab>

  <Tab title="Jan">
    1. **Settings** -> **Providers** を開く
    2. リモートのOpenAI互換プロバイダーを追加
    3. 以下を入力：
       - **Provider name**: TokenLab
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. `gpt-5.4-mini` またはその他のTokenLabモデルを選択
  </Tab>

  <Tab title="LibreChat">
    LibreChatのプロバイダー設定にOpenAI互換エンドポイントを追加し、以下のように指定します：

    ```yaml
    customEndpoints:
      - name: TokenLab
        apiKey: '${OPENAI_API_KEY}'
        baseURL: 'https://api.tokenlab.sh/v1'
        models:
          default: ['gpt-5.4-mini', 'gpt-5.4', 'claude-sonnet-5']
          fetch: false
    ```
  </Tab>
</Tabs>

## 推奨モデルのデフォルト設定

| カテゴリ | 推奨モデル |
|----------|------------------|
| 一般的なデフォルト | `gpt-5.4-mini`, `gpt-5.4`, `gpt-5.5` |
| Anthropic | `claude-sonnet-5`, `claude-opus-4-8`, `claude-fable-5` |
| Google | `gemini-3.5-flash`, `gemini-3.1-flash-lite` |
| DeepSeek | `deepseek-v4-flash`, `deepseek-v4-pro` |

## ヒント

<AccordionGroup>
  <Accordion title="アプリが対応している場合はベースURLを優先する">
    ほとんどのアプリでは、完全なエンドポイントURLではなくベースURLとして `https://api.tokenlab.sh/v1` を指定する方が、設定が簡単で安定します。
  </Accordion>

  <Accordion title="まずは軽量なモデルから使用する">
    日常的なチャットには `gpt-5.4-mini` や `deepseek-v4-flash` から始め、より高度な推論タスクが必要な場合に `gpt-5.4` や `claude-opus-4-8` に切り替えてください。
  </Accordion>

  <Accordion title="コーディングツールは分けて管理する">
    汎用チャットアプリとコーディングエージェントでは、必要なエンドポイントの動作が異なることがよくあります。Codex/Cursorスタイルのツールは、専用の統合ページの設定に従ってください。
  </Accordion>
</AccordionGroup>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - ベースURLが正確に `https://api.tokenlab.sh/v1` であることを確認してください
    - アプリがパスを自動的に付加する場合は、末尾のスラッシュを削除してください
    - アプリが完全なエンドポイントURLを要求する場合は、`https://api.tokenlab.sh/v1/chat/completions` を使用してください
  </Accordion>

  <Accordion title="401 Unauthorized（認証エラー）">
    - APIキーを再確認してください
    - TokenLabダッシュボードでキーが有効であることを確認してください
    - 余分なスペースや改行が含まれていないことを確認してください
  </Accordion>

  <Accordion title="モデルが利用できない">
    - モデル名を正確に確認してください
    - `gpt-5.4-mini`、`deepseek-v4-flash`、`claude-sonnet-5` など、広くサポートされているデフォルトモデルを試してください
    - TokenLabのドキュメントまたはダッシュボードで現在の可用性を確認してください
  </Accordion>
</AccordionGroup>
