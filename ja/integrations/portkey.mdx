## 概要

Portkey Gatewayは、アップストリームプロバイダーとしてTokenLabにリクエストをルーティングできます。最も安全なデフォルト設定はOpenAI互換のチャット補完（chat completions）です。お使いのPortkeyのバージョンでTokenLab向けのパスが公開されている場合は、Responsesを使用してください。

<Note>
**タイプ**: AI Gateway

**主要パス**: OpenAI互換のチャット補完およびResponses

**サポート状況**: サポート済みパス
</Note>

## プロバイダー値

| フィールド | 値 |
|-------|-------|
| Provider | `tokenlab` |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | `sk-your-tokenlab-key` |
| デフォルトモデル | `gpt-5.4-mini` |

## チャット補完 (Chat Completions)

OpenAI互換のチャットリクエストにTokenLabを使用します：

```bash
curl https://your-portkey-gateway.example/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-portkey-provider: tokenlab" \
  -H "Authorization: Bearer sk-your-tokenlab-key" \
  -d '{
    "model": "gpt-5.4-mini",
    "messages": [{"role": "user", "content": "Say hello from TokenLab."}]
  }'
```

## Responses

お使いのPortkeyビルドがTokenLabのResponsesをルーティングしている場合は、`/v1/responses` に対して `gpt-5.5`、`gpt-5.4`、または `gpt-5.4-mini` を使用してください。

## ネイティブエンドポイントに関する注意

TokenLabは、Anthropic MessagesおよびGemini互換のエンドポイントも直接公開しています。これらをPortkey経由で使用できるかどうかは、デプロイされているバージョンにおけるPortkeyのプロバイダーおよびエンドポイントのサポート状況に依存します。
