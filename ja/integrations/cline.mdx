## 概要

[Cline](https://docs.cline.bot/provider-config/openai-compatible) は IDE 設定から OpenAI 互換プロバイダーを追加できます。

## TokenLab の設定

変更前に、現在のプロバイダー、モデル、接続設定をローカルに保存してください。これらの設定はアクティブなモデルを変更するため、使用後は元の値に戻します。ログイン済みアカウントとツール権限は変更しません。復元可能なバックアップなしに既存の OpenAI 互換接続を上書きしないでください。

1. エディターの拡張機能マーケットから **Cline** をインストールします。
2. Cline パネルの歯車を開き、**API Provider** で **OpenAI Compatible** を選びます。
3. 次の値を入力します。

| フィールド | 値 |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key |
| Model ID | `kimi-k3` |

4. **Verify** をクリックします。

検証後は、ファイルを変更せずワークスペースを説明する読み取り専用タスクから始めます。404 の場合は Base URL が `/v1` で終わり、`/chat/completions` を含まないことを確認してください。モデル ID は `kimi-k3` です。

設定の保存やモデル一覧だけでは、キーの有効性やリクエストの完了は確認できません。プロンプト送信には TokenLab 残高を使います。応答と対応する[リクエスト記録](https://tokenlab.sh/dashboard/runs?section=requests)を照合してからツールを試してください。補助リクエストにも料金が発生する場合があります。
