## 概要

<Note>
**種類**: IDE コーディングエージェント

**主要パス**: OpenAI 互換 Chat Completions

**サポート**: 公式プロバイダーパス
</Note>

[Cline](https://docs.cline.bot/provider-config/openai-compatible) は IDE 設定から OpenAI 互換プロバイダーを追加できます。

## TokenLab の設定

1. エディターの拡張機能マーケットから **Cline** をインストールします。
2. Cline パネルの歯車を開き、**API Provider** で **OpenAI Compatible** を選びます。
3. 次の値を入力します。

| フィールド | 値 |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key |
| Model ID | `kimi-k3` |

4. **Verify** をクリックします。

任意の詳細設定では、入力上限を `1048576`、最大出力を `131072` にし、画像とツール / Computer Use を有効にできます。

検証後は、ファイルを変更せずワークスペースを説明する読み取り専用タスクから始めます。404 の場合は Base URL が `/v1` で終わり、`/chat/completions` を含まないことを確認してください。モデル ID は `kimi-k3` です。
