## 概要

CrewAIは、環境変数または `LLM` クラスでモデル、APIキー、ベースURLを設定することにより、OpenAI互換のLLMをサポートしています。

<Note>
**タイプ**: エージェントフレームワーク

**主要なパス**: OpenAI互換のチャット補完 (Chat Completions)

**サポートの信頼性**: カスタムエンドポイントパスをサポート
</Note>

## 環境変数

```python
import os

os.environ["OPENAI_API_KEY"] = "sk-your-tokenlab-key"
os.environ["OPENAI_API_BASE"] = "https://api.tokenlab.sh/v1"
os.environ["OPENAI_MODEL_NAME"] = "openai/claude-sonnet-5"
```

## LLMクラス

```python
from crewai import Agent, LLM

llm = LLM(
    model="claude-sonnet-5",
    custom_openai=True,
    base_url="https://api.tokenlab.sh/v1",
    api_key="sk-your-tokenlab-key",
)

agent = Agent(
    role="Research analyst",
    goal="Summarize technical tradeoffs clearly",
    backstory="You produce concise implementation notes.",
    llm=llm,
)
```

## モデルの推奨事項

日常的なクルーには `gpt-5.4-mini` を、計画重視のエージェントには `claude-sonnet-5` または `gpt-5.4` を、高速で低コストな反復作業には `deepseek-v4-flash` を使用してください。

## エンドポイントに関する注意点

CrewAIのOpenAI互換パスは、Chat Completions形式のエージェント呼び出しに最適です。選択したツールやSDKがネイティブプロトコルに対応している場合にのみ、TokenLabのネイティブエンドポイントを直接使用してください。
