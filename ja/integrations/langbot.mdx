## 概要

LangBotは、OpenAI互換のLLMリクエスターを通じてTokenLabを呼び出すことができます。

<Note>
**タイプ**: ボットプラットフォーム

**主要パス**: OpenAI互換のチャット補完

**サポート信頼度**: スコープ制限付きでサポート
</Note>

## TokenLabリクエスター

LangBotのビルドに **TokenLab** リクエスターが含まれている場合：

1. LangBotのモデルプロバイダー設定を開きます。
2. リクエスターとして **TokenLab** を持つプロバイダーを追加します。
3. APIキーにTokenLabキーを設定します。
4. `gpt-5.4-mini` などのモデルを選択または作成します。
5. そのモデルを使用するパイプラインまたはボットにモデルをアタッチします。

## OpenAI互換フォールバック

TokenLabがまだリストにない場合は、OpenAI互換リクエスターを使用してください：

| フィールド | 値 |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## 推奨モデル

- `gpt-5.4-mini`: ほとんどのボットインタラクション向け
- `claude-sonnet-5`: 長文の作成や推論向け
- `deepseek-v4-flash`: 高速なコーディングおよび推論ループ向け
- `gemini-3.5-flash`: 高速な汎用ワークフロー向け
