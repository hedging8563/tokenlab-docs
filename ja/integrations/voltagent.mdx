## 概要

VoltAgentは、AI SDKの言語モデルを直接受け入れることができます。OpenAI互換のAI SDKプロバイダーをTokenLabの `/v1` ベースURLで構成し、選択したモデルをエージェントに渡してください。

<Note>
**タイプ**: TypeScriptエージェントフレームワーク

**主要なパス**: AI SDKを通じたOpenAI互換のChat Completions

**サポートの信頼性**: サポートされているOpenAI互換パス
</Note>

## インストール

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## 環境設定

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 直接的なAI SDKプロバイダー

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## モデルルーターパス

VoltAgentレジストリスナップショットに `models.dev` からのTokenLabプロバイダーエントリが含まれている場合は、以下のように構成します。

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

その後、`tokenlab/claude-sonnet-5` のようにレジストリモデル文字列を使用します。

## エンドポイントに関する注意点

直接的なAI SDKパスが最も明示的なセットアップ方法です。TokenLabネイティブのResponses、Anthropic Messages、またはGeminiエンドポイントは、選択したAI SDKプロバイダー/クライアントがそのプロトコル用に構成されている場合にのみ使用してください。
