## 概要

Open WebUIは、カスタムのOpenAI互換API接続をサポートしています。TokenLabをリモートのOpenAI互換エンドポイントとして追加し、モデルリストを更新してください。

<Note>
**タイプ**: Webチャットアプリ

**主要パス**: OpenAI互換チャット補完

**サポート信頼度**: サポートされているチャットアプリパス
</Note>

## 管理者接続

1. **Admin Panel** -> **Settings** -> **Connections** を開きます。
2. OpenAI API接続エリアで、接続を追加します。
3. ベースURLに `https://api.tokenlab.sh/v1` を設定します。
4. APIキーにTokenLabキーを設定します。
5. 接続を保存し、モデルを更新します。

## 値

| フィールド | 値 |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| 例となるモデル | `gpt-5.4-mini` |

## 推奨モデル

- `gpt-5.4-mini` (一般的なチャット用)
- `claude-sonnet-5` (ライティングおよび推論用)
- `deepseek-v4-pro` (コード中心のチャット用)
- `gemini-3.5-flash` (高速なマルチモーダル対応ワークフロー用)

デプロイメントでモデルの自動検出が無効になっている場合やキャッシュされている場合は、Open WebUIのモデル設定でモデルIDを手動で追加してください。
