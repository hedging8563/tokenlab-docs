## 概要

Agno は、エージェントやワークフロー向けの OpenAI 互換モデルプロバイダーとして TokenLab を使用できます。

<Note>
**タイプ**: エージェントフレームワーク

**主要なパス**: OpenAI 互換のチャット補完

**サポートの信頼度**: サポート対象
</Note>

## 環境設定

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## TokenLab モデルラッパー

お使いの Agno バージョンに TokenLab モデルラッパーが含まれている場合:

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

一部の Agno ビルドでは、モデル文字列もサポートされています:

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## OpenAI 互換のフォールバック

お使いのバージョンにまだ TokenLab が含まれていない場合は、Agno の OpenAI 互換モデルパスを以下のように使用してください:

- Base URL: `https://api.tokenlab.sh/v1`
- API key: `TOKENLAB_API_KEY`
- Model: `gpt-5.4-mini`

## モデルの推奨事項

デフォルトのエージェントには `gpt-5.4-mini` を、より深い推論が必要な場合は `gpt-5.4` または `claude-sonnet-5` を、より高速なループ処理には `deepseek-v4-flash` を使用してください。
