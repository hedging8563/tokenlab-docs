## 概要

Prompt flowのOpenAI接続は、カスタムの `base_url` をサポートしています。これをTokenLabの `/v1` エンドポイントに設定し、フロー内でTokenLabのモデルIDを使用してください。

<Note>
**タイプ**: フロービルダーおよび評価プラットフォーム

**主要パス**: OpenAI互換のChat Completions

**サポート信頼度**: サポートされているOpenAI互換パス
</Note>

## 接続の作成

```bash
pf connection create \
  --file ./my_chatbot/openai.yaml \
  --set api_key=sk-your-tokenlab-key base_url=https://api.tokenlab.sh/v1 \
  --name open_ai_connection
```

## フローに関する注意点

`flow.dag.yaml` では、接続名を上記のコマンドと一致させてください。

```yaml
connection: open_ai_connection
deployment_name: claude-sonnet-5
```

一部のPrompt flowテンプレートでは、Azure OpenAIのデプロイメントもサポートしているため、この値を `deployment_name` と呼んでいます。TokenLabを使用する場合は、TokenLabのモデルIDを指定してください。

## エンドポイントに関する注意点

この統合では、Prompt flowのOpenAI互換接続を使用します。ネイティブのTokenLabレスポンス、Anthropic Messages、およびGeminiルートを利用するには、Prompt flowのツール、またはそれらのエンドポイントを直接呼び出すカスタムPythonノードが必要です。
