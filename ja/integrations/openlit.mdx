## 概要

OpenLITは公式のOpenAI SDKをインストルメント化するため、SDKクライアントのベースURLにTokenLabの `/v1` を設定することで、TokenLabのリクエストを監視できます。

<Note>
**タイプ**: 可観測性 (Observability)

**主要パス**: OpenAI SDKインストルメンテーション

**サポート信頼度**: サポートされているOpenAI互換の可観測性パス
</Note>

## インストール

```bash
pip install openlit openai
```

## 環境設定

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 例

```python
import os

import openlit
from openai import OpenAI

openlit.init()

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Hello from OpenLIT"}],
)
```

## エンドポイントに関する注意点

OpenLITはSDKインストルメンテーションパスに従います。Chat Completionsは最も安全な統合インターフェースです。その他のTokenLabネイティブな呼び出しについては、使用しているOpenLIT/OpenTelemetryの設定がそのSDKメソッドやHTTPクライアントをキャプチャできるかどうかに依存します。
