## 概要

このページは LiteLLM を使い、**Settings → LLM → Advanced** がある OpenHands UI 向けです。**OpenAI** を選び、`openai/` 接頭辞付きのカスタムモデル、ローカル欄への TokenLab キー、以下の Base URL を入力します。以前の選択を記録し、終了後に戻してください。アカウントとツール権限は維持します。[公式 OpenAI 互換設定](https://docs.openhands.dev/openhands/usage/llms/openai-llms)を参照してください。CLI、クラウド、ソースからの導入では手順が異なる場合があります。導入した版の説明に従い、`make setup-config` を汎用 CLI コマンドとして使わないでください。

## モデル設定

変更前に、現在のプロバイダー、モデル、接続設定をローカルに保存してください。これらの設定はアクティブなモデルを変更するため、使用後は元の値に戻します。ログイン済みアカウントとツール権限は変更しません。復元可能なバックアップなしに既存の OpenAI 互換接続を上書きしないでください。

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

設定の保存やモデル一覧だけでは、キーの有効性やリクエストの完了は確認できません。プロンプト送信には TokenLab 残高を使います。応答と対応する[リクエスト記録](https://tokenlab.sh/dashboard/runs?section=requests)を照合してからツールを試してください。補助リクエストにも料金が発生する場合があります。

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
