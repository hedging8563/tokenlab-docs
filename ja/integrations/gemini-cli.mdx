## 概要

Gemini CLI **0.60.0** は API キー認証での `GOOGLE_GEMINI_BASE_URL` を公式に説明しています。`gemini_generate_content` 対応の現行モデルを選び、TokenLab の Gemini ネイティブ API を使ってください。[公式設定](https://geminicli.com/docs/reference/configuration/)と[認証ガイド](https://geminicli.com/docs/get-started/authentication/)を参照できます。Google のサブスクリプションを TokenLab 経由にする設定ではありません。

## インストール

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## 設定

[クイックスタート](/ja/quickstart)の macOS、Linux、WSL、Windows PowerShell 向け手順で、キーをコマンド履歴に残さず `TOKENLAB_API_KEY` を設定し、同じターミナルから Gemini CLI を起動します。継続して使う場合はローカルのシークレット管理ツールを利用し、平文のキーをシェル設定へ追記しないでください。

現在の Google ログインと設定を残します。TokenLab 用に未使用の設定ルート `~/.gemini-tokenlab`（PowerShell では `$HOME`）などを選び、その中に `.gemini` を作成してください。既存の `.gemini/settings.json` と必要なポリシーファイルを対応する場所へコピーし、権限、サンドボックス、他の設定を維持します。そのコピーにだけ次の認証項目を追加し、設定ファイルがなければ作成します。OAuth キャッシュはコピーせず、元の認証情報も削除しません。管理された認証ポリシーに従ってください。

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## 使用方法

以下は `~/.gemini-tokenlab/.gemini/settings.json` を使用します。別のルートならパスを変更してください。作業フォルダーは通常の信頼確認で承認し、既存のツール承認ルールを保ちます。モデルは今回のセッションに明示指定します。

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

これらの変数は今回の起動だけに適用され、保存済みのアカウント、既定モデル、権限は維持されます。従来の設定を使うには変数なしで通常どおり起動してください。シェルの設定ファイルには保存しないでください。

## 確認

設定の保存やモデル一覧だけでは、キーの有効性やリクエストの完了は確認できません。プロンプト送信には TokenLab 残高を使います。応答と対応する[リクエスト記録](https://tokenlab.sh/dashboard/runs?section=requests)を照合してからツールを試してください。補助リクエストにも料金が発生する場合があります。

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
