## 概要

LibreChatは、カスタムのOpenAI互換エンドポイントを通じてTokenLabとスムーズに連携します。

<Note>
**タイプ**: チャットアプリ

**主要パス**: OpenAI互換チャット補完

**サポート信頼度**: サポート済みパス
</Note>

## 環境

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## エンドポイントの例

LibreChatのエンドポイント設定にTokenLabを追加します。

```yaml
customEndpoints:
  - name: 'TokenLab'
    apiKey: '${TOKENLAB_API_KEY}'
    baseURL: 'https://api.tokenlab.sh/v1'
    models:
      default:
        - 'gpt-5.5'
        - 'gpt-5.4'
        - 'gpt-5.4-mini'
        - 'claude-opus-4-8'
        - 'claude-sonnet-5'
        - 'gemini-3.5-flash'
        - 'deepseek-v4-pro'
        - 'deepseek-v4-flash'
      fetch: true
    titleConvo: true
    titleModel: 'gpt-5.4-mini'
    modelDisplayLabel: 'TokenLab'
```

## 注意事項

LibreChatはこの設定においてOpenAI互換のチャットパスを使用します。TokenLabは、それぞれの要求形式をサポートするクライアント向けに、ネイティブのResponses、Anthropic Messages、およびGemini互換エンドポイントも公開しています。
