## 概要

LibreChatは、カスタムのOpenAI互換エンドポイントを通じてTokenLabとスムーズに連携します。

## 環境

LibreChat プロジェクトのルートにある `.env` ファイルに追加します。

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## エンドポイントの例

LibreChat プロジェクトのルートに `librechat.yaml` がない場合は、`librechat.example.yaml` からコピーします。必須の `version` と既存の設定を保持し、次の項目を `endpoints.custom` に追加します。

```yaml
endpoints:
  custom:
    - name: 'TokenLab'
      apiKey: '${TOKENLAB_API_KEY}'
      baseURL: 'https://api.tokenlab.sh/v1'
      models:
        default:
          - 'gpt-5.5'
          - 'gpt-5.6-terra'
          - 'gpt-5.6-luna'
          - 'claude-opus-4-8'
          - 'claude-sonnet-5'
          - 'gemini-3.5-flash'
          - 'deepseek-v4-pro'
          - 'deepseek-v4-flash'
        fetch: true
      titleConvo: true
      titleModel: 'gpt-5.6-luna'
      modelDisplayLabel: 'TokenLab'
```

Docker を使用する場合は、このファイルを API コンテナの `/app/librechat.yaml` にマウントします。同じ LibreChat 環境を再起動し、TokenLab を選択してください。詳しくは [LibreChat の設定ガイド](https://www.librechat.ai/docs/configuration/librechat_yaml)を参照してください。

## 注意事項

LibreChatはこの設定においてOpenAI互換のチャットパスを使用します。TokenLabは、それぞれの要求形式をサポートするクライアント向けに、ネイティブのResponses、Anthropic Messages、およびGemini互換エンドポイントも公開しています。
