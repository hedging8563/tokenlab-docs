## 概要

Browser Useは、OpenAI互換のチャットモデルラッパーである `ChatOpenAILike` を通じてTokenLabを呼び出すことができます。

<Note>
**タイプ**: ブラウザ自動化エージェントフレームワーク

**主要なパス**: OpenAI互換のChat Completions

**サポートの信頼性**: OpenAI互換パスとしてサポート済み
</Note>

## 環境設定

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 例

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    add_schema_to_system_prompt=True,
    dont_force_structured_output=True,
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## エンドポイントに関する注意点

OpenAI互換クライアントを通じてChat Completionsを呼び出すBrowser Useワークフローには、このページの手順を使用してください。ワークフローでTokenLabネイティブのレスポンス、Anthropic Messages、またはGeminiエンドポイントが必要な場合は、そのプロトコルを直接サポートしているBrowser Useのクライアントパスを使用してください。
