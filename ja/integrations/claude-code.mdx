## 概要

[Claude Code](https://code.claude.com/docs/en/setup) は、AI 支援コーディングのための Anthropic 公式 CLI ツールです。API プロバイダーとして TokenLab を使用するように設定できます。

## インストール

Anthropic は現在、ネイティブインストーラーを推奨しています。npm インストールも互換性のために引き続き存在しますが、upstream では非推奨です。

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

npm パッケージが特に必要な場合は、以下を使用します:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
Claude Code に対して `sudo npm install -g` は使用しないでください。
</Warning>

## 設定

[クイックスタート](/ja/quickstart)の macOS、Linux、WSL、Windows PowerShell 向け手順で、キーをコマンド履歴に残さず `TOKENLAB_API_KEY` を設定し、同じターミナルから Claude Code を起動します。継続して使う場合はローカルのシークレット管理ツールを利用し、平文のキーをシェル設定へ追記しないでください。

これらの変数は今回の起動だけに適用され、保存済みのアカウント、既定モデル、権限は維持されます。従来の設定を使うには変数なしで通常どおり起動してください。シェルの設定ファイルには保存しないでください。

この起動方法は Claude Code **2.1.263** と `ANTHROPIC_AUTH_TOKEN` による Bearer 認証を使います。Base URL に `/v1` は付けません。設定ファイルの `env`、認証ヘルパー、クラウド設定、管理ポリシーが認証に影響するため、起動前に確認してください。競合がある場合はアカウント情報の削除や権限の緩和をせず、下記ヘルパーを使います。`/status` でモデルと権限を確認してください。

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

任意で、Python 3.11+ の[復元可能な Claude Code 設定ヘルパー](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md)を使い、変更のプレビュー、適用、元ファイルの復元を行えます。TokenLab Skills プラグイン **0.1.2** にこれらのスクリプトが含まれます。単体の Skill も、スクリプトを含む版に更新すれば利用できます。既存のプラグインまたは単体 Skill は [README の更新手順](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation)に従って更新し、スクリプトの存在を確認してください。このページの手動設定だけでも完了できます。

設定の保存やモデル一覧だけでは、キーの有効性やリクエストの完了は確認できません。プロンプト送信には TokenLab 残高を使います。応答と対応する[リクエスト記録](https://tokenlab.sh/dashboard/runs?section=requests)を照合してからツールを試してください。補助リクエストにも料金が発生する場合があります。

## 使用方法

設定後は、通常どおり Claude Code を使用します:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

必要に応じてインストールを確認します:

```bash
claude --version
claude doctor
```

## 利用可能なモデル

TokenLab はすべての Claude モデルをサポートしています:

| モデル | 説明 |
|-------|-------------|
| `claude-opus-4-6` | 最も高性能、複雑な推論向け |
| `claude-sonnet-4-6` | バランスの取れた性能、コーディングに最適 |
| `claude-haiku-4-5` | 最速、コスト効率が高い |

## モデル選択

`--model` フラグでモデルを指定します:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## 拡張思考

複雑な推論タスクには、extended thinking を備えたモデルを使用します:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## トラブルシューティング

  </Accordion>

  <Accordion title="無効な API キー">

  </Accordion>

    モデル名が正しいことを確認してください。`claude-sonnet-4-6` 形式を使用します。
  </Accordion>
</AccordionGroup>
