## 概要

<Note>
**種類**: IDE / CLI コーディングエージェント

**主要パス**: OpenAI 互換 Chat Completions

**サポート**: 公式カスタムプロバイダーパス
</Note>

[Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible) の VS Code 拡張機能と Kilo CLI は同じ OpenAI 互換設定を使用できます。

## インストールと UI 設定

VS Code で **Kilo Code** のプレリリース版をインストールするか、CLI をインストールします。

```bash
npm install -g @kilocode/cli
kilo --version
```

**Settings → Providers → Custom provider** を開きます。

| フィールド | 値 |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | TokenLab API Key |
| Model | `kimi-k3` |

Kilo は `/v1/models` からモデルを自動検出します。保存後に `tokenlab/kimi-k3` を選択します。

## CLI 設定

Key を環境変数に保存し、信頼済みグローバル設定 `~/.config/kilo/kilo.jsonc` を編集します。

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

再起動して `kilo models` を実行します。`{env:...}` は信頼済みのグローバルまたは管理設定でのみ解決されます。実際の Key を Git 管理されるプロジェクト設定へ書かないでください。
