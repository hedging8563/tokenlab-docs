## 概要

OpenLLMetryのOpenAIインストゥルメンテーションは、公式のOpenAI SDKを通じて行われる呼び出しをトレースします。そのSDKをTokenLabの `/v1` ベースURLで構成してください。

<Note>
**タイプ**: 可観測性 (Observability)

**主要パス**: OpenAI SDKインストゥルメンテーション

**サポート信頼度**: サポートされているOpenAI互換の可観測性パス
</Note>

## インストール

```bash
pip install opentelemetry-instrumentation-openai openai
```

## 環境変数

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 例

```python
import os

from openai import OpenAI
from opentelemetry.instrumentation.openai import OpenAIInstrumentor

OpenAIInstrumentor().instrument()

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Trace this request"}],
)
```

## エンドポイントに関する注意点

このパスは、OpenAI SDK互換のTokenLab呼び出しに使用してください。TokenLabネイティブのエンドポイントについては、実際にそれらのリクエストを送信するHTTPクライアントまたはSDKクライアントをインストゥルメントしてください。
