## 概要

Flowiseでは、利用可能な場合にTokenLabチャットノードを通じて、またはTokenLabを指定したOpenAI互換チャットモデルノードを通じて、TokenLabを呼び出すことができます。

<Note>
**タイプ**: ワークフロービルダー

**主要なパス**: OpenAI互換チャット補完

**サポートの信頼性**: スコープ制限付きでサポート
</Note>

## TokenLabノード

Flowiseビルドに **TokenLab** チャットモデルノードが含まれている場合：

1. **Chat Models** -> **TokenLab** を追加します
2. TokenLab API認証情報を作成します
3. **Model Name** を `gpt-5.4-mini` に設定します
4. チェーン、エージェント、またはワークフローに接続します
5. テストプロンプトを実行します。

## OpenAI互換フォールバック

お使いのビルドにTokenLabノードがない場合は、**Chat Models** → **OpenAI Custom Model** を追加します。**Connect Credential** でTokenLabのキーを使って **OpenAI API** の認証情報を作成します。**Model Name** と **Additional Parameters** → **Base Path** を次のように設定します。

| フィールド | 値 |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

ノードをチェーン、エージェント、またはワークフローに接続し、テストプロンプトを送信します。

## 推奨モデル

- `gpt-5.4-mini`: ほとんどのワークフローテスト用
- `claude-sonnet-5`: より強力なライティングおよび推論用
- `gemini-3.5-flash`: 高速なマルチモーダル対応ワークフロー用
- `deepseek-v4-flash`: 高速なコード生成や推論の反復用
