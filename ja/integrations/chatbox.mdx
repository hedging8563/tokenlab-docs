## 概要

Chatboxでは、OpenAI互換のAPI設定を通じてTokenLabを利用できます。

<Note>
**タイプ**: チャットアプリ

**主要なパス**: OpenAI互換のチャット補完

**サポートの信頼性**: サポート済みパス
</Note>

## Chatboxの設定

1. **Settings** -> **Model Provider** -> **Add** -> **Add Custom Provider** を開きます
2. **Name** をTokenLab、**API Mode** を **OpenAI API Compatible** に設定し、**Add** をクリックします。
3. 以下を入力します:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Path**: `/chat/completions`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. 保存し、短いテストメッセージを送信します。

## 推奨モデル

| ユースケース | モデル |
|----------|-------|
| 日常的なチャット | `gpt-5.4-mini` |
| 高度な推論 | `gpt-5.4` または `gpt-5.5` |
| Claudeスタイルの出力 | `claude-sonnet-5` |
| 高速なフォールバック | `deepseek-v4-flash` |

## 注意事項

お使いのChatboxのビルドでTokenLabが組み込みプロバイダーとしてすでにリストされている場合は、直接それを選択してください。リストされていない場合は、上記のOpenAI互換プロバイダーのパスが最も安全なフォールバックとなります。
