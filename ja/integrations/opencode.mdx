## 概要

OpenCode は、ターミナルで動作するオープンソースの AI コーディングアシスタントです。複数の LLM プロバイダーをサポートしており、TokenLab の API を使用するように設定することで、300 以上のモデルにアクセスできます。

## インストール

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

インストールを確認します:

```bash
opencode --version
```

## 設定

### ステップ 1: 環境変数を設定する

[クイックスタート](/ja/quickstart)の macOS、Linux、WSL、Windows PowerShell 向け手順で、キーをコマンド履歴に残さず `TOKENLAB_API_KEY` を設定し、同じターミナルから OpenCode を起動します。継続して使う場合はローカルのシークレット管理ツールを利用し、平文のキーをシェル設定へ追記しないでください。

### ステップ 2: OpenCode を設定する

以下の設定は **OpenCode 1.18.31** で確認しています。他のバージョンは、それぞれの公式ドキュメントに沿って確認してください。

以下を独立した `~/.config/opencode/tokenlab.jsonc` に保存します。`XDG_CONFIG_HOME` が設定されている場合は、そのディレクトリ内の `opencode/tokenlab.jsonc` を使います。通常の `opencode.json` / `opencode.jsonc`、アカウント、既定モデル、権限は変更しません。このファイルは、その起動時に `OPENCODE_CONFIG` で指定した場合のみ読み込まれます。ファイルやプロバイダー名が既に使われている場合は別の名前を選び、起動コマンドも変更してください。

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
この設定は `@ai-sdk/openai-compatible` で Chat Completions を送信します。現在のモデル情報で Chat Completions と必要なツールの対応を確認してください。この例は他のプロトコルやバージョンの互換性を保証しません。
</Note>

任意で、Python 3.11+ の[復元可能な OpenCode 設定ヘルパー](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md)を使い、変更のプレビュー、適用、元ファイルの復元を行えます。TokenLab Skills プラグイン **0.1.2** にこれらのスクリプトが含まれます。単体の Skill も、スクリプトを含む版に更新すれば利用できます。既存のプラグインまたは単体 Skill は [README の更新手順](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation)に従って更新し、スクリプトの存在を確認してください。このページの手動設定だけでも完了できます。

## 基本的な使い方

クイックスタートの手順でキーを設定し、この起動に限ってファイルを読み込み、モデルを明示的に選びます。独自のパスやプロバイダー名を使う場合は置き換えてください。既存の `OPENCODE_CONFIG` やインラインの `OPENCODE_CONFIG_CONTENT` は保持し、別の起動環境を使います。プロジェクトや管理設定が優先される場合もあります。

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

モデル一覧はローカルの読み込み確認であり、キーの有効性や実際の API 成功を証明しません。プロンプト送信には TokenLab 残高を使い、OpenCode はタイトル生成など別途課金される補助リクエストを送る場合があります。応答と対応する[リクエスト記録](https://tokenlab.sh/dashboard/runs?section=requests)を確認してください。

このファイルを読み込まずに起動すれば通常の設定を使えます。本手順のために `OPENCODE_CONFIG` をシェルの設定ファイルへ保存しないでください。手動設定を戻す際は、新規作成した独立ファイルだけを削除するか、既存ファイルのバックアップを復元します。

## 利用可能なモデル

| モデル | 最適用途 |
|-------|----------|
| `gpt-5.6-terra` | 複雑なタスク、コードアーキテクチャ |
| `gpt-5.6-luna` | 素早い修正、簡単な問い合わせ |
| `claude-sonnet-4-6` | コードレビュー、ドキュメント作成 |
| `claude-opus-4-6` | 複雑な推論 |
| `gemini-3.5-flash` | 高速な応答 |

## よく使うコマンド

**コードを解析する:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**コードを生成する:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**変更をレビューする:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**エラーを修正する:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## 対話コマンド

| コマンド | 説明 |
|---------|-------------|
| `/help` | 利用可能なコマンドを表示 |
| `/models` | 別のモデルに切り替える |
| `/clear` | 会話履歴をクリアする |
| `/exit` | OpenCode を終了する |

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - `options.baseURL` が `https://api.tokenlab.sh/v1` に設定されていることを確認してください
    - ネットワーク接続を確認してください
    - テストとして `curl https://api.tokenlab.sh/v1/models` を試してください
  </Accordion>

  <Accordion title="認証に失敗しました">
    - `TOKENLAB_API_KEY` 環境変数が設定されていることを確認してください
    - `options.apiKey` が `{env:TOKENLAB_API_KEY}` または別の有効な secret ソースを参照していることを確認してください
    - キーが `sk-` で始まっていることを確認してください
    - TokenLab ダッシュボードでキーが有効になっていることを確認してください
  </Accordion>

  <Accordion title="モデルが見つかりません">
    - 設定内のモデル名が完全に一致していることを確認してください
    - [tokenlab.sh/en/models](https://tokenlab.sh/ja/models) でモデルの利用可否を確認してください
  </Accordion>
</AccordionGroup>
