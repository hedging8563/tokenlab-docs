## 概要

OpenCode は、ターミナルで動作するオープンソースの AI コーディングアシスタントです。複数の LLM プロバイダーをサポートしており、TokenLab の API を使用するように設定することで、300 以上のモデルにアクセスできます。

## インストール

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

インストールを確認します:

```bash
opencode --version
```

## 設定

### ステップ 1: 環境変数を設定する

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

永続的に設定するには、`~/.bashrc` または `~/.zshrc` に追加します:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### ステップ 2: OpenCode を設定する

OpenCode の現在のドキュメントでは、`opencode.json` または `opencode.jsonc` を通じてプロバイダーを設定することが推奨されています。TokenLab では、組み込みの `openai` プロバイダーを流用するのではなく、カスタムプロバイダーを使用してください:

この例は対応している V1 形式です。`~/.config/opencode/opencode.json` にマージし、既存のプロバイダーと権限を残します。V2 は対応する V1 設定を読めますが、同一プロバイダー内で形式を混ぜないでください。[公式移行ガイド](https://opencode.ai/v2/docs/migrate-v1/)を参照してください。`/models` で登録を確認し、有料テストを TokenLab の記録と照合します。復元時は元のモデルに戻し、この項目だけを削除します。

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
チャット補完形式との互換性には `@ai-sdk/openai-compatible` を使用してください。`/v1/responses` 上に構築されたプロバイダーパスが特に必要な場合は、OpenCode のプロバイダードキュメントではパッケージを `@ai-sdk/openai` に切り替えることが推奨されています。
</Note>

## 基本的な使い方

**対話モードを開始する:**

```bash
opencode
```

**プロンプトを指定して実行する:**

```bash
opencode run "Explain this codebase"
```

**モデルを指定する:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## 利用可能なモデル

| モデル | 最適用途 |
|-------|----------|
| `gpt-5.6-terra` | 複雑なタスク、コードアーキテクチャ |
| `gpt-5.6-luna` | 素早い修正、簡単な問い合わせ |
| `claude-sonnet-4-6` | コードレビュー、ドキュメント作成 |
| `claude-opus-4-6` | 複雑な推論 |
| `gemini-3.5-flash` | 高速な応答 |

## よく使うコマンド

**コードを解析する:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**コードを生成する:**

```bash
opencode run "Create a REST API with Express"
```

**変更をレビューする:**

```bash
git diff | opencode run "Review these changes"
```

**エラーを修正する:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## 対話コマンド

| コマンド | 説明 |
|---------|-------------|
| `/help` | 利用可能なコマンドを表示 |
| `/models` | 別のモデルに切り替える |
| `/clear` | 会話履歴をクリアする |
| `/exit` | OpenCode を終了する |

## トラブルシューティング

<AccordionGroup>
  <Accordion title="接続エラー">
    - `options.baseURL` が `https://api.tokenlab.sh/v1` に設定されていることを確認してください
    - ネットワーク接続を確認してください
    - テストとして `curl https://api.tokenlab.sh/v1/models` を試してください
  </Accordion>

  <Accordion title="認証に失敗しました">
    - `TOKENLAB_API_KEY` 環境変数が設定されていることを確認してください
    - `options.apiKey` が `{env:TOKENLAB_API_KEY}` または別の有効な secret ソースを参照していることを確認してください
    - キーが `sk-` で始まっていることを確認してください
    - TokenLab ダッシュボードでキーが有効になっていることを確認してください
  </Accordion>

  <Accordion title="モデルが見つかりません">
    - 設定内のモデル名が完全に一致していることを確認してください
    - [tokenlab.sh/en/models](https://tokenlab.sh/ja/models) でモデルの利用可否を確認してください
  </Accordion>
</AccordionGroup>
