---
title: "マテリアルアセットの削除"
openapi: "/openapi/ja.json DELETE /v1/videos/assets/{assetId}"
description: "現在の組織が所有するSeedanceマテリアルアセットを削除します。"
---

マテリアルアセットを1つ削除します。これによって、そのアセットを含むマテリアルグループが削除されることはありません。削除後、そのアセットIDを `material_asset_id` として使用することはできなくなります。

`project_name` は認証済み組織内のリソースを分離します。デフォルトは `default` です。関連するグループと素材には、大文字と小文字を区別した同じ値を使用してください。POST/PUT では JSON ボディ、GET/DELETE ではクエリに指定します。

## リクエスト例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr?project_name=default" \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## レスポンス例

```json
{
  "deleted": true,
  "id": "asset-20260720123456-qn7wr"
}
```
