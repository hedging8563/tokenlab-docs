---
title: "マテリアルアセットの一覧取得"
openapi: "GET /v1/videos/assets"
description: "現在の組織が所有するSeedanceマテリアルアセットの一覧を取得します。"
---

認証された組織が所有するマテリアルアセットの一覧を取得します。特定の生成ワークフロー用のアセットを検索する必要がある場合は、`library_type`、`group_id`、または `status` でフィルタリングしてください。

`status` が `ACTIVE` であるアセットのみを使用してください。動画を作成するときは、返されたTokenLab素材アセットの `id` を使用してください。

`project_name` は認証済み組織内のリソースを分離します。デフォルトは `default` です。関連するグループと素材には、大文字と小文字を区別した同じ値を使用してください。POST/PUT では JSON ボディ、GET/DELETE ではクエリに指定します。

## リクエスト例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## レスポンス例

```json
{
  "assets": [
    {
      "id": "asset-20260720123456-qn7wr",
      "object": "seedance.material_asset",
      "project_name": "default",
      "group_id": "group-20260720123456-vrt01",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
