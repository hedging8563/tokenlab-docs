description: "TokenLabのグループIDを使用して、Seedanceマテリアルグループを1つ取得します。"
---

マテリアルグループを1つ取得します。`library_type`は、そのグループがバーチャルアバターグループか、実在の人物グループかを示します。

アップロード前にグループが現在も存在し、`status: "ACTIVE"`であることを確認する必要がある場合は、このエンドポイントを使用してください。

`project_name` は認証済み組織内のリソースを分離します。デフォルトは `default` です。関連するグループと素材には、大文字と小文字を区別した同じ値を使用してください。POST/PUT では JSON ボディ、GET/DELETE ではクエリに指定します。

## リクエスト例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## レスポンス例

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
