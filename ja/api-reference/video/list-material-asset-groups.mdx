title: "マテリアルアセットグループの一覧取得"
openapi: "GET /v1/videos/assets/groups"
description: "現在の組織が所有するSeedanceマテリアルグループを一覧表示します。"
---

認証された組織が所有するマテリアルグループを一覧表示します。`library_type` および `status` でフィルタリングすることで、バーチャルアバターグループと実写グループを区別できます。

マテリアルをアップロードする際は、返された `id` を使用してください。動画生成時に `group_id` を `material_asset_id` として渡さないでください。生成にはマテリアルアセットの `id` が必要です。

`project_name` は認証済み組織内のリソースを分離します。デフォルトは `default` です。関連するグループと素材には、大文字と小文字を区別した同じ値を使用してください。POST/PUT では JSON ボディ、GET/DELETE ではクエリに指定します。

## リクエスト例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups?library_type=aigc_avatar&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## レスポンス例

```json
{
  "groups": [
    {
      "id": "group-20260720123456-vrt01",
      "object": "seedance.material_asset_group",
      "project_name": "default",
      "library_type": "aigc_avatar",
      "group_name": "Product references",
      "status": "ACTIVE",
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
