---
title: "マテリアルアセットの更新"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "現在の組織が所有するSeedanceマテリアルアセットを更新します。"
---

マテリアル名またはメタデータを更新します。ソースURLとアセットタイプは作成後に固定されるため、ソースファイルが変更された場合は新しいアセットを作成してください。

`project_name` は認証済み組織内のリソースを分離します。デフォルトは `default` です。関連するグループと素材には、大文字と小文字を区別した同じ値を使用してください。POST/PUT では JSON ボディ、GET/DELETE ではクエリに指定します。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"},"project_name":"default"}'
```
