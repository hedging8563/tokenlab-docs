---
title: "マテリアルアセットの作成"
openapi: "POST /v1/videos/assets"
description: "SeedanceマテリアルアセットをTokenLabマテリアルグループにアップロードします。"
---

公開されているソースURLからSeedanceマテリアルグループにインポートします。TokenLabは後で使用するためにマテリアルを保存します。生成時にはソースURLではなく、返されたマテリアルアセットの `id` を使用してください。

`library_type: "aigc_avatar"` の場合、`group_id` は任意です。TokenLabは組織のデフォルトのバーチャルアバターグループを使用または作成します。`library_type: "liveness_face"` の場合、`group_id` は必須であり、[ビジュアル確認結果の取得](/ja/api-reference/video/get-visual-validation-result)によって返されるTokenLabグループである必要があります。

| タイプ | サポートされている入力 |
|------|-----------------|
| 画像 | `jpeg`, `jpg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; ≤30 MiB; 幅と高さ `[300, 6000]` px; アスペクト比 `[0.4, 2.5]`. |
| 動画 | `mp4`, `mov`; ≤200 MiB. |
| 音声 | `aac`, `wav`, `mp3`; ≤15 MiB. |

TokenLab はソース URL、メディア形式、ファイルサイズ、読み取り可能な画像寸法を確認します。インポートの受付は利用準備の完了を意味しません。`ACTIVE` を待ち、処理が失敗した場合は `error_message` を確認してください。その他のメディアや顔の条件は処理中に検証されます。

作成は非同期で行われます。`status` が `ACTIVE` になるまで [マテリアルアセットの取得](/ja/api-reference/video/get-material-asset) をポーリングしてください。実在人物グループの場合、1つのグループは1人の認証済み人物に対応します。複数の顔が含まれている場合や、認証済みの人物と一致しない顔がアップロードされた場合は失敗する可能性があります。

`project_name` は認証済み組織内のリソースを分離します。デフォルトは `default` です。関連するグループと素材には、大文字と小文字を区別した同じ値を使用してください。POST/PUT では JSON ボディ、GET/DELETE ではクエリに指定します。

## リクエスト例

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"group-20260720123456-vrt01","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view","project_name":"default"}'
```
