## リクエストボディ

文字起こしは結果を直接返す場合と、HTTP `200`、`id`、`status` で非同期タスクの受け付けを返す場合があります。非同期の場合は `poll_url` または `/v1/tasks/{id}` を確認してください。長い音声を同期処理する場合、タイムアウトは少なくとも `120s` に設定してください。

<ParamField body="file" type="file" required>
  文字起こしする音声ファイル。対応形式: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm。 最大ファイルサイズ: 25 MB。
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  文字起こしモデル ID。例: `whisper-1`、`gpt-4o-transcribe`。現在の候補は `GET /v1/models?recommended_for=stt` で確認してください。
</ParamField>

<ParamField body="language" type="string">
  ISO-639-1 形式の音声言語（例: `en`, `zh`, `ja`）。
</ParamField>

<ParamField body="prompt" type="string">
  モデルのスタイルを誘導したり、前のセグメントの続きを生成したりするための任意のテキスト。
</ParamField>

<ParamField body="response_format" type="string" default="json">
  出力形式。Whisper は `json`、`text`、`srt`、`verbose_json`、`vtt` に対応します。他のモデルの対応形式はモデル詳細で確認してください。
</ParamField>

<ParamField body="temperature" type="number">
  0～1 のサンプリング温度。このパラメーターに対応するモデルでのみ使用できます。
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  対応モデルでは `word` と／または `segment` を指定できます。Whisper は `response_format=verbose_json` が必要です。multipart で複数値を渡す場合は `timestamp_granularities[]` を繰り返します。
</ParamField>

## レスポンス

以下のフィールドは JSON の文字起こし・翻訳応答を説明します。`text`、`srt`、`vtt` は JSON ではなくテキストや字幕を返します。追加フィールドはモデルと出力形式に依存します。

<ResponseField name="text" type="string">
  文字起こしされたテキスト。
</ResponseField>

`verbose_json` の場合:

<ResponseField name="task" type="string">
  返される場合のタスク名。例: `transcribe`。
</ResponseField>

<ResponseField name="language" type="string">
  検出された言語。
</ResponseField>

<ResponseField name="duration" type="number">
  音声の長さ（秒）。
</ResponseField>

<ResponseField name="segments" type="array">
  タイムスタンプ付きの文字起こしセグメント。
</ResponseField>

<ResponseField name="words" type="array">
  単語レベルのタイムスタンプ（要求された場合）。
</ResponseField>

非同期の文字起こしタスクが受け付けられると、本文の代わりに次のフィールドを返します。

<ResponseField name="id" type="string">
  タスクID。
</ResponseField>

<ResponseField name="task_id" type="string">
  利用可能な場合の非同期タスク ID 別名です。
</ResponseField>

<ResponseField name="status" type="string">
  タスクのステータス: `pending`、`processing`、`completed`、または `failed`。
</ResponseField>

<ResponseField name="poll_url" type="string">
  作成レスポンスで提供された場合に優先して使うポーリング URL。
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],

        'model' => 'whisper-1',
        'language' => 'en'
    ]

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```

## 翻訳

音声を英語に翻訳するには、translations endpoint を使用します:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
