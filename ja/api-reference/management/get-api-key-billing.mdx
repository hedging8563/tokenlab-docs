---

## 概要

このエンドポイントは、選択した API キーに対する消費ベースの請求集計を返します。総コスト、総リクエスト数、課金単位別の使用量、`by_model`、`by_logical_model`、`by_model_vendor`、`by_scene` の各内訳、および日次コスト推移が含まれます。

## 注意事項

- 金額フィールドは USD のみをサポートします。`CNY` 入力は廃止されており、`400 currency_retired` が返されます。

- チャージ、請求書、その他の組織レベルの財務記録は含まれません。

## 例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 重要なフィールド

<ResponseField name="api_key" type="object">list/create/update レスポンスと同じフィールドを持つ API キー概要。</ResponseField>
<ResponseField name="summary" type="object">選択したフィルターに基づく集計値。</ResponseField>
<ResponseField name="breakdowns" type="object">選択したフィルターに基づく内訳。</ResponseField>
<ResponseField name="summary.total_requests" type="number">総リクエスト数。</ResponseField>
<ResponseField name="summary.total_cost" type="number">表示用に JSON 数値で返される USD の総コスト。</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">10 進文字列で返される USD の正確な総コスト。</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">プロンプトトークン総数。</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">完了トークン総数。</ResponseField>
<ResponseField name="summary.total_tokens" type="number">総トークン数。</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">利用単位別にグループ化した使用量。</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">リクエストされた公開モデル別の内訳。</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">論理公開モデル別の内訳。</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">公開モデルベンダー別の内訳。</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">公開リクエストシーン別の内訳。</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">日次コスト推移。</ResponseField>
