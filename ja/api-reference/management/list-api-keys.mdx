## 概要

現在の管理トークンに紐づく組織のユーザー API キー一覧を返します。

## 注意事項

- 金額フィールドは USD のみをサポートします。`CNY` 入力は廃止されており、`400 currency_retired` が返されます。

- システム管理のキーは結果に含まれません。

## 例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## リクエスト / レスポンス

正確なスキーマについては、上記のインタラクティブな OpenAPI パネルを使用してください。

## 重要なフィールド

<ResponseField name="object" type="string">常に `list` です。</ResponseField>
<ResponseField name="data" type="array">API キーオブジェクトの配列。</ResponseField>
<ResponseField name="pagination" type="object">`page`、`limit`、`total`、`totalPages` を含むページネーションメタデータ。</ResponseField>
<ResponseField name="data[].id" type="string">後続の Management API 呼び出しで使用する API キー識別子。</ResponseField>
<ResponseField name="data[].name" type="string">API キーの表示名。</ResponseField>
<ResponseField name="data[].key_prefix" type="string">表示およびサポート用の機密ではないキープレフィックス。</ResponseField>
<ResponseField name="data[].status" type="string">`active`、`inactive`、`revoked` のいずれか。</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">表示用に JSON 数値で返される USD の利用上限。`null` は無制限を意味します。</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">10 進文字列で返される USD の正確な利用上限。`null` は無制限を意味します。</ResponseField>
<ResponseField name="data[].used_amount" type="number">表示用に JSON 数値で返される USD の累積利用額。</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">10 進文字列で返される USD の正確な累積利用額。</ResponseField>
<ResponseField name="data[].models" type="string[]">キー単位のモデル許可リスト。空の配列は、キー単位の追加モデル制限がないことを意味します。</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">キーの有効期限を示す ISO タイムスタンプ。期限なしの場合は `null`。</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">最終利用時刻の ISO タイムスタンプ。未使用の場合は `null`。</ResponseField>
<ResponseField name="data[].created_at" type="string">作成時刻の ISO タイムスタンプ。</ResponseField>
