---
title: "音楽の作成"
openapi: "/openapi/ja.json POST /v1/music/generations"
description: "Sunoを使用して音楽生成タスクを作成します"
---

AIを使用して音楽と歌詞を生成します。これは非同期 API です。作成レスポンスはタスク ID を返し、利用可能な場合は優先して使う `poll_url` も返します。

## リクエストボディ

<ParamField body="model" type="string" default="suno_music">
  音楽モデル ID。例: `suno-music`。歌詞のみの場合は、現在の公開操作に `lyrics` を含むモデルを選んでください。
</ParamField>

<ParamField body="prompt" type="string">
  音楽の説明または置換テキスト。音楽、歌詞、upload-cover、upload-extend、replace-section では必須です。add-instrumental と音源分離では省略できます。
</ParamField>

<ParamField body="title" type="string">
  生成された曲のタイトル。
</ParamField>

<ParamField body="tags" type="string">
  スタイルタグ（例：「pop, upbeat, electronic」）。
</ParamField>

<ParamField body="negative_tags" type="string">
  避けたいスタイル。`audio_operation` が `add-instrumental` の場合は必須です。
</ParamField>

<ParamField body="action" type="string">
  任意の `MUSIC` または `LYRICS`。対応する公開操作をサポートするモデルを選んでください。このフィールドで音楽専用モデルに歌詞生成機能を追加することはできません。
</ParamField>

<ParamField body="mv" type="string">
  Suno バージョンの指定。生成、upload-cover、upload-extend、add-instrumental、`audio_url` を使った置換では必須です。歌詞、`task_id` + `audio_id` を使った置換、音源分離では省略してください。対応値: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  `true` にするとボーカルなしのインストゥルメンタルを生成します。
</ParamField>

<ParamField body="audio_url" type="string">
  公開アクセス可能な参照またはアップロード済み音声 URL。`audio_operation` を省略すると upload-cover フローを使います。
</ParamField>

<ParamField body="audio_operation" type="string">
  音声操作: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`、`multi-stem-separation`、`advanced-split` は `task_id` + `audio_id` が必要です。`advanced-split` は `stem_name` も必要です。`upload-extend` は 0 より大きい `continue_at`、`add-instrumental` は `audio_url`、`title`、`tags`、`negative_tags` が必要です。

  `replace-section` では `prompt`、`tags`、`title`、`infill_start_s`、`infill_end_s`、`full_lyrics` が必要です。ソースは `task_id` + `audio_id` または `audio_url` + `mv` のどちらか一方のみを指定します。置換区間は 6～60 秒です。
</ParamField>

<ParamField body="task_id" type="string">
  生成音声の置換や音源分離に使う、自分の組織が所有するソースタスク ID。
</ParamField>

<ParamField body="audio_id" type="string">
  ソースタスクの結果が返す音声 ID。生成音声の置換と音源分離では `task_id` とともに必要です。
</ParamField>

<ParamField body="infill_start_s" type="number">
  置換開始時刻（秒）。0 以上。`replace-section` で必須です。
</ParamField>

<ParamField body="infill_end_s" type="number">
  置換終了時刻（秒）。`replace-section` で必須で、`infill_start_s` の 6～60 秒後に指定します。
</ParamField>

<ParamField body="full_lyrics" type="string">
  完成する曲の歌詞全体。`replace-section` で必須です。
</ParamField>

<ParamField body="stem_name" type="string">
  分離するステム名。`advanced-split` で必須です。
</ParamField>

<ParamField body="continue_clip_id" type="string">
  続きから開始する前のクリップのID。
</ParamField>

<ParamField body="continue_at" type="number">
  続きを開始する秒数。`upload-extend` では必須で、0 より大きい値です。
</ParamField>

<Note>
`prompt` は最大 5000 文字、`tags` と `negative_tags` は各最大 1000 文字です。対応する操作とパラメーターは選択したモデルの現在の詳細に従います。
</Note>

## レスポンス

<ResponseField name="id" type="string">
  ステータスをポーリングするためのタスクID。
</ResponseField>

<ResponseField name="task_id" type="string">
  同じ非同期タスク ID の別名。返される場合のみ存在します。
</ResponseField>

<ResponseField name="poll_url" type="string">
  利用可能な場合に返される優先ポーリング URL です。
</ResponseField>

<ResponseField name="status" type="string">
  タスクのステータス：`pending`、`processing`、`completed`、または `failed`。
</ResponseField>

<ResponseField name="created" type="integer">
  返される場合のタスク作成 Unix タイムスタンプ。
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
