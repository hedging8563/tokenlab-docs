---
title: "モデルの一覧取得"
openapi: "GET /v1/models"
description: "TokenLabで現在利用可能なモデルの一覧を取得します"
---

モデルカタログは公開されており、APIキーは不要です。各項目には、現在の機能、価格、およびAPIフォーマットの概要が含まれています。詳細が必要な場合は、個別のモデルを取得してください。

## クエリパラメータ

<ParamField query="category" type="string">
  `chat`、`image`、`video`、`audio`、`tts`、`stt`、`music`、`3d`、`embedding`、`rerank`、または `translation` でフィルタリングします。
</ParamField>

<ParamField query="recommended_for" type="string">
  `image`、`video`、`music`、`3d`、`tts`、`stt`、`embedding`、`rerank`、または `translation` などのタスクに対する現在の推奨事項を返します。
</ParamField>

<ParamField query="provider" type="string">
  `openai`、`anthropic`、`google`、または `deepseek` などのモデル提供元でフィルタリングします。
</ParamField>

<ParamField query="tag" type="string">
  `chat`、`image`、`video`、`embedding`、または `translation` などのタグでフィルタリングします。
</ParamField>

## レスポンス

<ResponseField name="object" type="string">常に `list` です。</ResponseField>
<ResponseField name="data" type="array">`id`、`owned_by`、および `tokenlab` の概要を含むモデルのリストです。</ResponseField>

`tokenlab` 配下の一般的なリストフィールドは以下の通りです：

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` および `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` および `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`、`tokenlab.commercial`、および `tokenlab.badges`
- `tokenlab.request_format_summary`
- `recommended_for` が使用されている場合の `tokenlab.agent_preferences`

`recommended_for` が使用されている場合、結果には推奨ステータスや更新日時が含まれることがあります。順序を固定するのではなく、現在のレスポンスを読み取ってください。

## 例

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```

詳細については、[モデルの取得](/ja/api-reference/models/get-model)を参照してください。
