---
title: "コンテンツの生成"
openapi: "POST /v1beta/models/{model}:generateContent"
description: "Google Gemini API形式を使用してコンテンツを生成します"
---

Gemini Models API が返すモデルを選び、Gemini のリクエストとレスポンス形式を使用します。ProtoJSON lowerCamelCase と対応する proto snake_case のフィールド名を使用できます。任意フィールドと値の対応範囲は選択したモデルによって異なります。

## パスパラメータ

<ParamField path="model" type="string" required>
  モデル名 (例: `gemini-2.5-pro`、`gemini-3.5-flash`)。
</ParamField>

## クエリパラメータ

<ParamField query="key" type="string">
  APIキー（ヘッダー認証の代替）。
</ParamField>

## 認証

Geminiエンドポイントは、複数の認証方法をサポートしています：
- `?key=YOUR_API_KEY` クエリパラメータ
- `x-goog-api-key: YOUR_API_KEY` ヘッダー
- `Authorization: Bearer YOUR_API_KEY` ヘッダー

## リクエストボディ

<ParamField body="contents" type="array" required>
  `parts` と任意の `role` を含む会話内容です。メディアには `inlineData` / `inline_data` または `fileData` / `file_data` を使用します。TokenLab が作成した Files と Cache の ID は所有するワークスペース内でのみ使用できます。
</ParamField>

<ParamField body="systemInstruction" type="object">
  モデルへのシステム指示。
</ParamField>

<ParamField body="generationConfig" type="object">
  `temperature`、`topP`、`topK`、`maxOutputTokens`、`stopSequences`、`candidateCount`、`responseModalities`、`responseMimeType`、`responseSchema`、`thinkingConfig` などの生成設定です。対応する snake_case 名も使用できます。値と組み合わせの対応範囲はモデルによって異なります。
</ParamField>

<ParamField body="safetySettings" type="array">
  セーフティフィルター設定。
</ParamField>

## レスポンス

<ResponseField name="candidates" type="array">
  生成されたコンテンツの候補。
</ResponseField>

<ResponseField name="usageMetadata" type="object">
  トークン使用状況の情報。
</ResponseField>

## マルチモーダル入力例

Gemini のマルチモーダルリクエストでは、媒体を `contents[].parts[]` に入れ、インラインバイトまたは URL ベースのファイル参照のどちらかで渡します。

現在の公共 Gemini 契約でサポートしている媒体カテゴリ：
- 画像
- 音声
- 動画

インライン媒体では `inlineData` または `inline_data` を使い、Base64 化したファイルバイトを渡します。

URL 媒体では `fileData` または `file_data` を使い、公開到達可能な `https` URL を渡します。

### 画像入力例

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "この画像を説明してください。" },
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "/9j/4AAQSkZJRgABAQ..."
          }
        }
      ]
    }
  ]
}
```

### 音声入力例

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "この音声を文字起こしして要約してください。" },
        {
          "file_data": {
            "mime_type": "audio/mpeg",
            "file_uri": "https://example.com/sample.mp3"
          }
        }
      ]
    }
  ]
}
```

### 動画入力例

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "この動画を簡潔に説明してください。" },
        {
          "fileData": {
            "mimeType": "video/mp4",
            "fileUri": "https://example.com/sample.mp4"
          }
        }
      ]
    }
  ]
}
```
