## 概要

`/v1/files` で作成したファイルを削除します。Anthropic ヘッダーがない場合は、TokenLab のバッチファイルまたは紐付け済みの画像/参照ファイルを削除します。`anthropic-beta: files-api-2025-04-14` がある場合は、紐付いたワークスペースで Anthropic Files API モードを使います。

## 注意事項

- バッチファイルの削除では、保存済みのバッチファイル記録を削除し、その file ID を今後のバッチジョブで使えないようにします。
- 画像/参照ファイルの削除では、選択されたプロバイダーに削除を依頼し、受理後に TokenLab 側の紐付けを削除します。
- Anthropic Files API モードでは、アップロードや取得時と同じ Anthropic ネイティブヘッダーが必要です。

## 例

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseField name="id" type="string">削除されたファイル識別子。</ResponseField>
<ResponseField name="deleted" type="boolean">削除リクエストが成功したかどうか。</ResponseField>
