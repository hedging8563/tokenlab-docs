## 概要

`/v1/files` で作成したファイルを削除します。Batch ファイルと TokenLab 作成の画像参照ファイルは、OpenAI 互換の deleted オブジェクトを返します。

リクエストが Anthropic Files 互換モードを選ぶ場合、同じルートはバインドされたワークスペースから Anthropic スタイルのファイルを削除します。

## 注意事項

- ファイルを削除しても、そのファイルをすでに参照している Batch ジョブはキャンセルされません。
- 存在しない、または権限のない file id は、ルーティング状態を公開せず public な not-found エラーを返します。
- 画像参照ファイルは、保留中の画像編集リクエストが不要になってから削除してください。

## 例

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
