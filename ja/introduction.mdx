## TokenLabとは？

TokenLab は、1 つの API キーとワークスペース共通の残高で、アプリやコーディングツールを AI モデルに接続します。モデルと対応する API 形式を選び、公開料金に基づいて利用できます。

## 対応機能

最新のモデル ID、提供状況、対応形式、料金は[モデルカタログ](https://tokenlab.sh/ja/models)で確認してください。

| 機能 | 説明 |
|---|---|
| チャットと推論 | テキスト生成、計画、ツール利用 |
| ビジョンとマルチモーダル | 画像理解とマルチモーダルチャット |
| 画像生成と編集 | テキストから画像生成、画像編集 |
| 動画生成 | テキスト/画像/参照動画からの生成とモーション制御 |
| 音声と Realtime | TTS、文字起こし、翻訳、リアルタイムセッション |
| Embeddings と rerank | テキストベクトル化と再ランキング |
| 翻訳 | テキスト翻訳と WebSocket 音声翻訳ワークフロー |
| 音楽と 3D | 音楽と 3D アセット生成 |
| Worlds | World 生成、ステータスポーリング、メディアアセットフロー |
