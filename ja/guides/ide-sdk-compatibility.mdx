---
title: "ツールと SDK の互換性"
description: "開発ツール、チャットアプリ、SDK、フレームワークに適した TokenLab の設定を探す"
---

多くのツールは API キーとベース URL を変更することで TokenLab に接続できます。具体的な設定は、ツールが使用できる API 形式によって異なります。

| API 形式 | ベース URL | 主なクライアント |
| --- | --- | --- |
| Chat Completions (OpenAI 互換) | `https://api.tokenlab.sh/v1` | OpenAI SDK、多くのチャットアプリやフレームワーク |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | Responses クライアントと Responses イベントを利用するツール |
| Anthropic Messages | `https://api.tokenlab.sh` | Anthropic SDK と Claude 向けツール |
| Gemini | `https://api.tokenlab.sh` | カスタムホストを指定できる Gemini REST または SDK クライアント |

選択するモデルの `accepted_request_formats` に、使用する形式が含まれている必要があります。ストリーミングとツール呼び出しには、モデルの機能とクライアント側の対応も必要です。例は [API 形式](/ja/guides/api-formats)を参照してください。

## 互換性のラベル

| ラベル | 意味 |
| --- | --- |
| **利用可能** | リンク先の TokenLab 設定は、クライアントが公式に公開している設定項目を使用しています |
| **一部制限あり** | 設定は特定の機能や認証方式に適用されます。ベンダーのその他のサービスには、それぞれの利用条件が適用されます |

このラベルはリンク先の設定方法を示します。利用できる機能は、選択したモデルとクライアントのバージョンにも依存します。

## ストリーミング応答の使用量

Chat Completions のストリームは `stream_options: { include_usage: true }` を受け付け、終了前に使用量のチャンクを追加します。Responses API に `include_usage` はなく、Responses ストリームでは終了イベントに使用量が含まれます。

## カスタム API キーでは置き換えられないもの

一部の製品はモデル呼び出しに加え、ベンダーが提供するオンライン機能を備えています。TokenLab キーは BYOK 設定で公開されているモデルリクエストに使えますが、別のサブスクリプション、自動補完サービス、アカウント機能、独自拡張機能を置き換えるものではありません。

ツールの更新で設定方法が変わった場合は、古い環境変数の例をコピーせず、現在の連携ページを参照してください。

## 機能を利用する前の確認

- 必要な形式でカスタムのベース URL を指定できるか確認してください。
- モデルの `accepted_request_formats` にその形式が含まれているか確認してください。
- ワークフローに必要な場合は、ストリーミングとツール呼び出しを試してください。
- API キーは信頼できる端末またはサーバーに保管してください。
- 問題を報告する際はリクエスト ID を記録してください。
