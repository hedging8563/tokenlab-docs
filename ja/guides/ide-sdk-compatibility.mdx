## 概要

TokenLab は複数の API 形式を公開しているため、一般的なコーディングツール、SDK、フレームワークが最小限のグルーコードで統合可能です。

このページは、マーケティング用のマトリックスよりも意図的に範囲を絞っています。

- **Supported (サポート済み)**: 具体的なセットアップ手順が文書化されており、TokenLab がその手順で期待されるプロトコル形式を公開していることを意味します。
- **Strong native path (強力なネイティブパス)**: そのリポジトリが、当該プロトコルファミリーに対する直接的なアダプターやリクエスト形式のエビデンスを備えていることを意味します。
- **Best-effort (ベストエフォート)**: 統合は機能する可能性がありますが、アップストリームのクライアントがこのカスタムゲートウェイワークフローを安定したコントラクトとして扱っていないことを意味します。

<Note>
  サポートされていないフィールドは一律には処理されません。互換性ルートでは、一部のフィールドは無視されるか正規化されます。`/v1/responses` では、リクエストされた動作を保証できない場合、サポートされていないフィールドに対して明示的な `400` または `503` エラーが返されることがあります。
</Note>

## サポートされている API 形式

| エンドポイント | 形式 | ユースケース |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | ユニバーサルな互換性 |
| `/v1/responses` | OpenAI Responses | ステートフルな会話 |
| `/v1/messages` | Anthropic Messages | Claude ネイティブ機能 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini ネイティブ機能 |

## IDE & CLI の互換性

### 文書化されたツールパス

| ツール | サポートレベル | 形式 | 備考 |
|------|---------------|--------|-------|
| **Cursor** | 限定的にサポート | OpenAI 互換 | BYOK 標準チャット/エディタフローには対応していますが、Tab Completion のような Cursor 管理機能の代替としては機能しません |
| **Claude Code CLI** | 強力なネイティブパス | Anthropic | thinking および `tool_choice` のアダプターカバレッジを備えたネイティブな `/v1/messages` ルート |
| **Codex CLI** | モデル/パス制限付きでサポート | OpenAI Responses | `/v1/responses` を Codex 特有のワークフロー向けの高度なパスとして扱ってください。Responses 専用の一部のフィールドは、すべてのモデルやルーティングパスで保証されているわけではありません |
| **Gemini CLI** | ベストエフォート / 実験的 | Gemini | カスタム TokenLab ベース URL フローは、公式の Gemini CLI 統合ではありません |
| **OpenCode** | サポート済み | OpenAI 互換 | デフォルトでは OpenAI 互換プロバイダーを使用してください。明示的に必要な場合にのみ Responses ベースのプロバイダーに移行してください |
| **OpenHands** | サポート済み | OpenAI 互換 | `openai/<model>` と TokenLab の `/v1` ベース URL を使用して、LiteLLM/OpenAI 互換パスを使用してください |

<Note>
  他の OpenAI 互換エディタやエージェントツールも、同じベース URL パターンで動作することがよくあります。本番環境で使用する前に、そのツール独自のカスタムプロバイダーサポートを確認してください。
</Note>

<Tabs>

    - Anthropic 形式: `{ name, input_schema }` (type フィールドなし)

  </Tab>

## SDK の互換性

## Chat Completions パラメータ

### コアパラメータ

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `model` | string | モデル識別子 (必須) |
| `messages` | array | 会話メッセージ (必須) |
| `max_tokens` | integer | 最大出力トークン数 |
| `temperature` | number | サンプリング温度 (0-2) |
| `top_p` | number | 核サンプリング (0-1) |
| `stream` | boolean | ストリーミングの有効化 |

### ツール呼び出し

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### ツール選択オプション

| 形式 | 例 | 説明 |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | 単純な選択 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 特定の関数を強制 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic ネイティブ形式 |

### 高度なパラメータ

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `stream_options` | object | Chat Completions のみ: `{ include_usage: true }` でトークン数を取得 |
| `reasoning_effort` | string | 推論対応 GPT-5 モデル用の `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` または `"default"` |
| `seed` | integer | 決定論的な出力 |
| `logprobs` | boolean | ログ確率を返す |
| `top_logprobs` | integer | 上位ログ確率の数 (0-20) |
| `logit_bias` | object | トークンバイアスマップ (-100 ～ 100) |
| `frequency_penalty` | number | 繰り返しペナルティ (-2 ～ 2) |
| `presence_penalty` | number | トピックペナルティ (-2 ～ 2) |
| `stop` | string/array | 停止シーケンス |
| `n` | integer | 補完数 (1-128) |
| `user` | string | 追跡用のユーザー識別子 |

### OpenAI 高度な機能

| パラメータ | 型 | 説明 |
|-----------|------|-------------|
| `modalities` | array | マルチモーダル用の `["text", "audio"]` |
| `audio` | object | 音声出力設定 (音声、形式) |
| `prediction` | object | 高速補完のための予測出力 |
| `metadata` | object | 追跡用のキーバリューペア |
| `store` | boolean | 後で取得するために保存 |

### プロバイダー固有のオプション

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## ストリーミング

Chat Completions や Responses を含む `stream: true` を公開する生成エンドポイントは、Server-Sent Events (SSE) を使用します：

```bash
# Chat Completions
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# Chat Completions 使用状況追跡
-d '{"...", "stream_options": {"include_usage": true}}'
```

## エラーハンドリング

TokenLab は OpenAI 互換のエラーレスポンスを返します：

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

詳細は [Error Handling Guide](/guides/error-handling) を参照してください。

## ベストプラクティス

<AccordionGroup>
  <Accordion title="不明なパラメータにはパススルーを使用する">
    不明なパラメータは、選択されたパブリックルートとモデルがそれらをサポートしている場合にのみ転送されます。
  </Accordion>

  <Accordion title="stream_options.include_usage は Chat Completions にのみ使用する">
    Chat Completions のストリーミングでは、正確なトークン数のために `stream_options.include_usage` を有効にしてください。Responses には独自のストリーミングコントラクトがあり、この Chat 専用オプションは公開されていません。
  </Accordion>

  <Accordion title="適切な tool_choice 形式を使用する">
    SDK が期待する形式に合わせてください。TokenLab は OpenAI 形式と Anthropic 形式の両方を受け入れます。
  </Accordion>
</AccordionGroup>
