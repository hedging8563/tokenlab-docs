---

アプリケーションに Seedance 2.0 を追加する場合は、ここから始めてください。このページではモデルとワークフローの選択だけを扱い、Volcengine からの移行、再利用可能な素材、実在人物の認証は個別のガイドに分けています。

## 統合経路を選ぶ

| 目的 | 使用するもの | 次に読むページ |
| --- | --- | --- |
| TokenLab の新しいビデオ統合を構築する | 統一 `POST /v1/videos/generations` API | [ビデオ生成ガイド](/ja/guides/video-generation) |
| 既存の Volcengine Seedance クライアントを移行する | Volcengine 互換 REST または Action API | [Volcengine から Seedance を移行](/ja/guides/seedance-volcengine-migration) |
| アバター、商品、スタイル、実在人物の参照を再利用する | TokenLab 素材ライブラリ | [Seedance 素材と実在人物の認証](/ja/guides/seedance-materials) |

3 つの経路はいずれも `Authorization: Bearer <TOKENLAB_API_KEY>` を使用します。Volcengine 互換経路はリクエスト形式を維持しますが、AK/SK 署名には対応しません。

## モデルの選択

| モデル | サポートされている解像度 |
|-------|-----------------------|
| `seedance-2.0` | `480p`, `720p`, `1080p`, `4k` |
| `seedance-2.0-fast` | `480p`, `720p` |
| `seedance-2.0-mini` | `480p`, `720p` |

`seedance-2.0-fast` および `seedance-2.0-mini` は、`1080p` および `4k` のリクエストを拒否します。オーディオはサポートされているリファレンスワークフローでのみ使用可能です。純粋なオーディオのみ、またはテキストとオーディオのみのSeedanceリクエストはサポートされていません。

## サポートされている操作

| 操作 | 一般的な入力 |
|-----------|----------------|
| `text-to-video` | `prompt` |
| `image-to-video` | `prompt`, `image_url` または互換性のある画像入力 |
| `start-end-to-video` | `prompt`, `start_image`, `end_image` |
| `reference-to-video` | `prompt`, `reference_images`, オプションの `video_urls`, オプションの `audio_urls` |
| `video-to-video` | `prompt`, `video_url` または互換性のあるビデオ入力 |
| `video-extension` | `task_id` またはモデル固有の継続入力 |

## 料金と非同期結果

Seedance 2.0の料金は、出力解像度、入力タイプ、およびモデルによって異なります。製品のUIにハードコードする前に、[Pricing API](/ja/api-reference/pricing/get-pricing) または [Models API](/ja/api-reference/models/list-models) を使用してください。

ビデオ生成は非同期で行われます。作成リクエストによって返された `poll_url` を追跡するか、返されたタスクIDを使用して [タスクのステータスを取得](/ja/api-reference/tasks/get-task-status) を使用してください。
