TokenLab の残高は複数のモデルで共通です。サブスクリプションや最低利用額はなく、モデルと記録された利用量に応じて課金されます。

## 価格と配信オプション

現在の価格はモデルページ、`GET /v1/models/{model}/pricing`、Pricing API で確認してください。価格表を固定値にしないでください。テキストや埋め込みは入力・出力・キャッシュのトークン、メディアは画像、秒、分、リクエスト、タスクなどが単位になります。

`TokenLab Verified` は TokenLab 公開価格、`Official` はモデル提供元の公開価格に基づく Official 価格を使います。`Auto` は Verified を優先し、必要に応じて Official を使い、結果を提供した選択肢で一度だけ課金します。Console は有料生成の確認前に最大見積もり、完了後に Runs と Usage で最終額を表示します。

[Pricing API](/ja/api-reference/pricing/get-pricing)

## 非同期の請求と記録

一部のタスクは作成時に推定額を確保します。タスク ID と `poll_url` を保存し、`completed` または `failed` まで確認します。成功したタスクは一度だけ課金され、未使用の確保額は解放されます。失敗したタスクでは保留額を解放または返金します。

非ストリーミングの OpenAI 互換応答は、請求完了後に `billing_transaction_id` や `X-Billing-Transaction-ID` を返す場合があります。ネイティブ形式はヘッダーのみの場合もあります。非同期やストリーミングの結果は請求記録より先に届くことがあるため、値がなければ Usage を確認します。

Usage でモデル、キー、費用、利用量を確認します。トークン化はモデル、言語、メディアで異なり、文字数による概算は請求額の代わりにはなりません。ストリーミングでも課金トークンは減りません。同じタスクの最終費用を比較し、対応する出力上限を設定してください。

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Console の操作

Console → Billing で金額と表示される支払方法を選びます。決済サービスの確認後に残高が更新されます。

Console → API Keys でキーの作成・編集時に支出上限を設定できます。上限到達時は `402 Payment Required` が返ります。

Console → Settings で残高通知のしきい値を設定できます。請求の問い合わせは Request ID とタスク ID を添えて support@tokenlab.sh へ。API キーは送らないでください。
