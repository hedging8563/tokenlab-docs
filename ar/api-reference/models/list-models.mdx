---
title: "سرد النماذج"
openapi: "GET /v1/models"
description: "سرد النماذج المتاحة حالياً على TokenLab"
---

كتالوج النماذج متاح للعامة ولا يتطلب API key. يتضمن كل عنصر ملخصاً للقدرات الحالية، والأسعار، وتنسيقات API. يمكنك استرداد نموذج واحد عندما تحتاج إلى تفاصيل كاملة.

## معلمات الاستعلام (Query Parameters)

<ParamField query="category" type="string">
  التصفية حسب `chat` أو `image` أو `video` أو `audio` أو `tts` أو `stt` أو `music` أو `3d` أو `embedding` أو `rerank` أو `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  إرجاع التوصيات الحالية لمهمة معينة مثل `image` أو `video` أو `music` أو `3d` أو `tts` أو `stt` أو `embedding` أو `rerank` أو `translation`.
</ParamField>

<ParamField query="provider" type="string">
  التصفية حسب الجهة المصنعة للنموذج، مثل `openai` أو `anthropic` أو `google` أو `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  التصفية حسب وسم (tag) مثل `chat` أو `image` أو `video` أو `embedding` أو `translation`.
</ParamField>

## الاستجابة (Response)

<ResponseField name="object" type="string">دائماً `list`.</ResponseField>
<ResponseField name="data" type="array">النماذج مع `id` و `owned_by` وملخص `tokenlab`.</ResponseField>

تشمل حقول القائمة الشائعة تحت `tokenlab` ما يلي:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` و `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` و `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle` و `tokenlab.commercial` و `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` عند استخدام `recommended_for`

عند استخدام `recommended_for`، قد تتضمن النتائج أيضاً حالة التوصية ووقت التحديث. يرجى قراءة الاستجابة الحالية بدلاً من تثبيت الترتيب.

## مثال

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```

راجع [الحصول على نموذج](/api-reference/models/get-model) للحصول على التفاصيل الكاملة.
