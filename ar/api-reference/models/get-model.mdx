## معامل المسار (Path Parameter)

<ParamField path="model" type="string" required>
  معرف النموذج (Model ID)، مثل `gpt-5.6-terra` أو `claude-sonnet-4-6`.
</ParamField>

## الاستجابة (Response)

<ResponseField name="id" type="string">معرف النموذج.</ResponseField>
<ResponseField name="object" type="string">دائماً `model`.</ResponseField>
<ResponseField name="owned_by" type="string">الجهة المصنعة للنموذج.</ResponseField>
<ResponseField name="tokenlab" type="object">
  معلومات نموذج TokenLab، بما في ذلك القدرات، والأسعار، ووحدات الفوترة، وحدود السياق، وتنسيقات الـ API المقبولة، والعمليات، وحالة دورة حياة النموذج.
</ResponseField>

تشمل حقول `tokenlab` الشائعة ما يلي:

- `capabilities`: النص، والصورة، والفيديو، والصوت، والقدرات الأخرى.
- `pricing`: الأسعار العامة الحالية.
- `max_input_tokens` و `max_output_tokens`: حدود السياق والمخرجات.
- `accepted_request_formats`: تنسيقات الـ API المدعومة.
- `supported_operations`: عمليات مثل تحويل النص إلى صورة أو تحويل الصورة إلى فيديو.
- `lifecycle`: التوفر، وتاريخ الإصدار، وتاريخ الإيقاف، أو النموذج البديل.

تتضمن بعض نماذج الوسائط أيضاً حالة التوصية ووقت التحديث. يمكن أن تتغير التوصيات بناءً على التوفر والأداء، لذا لا تقم ببرمجة ترتيبها بشكل ثابت (hard-code).

## مثال

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.6-terra"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["coding", "json-mode", "prompt-cache", "reasoning", "tool-use", "vision"],
    "accepted_request_formats": ["openai_chat_completions", "openai_responses"]
  }
}
```

النموذج غير المعروف يُرجع `404 model_not_found`.
