استرجع مجموعة مواد واحدة. يوضح لك `library_type` ما إذا كانت المجموعة عبارة عن مجموعة صور رمزية افتراضية (virtual-avatar) أو مجموعة أشخاص حقيقيين (real-person).

استخدم نقطة النهاية (endpoint) هذه قبل الرفع إذا كنت بحاجة إلى التأكد من أن المجموعة لا تزال موجودة وأن حالتها `status: "ACTIVE"`.

يعزل `project_name` الموارد داخل المؤسسة المصادق عليها. قيمته الافتراضية `default`؛ استخدم القيمة نفسها مع مراعاة حالة الأحرف للمجموعات والأصول المرتبطة. أرسله في جسم JSON مع POST/PUT وفي معاملات الاستعلام مع GET/DELETE.

## مثال على الطلب

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## مثال على الاستجابة

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
