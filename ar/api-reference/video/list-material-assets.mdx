قم بسرد أصول المواد المملوكة للمؤسسة التي تم التحقق من هويتها. يمكنك التصفية باستخدام `library_type` أو `group_id` أو `status` عندما تحتاج إلى العثور على أصول لسير عمل إنشاء معين.

استخدم فقط الأصول التي تكون حالة `status` الخاصة بها `ACTIVE`. عند إنشاء الفيديوهات، استخدم `id` الخاص بأصل مادة TokenLab الذي تم إرجاعه.

يعزل `project_name` الموارد داخل المؤسسة المصادق عليها. قيمته الافتراضية `default`؛ استخدم القيمة نفسها مع مراعاة حالة الأحرف للمجموعات والأصول المرتبطة. أرسله في جسم JSON مع POST/PUT وفي معاملات الاستعلام مع GET/DELETE.

## مثال على الطلب

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
