## نظرة عامة

اطلب الإلغاء باستخدام مفتاح TokenLab Bearer API والمعرّف `cgt-...`. يُحاول الإلغاء قدر الإمكان ولا ينجح إلا إذا كانت المهمة لا تزال قابلة للإلغاء.

انظر أيضا [نماذج فيديو Seedance 2.0](/ar/guides/seedance-2-video) و [توليد الفيديو](/ar/guides/video-generation).

## شكل الاستجابة

يعيد طلب الإلغاء الناجح HTTP 200 مع جسم فارغ. استعلم عن المهمة بعد ذلك إذا احتجت إلى تأكيد الحالة النهائية.

إذا اكتملت المهمة أو فشلت أو انتهت صلاحيتها أو لم تعد قابلة للإلغاء، تُرجع نقطة النهاية خطأ. استعلم عن المهمة لتأكيد حالتها. لا تحتوي المهمة الملغاة على نتيجة فيديو.

## مثال

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
