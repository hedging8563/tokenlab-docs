## معلمات المسار

<ParamField path="id" type="string" required>
  معرّف المهمة المُعاد من طلب إنشاء الفيديو. اعتبر `id` و `task_id` نفس الهوية غير المتزامنة.
</ParamField>

<Info>
إذا أعادت استجابة الإنشاء قيمة `poll_url`، فاستدعِ ذلك العنوان بالضبط. عندما يشير إلى `/v1/tasks/{id}`، اعتبره نقطة النهاية الأساسية الثابتة لحالة المهمة.

قد تعيد المهمة العامة المنتهية أو غير المتاحة `404 async_task_not_found`. إذا تعذر إثبات ملكية المهمة لمفتاح API الحالي، تكون الاستجابة `403 task_not_owned`.
</Info>

## الاستجابة

<Note>
تُعاد حقول النتائج والأخطاء والطوابع الزمنية والنموذج عند توفرها للمهمة.
</Note>

<ResponseField name="id" type="string">
  المعرّف الرسمي للمهمة غير المتزامنة.
</ResponseField>

<ResponseField name="task_id" type="string">
  الاسم المستعار لمعرّف المهمة غير المتزامنة.
</ResponseField>

<ResponseField name="poll_url" type="string">
  عنوان URL المفضل للاستعلام المتكرر عندما توفر استجابة الإنشاء واحدًا.
</ResponseField>

<ResponseField name="billing_transaction_id" type="string">
  معرّف معاملة الفوترة في TokenLab عندما تكون التسوية قد اكتملت بالفعل. هذا هو معرّف المعاملة المستخدم في لوحة التحكم / المطابقة، وهو منفصل عن `id` / `task_id` غير المتزامن.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة: `pending`, `processing`, `completed`, `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  قيمة تقدم اختيارية. لا تُعاد إلا عند توفر قيمة تقدم حقيقية؛ استخدم `status` لتحديد اكتمال المهمة.
</ResponseField>

<ResponseField name="video_url" type="string">
  عنوان URL للفيديو الناتج (عند الاكتمال).
</ResponseField>

<ResponseField name="video" type="object">
  حمولة فيديو مفردة تحتوي على الحقول `url`, `duration`, `width`, و `height` عندما تتوفر.
</ResponseField>

<ResponseField name="videos" type="array">
  حمولات فيديو متعددة عندما تعيد مهمة التوليد أكثر من مخرج واحد.
</ResponseField>

<ResponseField name="error" type="string | object">
  رسالة الخطأ (إذا فشلت).
</ResponseField>

<ResponseField name="created" type="integer">
  طابع زمني للإنشاء.
</ResponseField>

<ResponseField name="updated" type="integer">
  طابع زمني لآخر تحديث.
</ResponseField>

<ResponseField name="model" type="string">
  النموذج المستخدم للمهمة.
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )

    response.raise_for_status()
    data = response.json()
    print(f"Status: {data['status']}")

    if data["status"] == "completed":
        print(f"Video URL: {data['video_url']}")
        break
    elif data["status"] == "failed":
        print(f"Error: {data['error']}")
        break

    time.sleep(5)  # Poll every 5 seconds
```

const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForVideo() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(`HTTP ${response.status}: ${await response.text()}`);
    const data = await response.json();
    console.log(`Status: ${data.status}`);

    if (data.status === 'completed') {
      console.log(`Video URL: ${data.video_url}`);
      return data.video_url;
    } else if (data.status === 'failed') {
      throw new Error(data.error);
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

## أفضل ممارسات الاستطلاع

- استعلم كل 5-10 ثوانٍ
- طبّق آلية تراجع أُسِّي (exponential backoff) للمهام الطويلة
- حدد مهلة قصوى (مثلاً، 10 دقائق)
- تعامل مع الحالة `failed` بشكل ملائم

```python
import requests
import time

def wait_for_video(task_id, max_wait=600, interval=5):
    """Wait for video with timeout."""
    start = time.time()

    while time.time() - start < max_wait:
        response = requests.get(
            f"https://api.tokenlab.sh/v1/tasks/{task_id}",
            headers={"Authorization": "Bearer sk-your-api-key"}
        )
        response.raise_for_status()
        data = response.json()

        if data["status"] == "completed":
            return data["video_url"]
        elif data["status"] == "failed":
            raise Exception(data.get("error", "Video generation failed"))

        time.sleep(interval)

    raise TimeoutError("Video generation timed out")
```
