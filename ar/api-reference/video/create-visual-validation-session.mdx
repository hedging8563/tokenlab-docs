أنشئ جلسة تحقق مرئي قبل رفع مواد `liveness_face` القابلة لإعادة الاستخدام. يستخدم TokenLab تنسيق Action API من Volc ومصادقة Bearer الخاصة بـ TokenLab.

استخدم المؤسسة المصادق عليها والمستخدم و`ProjectName` نفسها التي أنشأت الجلسة، مع مراعاة حالة الأحرف.

افتح `Result.H5Link` فور إنشاء الجلسة. قد تنتهي مهلة الفتح الأول لصفحة H5 قبل مدة صلاحية `BytedToken` البالغة 30 دقيقة.

## نقطة النهاية والمصادقة

```text
POST https://api.tokenlab.sh/api/v3?Action=CreateVisualValidateSession&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

لا تُقبل توقيعات AK/SK من Volc. الحقل `CallbackURL` مطلوب ويجب أن يكون عنوان HTTPS عامًا. الحقل `ProjectName` اختياري وقيمته الافتراضية `default`.

## التدفق

1. احفظ `Result.BytedToken` وافتح `Result.H5Link` للشخص المراد التحقق منه.
2. لاختيار لغة H5، أضف `lng` إلى `H5Link`، مثل `&lng=en`. اللغة ليست حقلاً في نص الطلب.
3. بعد اكتمال تدفق H5، يفتح المتصفح `Result.CallbackURL`. قد يتضمن استعلام callback القيم `bytedToken` و`resultCode` و`algorithmBaseRespCode` و`reqMeasureInfoValue` و`verify_type`.
4. استعلم دوريًا عن [الحصول على نتيجة التحقق المرئي](/ar/api-reference/video/get-visual-validation-result) باستخدام `BytedToken` المحفوظ حتى تُعاد `Result.GroupId`.

تظل `BytedToken` صالحة لمدة 30 دقيقة وترتبط بالمؤسسة المصادق عليها وبـ `ProjectName`. يسمح رابط H5 بإكمال تحقق واحد فقط ويصبح غير صالح بعد الاستخدام.

تعامل مع `Result.H5Link` كعنوان متصفح غير شفاف: افتحه كصفحة من المستوى الأعلى، ولا تحلله أو تفك ترميزه أو تعيد كتابته أو تضمّنه. تتولى TokenLab تسليم المتصفح وجسر callback.

## مثال على الطلب

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=CreateVisualValidateSession&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"CallbackURL":"https://yourapp.example.com/seedance/callback","ProjectName":"default"}'
```

## مثال على الاستجابة

```json
{
  "ResponseMetadata": {
    "RequestId": "req_abc123",
    "Action": "CreateVisualValidateSession",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "BytedToken": "ZXhhbXBsZS10b2tlbg",
    "H5Link": "https://api.tokenlab.sh/api/v3/visual-validation/sessions/svv_example/h5?Version=2024-01-01",
    "CallbackURL": "https://yourapp.example.com/seedance/callback"
  }
}
```

تستخدم الأخطاء البنية العليا نفسها. اقرأ `ResponseMetadata.Error.Code` و`ResponseMetadata.Error.Message` بدل توقع حقول الأخطاء في واجهات TokenLab الأخرى ضمن `/v1`.
