قم بتحديث اسم العرض أو الوصف أو البيانات الوصفية (metadata) لمجموعة مواد. بالنسبة للمجموعات المدارة لأشخاص حقيقيين، يظل تعيين الشخص الموثق دون تغيير.

يعزل `project_name` الموارد داخل المؤسسة المصادق عليها. قيمته الافتراضية `default`؛ استخدم القيمة نفسها مع مراعاة حالة الأحرف للمجموعات والأصول المرتبطة. أرسله في جسم JSON مع POST/PUT وفي معاملات الاستعلام مع GET/DELETE.

## مثال على الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos","project_name":"default"}'
```

## مثال على الاستجابة

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
