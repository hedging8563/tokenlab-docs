---
title: "إنشاء الموسيقى"
openapi: "POST /v1/music/generations"
description: "إنشاء مهمة توليد موسيقى باستخدام Suno"
---

قم بتوليد الموسيقى والكلمات باستخدام الذكاء الاصطناعي. هذه API غير متزامنة. تعيد استجابة الإنشاء هوية المهمة، وقد تتضمن أيضًا `poll_url` مفضلًا عند توفره.

## جسم الطلب

<ParamField body="model" type="string" default="suno_music">
  معرّف نموذج الموسيقى، مثل `suno-music`. للكلمات فقط، اختر نموذجًا تتضمن عملياته العامة الحالية `lyrics`.
</ParamField>

<ParamField body="prompt" type="string">
  وصف الموسيقى أو النص البديل. مطلوب للموسيقى والكلمات وupload-cover وupload-extend وreplace-section؛ واختياري مع add-instrumental وفصل المسارات.
</ParamField>

<ParamField body="title" type="string">
  عنوان الأغنية التي تم توليدها.
</ParamField>

<ParamField body="tags" type="string">
  علامات النمط (مثل: "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  الأنماط المطلوب تجنبها. مطلوب عندما تكون `audio_operation` هي `add-instrumental`.
</ParamField>

<ParamField body="action" type="string">
  قيمة اختيارية `MUSIC` أو `LYRICS`. اختر نموذجًا يدعم العملية العامة المقابلة؛ لا يضيف هذا الحقل توليد الكلمات إلى نموذج مخصص للموسيقى فقط.
</ParamField>

<ParamField body="mv" type="string">
  محدد إصدار Suno. مطلوب للتوليد وupload-cover وupload-extend وadd-instrumental والاستبدال من `audio_url`. احذفه لطلبات الكلمات والاستبدال من `task_id` + `audio_id` وفصل المسارات. القيم المقبولة: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  اضبطه على `true` لإنشاء نتيجة موسيقية بلا غناء.
</ParamField>

<ParamField body="audio_url" type="string">
  رابط صوت مرجعي أو مرفوع يمكن الوصول إليه علناً. عند إرساله من دون `audio_operation` يستخدم TokenLab تدفق upload-cover.
</ParamField>

<ParamField body="audio_operation" type="string">
  عملية الصوت: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  تتطلب `vocal-separate` و`multi-stem-separation` و`advanced-split` الحقلين `task_id` + `audio_id`؛ وتتطلب `advanced-split` أيضًا `stem_name`. تتطلب `upload-extend` قيمة `continue_at` أكبر من 0. وتتطلب `add-instrumental` الحقول `audio_url` و`title` و`tags` و`negative_tags`.

  تتطلب `replace-section` الحقول `prompt` و`tags` و`title` و`infill_start_s` و`infill_end_s` و`full_lyrics`. اختر مصدرًا واحدًا فقط: `task_id` + `audio_id`، أو `audio_url` + `mv`. يجب أن تتراوح فترة الاستبدال بين 6 و60 ثانية.
</ParamField>

<ParamField body="task_id" type="string">
  معرّف مهمة مصدر تملكها مؤسستك، لاستبدال الصوت المولّد أو فصل المسارات.
</ParamField>

<ParamField body="audio_id" type="string">
  معرّف الصوت الوارد في نتيجة مهمة المصدر. مطلوب مع `task_id` لاستبدال الصوت المولّد وفصل المسارات.
</ParamField>

<ParamField body="infill_start_s" type="number">
  بداية الاستبدال بالثواني، لا تقل عن 0. مطلوبة لـ `replace-section`.
</ParamField>

<ParamField body="infill_end_s" type="number">
  نهاية الاستبدال بالثواني. مطلوبة لـ `replace-section`، ويجب أن تأتي بعد `infill_start_s` بفترة من 6 إلى 60 ثانية.
</ParamField>

<ParamField body="full_lyrics" type="string">
  الكلمات الكاملة للأغنية الناتجة. مطلوبة لـ `replace-section`.
</ParamField>

<ParamField body="stem_name" type="string">
  اسم المسار. مطلوب لـ `advanced-split`.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  معرف (ID) لمقطع سابق للمتابعة منه.
</ParamField>

<ParamField body="continue_at" type="number">
  موضع المتابعة بالثواني. مطلوب وأكبر من 0 مع `upload-extend`.
</ParamField>

<Note>
الحد الأقصى لـ `prompt` هو 5000 حرف، ولكل من `tags` و`negative_tags` هو 1000 حرف. تعتمد العمليات والمعلمات المدعومة على تفاصيل النموذج الحالية.
</Note>

## الاستجابة

<ResponseField name="id" type="string">
  معرف المهمة (Task ID) للاستعلام عن الحالة.
</ResponseField>

<ResponseField name="task_id" type="string">
  اسم بديل لمعرّف المهمة غير المتزامنة نفسه، عند إرجاعه.
</ResponseField>

<ResponseField name="poll_url" type="string">
  رابط polling المفضّل عندما يكون متاحًا.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة: `pending` أو `processing` أو `completed` أو `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  طابع Unix الزمني لإنشاء المهمة، عند إرجاعه.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
