استعلم دورياً (Poll) عن نقطة النهاية هذه للتحقق من حالة مهمة إنشاء الموسيقى الخاصة بك.

<Info>
إذا تضمنت استجابة الإنشاء `poll_url`، فامنح الأفضلية لهذا الرابط الدقيق عند إجراء polling. يجب التعامل مع `id` و`task_id` على أنهما هوية المهمة غير المتزامنة نفسها.


قد تعيد المهمة العامة المنتهية أو غير المتاحة `404 async_task_not_found`. إذا تعذر إثبات ملكية المهمة لمفتاح API الحالي، تكون الاستجابة `403 task_not_owned`.
</Info>

## معلمات المسار

<ParamField path="id" type="string" required>
  معرف (ID) مهمة إنشاء الموسيقى.
</ParamField>

## الاستجابة (Response)

<ResponseField name="id" type="string">
  معرف المهمة.
</ResponseField>

<ResponseField name="task_id" type="string">
  اسم بديل لمعرّف المهمة غير المتزامنة نفسه، عند إرجاعه.
</ResponseField>

<ResponseField name="poll_url" type="string">
  عنوان URL المفضل للاستعلام عند توفيره في استجابة الإنشاء.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة: `pending` أو `processing` أو `completed` أو `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  قيمة تقدم اختيارية. لا تُعاد إلا عند توفر قيمة تقدم حقيقية؛ استخدم `status` لتحديد اكتمال المهمة.
</ResponseField>

تعتمد حقول النتيجة على العملية. قد تعيد الموسيقى `audio_url` و`audio_id`، وتعيد مهام الكلمات `lyrics`، وقد يعيد الفصل عدة ملفات في `data`. الحقول `video_url` والعنوان والتقدم وغيرها اختيارية. تحقق من الاكتمال عبر `status` واقرأ الحقول التي أُعيدت فعليًا.

<ResponseField name="audio_id" type="string">
  معرّف صوت اختياري يمكن استخدامه مع معرّف هذه المهمة في عمليات المتابعة المدعومة.
</ResponseField>

<ResponseField name="data" type="array">
  مصفوفة مخرجات اختيارية، تشمل ملفات المسارات المفصولة مع `audio_url` أو `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  رابط (URL) لتنزيل ملف الصوت (عند الاكتمال).
</ResponseField>

<ResponseField name="video_url" type="string">
  رابط (URL) لنسخة الفيديو مع المصور المرئي (عند الاكتمال).
</ResponseField>

<ResponseField name="title" type="string">
  عنوان الأغنية المنشأة.
</ResponseField>

<ResponseField name="lyrics" type="string">
  كلمات الأغنية المنشأة أو المقدمة.
</ResponseField>

<ResponseField name="error" type="string | object">
  رسالة الخطأ (عند الفشل).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
