## نظرة عامة

يخدم هذا الـ endpoint أساسًا واجهة TokenLab المتوافقة مع OpenAI Batch API، بما في ذلك مدخلات الدفعات المرفوعة وملفات الإخراج أو الخطأ المُنشأة.

عندما يفعّل الطلب وضع التوافق مع Anthropic Files، يمكن لنفس المسار أيضًا عرض ملفات على نمط Anthropic المتاحة لمساحة العمل المرتبطة.


بدون ترويسات Anthropic، يمكن أن تتضمن القائمة ملفات دفعات وملفات صور/مراجع من TokenLab. استخدم `purpose=batch` أو `purpose=batch_output` أو `purpose=user_data` أو `purpose=vision` لتضييق القائمة.
## ملاحظات

- يجب أن تستخدم ملفات إدخال الدفعة `purpose=batch`.
- استخدم `purpose=batch_output` للتركيز على ملفات الإخراج المنشأة.
- `completion_window` حاليًا `24h`.
- ترتيب الإخراج غير مضمون؛ طابِق دائمًا بواسطة `custom_id`.
- لا يدعم هذا المسار البث داخل عناصر الدفعة.

## مثال

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files?purpose=batch&limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## الطلب / الاستجابة

استخدم لوحة OpenAPI التفاعلية أعلاه للحصول على المخطط الدقيق.

## نصائح تشغيلية

- استخدم `custom_id` للمصالحة اللاحقة غير المتكررة.
- توقّع `output_file_id` و `error_file_id` فقط بعد انتهاء العامل من الدفعة.
- قد تختلف أسعار الدفعات عن الأسعار المتزامنة لأن قواعد الخصم `isBatchRequest=true` تنطبق.

## مثال الاستجابة

<ResponseExample>

</ResponseExample>
