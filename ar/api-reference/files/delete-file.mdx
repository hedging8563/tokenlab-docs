## نظرة عامة

يحذف ملفًا أُنشئ عبر `/v1/files`. ترجع ملفات Batch وملفات مراجع الصور التي أنشأتها TokenLab كائن deleted متوافقًا مع OpenAI.

عندما يستخدم الطلب وضع التوافق مع Anthropic Files، يحذف المسار نفسه الملف بنمط Anthropic من مساحة العمل المرتبطة.

## ملاحظات

- حذف ملف لا يلغي مهام Batch التي تشير إليه مسبقًا.
- تعيد file ids المفقودة أو غير المصرح بها خطأ not-found عامًا دون كشف حالة التوجيه.
- احذف ملفات مراجع الصور فقط بعد أن لا تعود أي طلبات تحرير صور معلقة بحاجة إليها.

## مثال

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
