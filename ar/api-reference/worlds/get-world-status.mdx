استخدم polling لهذا endpoint للتحقق من حالة مهمة توليد World Labs Marble. إذا تضمنت استجابة الإنشاء `poll_url`، فاستخدم هذا الرابط كما هو.

<Info>
قد تعيد المهمة العامة المنتهية أو غير المتاحة `404 async_task_not_found`. إذا تعذر إثبات ملكية المهمة لمفتاح API الحالي، تكون الاستجابة `403 task_not_owned`.
</Info>

## معلمات المسار

<ParamField path="id" type="string" required>
  معرف مهمة توليد العالم.
</ParamField>

## الاستجابة

الحقول المطلوبة في استجابة الحالة الناجحة هي `id` و`status` فقط. تُعاد أسماء المهمة البديلة ومعرّفات العملية وموارد العالم والأوصاف والتكلفة والحقل النصي `error` عند توفرها. اكتمال المهمة لا يضمن وجود كل روابط الموارد.

<ResponseField name="id" type="string">
  معرف مهمة عام.
</ResponseField>

<ResponseField name="task_id" type="string">
  اسم بديل لمعرف المهمة غير المتزامنة.
</ResponseField>

<ResponseField name="operation_id" type="string">
  معرّف العملية في خدمة World Labs المصدرية.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة: `pending` أو `processing` أو `completed` أو `failed` أو `timeout`.
</ResponseField>

<ResponseField name="world_id" type="string">
  معرّف العالم في خدمة World Labs المصدرية عند الاكتمال.
</ResponseField>

<ResponseField name="world_marble_url" type="string">
  رابط عالم Marble الناتج عند الاكتمال.
</ResponseField>

<ResponseField name="model_url" type="string">
  اسم بديل لرابط العالم/النموذج الأساسي الناتج.
</ResponseField>

<ResponseField name="glb_url" type="string">
  رابط GLB لشبكة collider عند توفره.
</ResponseField>

<ResponseField name="pano_url" type="string">
  رابط صورة بانورامية عند توفرها.
</ResponseField>

<ResponseField name="thumbnail_url" type="string">
  رابط صورة مصغرة عند توفره.
</ResponseField>

<ResponseField name="caption" type="string">
  Caption من upstream للعالم الناتج.
</ResponseField>

<ResponseField name="cost" type="object">
  تفاصيل تكلفة التوليد عند توفرها، بما فيها `total_credits`. راجع سجلات الاستخدام لمعرفة المبلغ المفوتر.
</ResponseField>

<ResponseField name="error" type="string">
  رسالة الخطأ عند فشل المهمة.
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/worlds/generations/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"},
    )
    response.raise_for_status()
    result = response.json()
    if result["status"] in ["completed", "failed", "timeout"]:
        print(result)
        break
    time.sleep(10)
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
const response = await fetch(`https://api.tokenlab.sh/v1/worlds/generations/${taskId}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' }
});

if (!response.ok) throw new Error(await response.text());
const result = await response.json();
console.log(result);
```
