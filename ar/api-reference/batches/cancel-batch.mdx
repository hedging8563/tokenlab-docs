---
title: "إلغاء الدفعة"
openapi: "/openapi/ar.json POST /v1/batches/{batch_id}/cancel"
description: "يلغي مهمة دفعة متوقفة أو قيد التشغيل."
---

اطلب إلغاء دفعة في قائمة الانتظار أو قيد التشغيل. تتضمن الاستجابة حالتها الحالية؛ فقد يكون الإلغاء جاريًا أو قد اكتمل بالفعل. تحتفظ الدفعة المنتهية بحالتها النهائية السابقة. إذا لم تكن الحالة المعادة نهائية، فاسترجع الدفعة مرة أخرى للتحقق من النتيجة.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">معرّف لاستخدامه في الطلبات اللاحقة والدعم.</ResponseField>
<ResponseField name="status" type="string">الحالة الحالية للدفعة. لا تعني استجابة الإلغاء الناجحة أن الحالة المعادة هي دائمًا `cancelling`.</ResponseField>
