---

## نظرة عامة

استخدم نقطة النهاية هذه للاستطلاع غير المتزامن الموحّد عبر أنواع المهام مثل إنشاء الفيديو والصورة والموسيقى و3D.

إذا كانت استجابة الإنشاء تتضمن `poll_url`، فاستدعِ ذلك المسار نفسه تمامًا. بالنسبة لسير العمل غير المتزامن الأحدث، قد يشير `poll_url` إلى `/v1/tasks/{id}`.

## معاملات المسار

<ParamField path="id" type="string" required>
  معرّف المهمة المُعاد من طلب الإنشاء.
</ParamField>

## الاستجابة

<Note>
تُعاد حقول النتائج والأخطاء والطوابع الزمنية والنموذج عند توفرها للمهمة.
</Note>

<ResponseField name="id" type="string">
  معرّف المهمة.
</ResponseField>

<ResponseField name="task_id" type="string">
  اسم مستعار لمعرّف المهمة غير المتزامنة.
</ResponseField>

<ResponseField name="poll_url" type="string">
  عنوان URL المفضل للاستعلام عندما توفره استجابة الإنشاء.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة مثل `pending` أو `processing` أو `completed` أو `failed`. يتم تمثيل المهام الملغاة كـ `failed` مع `cancelled: true`.
</ResponseField>

<ResponseField name="cancelled" type="boolean">
  `true` عندما يتم إلغاء مهمة غير متزامنة في قائمة الانتظار قبل التنفيذ.
</ResponseField>

<ResponseField name="cancellation_status" type="string">
  مؤشر الإلغاء. يظهر كـ `cancelled` عند نجاح الإلغاء.
</ResponseField>

<ResponseField name="data" type="array">
  بالنسبة لمهام الصور المكتملة، تُعاد نتائج الصور التي تم إنشاؤها هنا. تعيد مهام الصور روابط URL في `data[].url`.
</ResponseField>

<ResponseField name="progress" type="number">
  قيمة تقدم اختيارية. لا تُعاد إلا عند توفر قيمة تقدم حقيقية؛ استخدم `status` لتحديد اكتمال المهمة.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL الأصل الناتج عند اكتمال المهمة وإنتاج فيديو.
</ResponseField>

<ResponseField name="video" type="object">
  حمولة فيديو مفردة تحتوي على الحقول `url`, `duration`, `width`, و `height` عندما تتوفر.
</ResponseField>

<ResponseField name="videos" type="array">
  حمولات فيديو متعددة عندما تعيد مهمة التوليد أكثر من مخرج واحد.
</ResponseField>

<ResponseField name="created" type="integer">
  طابع زمني للإنشاء.
</ResponseField>

<ResponseField name="updated" type="integer">
  طابع زمني لآخر تحديث.
</ResponseField>

<ResponseField name="model" type="string">
  النموذج المستخدم للمهمة.
</ResponseField>

<ResponseField name="error" type="string | object">
  رسالة الخطأ عند فشل المهمة.
</ResponseField>

## سلوك الخطأ

قد تعيد المهمة العامة المنتهية أو غير المتاحة `404 async_task_not_found`. إذا تعذر إثبات ملكية المهمة لمفتاح API الحالي، تكون الاستجابة `403 task_not_owned`.

```json
{
  "error": {
    "message": "Task not found or no longer available.",
    "type": "invalid_request_error",
    "code": "async_task_not_found"
  }
}
```

## أمثلة

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

```python Python
import requests

poll_url = "/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
response = requests.get(
    f"https://api.tokenlab.sh{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
const response = await fetch(`https://api.tokenlab.sh${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
