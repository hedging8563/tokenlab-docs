## نظرة عامة

يعيد مفاتيح API الخاصة بالمستخدم في المؤسسة المرتبطة برمز الإدارة الحالي.

## ملاحظات

- تدعم حقول المبالغ المالية الدولار الأمريكي فقط.

- يتم استبعاد المفاتيح التي يديرها النظام.

## مثال

<ParamField query="page" type="integer" default="1">رقم الصفحة بدءًا من 1.</ParamField>
<ParamField query="limit" type="integer" default="50">حجم الصفحة من 1 إلى 100.</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## الطلب / الاستجابة

توفّر هذه الصفحة مخطط OpenAPI وأمثلة طلبات قابلة للنسخ. أرسل طلبات الإدارة من الطرفية أو برنامج العميل باستخدام Management Token؛ لا يتوفر الإرسال المباشر من هذه الصفحة.

## الحقول المهمة

<ResponseField name="object" type="string">القيمة دائمًا `list`.</ResponseField>
<ResponseField name="data" type="array">مصفوفة من كائنات مفاتيح API.</ResponseField>
<ResponseField name="pagination" type="object">بيانات وصفية لترقيم الصفحات تتضمن `page` و`limit` و`total` و`totalPages`.</ResponseField>
<ResponseField name="data[].id" type="string">معرّف مفتاح API المستخدم في استدعاءات واجهة API للإدارة اللاحقة.</ResponseField>
<ResponseField name="data[].name" type="string">اسم العرض لمفتاح API.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">بادئة مفتاح غير سرية للعرض والدعم.</ResponseField>
<ResponseField name="data[].status" type="string">إحدى القيم `active` أو `inactive` أو `suspended` أو `revoked`.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">حد الإنفاق بالدولار الأمريكي كرقم JSON للعرض. تعني `null` عدم وجود حد.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">حد الإنفاق الدقيق بالدولار الأمريكي كسلسلة عشرية. تعني `null` عدم وجود حد.</ResponseField>
<ResponseField name="data[].used_amount" type="number">الإنفاق التراكمي للاستخدام بالدولار الأمريكي كرقم JSON للعرض.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">الإنفاق التراكمي الدقيق للاستخدام بالدولار الأمريكي كسلسلة عشرية.</ResponseField>
<ResponseField name="data[].models" type="string[]">قائمة النماذج المسموح بها لكل مفتاح. تعني المصفوفة الفارغة عدم وجود قيود إضافية على النماذج على مستوى المفتاح.</ResponseField>
<ResponseField name="data[].delivery_policy" type="string | null">`auto`, `verified`, `official`, `null`. تعني `null` وراثة سياسة التسليم لمساحة العمل.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">طابع زمني ISO لانتهاء صلاحية المفتاح، أو `null` إذا لم تكن له مدة انتهاء.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">طابع زمني ISO لأحدث استخدام، أو `null` إذا لم يُستخدم.</ResponseField>
<ResponseField name="data[].created_at" type="string">طابع زمني ISO للإنشاء.</ResponseField>
