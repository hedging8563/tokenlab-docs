## نظرة عامة

تعيد نقطة النهاية هذه تجميعات فوترة قائمة على الاستهلاك لمفتاح API المحدد، بما في ذلك التكلفة الإجمالية وإجمالي الطلبات والاستخدام حسب وحدة الفوترة، وتفصيلات `by_model` و`by_logical_model` و`by_model_vendor` و`by_scene`، إضافة إلى اتجاه التكلفة اليومي.

## ملاحظات

- تدعم حقول المبالغ المالية الدولار الأمريكي فقط. تم إيقاف مدخلات `CNY` وتعيد `400 currency_retired`.

- يتم استبعاد عمليات الشحن والفواتير والسجلات المالية الأخرى على مستوى المؤسسة.

## مثال

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## الحقول المهمة

<ResponseField name="api_key" type="object">ملخص مفتاح API باستخدام الحقول نفسها الموجودة في استجابات القائمة والإنشاء والتحديث.</ResponseField>
<ResponseField name="summary" type="object">إجماليات مجمعة للفلاتر المحددة.</ResponseField>
<ResponseField name="breakdowns" type="object">تفصيلات مجمعة للفلاتر المحددة.</ResponseField>
<ResponseField name="summary.total_requests" type="number">إجمالي عدد الطلبات.</ResponseField>
<ResponseField name="summary.total_cost" type="number">إجمالي التكلفة بالدولار الأمريكي كرقم JSON للعرض.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">إجمالي التكلفة الدقيقة بالدولار الأمريكي كسلسلة عشرية.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">إجمالي رموز المطالبة.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">إجمالي رموز الإكمال.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">إجمالي الرموز.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">كمية الاستخدام مجمعة حسب وحدة الاستخدام.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">تفصيل حسب النموذج العام المطلوب.</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">تفصيل حسب النموذج العام المنطقي.</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">تفصيل حسب مورّد النموذج العام.</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">تفصيل حسب مشهد الطلب العام.</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">اتجاه التكلفة اليومي.</ResponseField>
