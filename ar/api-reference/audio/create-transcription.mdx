## جسم الطلب

قد يعيد التفريغ النص مباشرة أو يقبل مهمة غير متزامنة مع HTTP `200` و`id` و`status`. للمهمة المقبولة، اتبع `poll_url` أو استعلم عن `/v1/tasks/{id}`. للصوت الطويل الذي يُعالج تزامنيًا، اسمح بمهلة لا تقل عن `120s`.

<ParamField body="file" type="file" required>
  ملف الصوت المراد تفريغه. التنسيقات المدعومة: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. الحد الأقصى لحجم الملف: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  معرّف نموذج التفريغ، مثل `whisper-1` أو `gpt-4o-transcribe`. اعرض الخيارات الحالية عبر `GET /v1/models?recommended_for=stt`.
</ParamField>

<ParamField body="language" type="string">
  لغة الصوت بتنسيق ISO-639-1 (على سبيل المثال: `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  نص اختياري لتوجيه أسلوب النموذج أو متابعة مقطع سابق.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  تنسيق الإخراج. يدعم Whisper القيم `json` و`text` و`srt` و`verbose_json` و`vtt`. قد تختلف التنسيقات في النماذج الأخرى؛ راجع تفاصيل النموذج.
</ParamField>

<ParamField body="temperature" type="number">
  درجة حرارة أخذ العينات من 0 إلى 1، للنماذج التي تدعم هذه المعلمة فقط.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  `word` و/أو `segment` إذا كان النموذج يدعمهما. يتطلب Whisper القيمة `response_format=verbose_json`. في multipart، كرّر `timestamp_granularities[]` لإرسال عدة قيم.
</ParamField>

## الاستجابة

تصف الحقول التالية استجابات JSON للتفريغ أو الترجمة. تعيد `text` و`srt` و`vtt` نصًا أو ترجمة مصاحبة خامًا بدلاً من كائن JSON. تعتمد الحقول الإضافية على النموذج وتنسيق الإخراج.

<ResponseField name="text" type="string">
  النص المُفرَّغ.
</ResponseField>

بالنسبة إلى `verbose_json`:

<ResponseField name="task" type="string">
  اسم المهمة عند إرجاعه، مثل `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  اللغة المكتشفة.
</ResponseField>

<ResponseField name="duration" type="number">
  مدة الصوت بالثواني.
</ResponseField>

<ResponseField name="segments" type="array">
  مقاطع التفريغ مع الطوابع الزمنية.
</ResponseField>

<ResponseField name="words" type="array">
  طوابع زمنية على مستوى الكلمات (إذا تم طلبها).
</ResponseField>

تعيد مهمة التفريغ غير المتزامنة المقبولة الحقول التالية بدلاً من النص:

<ResponseField name="id" type="string">
  معرف المهمة.
</ResponseField>

<ResponseField name="task_id" type="string">
  الاسم البديل لمعرّف المهمة غير المتزامنة عندما يكون متاحًا.
</ResponseField>

<ResponseField name="status" type="string">
  حالة المهمة: `pending` أو `processing` أو `completed` أو `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  عنوان URL المفضل للاستعلام عند توفيره في استجابة الإنشاء.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```

## الترجمة

لترجمة الصوت إلى الإنجليزية، استخدم endpoint الخاص بالترجمات:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
