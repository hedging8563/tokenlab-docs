## الخطوة 1: ابدأ بأرصدة التجربة

<Steps>
  <Step title="إنشاء حساب">
    سجّل في [tokenlab.sh](https://tokenlab.sh) باستخدام بريدك الإلكتروني أو Gmail أو حساب GitHub.
  </Step>
  <Step title="التحقق من رصيد مساحة العمل">
    راجع الرصيد والرصيد التجريبي المتاح في [الفوترة](https://tokenlab.sh/dashboard/billing). يُحاسب هذا الطلب بسعر النموذج الحالي؛ أضف رصيدًا عند الحاجة.
  </Step>
  <Step title="إنشاء مفتاح API وحفظه">
    افتح [مفاتيح API](https://tokenlab.sh/dashboard/api?tab=keys) في مساحة عملك. أنشئ مفتاحًا واحفظ قيمته الكاملة فورًا؛ فهي تظهر مرة واحدة فقط. إذا كنت قد حفظت مفتاحًا كاملًا من قبل، فاستخدم تلك القيمة. البادئة المعروضة أو المنسوخة من القائمة لا تصلح لمصادقة الطلبات.
  </Step>
</Steps>

<Warning>
احفظ مفتاح الـ API الخاص بك بأمان. لا تكشف عنه في شيفرة جانب العميل أو في مستودعات عامة.
</Warning>

## تعيين المفتاح لهذه الطرفية

لا تضع هذه الأوامر المفتاح داخل نص الأمر نفسه. يسري فقط على الطرفية الحالية والعمليات التابعة لها. استخدم مدير أسرار للتطبيقات المنشورة.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## الخطوة 3: أجرِ طلبك الأول

بالنسبة لمعظم عمليات التكامل الجديدة، ابدأ بـ **إكمالات الدردشة** على `POST /v1/chat/completions`.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

احفظ مثال SDK باسم `quickstart.py` أو `quickstart.mjs` أو `main.go` أو `quickstart.php`، ثم شغّل `python quickstart.py` أو `node quickstart.mjs` أو `go run .` أو `php quickstart.php`. تستخدم Python وJavaScript وGo حزم OpenAI الرسمية؛ وتستخدم PHP [عميل المجتمع](https://github.com/openai-php/client) وتتطلب PHP 8.2 أو أحدث.

<Note>
استخدم `POST /v1/responses` فقط عندما تحتاج صراحةً إلى سلوك مخصص لـ Responses. بعض الحقول الخاصة بـ Responses تعتمد على النموذج المحدد ومسار التوجيه.
</Note>
