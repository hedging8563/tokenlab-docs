رصيد TokenLab واحد يغطي النماذج كلها. لا يوجد اشتراك أو حد أدنى للإنفاق؛ تعتمد الرسوم على النموذج والاستخدام المسجل.

## الأسعار وخيارات التسليم

راجع السعر الحالي في صفحة النموذج أو `GET /v1/models/{model}/pricing` أو Pricing API. لا تثبت جدولًا منسوخًا داخل التطبيق. قد تُحسب النصوص والتضمينات برموز الإدخال أو الإخراج أو التخزين المؤقت، والوسائط بالصورة أو الثانية أو الدقيقة أو الطلب أو المهمة.

يستخدم `TokenLab Verified` أسعار TokenLab العامة، ويستخدم `Official` طبقة Official المبنية على أسعار صانع النموذج العامة. يفضل `Auto` خيار Verified ثم Official عند الحاجة؛ تُفرض رسوم مرة واحدة وفق الخيار الذي سلّم النتيجة. يعرض Console التقدير الأقصى قبل تأكيد الإنشاء المدفوع والمبلغ النهائي في Runs وUsage.

[Pricing API](/ar/api-reference/pricing/get-pricing)

## الفوترة غير المتزامنة والسجلات

تحجز بعض المهام التكلفة المقدرة عند إنشائها. احفظ المعرف و`poll_url` واستعلم حتى `completed` أو `failed`. تُحاسب المهمة الناجحة مرة واحدة ويُحرر الحجز المتبقي؛ عند الفشل يُحرر المبلغ المعلق أو يُرد.

قد تتضمن استجابات OpenAI المتوافقة غير المتدفقة `billing_transaction_id` أو `X-Billing-Transaction-ID` بعد الفوترة. قد تستخدم التنسيقات الأصلية الترويسة فقط. قد تصل النتائج غير المتزامنة أو المتدفقة قبل السجل المالي؛ راجع Usage عند غياب المعرف.

يعرض Usage النموذج والمفتاح والتكلفة والاستهلاك. تختلف الرموز حسب النموذج واللغة والوسائط؛ تقدير الأحرف ليس بديلًا للفاتورة النهائية. البث لا يقلل الرموز المفوترة. قارن التكلفة النهائية لمهام متماثلة واستخدم حدود الإخراج المدعومة.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## استخدام Console

اختر المبلغ وطريقة دفع معروضة في Console → Billing. يتحدث الرصيد بعد تأكيد خدمة الدفع.

حدد سقف إنفاق عند إنشاء مفتاح أو تعديله في Console → API Keys. عند بلوغه تعيد API الخطأ `402 Payment Required`.

اضبط تنبيهات الرصيد في Console → Settings. للاستفسارات أرسل Request ID ومعرف المهمة إلى support@tokenlab.sh، ولا ترسل مفتاح API.
