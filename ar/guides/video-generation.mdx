توليد الفيديو غير متزامن. `POST /v1/videos/generations` يعيد هوية مهمة عامة وعادةً ما يعيد `poll_url`؛ يظهر الفيديو النهائي في ردود الحالة اللاحقة.

أرسل روابط HTTP(S) عامة أو روابط data مدعومة في حقول الصور التي يقبلها النموذج المختار. تُعالج كمدخلات وسائط عادية ولا تُنشئ تلقائيًا معرّفات مواد قابلة لإعادة الاستخدام.

إذا كانت المادة المحددة صراحةً لا تزال قيد الإعداد، يعيد `POST /v1/videos/generations` الخطأ `409 seedance_material_preparing` مع `inactive_asset_ids`. استعلم عنها حتى تصبح `ACTIVE` ثم أعد المحاولة بالمعرّفات نفسها. عند `FAILED` راجع `error_message` وصحح المادة أو أعد استيرادها أولًا.

## العمليات المدعومة

استخدم `operation` صريحة في الإنتاج. يمكن لـ TokenLab استنتاج بعض العمليات من المدخلات، لكن القيم الصريحة للعملية تجعل التحقق والدعم وإعادة المحاولة أكثر وضوحًا.

| العملية | المدخل المطلوب أو النموذجي | حالة الاستخدام |
|---------|-----------------------------|----------------|
| `text-to-video` | `prompt` | توليد من النص فقط |
| `image-to-video` | `image_url` أو `image` متوافق | تحريك صورة البداية |
| `reference-to-video` | `reference_images` و `video_urls` / `audio_urls` الاختيارية على النماذج المدعومة | الحفاظ على الهوية أو الأسلوب أو مراجع الأصول |
| `start-end-to-video` | `start_image`, `end_image` | التحكم في الإطارات الأولى والأخيرة |
| `video-to-video` | `video_url` أو `task_id` المحدد للنموذج | تحويل أو تحسين مقطع موجود |
| `motion-control` | `image_url` بالإضافة إلى `video_url` | تطبيق مرجع الحركة على موضوع |
| `audio-to-video` | `audio_url` | تدفقات الفيديو المشروطة بالصوت |
| `video-extension` | `task_id`, `extend_at`, أو حقول التمديد المحددة للنموذج | متابعة فيديو تم توليده |

## اكتشاف النموذج

```bash
curl "https://api.tokenlab.sh/v1/models?recommended_for=video" \
  -H "Authorization: Bearer sk-your-api-key"
```

استخدم معرفات النماذج التي تعرضها TokenLab في `model`، ثم اختر متغيرات العملية عبر `operation` ومدخلات الوسائط المناسبة. تشمل الأمثلة `wan-2.7` و`happyhorse-1.0` و`viduq3` و`viduq3-mix` و`pixverse-v6` و`veo3.1` و`seedance-2.0`؛ لا تستخدم أسماء العمليات الخاصة بالمزوّد كأسماء نماذج في TokenLab.

اقرأ تفاصيل النموذج المحدد قبل الاعتماد على الحقول المتخصصة مثل `reference_images`, `kling_elements`, `output_audio`, `duration`, `resolution`, أو `aspect_ratio`.

## إنشاء الطلب

```bash
curl https://api.tokenlab.sh/v1/videos/generations \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo3.1",
    "operation": "text-to-video",
    "prompt": "لقطة سينمائية هادئة لقط يسير في حديقة مضاءة بأشعة الشمس",
    "duration": 4,
    "aspect_ratio": "16:9"
  }'
```

لإدخال وسائط الإنتاج، يفضل استخدام `https` URLs العامة بدلاً من `data:` URLs المضمنة. إذا كنت تستخدم URLs مؤقتة، أبقها صالحة حتى ينتهي TokenLab من إنشاء المهمة.

## المدخلات والحقول المحددة للنموذج

- طلبات عائلة Veo 3 افتراضيًا تكون على وضع الصوت عند حذف `output_audio`. قم بتعيينها صراحة عندما يدعم النموذج التبديل وتعتمد تجربة المستخدم الخاصة بك على الصوت.
- بالنسبة إلى عائلة Seedance 2.0، اقرأ [دليل نماذج فيديو Seedance 2.0](/ar/guides/seedance-2-video) قبل استخدام مخرجات 4K أو حدود Fast/Mini أو مدخلات المرجع متعددة الوسائط.
- في video-to-video مع `grok-imagine-video`، أرسل `prompt` ورابط HTTPS عامًا لملف `.mp4` في `video_url`. لا تستخدم هذه العملية خيارات `duration` أو `resolution` أو `aspect_ratio`.

## استعلام النتائج

استخدم `poll_url` المعاد أولاً. إذا كنت بحاجة إلى نقطة نهاية ثابتة، استخدم `GET /v1/tasks/{id}` بنفس `id` / `task_id` من رد الإنشاء.

قد تعيد مهام الفيديو المكتملة `video_url` أو `video` أو `videos` بحسب النموذج وعدد المخرجات. اعتبر `billing_transaction_id` معرفًا للفوترة، وليس معرفًا للمهمة.

## الأخطاء الشائعة

- لا تقم بتشفير مسارات حالة الفيديو القديمة؛ يفضل استخدام `poll_url`.
- لا تجمع بين حقول الإطار الأول مع تدفقات صورة مرجعية مخصصة ما لم يسمح بذلك تفاصيل النموذج.
- لا تفترض أن `duration` تصف طول فيديو المرجع المدخل؛ عادةً ما تتحكم في طول المخرجات المولدة.
- لا تقم بإعادة محاولة طلبات الإنشاء بعد انتهاء المهلة دون التحقق مما إذا كانت المهمة قد تم إنشاؤها بالفعل.

## واجهات فيديو بأسلوب OpenAI ومتوافقة مع Volc

استخدم `/v1/videos/generations` لواجهة الفيديو الموحدة في TokenLab عبر النماذج. إذا كنت تنقل تكاملا قائما مع Seedance 2.0 يستخدم بالفعل `content[]` أو طلبات Action بأسلوب Volc، فاستخدم واجهات توافق Seedance تحت `/api/v3`. يستخدم الأسلوبان مفاتيح TokenLab Bearer API والاستعلام غير المتزامن، لكن شكل الطلب والاستجابة مختلف.
