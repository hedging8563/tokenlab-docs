## نظرة عامة

تُتيح TokenLab تنسيقات API متعددة بحيث يمكن لأدوات البرمجة الشائعة، وSDKs، وأطر العمل التكامل معها بأقل قدر من التعليمات البرمجية الإضافية (glue code).

هذه الصفحة مصممة لتكون أكثر تركيزاً من مصفوفة التسويق:

- **مدعوم (Supported):** يعني أننا نوثق مسار إعداد ملموس وأن TokenLab توفر شكل البروتوكول الذي يتوقعه ذلك المسار.
- **مسار أصلي قوي (Strong native path):** يعني أن المستودع يحتوي أيضاً على دليل مباشر للمحول (adapter) أو تنسيق الطلب لعائلة البروتوكول تلك.
- **بذل الجهد (Best-effort):** يعني أن التكامل قد يعمل، لكن العميل (upstream client) لا يتعامل مع سير عمل البوابة المخصص هذا كعقد مستقر.

<Note>
  الحقول غير المدعومة لا يتم التعامل معها بشكل موحد. في مسارات التوافق، يتم تجاهل بعض الحقول أو تطبيعها. في `/v1/responses`، قد تُرجع الحقول غير المدعومة أخطاء صريحة من نوع `400` أو `503` عندما لا يستطيع ذلك المسار ضمان السلوك المطلوب.
</Note>

## تنسيقات API المدعومة

| نقطة النهاية (Endpoint) | التنسيق | حالة الاستخدام |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | توافق عالمي |
| `/v1/responses` | OpenAI Responses | محادثات ذات حالة (Stateful) |
| `/v1/messages` | Anthropic Messages | ميزات Claude الأصلية |
| `/v1beta/models/:model:generateContent` | Google Gemini | ميزات Gemini الأصلية |

## توافق IDE و CLI

### مسارات الأدوات الموثقة

| الأداة | مستوى الدعم | التنسيق | ملاحظات |
|------|---------------|--------|-------|
| **Cursor** | مدعوم مع قيود | متوافق مع OpenAI | يعمل مع تدفقات الدردشة/المحرر القياسية BYOK، وليس كبديل للميزات التي يديرها Cursor مثل الإكمال التلقائي (Tab Completion) |
| **Claude Code CLI** | مسار أصلي قوي | Anthropic | مسار أصلي `/v1/messages` مع تغطية محول للتفكير (thinking) و `tool_choice` |
| **Codex CLI** | مدعوم مع قيود النموذج/المسار | OpenAI Responses | تعامل مع `/v1/responses` كمسار متقدم لسير عمل Codex الخاص؛ بعض الحقول الخاصة بـ Responses فقط غير مضمونة عبر كل نموذج ومسار موجه |
| **Gemini CLI** | بذل الجهد / تجريبي | Gemini | تدفق عنوان URL الأساسي المخصص لـ TokenLab ليس تكاملاً رسمياً لـ Gemini CLI |
| **OpenCode** | مدعوم | متوافق مع OpenAI | استخدم مزوداً متوافقاً مع OpenAI افتراضياً؛ انتقل إلى مزود يعتمد على Responses فقط عندما تحتاج ذلك صراحةً |
| **OpenHands** | مدعوم | متوافق مع OpenAI | استخدم مسار LiteLLM/OpenAI-compatible مع `openai/<model>` وعنوان URL الأساسي `/v1` الخاص بـ TokenLab |

<Note>
  غالباً ما تعمل المحررات وأدوات الوكلاء الأخرى المتوافقة مع OpenAI بنفس نمط عنوان URL الأساسي؛ تحقق من دعم المزود المخصص الخاص بالأداة قبل استخدامها في بيئة الإنتاج.
</Note>

## توافق SDK

|-----------------|----------|---------------|-------|
| **OpenAI SDK** | Python/JS/Go | مسار أساسي مدعوم | مسار توافق لـ `/v1` Chat Completions و Embeddings؛ استخدم مسارات المزود الأصلية للسلوك الخاص بالمزود، ولا تفترض أن الحقول الخاصة بـ Responses فقط تعمل عبر كل نموذج |

## معلمات Chat Completions

### المعلمات الأساسية

| المعلمة | النوع | الوصف |
|-----------|------|-------------|
| `model` | string | معرف النموذج (مطلوب) |
| `messages` | array | رسائل المحادثة (مطلوب) |
| `max_tokens` | integer | الحد الأقصى لرموز المخرجات |
| `temperature` | number | درجة حرارة أخذ العينات (0-2) |
| `top_p` | number | أخذ عينات النواة (0-1) |
| `stream` | boolean | تمكين البث |

### استدعاء الأدوات

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### خيارات اختيار الأداة

| التنسيق | مثال | الوصف |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | اختيار بسيط |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | فرض وظيفة محددة |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | تنسيق Anthropic الأصلي |

### المعلمات المتقدمة

| المعلمة | النوع | الوصف |
|-----------|------|-------------|
| `stream_options` | object | Chat Completions فقط: `{ include_usage: true }` لحساب الرموز |
| `reasoning_effort` | string | `"low"`, `"medium"`, `"high"` لنماذج GPT-5 التي تدعم التفكير |
| `service_tier` | string | `"auto"` أو `"default"` |
| `seed` | integer | مخرجات حتمية |
| `logprobs` | boolean | إرجاع احتمالات السجل |
| `top_logprobs` | integer | عدد احتمالات السجل العليا (0-20) |
| `logit_bias` | object | خريطة انحياز الرموز (-100 إلى 100) |
| `frequency_penalty` | number | عقوبة التكرار (-2 إلى 2) |
| `presence_penalty` | number | عقوبة الموضوع (-2 إلى 2) |
| `stop` | string/array | تسلسلات التوقف |
| `n` | integer | عدد الإكمالات (1-128) |
| `user` | string | معرف المستخدم للتتبع |

### ميزات OpenAI المتقدمة

| المعلمة | النوع | الوصف |
|-----------|------|-------------|
| `modalities` | array | `["text", "audio"]` للوسائط المتعددة |
| `audio` | object | تكوين مخرجات الصوت (الصوت، التنسيق) |
| `prediction` | object | المخرجات المتوقعة لإكمال أسرع |
| `metadata` | object | أزواج المفتاح والقيمة للتتبع |
| `store` | boolean | التخزين للاسترجاع لاحقاً |

### خيارات خاصة بالمزود

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## البث (Streaming)

نقاط نهاية التوليد التي تكشف عن `stream: true`، بما في ذلك Chat Completions و Responses، تستخدم أحداث الخادم (SSE):

```bash
# Chat Completions
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# Chat Completions usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

```json
    "code": "invalid_api_key"
  }

```
