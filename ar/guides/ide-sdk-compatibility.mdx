تتصل معظم الأدوات بـ TokenLab عبر تغيير مفتاح API وعنوان URL الأساسي. ويعتمد الإعداد الدقيق على تنسيق API الذي يمكن للأداة استخدامه.

| تنسيق API | عنوان URL الأساسي | العملاء الشائعون |
| --- | --- | --- |
| Chat Completions (متوافق مع OpenAI) | `https://api.tokenlab.sh/v1` | حزم SDK الخاصة بـ OpenAI والعديد من تطبيقات الدردشة وأطر العمل |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | عملاء Responses والأدوات التي تستخدم أحداث Responses |
| Anthropic Messages | `https://api.tokenlab.sh` | حزم SDK الخاصة بـ Anthropic والأدوات الموجهة إلى Claude |
| Gemini | `https://api.tokenlab.sh` | عملاء Gemini عبر REST أو SDK الذين يسمحون بمضيف مخصص |

يجب أن يتضمن `accepted_request_formats` للنموذج المختار التنسيق نفسه. ويعتمد البث واستدعاء الأدوات أيضًا على قدرات النموذج ودعم العميل. راجع الأمثلة في [تنسيقات API](/ar/guides/api-formats).

## حالات التوافق

| الحالة | المعنى |
| --- | --- |
| **متوافق** | يستخدم إعداد TokenLab في الصفحة المرتبطة خيارات الإعداد الموثقة للعميل |
| **متوافق مع قيود** | ينطبق الإعداد على ميزات أو طرق مصادقة محددة؛ وتبقى لخدمات المورّد الأخرى متطلباتها الخاصة |

تصف هذه الحالات طريقة الإعداد في الصفحة المرتبطة. ويعتمد توفر الميزات أيضًا على النموذج المختار وإصدار العميل.

## الاستهلاك في الاستجابات المتدفقة

تقبل تدفقات Chat Completions الخيار `stream_options: { include_usage: true }`، الذي يضيف جزءًا أخيرًا يتضمن الاستهلاك قبل إغلاق التدفق. لا توفر واجهة Responses الخيار `include_usage`؛ بل تعرض تدفقاتها الاستهلاك في الحدث الختامي.

## ما لا يستبدله مفتاح API مخصص

تجمع بعض المنتجات بين استدعاءات النموذج وميزات يستضيفها المورّد. يمكن لمفتاح TokenLab تشغيل طلبات النموذج المتاحة عبر إعدادات BYOK، لكنه لا يستبدل الاشتراكات الأخرى أو خدمات الإكمال التلقائي أو ميزات الحساب أو الإضافات المملوكة للمورّد.

إذا غيّر تحديث الأداة طريقة إعدادها، فاتبع صفحة التكامل الحالية بدلًا من نسخ مثال قديم لمتغيرات البيئة.

## قبل الاعتماد على ميزة

- تأكد من أن الأداة تسمح بعنوان URL أساسي مخصص للتنسيق المطلوب.
- تأكد من أن النموذج يدرج هذا التنسيق في `accepted_request_formats`.
- جرّب البث واستدعاءات الأدوات إذا كان سير عملك يتطلبها.
- احتفظ بمفتاح API على جهاز أو خادم موثوق.
- سجّل معرّف الطلب عند الإبلاغ عن خطأ.
