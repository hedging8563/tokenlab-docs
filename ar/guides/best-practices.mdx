## النماذج والتكلفة

تحقق من القدرات والأسعار الحالية عبر API النماذج أو صفحة النموذج. قارن مهام متماثلة وحدد النموذج في كل طلب. لا تبدله دون إعلام المستخدم، لأن السعر والجودة والأدوات والسياق قد تتغير.

حدد سقف الإخراج وفق التنسيق والنموذج وقلل السياق المكرر. قد تعتمد تكلفة الوسائط على العدد أو المدة أو الدقة؛ اعرض التقدير المتاح قبل تأكيد إنشاء مرتفع التكلفة.

## البث وإعادة المحاولة

يُظهر البث النص مبكرًا لكنه لا يخفض تكلفة الرموز. احتفظ بالإخراج الجزئي المفيد عند الانقطاع دون اعتباره إجابة مكتملة.

عند 429 انتظر وفق `Retry-After` أو `retry_after`، واستخدم تراجعًا قصيرًا لأخطاء 5xx المؤقتة. أخطاء المصادقة والصلاحيات والرصيد والتحقق والسياق تحتاج إلى تصحيح. حدد عدد المحاولات والوقت الإجمالي ولا تضاعف إعادة المحاولة المدمجة في SDK.

- [البث](/ar/guides/streaming)
- [429 / Retry-After](/ar/guides/rate-limits)

## المفاتيح والسجلات

احفظ المفاتيح على الخادم أو في مدير أسرار، لا في المتصفح أو حزمة التطبيق أو المستودعات العامة أو السجلات. افصل مفاتيح التطوير والإنتاج والتطبيقات وحدد النماذج والإنفاق، وألغِ المفاتيح المكشوفة فورًا.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
)
```

سجل `request_id` و`task_id` و`billing_transaction_id` المعاد والنموذج ونقطة النهاية ومعرف مهمتك. لا تسجل بيانات الاعتماد أو المطالبات الخاصة الكاملة أو الوسائط أو الروابط الموقعة. راجع Usage أو API الإدارة للمبلغ النهائي.

## المهام غير المتزامنة

احفظ معرف المهمة و`poll_url` بعد الإنشاء غير المتزامن واستعلم حتى `completed` أو `failed`. فشل الاستعلام لا يعني فشل الإنشاء. بعد انتهاء المهلة أو التحديث، استأنف المهمة المحفوظة؛ استخدم مفتاح منع التكرار عندما تدعمه نقطة النهاية.

[وظائف غير متزامنة واستطلاع](/ar/guides/async-jobs-polling)

## قبل الإطلاق

قبل الإطلاق تحقق من النموذج والتنسيق الفعليين والنجاح والأخطاء الشائعة والأسعار الحالية وتحديث الصفحة والنقرات المتكررة.
