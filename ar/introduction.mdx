## ما هي TokenLab؟

يربط TokenLab تطبيقك أو أداة البرمجة بنماذج الذكاء الاصطناعي باستخدام مفتاح API واحد ورصيد مشترك لمساحة العمل. اختر نموذجًا وصيغة API يدعمها؛ تُحاسب الطلبات بالسعر المنشور.

## الإمكانيات المدعومة

راجع [كتالوج النماذج](https://tokenlab.sh/ar/models) لمعرفة المعرّفات والتوافر والصيغ والأسعار الحالية.

| الإمكانية | الوصف |
|---|---|
| المحادثة والاستدلال | توليد النص والتخطيط والأدوات |
| الرؤية ومتعدد الوسائط | فهم الصور والمحادثة متعددة الوسائط |
| توليد الصور وتحريرها | تحويل النص إلى صورة وتحرير الصور |
| توليد الفيديو | نص/صورة/مرجع إلى فيديو والتحكم بالحركة |
| الصوت وRealtime WebSocket | TTS والنسخ وترجمة الصوت وجلسات WebSocket الفورية |
| Embeddings وrerank | تمثيل النصوص وإعادة الترتيب |
| الترجمة | ترجمة النص وترجمة الكلام عبر WebSocket |
| الموسيقى و3D | توليد الموسيقى وأصول 3D |
| Worlds | توليد worlds وتتبع الحالة وتدفقات media assets |
