## مفاتيح API

تتطلب استدعاءات النماذج والموارد الخاصة مفتاح API. تعمل نقاط الاكتشاف العامة مثل `GET /v1/models` و`GET /v1/models/{model}` دون مفتاح. نجاح استعلام الاكتشاف لا يؤكد صلاحية المفتاح؛ اتبع دليل البدء السريع لإرسال طلب إلى نموذج. استخدم المفتاح الكامل المحفوظ، لا البادئة الظاهرة في القائمة.

بالنسبة إلى نقاط النهاية المتوافقة مع OpenAI، أرسله بالشكل التالي:

```bash
Authorization: Bearer sk-your-api-key
```

بالنسبة إلى طلبات `/v1/messages` المتوافقة مع Anthropic، يمكنك أيضًا استخدام:

```bash
x-api-key: sk-your-api-key
```

## رموز الإدارة

تستخدم نقاط نهاية واجهة إدارة API نوعًا منفصلًا من الرموز:

```bash
Authorization: Bearer mt-your-management-token
```

استخدم رموز الإدارة فقط مع `/v1/management/*`. افتح [API → Tokens](https://tokenlab.sh/dashboard/api?tab=tokens) لمساحة العمل المحددة لإنشاء رمز أو استبداله. احفظ الرمز الكامل بأمان عند ظهوره؛ فهو يُعرض مرة واحدة فقط بعد الإنشاء أو الاستبدال.

<Note>
لا يمكن استخدام رموز الإدارة لاستدلال النماذج، ولا يمكن استخدام مفاتيح API العادية `sk-...` مع واجهة إدارة API.
</Note>

## الحصول على مفتاح API الخاص بك

1. سجّل الدخول إلى [لوحة تحكم TokenLab](https://tokenlab.sh/dashboard)
2. افتح **API Keys**
3. أنشئ مفتاحًا جديدًا
4. امنحه اسمًا وصفيًا
5. انسخه فورًا لأنه يُعرض مرة واحدة فقط

<Warning>
- لا تكشف أبدًا عن مفاتيح API في كود جهة العميل
- لا تقم أبدًا بإيداع مفاتيح API في نظام التحكم بالإصدارات
- استخدم متغيرات البيئة أو مدير الأسرار
- قم بتدوير المفاتيح بشكل دوري
- احذف المفاتيح غير المستخدمة
</Warning>

## استخدام مفاتيح API

راجع [البدء السريع](/ar/quickstart) لمتغيرات البيئة وطلب أول كامل. استخدم SDK المناسب [لصيغة API](/ar/guides/api-formats) المختارة واحتفظ بالمفاتيح على الخادم.

## ميزات مفتاح API

### حدود الاستخدام

يمكنك تعيين حد استخدام لكل مفتاح API:

| الإعداد | الوصف |
|---------|-------------|
| **بدون حد** | يستخدم المفتاح رصيد حسابك دون قيود |
| **حد ثابت** | يتوقف المفتاح عن العمل بعد الوصول إلى المبلغ المحدد |

### بادئة المفتاح

تبدأ جميع مفاتيح TokenLab API بـ `sk-`.

## استجابات الأخطاء

| رمز الحالة | النوع | الرمز | الوصف |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | مفتاح API مفقود أو غير صالح أو غير نشط أو ملغى |
| 401 | `expired_api_key` | `expired_api_key` | انتهت صلاحية مفتاح API |
| 402 | `insufficient_balance` | `insufficient_balance` | رصيد الحساب غير كافٍ |
| 402 | `quota_exceeded` | `quota_exceeded` | تم الوصول إلى حد استخدام مفتاح API |

مثال:

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
