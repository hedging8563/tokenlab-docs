## نظرة عامة

يمكن لـ Mem0 OSS استخدام TokenLab من خلال إعدادات LLM المتوافقة مع OpenAI عن طريق إبقاء `provider: "openai"` وتعيين `openai_base_url`.

<Note>
**النوع**: إطار عمل الذاكرة (Memory Framework)

**المسار الأساسي**: إعدادات LLM المتوافقة مع OpenAI

**مستوى دعم الموثوقية**: مسار نقطة النهاية المخصصة مدعوم
</Note>

## التثبيت

```bash
pip install mem0ai
```

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## إعدادات Python

```python
import os

from mem0 import Memory

config = {
    "llm": {
        "provider": "openai",
        "config": {
            "model": "claude-sonnet-5",
            "api_key": os.environ["TOKENLAB_API_KEY"],
            "openai_base_url": "https://api.tokenlab.sh/v1",
            "temperature": 0.1,
        },
    },
    "embedder": {
        "provider": "openai",
        "config": {
            "model": "text-embedding-3-small",
            "api_key": os.environ["TOKENLAB_API_KEY"],
            "openai_base_url": "https://api.tokenlab.sh/v1",
        },
    },
    "vector_store": {
        "provider": "qdrant",
        "config": {"path": "./mem0-qdrant"},
    },
}

memory = Memory.from_config(config)
```

## الاستخدام الأساسي

```python
memory.add("The user prefers concise engineering summaries.", user_id="demo")
results = memory.search("How should I answer?", filters={"user_id": "demo"})
print(results)
```

## ملاحظات حول نقطة النهاية

تغطي هذه الإعدادات مسار LLM المتوافق مع OpenAI في Mem0. قم بتهيئة أدوات التضمين (embedders) بشكل منفصل وفقاً لمخزن المتجهات (vector store) ونموذج التضمين الذي تستخدمه.
