## نظرة عامة

يدعم اتصال OpenAI في Prompt flow خاصية `base_url` مخصصة. قم بضبطها على نقطة النهاية `/v1` الخاصة بـ TokenLab واستخدم معرفات نماذج TokenLab في تدفق العمل (flow) الخاص بك.

<Note>
**النوع**: منصة بناء وتقييم تدفق العمل (Flow builder and evaluation platform)

**المسار الأساسي**: Chat Completions المتوافقة مع OpenAI

**مستوى دعم الموثوقية**: مسار مدعوم ومتوافق مع OpenAI
</Note>

## التثبيت

```bash
pip install promptflow promptflow-tools
```

## إنشاء اتصال

احفظ الاتصال أدناه في `openai.yaml`. يطلب الأمر مفتاح API محليًا. في عقدة OpenAI، ضع معرّف نموذج TokenLab في `inputs.model`؛ أما `deployment_name` فهو خاص بـ Azure OpenAI.

```yaml
$schema: https://azuremlschemas.azureedge.net/promptflow/latest/OpenAIConnection.schema.json
name: open_ai_connection
type: open_ai
base_url: https://api.tokenlab.sh/v1
api_key: "<user-input>"
```

```bash
pf connection create --file openai.yaml
```

## ملاحظات حول تدفق العمل (Flow)

في ملف `flow.dag.yaml` الخاص بك، تأكد من مطابقة اسم الاتصال مع الأمر المذكور أعلاه:

```yaml
nodes:
  - name: chat
    type: llm
    source:
      type: code
      path: chat.jinja2
    inputs:
      model: claude-sonnet-5
    api: chat
    connection: open_ai_connection
```


## ملاحظات حول نقطة النهاية (Endpoint)

يستخدم هذا التكامل اتصال Prompt flow المتوافق مع OpenAI. تتطلب استجابات TokenLab الأصلية (Native TokenLab Responses)، و Anthropic Messages، ومسارات Gemini استخدام أدوات Prompt flow أو عقد Python مخصصة تقوم باستدعاء نقاط النهاية تلك مباشرة.
