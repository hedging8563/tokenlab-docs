## اختر القدرة المطلوبة

- يضيف MCP أدوات TokenLab API إلى عميل متوافق. ابدأ بإعداد `catalog` أدناه دون مفتاح API.
- يثبّت [TokenLab Skill](/ar/integrations/coding-agent-skill) إرشادات الربط عبر `npx skills add` ولا يشغّل خادم MCP.

كلاهما يوسّع وكيلًا موجودًا. لتغيير مزود النموذج الرئيسي، اتبع دليل العميل نفسه.

يقوم [خادم TokenLab MCP](https://github.com/hedging8563/tokenlab-mcp-server) بإنشاء أدوات MCP من عقد OpenAPI العام الخاص بـ TokenLab. يمكن للوكلاء المتوافقين مع MCP اكتشاف النماذج والأسعار، واستدعاء نقاط نهاية LLM الأصلية والمتوافقة مع OpenAI، وإنشاء وسائط متعددة، ورفع الملفات، وإدارة المهام غير المتزامنة.

استخدمه عندما يحتاج الوكيل إلى عقد TokenLab API الحالي بدلاً من قائمة أدوات يتم صيانتها يدوياً. يكشف ملف التعريف الافتراضي `core` عن 29 أداة لنقاط النهاية التي تم إنشاؤها بالإضافة إلى أداتين مركبتين للاكتشاف. بينما يكشف ملف التعريف `full` عن 78 أداة لنقاط النهاية التي تم إنشاؤها بالإضافة إلى نفس الأداتين المركبتين.

تشرح هذه الصفحة إضافة TokenLab كخادم أدوات داخل Claude Code وCursor وVS Code وCodex وClaude Desktop وCline وWindsurf أو أي عميل MCP آخر. لاستدعاء TokenLab مباشرة من كود التطبيق، ابدأ بـ [البدء السريع لواجهة API](/ar/quickstart).

<Note>
لا تتطلب أدوات الكتالوج والأسعار العامة مفتاح TokenLab API. قم بتعيين `TOKENLAB_API_KEY` لعمليات الاستدلال (inference)، والوسائط، والصوت، والملفات، والمهام، والتضمين (embedding)، وإعادة الترتيب (rerank)، والترجمة المعتمدة. لا تضع أبداً مفتاح API في وسائط الأداة.
</Note>

## ما الذي يوفره

- اكتشاف مباشر للنماذج من `https://api.tokenlab.sh/v1/models`.
- البحث عن تفاصيل النموذج من `/v1/models/{model}`.
- البحث عن الأسعار من `/v1/models/{model}/pricing`.
- نظرة عامة على API قابلة للقراءة من قبل الوكيل من `https://api.tokenlab.sh/llms.txt`.
- إكمال الدردشة والاستجابات المتوافقة مع OpenAI، ورسائل Anthropic، و Gemini generateContent دون تغيير أشكال الطلبات الأصلية الخاصة بها.
- إنشاء الصور وتعديلها من خلال روابط JSON، أو معرفات ملفات TokenLab، أو ملفات multipart محلية.
- الفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، والكلام، والنسخ، وترجمة الصوت، والتضمينات، والتضمينات متعددة الوسائط، وإعادة الترتيب، وترجمة النصوص.
- ملخصات مهام غير متزامنة موحدة لعمليات الصور، والفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، وعمليات إنشاء العوالم.
- مزامنة يومية للعقد تقوم بجلب مستند OpenAPI العام، وإعادة إنشاء مخططات الأدوات، وتشغيل اختبارات نقاط النهاية والملفات، وتحديث `main` فقط عند اجتياز كل فحص.

## مرجع الإعداد

في أي عميل stdio محلي، استخدم اسم الخادم `tokenlab` والأمر `npx` والوسيطتين المنفصلتين `-y` و`@tokenlabai/mcp-server`، واترك دليل العمل فارغاً. استخدم `@tokenlabai/mcp-server@0.6.19` لتثبيت الإصدار المتحقق منه حالياً.

إعداد قياسي للأدوات الموثقة:

```json
{
  "mcpServers": {
    "tokenlab": {
      "command": "npx",
      "args": ["-y", "@tokenlabai/mcp-server"],
      "env": {
        "TOKENLAB_API_KEY": "<TOKENLAB_API_KEY>",
        "TOKENLAB_MCP_TOOL_PROFILE": "core"
      }
    }
  }
}
```

يستخدم VS Code كائن `servers` في المستوى الأعلى. إذا كان العميل يتوقع كائن خادم واحداً، فانسخ الكائن الداخلي الذي يحتوي على `command` و`args` و`env` فقط.

| متغير البيئة | الافتراضي | الغرض |
|---|---|---|
| `TOKENLAB_API_BASE` | `https://api.tokenlab.sh` | تغيير عنوان API الأساسي من دون شرطة مائلة أخيرة. |
| `TOKENLAB_API_KEY` | غير معيّن | مطلوب لمكالمات الاستدلال والوسائط والملفات والمهام والتضمين وإعادة الترتيب والترجمة الموثقة. |
| `TOKENLAB_MCP_TOOL_PROFILE` | `core` | اختر `catalog` أو `core` أو `full`. |
| `TOKENLAB_MCP_SCHEMA_MODE` | افتراضي ملف التعريف | اختر `portable` أو `exact` أو `strict`؛ احتفظ عادةً بـ`portable`. |
| `TOKENLAB_REQUEST_TIMEOUT_MS` | `120000` | مهلة طلب API بالمللي ثانية. |
| `TOKENLAB_MCP_MAX_FILE_BYTES` | `104857600` | الحد الأقصى لحجم كل ملف محلي مرفوع بالبايت. |
| `TOKENLAB_MCP_INLINE_BYTES` | `2097152` | الحد الأقصى لنتيجة ثنائية أو JSON معادة ضمن الاستجابة. |
| `TOKENLAB_ARTIFACT_DIR` | دليل النظام المؤقت | موقع كتابة عناصر الاستجابة الكبيرة. |

<Warning>
لا تنشر لقطات شاشة أو سجلات أو سجل shell أو ملفات إعداد تحتوي على مفتاح API حقيقي. استخدم إدخال الأسرار أو متغيرات البيئة في العميل، وضع عناصر نائبة في الأمثلة المشتركة، وبدّل أي مفتاح مكشوف.
</Warning>

## التثبيت من المصدر

استخدم نسخة من المصدر فقط لتدقيق خادم MCP أو تطويره. يجب أن يستخدم إعداد العميل العادي حزمة npm المنشورة الموضحة أعلاه.

```bash
git clone https://github.com/hedging8563/tokenlab-mcp-server.git
cd tokenlab-mcp-server
npm install
npm test
npm start
```

ينشر `core` و`full` افتراضياً مخططات `portable` محدودة الحجم والعمق، بينما يتحقق الخادم من كل استدعاء باستخدام تعريف OpenAPI الكامل. استخدم `exact` للمخططات المتداخلة الكاملة أو `strict` عندما يتطلب موفر النموذج كائنات مغلقة وإدراج كل خاصية في `required`.

## ملفات تعريف الأدوات التي تم إنشاؤها

| ملف التعريف | الأدوات المكشوفة | التغطية |
|---|---:|---|
| `catalog` | 6 | أربع أدوات عامة للكتالوج والأسعار بالإضافة إلى `compare_models` و `get_api_overview`. لا يتطلب مفتاح API. |
| `core` (افتراضي) | 31 | 29 أداة لنقاط النهاية بالإضافة إلى `compare_models` و `get_api_overview`. تغطي الكتالوج، والأسعار، ونقاط نهاية LLM الأصلية، والصور، والفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، والصوت، والمهام، والملفات، والتضمينات، وإعادة الترتيب، والترجمة. |
| `full` | 80 | 78 أداة لنقاط النهاية بالإضافة إلى أداتي الاكتشاف المركبتين. تضيف دورة حياة الاستجابة، والدفعات، والعوالم، واكتشاف النماذج الأصلية، وعمليات المطورين الأخرى المسموح بها. |

يتم إنشاء أسماء الأدوات، والأوصاف، ومخططات الإدخال، وطرق HTTP، والمسارات، وأنواع المحتوى، ومتطلبات المصادقة، وسلوك المهام من لقطة OpenAPI المعتمدة. يوفر تراكب MCP فقط أسماء مستعارة ثابتة للأدوات، وعضوية ملف التعريف، ودلالات المهام غير المتزامنة، ومتغيرات multipart، وحذف الأسرار، وقيود عدم البث.

يعيد الإصدار 0.6.0 أيضاً بيانات JSON عبر `structuredContent` في MCP، وينشر ثلاثة موارد للعقد، ويوفر قالبين للمطالبات لاختيار النموذج وإنشاء الطلبات الأصلية. تتضمن الأدوات المولدة والمركبة تعليقات قياسية للمخاطر حتى تتمكن العملاء المتوافقة من تطبيق سياسات موافقة أكثر أماناً.

تشمل أدوات `core` الشائعة:

| العائلة | أدوات تمثيلية |
|---|---|
| الكتالوج والأسعار | `list_models`, `get_model`, `get_model_pricing`, `get_pricing`, `compare_models` |
| نقاط نهاية LLM الأصلية | `create_chat_completion`, `create_response`, `create_anthropic_message`, `create_gemini_content` |
| الصور | `create_image`, `create_image_file`, `edit_image`, `edit_image_file` |
| الفيديو، الموسيقى، والنمذجة ثلاثية الأبعاد | `create_video`, `create_music`, `create_3d_model` |
| الصوت | `create_speech`, `transcribe_audio`, `translate_audio` |
| التضمينات والنصوص | `create_embedding`, `create_multimodal_embedding`, `rerank_documents`, `translate_text` |
| الملفات والمهام | `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`, `delete_file`, `get_task_status`, `cancel_task` |

تعيد استدعاءات أدوات MCP نتيجة نهائية واحدة. يتم استبعاد العمليات التي تعتمد على البث فقط والعمليات في الوقت الفعلي؛ ويثبت الخادم وسيطات `stream` المدعومة داخليًا على `false` دون كشف ثابت منطقي لمحولات provider. تعيد استجابات الصور والصوت الصغيرة محتوى MCP أصلياً؛ بينما تُكتب الاستجابات الثنائية الأكبر في `TOKENLAB_ARTIFACT_DIR` وتُعاد مع مسارها المحلي، ونوع MIME، وعدد البايتات.

## نتائج الوسائط غير المتزامنة

تعيد عمليات إنشاء الفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد ملخصات مهام غير متزامنة. يمكن أن تعيد عمليات إنشاء الصور وتعديلها إما نتيجة مكتملة أو مهمة غير متزامنة، اعتماداً على النموذج والطلب المختارين.

عندما يكون `delivery.mode` هو `async`، قم باستدعاء `get_task_status` مع `{ "id": delivery.task_id }` حتى يصبح `delivery.terminal` هو `true`. حدد الاكتمال من `status`؛ `progress` اختياري ويجب عدم استخدامه كشرط نهائي.

## سير عمل الوكيل الموصى به

1. استدعِ `list_models` عندما لا يحدد المستخدم نموذجاً.
2. استخدم `recommended_for` للمهام غير المتعلقة بالدردشة، مثل الصور، والفيديو، والموسيقى، والنمذجة ثلاثية الأبعاد، و TTS، و STT، والتضمينات، وإعادة الترتيب، أو الترجمة.
3. استدعِ `get_model` قبل بناء طلب غير متعلق بالدردشة، أو إعادة محاولة طلب فاشل، أو التبديل بين عائلات نقاط النهاية.
4. استدعِ `get_model_pricing` عندما تؤثر تكلفة النموذج على اختيار المستخدم.
5. استخدم `compare_models` عندما يعتمد الاختيار على عدة مرشحين.
6. استدعِ الأداة التي تم إنشاؤها والتي تطابق عقد API المطلوب، أو استخدم `get_api_overview` للحصول على خريطة مضغوطة لعائلات TokenLab API.

## توجيهات نقاط النهاية الأصلية

يدعم TokenLab المسارات المتوافقة مع OpenAI وعائلات نقاط النهاية الأصلية. يساعد خادم MCP الوكيل في اختيار المسار الصحيح قبل كتابة الكود:

| العائلة | المسار الشائع |
|---|---|
| دردشة متوافقة مع OpenAI | `/v1/chat/completions` |
| الاستجابات | `/v1/responses` |
| رسائل Anthropic | `/v1/messages` |
| Gemini أصلي | `/v1beta/models/{model}:generateContent` |
| الصور | `/v1/images/generations`, `/v1/images/edits` |
| الفيديو | `/v1/videos/generations` |
| الموسيقى | `/v1/music/generations` |
| النمذجة ثلاثية الأبعاد | `/v1/3d/generations` |
| الصوت | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| التضمينات وإعادة الترتيب | `/v1/embeddings`, `/v1/rerank` |
| ترجمة النصوص | `/v1/translations` |

## مستكشف النماذج المستضاف

يمكن للعملاء الذين يدعمون Streamable HTTP الاتصال بـ:

```text
https://tokenlab-model-explorer.vercel.app/mcp
```

المستكشف المستضاف عام ويكشف عن `open_tokenlab_model_explorer` و `compare_tokenlab_models` و `generate_tokenlab_endpoint_example`. استخدم خادم npm المحلي أعلاه عندما تحتاج إلى ملفات تعريف core/full التي تم إنشاؤها، أو رفع الملفات المحلية، أو عمليات API المعتمدة.

## الاستخدام مع مهارات TokenLab

يعد خادم MCP مفيداً في وقت التشغيل، بينما يعلم [مستودع مهارات TokenLab](https://github.com/hedging8563/tokenlab-skills) وكلاء البرمجة كيفية إنشاء وإصلاح كود التكامل.

استخدم كلاهما عند توفرهما:

- خادم MCP: لاكتشاف النماذج الحالية، والأسعار، وتفاصيل نقاط النهاية.
- مهارة `tokenlab-api-integration`: لإنشاء أمثلة API قابلة للتشغيل ومعالجة أخطاء TokenLab المهيكلة.
- مهارة `tokenlab-model-picker`: لاختيار نماذج قوية لمهمة المستخدم.
- مهارة `tokenlab-native-endpoints`: لتقرير متى يجب استخدام الاستجابات، ورسائل Anthropic، و Gemini، والوسائط، والصوت، والتضمين، وإعادة الترتيب، أو مسارات الترجمة.

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
  <Accordion title="لا يمكن للعميل بدء تشغيل الخادم">
    تأكد من أن Node.js بإصدار 18.17 على الأقل وأن العميل يجد `npx`. شغّل `npx -y @tokenlabai/mcp-server` في الطرفية لإظهار أخطاء npm أو الشبكة. ينتظر تشغيل stdio الناجح رسائل MCP بصمت؛ أنهه باستخدام **Ctrl+C** بعد التحقق.
  </Accordion>

  <Accordion title="تم إعداد الخادم لكن الأدوات لا تظهر">
    أعد تشغيل العميل ووافق على الخادم المحلي. في Claude Code افحص `claude mcp list` أو `/mcp`؛ وفي VS Code استخدم **MCP: List Servers** ثم **Show Output**؛ وفي Cursor افتح **Settings → Tools & MCP**.
  </Accordion>

  <Accordion title="يعرض Claude Code حالة Pending approval">
    تتطلب خوادم `.mcp.json` الخاصة بالمشروع الثقة في مساحة العمل والموافقة الصريحة. شغّل Claude Code تفاعلياً داخل المشروع، وافق على الثقة، ثم وافق على `tokenlab` في `/mcp`. استخدم `--scope user` لإعداد خاص متاح في كل المشاريع.
  </Accordion>

  <Accordion title="قائمة النماذج فارغة">
    تحقق من أن الجهاز يمكنه الوصول إلى `https://api.tokenlab.sh/v1/models`. إذا قمت بتجاوز `TOKENLAB_API_BASE`، فتأكد من أنه لا يتضمن شرطة مائلة في النهاية.
  </Accordion>

  <Accordion title="لا يزال الوكيل يختار معرفات نماذج قديمة">
    اطلب من الوكيل استدعاء `list_models` أو `get_model` قبل كتابة اسم النموذج برمجياً. يؤدي إقران خادم MCP مع `tokenlab-model-picker` إلى نتائج أفضل.
  </Accordion>

  <Accordion title="هل يمكن لهذا الخادم استدعاء واجهات برمجة تطبيقات استدلال TokenLab المدفوعة؟">
    نعم. قم بتعيين `TOKENLAB_API_KEY`، ثم استخدم أدوات LLM، والوسائط، والصوت، والمهام، والملفات، والتضمين، وإعادة الترتيب، أو الترجمة التي تم إنشاؤها. تظل أدوات الكتالوج والأسعار متاحة بدون مفتاح.
  </Accordion>

  <Accordion title="تعيد أداة موثقة خطأ مصادقة">
    عيّن `TOKENLAB_API_KEY` في بيئة خادم MCP، وليس في وسائط الأداة أو المطالبة، ثم أعد تشغيل العميل. بدّل أي مفتاح ظهر في ملف مشترك أو صورة أو سجل أو سجل shell.
  </Accordion>

  <Accordion title="يرفض العميل مخططات الأدوات أو يحمّل أدوات كثيرة">
    استخدم `TOKENLAB_MCP_TOOL_PROFILE=catalog` لست أدوات اكتشاف أو ملف `core` الافتراضي لـ31 أداة. احتفظ عادةً بـ`portable`؛ استخدم `exact` للتداخل الكامل و`strict` للكائنات المغلقة مع جميع الخصائص في `required`.
  </Accordion>

  <Accordion title="كيف أثبت إصدار الحزمة أو أحدثه؟">
    استخدم `@tokenlabai/mcp-server@0.6.19` لتثبيت الإصدار المتحقق منه حالياً. لتغييره، حدّث وسيطة الحزمة وأعد تشغيل الخادم وراجع المستودع العام قبل اعتماد إصدار أحدث.
  </Accordion>
</AccordionGroup>
