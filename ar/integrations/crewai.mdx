## نظرة عامة

يدعم CrewAI نماذج LLM المتوافقة مع OpenAI عن طريق تعيين النموذج، ومفتاح API، و base URL في متغيرات البيئة أو في فئة `LLM`.

<Note>
**النوع**: إطار عمل الوكلاء (Agent Framework)

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI (OpenAI-compatible chat completions)

**مستوى دعم الموثوقية**: مسار نقطة النهاية المخصصة مدعوم
</Note>

## متغيرات البيئة

```python
import os

os.environ["OPENAI_API_KEY"] = "sk-your-tokenlab-key"
os.environ["OPENAI_API_BASE"] = "https://api.tokenlab.sh/v1"
os.environ["OPENAI_MODEL_NAME"] = "openai/claude-sonnet-5"
```

## فئة LLM

```python
from crewai import Agent, LLM

llm = LLM(
    model="claude-sonnet-5",
    custom_openai=True,
    base_url="https://api.tokenlab.sh/v1",
    api_key="sk-your-tokenlab-key",
)

agent = Agent(
    role="Research analyst",
    goal="Summarize technical tradeoffs clearly",
    backstory="You produce concise implementation notes.",
    llm=llm,
)
```

## اقتراحات النماذج

استخدم `gpt-5.4-mini` لفرق العمل الروتينية، و `claude-sonnet-5` أو `gpt-5.4` للوكلاء الذين يعتمدون بشكل كبير على التخطيط، و `deepseek-v4-flash` للتكرارات السريعة منخفضة التكلفة.

## ملاحظات حول نقاط النهاية

يُعد مسار CrewAI المتوافق مع OpenAI هو الأفضل لاستدعاءات الوكلاء بنمط Chat Completions. استخدم نقاط نهاية TokenLab الأصلية مباشرة فقط عندما تكون الأداة أو الـ SDK التي تختارها قادرة على التعامل مع تلك البروتوكولات الأصلية.
