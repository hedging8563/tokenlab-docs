## نظرة عامة



<Note>
**النوع**: أداة برمجة

**المسار الرئيسي**: Anthropic-native

**مستوى الدعم**: مسار أصلي قوي
</Note>

يُعد [Claude Code](https://code.claude.com/docs/en/setup) أداة CLI الرسمية من Anthropic للبرمجة بمساعدة AI. يمكنك تهيئته لاستخدام TokenLab كمزوّد API.

## التثبيت

توصي Anthropic الآن بالمُثبّت الأصلي. لا يزال التثبيت عبر npm موجودًا من أجل التوافق، لكنه أصبح مهجورًا من المصدر الأساسي.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

إذا كنت تحتاج تحديدًا إلى حزمة npm، فاستخدم:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
لا تستخدم `sudo npm install -g` مع Claude Code.
</Warning>

## التهيئة

اتبع خطوات الطرفية في [البدء السريع](/ar/quickstart) لنظام macOS أو Linux أو WSL أو Windows PowerShell لتعيين `TOKENLAB_API_KEY` دون كتابة المفتاح في سجل الأوامر. شغّل Claude Code من الطرفية نفسها. للاستخدام الدائم، استخدم مدير أسرار محليًا ولا تُضف المفتاح كنص صريح إلى ملف إعدادات الصدفة.

تسري هذه المتغيرات على هذا التشغيل فقط؛ تبقى إعدادات الحساب والنموذج الافتراضي والأذونات المحفوظة. شغّل بشكل عادي دون هذه المتغيرات لاستخدام الإعداد السابق. لا تحفظها في ملف إعداد الصدفة.

يستخدم هذا المسار Claude Code **2.1.263** ومصادقة Bearer عبر `ANTHROPIC_AUTH_TOKEN`. اترك Base URL دون `/v1`. قد تؤثر قيم `env` المحفوظة ومساعدات الاعتماد وخيارات مزوّد السحابة والسياسات المُدارة في المصادقة؛ افحصها قبل التشغيل. عند التعارض، استخدم المساعد أدناه بدل حذف بيانات الحساب أو تخفيف السياسات. تحقق من النموذج والأذونات عبر `/status`.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

اختياريًا، يتيح [مساعد إعداد Claude Code القابل للاستعادة](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md) المعاينة والتطبيق واستعادة الملف الأصلي باستخدام Python 3.11+. تتضمن إضافة TokenLab Skills **0.1.2** هذه السكربتات؛ ويمكن أيضًا استخدام Skill مستقل بعد تحديثه إلى إصدار يحتوي عليها. للإضافة أو Skill المستقل المثبّت مسبقًا، اتبع [تعليمات تحديث README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) وتأكد من وجود السكربت. تظل خطوات الإعداد اليدوي هنا كافية دون المساعد.

حفظ الإعدادات أو عرض النماذج لا يتحقق من صلاحية المفتاح أو اكتمال طلب. تستخدم المطالبة رصيد TokenLab. راجع الرد و[سجل الطلب المطابق](https://tokenlab.sh/dashboard/runs?section=requests) قبل تجربة الأدوات؛ وقد تُحتسب الطلبات المساعدة أيضًا.

## الاستخدام

بعد التهيئة، استخدم Claude Code بشكل طبيعي:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

تحقق من التثبيت عند الحاجة:

```bash
claude --version
claude doctor
```

## النماذج المتاحة

يدعم TokenLab جميع نماذج Claude:

| النموذج | الوصف |
|-------|-------------|
| `claude-opus-4-6` | الأكثر قدرة، للاستدلال المعقّد |
| `claude-sonnet-4-6` | أداء متوازن، ممتاز للبرمجة |
| `claude-haiku-4-5` | الأسرع، وفعّال من حيث التكلفة |

## اختيار النموذج

حدّد نموذجًا باستخدام الخيار `--model`:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## التفكير الموسّع

لمهام الاستدلال المعقّدة، استخدم النماذج التي تدعم التفكير الموسّع:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```
