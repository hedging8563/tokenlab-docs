## نظرة عامة

يدعم VoltAgent نماذج لغة AI SDK مباشرة. قم بتهيئة مزود AI SDK متوافق مع OpenAI باستخدام عنوان URL الأساسي `/v1` الخاص بـ TokenLab وقم بتمرير النموذج المختار إلى الوكيل الخاص بك.

<Note>
**النوع**: إطار عمل وكيل TypeScript

**المسار الأساسي**: إكمال المحادثة المتوافق مع OpenAI عبر AI SDK

**مستوى الدعم**: مسار متوافق مع OpenAI مدعوم
</Note>

## التثبيت

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## مزود AI SDK المباشر

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## مسار موجه النماذج (Model Router)

إذا كانت لقطة سجل VoltAgent الخاصة بك تتضمن إدخال مزود TokenLab من `models.dev`، فقم بتهيئة ما يلي:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

ثم استخدم سلسلة نموذج السجل، على سبيل المثال `tokenlab/claude-sonnet-5`.

## ملاحظات حول نقاط النهاية

يعد مسار AI SDK المباشر هو الإعداد الأكثر وضوحاً. استخدم استجابات TokenLab الأصلية، أو رسائل Anthropic، أو نقاط نهاية Gemini فقط عندما يتم تهيئة مزود/عميل AI SDK المختار الخاص بك لهذا البروتوكول.
