## نطاق الاستخدام

يخص هذا الدليل **محرر Cursor لسطح المكتب** على macOS وWindows وLinux. يقتصر دعم OpenAI BYOK الرسمي على نماذج المحادثة العادية غير الاستدلالية؛ ويستمر إكمال Tab باستخدام نماذج Cursor. تغيير OpenAI Base URL لا يتيح جميع نماذج TokenLab أو ميزات Cursor. راجع [الحدود الرسمية](https://cursor.com/help/models-and-usage/api-keys).

إذا كنت تحتاج فقط إلى أدوات الصور والفيديو وغيرها من واجهات API، احتفظ بمزوّد المحادثة وأضف [MCP](/ar/integrations/tokenlab-mcp-server). أما [Skill](/ar/integrations/coding-agent-skill) فتقدّم إرشادات ولا تغيّر النموذج الرئيسي.

## مهمة لوكيلك الحالي

```text
اقرأ https://docs.tokenlab.sh/ar/integrations/cursor وتحقق من الإصدار المثبت ونظام التشغيل لديّ.
تأكد هل أحتاج TokenLab كنموذج رئيسي أم أدوات MCP أم Skill لتعليمات API.
احتفظ بالحسابات وإعدادات المزوّدين والأذونات، واشرح كيفية استعادة الإعدادات المعدّلة.
لا تطلب مفاتيح API في المحادثة؛ سأدخلها محليًا وأنفّذ خطوات الواجهة اللازمة.
اشرح تكلفة طلب تحقق صغير، ولا تساعد في تنفيذه ومطابقته بسجل TokenLab إلا بعد اختياري الصريح لذلك الاختبار.
```

## فتح الإعدادات الصحيحة

1. ثبّت نسخة سطح المكتب أو حدّثها من [Cursor Downloads](https://cursor.com/downloads). هذه الخطوات لا تضبط CLI أو Cloud Agents.
2. افتح **Cursor Settings** من لوحة الأوامر أو عبر `Cmd/Ctrl + Shift + J`. الاختصار `Cmd/Ctrl + ,` يفتح إعدادات المحرر العامة.
3. في **Models**، دوّن إعدادات OpenAI الحالية لتتمكن من استعادتها، واحتفظ بإعدادات المزوّدين الآخرين.
4. أدخل مفتاح TokenLab محليًا في **OpenAI API Key** واحفظه. لا ترسله في المحادثة ولا تضعه في git.
5. فعّل **Override OpenAI Base URL** وأدخل:

```text
https://api.tokenlab.sh/v1
```

تمر طلبات BYOK أيضًا عبر خوادم Cursor لتجميع التعليمات؛ ولا يتصل المحرر مباشرةً بـ TokenLab.

## اختيار النموذج

انسخ المعرّف الدقيق من [كتالوج TokenLab الحالي](https://tokenlab.sh/ar/models)، وتحقق من دعمه في مسار OpenAI BYOK داخل Cursor. تصنيف النموذج chat لدى TokenLab لا يثبت توافقه مع Cursor.

لأول اختبار نصي، يمكن استخدام `gpt-4.1-mini` مثالًا لنموذج غير استدلالي إن ظل متاحًا. فعّل إدخاله الحالي في **Models**، أو استخدم **Add model** إن لم يوجد، ثم اختره في المحادثة. لا تكرر نموذجًا مدمجًا بتهجئة مختلفة، ولا تفترض أن Claude أو Gemini يستخدمان تجاوز OpenAI. راجع [توضيح Cursor](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488).

## التحقق بطلب صغير

ابدأ محادثة جديدة بالنموذج المحدد وأرسل:

```text
أجب فقط بـ TOKENLAB_CONNECTION_OK. لا تستخدم أدوات ولا تعدّل ملفات.
```

هذا الطلب مدفوع. تحقق من الإجابة وطابق النموذج والوقت والحالة في [سجل طلبات TokenLab](https://tokenlab.sh/dashboard/runs?section=requests). ظهور نموذج أو وصول إجابة بلا سجل مطابق لا يؤكد هذا المسار.

## معالجة الأخطاء

- **النموذج غائب أو مرفوض:** تحقق من المعرّف وحدود BYOK، واستخدم الإدخال المدمج إن وجد. إعادة التشغيل لا تعالج عدم التوافق.
- **خطأ مصادقة:** تحقق من مفتاح TokenLab في حقل OpenAI ومن Base URL. خطأ الرصيد أو الحصة مختلف عن مفتاح غير صالح.
- **لا يوجد سجل TokenLab:** راجع نموذج المحادثة والتجاوز وخطأ Cursor. إكمال Tab ليس اختبارًا لهذا الاتصال.
- **تعطل مزوّد آخر:** استعد إعدادات OpenAI السابقة أو عطّل التجاوز ثم ابدأ محادثة جديدة.

## إضافة MCP وSkills بشكل مستقل

يضيف [MCP](/ar/integrations/tokenlab-mcp-server) أدوات قابلة للاستدعاء عبر إعدادات MCP في Cursor أو `.cursor/mcp.json`. تحقق أولًا من اكتشاف الأدوات، ثم نفّذ عمليات التوليد المدفوعة المطلوبة فقط. لا يستبدل MCP النموذج الرئيسي.

توفّر [Skills](/ar/integrations/coding-agent-skill) تعليمات API. ضع المجلد كاملًا مع `SKILL.md` وملفاته المرجعية في `.cursor/skills/tokenlab-api-integration/`، وتحقق من **Customize → Skills**. لا توفّر Skill مفتاحًا ولا تثبّت خادم MCP. راجع دليلَي [MCP](https://cursor.com/docs/mcp) و[Skills](https://cursor.com/docs/skills) الرسميين بحسب إصدارك.
