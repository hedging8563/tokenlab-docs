## نظرة عامة

تقوم أداة OpenLLMetry الخاصة بـ OpenAI بتتبع الاستدعاءات التي تتم عبر SDK الرسمي لـ OpenAI. قم بتهيئة ذلك الـ SDK باستخدام عنوان URL الأساسي `/v1` الخاص بـ TokenLab.

<Note>
**النوع**: القابلية للملاحظة (Observability)

**المسار الأساسي**: تتبع (Instrumentation) عبر OpenAI SDK

**مستوى دعم الثقة**: مسار قابلية ملاحظة مدعوم ومتوافق مع OpenAI
</Note>

## التثبيت

```bash
pip install opentelemetry-instrumentation-openai opentelemetry-sdk openai
```

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## مثال

يعرض هذا المثال المستقل بيانات span في الطرفية. إذا كان تطبيقك يتضمن بالفعل tracer provider من OpenTelemetry، فأعد استخدامه مع الـ exporter الخاص به.

```python
import os

from openai import OpenAI
from opentelemetry import trace
from opentelemetry.instrumentation.openai import OpenAIInstrumentor
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import ConsoleSpanExporter, SimpleSpanProcessor

tracer_provider = TracerProvider()
tracer_provider.add_span_processor(SimpleSpanProcessor(ConsoleSpanExporter()))
trace.set_tracer_provider(tracer_provider)

OpenAIInstrumentor().instrument()

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Trace this request"}],
)
```

## ملاحظات حول نقاط النهاية (Endpoints)

استخدم هذا المسار لطلبات TokenLab المتوافقة مع OpenAI SDK. بالنسبة لنقاط نهاية TokenLab الأصلية، قم بتتبع (instrument) عميل HTTP أو SDK الذي يرسل تلك الطلبات فعلياً.
