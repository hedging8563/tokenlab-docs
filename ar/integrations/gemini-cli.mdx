## نظرة عامة

يوثّق Gemini CLI **0.60.0** المتغير `GOOGLE_GEMINI_BASE_URL` لمصادقة مفتاح API. استخدم مسار Gemini الأصلي في TokenLab مع نموذج يدعم `gemini_generate_content`. راجع [مرجع الإعداد الرسمي](https://geminicli.com/docs/reference/configuration/) و[دليل المصادقة](https://geminicli.com/docs/get-started/authentication/). هذا الإعداد لا يمرّر اشتراك Google عبر TokenLab.

## التثبيت

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## التهيئة

اتبع خطوات الطرفية في [البدء السريع](/ar/quickstart) لنظام macOS أو Linux أو WSL أو Windows PowerShell لتعيين `TOKENLAB_API_KEY` دون كتابة المفتاح في سجل الأوامر. شغّل Gemini CLI من الطرفية نفسها. للاستخدام الدائم، استخدم مدير أسرار محليًا ولا تُضف المفتاح كنص صريح إلى ملف إعدادات الصدفة.

احتفظ بتسجيل Google وإعدادك الحالي. لتشغيل TokenLab بشكل منفصل، اختر مجلدًا غير مستخدم مثل `~/.gemini-tokenlab` (`$HOME` في PowerShell) وأنشئ داخله `.gemini`. انسخ `settings.json` الحالي وملفات السياسات اللازمة إلى المواقع المناظرة، مع إبقاء الأذونات والعزل والإعدادات الأخرى. ادمج حقل المصادقة التالي في النسخة فقط، أو أنشئ ملف الإعداد إن لم يكن موجودًا. لا تنسخ ذاكرة OAuth أو تحذف الاعتمادات الأصلية. التزم بسياسة المصادقة المُدارة.

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## الاستخدام

يستخدم التشغيل أدناه `~/.gemini-tokenlab/.gemini/settings.json`. عدّل المسار إن اخترت مجلدًا آخر. وافق على مجلد العمل من خلال مطالبة الثقة المعتادة واحتفظ بسياسات موافقة الأدوات. يُختار النموذج صراحةً لهذه الجلسة.

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

تسري هذه المتغيرات على هذا التشغيل فقط؛ تبقى إعدادات الحساب والنموذج الافتراضي والأذونات المحفوظة. شغّل بشكل عادي دون هذه المتغيرات لاستخدام الإعداد السابق. لا تحفظها في ملف إعداد الصدفة.

## التحقق

حفظ الإعدادات أو عرض النماذج لا يتحقق من صلاحية المفتاح أو اكتمال طلب. تستخدم المطالبة رصيد TokenLab. راجع الرد و[سجل الطلب المطابق](https://tokenlab.sh/dashboard/runs?section=requests) قبل تجربة الأدوات؛ وقد تُحتسب الطلبات المساعدة أيضًا.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
