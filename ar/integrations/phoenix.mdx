## نظرة عامة

يمكن لـ Phoenix تتبع طلبات TokenLab من خلال الأتمتة التلقائية (auto-instrumenting) لعميل OpenAI Python المكون باستخدام عنوان URL الأساسي المتوافق مع OpenAI الخاص بـ TokenLab.

<Note>
**النوع**: القابلية للملاحظة (Observability)

**المسار الأساسي**: أداة OpenAI SDK

**مستوى دعم الثقة**: مسار تتبع متوافق مع OpenAI مدعوم
</Note>

## التثبيت

```bash
pip install arize-phoenix openinference-instrumentation-openai openai
```

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## تسجيل Phoenix

قبل تشغيل هذا المثال، شغّل Phoenix محلياً أو استخدم نشراً موجوداً. يرسل `register()` بيانات التتبع افتراضياً إلى مستقبل OTLP/gRPC المحلي على `http://localhost:4317`. للنشر في موقع آخر، اضبط نقطة نهاية المستقبل والمصادقة وفق [دليل Phoenix](https://arize.com/docs/phoenix/sdk-api-reference/python/arize-phoenix-otel). تثبيت SDK لا يشغّل المستقبل.

```python
from phoenix.otel import register

tracer_provider = register(
    project_name="tokenlab-app",
    auto_instrument=True,
)
```

## استدعاء TokenLab

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Write a short haiku."}],
)

print(response.choices[0].message.content)
```

## ملاحظات حول نقاط النهاية (Endpoints)

يقوم Phoenix بتتبع مسار استدعاء OpenAI SDK. استخدم هذه الصفحة لطلبات TokenLab بنمط Chat Completions. لا يزال من الممكن تتبع نقاط نهاية TokenLab الأصلية الأخرى إذا كانت أداة تطبيقك تلتقط العميل الذي تستخدمه لتلك الطلبات.
