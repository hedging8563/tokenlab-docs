## نظرة عامة

يمكن لـ Agno استخدام TokenLab كمزود نماذج متوافق مع OpenAI للوكلاء وسير العمل.

<Note>
**النوع**: إطار عمل الوكيل (Agent Framework)

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI

**مستوى الدعم**: مسار مدعوم
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## غلاف نموذج TokenLab

إذا كان إصدار Agno الخاص بك يتضمن غلاف نموذج TokenLab:

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

تدعم بعض إصدارات Agno أيضاً سلاسل النماذج (model strings):

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## المسار البديل المتوافق مع OpenAI

إذا كان إصدارك لا يتضمن TokenLab بعد، استخدم مسار النموذج المتوافق مع OpenAI في Agno من خلال:

- Base URL: `https://api.tokenlab.sh/v1`
- API key: `TOKENLAB_API_KEY`
- Model: `gpt-5.4-mini`

## اقتراحات النماذج

استخدم `gpt-5.4-mini` للوكلاء الافتراضيين، و `gpt-5.4` أو `claude-sonnet-5` للاستنتاج الأكثر عمقاً، و `deepseek-v4-flash` للحلقات الأسرع.
