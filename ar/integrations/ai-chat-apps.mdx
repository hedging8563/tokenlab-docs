## نظرة عامة

تتصل معظم تطبيقات الدردشة العامة بالذكاء الاصطناعي بـ TokenLab من خلال مسار الدردشة القياسي المتوافق مع OpenAI.

عملياً، هذا يعني:
- استخدم `https://api.tokenlab.sh/v1` كعنوان URL أساسي (base URL) ما لم يطلب التطبيق صراحةً عنوان URL كاملاً لنقطة النهاية (endpoint URL).
- استخدم مفتاح API الخاص بـ TokenLab كمفتاح API بنمط OpenAI.
- اختر النماذج التي يمكن للتطبيق استخدامها في سير عمل الدردشة القياسي.

<Note>
توضح إعدادات كل تطبيق أدناه واجهة API عند الحاجة إلى اختيارها. تختار بعض التطبيقات Responses بحسب النموذج. استخدم نموذجاً يدعم واجهة API التي يستخدمها التطبيق؛ ولأدوات البرمجة أدلة تكامل منفصلة.
</Note>

<Note>
**النوع**: تطبيق دردشة

**المسار الأساسي**: إكمال الدردشة المتوافق مع OpenAI

**مستوى الدعم**: مسار مدعوم
</Note>

## التطبيقات المدعومة

| التطبيق | المنصة | ملاحظات |
|-------------|----------|-------|
| Open WebUI | الويب، الاستضافة الذاتية | خيار شائع للاستضافة الذاتية مع اتصالات متوافقة مع OpenAI |
| LibreChat | الويب، الاستضافة الذاتية | مساحة عمل دردشة متعددة الموفرين مع نقاط نهاية OpenAI مخصصة |
| LobeChat | الويب، سطح المكتب، الاستضافة الذاتية | دعم قوي للموفرين المخصصين |
| Cherry Studio | Windows, macOS, Linux | تدفق جيد للموفرين المتوافقين مع OpenAI |
| Chatbox | Windows, macOS, Linux | إعداد بسيط متوافق مع OpenAI |
| DeepChat | Windows, macOS, Linux | عميل سطح مكتب مع إعدادات موفر متوافقة مع OpenAI |
| Jan | سطح المكتب، الاستضافة الذاتية | تطبيق محلي أولاً مع موفرين عن بُعد متوافقين مع OpenAI |
| TypingMind | الويب، سطح المكتب | يستخدم نمط نقطة نهاية مخصص |
| NextChat | الويب، الاستضافة الذاتية | عميل خفيف بنمط ChatGPT مع تجاوزات لعنوان URL الأساسي |
| ChatWise | Windows, macOS | نمط الموفر المخصص القياسي |

## قيم الاتصال الافتراضية

| الحقل | القيمة |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| نوع API | متوافق مع OpenAI |

إذا طلب التطبيق **عنوان URL كاملاً لنقطة النهاية** بدلاً من عنوان URL أساسي، استخدم:
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## إعدادات التطبيقات النموذجية

<Tabs>
  <Tab title="LobeChat">
    **استضافة LobeChat ذاتياً**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. افتح **Settings** → **AI Providers**
    2. اختر **OpenAI**
    3. أدخل مفتاح API الخاص بـ TokenLab
    4. اضبط نقطة النهاية المخصصة على `https://api.tokenlab.sh/v1`

    فعّل نموذجاً واختره، ثم أرسل رسالة اختبار. قد يستخدم LobeChat واجهة Responses تلقائياً لبعض نماذج GPT، لذا اختر نموذج TokenLab يدعم واجهة API المستخدمة.
  </Tab>

  <Tab title="Cherry Studio">
    اتبع [دليل إعداد Cherry Studio](/ar/integrations/cherry-studio) لإعداد الاتصال واختيار النموذج وإرسال أول رسالة اختبار.
  </Tab>

  <Tab title="Chatbox">
    اتبع [دليل إعداد Chatbox](/ar/integrations/chatbox) لإعداد الاتصال واختيار النموذج وإرسال أول رسالة اختبار.
  </Tab>

  <Tab title="TypingMind">
    1. افتح **Models** → **Add Custom Models**.
    2. أدخل:
       - **Name**: TokenLab
       - **Endpoint**: `https://api.tokenlab.sh/v1/chat/completions`
       - **Model ID / Context length**: انسخ معرّف النموذج الدقيق وطول السياق من [نماذج TokenLab](https://tokenlab.sh/ar/models).
       - **Custom Headers**: `Authorization: Bearer sk-your-tokenlab-key`
    3. انقر **Test** ثم **Add Model**. اختر النموذج الجديد وأرسل رسالة اختبار.
  </Tab>

  <Tab title="Open WebUI">
    اتبع [دليل إعداد Open WebUI](/ar/integrations/open-webui) لإعداد الاتصال واختيار النموذج وإرسال أول رسالة اختبار.
  </Tab>

  <Tab title="DeepChat">
    اتبع [دليل إعداد DeepChat](/ar/integrations/deepchat) لإعداد الاتصال واختيار النموذج وإرسال أول رسالة اختبار.
  </Tab>

  </Tab>

## نصائح

<AccordionGroup>
  <Accordion title="فضل استخدام عنوان URL الأساسي عندما يدعمه التطبيق">
    تكون معظم التطبيقات أسهل في التهيئة وأقل عرضة للأخطاء عند توفير `https://api.tokenlab.sh/v1` كعنوان URL أساسي بدلاً من عنوان URL كامل لنقطة النهاية.
  </Accordion>

  <Accordion title="استخدم النماذج الأصغر أولاً">
    ابدأ بـ `gpt-5.4-mini` أو `deepseek-v4-flash` للدردشة اليومية، ثم انتقل إلى مهام الاستدلال الأكثر تعقيداً باستخدام `gpt-5.4` أو `claude-opus-4-8`.
  </Accordion>

  <Accordion title="حافظ على فصل أدوات البرمجة">
    غالباً ما تحتاج تطبيقات الدردشة العامة وعملاء البرمجة إلى سلوك مختلف لنقاط النهاية. احتفظ بالأدوات من نوع Codex/Cursor في صفحات التكامل المخصصة لها.
  </Accordion>
</AccordionGroup>

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
  <Accordion title="خطأ في الاتصال">
    - تحقق من أن عنوان URL الأساسي هو بالضبط `https://api.tokenlab.sh/v1`
    - قم بإزالة الشرطات المائلة الزائدة إذا كان التطبيق يضيف مسارات تلقائياً
    - إذا كان التطبيق يطلب عنوان URL كاملاً لنقطة النهاية، استخدم `https://api.tokenlab.sh/v1/chat/completions`
  </Accordion>

  <Accordion title="401 غير مصرح به">
    - تحقق جيداً من مفتاح API الخاص بك
    - تأكد من أن المفتاح نشط في لوحة تحكم TokenLab
    - تأكد من عدم وجود مسافات إضافية أو فواصل أسطر
  </Accordion>

  <Accordion title="النموذج غير متاح">
    - تحقق من اسم النموذج بدقة
    - جرب نموذجاً افتراضياً مدعوماً على نطاق واسع مثل `gpt-5.4-mini` أو `deepseek-v4-flash` أو `claude-sonnet-5`
    - تحقق من التوفر الحالي في وثائق أو لوحة تحكم TokenLab
  </Accordion>
</AccordionGroup>
