## نظرة عامة



<Note>
**النوع**: أداة برمجة

**المسار الرئيسي**: متوافق مع OpenAI

**مستوى الدعم**: مسار مدعوم
</Note>

OpenCode هو مساعد برمجة AI مفتوح المصدر يعمل داخل الطرفية الخاصة بك. وهو يدعم عدة مزوّدي LLM ويمكن تهيئته لاستخدام API الخاصة بـ TokenLab للوصول إلى مئات النماذج.

## التثبيت

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

تحقق من التثبيت:

```bash
opencode --version
```

## التهيئة

### الخطوة 1: تعيين متغيرات البيئة

اتبع خطوات الطرفية في [البدء السريع](/ar/quickstart) لنظام macOS أو Linux أو WSL أو Windows PowerShell لتعيين `TOKENLAB_API_KEY` دون كتابة المفتاح في سجل الأوامر. شغّل OpenCode من الطرفية نفسها. للاستخدام الدائم، استخدم مدير أسرار محليًا ولا تُضف المفتاح كنص صريح إلى ملف إعدادات الصدفة.

### الخطوة 2: تهيئة OpenCode

تم التحقق من الإعداد أدناه باستخدام **OpenCode 1.18.31**. تحتاج الإصدارات الأخرى إلى تحقق مستقل وفق وثائقها الرسمية.

احفظ الإعداد في ملف مستقل `~/.config/opencode/tokenlab.jsonc`. إذا كان `XDG_CONFIG_HOME` محددًا، فاستخدم `opencode/tokenlab.jsonc` داخل ذلك المجلد. احتفظ بملفات `opencode.json` / `opencode.jsonc` المعتادة والحسابات والنموذج الافتراضي والأذونات. لا يُحمّل الملف المستقل إلا عند اختياره عبر `OPENCODE_CONFIG` لهذا التشغيل. إذا كان الملف أو اسم المزوّد مستخدمًا، فاختر اسمًا آخر وعدّل الأوامر.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
يرسل هذا الإعداد طلبات Chat Completions عبر `@ai-sdk/openai-compatible`. تحقق من دعم Chat Completions والأدوات المطلوبة في تفاصيل النموذج الحالية. لا يثبت المثال توافق بروتوكولات أو إصدارات أخرى.
</Note>

اختياريًا، يتيح [مساعد إعداد OpenCode القابل للاستعادة](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md) المعاينة والتطبيق واستعادة الملف الأصلي باستخدام Python 3.11+. تتضمن إضافة TokenLab Skills **0.1.2** هذه السكربتات؛ ويمكن أيضًا استخدام Skill مستقل بعد تحديثه إلى إصدار يحتوي عليها. للإضافة أو Skill المستقل المثبّت مسبقًا، اتبع [تعليمات تحديث README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) وتأكد من وجود السكربت. تظل خطوات الإعداد اليدوي هنا كافية دون المساعد.

## الاستخدام الأساسي

عيّن المفتاح وفق البدء السريع، ثم حمّل الملف واختر النموذج صراحةً لهذا التشغيل فقط. استبدل المسار واسم المزوّد إذا خصصتهما. احتفظ بإعدادات `OPENCODE_CONFIG` أو `OPENCODE_CONFIG_CONTENT` الموجودة واستخدم بيئة تشغيل منفصلة؛ قد تظل إعدادات المشروع أو الإدارة ذات أولوية.

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

تتحقق قائمة النماذج من التحميل المحلي، وليس صلاحية المفتاح أو نجاح طلب فعلي. يستخدم إرسال مطالبة رصيد TokenLab، وقد يرسل OpenCode طلبات مساعدة تُحتسب منفصلة، مثل إنشاء عنوان. راجع الرد و[سجلات الطلبات المطابقة](https://tokenlab.sh/dashboard/runs?section=requests).

شغّل دون تحميل هذا الملف لاستخدام إعدادك المعتاد. لا تحفظ `OPENCODE_CONFIG` في ملف إعداد الصدفة من أجل هذا الدليل. للتراجع عن الإعداد اليدوي، احذف الملف المستقل الذي أنشأته فقط، أو استعد نسخته الاحتياطية إذا كان موجودًا سابقًا.

## النماذج المتاحة

| النموذج | الأفضل لـ |
|-------|----------|
| `gpt-5.6-terra` | المهام المعقدة، بنية الكود |
| `gpt-5.6-luna` | الإصلاحات السريعة، الاستعلامات البسيطة |
| `claude-sonnet-4-6` | مراجعة الكود، التوثيق |

| `gemini-3.5-flash` | الاستجابات السريعة |

## الأوامر الشائعة

**تحليل الكود:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**توليد الكود:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**مراجعة التغييرات:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**إصلاح الأخطاء:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## الأوامر التفاعلية

| الأمر | الوصف |
|---------|-------------|
| `/help` | عرض الأوامر المتاحة |
| `/models` | التبديل إلى نموذج مختلف |
| `/clear` | مسح سجل المحادثة |
| `/exit` | الخروج من OpenCode |

## استكشاف الأخطاء وإصلاحها

<AccordionGroup>
  <Accordion title="خطأ في الاتصال">
    - تحقق من أن `options.baseURL` مضبوط على `https://api.tokenlab.sh/v1`
    - تحقق من اتصال الشبكة
    - جرّب `curl https://api.tokenlab.sh/v1/models` للاختبار
  </Accordion>

  <Accordion title="فشلت المصادقة">
    - تحقق من تعيين متغير البيئة `TOKENLAB_API_KEY`
    - تحقق من أن `options.apiKey` يشير إلى `{env:TOKENLAB_API_KEY}` أو إلى مصدر secret صالح آخر
    - تحقق من أن المفتاح يبدأ بـ `sk-`
    - تأكد من أن المفتاح نشط في لوحة تحكم TokenLab
  </Accordion>

  <Accordion title="النموذج غير موجود">
    - تحقق من أن اسم النموذج في ملف التهيئة مطابق تمامًا
    - تحقق من توفر النموذج على [tokenlab.sh/en/models](https://tokenlab.sh/ar/models)
  </Accordion>
</AccordionGroup>
