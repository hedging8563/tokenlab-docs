## نظرة عامة

يعمل LibreChat بشكل جيد مع TokenLab من خلال نقطة نهاية مخصصة متوافقة مع OpenAI.

<Note>
**النوع**: تطبيق دردشة (Chat App)

**المسار الأساسي**: إكمال الدردشة المتوافق مع OpenAI

**مستوى الثقة في الدعم**: مسار مدعوم
</Note>

## البيئة

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## مثال على نقطة النهاية

أضف TokenLab إلى إعدادات نقطة نهاية LibreChat الخاصة بك:

```yaml
customEndpoints:
  - name: 'TokenLab'
    apiKey: '${TOKENLAB_API_KEY}'
    baseURL: 'https://api.tokenlab.sh/v1'
    models:
      default:
        - 'gpt-5.5'
        - 'gpt-5.4'
        - 'gpt-5.4-mini'
        - 'claude-opus-4-8'
        - 'claude-sonnet-5'
        - 'gemini-3.5-flash'
        - 'deepseek-v4-pro'
        - 'deepseek-v4-flash'
      fetch: true
    titleConvo: true
    titleModel: 'gpt-5.4-mini'
    modelDisplayLabel: 'TokenLab'
```

## ملاحظات

يستخدم LibreChat مسار الدردشة المتوافق مع OpenAI لهذا الإعداد. كما يوفر TokenLab استجابات أصلية (native Responses)، ونقاط نهاية متوافقة مع Anthropic Messages وGemini للعملاء الذين يدعمون أشكال الطلبات تلك.
