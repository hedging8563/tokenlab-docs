## نظرة عامة

يمكن لـ Semantic Kernel استدعاء TokenLab من خلال خدمة إكمال الدردشة (chat completion) الخاصة بنقطة النهاية المخصصة لـ OpenAI.

<Note>
**النوع**: SDK / إطار عمل الوكيل (Agent Framework)

**المسار الأساسي**: إكمال الدردشة المتوافق مع OpenAI

**مستوى دعم الموثوقية**: مسار نقطة النهاية المخصصة مدعوم
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## .NET Kernel Builder

يجب أن تشير نقطة النهاية المخصصة لـ Semantic Kernel إلى المسار الجذري `/v1` المتوافق مع OpenAI، وليس `/v1/chat/completions`.

```csharp
using Microsoft.SemanticKernel;

#pragma warning disable SKEXP0010

var builder = Kernel.CreateBuilder();

builder.AddOpenAIChatCompletion(
    modelId: "gpt-5.4-mini",
    endpoint: new Uri("https://api.tokenlab.sh/v1"),
    apiKey: Environment.GetEnvironmentVariable("TOKENLAB_API_KEY"));

var kernel = builder.Build();
```

## مطالبة أساسية (Basic Prompt)

```csharp
var result = await kernel.InvokePromptAsync(
    "Give me a concise checklist for evaluating an LLM gateway.");

Console.WriteLine(result);
```

## ملاحظات حول نقطة النهاية

استخدم:

```text
https://api.tokenlab.sh/v1
```

لا تستخدم:

```text
https://api.tokenlab.sh/v1/chat/completions
```

يقوم Semantic Kernel بإلحاق مسار إكمال الدردشة داخلياً لهذا الموصل (connector).
