## نظرة عامة

<Note>
**النوع**: وكيل برمجة لبيئة التطوير وسطر الأوامر

**المسار الرئيسي**: Chat Completions متوافق مع OpenAI

**الدعم**: مسار مزوّد مخصص رسمي
</Note>

يدعم [Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible) المزوّدين المتوافقين مع OpenAI في إضافة VS Code وKilo CLI.

## التثبيت والواجهة

ثبّت قناة ما قبل الإصدار من **Kilo Code** في VS Code أو ثبّت CLI:

```bash
npm install -g @kilocode/cli
kilo --version
```

افتح **Settings → Providers → Custom provider**.

| الحقل | القيمة |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | مفتاح TokenLab API الخاص بك |
| Model | `kimi-k3` |

يكتشف Kilo النماذج عبر `/v1/models`. بعد الحفظ اختر `tokenlab/kimi-k3`.

## تهيئة CLI

ضع المفتاح في متغير بيئة وعدّل الملف العام الموثوق `~/.config/kilo/kilo.jsonc`:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

أعد تشغيل Kilo ثم نفّذ `kilo models`. لا تُحل `{env:...}` إلا في إعداد عام موثوق أو مُدار. لا تكتب المفتاح الحقيقي في إعداد مشروع قد يُرسل إلى Git.
