## نظرة عامة

يمكن لـ Flowise استدعاء TokenLab من خلال عقدة محادثة TokenLab عند توفرها، أو من خلال عقدة نموذج محادثة متوافقة مع OpenAI وموجهة نحو TokenLab.

<Note>
**النوع**: منشئ سير العمل (Workflow Builder)

**المسار الأساسي**: إكمال المحادثة المتوافق مع OpenAI

**مستوى دعم الموثوقية**: مدعوم مع حدود في النطاق
</Note>

## عقدة TokenLab

إذا كان إصدار Flowise الخاص بك يتضمن عقدة نموذج محادثة **TokenLab**:

1. أضف **Chat Models** -> **TokenLab**
2. أنشئ بيانات اعتماد API خاصة بـ TokenLab
3. اضبط **Model Name** على `gpt-5.4-mini`
4. قم بتوصيلها بالسلسلة (chain) أو الوكيل (agent) أو سير العمل الخاص بك
5. قم بتشغيل مطالبة اختبار (test prompt).

## البديل المتوافق مع OpenAI

إذا لم تتضمن نسختك عقدة TokenLab، فأضف **Chat Models** → **OpenAI Custom Model**. ضمن **Connect Credential**، أنشئ بيانات اعتماد **OpenAI API** باستخدام مفتاح TokenLab. اضبط **Model Name** و**Additional Parameters** → **Base Path** كما يلي:

| الحقل | القيمة |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

اربط العقدة بالسلسلة أو الوكيل أو سير العمل، ثم أرسل طلباً تجريبياً.

## النماذج الموصى بها

- `gpt-5.4-mini` لمعظم اختبارات سير العمل
- `claude-sonnet-5` لكتابة واستنتاج أقوى
- `gemini-3.5-flash` لسير عمل سريع ومتوافق مع الوسائط المتعددة
- `deepseek-v4-flash` لتكرارات الكود أو الاستنتاج السريعة
