## نظرة عامة

يمكن لـ Chatbox استخدام TokenLab من خلال إعدادات API المتوافقة مع OpenAI.

<Note>
**النوع**: تطبيق دردشة (Chat App)

**المسار الأساسي**: إكمال الدردشة المتوافق مع OpenAI

**مستوى الدعم**: مسار مدعوم
</Note>

## إعداد Chatbox

1. افتح **Settings** -> **Model Provider** -> **Add** -> **Add Custom Provider**
2. اضبط **Name** على TokenLab و**API Mode** على **OpenAI API Compatible**، ثم انقر **Add**.
3. أدخل البيانات التالية:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Path**: `/chat/completions`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. احفظ الإعدادات وأرسل رسالة اختبار قصيرة.

## النماذج الموصى بها

| حالة الاستخدام | النموذج |
|----------|-------|
| الدردشة اليومية | `gpt-5.4-mini` |
| استنتاج أقوى | `gpt-5.4` أو `gpt-5.5` |
| مخرجات بنمط Claude | `claude-sonnet-5` |
| بديل سريع | `deepseek-v4-flash` |

## ملاحظات

إذا كان إصدار Chatbox الخاص بك يدرج TokenLab بالفعل كمزود مدمج، فقم باختياره مباشرة. إذا لم يكن كذلك، فإن مسار المزود المتوافق مع OpenAI المذكور أعلاه هو البديل الأكثر أماناً.
