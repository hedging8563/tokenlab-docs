## نظرة عامة

هذه الصفحة لواجهة OpenHands التي توفر إعدادات **Settings → LLM → Advanced** المعتمدة على LiteLLM. اختر **OpenAI** وأدخل نموذجًا مخصصًا بالبادئة `openai/` ومفتاح TokenLab في حقل المفتاح المحلي وعنوان Base URL أدناه. سجّل الاختيار السابق وأعده عند الانتهاء، مع الحفاظ على الحسابات وأذونات الأدوات. راجع [الإعداد الرسمي المتوافق مع OpenAI](https://docs.openhands.dev/openhands/usage/llms/openai-llms). تختلف إجراءات إعداد CLI والسحابة ونسخة المصدر؛ اتبع تعليمات إصدارك. `make setup-config` ليس أمرًا عامًا للـ CLI المثبّت.

## إعدادات النموذج

احفظ إعدادات المزوّد والنموذج والاتصال الحالية محليًا قبل التعديل. تغيّر هذه الخيارات النموذج النشط؛ استعد القيم السابقة عند الانتهاء. أبقِ الحسابات المسجّلة وأذونات الأدوات كما هي، ولا تستبدل اتصالًا آخر متوافقًا مع OpenAI دون نسخة احتياطية قابلة للاستعادة.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

حفظ الإعدادات أو عرض النماذج لا يتحقق من صلاحية المفتاح أو اكتمال طلب. تستخدم المطالبة رصيد TokenLab. راجع الرد و[سجل الطلب المطابق](https://tokenlab.sh/dashboard/runs?section=requests) قبل تجربة الأدوات؛ وقد تُحتسب الطلبات المساعدة أيضًا.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
