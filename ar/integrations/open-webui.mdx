## نظرة عامة

يدعم Open WebUI اتصالات API مخصصة متوافقة مع OpenAI. أضف TokenLab كنقطة نهاية (endpoint) بعيدة متوافقة مع OpenAI وقم بتحديث قائمة النماذج.

<Note>
**النوع**: تطبيق دردشة ويب

**المسار الأساسي**: إكمال الدردشة المتوافق مع OpenAI

**مستوى الدعم**: مسار تطبيق دردشة مدعوم
</Note>

## اتصال المسؤول

1. افتح **Admin Panel** -> **Settings** -> **Connections**.
2. في منطقة اتصال OpenAI API، أضف اتصالاً جديداً.
3. اضبط عنوان URL الأساسي (base URL) على `https://api.tokenlab.sh/v1`.
4. اضبط مفتاح API على مفتاح TokenLab الخاص بك.
5. احفظ الاتصال وقم بتحديث النماذج.

## القيم

| الحقل | القيمة |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| نموذج تجريبي | `gpt-5.4-mini` |

## النماذج الموصى بها

- `gpt-5.4-mini` للدردشة العامة
- `claude-sonnet-5` للكتابة والاستنتاج
- `deepseek-v4-pro` للدردشة التي تتطلب كتابة أكواد برمجية مكثفة
- `gemini-3.5-flash` لسير العمل السريع والمتوافق مع الوسائط المتعددة

لتحديد معرّفات النماذج يدوياً، عدّل هذا الاتصال وافتح **Advanced** → **Model IDs (Filter)**. أضف معرّفات نماذج TokenLab الدقيقة، ثم احفظ.
