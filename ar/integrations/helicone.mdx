## نظرة عامة

يمكن لـ Helicone إجراء عملية الوكيل (proxy) ومراقبة طلبات TokenLab المتوافقة مع OpenAI عن طريق توجيهها عبر Helicone Gateway واستهداف TokenLab.

<Note>
**النوع**: بوابة المراقبة (Observability Gateway)

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI عبر Helicone Gateway

**مستوى دعم الموثوقية**: مسار مراقبة مدعوم
</Note>

## البيئة

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## النطاق

هذا الإعداد مخصص لحركة مرور `/v1` المتوافقة مع OpenAI. توفر TokenLab أيضاً استجابات أصلية (native Responses)، ورسائل Anthropic، ونقاط نهاية متوافقة مع Gemini؛ استخدم مسارات TokenLab المباشرة لتلك التنسيقات الأصلية ما لم يكن وكيل المراقبة الخاص بك يدعمها بشكل صريح.
