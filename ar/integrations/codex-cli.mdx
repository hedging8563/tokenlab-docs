## نظرة عامة

يمكن لـ Codex CLI الاتصال بـ TokenLab عبر `/v1/responses`. يجب أن يتضمن `tokenlab.accepted_request_formats` للنموذج المختار القيمة `openai_responses`؛ وقد تختلف الميزات حسب النموذج.

يدعم Codex CLI الضغط البعيد عبر `POST /v1/responses/compact`. يرسل Codex قيمة `model` الخاصة بالجلسة الحالية في `body.model` عند استخدام `/compact` والضغط التلقائي، لذلك يجب أن يكون النموذج الذي تريد استخدامه للضغط متاحا على مسار Responses. لا تقم بضبط `/v1/compact`.

## متطلبات النظام

اتبع [دليل CLI الرسمي](https://learn.chatgpt.com/docs/codex/cli) لنظام macOS أو Linux أو Windows. Windows الأصلي وWSL بيئتان منفصلتان؛ راجع [دليل Windows](https://learn.chatgpt.com/docs/windows/windows-sandbox). npm خيار تثبيت وليس شرطًا للملفات التنفيذية الأصلية.

## التثبيت

```bash
npm install -g @openai/codex@0.149.0
```

التحقق من التثبيت:

```bash
codex --version
```

## التكوين

### الخطوة 1: تعيين مفتاح API

اتبع خطوات الطرفية في [البدء السريع](/ar/quickstart) لنظام macOS أو Linux أو WSL أو Windows PowerShell لتعيين `TOKENLAB_API_KEY` دون كتابة المفتاح في سجل الأوامر. شغّل Codex من الطرفية نفسها. للاستخدام الدائم، استخدم مدير أسرار محليًا ولا تُضف المفتاح كنص صريح إلى ملف إعدادات الصدفة.

### الخطوة 2: تكوين tokenlab.config.toml

استخدم ملف `tokenlab.config.toml` مستقلًا داخل `CODEX_HOME` النشط (عادةً `~/.codex`) مع Codex **0.149.0**. أنشئه فقط إن لم يكن الاسم مستخدمًا، أو انسخه احتياطيًا قبل تعديل ملف TokenLab موجود. يُحمّل الملف صراحةً عبر `codex --profile tokenlab` مع إبقاء `config.toml` و`auth.json` والحسابات وسياسات الأذونات الحالية. لا تستخدم جدول `[profiles.tokenlab]` القديم. شغّل دون هذا الملف للعودة إلى إعدادك المعتاد. راجع [إعداد الملفات الرسمي](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles).

```toml
model_provider = "tokenlab"
model = "gpt-5.6-sol"
model_reasoning_effort = "xhigh"

[model_providers.tokenlab]
env_key = "TOKENLAB_API_KEY"
name = "TokenLab"
base_url = "https://api.tokenlab.sh/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000
```

وضع WebSocket هذا هو جسر Responses-over-WebSocket لعملاء Codex. يقبل أحداث `response.create` الرسمية فقط؛ يكون `stream` ضمنيًا، ولا تتوفر `background` أو `response.cancel` على هذا النقل. وهو ليس OpenAI Realtime API ولا يقبل `session.update` أو `conversation.item.*` أو `input_audio_buffer.*` أو الصوت الثنائي أو أغلفة Realtime المتداخلة `response.create.response`.

<Note>
أنشئ ملف الإعداد المختار إذا لم يكن موجودًا. بعد تعديله، ابدأ جلسة جديدة باستخدام الأمر المطابق أدناه.
</Note>

يستخدم Codex الحالي `wire_api = "responses"` وليس `chat/completions`. احذف إعداد `requires_openai_auth` أو اجعله false كي يستخدم هذا المزود `env_key`.

<Note>
لا تُحوّل طلبات Responses إلى Chat Completions. تعتمد الحقول الاختيارية والمستقبلية على النموذج المختار.
</Note>

## الاستخدام الأساسي

**بدء الوضع التفاعلي:**

```bash
codex --profile tokenlab
```

**أمر مباشر:**

```bash
codex --profile tokenlab "Fix the bug in main.py line 42"
```

**تحديد النموذج:**

```bash
codex --profile tokenlab -m gpt-5.6-sol "Build a REST API server"
```

## اختيار نموذج

اختر نموذجًا تتضمن قائمة `tokenlab.accepted_request_formats` الحالية له القيمة `openai_responses`. قارن النماذج في مهامك وتحقق من الأسعار الحالية في [صفحة النماذج](https://tokenlab.sh/ar/models).

## الأوامر التفاعلية

| الأمر | الوصف |
|---------|-------------|
| `/help` | عرض المساعدة |
| `/exit` or `Ctrl+C` | الخروج |
| `/clear` | مسح المحادثة |
| `/status` | عرض النموذج النشط والصلاحيات واستخدام الرموز |
| `/model <name>` | تبديل النموذج |

## التحقق من التكوين

تحقق فقط من تعيين متغير البيئة دون طباعة قيمته. هذا الفحص لا يتحقق من صلاحية المفتاح:

```bash
if [ -n "${TOKENLAB_API_KEY:-}" ]; then
  printf '%s\n' 'TOKENLAB_API_KEY is set'
else
  printf '%s\n' 'TOKENLAB_API_KEY is not set'
fi
```

شغّل Codex ونفّذ `/status` للتحقق من النموذج النشط والصلاحيات. إذا كنت تستخدم ملف تعريف، فشغّل ملف التعريف نفسه. راجع [أمر الحالة الرسمي](https://learn.chatgpt.com/docs/developer-commands?surface=cli#inspect-the-session-with-status).

عندما تكون مستعدًا لإرسال طلب حقيقي، نفّذ الأمر التالي. سيستخدم رصيدك في TokenLab. تحقق من الرد والسجل المطابق في [الطلبات](https://tokenlab.sh/dashboard/runs?section=requests). تعيين المتغير أو نجاح بدء التشغيل وحده لا يثبت نجاح الطلب.

```bash
codex --profile tokenlab "Reply only with OK. Do not use tools or modify files."
```

## حالات استخدام شائعة

**مراجعة الشيفرة:**

```bash
git diff | codex --profile tokenlab "Review these code changes"
```

**توليد رسائل الالتزام:**

```bash
git diff --staged | codex --profile tokenlab "Generate a commit message for these changes"
```

**إصلاح الأخطاء:**

```bash
codex --profile tokenlab "Fix the TypeScript errors in src/components/"
```

**شرح الشيفرة:**

```bash
cat main.py | codex --profile tokenlab "Explain what this code does"
```
