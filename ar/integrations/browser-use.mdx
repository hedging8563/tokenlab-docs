## نظرة عامة

يمكن لـ Browser Use استدعاء TokenLab من خلال `ChatOpenAILike`، وهو غلاف نموذج الدردشة المتوافق مع OpenAI.

<Note>
**النوع**: إطار عمل وكيل أتمتة المتصفح

**المسار الأساسي**: Chat Completions المتوافقة مع OpenAI

**مستوى دعم الموثوقية**: مسار مدعوم ومتوافق مع OpenAI
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## مثال

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    add_schema_to_system_prompt=True,
    dont_force_structured_output=True,
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## ملاحظات حول نقاط النهاية (Endpoint Notes)

استخدم هذه الصفحة لسير عمل Browser Use التي تستدعي Chat Completions من خلال عميل متوافق مع OpenAI. إذا كان سير العمل الخاص بك يتطلب استجابات TokenLab الأصلية، أو رسائل Anthropic، أو نقاط نهاية Gemini، فاستخدم مسار عميل في Browser Use يتحدث ذلك البروتوكول مباشرة.
