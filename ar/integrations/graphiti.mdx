## نظرة عامة

يدعم Graphiti نقاط النهاية `/v1` المتوافقة مع OpenAI من خلال `OpenAIGenericClient`. قم بتوجيه هذا العميل إلى TokenLab واختر نموذج TokenLab المناسب.

<Note>
**النوع**: إطار عمل ذاكرة الرسم البياني المعرفي (Knowledge graph memory framework)

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI (OpenAI-compatible Chat Completions)

**مستوى دعم الموثوقية**: مسار مدعوم ومتوافق مع OpenAI
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## عميل LLM

```python
import os

from graphiti_core.llm_client.config import LLMConfig
from graphiti_core.llm_client.openai_generic_client import OpenAIGenericClient

llm_config = LLMConfig(
    api_key=os.environ["TOKENLAB_API_KEY"],
    model="claude-sonnet-5",
    small_model="gpt-5.4-mini",
    base_url="https://api.tokenlab.sh/v1",
)

llm_client = OpenAIGenericClient(config=llm_config)
```

قم بتمرير `llm_client` إلى مثيل `Graphiti(...)` الخاص بك بجانب إعدادات قاعدة بيانات الرسم البياني والمُضمّن (embedder) لديك.

## ملاحظات حول نقطة النهاية

مسار Graphiti المتوافق مع OpenAI موجه نحو إكمال المحادثات (chat-completions). استخدم النماذج التي تعيد JSON مهيكلاً بشكل موثوق لمهام الاستخراج وإلغاء التكرار (deduplication).
