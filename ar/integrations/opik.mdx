## نظرة عامة

يمكن لـ Opik تسجيل استدعاءات TokenLab عن طريق تغليف عميل OpenAI الذي يشير إلى نقطة نهاية TokenLab المتوافقة مع OpenAI.

<Note>
**النوع**: القابلية للملاحظة (Observability)

**المسار الأساسي**: غلاف تتبع OpenAI SDK

**مستوى دعم الثقة**: مسار تتبع مدعوم ومتوافق مع OpenAI
</Note>

## التثبيت

```bash
pip install opik openai
```

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export OPIK_PROJECT_NAME="tokenlab-integration-demo"
```

## تغليف عميل OpenAI

اضبط Opik قبل تشغيل المثال: يتطلب Opik Cloud متغير `OPIK_API_KEY`، وكذلك `OPIK_WORKSPACE` عند الحاجة. للنشر الذاتي الموجود، اضبط `OPIK_URL_OVERRIDE` على عنوان API الخاص به، مثل `http://localhost:5173/api`. راجع [دليل إعداد Opik](https://www.comet.com/docs/opik/tracing/advanced/sdk_configuration).

```python
import os

from openai import OpenAI
from opik.integrations.openai import track_openai

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

openai_client = track_openai(client)
```

## تسجيل إكمال المحادثة (Chat Completion)

```python
completion = openai_client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[
        {"role": "user", "content": "Summarize why LLM observability matters."}
    ],
)

print(completion.choices[0].message.content)
```

## ملاحظات حول نقطة النهاية

يقوم هذا الإعداد بتتبع مسار SDK المتوافق مع OpenAI. إذا كنت تستخدم نقاط نهاية TokenLab الأصلية خارج نطاق OpenAI SDK، فيجب عليك تهيئة ذلك العميل أو سير العمل بشكل منفصل.
