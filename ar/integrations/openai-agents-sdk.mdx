## نظرة عامة

يمكن لـ OpenAI Agents SDK استخدام TokenLab من خلال عميل متوافق مع OpenAI و `OpenAIChatCompletionsModel`.

<Note>
**النوع**: Python Agent SDK

**المسار الأساسي**: إكمال المحادثات المتوافق مع OpenAI

**مستوى دعم الموثوقية**: مسار إكمال المحادثات مدعوم
</Note>

## البيئة

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
export TOKENLAB_MODEL="gpt-5.4-mini"
```

## مثال

```python
import asyncio
import os

from openai import AsyncOpenAI

from agents import Agent, OpenAIChatCompletionsModel, Runner, set_tracing_disabled

client = AsyncOpenAI(
    base_url=os.getenv("TOKENLAB_BASE_URL", "https://api.tokenlab.sh/v1"),
    api_key=os.environ["TOKENLAB_API_KEY"],
)

set_tracing_disabled(disabled=True)


async def main():
    agent = Agent(
        name="Assistant",
        instructions="You are concise and practical.",
        model=OpenAIChatCompletionsModel(
            model=os.getenv("TOKENLAB_MODEL", "gpt-5.4-mini"),
            openai_client=client,
        ),
    )

    result = await Runner.run(agent, "Explain custom model providers in one paragraph.")
    print(result.final_output)


asyncio.run(main())
```

## النطاق

يستخدم هذا المسار توافقية Chat Completions. نقطة نهاية Responses الأصلية الخاصة بـ TokenLab متاحة على `https://api.tokenlab.sh/v1/responses`، ولكن يجب التحقق من ميزات SDK التي تعتمد على دلالات Responses الخاصة بـ OpenAI مع النموذج وسير العمل المحدد قبل الاستخدام في بيئة الإنتاج.
