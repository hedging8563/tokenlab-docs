## Gambaran Umum

Chatbox dapat menggunakan TokenLab melalui pengaturan API yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Aplikasi Chat

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur didukung
</Note>

## Mengonfigurasi Chatbox

1. Buka **Settings** -> **Model Provider** -> **Add** -> **Add Custom Provider**
2. Atur **Name** ke TokenLab dan **API Mode** ke **OpenAI API Compatible**, lalu klik **Add**.
3. Masukkan:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Path**: `/chat/completions`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. Simpan dan kirim pesan tes singkat.

## Model yang Direkomendasikan

| Kasus Penggunaan | Model |
|----------|-------|
| Chat sehari-hari | `gpt-5.4-mini` |
| Penalaran lebih kuat | `gpt-5.4` atau `gpt-5.5` |
| Output gaya Claude | `claude-sonnet-5` |
| Fallback cepat | `deepseek-v4-flash` |

## Catatan

Jika build Chatbox Anda sudah mencantumkan TokenLab sebagai penyedia bawaan, pilih penyedia tersebut secara langsung. Jika tidak, jalur penyedia yang kompatibel dengan OpenAI di atas adalah fallback yang paling aman.
