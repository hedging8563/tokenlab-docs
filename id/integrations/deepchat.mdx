## Gambaran Umum

DeepChat bekerja dengan TokenLab melalui konfigurasi penyedia standar yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Aplikasi Chat

**Jalur Utama**: Penyelesaian chat yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur didukung
</Note>

## Konfigurasi DeepChat

1. Buka **Settings** -> **Model Provider**
2. Tambahkan atau edit penyedia yang kompatibel dengan OpenAI
3. Masukkan:
   - **Provider name**: TokenLab
   - **API Type**: **OpenAI Completions** (Chat Completions)
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Tambahkan model seperti `gpt-5.4-mini`
5. Simpan dan uji chat.

## Pilihan Model

Mulailah dengan `gpt-5.4-mini` sebagai default yang ringan. Gunakan `claude-sonnet-5`, `gpt-5.4`, atau `deepseek-v4-pro` ketika percakapan membutuhkan penalaran yang lebih kuat.

## Pemecahan Masalah

- Gunakan base URL, bukan jalur lengkap `/chat/completions`, kecuali jika DeepChat secara eksplisit meminta URL endpoint lengkap.
- Hapus spasi tambahan dari API key.
- Jika model tidak tercantum, tambahkan id model TokenLab yang tepat secara manual.
