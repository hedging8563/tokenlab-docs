## Gambaran Umum

Konfigurasikan TokenLab sebagai host kustom yang kompatibel dengan OpenAI di Portkey. Gunakan Responses hanya jika versi Portkey Anda mendukung endpoint Responses kustom.

<Note>
**Tipe**: AI Gateway

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI dan Responses

**Tingkat Dukungan**: Jalur didukung
</Note>

## Nilai Penyedia

| Kolom | Nilai |
|-------|-------|
| Provider | `openai` |
| Custom Host | `https://api.tokenlab.sh/v1` |
| API key | `sk-your-tokenlab-key` |
| Model | ID model TokenLab yang tersedia saat ini |

## Chat Completions

Gunakan TokenLab untuk permintaan chat yang kompatibel dengan OpenAI:

Contoh ini memerlukan Portkey Gateway yang dihosting sendiri dan sudah berjalan. Ganti URL gateway dengan URL deployment Anda. Untuk Portkey Cloud, kirim juga API key Portkey melalui `x-portkey-api-key`. Lihat [panduan konfigurasi Portkey](https://portkey.ai/docs/api-reference/inference-api/headers).

```bash
curl https://your-portkey-gateway.example/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-portkey-provider: openai" \
  -H "x-portkey-custom-host: https://api.tokenlab.sh/v1" \
  -H "Authorization: Bearer sk-your-tokenlab-key" \
  -d '{
    "model": "gpt-5.6-luna",
    "messages": [{"role": "user", "content": "Say hello from TokenLab."}]
  }'
```

## Responses

Jika versi Portkey Anda mendukung URL Responses kustom, pilih model yang tersedia dan mendukung Responses dari [halaman model](https://tokenlab.sh/id/models), lalu gunakan `/v1/responses`.

## Catatan Endpoint Native

Anthropic Messages dan Gemini hanya dapat digunakan melalui Portkey jika versi Portkey Anda mendukung URL kustom untuk format tersebut.
