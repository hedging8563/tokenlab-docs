## Gambaran Umum

Halaman ini untuk antarmuka OpenHands dengan LiteLLM dan **Settings → LLM → Advanced**. Pilih **OpenAI**, masukkan model khusus berprefiks `openai/`, kunci TokenLab pada kolom lokal, dan Base URL di bawah. Catat pilihan sebelumnya lalu pulihkan setelah selesai; pertahankan akun dan izin alat. Lihat [konfigurasi kompatibel OpenAI resmi](https://docs.openhands.dev/openhands/usage/llms/openai-llms). Instalasi CLI, cloud, dan dari sumber dapat memakai alur berbeda; ikuti edisi yang dipasang. `make setup-config` bukan perintah umum CLI yang telah terpasang.

## Pengaturan Model

Simpan penyedia, model, dan pengaturan koneksi saat ini secara lokal sebelum mengedit. Kontrol ini mengubah model aktif; pulihkan nilai sebelumnya setelah selesai. Pertahankan akun yang masuk dan izin alat. Jangan timpa koneksi kompatibel OpenAI lain tanpa cadangan yang dapat dipulihkan.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

Menyimpan pengaturan atau menampilkan model tidak memvalidasi kunci maupun permintaan yang selesai. Prompt memakai saldo TokenLab. Periksa respons dan [catatan permintaan terkait](https://tokenlab.sh/dashboard/runs?section=requests) sebelum mencoba alat; permintaan tambahan juga dapat dikenai biaya.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
