## Ikhtisar

<Note>
**Tipe**: agen coding IDE dan CLI

**Jalur utama**: Chat Completions kompatibel OpenAI

**Dukungan**: jalur penyedia khusus resmi
</Note>

[Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible) mendukung penyedia kompatibel OpenAI pada ekstensi VS Code dan CLI.

## Instalasi dan UI

Instal kanal pre-release **Kilo Code** di VS Code atau instal CLI:

```bash
npm install -g @kilocode/cli@7.7.2
kilo --version
```

Buka **Settings → Providers → Custom provider**.

Simpan penyedia, model, dan pengaturan koneksi saat ini secara lokal sebelum mengedit. Kontrol ini mengubah model aktif; pulihkan nilai sebelumnya setelah selesai. Pertahankan akun yang masuk dan izin alat. Jangan timpa koneksi kompatibel OpenAI lain tanpa cadangan yang dapat dipulihkan.

| Kolom | Nilai |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | TokenLab API Key Anda |
| Model | `kimi-k3` |

Kilo mendeteksi model melalui `/v1/models`. Setelah disimpan, pilih `tokenlab/kimi-k3`.

## Konfigurasi CLI

Ikuti langkah terminal [panduan cepat](/id/quickstart) untuk macOS, Linux, WSL, atau Windows PowerShell guna mengatur `TOKENLAB_API_KEY` tanpa menulis kunci ke riwayat perintah. Jalankan Kilo dari terminal tersebut. Untuk penggunaan berkelanjutan, gunakan pengelola rahasia lokal, bukan kunci teks biasa di profil shell.

Sebelum menjalankan Kilo **7.7.2**, cadangkan konfigurasi global aktif dan periksa `permission.bash`. Versi ini menambahkan `bash: "allow"` pada konfigurasi lama tanpa aturan eksplisit tersebut, meskipun `permission["*"]` bernilai `deny`. Pertahankan aturan shell saat ini secara eksplisit: jika aturan wildcard yang ada adalah `deny`, gabungkan `"bash": "deny"` ke objek `permission` tanpa mengubah aturan lain. Berkas penyedia terpisah tidak mencegah migrasi klien ini.

Simpan konfigurasi di file terpisah `~/.config/kilo/tokenlab.jsonc`. Jika `XDG_CONFIG_HOME` diatur, gunakan `kilo/tokenlab.jsonc` di direktori tersebut. Pertahankan `kilo.json` / `kilo.jsonc` biasa, akun, model default, dan izin. File terpisah ini hanya dimuat saat peluncuran memilihnya melalui `KILO_CONFIG`. Jika file atau nama penyedia sudah dipakai, pilih nama lain dan sesuaikan perintah.

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "provider": {
    "tokenlab": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "modalities": {
            "input": [
              "text",
              "image"
            ],
            "output": [
              "text"
            ]
          },
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        }
      },
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab"
    }
  }
}
```

<CodeGroup>
```bash macOS / Linux / WSL
KILO_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/kilo/tokenlab.jsonc" kilo models tokenlab
KILO_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/kilo/tokenlab.jsonc" kilo --model tokenlab/kimi-k3
```

```powershell Windows PowerShell
$previous = @{}
$previous['KILO_CONFIG'] = [Environment]::GetEnvironmentVariable('KILO_CONFIG', 'Process')
try {
  $env:KILO_CONFIG = (Join-Path $(if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }) 'kilo/tokenlab.jsonc')
  kilo models tokenlab
  kilo --model tokenlab/kimi-k3
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Menyimpan pengaturan atau menampilkan model tidak memvalidasi kunci maupun permintaan yang selesai. Prompt memakai saldo TokenLab. Periksa respons dan [catatan permintaan terkait](https://tokenlab.sh/dashboard/runs?section=requests) sebelum mencoba alat; permintaan tambahan juga dapat dikenai biaya.
