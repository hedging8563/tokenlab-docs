## Gambaran Umum

Semantic Kernel dapat memanggil TokenLab melalui layanan penyelesaian chat endpoint kustom OpenAI-nya.

<Note>
**Tipe**: SDK / Kerangka Kerja Agen

**Jalur Utama**: Penyelesaian chat yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur endpoint kustom yang didukung
</Note>

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## .NET Kernel Builder

Endpoint kustom Semantic Kernel harus mengarah ke endpoint root `/v1` yang kompatibel dengan OpenAI, bukan `/v1/chat/completions`.

```csharp
using Microsoft.SemanticKernel;

#pragma warning disable SKEXP0010

var builder = Kernel.CreateBuilder();

builder.AddOpenAIChatCompletion(
    modelId: "gpt-5.4-mini",
    endpoint: new Uri("https://api.tokenlab.sh/v1"),
    apiKey: Environment.GetEnvironmentVariable("TOKENLAB_API_KEY"));

var kernel = builder.Build();
```

## Prompt Dasar

```csharp
var result = await kernel.InvokePromptAsync(
    "Give me a concise checklist for evaluating an LLM gateway.");

Console.WriteLine(result);
```

## Catatan Endpoint

Gunakan:

```text
https://api.tokenlab.sh/v1
```

Jangan gunakan:

```text
https://api.tokenlab.sh/v1/chat/completions
```

Semantic Kernel menambahkan jalur penyelesaian chat secara internal untuk konektor ini.
