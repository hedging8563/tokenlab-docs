## Ringkasan

OpenCode adalah asisten coding AI open-source yang berjalan di terminal Anda. Ini mendukung banyak penyedia LLM dan dapat dikonfigurasikan untuk menggunakan API TokenLab guna mengakses ratusan model.


<Note>
**Jenis**: Alat coding

**Jalur utama**: kompatibel OpenAI

**Tingkat dukungan**: Jalur yang didukung
</Note>

## Instalasi

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

Verifikasi instalasi:

```bash
opencode --version
```

## Konfigurasi

### Langkah 1: Atur Environment Variable

Ikuti langkah terminal [panduan cepat](/id/quickstart) untuk macOS, Linux, WSL, atau Windows PowerShell guna mengatur `TOKENLAB_API_KEY` tanpa menulis kunci ke riwayat perintah. Jalankan OpenCode dari terminal tersebut. Untuk penggunaan berkelanjutan, gunakan pengelola rahasia lokal, bukan kunci teks biasa di profil shell.

### Langkah 2: Konfigurasikan OpenCode

Konfigurasi berikut telah diperiksa dengan **OpenCode 1.18.31**. Versi lain perlu diverifikasi sendiri berdasarkan dokumentasi resminya.

Simpan konfigurasi di file terpisah `~/.config/opencode/tokenlab.jsonc`. Jika `XDG_CONFIG_HOME` diatur, gunakan `opencode/tokenlab.jsonc` di direktori tersebut. Pertahankan `opencode.json` / `opencode.jsonc` biasa, akun, model default, dan izin. File terpisah ini hanya dimuat saat peluncuran memilihnya melalui `OPENCODE_CONFIG`. Jika file atau nama penyedia sudah dipakai, pilih nama lain dan sesuaikan perintah.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
Konfigurasi ini mengirim Chat Completions melalui `@ai-sdk/openai-compatible`. Periksa dukungan Chat Completions dan alat yang diperlukan pada detail model saat ini. Contoh ini tidak membuktikan kompatibilitas protokol atau versi lain.
</Note>

Opsional: [helper konfigurasi OpenCode yang dapat dipulihkan](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md) menyediakan pratinjau, penerapan, dan pemulihan file asli dengan Python 3.11+. ## Penggunaan Dasar

Atur kunci sesuai panduan cepat, lalu muat file hanya untuk peluncuran ini dan pilih model secara eksplisit. Sesuaikan path serta nama penyedia kustom. Pertahankan pengaturan `OPENCODE_CONFIG` atau `OPENCODE_CONFIG_CONTENT` yang sudah ada dalam lingkungan peluncuran terpisah; pengaturan proyek atau terkelola masih dapat memiliki prioritas.

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

Daftar model memeriksa pemuatan lokal, bukan validitas kunci atau keberhasilan permintaan langsung. Prompt memakai saldo TokenLab dan OpenCode dapat mengirim permintaan tambahan yang ditagih terpisah, seperti pembuatan judul. Periksa respons dan [catatan permintaan terkait](https://tokenlab.sh/dashboard/runs?section=requests).

Jalankan tanpa file ini untuk memakai pengaturan biasa. Jangan menyimpan `OPENCODE_CONFIG` dalam profil shell untuk panduan ini. Untuk membatalkan konfigurasi manual, hapus hanya file terpisah yang baru dibuat atau pulihkan cadangannya jika sudah ada sebelumnya.

## Perintah Umum

**Analisis kode:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**Hasilkan kode:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**Review perubahan:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**Perbaiki error:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## Perintah Interaktif

| Command | Deskripsi |
|---------|-------------|
| `/help` | Tampilkan perintah yang tersedia |
| `/models` | Beralih ke model yang berbeda |
| `/clear` | Hapus riwayat percakapan |
| `/exit` | Keluar dari OpenCode |

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Error Koneksi">
    - Verifikasi `options.baseURL` diatur ke `https://api.tokenlab.sh/v1`
    - Periksa konektivitas jaringan
    - Coba `curl https://api.tokenlab.sh/v1/models` untuk pengujian
  </Accordion>

  <Accordion title="Autentikasi Gagal">
    - Verifikasi environment variable `TOKENLAB_API_KEY` telah diatur
    - Verifikasi `options.apiKey` mereferensikan `{env:TOKENLAB_API_KEY}` atau sumber secret valid lainnya
    - Periksa bahwa key diawali dengan `sk-`
    - Pastikan key aktif di dashboard TokenLab
  </Accordion>

  <Accordion title="Model Tidak Ditemukan">
    - Periksa nama model di config harus sama persis
    - Verifikasi ketersediaan model di [tokenlab.sh/en/models](https://tokenlab.sh/id/models)
  </Accordion>
</AccordionGroup>
