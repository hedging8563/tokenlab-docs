## Ringkasan

OpenCode adalah asisten coding AI open-source yang berjalan di terminal Anda. Ini mendukung banyak penyedia LLM dan dapat dikonfigurasikan untuk menggunakan API TokenLab guna mengakses ratusan model.


<Note>
**Jenis**: Alat coding

**Jalur utama**: kompatibel OpenAI

**Tingkat dukungan**: Jalur yang didukung
</Note>

## Instalasi

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

Verifikasi instalasi:

```bash
opencode --version
```

## Konfigurasi

### Langkah 1: Atur Environment Variable

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

Untuk konfigurasi permanen, tambahkan ke `~/.bashrc` atau `~/.zshrc`:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### Langkah 2: Konfigurasikan OpenCode

Dokumentasi OpenCode saat ini merekomendasikan konfigurasi penyedia melalui `opencode.json` atau `opencode.jsonc`. Untuk TokenLab, gunakan penyedia kustom alih-alih menimpa penyedia bawaan `openai`:

Contoh memakai format V1 yang didukung. Gabungkan ke `~/.config/opencode/opencode.json` dan pertahankan penyedia serta izin. V2 membaca V1 yang didukung; jangan campur format dalam satu penyedia. Lihat [panduan migrasi](https://opencode.ai/v2/docs/migrate-v1/). Periksa `/models`, lalu cocokkan uji berbayar dengan catatan TokenLab. Untuk membatalkan, pilih model lama dan hapus entri ini saja.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
Gunakan `@ai-sdk/openai-compatible` untuk kompatibilitas gaya chat-completions. Jika Anda secara khusus membutuhkan jalur penyedia yang dibangun di atas `/v1/responses`, dokumentasi OpenCode merekomendasikan untuk mengganti package menjadi `@ai-sdk/openai`.
</Note>

## Penggunaan Dasar

**Mulai mode interaktif:**

```bash
opencode
```

**Jalankan dengan prompt:**

```bash
opencode run "Explain this codebase"
```

**Tentukan model:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## Model yang Tersedia

| Model | Paling Cocok Untuk |
|-------|----------|
| `gpt-5.6-terra` | Tugas kompleks, arsitektur kode |
| `gpt-5.6-luna` | Perbaikan cepat, query sederhana |
| `claude-sonnet-4-6` | Review kode, dokumentasi |
| `claude-opus-4-6` | Penalaran kompleks |
| `gemini-3.5-flash` | Respons cepat |

## Perintah Umum

**Analisis kode:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**Hasilkan kode:**

```bash
opencode run "Create a REST API with Express"
```

**Review perubahan:**

```bash
git diff | opencode run "Review these changes"
```

**Perbaiki error:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## Perintah Interaktif

| Command | Deskripsi |
|---------|-------------|
| `/help` | Tampilkan perintah yang tersedia |
| `/models` | Beralih ke model yang berbeda |
| `/clear` | Hapus riwayat percakapan |
| `/exit` | Keluar dari OpenCode |

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Error Koneksi">
    - Verifikasi `options.baseURL` diatur ke `https://api.tokenlab.sh/v1`
    - Periksa konektivitas jaringan
    - Coba `curl https://api.tokenlab.sh/v1/models` untuk pengujian
  </Accordion>

  <Accordion title="Autentikasi Gagal">
    - Verifikasi environment variable `TOKENLAB_API_KEY` telah diatur
    - Verifikasi `options.apiKey` mereferensikan `{env:TOKENLAB_API_KEY}` atau sumber secret valid lainnya
    - Periksa bahwa key diawali dengan `sk-`
    - Pastikan key aktif di dashboard TokenLab
  </Accordion>

  <Accordion title="Model Tidak Ditemukan">
    - Periksa nama model di config harus sama persis
    - Verifikasi ketersediaan model di [tokenlab.sh/en/models](https://tokenlab.sh/id/models)
  </Accordion>
</AccordionGroup>

## Praktik Terbaik

  <Accordion title="Gunakan konteks project">

  </Accordion>

  <Accordion title="Review kode yang dihasilkan">
    Selalu review kode yang dihasilkan AI sebelum menerapkan perubahan pada project Anda.
  </Accordion>
</AccordionGroup>
