## Gambaran Umum

Graphiti mendukung endpoint `/v1` yang kompatibel dengan OpenAI melalui `OpenAIGenericClient`. Arahkan klien tersebut ke TokenLab dan pilih model TokenLab.

<Note>
**Tipe**: Kerangka kerja memori knowledge graph

**Jalur Utama**: Chat Completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur yang kompatibel dengan OpenAI didukung
</Note>

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Klien LLM

```python
import os

from graphiti_core.llm_client.config import LLMConfig
from graphiti_core.llm_client.openai_generic_client import OpenAIGenericClient

llm_config = LLMConfig(
    api_key=os.environ["TOKENLAB_API_KEY"],
    model="claude-sonnet-5",
    small_model="gpt-5.4-mini",
    base_url="https://api.tokenlab.sh/v1",
)

llm_client = OpenAIGenericClient(config=llm_config)
```

Teruskan `llm_client` ke dalam instance `Graphiti(...)` Anda bersama dengan konfigurasi basis data grafik dan embedder Anda.

## Catatan Endpoint

Jalur yang kompatibel dengan OpenAI pada Graphiti berorientasi pada chat-completions. Gunakan model yang secara andal mengembalikan JSON terstruktur untuk tugas ekstraksi dan deduplikasi.
