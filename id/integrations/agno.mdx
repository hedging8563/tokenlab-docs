## Gambaran Umum

Agno dapat menggunakan TokenLab sebagai penyedia model yang kompatibel dengan OpenAI untuk agen dan alur kerja.

<Note>
**Tipe**: Kerangka Kerja Agen

**Jalur Utama**: Penyelesaian chat yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur yang didukung
</Note>

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Wrapper Model TokenLab

Jika versi Agno Anda menyertakan wrapper model TokenLab:

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

Beberapa build Agno juga mendukung string model:

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## Fallback yang Kompatibel dengan OpenAI

Jika versi Anda belum menyertakan TokenLab, gunakan jalur model yang kompatibel dengan OpenAI dari Agno dengan:

- Base URL: `https://api.tokenlab.sh/v1`
- API key: `TOKENLAB_API_KEY`
- Model: `gpt-5.4-mini`

## Saran Model

Gunakan `gpt-5.4-mini` untuk agen default, `gpt-5.4` atau `claude-sonnet-5` untuk penalaran yang lebih mendalam, dan `deepseek-v4-flash` untuk loop yang lebih cepat.
