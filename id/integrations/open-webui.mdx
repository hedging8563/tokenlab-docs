## Gambaran Umum

Open WebUI mendukung koneksi API kustom yang kompatibel dengan OpenAI. Tambahkan TokenLab sebagai endpoint jarak jauh yang kompatibel dengan OpenAI dan segarkan daftar model.

<Note>
**Tipe**: Aplikasi Obrolan Web

**Jalur Utama**: Penyelesaian obrolan (chat completions) yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur aplikasi obrolan yang didukung
</Note>

## Koneksi Admin

1. Buka **Admin Panel** -> **Settings** -> **Connections**.
2. Di area koneksi OpenAI API, tambahkan koneksi.
3. Atur base URL ke `https://api.tokenlab.sh/v1`.
4. Atur API key ke kunci TokenLab Anda.
5. Simpan koneksi dan segarkan model.

## Nilai

| Bidang | Nilai |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Contoh model | `gpt-5.4-mini` |

## Model yang Direkomendasikan

- `gpt-5.4-mini` untuk obrolan umum
- `claude-sonnet-5` untuk penulisan dan penalaran
- `deepseek-v4-pro` untuk obrolan yang padat kode
- `gemini-3.5-flash` untuk alur kerja multimodal yang cepat

Untuk menentukan ID model secara manual, edit koneksi ini dan buka **Advanced** → **Model IDs (Filter)**. Tambahkan ID model TokenLab yang persis, lalu simpan.
