## Gambaran Umum

[Claude Code](https://code.claude.com/docs/en/setup) adalah alat CLI resmi Anthropic untuk coding dengan bantuan AI. Anda dapat mengonfigurasinya untuk menggunakan TokenLab sebagai penyedia API.


<Note>
**Jenis**: Alat coding

**Jalur utama**: Anthropic-native

**Tingkat dukungan**: Jalur native yang kuat
</Note>

## Instalasi

Anthropic sekarang merekomendasikan installer native. Instalasi npm masih tersedia untuk kompatibilitas, tetapi sudah deprecated di upstream.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Jika Anda secara khusus memerlukan package npm, gunakan:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
Jangan gunakan `sudo npm install -g` untuk Claude Code.
</Warning>

## Konfigurasi

Ikuti langkah terminal [panduan cepat](/id/quickstart) untuk macOS, Linux, WSL, atau Windows PowerShell guna mengatur `TOKENLAB_API_KEY` tanpa menulis kunci ke riwayat perintah. Jalankan Claude Code dari terminal tersebut. Untuk penggunaan berkelanjutan, gunakan pengelola rahasia lokal, bukan kunci teks biasa di profil shell.

Variabel ini hanya berlaku untuk peluncuran ini; akun, model default, dan izin tersimpan tetap ada. Jalankan tanpa variabel tersebut untuk memakai konfigurasi sebelumnya. Jangan simpan dalam profil shell.

Jalur sesi ini memakai Claude Code **2.1.263** dan autentikasi Bearer melalui `ANTHROPIC_AUTH_TOKEN`. Base URL tidak memakai `/v1`. Nilai `env` tersimpan, helper kredensial, opsi penyedia cloud, atau kebijakan terkelola dapat memengaruhi autentikasi; periksa sebelum mulai. Jika bertentangan, gunakan helper di bawah tanpa menghapus akun atau melonggarkan kebijakan. Periksa model dan izin melalui `/status`.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Opsional: [helper konfigurasi Claude Code yang dapat dipulihkan](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md) menyediakan pratinjau, penerapan, dan pemulihan file asli dengan Python 3.11+. Plugin TokenLab Skills **0.1.2** menyertakan skrip ini; Skill mandiri juga dapat digunakan setelah diperbarui ke versi yang memuatnya. Untuk plugin atau Skill mandiri yang sudah terpasang, ikuti [petunjuk pembaruan README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) dan pastikan skrip tersedia. Konfigurasi manual di halaman ini tetap dapat digunakan tanpa helper.

Menyimpan pengaturan atau menampilkan model tidak memvalidasi kunci maupun permintaan yang selesai. Prompt memakai saldo TokenLab. Periksa respons dan [catatan permintaan terkait](https://tokenlab.sh/dashboard/runs?section=requests) sebelum mencoba alat; permintaan tambahan juga dapat dikenai biaya.

## Penggunaan

Setelah konfigurasi, gunakan Claude Code seperti biasa:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Verifikasi instalasi jika diperlukan:

```bash
claude --version
claude doctor
```

## Model yang Tersedia

TokenLab mendukung semua model Claude:

| Model | Deskripsi |
|-------|-------------|
| `claude-opus-4-6` | Paling mumpuni, penalaran kompleks |
| `claude-sonnet-4-6` | Performa seimbang, sangat baik untuk coding |
| `claude-haiku-4-5` | Paling cepat, hemat biaya |

## Pemilihan Model

Tentukan model dengan flag `--model`:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Pemikiran Mendalam

Untuk tugas penalaran kompleks, gunakan model dengan extended thinking:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan koneksi">
    Verifikasi bahwa base URL adalah tepat `https://api.tokenlab.sh` (tanpa sufiks `/v1` untuk request bergaya Anthropic).
  </Accordion>

  <Accordion title="API key tidak valid">
    Pastikan API key TokenLab Anda diawali dengan `sk-` dan memiliki saldo yang cukup.
  </Accordion>


  <Accordion title="Model tidak ditemukan">
    Periksa bahwa nama model sudah benar. Gunakan format `claude-sonnet-4-6`.
  </Accordion>
</AccordionGroup>
