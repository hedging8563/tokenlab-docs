Tambahkan TokenLab sebagai penyedia bernama tanpa mengganti akun, pengaturan, dan izin alat yang sudah ada.

## Serahkan tugas ini kepada Agent

```text
Baca panduan ini dan hubungkan Hermes ke TokenLab:
https://docs.tokenlab.sh/id/integrations/hermes-agent
Periksa versi terpasang dan konfigurasi aktif terlebih dahulu.
Pertahankan akun, penyedia, model bawaan dan izin; cadangkan berkas dan tampilkan perubahan.
Saya akan memasukkan kunci secara lokal; jangan meminta, mencetak atau menempelkannya dalam chat.
Periksa pemuatan konfigurasi dahulu. Jelaskan pengujian berbayar secara terpisah dan jalankan hanya setelah saya memilihnya.
```

## Instal atau periksa Hermes

[Panduan resmi](https://hermes-agent.nousresearch.com/docs/getting-started/installation) menyediakan pemasang desktop untuk macOS Apple Silicon dan Windows, serta CLI untuk Linux dan Windows native. Periksa persyaratan sistem; lewati instalasi jika Hermes sudah tersedia.

## Opsional: konfigurasi yang dapat dipulihkan

TokenLab Skills **0.1.3** menyediakan alat konfigurasi untuk Hermes resmi **0.21.3**. Alat menampilkan pratinjau dan cadangan lalu hanya menambahkan penyedia bernama, dengan tetap menjaga komentar YAML, akun, model bawaan dan izin. Baca [panduan](https://github.com/hedging8563/tokenlab-skills/blob/900de0c4e296c0d2ed00b5d842815ed89c403503/skills/tokenlab-api-integration/references/hermes_setup.md) terlebih dahulu.

Atur `SKILL_DIR` ke folder `tokenlab-api-integration` yang terpasang dan `HERMES_PYTHON` ke Python di direktori instalasi dari `hermes --version`: `venv/bin/python` pada macOS/Linux atau `venv\Scripts\python.exe` pada Windows. PowerShell menggunakan `$SkillDir` dan `$HermesPython`. Alat memakai lingkungan yang ada tanpa memasang paket Python global.

```bash
"$HERMES_PYTHON" "$SKILL_DIR/scripts/configure_hermes.py" --model gpt-5.6-luna
"$HERMES_PYTHON" "$SKILL_DIR/scripts/configure_hermes.py" --model gpt-5.6-luna --apply
```

```powershell
& $HermesPython "$SkillDir/scripts/configure_hermes.py" --model gpt-5.6-luna
& $HermesPython "$SkillDir/scripts/configure_hermes.py" --model gpt-5.6-luna --apply
```

Setelah diterapkan, lewati penggabungan manual di bawah dan ikuti direktori serta perintah pemuatan yang ditampilkan; `active_profile` dikenali. Membaca konfigurasi tidak memvalidasi kunci. Pratinjau pemulihan dengan `--restore`, lalu tambahkan `--apply` untuk memulihkan byte asli. Konflik, suntingan berikutnya, pengaturan terkelola atau WSL menghentikan otomatisasi; pertahankan pengaturan dan gunakan jalur manual.

## Atur penyedia bernama

Gunakan direktori `HERMES_HOME` jika diatur, atau `~/.hermes` (Windows: `%LOCALAPPDATA%\hermes`). Cadangkan `config.yaml`, lalu gabungkan entri berikut tanpa mengganti pengaturan lain. Pilih model saat ini yang mendukung Chat Completions dan pemanggilan alat.

Cadangkan konfigurasi aktif. Tambahkan hanya entri TokenLab dan pertahankan penyedia, akun, model default, serta izin yang ada. Jika namanya sudah dipakai, pilih nama lain dan sesuaikan perintah. Untuk membatalkan, hapus hanya entri tambahan atau pulihkan cadangan sebelumnya.

```yaml
providers:
  tokenlab:
    api: https://api.tokenlab.sh/v1
    key_env: TOKENLAB_API_KEY
    transport: chat_completions
    default_model: gpt-5.6-luna
```

Buat kunci di [Kunci API](https://tokenlab.sh/dashboard/api?tab=keys). Simpan secara lokal sebagai `TOKENLAB_API_KEY` dalam `.env` di direktori Hermes atau lingkungan proses yang menjalankannya. Jangan tempelkan kunci ke percakapan atau YAML penyedia.

## Periksa lalu kirim permintaan

Periksa penyedia dengan `hermes config get providers.tokenlab.api`; hasilnya harus `https://api.tokenlab.sh/v1`. Pertahankan bagian `model` yang ada. Mulai sesi baru dengan penyedia dan model eksplisit di bawah; tanpa opsi tersebut, default sebelumnya tetap digunakan. Pemeriksaan ini tidak memvalidasi kunci.

```bash
hermes chat --provider custom:tokenlab --model gpt-5.6-luna
```

Saat siap memakai saldo TokenLab, kirim teks singkat lalu cocokkan balasan dengan [catatan permintaan](https://tokenlab.sh/dashboard/runs?section=requests). Setelah itu coba tugas alat hanya baca. Model pendukung dan alat opsional dapat memakai penyedia atau kunci tersendiri.

## Pulihkan dan atasi masalah

Jika penyedia tidak dikenal, periksa versi dan [format terbaru](https://hermes-agent.nousresearch.com/docs/integrations/providers). Untuk kegagalan autentikasi, periksa lingkungan dan status kunci tanpa mencetaknya. Untuk membatalkan, pulihkan model sebelumnya dan hapus hanya entri TokenLab yang ditambahkan.

MCP dan Skills adalah ekstensi terpisah: [panduan MCP](/id/integrations/tokenlab-mcp-server) menambahkan alat API, sedangkan [panduan Skill](/id/integrations/coding-agent-skill) memberi petunjuk integrasi. Keduanya tidak wajib untuk penyedia ini.
