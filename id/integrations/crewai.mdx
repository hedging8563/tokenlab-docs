## Gambaran Umum

CrewAI mendukung LLM yang kompatibel dengan OpenAI dengan mengatur model, API key, dan base URL pada variabel lingkungan atau pada kelas `LLM`.

<Note>
**Tipe**: Kerangka Kerja Agen

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Mendukung jalur endpoint kustom
</Note>

## Variabel Lingkungan

```python
import os

os.environ["OPENAI_API_KEY"] = "sk-your-tokenlab-key"
os.environ["OPENAI_API_BASE"] = "https://api.tokenlab.sh/v1"
os.environ["OPENAI_MODEL_NAME"] = "openai/claude-sonnet-5"
```

## Kelas LLM

```python
from crewai import Agent, LLM

llm = LLM(
    model="claude-sonnet-5",
    custom_openai=True,
    base_url="https://api.tokenlab.sh/v1",
    api_key="sk-your-tokenlab-key",
)

agent = Agent(
    role="Research analyst",
    goal="Summarize technical tradeoffs clearly",
    backstory="You produce concise implementation notes.",
    llm=llm,
)
```

## Saran Model

Gunakan `gpt-5.4-mini` untuk crew rutin, `claude-sonnet-5` atau `gpt-5.4` untuk agen yang membutuhkan banyak perencanaan, dan `deepseek-v4-flash` untuk iterasi berbiaya rendah yang lebih cepat.

## Catatan Endpoint

Jalur yang kompatibel dengan OpenAI di CrewAI paling cocok untuk panggilan agen bergaya Chat Completions. Gunakan endpoint asli TokenLab secara langsung hanya jika alat atau SDK yang Anda pilih dapat menggunakan protokol asli tersebut.
