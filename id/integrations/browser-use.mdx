## Gambaran Umum

Browser Use dapat memanggil TokenLab melalui `ChatOpenAILike`, yaitu wrapper model chat yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Kerangka kerja agen otomatisasi browser

**Jalur Utama**: Chat Completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur yang kompatibel dengan OpenAI didukung
</Note>

## Lingkungan

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Contoh

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    add_schema_to_system_prompt=True,
    dont_force_structured_output=True,
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## Catatan Endpoint

Gunakan halaman ini untuk alur kerja Browser Use yang memanggil Chat Completions melalui klien yang kompatibel dengan OpenAI. Jika alur kerja Anda memerlukan Respons asli TokenLab, Pesan Anthropic, atau endpoint Gemini, gunakan jalur klien di Browser Use yang menggunakan protokol tersebut secara langsung.
