## Gambaran Umum

Koneksi OpenAI pada Prompt flow mendukung `base_url` kustom. Atur ke endpoint `/v1` TokenLab dan gunakan ID model TokenLab di dalam flow Anda.

<Note>
**Tipe**: Platform pembuat flow dan evaluasi

**Jalur Utama**: Chat Completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur yang kompatibel dengan OpenAI didukung
</Note>

## Instalasi

```bash
pip install promptflow promptflow-tools
```

## Membuat Koneksi

Simpan koneksi berikut sebagai `openai.yaml`. Perintah meminta API key secara lokal. Pada node OpenAI, isi ID model TokenLab di `inputs.model`; `deployment_name` digunakan untuk Azure OpenAI.

```yaml
$schema: https://azuremlschemas.azureedge.net/promptflow/latest/OpenAIConnection.schema.json
name: open_ai_connection
type: open_ai
base_url: https://api.tokenlab.sh/v1
api_key: "<user-input>"
```

```bash
pf connection create --file openai.yaml
```

## Catatan Flow

Di dalam `flow.dag.yaml` Anda, pastikan nama koneksi selaras dengan perintah di atas:

```yaml
nodes:
  - name: chat
    type: llm
    source:
      type: code
      path: chat.jinja2
    inputs:
      model: claude-sonnet-5
    api: chat
    connection: open_ai_connection
```


## Catatan Endpoint

Integrasi ini menggunakan koneksi yang kompatibel dengan OpenAI dari Prompt flow. Respons Native TokenLab, Anthropic Messages, dan rute Gemini memerlukan alat Prompt flow atau node Python kustom yang memanggil endpoint tersebut secara langsung.
