## Gambaran Umum

Gemini CLI **0.60.0** mendokumentasikan `GOOGLE_GEMINI_BASE_URL` untuk autentikasi kunci API. Gunakan endpoint Gemini asli TokenLab dengan model terkini yang mendukung `gemini_generate_content`. Lihat [konfigurasi resmi](https://geminicli.com/docs/reference/configuration/) dan [panduan autentikasi](https://geminicli.com/docs/get-started/authentication/). Ini tidak merutekan langganan Google melalui TokenLab.

## Instalasi

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## Konfigurasi

Ikuti langkah terminal [panduan cepat](/id/quickstart) untuk macOS, Linux, WSL, atau Windows PowerShell guna mengatur `TOKENLAB_API_KEY` tanpa menulis kunci ke riwayat perintah. Jalankan Gemini CLI dari terminal tersebut. Untuk penggunaan berkelanjutan, gunakan pengelola rahasia lokal, bukan kunci teks biasa di profil shell.

Pertahankan login Google dan konfigurasi saat ini. Untuk TokenLab, pilih direktori konfigurasi yang belum dipakai seperti `~/.gemini-tokenlab` (`$HOME` di PowerShell), lalu buat `.gemini` di dalamnya. Salin `.gemini/settings.json` dan berkas kebijakan yang diperlukan ke lokasi yang sesuai, dengan tetap mempertahankan izin, sandbox, dan pengaturan lain. Gabungkan hanya bidang autentikasi berikut pada salinan tersebut; buat berkas jika belum ada. Jangan salin cache OAuth atau hapus kredensial asli. Patuhi kebijakan autentikasi terkelola.

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## Penggunaan

Peluncuran berikut memakai `~/.gemini-tokenlab/.gemini/settings.json`. Sesuaikan jalur jika memilih direktori lain. Setujui direktori kerja lewat dialog kepercayaan biasa dan pertahankan kebijakan persetujuan alat. Model dipilih secara eksplisit untuk sesi ini.

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Variabel ini hanya berlaku untuk peluncuran ini; akun, model default, dan izin tersimpan tetap ada. Jalankan tanpa variabel tersebut untuk memakai konfigurasi sebelumnya. Jangan simpan dalam profil shell.

## Verifikasi

Menyimpan pengaturan atau menampilkan model tidak memvalidasi kunci maupun permintaan yang selesai. Prompt memakai saldo TokenLab. Periksa respons dan [catatan permintaan terkait](https://tokenlab.sh/dashboard/runs?section=requests) sebelum mencoba alat; permintaan tambahan juga dapat dikenai biaya.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
