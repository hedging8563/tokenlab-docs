## Apa yang dilakukan skill ini

- Membuat contoh minimal yang dapat dijalankan untuk keluarga API TokenLab seperti chat, image, audio, video, translation, dan lainnya.
- Menggunakan `https://api.tokenlab.sh/v1` untuk client kompatibel OpenAI dan menjelaskan kapan berpindah ke route native Anthropic atau Gemini.
- Menemukan model lewat `/v1/models`, `/llms.txt`, dan daftar `recommended_for` alih-alih menebak dari daftar usang.
- Membaca detail model model sebelum mencoba ulang permintaan non-chat agar field yang tidak didukung tidak dibuang diam-diam.
- Menangani petunjuk error Agent-First seperti `did_you_mean`, `suggestions`, `retry_after`, dan `recommended_request`.

## Alur Agent yang disarankan

Baca daftar model terkini, lalu `tokenlab.accepted_request_formats` dan bidang permintaan publik model yang dipilih. Pertahankan satu format untuk percakapan dan pemanggilan alat; bidang tidak dikonversi otomatis. Jangan mengganti model atau protokol atas inisiatif sendiri saat terjadi kesalahan.

## Contoh chat minimal

Contoh ini memakai OpenAI Python SDK dengan base URL TokenLab:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "Hello!"}],
)

print(response.choices[0].message.content)
```

Jalankan dengan:

```bash
pip install openai
export TOKENLAB_API_KEY="sk-your-api-key"
python app.py
```

## Penemuan model dan detail model

Utamakan penemuan live daripada daftar bawaan yang usang:

```bash
# Ringkasan API yang dapat dibaca mesin
curl https://api.tokenlab.sh/llms.txt

# Daftar model
curl "https://api.tokenlab.sh/v1/models" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?category=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Daftar pendek non-chat berperingkat
curl "https://api.tokenlab.sh/v1/models?recommended_for=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=video" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=translation" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Baca detail model satu model sebelum mencoba ulang permintaan non-chat
curl "https://api.tokenlab.sh/v1/models/gpt-image-2" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Detail khusus harga
curl "https://api.tokenlab.sh/v1/models/gpt-image-2/pricing" -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Pemilihan protokol native

Jalur kompatibel OpenAI `/v1` adalah default untuk contoh umum chat, image, embedding, audio, dan rerank. Jangan simpulkan ketersediaan protokol native dari nama model atau provider, maupun dari header respons Chat. Baca `GET /v1/models/{model}` dan gunakan hanya format permintaan yang diiklankan oleh detail model.

Field yang dibaca adalah `tokenlab.accepted_request_formats`.

Endpoint protokolnya adalah `/v1/chat/completions` untuk Chat Completions, `/v1/responses` untuk Responses, `/v1/messages` untuk Messages, dan `/v1beta/models/{model}:generateContent` untuk Gemini.

## Pemulihan error Agent-First

Error menyertakan field yang dapat diparse coding agent tanpa mengorek dokumentasi:

Utamakan status HTTP dan `code` kesalahan. Gunakan `did_you_mean` untuk nama yang salah, tetapi jangan mengganti model tanpa pilihan pengguna. Untuk `429`, ikuti `Retry-After` atau `retry_after` dan ulangi hanya jika diizinkan kesalahan serta dipilih secara eksplisit. Perbaiki dahulu kesalahan validasi, autentikasi, saldo, atau izin. Jika pembuatan permintaan timeout, periksa apakah tugas sudah ada sebelum mengirim ulang.

## Keluarga API yang didukung

| Keluarga | Path utama |
|---|---|
| Chat dan Responses | `/v1/chat/completions`, `/v1/responses` |
| Pesan asli Claude | `/v1/messages` |
| Permintaan Gemini-native | `/v1beta/models/{model}:generateContent` |
| Gambar | `/v1/images/generations`, `/v1/images/edits` |
| Video | `/v1/videos/generations` |
| Musik | `/v1/music/generations` |
| Worlds | `/v1/worlds/generations` plus endpoint status world dan media asset |
| 3D | `/v1/3d/generations` |
| Audio | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| Realtime | `/v1/realtime?model={model}` |
| Embeddings dan rerank | `/v1/embeddings`, `/v1/rerank` |
| Terjemahan teks | `/v1/translations` |
