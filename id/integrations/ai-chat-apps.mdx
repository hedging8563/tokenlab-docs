## Gambaran Umum

Sebagian besar aplikasi chat AI umum terhubung ke TokenLab melalui jalur chat standar yang kompatibel dengan OpenAI.

Dalam praktiknya, ini berarti:
- gunakan `https://api.tokenlab.sh/v1` sebagai base URL kecuali aplikasi secara eksplisit meminta URL endpoint lengkap
- gunakan kunci API TokenLab Anda sebagai kunci API bergaya OpenAI
- pilih model yang dapat digunakan aplikasi dalam alur kerja chat standar

<Note>
Aplikasi chat umum biasanya **berorientasi pada chat-completions**, bukan klien WebSocket Codex Responses. Untuk Codex CLI/App, Cursor, atau alat coding lain yang memerlukan perilaku khusus Responses, gunakan panduan integrasi khusus sebagai gantinya.
</Note>

<Note>
**Tipe**: Aplikasi Chat

**Jalur Utama**: Chat-completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur didukung
</Note>

## Aplikasi yang Didukung

| Aplikasi | Platform | Catatan |
|-------------|----------|-------|
| Open WebUI | Web, Self-hosted | Pilihan self-hosted populer dengan koneksi yang kompatibel dengan OpenAI |
| LibreChat | Web, Self-hosted | Ruang kerja chat multi-penyedia dengan endpoint OpenAI kustom |
| LobeChat | Web, Desktop, Self-hosted | Dukungan penyedia kustom yang kuat |
| Cherry Studio | Windows, macOS, Linux | Alur penyedia yang kompatibel dengan OpenAI yang baik |
| Chatbox | Windows, macOS, Linux | Pengaturan yang kompatibel dengan OpenAI yang sederhana |
| DeepChat | Windows, macOS, Linux | Klien desktop dengan pengaturan penyedia yang kompatibel dengan OpenAI |
| Jan | Desktop, Self-hosted | Aplikasi local-first dengan penyedia OpenAI jarak jauh yang kompatibel |
| TypingMind | Web, Desktop | Menggunakan gaya endpoint kustom |
| NextChat | Web, Self-hosted | Klien bergaya ChatGPT yang ringan dengan penggantian base-URL |
| ChatWise | Windows, macOS | Pola penyedia kustom standar |

## Nilai Koneksi Default

| Bidang | Nilai |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Jenis API | Kompatibel dengan OpenAI |

Jika aplikasi meminta **URL endpoint lengkap** alih-alih base URL, gunakan:
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## Contoh Pengaturan Aplikasi

<Tabs>
  <Tab title="LobeChat">
**LobeChat yang di-host sendiri**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. Buka **Settings** → **AI Service Provider**
    2. Pilih **OpenAI**
    3. Masukkan kunci API TokenLab Anda
    4. Atur endpoint kustom ke `https://api.tokenlab.sh/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. Buka **Settings** → **Model Provider**
    2. Tambahkan penyedia **OpenAI-compatible**
    3. Masukkan:
       - **Name**: TokenLab
       - **API Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. Tambahkan model yang ingin Anda gunakan
  </Tab>

  <Tab title="Chatbox">
    1. Buka **Settings** → **AI Model**
    2. Pilih **OpenAI API Compatible**
    3. Masukkan:
       - **API Host**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini` atau `claude-sonnet-5`
  </Tab>

  <Tab title="TypingMind">
    1. Buka **Settings**
    2. Pilih **Custom Endpoint**
    3. Masukkan:
       - **Endpoint URL**: `https://api.tokenlab.sh/v1/chat/completions`
       - **API Key**: `sk-your-tokenlab-key`
    4. Konfigurasikan model yang ingin Anda tampilkan
  </Tab>

  <Tab title="Open WebUI">
    1. Buka **Admin Settings** → **Connections**
    2. Tambahkan koneksi **OpenAI-compatible**
    3. Masukkan:
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. Simpan dan pilih model yang ingin Anda tampilkan
  </Tab>

  <Tab title="DeepChat">
    1. Buka **Settings** -> **Model Provider**
    2. Tambahkan penyedia OpenAI-compatible
    3. Masukkan:
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini`
    4. Simpan dan jalankan chat uji coba
  </Tab>

  <Tab title="Jan">
    1. Buka **Settings** -> **Providers**
    2. Tambahkan penyedia OpenAI-compatible jarak jauh
    3. Masukkan:
       - **Provider name**: TokenLab
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. Pilih `gpt-5.4-mini` atau model TokenLab lainnya
  </Tab>

  <Tab title="LibreChat">
    Tambahkan endpoint OpenAI-compatible di konfigurasi penyedia LibreChat Anda dan arahkan ke:

    ```yaml
    customEndpoints:
      - name: TokenLab
        apiKey: '${OPENAI_API_KEY}'
        baseURL: 'https://api.tokenlab.sh/v1'
        models:
          default: ['gpt-5.4-mini', 'gpt-5.4', 'claude-sonnet-5']
          fetch: false
    ```
  </Tab>
</Tabs>

## Tips

<AccordionGroup>
  <Accordion title="Gunakan base URL jika aplikasi mendukungnya">
    Sebagian besar aplikasi lebih mudah dikonfigurasi dan lebih stabil jika Anda memberikan `https://api.tokenlab.sh/v1` sebagai base URL alih-alih URL endpoint lengkap.
  </Accordion>

  <Accordion title="Gunakan model yang lebih kecil terlebih dahulu">
    Mulailah dengan `gpt-5.4-mini` atau `deepseek-v4-flash` untuk chat sehari-hari, kemudian pindahkan tugas penalaran yang lebih berat ke `gpt-5.4` atau `claude-opus-4-8`.
  </Accordion>

  <Accordion title="Pisahkan alat coding">
    Aplikasi chat umum dan agen coding sering kali memerlukan perilaku endpoint yang berbeda. Simpan alat bergaya Codex/Cursor di halaman integrasi khusus mereka.
  </Accordion>
</AccordionGroup>

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan Koneksi">
    - Pastikan base URL tepat `https://api.tokenlab.sh/v1`
    - Hapus garis miring (trailing slash) jika aplikasi menambahkan jalur secara otomatis
    - Jika aplikasi meminta URL endpoint lengkap, gunakan `https://api.tokenlab.sh/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Tidak terotorisasi">
    - Periksa kembali kunci API Anda
    - Pastikan kunci aktif di dasbor TokenLab
    - Pastikan tidak ada spasi tambahan atau baris baru
  </Accordion>

  <Accordion title="Model Tidak Tersedia">
    - Verifikasi nama model dengan tepat
    - Coba default yang didukung secara luas seperti `gpt-5.4-mini`, `deepseek-v4-flash`, atau `claude-sonnet-5`
    - Periksa ketersediaan saat ini di dokumentasi atau dasbor TokenLab
  </Accordion>
</AccordionGroup>
