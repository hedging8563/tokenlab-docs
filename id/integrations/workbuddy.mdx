## Ikhtisar

<Note>
**Tipe**: agen desktop untuk coding dan tugas

**Jalur utama**: Chat Completions kompatibel OpenAI

**Dukungan**: jalur model khusus resmi
</Note>

[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) menyediakan editor visual untuk model kompatibel OpenAI, tanpa perlu mengedit berkas model lokal secara manual.

## Konfigurasi TokenLab

Buka **Settings → Model**, tambahkan model lalu pilih **Custom**.

| Kolom | Nilai |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key Anda |
| Model name | `kimi-k3` |
| Custom Protocol | **Nonaktif** |

<Warning>
Biarkan Custom Protocol nonaktif. Mode standar memvalidasi Base URL dan menambahkan `/chat/completions`. Jika diaktifkan dengan hanya `/v1`, permintaan akan memakai jalur yang salah.
</Warning>

Atur alat, gambar, penalaran, dan batas sesuai detail model terbaru di TokenLab. Jangan aktifkan semuanya atau menyalin batas 1M/128K model lain. Gunakan ID yang ditampilkan.

Simpan, pilih `kimi-k3`, lalu uji pemeriksaan folder hanya-baca. Tutupi Key dan endpoint privat sebelum membagikan tangkapan layar.

Menyimpan dan memilih hanya memastikan pengaturan lokal. Tugas teks atau alat memakai saldo TokenLab; cocokkan balasan dan [catatan permintaan](https://tokenlab.sh/dashboard/runs?section=requests). Untuk membatalkan, pilih model sebelumnya dan hapus hanya entri TokenLab yang ditambahkan.

Aplikasi resmi tersedia untuk macOS dan Windows. Gunakan [editor model resmi](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model); panduan ini tidak mengasumsikan versi Linux atau format file yang dapat ditulis langsung.

[Alat MCP API](/id/integrations/tokenlab-mcp-server) dan [petunjuk Skill](/id/integrations/coding-agent-skill) dipasang terpisah dan tidak mengganti model utama.
