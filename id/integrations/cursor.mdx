## Cakupan

Panduan ini untuk **editor desktop Cursor** di macOS, Windows, dan Linux. Dukungan resmi OpenAI BYOK mencakup model chat standar tanpa penalaran; pelengkapan Tab tetap menggunakan model Cursor. Mengubah OpenAI Base URL tidak mengaktifkan semua model TokenLab atau fitur Cursor. Lihat [batasan resmi](https://cursor.com/help/models-and-usage/api-keys).

Jika hanya membutuhkan alat API gambar, video, atau lainnya, pertahankan penyedia chat saat ini dan tambahkan [MCP](/id/integrations/tokenlab-mcp-server). [Skill](/id/integrations/coding-agent-skill) menyediakan petunjuk API tanpa mengganti model utama.

## Tugas untuk agen Anda saat ini

```text
Baca https://docs.tokenlab.sh/id/integrations/cursor dan periksa versi terpasang serta sistem operasi saya.
Pastikan apakah saya membutuhkan TokenLab sebagai model utama, alat MCP, atau Skill API.
Pertahankan akun, konfigurasi penyedia, dan izin yang ada; jelaskan cara memulihkan perubahan.
Jangan minta kunci API di chat. Saya akan mengisinya secara lokal dan melakukan langkah UI yang diperlukan.
Jelaskan biaya satu permintaan verifikasi kecil. Hanya setelah saya memilih pengujian itu secara eksplisit, bantu jalankan dan cocokkan catatan TokenLab-nya.
```

## Buka pengaturan yang tepat

1. Instal atau perbarui editor melalui [Cursor Downloads](https://cursor.com/downloads). Panduan ini tidak mengonfigurasi CLI atau Cloud Agents.
2. Buka **Cursor Settings** dari palet perintah atau tekan `Cmd/Ctrl + Shift + J`. `Cmd/Ctrl + ,` membuka pengaturan umum editor.
3. Pada **Models**, catat konfigurasi OpenAI yang ada agar dapat dipulihkan. Pertahankan penyedia lain.
4. Masukkan dan simpan kunci TokenLab secara lokal di **OpenAI API Key**. Jangan kirim di chat atau commit ke git.
5. Aktifkan **Override OpenAI Base URL** dan isi:

```text
https://api.tokenlab.sh/v1
```

Permintaan BYOK tetap melewati server Cursor untuk menyusun prompt. Editor tidak terhubung langsung ke TokenLab.

## Pilih model

Salin ID persis dari [katalog TokenLab terkini](https://tokenlab.sh/id/models), lalu periksa dukungan jalur OpenAI BYOK di Cursor. Kategori chat di TokenLab bukan bukti kompatibilitas Cursor.

Untuk pengujian teks pertama, `gpt-4.1-mini` dapat menjadi contoh tanpa penalaran jika masih tersedia. Aktifkan entri yang ada di **Models**, atau gunakan **Add model** jika belum ada, lalu pilih dalam chat. Jangan menggandakan model bawaan dengan ejaan berbeda atau menganggap Claude maupun Gemini memakai override OpenAI. Lihat [penjelasan Cursor](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488).

## Verifikasi satu permintaan kecil

Buat chat baru dengan model yang dipilih dan kirim:

```text
Balas hanya TOKENLAB_CONNECTION_OK. Jangan gunakan alat atau ubah berkas.
```

Permintaan ini berbayar. Periksa balasan serta model, waktu, dan status pada [catatan permintaan TokenLab](https://tokenlab.sh/dashboard/runs?section=requests). Model yang terlihat atau balasan tanpa catatan terkait belum membuktikan jalur ini.

## Jika terjadi kegagalan

- **Model hilang atau ditolak:** periksa ID dan dukungan BYOK; gunakan entri bawaan jika ada. Memulai ulang tidak mengatasi ketidakcocokan.
- **Kesalahan autentikasi:** periksa kunci TokenLab pada kolom OpenAI dan Base URL. Kesalahan saldo atau kuota berbeda dari kunci tidak valid.
- **Tidak ada catatan TokenLab:** periksa model chat, override, dan kesalahan Cursor. Pelengkapan Tab bukan pengujian koneksi ini.
- **Penyedia lain berhenti bekerja:** pulihkan konfigurasi OpenAI sebelumnya atau nonaktifkan override, lalu mulai chat baru.

## Tambahkan MCP dan Skills secara terpisah

[MCP](/id/integrations/tokenlab-mcp-server) menambahkan alat yang bisa dipanggil melalui pengaturan MCP Cursor atau `.cursor/mcp.json`. Periksa penemuan alat terlebih dahulu, lalu jalankan generasi berbayar yang memang diperlukan. MCP tidak mengganti model utama.

[Skills](/id/integrations/coding-agent-skill) menyediakan petunjuk API. Letakkan seluruh folder beserta `SKILL.md` dan referensinya di `.cursor/skills/tokenlab-api-integration/`, lalu periksa **Customize → Skills**. Skill tidak menyediakan kunci atau menginstal server MCP. Lihat panduan resmi [MCP](https://cursor.com/docs/mcp) dan [Skills](https://cursor.com/docs/skills) untuk versi Anda.
