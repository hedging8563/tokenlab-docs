## Gambaran Umum

Helicone dapat melakukan proxy dan observasi terhadap permintaan yang kompatibel dengan OpenAI milik TokenLab dengan merutekannya melalui Helicone Gateway dan menargetkan TokenLab.

<Note>
**Tipe**: Gateway Observabilitas

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI melalui Helicone Gateway

**Tingkat Dukungan**: Jalur observabilitas didukung
</Note>

## Lingkungan

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## Cakupan

Pengaturan ini ditujukan untuk trafik `/v1` yang kompatibel dengan OpenAI. TokenLab juga menyediakan endpoint native Responses, Anthropic Messages, dan yang kompatibel dengan Gemini; gunakan rute TokenLab secara langsung untuk format native tersebut kecuali jika proxy observabilitas Anda mendukungnya secara eksplisit.
