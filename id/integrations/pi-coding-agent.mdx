## Instal dan konfigurasi Pi

Gunakan [instalasi resmi](https://pi.dev/). Paket npm saat ini adalah `@earendil-works/pi-coding-agent`. Windows memakai Git Bash secara default; lihat [pengaturan shell](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md). Lewati instalasi jika Pi sudah ada.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi --version
```

Gabungkan ke `~/.pi/agent/models.json` atau direktori `PI_CODING_AGENT_DIR`. Cadangkan file dan pertahankan penyedia lain. Atur `TOKENLAB_API_KEY` secara lokal pada lingkungan peluncuran, bukan dalam chat. Variabel Base URL saja tidak membuat penyedia ini.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

Tanda `$` dalam `"$TOKENLAB_API_KEY"` wajib; tanpanya nilai menjadi teks literal. Pilih model saat ini yang mendukung Chat Completions dan alat. Batas serta opsi gambar dan penalaran mengikuti detail model tersebut.

## Periksa dan pulihkan

Jalankan `pi --list-models`, lalu pilih `tokenlab/gpt-5.6-luna` di `/model`. Pemilih memuat ulang `models.json`. Ini memeriksa pendaftaran dan keberadaan kredensial, bukan validitasnya atau keberhasilan panggilan API.

Permintaan teks menggunakan saldo TokenLab. Cocokkan balasan dan [catatan permintaan](https://tokenlab.sh/dashboard/runs?section=requests) sebelum mencoba alat. Untuk memulihkan, pilih penyedia sebelumnya dan hapus hanya entri TokenLab yang ditambahkan.

## Skills dan MCP

Pi mendukung [Skills secara native](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). Instal [TokenLab Skill](/id/integrations/coding-agent-skill). MCP memerlukan ekstensi terpisah; jangan masukkan konfigurasinya ke `models.json`.
