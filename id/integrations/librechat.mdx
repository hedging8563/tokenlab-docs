## Gambaran Umum

LibreChat bekerja dengan baik bersama TokenLab melalui endpoint kustom yang kompatibel dengan OpenAI.

<Note>
**Tipe**: Aplikasi Chat

**Jalur Utama**: Chat completions yang kompatibel dengan OpenAI

**Tingkat Dukungan**: Jalur didukung
</Note>

## Lingkungan

Tambahkan variabel ini ke file `.env` di direktori utama proyek LibreChat Anda:

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## Contoh Endpoint

Jika belum ada, buat `librechat.yaml` dari `librechat.example.yaml` di direktori utama proyek LibreChat. Pertahankan kolom wajib `version` dan konfigurasi yang sudah ada, lalu tambahkan entri ini ke `endpoints.custom`:

```yaml
endpoints:
  custom:
    - name: 'TokenLab'
      apiKey: '${TOKENLAB_API_KEY}'
      baseURL: 'https://api.tokenlab.sh/v1'
      models:
        default:
          - 'gpt-5.5'
          - 'gpt-5.6-terra'
          - 'gpt-5.6-luna'
          - 'claude-opus-4-8'
          - 'claude-sonnet-5'
          - 'gemini-3.5-flash'
          - 'deepseek-v4-pro'
          - 'deepseek-v4-flash'
        fetch: true
      titleConvo: true
      titleModel: 'gpt-5.6-luna'
      modelDisplayLabel: 'TokenLab'
```

Jika menggunakan Docker, pasang file ini sebagai `/app/librechat.yaml` di container API. Mulai ulang instance LibreChat yang sama, lalu pilih TokenLab. Lihat [panduan konfigurasi LibreChat](https://www.librechat.ai/docs/configuration/librechat_yaml).

## Catatan

LibreChat menggunakan jalur chat yang kompatibel dengan OpenAI untuk pengaturan ini. TokenLab juga menyediakan endpoint native Responses, Anthropic Messages, dan yang kompatibel dengan Gemini untuk klien yang mendukung bentuk permintaan tersebut.
