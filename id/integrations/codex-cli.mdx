## Gambaran Umum

Codex CLI terhubung ke TokenLab melalui `/v1/responses`. Model yang dipilih harus mencantumkan `openai_responses` dalam `tokenlab.accepted_request_formats`; fitur dapat berbeda menurut model.

Kompaksi jarak jauh Codex CLI didukung di `POST /v1/responses/compact`. Codex mengirim `model` sesi saat ini di `body.model` untuk `/compact` dan auto-compact, jadi model yang ingin dipakai untuk kompaksi harus tersedia di jalur Responses. Jangan mengonfigurasi `/v1/compact`.

## Persyaratan Sistem

Ikuti [panduan CLI resmi](https://learn.chatgpt.com/docs/codex/cli) untuk macOS, Linux, atau Windows. Windows native dan WSL adalah lingkungan terpisah; lihat [panduan Windows](https://learn.chatgpt.com/docs/windows/windows-sandbox). npm adalah pilihan instalasi, bukan syarat biner native.

## Instalasi

```bash
npm install -g @openai/codex@0.149.0
```

Verifikasi instalasi:

```bash
codex --version
```

## Konfigurasi

### Langkah 1: Atur API Key

Ikuti langkah terminal [panduan cepat](/id/quickstart) untuk macOS, Linux, WSL, atau Windows PowerShell guna mengatur `TOKENLAB_API_KEY` tanpa menulis kunci ke riwayat perintah. Jalankan Codex dari terminal tersebut. Untuk penggunaan berkelanjutan, gunakan pengelola rahasia lokal, bukan kunci teks biasa di profil shell.

### Langkah 2: Konfigurasi tokenlab.config.toml

Dengan Codex **0.149.0**, gunakan `tokenlab.config.toml` terpisah dalam `CODEX_HOME` aktif (biasanya `~/.codex`). Buat hanya jika namanya belum dipakai, atau cadangkan profil TokenLab yang ada sebelum mengeditnya. `codex --profile tokenlab` memuat profil secara eksplisit tanpa mengubah `config.toml`, `auth.json`, akun, atau izin. Jangan gunakan tabel lama `[profiles.tokenlab]`. Jalankan tanpa profil ini untuk kembali ke pengaturan biasa. Lihat [konfigurasi profil resmi](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles).

```toml
model_provider = "tokenlab"
model = "gpt-5.6-sol"
model_reasoning_effort = "xhigh"

[model_providers.tokenlab]
env_key = "TOKENLAB_API_KEY"
name = "TokenLab"
base_url = "https://api.tokenlab.sh/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000
```

Mode WebSocket ini adalah bridge Responses-over-WebSocket untuk klien Codex. Mode ini hanya menerima event resmi `response.create`; `stream` bersifat implisit, sedangkan `background` dan `response.cancel` tidak tersedia pada transport ini. Ini bukan OpenAI Realtime API dan tidak menerima `session.update`, `conversation.item.*`, `input_audio_buffer.*`, audio biner, atau envelope Realtime bertingkat `response.create.response`.

<Note>
Buat file konfigurasi yang dipilih jika belum ada. Setelah mengeditnya, mulai sesi baru dengan perintah yang sesuai di bawah.
</Note>

Codex saat ini memakai `wire_api = "responses"`, bukan `chat/completions`. Hilangkan `requires_openai_auth` atau isi false agar penyedia memakai `env_key`.

<Note>
Permintaan Responses tidak diubah menjadi Chat Completions. Kolom opsional dan mendatang bergantung pada model yang dipilih.
</Note>

## Penggunaan Dasar

**Mulai mode interaktif:**

```bash
codex --profile tokenlab
```

**Perintah langsung:**

```bash
codex --profile tokenlab "Fix the bug in main.py line 42"
```

**Menentukan model:**

```bash
codex --profile tokenlab -m gpt-5.6-sol "Build a REST API server"
```

## Pilih model

Pilih model yang saat ini mencantumkan `openai_responses` dalam `tokenlab.accepted_request_formats`. Bandingkan model dengan tugas Anda dan periksa harga di [halaman model](https://tokenlab.sh/id/models).

## Perintah Interaktif

| Perintah | Deskripsi |
|---------|-----------|
| `/help` | Tampilkan bantuan |
| `/exit` or `Ctrl+C` | Keluar |
| `/clear` | Bersihkan percakapan |
| `/status` | Tampilkan model aktif, izin, dan penggunaan token |
| `/model <name>` | Ganti model |

## Verifikasi Konfigurasi

Periksa hanya apakah variabel lingkungan sudah diatur tanpa mencetak nilainya. Pemeriksaan ini tidak memvalidasi key:

```bash
if [ -n "${TOKENLAB_API_KEY:-}" ]; then
  printf '%s\n' 'TOKENLAB_API_KEY is set'
else
  printf '%s\n' 'TOKENLAB_API_KEY is not set'
fi
```

Jalankan Codex lalu `/status` untuk memeriksa model aktif dan izin. Jika menggunakan profil, jalankan profil yang sama. Lihat [perintah status resmi](https://learn.chatgpt.com/docs/developer-commands?surface=cli#inspect-the-session-with-status).

Saat siap mengirim request nyata, jalankan perintah berikut. Perintah ini menggunakan saldo TokenLab. Periksa balasan dan catatan yang sesuai di [Request](https://tokenlab.sh/dashboard/runs?section=requests). Variabel yang sudah diatur atau aplikasi yang berhasil dimulai belum membuktikan request berhasil.

```bash
codex --profile tokenlab "Reply only with OK. Do not use tools or modify files."
```

## Kasus Penggunaan Umum

**Tinjauan kode:**

```bash
git diff | codex --profile tokenlab "Review these code changes"
```

**Hasilkan pesan commit:**

```bash
git diff --staged | codex --profile tokenlab "Generate a commit message for these changes"
```

**Perbaiki kesalahan:**

```bash
codex --profile tokenlab "Fix the TypeScript errors in src/components/"
```

**Jelaskan kode:**

```bash
cat main.py | codex --profile tokenlab "Explain what this code does"
```

## Pemecahan Masalah

<AccordionGroup>
  <Accordion title="Kesalahan Koneksi">
    - Pastikan `base_url` di tokenlab.config.toml persis `https://api.tokenlab.sh/v1`
    - Periksa konektivitas jaringan
    - Pastikan tidak ada gangguan dari proxy
  </Accordion>

  <Accordion title="Autentikasi Gagal">
    Setelah memperbarui ke Codex 0.149.0 atau versi yang lebih baru, kesalahan `API_KEY_REQUIRED` atau `401 Unauthorized` dapat terjadi jika penyedia kustom hanya mengandalkan `auth.json` saat `requires_openai_auth` tidak diatur atau bernilai `false`. Panduan ini menggunakan `env_key` untuk membaca kunci dari `TOKENLAB_API_KEY` dan tidak bergantung pada `auth.json`. Biarkan `requires_openai_auth` tidak diatur atau bernilai `false`; konfigurasi ini tidak mengharuskan Anda mengubahnya menjadi `true` atau menimpa `auth.json`.

    - Pastikan konfigurasi atau profil yang benar-benar digunakan memuat `env_key = "TOKENLAB_API_KEY"`. Jika Anda menyimpan pengaturan di `tokenlab.config.toml`, jalankan Codex dengan `codex --profile tokenlab`
    - Pastikan `TOKENLAB_API_KEY` sudah diatur di terminal yang digunakan untuk menjalankan Codex. Setelah mengatur variabel tersebut, mulai ulang Codex dari terminal itu
    - Periksa bahwa kunci dimulai dengan `sk-`
    - Pastikan kunci aktif di dashboard TokenLab
  </Accordion>

  <Accordion title="Model Tidak Ditemukan">
    - Periksa nama model agar cocok secara tepat
    - Verifikasi ketersediaan model di [tokenlab.sh/en/models](https://tokenlab.sh/id/models)
  </Accordion>

  <Accordion title="Field khusus Responses ditolak">
    - Beberapa field hanya tersedia di `/v1/responses` ketika TokenLab dapat menjamin perilaku tersebut untuk model dan jalur yang dipilih
    - Jika Anda melihat `unsupported_request_field`, hapus field tersebut atau beralih ke alur kerja yang tidak bergantung padanya
  </Accordion>

  <Accordion title="/compact atau auto-compact gagal">
    - Codex CLI memanggil `POST /v1/responses/compact`, bukan `/v1/compact`
    - Permintaan kompaksi menggunakan `model` sesi saat ini, jadi model tersebut harus tersedia di jalur Responses
    - Pertahankan `wire_api = "responses"` dan `base_url = "https://api.tokenlab.sh/v1"`
  </Accordion>
</AccordionGroup>
