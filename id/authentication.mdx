## API Key

Panggilan model dan sumber daya privat memerlukan kunci API. Endpoint publik seperti `GET /v1/models` dan `GET /v1/models/{model}` dapat digunakan tanpa kunci. Keberhasilan kueri penemuan tidak membuktikan kunci dapat digunakan; ikuti panduan mulai cepat untuk mengirim permintaan model. Gunakan kunci lengkap yang disimpan, bukan awalan dalam daftar.

Untuk endpoint yang kompatibel dengan OpenAI, kirim sebagai:

```bash
Authorization: Bearer sk-your-api-key
```

Untuk permintaan `/v1/messages` yang kompatibel dengan Anthropic, Anda juga dapat menggunakan:

```bash
x-api-key: sk-your-api-key
```

## Token manajemen

Endpoint API manajemen menggunakan jenis token tersendiri:

```bash
Authorization: Bearer mt-your-management-token
```

Gunakan token manajemen hanya untuk `/v1/management/*`. Buka [API → Tokens](https://tokenlab.sh/dashboard/api?tab=tokens) pada workspace yang dipilih untuk membuat atau mengganti token. Simpan token lengkap dengan aman saat ditampilkan; token hanya ditampilkan sekali setelah dibuat atau diganti.

<Note>
Token manajemen tidak dapat digunakan untuk inferensi model, dan API key biasa `sk-...` tidak dapat digunakan untuk API manajemen.
</Note>

## Mendapatkan API Key Anda

1. Masuk ke [TokenLab Dashboard](https://tokenlab.sh/dashboard) Anda
2. Buka **API Keys**
3. Buat key baru
4. Beri nama yang deskriptif
5. Salin segera karena hanya ditampilkan satu kali

<Warning>
- Jangan pernah mengekspos API key dalam kode sisi klien
- Jangan pernah melakukan commit API key ke version control
- Gunakan environment variables atau secret manager
- Rotasi key secara berkala
- Hapus key yang tidak digunakan
</Warning>

## Menggunakan API Key

Lihat [panduan mulai cepat](/id/quickstart) untuk variabel lingkungan dan permintaan pertama yang lengkap. Gunakan SDK sesuai [format API](/id/guides/api-formats) dan simpan kunci di server.

## Fitur API Key

### Batas Penggunaan

Anda dapat menetapkan batas penggunaan pada setiap API key:

| Pengaturan | Deskripsi |
|---------|-------------|
| **No Limit** | Key menggunakan saldo akun Anda tanpa batasan |
| **Fixed Limit** | Key berhenti berfungsi setelah mencapai jumlah yang ditentukan |

### Prefix Key

Semua API key TokenLab diawali dengan `sk-`.

## Respons Error

| Kode Status | Tipe | Kode | Deskripsi |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | Kunci API tidak ada, tidak valid, tidak aktif, atau telah dicabut |
| 401 | `expired_api_key` | `expired_api_key` | Kunci API telah kedaluwarsa |
| 402 | `insufficient_balance` | `insufficient_balance` | Saldo akun tidak mencukupi |
| 402 | `quota_exceeded` | `quota_exceeded` | Batas penggunaan API key tercapai |

Contoh:

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
