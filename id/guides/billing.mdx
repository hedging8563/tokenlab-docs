Satu saldo TokenLab berlaku untuk semua model. Tidak ada langganan atau pengeluaran minimum; tagihan mengikuti model dan penggunaan tercatat.

## Harga dan opsi pengiriman

Periksa harga terbaru di halaman model, `GET /v1/models/{model}/pricing`, atau Pricing API. Jangan menanam tabel harga salinan dalam aplikasi. Teks dan embedding dapat dihitung per token input, output, atau cache; media juga per gambar, detik, menit, permintaan, atau tugas.

`TokenLab Verified` memakai harga publik TokenLab, sedangkan `Official` memakai lapisan Official berdasarkan harga publik pembuat model. `Auto` mendahulukan Verified, lalu Official jika diperlukan; hanya opsi yang mengirim hasil yang ditagih sekali. Console menampilkan estimasi maksimum sebelum konfirmasi generasi berbayar dan biaya akhir di Runs serta Usage.

[Pricing API](/id/api-reference/pricing/get-pricing)

## Penagihan asinkron dan catatan

Sebagian tugas mencadangkan estimasi biaya saat dibuat. Simpan ID dan `poll_url`, lalu periksa hingga `completed` atau `failed`. Tugas sukses ditagih sekali dan sisa cadangan dilepas; saat gagal, biaya tertunda dilepas atau dikembalikan.

Respons kompatibel OpenAI tanpa streaming dapat memuat `billing_transaction_id` atau `X-Billing-Transaction-ID` setelah penagihan. Format native mungkin hanya memakai header. Hasil asinkron atau streaming dapat tiba sebelum catatan keuangan; periksa Usage jika ID belum ada.

Usage menampilkan model, kunci, biaya, dan konsumsi. Tokenisasi berbeda menurut model, bahasa, dan media; perkiraan karakter bukan pengganti tagihan akhir. Streaming tidak mengurangi token yang ditagih. Bandingkan biaya akhir tugas setara dan pakai batas keluaran yang didukung.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Menggunakan Console

Pilih jumlah dan metode pembayaran yang tersedia di Console → Billing. Saldo diperbarui setelah layanan pembayaran mengonfirmasi.

Atur batas belanja saat membuat atau mengedit kunci di Console → API Keys. Jika tercapai, API mengembalikan `402 Payment Required`.

Atur peringatan saldo di Console → Settings. Kirim Request ID dan ID tugas ke support@tokenlab.sh untuk pertanyaan tagihan, jangan kirim kunci API.
