description: "Kendalikan biaya dengan data penggunaan nyata"

Bandingkan tugas serupa berdasarkan biaya akhir pada penggunaan workspace. Catat model, kunci API, token input, output, cache, serta permintaan gagal atau berulang.

Fokuskan instruksi dan konteks pada tugas. Mulai sesi baru ketika riwayat tidak lagi membantu. Tetapkan batas output sesuai format API dan sisakan ruang untuk menyelesaikan pekerjaan.

Diskon cache dan tingkat hit tidak dijamin. Periksa detail model terkini serta penggunaan cache yang tercatat. Gunakan kunci API terpisah dan batas yang sesuai untuk setiap proyek. Bandingkan biaya per tugas yang selesai dengan benar, bukan hanya harga per token.
