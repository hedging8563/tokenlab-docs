Sebagian besar alat dapat terhubung ke TokenLab dengan mengganti kunci API dan URL dasar. Konfigurasi tepatnya bergantung pada format API yang dapat digunakan alat tersebut.

| Format API | URL dasar | Klien umum |
| --- | --- | --- |
| Chat Completions (Kompatibel dengan OpenAI) | `https://api.tokenlab.sh/v1` | SDK OpenAI, berbagai aplikasi chat dan framework |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | Klien Responses dan alat yang menggunakan event Responses |
| Anthropic Messages | `https://api.tokenlab.sh` | SDK Anthropic dan alat untuk Claude |
| Gemini | `https://api.tokenlab.sh` | Klien REST dan SDK Gemini yang mengizinkan host khusus |

Model yang dipilih harus mencantumkan format yang sama di `accepted_request_formats`. Streaming dan pemanggilan alat juga bergantung pada kemampuan model serta dukungan klien. Lihat contoh di [Format API](/id/guides/api-formats).

## Label kompatibilitas

| Label | Arti |
| --- | --- |
| **Kompatibel** | Konfigurasi TokenLab pada halaman yang ditautkan menggunakan opsi konfigurasi yang didokumentasikan oleh klien |
| **Kompatibel dengan batasan** | Konfigurasi berlaku untuk fitur atau metode autentikasi tertentu; layanan vendor lainnya tetap memiliki persyaratan tersendiri |

Label ini menjelaskan konfigurasi pada halaman yang ditautkan. Ketersediaan fitur juga bergantung pada model yang dipilih dan versi klien.

## Penggunaan dalam respons streaming

Aliran Chat Completions menerima `stream_options: { include_usage: true }`, yang menambahkan potongan penggunaan terakhir sebelum aliran berakhir. API Responses tidak menyediakan `include_usage`; alirannya menyampaikan penggunaan pada event terakhir.

## Hal yang tidak digantikan oleh kunci API khusus

Sebagian produk menggabungkan panggilan model dengan fitur yang dihosting vendor. Kunci TokenLab dapat digunakan untuk permintaan model yang tersedia melalui pengaturan BYOK, tetapi tidak menggantikan langganan lain, layanan pelengkapan otomatis, fitur akun, atau ekstensi milik vendor.

Jika pembaruan alat mengubah konfigurasinya, ikuti halaman integrasi terkini alih-alih menyalin contoh variabel lingkungan lama.

## Sebelum mengandalkan suatu fitur

- Pastikan alat mengizinkan URL dasar khusus untuk format yang diperlukan.
- Pastikan model mencantumkan format tersebut di `accepted_request_formats`.
- Coba streaming dan pemanggilan alat jika alur kerja Anda membutuhkannya.
- Simpan kunci API di perangkat atau server tepercaya.
- Catat ID permintaan saat melaporkan kegagalan.
