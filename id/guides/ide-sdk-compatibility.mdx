## Gambaran Umum

TokenLab menyediakan berbagai format API agar alat pengodean, SDK, dan framework yang umum digunakan dapat terintegrasi dengan kode tambahan (glue code) yang minimal.

Halaman ini sengaja dibuat lebih ringkas daripada matriks pemasaran:

- **Didukung (Supported)** berarti kami mendokumentasikan jalur pengaturan yang konkret dan TokenLab menyediakan bentuk protokol yang diharapkan oleh jalur tersebut.
- **Jalur asli yang kuat (Strong native path)** berarti repositori juga memiliki bukti adaptor langsung atau format permintaan untuk keluarga protokol tersebut.
- **Upaya terbaik (Best-effort)** berarti integrasi dapat berfungsi, namun klien upstream tidak memperlakukan alur kerja gateway kustom ini sebagai kontrak yang stabil.

<Note>
  Bidang yang tidak didukung tidak ditangani secara seragam. Pada rute kompatibilitas, beberapa bidang diabaikan atau dinormalisasi. Pada `/v1/responses`, bidang yang tidak didukung dapat mengembalikan kesalahan `400` atau `503` secara eksplisit jika rute tersebut tidak dapat menjamin perilaku yang diminta.
</Note>

## Format API yang Didukung

| Endpoint | Format | Kasus Penggunaan |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | Kompatibilitas universal |
| `/v1/responses` | OpenAI Responses | Percakapan stateful |
| `/v1/messages` | Anthropic Messages | Fitur asli Claude |
| `/v1beta/models/:model:generateContent` | Google Gemini | Fitur asli Gemini |

## Kompatibilitas IDE & CLI

### Jalur Alat yang Didokumentasikan

| Alat | Tingkat Dukungan | Format | Catatan |
|------|---------------|--------|-------|
| **Cursor** | Didukung dengan batasan | Kompatibel dengan OpenAI | Berfungsi untuk alur chat/editor standar BYOK, bukan sebagai pengganti fitur yang dikelola Cursor seperti Tab Completion |
| **Claude Code CLI** | Jalur asli yang kuat | Anthropic | Rute `/v1/messages` asli dengan cakupan adaptor untuk thinking dan `tool_choice` |
| **Codex CLI** | Didukung dengan batasan model/jalur | OpenAI Responses | Perlakukan `/v1/responses` sebagai jalur lanjutan untuk alur kerja khusus Codex; beberapa bidang khusus Responses tidak dijamin ada di setiap model dan jalur rute |
| **Gemini CLI** | Upaya terbaik / eksperimental | Gemini | Alur base URL kustom TokenLab bukan merupakan integrasi resmi Gemini CLI |
| **OpenCode** | Didukung | Kompatibel dengan OpenAI | Gunakan penyedia yang kompatibel dengan OpenAI secara default; beralih ke penyedia berbasis Responses hanya jika Anda benar-benar membutuhkannya |
| **OpenHands** | Didukung | Kompatibel dengan OpenAI | Gunakan jalur LiteLLM/kompatibel dengan OpenAI dengan `openai/<model>` dan base URL `/v1` TokenLab |

<Note>
  Editor dan alat agen lain yang kompatibel dengan OpenAI sering kali berfungsi dengan pola base URL yang sama; periksa dukungan penyedia kustom alat tersebut sebelum menggunakannya dalam produksi.
</Note>

## Parameter Chat Completions

### Parameter Inti

| Parameter | Tipe | Deskripsi |
|-----------|------|-------------|
| `model` | string | Pengenal model (wajib) |
| `messages` | array | Pesan percakapan (wajib) |
| `max_tokens` | integer | Token output maksimum |
| `temperature` | number | Suhu pengambilan sampel (0-2) |
| `top_p` | number | Pengambilan sampel nukleus (0-1) |
| `stream` | boolean | Aktifkan streaming |

### Pemanggilan Alat (Tool Calling)

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### Opsi Pilihan Alat (Tool Choice)

| Format | Contoh | Deskripsi |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | Pemilihan sederhana |
| Objek OpenAI | `{ "type": "function", "function": { "name": "fn" } }` | Paksa fungsi tertentu |
| Objek Anthropic | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Format asli Anthropic |

### Parameter Lanjutan

| Parameter | Tipe | Deskripsi |
|-----------|------|-------------|
| `stream_options` | object | Hanya Chat Completions: `{ include_usage: true }` untuk jumlah token |
| `reasoning_effort` | string | `"low"`, `"medium"`, `"high"` untuk model GPT-5 yang mendukung penalaran |
| `service_tier` | string | `"auto"` atau `"default"` |
| `seed` | integer | Output deterministik |
| `logprobs` | boolean | Kembalikan probabilitas log |
| `top_logprobs` | integer | Jumlah probabilitas log teratas (0-20) |
| `logit_bias` | object | Peta bias token (-100 hingga 100) |
| `frequency_penalty` | number | Penalti pengulangan (-2 hingga 2) |
| `presence_penalty` | number | Penalti topik (-2 hingga 2) |
| `stop` | string/array | Urutan berhenti |
| `n` | integer | Jumlah penyelesaian (1-128) |
| `user` | string | Pengenal pengguna untuk pelacakan |

### Fitur Lanjutan OpenAI

| Parameter | Tipe | Deskripsi |
|-----------|------|-------------|
| `modalities` | array | `["text", "audio"]` untuk multimodal |
| `audio` | object | Konfigurasi output audio (suara, format) |
| `prediction` | object | Output yang diprediksi untuk penyelesaian lebih cepat |
| `metadata` | object | Pasangan kunci-nilai untuk pelacakan |
| `store` | boolean | Simpan untuk pengambilan nanti |

### Opsi Khusus Penyedia

```json
{
  "anthropic_options": {
    "thinking": {
      "type": "enabled",
      "budget_tokens": 10000
    },
    "prompt_caching": true
  },
  "google_options": {
    "safety_settings": [...],
    "google_search": true,
    "code_execution": true
  }
}
```

## Parameter Responses API

### Parameter Inti

| Parameter | Tipe | Deskripsi |
|-----------|------|-------------|
| `model` | string | Pengenal model |
| `input` | string/array | Konten input |
| `instructions` | string | Instruksi sistem |
| `max_output_tokens` | integer | Token output maksimum |
| `previous_response_id` | string | Lanjutkan percakapan |

### Parameter Lanjutan

| Parameter | Tipe | Deskripsi |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` atau `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | Untuk model penalaran |
| `service_tier` | string | Tingkat prioritas |

### Format Alat

Mendukung format alat OpenAI dan Anthropic:

```json
// Format OpenAI
{ "type": "function", "name": "fn", "parameters": {...} }

// Format Anthropic (Kompatibilitas Cursor)
{ "name": "fn", "input_schema": {...} }
```

## Streaming

Endpoint generasi yang menyediakan `stream: true`, termasuk Chat Completions dan Responses, menggunakan Server-Sent Events (SSE):

```bash
# Chat Completions
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# Chat Completions usage tracking
-d '{"...", "stream_options": {"include_usage": true}}'
```

## Penanganan Kesalahan

TokenLab mengembalikan respons kesalahan yang kompatibel dengan OpenAI:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

Lihat [Panduan Penanganan Kesalahan](/guides/error-handling) untuk detailnya.

## Praktik Terbaik

<AccordionGroup>
  <Accordion title="Gunakan passthrough untuk parameter yang tidak diketahui">
    Parameter yang tidak diketahui hanya diteruskan jika rute publik dan model yang dipilih mendukungnya.
  </Accordion>

  <Accordion title="Gunakan stream_options.include_usage hanya untuk Chat Completions">
    Untuk streaming Chat Completions, aktifkan `stream_options.include_usage` untuk jumlah token yang akurat. Responses memiliki kontrak streaming sendiri dan tidak menyediakan opsi khusus Chat ini.
  </Accordion>

  <Accordion title="Gunakan format tool_choice yang sesuai">
    Sesuaikan dengan format yang diharapkan SDK Anda. TokenLab menerima format OpenAI maupun Anthropic.
  </Accordion>
</AccordionGroup>
