## Body Permintaan

Transkripsi dapat langsung mengembalikan teks atau menerima tugas asinkron dengan HTTP `200`, `id`, dan `status`. Untuk tugas yang diterima, ikuti `poll_url` atau periksa `/v1/tasks/{id}`. Untuk audio panjang yang diproses sinkron, gunakan batas waktu setidaknya `120s`.

<ParamField body="file" type="file" required>
  File audio untuk ditranskripsikan. Format yang didukung: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. Ukuran file maksimum: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  ID model transkripsi, misalnya `whisper-1` atau `gpt-4o-transcribe`. Temukan pilihan terkini melalui `GET /v1/models?recommended_for=stt`.
</ParamField>

<ParamField body="language" type="string">
  Bahasa audio dalam format ISO-639-1 (misalnya, `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  Teks opsional untuk memandu gaya model atau melanjutkan segmen sebelumnya.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Format keluaran. Whisper mendukung `json`, `text`, `srt`, `verbose_json`, dan `vtt`; model lain dapat mendukung pilihan berbeda. Periksa detail model.
</ParamField>

<ParamField body="temperature" type="number">
  Temperatur sampling dari 0 hingga 1, hanya untuk model yang mendukung parameter ini.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  `word` dan/atau `segment`, jika didukung model. Whisper memerlukan `response_format=verbose_json`. Dalam multipart, ulangi `timestamp_granularities[]` untuk beberapa nilai.
</ParamField>

## Respons

Field berikut menjelaskan respons JSON transkripsi atau terjemahan. `text`, `srt`, dan `vtt` mengembalikan teks atau subtitel mentah, bukan objek JSON. Field tambahan bergantung pada model dan format keluaran.

<ResponseField name="text" type="string">
  Teks hasil transkripsi.
</ResponseField>

Untuk `verbose_json`:

<ResponseField name="task" type="string">
  Nama tugas jika dikembalikan, misalnya `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  Bahasa yang terdeteksi.
</ResponseField>

<ResponseField name="duration" type="number">
  Durasi audio dalam detik.
</ResponseField>

<ResponseField name="segments" type="array">
  Segmen transkripsi dengan timestamp.
</ResponseField>

<ResponseField name="words" type="array">
  Timestamp tingkat kata (jika diminta).
</ResponseField>

Tugas transkripsi asinkron yang diterima mengembalikan field berikut, bukan teks transkripsi:

<ResponseField name="id" type="string">
  ID tugas.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias identifier tugas asinkron ketika tersedia.
</ResponseField>

<ResponseField name="status" type="string">
  Status tugas: `pending`, `processing`, `completed`, atau `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling yang diutamakan saat disediakan oleh respons pembuatan.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Terjemahan

Untuk menerjemahkan audio ke bahasa Inggris, gunakan endpoint translations:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
