## Ringkasan

Menerjemahkan audio dalam bahasa apa pun yang didukung ke dalam teks bahasa Inggris. Tidak seperti transcription, endpoint ini selalu menghasilkan teks bahasa Inggris terlepas dari bahasa input.

<Note>
  Endpoint ini menerjemahkan audio ke bahasa Inggris. Jangan kirim `language`; terjemahan audio tidak mendukung parameter ini dan dapat mengembalikan `unsupported_parameter`. Untuk terjemahan teks, gunakan `POST /v1/translations`; `recommended_for=translation` merujuk ke API teks tersebut.
</Note>

## Isi Permintaan

Respons dikembalikan setelah terjemahan selesai. Untuk audio panjang, atur batas waktu HTTP setidaknya `120s`.

<ParamField body="file" type="file" required>
  File audio yang akan diterjemahkan. Format yang didukung: `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`. Ukuran file maksimum adalah 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  ID model terjemahan audio, misalnya `whisper-1`. Pastikan detail model terkini mendukung `POST /v1/audio/translations`.
</ParamField>

<ParamField body="prompt" type="string">
  Teks opsional untuk memandu gaya model atau melanjutkan segmen sebelumnya. Harus dalam bahasa Inggris.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Format keluaran. Whisper mendukung `json`, `text`, `srt`, `verbose_json`, dan `vtt`; model lain dapat mendukung pilihan berbeda. Periksa detail model.
</ParamField>

<ParamField body="temperature" type="number">
  Temperatur sampling dari 0 hingga 1, hanya untuk model yang mendukung parameter ini.
</ParamField>

## Respons

Field berikut menjelaskan respons JSON transkripsi atau terjemahan. `text`, `srt`, dan `vtt` mengembalikan teks atau subtitel mentah, bukan objek JSON. Field tambahan bergantung pada model dan format keluaran.

<ResponseField name="text" type="string">
  Teks terjemahan dalam bahasa Inggris.
</ResponseField>

Untuk format `verbose_json`, response juga mencakup:

<ResponseField name="language" type="string">
  Label bahasa dalam respons, jika tersedia.
</ResponseField>

<ResponseField name="duration" type="number">
  Durasi audio input dalam detik.
</ResponseField>

<ResponseField name="segments" type="array">
  Segmen dari teks terjemahan beserta timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/translations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "file=@german_audio.mp3" \
  -F "model=whisper-1"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("german_audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.translations.create({
  model: 'whisper-1',
  file: fs.createReadStream('german_audio.mp3')
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/translations');

$file = new CURLFile('german_audio.mp3', 'audio/mpeg', 'german_audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Terjemahan vs Transcription

| Fitur | Terjemahan | Transcription |
|---------|-------------|---------------|
| Bahasa output | Selalu bahasa Inggris | Sama seperti input |
| Kasus penggunaan | Mengonversi audio berbahasa asing ke bahasa Inggris | Mempertahankan bahasa asli |
| Parameter bahasa | Tidak berlaku | Petunjuk opsional |
