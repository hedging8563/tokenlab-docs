## Ikhtisar

Endpoint ini mengembalikan total saldo saat ini untuk organisasi yang terkait dengan management token. Endpoint ini memakai sumber kebenaran saldo organisasi yang sama dengan billing dan settlement.

## Catatan

- Kolom moneter hanya mendukung USD. Input `CNY` telah dihentikan dan mengembalikan `400 currency_retired`.

- Field moneter dikembalikan dalam USD. Gunakan `balance`, `total_recharge`, dan `total_used` untuk tampilan; gunakan `balance_decimal`, `total_recharge_decimal`, dan `total_used_decimal` untuk rekonsiliasi akurat.

## Contoh

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
