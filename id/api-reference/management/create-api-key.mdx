## Ikhtisar

Membuat API key `type=user` baru di organisasi yang terkait dengan management token saat ini.

## Body Request

| Bidang | Tipe | Default / Batas | Catatan |
|-------|------|-----------------|---------|
| `name` | string | opsional, bawaan `Default Key`, panjang `1-50` | Nama tampilan, dipangkas di sisi server |
| `limitAmount` | number \| string \| null | `0–100000` USD | `null` berarti tanpa batas; `0` mencegah pengeluaran. String desimal mendukung hingga 6 angka desimal. Saat membuat kunci, menghilangkan kolom ini berarti tanpa batas. |
| `limitCurrency` | enum | bawaan `USD` | Hanya USD. Mengirim `CNY` menghasilkan `400 currency_retired`. |
| `models` | string[] | bawaan `[]` | Daftar izin model opsional |
| `deliveryPolicy` | string \| null | `auto`, `verified`, `official`, `null` | `null` mewarisi kebijakan pengiriman ruang kerja. |
| `expiresAt` | string \| null | datetime RFC3339 | `null` berarti tidak kedaluwarsa |

## Catatan

- Kolom moneter hanya mendukung USD. Input `CNY` telah dihentikan dan mengembalikan `400 currency_retired`.

- Nilai penuh API key hanya ditampilkan sekali dalam respons.
- `models: []` berarti key tidak memiliki batasan model tambahan di luar kebijakan organisasi.
- `limitAmount: 0` membuat key yang valid tetapi belum bisa memakai kuota sampai diperbarui.

## Contoh

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "kling-3.0-video"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>

## Kolom penting

<ResponseField name="key" type="string">Nilai rahasia lengkap kunci API. Nilai ini hanya dikembalikan sekali saat dibuat.</ResponseField>
<ResponseField name="id" type="string">Pengidentifikasi kunci API yang digunakan dalam panggilan API Manajemen berikutnya.</ResponseField>
<ResponseField name="name" type="string">Nama tampilan kunci API.</ResponseField>
<ResponseField name="key_prefix" type="string">Awalan kunci nonrahasia untuk tampilan dan dukungan.</ResponseField>
<ResponseField name="status" type="string">Salah satu dari `active`, `inactive`, `suspended`, atau `revoked`.</ResponseField>
<ResponseField name="limit_amount" type="number | null">Batas pengeluaran USD sebagai angka JSON untuk tampilan. `null` berarti tanpa batas.</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">Batas pengeluaran USD yang tepat sebagai string desimal. `null` berarti tanpa batas.</ResponseField>
<ResponseField name="used_amount" type="number">Akumulasi biaya penggunaan dalam USD sebagai angka JSON untuk tampilan.</ResponseField>
<ResponseField name="used_amount_decimal" type="string">Akumulasi biaya penggunaan yang tepat dalam USD sebagai string desimal.</ResponseField>
<ResponseField name="models" type="string[]">Daftar model yang diizinkan per kunci. Array kosong berarti tidak ada batasan model tambahan di tingkat kunci.</ResponseField>
<ResponseField name="delivery_policy" type="string | null">`auto`, `verified`, `official`, `null`. `null` mewarisi kebijakan pengiriman ruang kerja.</ResponseField>
<ResponseField name="expires_at" type="string | null">Stempel waktu ISO saat kunci kedaluwarsa, atau `null` jika tidak kedaluwarsa.</ResponseField>
<ResponseField name="last_used_at" type="string | null">Stempel waktu ISO penggunaan terbaru, atau `null` jika belum pernah digunakan.</ResponseField>
<ResponseField name="created_at" type="string">Stempel waktu ISO pembuatan.</ResponseField>
