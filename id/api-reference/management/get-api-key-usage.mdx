title: "Lihat penggunaan API key"
openapi: "GET /v1/management/api-keys/{keyId}/usage"
description: "Mengembalikan detail penggunaan yang dipaginasi untuk API key pengguna."
---

## Ikhtisar

Endpoint ini mengembalikan detail penggunaan per API key tanpa menampilkan detail routing penyedia.

## Parameter kueri

| Parameter | Tipe | Default / batas | Deskripsi |
|-----------|------|-----------------|-----------|
| `page` | integer | bawaan `1`, minimum `1` | Nomor halaman mulai dari 1 |
| `limit` | integer | bawaan `50`, minimum `1`, maksimum `100` | Ukuran halaman |
| `model` | string | panjang maksimum `100` | Nama model yang diminta |
| `modelVendor` | string | panjang maksimum `100` | Vendor model publik |
| `scene` | enum | - | `chat`, `image`, `audio`, `video`, `embedding`, `rerank`, `translation`, `music`, `3d`, `realtime` |
| `startDate` | string | - | Batas bawah inklusif; menerima RFC3339 dengan timezone atau `YYYY-MM-DD` |
| `endDate` | string | - | Batas atas inklusif; menerima RFC3339 dengan timezone atau `YYYY-MM-DD` |

Jika `startDate` dan `endDate` dikirim bersamaan, `startDate` harus lebih awal atau sama dengan `endDate`.

## Catatan

- Kolom moneter hanya mendukung USD. Input `CNY` telah dihentikan dan mengembalikan `400 currency_retired`.

- Respons ini dipaginasi.
- Respons hanya mencakup field penagihan dan pelaporan yang bersifat publik.
- Setiap item usage juga dapat menyertakan `billing_transaction_id` setelah request dasarnya mencapai status settlement selesai. Gunakan nilai ini bersama `request_id` untuk rekonsiliasi per request.
- Detail routing penyedia tidak ditampilkan.

## Contoh

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/usage?page=1&limit=20&scene=video&startDate=2026-03-01&endDate=2026-03-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
