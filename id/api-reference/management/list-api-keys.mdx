---
title: "Daftar API Key"
openapi: "GET /v1/management/api-keys"
description: "Mendaftarkan API key yang dikelola pengguna untuk token manajemen organisasi saat ini."
---

## Ikhtisar

Mengembalikan daftar API key pengguna di organisasi yang terkait dengan token manajemen saat ini.

## Catatan

- Kolom moneter hanya mendukung USD. Input `CNY` telah dihentikan dan mengembalikan `400 currency_retired`.

- Key yang dikelola sistem tidak disertakan.

## Contoh

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Kolom penting

<ResponseField name="object" type="string">Selalu `list`.</ResponseField>
<ResponseField name="data" type="array">Array objek kunci API.</ResponseField>
<ResponseField name="pagination" type="object">Metadata paginasi dengan `page`, `limit`, `total`, dan `totalPages`.</ResponseField>
<ResponseField name="data[].id" type="string">Pengidentifikasi kunci API yang digunakan dalam panggilan API Manajemen berikutnya.</ResponseField>
<ResponseField name="data[].name" type="string">Nama tampilan kunci API.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">Awalan kunci nonrahasia untuk tampilan dan dukungan.</ResponseField>
<ResponseField name="data[].status" type="string">Salah satu dari `active`, `inactive`, atau `revoked`.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">Batas pengeluaran USD sebagai angka JSON untuk tampilan. `null` berarti tanpa batas.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">Batas pengeluaran USD yang tepat sebagai string desimal. `null` berarti tanpa batas.</ResponseField>
<ResponseField name="data[].used_amount" type="number">Akumulasi biaya penggunaan dalam USD sebagai angka JSON untuk tampilan.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">Akumulasi biaya penggunaan yang tepat dalam USD sebagai string desimal.</ResponseField>
<ResponseField name="data[].models" type="string[]">Daftar model yang diizinkan per kunci. Array kosong berarti tidak ada batasan model tambahan di tingkat kunci.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">Stempel waktu ISO saat kunci kedaluwarsa, atau `null` jika tidak kedaluwarsa.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">Stempel waktu ISO penggunaan terbaru, atau `null` jika belum pernah digunakan.</ResponseField>
<ResponseField name="data[].created_at" type="string">Stempel waktu ISO pembuatan.</ResponseField>
