title: "Lihat billing API Key"
openapi: "GET /v1/management/api-keys/{keyId}/billing"
description: "Mengembalikan breakdown billing teragregasi untuk API key pengguna."
---

## Ikhtisar

Endpoint ini mengembalikan agregat billing berbasis konsumsi untuk API key yang dipilih, termasuk total biaya, total request, usage per unit penagihan, breakdown `by_model`, `by_logical_model`, `by_model_vendor`, dan `by_scene`, serta tren biaya harian.

## Catatan

- Kolom moneter hanya mendukung USD. Input `CNY` telah dihentikan dan mengembalikan `400 currency_retired`.

- Top-up, invoice, dan catatan keuangan tingkat organisasi lainnya tidak termasuk.

## Contoh

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Kolom penting

<ResponseField name="api_key" type="object">Ringkasan kunci API dengan bidang yang sama seperti respons daftar, pembuatan, dan pembaruan.</ResponseField>
<ResponseField name="summary" type="object">Total agregat untuk filter yang dipilih.</ResponseField>
<ResponseField name="breakdowns" type="object">Rincian agregat untuk filter yang dipilih.</ResponseField>
<ResponseField name="summary.total_requests" type="number">Total permintaan.</ResponseField>
<ResponseField name="summary.total_cost" type="number">Total biaya dalam USD sebagai angka JSON untuk tampilan.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">Total biaya yang tepat dalam USD sebagai string desimal.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">Total token prompt.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">Total token penyelesaian.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">Total token.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">Kuantitas penggunaan yang dikelompokkan menurut satuan penggunaan.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">Rincian berdasarkan model publik yang diminta.</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">Rincian berdasarkan model publik logis.</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">Rincian berdasarkan vendor model publik.</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">Rincian berdasarkan skenario permintaan publik.</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">Tren biaya harian.</ResponseField>
