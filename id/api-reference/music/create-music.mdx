---
title: "Buat Musik"
openapi: "POST /v1/music/generations"
description: "Membuat tugas pembuatan musik menggunakan Suno"
---

Hasilkan musik dan lirik menggunakan AI. Ini adalah API asinkron. Respons create mengembalikan identitas tugas dan, ketika tersedia, juga dapat menyertakan `poll_url` yang diprioritaskan.

## Body Permintaan

<ParamField body="model" type="string" default="suno_music">
  ID model musik, misalnya `suno-music`. Untuk lirik saja, pilih model yang operasi publik terkininya mencakup `lyrics`.
</ParamField>

<ParamField body="prompt" type="string">
  Deskripsi musik atau teks pengganti. Wajib untuk musik, lirik, upload-cover, upload-extend, dan replace-section; opsional untuk add-instrumental dan pemisahan trek.
</ParamField>

<ParamField body="title" type="string">
  Judul untuk lagu yang dihasilkan.
</ParamField>

<ParamField body="tags" type="string">
  Tag gaya (misalnya, "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  Gaya yang perlu dihindari. Wajib saat `audio_operation` bernilai `add-instrumental`.
</ParamField>

<ParamField body="action" type="string">
  Nilai opsional `MUSIC` atau `LYRICS`. Pilih model yang mendukung operasi publik terkait; field ini tidak menambahkan kemampuan lirik pada model khusus musik.
</ParamField>

<ParamField body="mv" type="string">
  Pemilih versi Suno. Wajib untuk pembuatan, upload-cover, upload-extend, add-instrumental, dan penggantian dari `audio_url`. Hilangkan untuk lirik, penggantian dari `task_id` + `audio_id`, dan pemisahan trek. Nilai yang diterima: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  Setel ke `true` untuk menghasilkan output instrumental tanpa vokal.
</ParamField>

<ParamField body="audio_url" type="string">
  URL audio referensi atau unggahan yang dapat diakses publik. Jika dikirim tanpa `audio_operation`, TokenLab memakai alur upload-cover.
</ParamField>

<ParamField body="audio_operation" type="string">
  Operasi audio: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation`, dan `advanced-split` memerlukan `task_id` + `audio_id`; `advanced-split` juga memerlukan `stem_name`. `upload-extend` memerlukan `continue_at` lebih besar dari 0. `add-instrumental` memerlukan `audio_url`, `title`, `tags`, dan `negative_tags`.

  `replace-section` memerlukan `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s`, dan `full_lyrics`. Pilih tepat satu sumber: `task_id` + `audio_id`, atau `audio_url` + `mv`. Interval penggantian harus 6–60 detik.
</ParamField>

<ParamField body="task_id" type="string">
  ID tugas sumber milik organisasi Anda, untuk mengganti audio yang dihasilkan atau memisahkan trek.
</ParamField>

<ParamField body="audio_id" type="string">
  ID audio yang dikembalikan dalam hasil tugas sumber. Wajib bersama `task_id` untuk penggantian audio yang dihasilkan dan pemisahan trek.
</ParamField>

<ParamField body="infill_start_s" type="number">
  Awal penggantian dalam detik, minimal 0. Wajib untuk `replace-section`.
</ParamField>

<ParamField body="infill_end_s" type="number">
  Akhir penggantian dalam detik. Wajib untuk `replace-section`, 6–60 detik setelah `infill_start_s`.
</ParamField>

<ParamField body="full_lyrics" type="string">
  Lirik lengkap lagu hasil. Wajib untuk `replace-section`.
</ParamField>

<ParamField body="stem_name" type="string">
  Nama trek. Wajib untuk `advanced-split`.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  ID klip sebelumnya untuk dilanjutkan.
</ParamField>

<ParamField body="continue_at" type="number">
  Waktu dalam detik untuk melanjutkan. Wajib dan lebih besar dari 0 untuk `upload-extend`.
</ParamField>

<Note>
`prompt` menerima hingga 5000 karakter; `tags` dan `negative_tags` masing-masing hingga 1000 karakter. Operasi dan parameter yang didukung mengikuti detail model terkini.
</Note>

## Respons

<ResponseField name="id" type="string">
  ID tugas untuk polling status.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias dari ID tugas asinkron yang sama, jika dikembalikan.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling prioritas ketika tersedia.
</ResponseField>

<ResponseField name="status" type="string">
  Status tugas: `pending`, `processing`, `completed`, atau `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  Timestamp Unix pembuatan tugas, jika dikembalikan.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
