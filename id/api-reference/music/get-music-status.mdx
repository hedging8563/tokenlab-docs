---
title: "Dapatkan Status Musik"
openapi: "GET /v1/tasks/{id}"
description: "Mengambil status dan hasil dari tugas pembuatan musik"
---

Lakukan polling pada endpoint ini untuk memeriksa status tugas pembuatan musik Anda.

<Info>
Jika respons create menyertakan `poll_url`, prioritaskan URL tersebut saat melakukan polling. `id` dan `task_id` harus diperlakukan sebagai identitas tugas asinkron yang sama.


Task publik yang kedaluwarsa atau tidak tersedia dapat mengembalikan `404 async_task_not_found`. Jika kepemilikan task untuk API key saat ini tidak dapat dipastikan, responsnya adalah `403 task_not_owned`.
</Info>

## Parameter Path

<ParamField path="id" type="string" required>
  ID tugas pembuatan musik.
</ParamField>

## Respons

<ResponseField name="id" type="string">
  ID tugas.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias dari ID tugas asinkron yang sama, jika dikembalikan.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling yang diutamakan saat disediakan oleh respons pembuatan.
</ResponseField>

<ResponseField name="status" type="string">
  Status tugas: `pending`, `processing`, `completed`, atau `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Nilai progres opsional. Hanya dikembalikan saat nilai progres nyata tersedia; gunakan `status` untuk menentukan penyelesaian.
</ResponseField>

Field hasil bergantung pada operasi. Musik dapat mengembalikan `audio_url` dan `audio_id`; tugas lirik saja mengembalikan `lyrics`; pemisahan dapat mengembalikan beberapa file dalam `data`. `video_url`, judul, progres, dan metadata lain bersifat opsional. Periksa penyelesaian melalui `status` dan baca field yang benar-benar dikembalikan.

<ResponseField name="audio_id" type="string">
  ID audio opsional untuk digunakan dengan ID tugas ini dalam operasi lanjutan yang didukung.
</ResponseField>

<ResponseField name="data" type="array">
  Array keluaran opsional, termasuk file trek terpisah dengan `audio_url` atau `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  URL untuk mengunduh file audio (saat selesai).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL ke versi video dengan visualizer (saat selesai).
</ResponseField>

<ResponseField name="title" type="string">
  Judul lagu yang dihasilkan.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Lirik yang dihasilkan atau disediakan.
</ResponseField>

<ResponseField name="error" type="string | object">
  Pesan kesalahan (saat gagal).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Polling setiap 5 detik
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
