Gunakan endpoint ini jika `accepted_request_formats` pada detail model memuat `openai_responses`. Permintaan dan respons menggunakan format Responses API. Field opsional dan nilai yang didukung bergantung pada model yang dipilih.

## Isi Permintaan

<ParamField body="model" type="string" required>
  ID model yang akan digunakan. Lihat [Models](https://tokenlab.sh/id/models) untuk opsi yang tersedia.
</ParamField>

<ParamField body="input" type="string | array">
  Input bersifat opsional ketika request menggunakan `prompt` yang dapat dipakai ulang atau melanjutkan respons tersimpan dengan `previous_response_id`.

  Daftar item input yang membentuk percakapan.

  Setiap item dapat berupa:
  - `message`: Sebuah pesan percakapan dengan role dan content
  - `function_call`: Permintaan pemanggilan fungsi
  - `function_call_output`: Output dari pemanggilan fungsi

  Untuk input multimodal, `message.content` dapat berupa string biasa atau array blok konten. Untuk model yang mendukung gambar seperti varian GPT-5.6 Terra, kirim gambar sebagai blok `input_image` alih-alih menyematkan URL atau string Base64 langsung ke dalam teks biasa.

  Contoh blok konten:
  - `{ "type": "input_text", "text": "Describe this image" }`
  - `{ "type": "input_image", "image_url": "https://example.com/image.jpg" }`
  - `{ "type": "input_image", "image_url": "data:image/png;base64,..." }`
</ParamField>

<ParamField body="instructions" type="string">
  Instruksi sistem untuk model (setara dengan pesan sistem).
</ParamField>

<ParamField body="max_output_tokens" type="integer">
  Jumlah maksimum token yang akan dihasilkan.
</ParamField>

<ParamField body="temperature" type="number">
  Suhu sampling. Nilai yang didukung dan nilai default bergantung pada model yang dipilih.
</ParamField>

<ParamField body="tools" type="array">
  Alat yang dapat dipanggil model. Jenis dan kombinasi yang didukung bergantung pada model yang dipilih.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Jika true, mengembalikan aliran events.
</ParamField>

<ParamField body="previous_response_id" type="string">
  ID dari respons sebelumnya untuk melanjutkan percakapan.
</ParamField>

<ParamField body="store" type="boolean" default="true">
  Menentukan apakah respons disimpan untuk pengambilan nanti.
</ParamField>

<ParamField body="background" type="boolean" default="false">
  Meminta eksekusi asinkron. Dukungan bergantung pada model yang dipilih.
</ParamField>

<ParamField body="prompt" type="object">
  Referensi ke templat prompt yang dapat digunakan kembali beserta variabelnya.
</ParamField>

<ParamField body="metadata" type="object">
  Metadata yang dilampirkan pada respons untuk keperluan pelacakan.
</ParamField>

<ParamField body="text" type="object">
  Pengaturan keluaran teks. Dukungan `text.format` bergantung pada model yang dipilih.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  Menentukan apakah memperbolehkan beberapa pemanggilan tool secara paralel.
</ParamField>

<ParamField body="top_p" type="number">
  Parameter nucleus sampling (0-1).
</ParamField>

<ParamField body="reasoning" type="object">
  Opsi penalaran, termasuk `effort`, bergantung pada model yang dipilih.
</ParamField>

## Respons

<ResponseField name="id" type="string">
  Identifier unik untuk respons.
</ResponseField>

<ResponseField name="object" type="string">
  Selalu `response`.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Timestamp Unix saat respons dibuat.
</ResponseField>

<ResponseField name="status" type="string">
  Status respons: `queued`, `in_progress`, `completed`, `incomplete`, `failed`, atau `cancelled`. Periksa field ini meskipun permintaan HTTP berhasil.
</ResponseField>

<ResponseField name="output" type="array">
  Daftar item output yang dihasilkan oleh model.
</ResponseField>

<ResponseField name="usage" type="object">
  Statistik penggunaan token.
</ResponseField>

## Endpoint terkait

- `GET /v1/responses/{id}` mengambil respons tersimpan dan mendukung `include`, `include_obfuscation`, `stream`, dan `starting_after`.
- `DELETE /v1/responses/{id}` menghapus respons tersimpan. Ini tidak membatalkan pembuatan respons.
- `POST /v1/responses/compact` mengembalikan objek `response.compaction`.
- Endpoint pembatalan, input-items, dan input-tokens saat ini belum tersedia.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "input": [
      {"type": "message", "role": "user", "content": "Hello!"}
    ],
    "max_output_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.responses.create(
    model="gpt-5.6-terra",
    input=[
        {"type": "message", "role": "user", "content": "Hello!"}
    ],
    max_output_tokens=1000
)

print(response.output)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.responses.create({
  model: 'gpt-5.6-terra',
  input: [
    { type: 'message', role: 'user', content: 'Hello!' }
  ],
  max_output_tokens: 1000
});

console.log(response.output);
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-5.6-terra",
        "input": []map[string]interface{}{
            {"type": "message", "role": "user", "content": "Hello!"},
        },
        "max_output_tokens": 1000,
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/responses", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result["output"])
}
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/responses');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-5.6-terra',
        'input' => [
            ['type' => 'message', 'role' => 'user', 'content' => 'Hello!']
        ],
        'max_output_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
print_r($data['output']);
```
## Contoh Input Visual

Gunakan model yang mendukung gambar dengan menempatkan gambar di dalam `message.content` sebagai blok `input_image`. Nilai `image_url` dapat berupa URL publik atau data URL Base64.

```json
{
  "model": "gpt-5.6-terra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Please describe this image."
        },
        {
          "type": "input_image",
          "image_url": "https://example.com/demo.jpg"
        }
      ]
    }
  ]
}
```
