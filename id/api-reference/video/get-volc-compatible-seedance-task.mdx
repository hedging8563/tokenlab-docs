## Ringkasan

Endpoint ini ditujukan untuk tim yang sudah memakai bentuk tugas Seedance bergaya Volc. Autentikasi memakai TokenLab Bearer API key. ID tugas yang dikembalikan diawali `cgt-`; polling status sampai `status` menjadi `succeeded`, `failed`, `cancelled`, atau `expired`.

<Warning>
Jangan gunakan kembali enum atau struct respons v1. `/v1/tasks/{id}` memakai `pending`, `processing`, `completed`, dan `failed`; endpoint ini memakai enum v3 di atas. Pada v3, `duration` berupa string saat ada dan `error` hanya muncul ketika gagal.
</Warning>

Lihat juga [Model Video Seedance 2.0](/id/guides/seedance-2-video) dan [Pembuatan Video](/id/guides/video-generation).

## Bentuk respons

Respons tugas menggunakan `queued`, `running`, `succeeded`, `failed`, `cancelled`, atau `expired`. Tugas berhasil mengembalikan `content.video_url`; `content.last_frame_url`, field generasi resmi, dan `usage` dapat muncul bila tersedia. `error` hanya disertakan saat gagal. Field TokenLab seperti `progress`, `return_last_frame`, `watermark`, `priority`, atau `camera_fixed` tidak ditambahkan.

## Contoh

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
