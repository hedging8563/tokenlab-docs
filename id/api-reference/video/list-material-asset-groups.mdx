---

Mencantumkan grup material yang dimiliki oleh organisasi yang terautentikasi. Lakukan filter berdasarkan `library_type` dan `status` untuk memisahkan grup avatar virtual dari grup orang asli.

Gunakan `id` yang dikembalikan saat mengunggah material. Jangan masukkan `group_id` sebagai `material_asset_id` selama pembuatan video; pembuatan video memerlukan `id` aset material.

`project_name` memisahkan sumber daya dalam organisasi yang terautentikasi. Nilai default adalah `default`; gunakan nilai yang sama dan peka huruf besar-kecil untuk grup dan aset terkait. Kirim di body JSON untuk POST/PUT dan parameter kueri untuk GET/DELETE.

## Contoh Permintaan

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups?library_type=aigc_avatar&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

      "object": "seedance.material_asset_group",

    }
  ],
  "next_page_token": null
}
