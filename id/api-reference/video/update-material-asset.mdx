---
title: "Memperbarui Aset Material"
openapi: "/openapi/id.json PUT /v1/videos/assets/{assetId}"
description: "Memperbarui aset material Seedance yang dimiliki oleh organisasi saat ini."
---

Perbarui nama material atau metadata. URL sumber dan tipe aset bersifat tetap setelah pembuatan; buat aset baru jika file sumber berubah.

`project_name` memisahkan sumber daya dalam organisasi yang terautentikasi. Nilai default adalah `default`; gunakan nilai yang sama dan peka huruf besar-kecil untuk grup dan aset terkait. Kirim di body JSON untuk POST/PUT dan parameter kueri untuk GET/DELETE.

## Contoh Permintaan

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"},"project_name":"default"}'
```
