Buat sesi validasi visual sebelum mengunggah material `liveness_face` yang dapat digunakan kembali. TokenLab menggunakan format Action API Volc dan autentikasi Bearer TokenLab.

Gunakan organisasi terautentikasi, pengguna, dan `ProjectName` peka huruf besar-kecil yang sama dengan saat membuat sesi.

Buka `Result.H5Link` segera setelah membuat sesi. Batas waktu pembukaan awal H5 dapat berakhir sebelum masa berlaku `BytedToken` selama 30 menit.

## Endpoint dan autentikasi

```text
POST https://api.tokenlab.sh/api/v3?Action=CreateVisualValidateSession&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

Tanda tangan AK/SK Volc tidak diterima. `CallbackURL` wajib diisi dan harus berupa URL HTTPS publik. `ProjectName` bersifat opsional dengan nilai default `default`.

## Alur

1. Simpan `Result.BytedToken` dan buka `Result.H5Link` untuk orang yang akan diverifikasi.
2. Untuk memilih bahasa H5, tambahkan `lng` ke `H5Link`, misalnya `&lng=en`. Bahasa bukan kolom dalam isi permintaan.
3. Setelah alur H5 selesai, browser membuka `Result.CallbackURL`. Kueri callback dapat memuat `bytedToken`, `resultCode`, `algorithmBaseRespCode`, `reqMeasureInfoValue`, dan `verify_type`.
4. Lakukan polling [Mendapatkan hasil validasi visual](/id/api-reference/video/get-visual-validation-result) dengan `BytedToken` yang disimpan hingga `Result.GroupId` dikembalikan.

`BytedToken` berlaku selama 30 menit dan terikat pada organisasi terautentikasi serta `ProjectName`. Tautan H5 hanya mendukung satu verifikasi yang selesai dan menjadi tidak valid setelah digunakan.

Perlakukan `Result.H5Link` sebagai URL browser yang opak: buka sebagai halaman tingkat atas, dan jangan mengurai, mendekode, menulis ulang, atau menyematkannya. TokenLab mengelola handoff browser dan jembatan callback.

## Contoh Permintaan

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=CreateVisualValidateSession&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"CallbackURL":"https://yourapp.example.com/seedance/callback","ProjectName":"default"}'
```

## Contoh Respons

```json
{
  "ResponseMetadata": {
    "RequestId": "req_abc123",
    "Action": "CreateVisualValidateSession",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "BytedToken": "ZXhhbXBsZS10b2tlbg",
    "H5Link": "https://api.tokenlab.sh/api/v3/visual-validation/sessions/svv_example/h5?Version=2024-01-01",
    "CallbackURL": "https://yourapp.example.com/seedance/callback"
  }
}
```

Kesalahan menggunakan struktur tingkat atas yang sama. Baca `ResponseMetadata.Error.Code` dan `ResponseMetadata.Error.Message`, bukan kolom kesalahan API `/v1` TokenLab lainnya.
