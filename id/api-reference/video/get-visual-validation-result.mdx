---
title: "Mendapatkan hasil validasi visual"
openapi: "/openapi/id.json POST /api/v3"
description: "Mendapatkan grup material orang asli yang dihasilkan oleh validasi visual."
---

Lakukan polling Action ini setelah alur validasi visual H5. Hasil yang berhasil mengembalikan ID grup material TokenLab untuk orang yang telah diverifikasi.

Gunakan organisasi terautentikasi, pengguna, dan `ProjectName` peka huruf besar-kecil yang sama dengan saat membuat sesi.

## Endpoint dan autentikasi

```text
POST https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

Kirim `BytedToken` yang dikembalikan oleh [Membuat sesi validasi visual](/id/api-reference/video/create-visual-validation-session). Jika Anda menetapkan `ProjectName` saat pembuatan, kirim nilai yang sama dengan kapitalisasi yang sama di sini; jika tidak, hilangkan atau gunakan `default`.

Hasil mungkin belum siap segera setelah callback browser. Ulangi permintaan yang sama hingga `Result.GroupId` dikembalikan atau `BytedToken` yang berlaku 30 menit kedaluwarsa. Mengulangi permintaan yang berhasil dengan token yang sama akan mengembalikan `GroupId` yang sama.

Gunakan `GroupId` yang dikembalikan sebagai `group_id` saat membuat material `liveness_face`.

## Contoh Permintaan

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"BytedToken":"ZXhhbXBsZS10b2tlbg","ProjectName":"default"}'
```

## Contoh Respons

```json
{
  "ResponseMetadata": {
    "RequestId": "req_def456",
    "Action": "GetVisualValidateResult",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "GroupId": "group-20260720123456-real1"
  }
}
```

Kesalahan menggunakan `ResponseMetadata.Error.Code` dan `ResponseMetadata.Error.Message`. Respons berhasil memuat `ResponseMetadata` dan `Result`; respons tersebut tidak menggunakan struktur respons API `/v1` TokenLab lainnya.
