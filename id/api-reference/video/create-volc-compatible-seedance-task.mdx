## Ringkasan

Endpoint ini ditujukan untuk tim yang sudah memakai bentuk tugas Seedance bergaya Volc. Autentikasi memakai TokenLab Bearer API key. ID tugas yang dikembalikan diawali `cgt-`; polling status sampai `status` menjadi `succeeded`, `failed`, `cancelled`, atau `expired`.

Kontrak task resmi menggunakan jalur REST di bawah `/api/v3/contents/generations/tasks`. Alias Action lama dipertahankan hanya untuk integrasi TokenLab terdahulu dan bukan bagian dari kontrak wire-compatible resmi.

`callback_url` menerima alamat HTTP(S) publik. TokenLab mengirim objek query yang sama pada setiap perubahan ke `queued`, `running`, `succeeded`, `failed`, atau `expired`, tanpa header privat TokenLab. Status `succeeded` dan `failed` dicoba ulang hingga tiga kali setelah lima detik.

<Note>
Untuk pemulihan aman setelah koneksi terputus, kirim `Idempotency-Key` unik pada create REST. Mengulang body dan key yang sama mengembalikan ID `cgt-...` yang sama; key yang sama dengan body berbeda mengembalikan `409`. Ini tidak berlaku untuk rute Action lama.
</Note>

Lihat juga [Model Video Seedance 2.0](/id/guides/seedance-2-video) dan [Pembuatan Video](/id/guides/video-generation).

## Aturan konten

- Gunakan `type=text` untuk teks prompt.
- `type=image_url` tanpa `role` diperlakukan sebagai frame pertama; Anda juga dapat menetapkan `role=first_frame`.
- Gunakan `role=last_frame` hanya bersama frame pertama.
- Gunakan `role=reference_image`, `reference_video`, atau `reference_audio` untuk media referensi.
- Jangan mencampur input frame pertama/terakhir dengan media referensi dalam satu permintaan.

## Catatan parameter

- `ratio` menerima `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, atau `adaptive`.
- Default resmi `generate_audio` adalah `false`; setel `true` saat audio tersinkron diperlukan.
- `service_tier=default` diterima. Tugas kompatibel Seedance 2.0 menolak `service_tier=flex`, `frames`, dan `camera_fixed=true`.
- Saat model yang dipilih mendukungnya, `tools` dapat berisi objek seperti `{ "type": "web_search" }`. Entri tool yang salah format ditolak, bukan diabaikan.

## Contoh

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Idempotency-Key: $CLIENT_JOB_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [
      {"type": "text", "text": "A cinematic forest at sunset"},
      {"type": "image_url", "role": "reference_image", "image_url": {"url": "https://example.com/ref.png"}}
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "generate_audio": false
  }'
```
