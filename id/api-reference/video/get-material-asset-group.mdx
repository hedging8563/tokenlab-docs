---
title: "Mendapatkan Grup Aset Material"
openapi: "GET /v1/videos/assets/groups/{groupId}"
description: "Mengambil satu grup material Seedance berdasarkan ID grup TokenLab."
---

Mengambil satu grup material. `library_type` memberi tahu Anda apakah grup tersebut merupakan grup avatar virtual atau grup orang asli.

Gunakan endpoint ini sebelum melakukan pengunggahan jika Anda perlu memastikan bahwa grup tersebut masih ada dan memiliki `status: "ACTIVE"`.

`project_name` memisahkan sumber daya dalam organisasi yang terautentikasi. Nilai default adalah `default`; gunakan nilai yang sama dan peka huruf besar-kecil untuk grup dan aset terkait. Kirim di body JSON untuk POST/PUT dan parameter kueri untuk GET/DELETE.

## Contoh Permintaan

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Contoh Respons

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
