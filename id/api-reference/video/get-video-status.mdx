## Parameter Path

<ParamField path="id" type="string" required>
  Identifier tugas asinkron kanonik. Saat `id` dan `task_id` sama-sama ada, perlakukan keduanya sebagai identitas tugas yang sama.
</ParamField>

<Info>
Jika respons create mengembalikan `poll_url`, panggil URL tersebut secara persis. Saat URL itu mengarah ke `/v1/tasks/{id}`, perlakukan itu sebagai endpoint status tetap yang kanonik.


Task publik yang kedaluwarsa atau tidak tersedia dapat mengembalikan `404 async_task_not_found`. Jika kepemilikan task untuk API key saat ini tidak dapat dipastikan, responsnya adalah `403 task_not_owned`.
</Info>

## Respons

<Note>
Field hasil, error, timestamp, dan model dikembalikan jika tersedia untuk task.
</Note>

<ResponseField name="id" type="string">
  Identifier tugas asinkron kanonik.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias identifier tugas asinkron.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling prioritas yang dikembalikan oleh respons create.
</ResponseField>

<ResponseField name="billing_transaction_id" type="string">
  ID transaksi billing TokenLab saat settlement sudah selesai. Ini adalah identitas transaksi untuk dashboard/rekonsiliasi dan terpisah dari `id` / `task_id` async.
</ResponseField>

<ResponseField name="status" type="string">
  Status tugas: `pending`, `processing`, `completed`, `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  Nilai progres opsional. Hanya dikembalikan saat nilai progres nyata tersedia; gunakan `status` untuk menentukan penyelesaian.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL dari video yang dihasilkan (saat selesai).
</ResponseField>

<ResponseField name="video" type="object">
  Objek video tunggal dengan `url`, `duration`, `width`, dan `height` saat tersedia.
</ResponseField>

<ResponseField name="videos" type="array">
  Array video saat tugas pembuatan mengembalikan lebih dari satu output.
</ResponseField>

<ResponseField name="error" type="string | object">
  Pesan kesalahan (jika gagal).
</ResponseField>

<ResponseField name="created" type="integer">
  Timestamp pembuatan.
</ResponseField>

<ResponseField name="updated" type="integer">
  Timestamp pembaruan terakhir.
</ResponseField>

<ResponseField name="model" type="string">
  Model yang digunakan oleh tugas.
</ResponseField>

import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}

const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForVideo() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(`HTTP ${response.status}: ${await response.text()}`);
    const data = await response.json();
    console.log(`Status: ${data.status}`);

    if (data.status === 'completed') {
      console.log(`Video URL: ${data.video_url}`);
      return data.video_url;
    } else if (data.status === 'failed') {
      throw new Error(data.error);
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

## Praktik Terbaik Polling

- Lakukan polling setiap 5-10 detik
- Terapkan exponential backoff untuk tugas yang lama
- Atur batas waktu maksimum (misalnya, 10 menit)
- Tangani status `failed` dengan baik

```python
import requests
import time

def wait_for_video(task_id, max_wait=600, interval=5):
    """Wait for video with timeout."""
    start = time.time()

    while time.time() - start < max_wait:
        response = requests.get(
            f"https://api.tokenlab.sh/v1/tasks/{task_id}",
            headers={"Authorization": "Bearer sk-your-api-key"}
        )
        response.raise_for_status()
        data = response.json()

        if data["status"] == "completed":
            return data["video_url"]
        elif data["status"] == "failed":
            raise Exception(data.get("error", "Video generation failed"))

        time.sleep(interval)

    raise TimeoutError("Video generation timed out")
```
