---
title: "Batalkan Batch"
openapi: "/openapi/id.json POST /v1/batches/{batch_id}/cancel"
description: "Membatalkan pekerjaan batch yang sedang antre atau berjalan."
---

Minta pembatalan batch yang sedang antre atau berjalan. Respons berisi status saat ini: pembatalan mungkin masih berlangsung atau sudah selesai. Batch yang sudah berakhir mempertahankan status akhirnya. Jika status yang dikembalikan belum final, ambil batch kembali untuk memeriksa hasilnya.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Identifier untuk panggilan lanjutan dan support.</ResponseField>
<ResponseField name="status" type="string">Status batch saat ini. Permintaan pembatalan yang berhasil tidak selalu mengembalikan `cancelling`.</ResponseField>
