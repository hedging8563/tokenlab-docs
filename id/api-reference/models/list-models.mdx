---
title: "List Models"
openapi: "/openapi/id.json GET /v1/models"
description: "Daftar model yang saat ini tersedia di TokenLab"
---

Katalog model bersifat publik dan tidak memerlukan API key. Setiap item mencakup ringkasan kemampuan saat ini, harga, dan format API. Ambil satu model jika Anda memerlukan detail lengkap.

## Query Parameters

<ParamField query="category" type="string">
  Filter berdasarkan `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank`, atau `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  Kembalikan rekomendasi saat ini untuk tugas seperti `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank`, atau `translation`.
</ParamField>

<ParamField query="provider" type="string">
  Filter berdasarkan pembuat model, seperti `openai`, `anthropic`, `google`, atau `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  Filter berdasarkan tag seperti `chat`, `image`, `video`, `embedding`, atau `translation`.
</ParamField>

## Response

<ResponseField name="object" type="string">Selalu `list`.</ResponseField>
<ResponseField name="data" type="array">Model dengan `id`, `owned_by`, dan ringkasan `tokenlab`.</ResponseField>

Field daftar umum di bawah `tokenlab` meliputi:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` dan `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` dan `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial`, dan `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` saat `recommended_for` digunakan

Saat `recommended_for` digunakan, hasil mungkin juga menyertakan status rekomendasi dan waktu pembaruan. Baca respons saat ini alih-alih menyematkan urutan.

## Example

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```
