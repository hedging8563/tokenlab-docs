---
title: "Mendapatkan Model"
openapi: "GET /v1/models/{model}"
description: "Mendapatkan kapabilitas, harga, dan format API sebuah model"
---

## Parameter Path

<ParamField path="model" type="string" required>
  ID Model, seperti `gpt-5.6-terra` atau `claude-sonnet-4-6`.
</ParamField>

## Respons

<ResponseField name="id" type="string">ID Model.</ResponseField>
<ResponseField name="object" type="string">Selalu `model`.</ResponseField>
<ResponseField name="owned_by" type="string">Pembuat model.</ResponseField>
<ResponseField name="tokenlab" type="object">
  Informasi model TokenLab, termasuk kapabilitas, harga, unit penagihan, batas konteks, format API yang diterima, operasi, dan status siklus hidup.
</ResponseField>

Field `tokenlab` yang umum meliputi:

- `capabilities`: kapabilitas teks, gambar, video, audio, dan lainnya.
- `pricing`: harga publik saat ini.
- `max_input_tokens` dan `max_output_tokens`: batas konteks dan output.
- `accepted_request_formats`: format API yang didukung.
- `supported_operations`: operasi seperti text-to-image atau image-to-video.
- `lifecycle`: ketersediaan, tanggal rilis, tanggal penghentian (deprecation), atau model pengganti.

Beberapa model media juga menyertakan status rekomendasi dan waktu pembaruan. Rekomendasi dapat berubah seiring dengan ketersediaan dan performa, jadi jangan melakukan hard-code pada urutannya.

## Contoh

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.6-terra"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["coding", "json-mode", "prompt-cache", "reasoning", "tool-use", "vision"],
    "accepted_request_formats": ["openai_chat_completions", "openai_responses"]
  }
}
```

Model yang tidak dikenal akan mengembalikan `404 model_not_found`.
