---
title: "Buat Konten"
openapi: "POST /v1beta/models/{model}:generateContent"
description: "Menghasilkan konten menggunakan format Google Gemini API"
---

Gunakan format permintaan dan respons Gemini dengan model yang dikembalikan Gemini Models API. Nama field ProtoJSON lowerCamelCase dan proto snake_case yang sesuai diterima. Field opsional dan nilai yang didukung bergantung pada model yang dipilih.

## Parameter Path

<ParamField path="model" type="string" required>
  Nama model (misalnya, `gemini-2.5-pro`, `gemini-3.5-flash`).
</ParamField>

## Parameter Query

<ParamField query="key" type="string">
  API key (alternatif untuk autentikasi header).
</ParamField>

## Autentikasi

Endpoint Gemini mendukung beberapa metode autentikasi:
- `?key=YOUR_API_KEY` parameter query
- `x-goog-api-key: YOUR_API_KEY` header
- `Authorization: Bearer YOUR_API_KEY` header

## Isi Permintaan

<ParamField body="contents" type="array" required>
  Konten percakapan dengan `parts` dan `role` opsional. Media menggunakan `inlineData` / `inline_data` atau `fileData` / `file_data`. ID Files dan Cache yang dibuat TokenLab hanya dapat digunakan dalam Workspace pemiliknya.
</ParamField>

<ParamField body="systemInstruction" type="object">
  Instruksi sistem untuk model.
</ParamField>

<ParamField body="generationConfig" type="object">
  Pengaturan generasi seperti `temperature`, `topP`, `topK`, `maxOutputTokens`, `stopSequences`, `candidateCount`, `responseModalities`, `responseMimeType`, `responseSchema`, dan `thinkingConfig`. Nama snake_case yang sesuai juga diterima. Nilai dan kombinasi bergantung pada model.
</ParamField>

<ParamField body="safetySettings" type="array">
  Pengaturan filter keamanan.
</ParamField>

## Respons

<ResponseField name="candidates" type="array">
  Kandidat konten yang dihasilkan.
</ResponseField>

<ResponseField name="usageMetadata" type="object">
  Informasi penggunaan token.
</ResponseField>

## Contoh input multimodal

Untuk permintaan multimodal Gemini, letakkan media di dalam `contents[].parts[]` dengan menggunakan byte inline atau referensi file berbasis URL.

Kategori media yang saat ini didukung dalam detail model Gemini:
- gambar
- audio
- video

Untuk media inline, gunakan `inlineData` atau `inline_data` dan kirim byte file yang sudah di-encode Base64.

Untuk media berbasis URL, gunakan `fileData` atau `file_data` dan kirim URL publik `https`.

### Contoh input gambar

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Tolong jelaskan gambar ini." },
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "/9j/4AAQSkZJRgABAQ..."
          }
        }
      ]
    }
  ]
}
```

### Contoh input audio

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Tolong transkripsikan dan ringkas audio ini." },
        {
          "file_data": {
            "mime_type": "audio/mpeg",
            "file_uri": "https://example.com/sample.mp3"
          }
        }
      ]
    }
  ]
}
```

### Contoh input video

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Tolong jelaskan video ini secara singkat." },
        {
          "fileData": {
            "mimeType": "video/mp4",
            "fileUri": "https://example.com/sample.mp4"
          }
        }
      ]
    }
  ]
}
```
