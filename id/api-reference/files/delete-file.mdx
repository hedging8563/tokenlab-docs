## Ikhtisar

Menghapus file yang dibuat melalui `/v1/files`. File Batch dan file referensi gambar yang dibuat TokenLab mengembalikan objek deleted yang kompatibel dengan OpenAI.

Ketika request memakai mode kompatibilitas Anthropic Files, route yang sama menghapus file bergaya Anthropic dari workspace yang terikat.

## Catatan

- Menghapus file tidak membatalkan job Batch yang sudah mereferensikannya.
- file ids yang tidak ada atau tidak diizinkan mengembalikan error not-found publik tanpa mengekspos status routing.
- Hapus file referensi gambar hanya setelah tidak ada request edit gambar tertunda yang membutuhkannya.

## Contoh

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Permintaan / Respons

Gunakan panel OpenAPI interaktif di atas untuk schema yang tepat.
