## Apa itu TokenLab?

TokenLab menghubungkan aplikasi atau alat pemrograman Anda ke model AI dengan satu kunci API dan saldo bersama workspace. Pilih model dan format API yang didukung; permintaan dikenakan tarif yang dipublikasikan.

## Kemampuan yang Didukung

Lihat [katalog model](https://tokenlab.sh/id/models) untuk ID, ketersediaan, format, dan harga terkini.

| Kemampuan | Deskripsi |
|---|---|
| Chat dan penalaran | Pembuatan teks, perencanaan, tools |
| Vision dan multimodal | Pemahaman gambar dan chat multimodal |
| Pembuatan dan edit gambar | Text-to-image dan edit gambar |
| Pembuatan video | Text/image/reference-to-video dan kontrol gerak |
| Audio & Realtime WebSocket | TTS, transkripsi, terjemahan audio, dan sesi WebSocket realtime |
| Embeddings dan rerank | Vektorisasi teks dan pemeringkatan ulang |
| Terjemahan | Alur terjemahan teks dan terjemahan suara melalui WebSocket |
| Musik dan 3D | Pembuatan musik dan asset 3D |
| Worlds | Pembuatan world, polling status, dan alur media asset |
