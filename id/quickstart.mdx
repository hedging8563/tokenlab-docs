## Langkah 1: Mulai dengan kredit uji coba

<Steps>
  <Step title="Buat akun">
    Daftar di [tokenlab.sh](https://tokenlab.sh) menggunakan email, Gmail, atau akun GitHub Anda.
  </Step>
  <Step title="Periksa saldo workspace">
    Lihat saldo dan kredit uji coba yang tersedia di [Penagihan](https://tokenlab.sh/dashboard/billing). Permintaan ditagih dengan harga model saat ini; tambah saldo bila perlu.
  </Step>
  <Step title="Buat dan simpan API key">
    Buka [API key](https://tokenlab.sh/dashboard/api?tab=keys) di workspace Anda. Buat key dan segera simpan nilai lengkapnya; nilai tersebut hanya ditampilkan sekali. Jika sudah menyimpan key lengkap, gunakan nilai itu. Awalan yang ditampilkan atau disalin dari daftar tidak dapat digunakan untuk mengautentikasi request.
  </Step>
</Steps>

<Warning>
Jaga keamanan API key Anda. Jangan pernah mengeksposnya di kode sisi-klien atau repositori publik.
</Warning>

## Atur kunci untuk terminal ini

Perintah berikut tidak memasukkan kunci ke teks perintah. Kunci hanya berlaku untuk terminal ini dan proses turunannya. Gunakan pengelola rahasia untuk aplikasi yang diterapkan.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## Langkah 3: Buat Permintaan Pertama Anda

Untuk sebagian besar integrasi baru, mulailah dengan **Chat Completions** pada `POST /v1/chat/completions`.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

Simpan salah satu contoh SDK sebagai `quickstart.py`, `quickstart.mjs`, `main.go`, atau `quickstart.php`, lalu jalankan `python quickstart.py`, `node quickstart.mjs`, `go run .`, atau `php quickstart.php`. Python, JavaScript, dan Go memakai SDK resmi OpenAI; PHP memakai [client komunitas](https://github.com/openai-php/client) dan memerlukan PHP 8.2+.

<Note>
Gunakan `POST /v1/responses` hanya ketika Anda secara eksplisit membutuhkan perilaku spesifik Responses. Beberapa field yang hanya untuk Responses bergantung pada model yang dipilih dan jalur routing.
</Note>
