---
title: "Optimisation des coûts des Coding Agents"
description: "Maîtriser les coûts avec les données d’utilisation réelles"
---

Comparez des tâches similaires à partir du coût final dans les statistiques d’utilisation de votre espace. Notez le modèle, la clé API, les tokens d’entrée, de sortie et en cache, ainsi que les requêtes échouées ou répétées.

Gardez des consignes et un contexte ciblés. Ouvrez une nouvelle session lorsque l’historique n’aide plus. Définissez les limites de sortie selon le format API choisi, tout en laissant assez de place pour terminer la tâche.

Les remises de cache et les taux de succès ne sont pas garantis. Vérifiez les détails actuels du modèle et l’utilisation réelle du cache. Séparez les projets par clé API avec des limites adaptées. Comparez le coût par tâche correctement terminée, pas seulement le prix du token.
