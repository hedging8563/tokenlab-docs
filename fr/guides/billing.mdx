Un solde TokenLab couvre tous les modèles. Il n’y a ni abonnement ni dépense minimale ; la facturation dépend du modèle et de l’usage enregistré.

## Prix et options de livraison

Consultez les prix actuels sur la page du modèle, via `GET /v1/models/{model}/pricing` ou Pricing API. Ne figez pas une table copiée. Texte et embeddings peuvent être facturés par tokens d’entrée, de sortie ou de cache ; les médias aussi par image, seconde, minute, requête ou tâche.

`TokenLab Verified` utilise les prix publics TokenLab et `Official` la couche Official fondée sur les prix publics du fabricant. `Auto` privilégie Verified puis utilise Official si nécessaire ; seule l’option livrant le résultat est facturée, une fois. Console affiche l’estimation maximale avant confirmation d’une génération payante, puis le montant final dans Runs et Usage.

[Pricing API](/fr/api-reference/pricing/get-pricing)

## Facturation asynchrone et journaux

Certaines tâches réservent le coût estimé à la création. Enregistrez l’ID et `poll_url`, puis consultez jusqu’à `completed` ou `failed`. Une tâche réussie est facturée une fois et le surplus réservé est libéré ; en cas d’échec, le montant en attente est libéré ou remboursé.

Les réponses compatibles OpenAI sans streaming peuvent inclure `billing_transaction_id` ou `X-Billing-Transaction-ID` après facturation. Les formats natifs peuvent n’utiliser que l’en-tête. Le résultat asynchrone ou streamé peut précéder l’écriture comptable ; consultez Usage si l’identifiant manque.

Usage affiche modèle, clé, coût et consommation. La tokenisation varie selon le modèle, la langue et les médias ; compter les caractères ne remplace pas la facture. Le streaming ne réduit pas les tokens facturés. Comparez le coût final de tâches identiques et utilisez les limites de sortie compatibles.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Utiliser Console

Dans Console → Billing, choisissez le montant et un moyen de paiement proposé. Le solde est mis à jour après confirmation du service de paiement.

Définissez un plafond lors de la création ou modification d’une clé dans Console → API Keys. Une fois atteint, l’API renvoie `402 Payment Required`.

Réglez les alertes de solde dans Console → Settings. Pour toute question, transmettez Request ID et ID de tâche à support@tokenlab.sh, jamais votre clé API.
