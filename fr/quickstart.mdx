## Étape 1 : Commencez avec les crédits d'essai

<Steps>
  <Step title="Créer un compte">
    Inscrivez-vous sur [tokenlab.sh](https://tokenlab.sh) avec votre e-mail, Gmail ou compte GitHub.
  </Step>
  <Step title="Vérifier le solde de l’espace de travail">
    Consultez le solde et les crédits d’essai disponibles dans [Facturation](https://tokenlab.sh/dashboard/billing). Cette requête est facturée au prix actuel du modèle ; ajoutez des fonds si nécessaire.
  </Step>
  <Step title="Créer et conserver une clé API">
    Ouvrez [Clés API](https://tokenlab.sh/dashboard/api?tab=keys) dans votre espace de travail. Créez une clé et enregistrez immédiatement sa valeur complète : elle ne s’affiche qu’une seule fois. Si vous avez déjà conservé une clé complète, utilisez cette valeur. Le préfixe affiché ou copié depuis la liste ne permet pas d’authentifier les requêtes.
  </Step>
</Steps>

<Warning>
Conservez votre clé API en lieu sûr. Ne l'exposez jamais dans le code côté client ni dans des dépôts publics.
</Warning>

## Définir la clé pour ce terminal

Ces commandes ne placent pas la clé dans la commande elle-même. Elle ne s’applique qu’au terminal courant et à ses processus enfants. En production, utilisez un gestionnaire de secrets.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## Étape 3 : Effectuez votre première requête

Pour la plupart des nouvelles intégrations, commencez par **Chat Completions** via `POST /v1/chat/completions`.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

Enregistrez un exemple SDK dans `quickstart.py`, `quickstart.mjs`, `main.go` ou `quickstart.php`, puis lancez `python quickstart.py`, `node quickstart.mjs`, `go run .` ou `php quickstart.php`. Python, JavaScript et Go utilisent les SDK officiels OpenAI ; PHP utilise le [client communautaire](https://github.com/openai-php/client), avec PHP 8.2+.

<Note>
Utilisez `POST /v1/responses` uniquement lorsque vous avez explicitement besoin du comportement spécifique à Responses. Certains champs réservés à Responses dépendent du modèle sélectionné et du chemin routé.
</Note>

## Vérifier le résultat

Une requête réussie renvoie une réponse non vide. Vérifiez le modèle, le statut et l’utilisation dans [Requêtes](https://tokenlab.sh/dashboard/runs) du même espace. Consultez le [dépannage](/fr/guides/observability-troubleshooting) en cas d’erreur et le [guide SDK](/fr/integrations/openai-sdk) pour changer de modèle ou activer le streaming.
