---

## Vue d’ensemble

Utilisez cet endpoint pour un polling async unifié entre différents types de tâches tels que la génération de vidéo, d’image, de musique et de 3D.

Si une réponse de création inclut `poll_url`, appelez ce chemin exact. Pour les workflows async plus récents, `poll_url` peut pointer vers `/v1/tasks/{id}`.

## Paramètres de chemin

<ParamField path="id" type="string" required>
  L’ID de tâche renvoyé par la requête de création.
</ParamField>

## Réponse

<Note>
Les champs de résultat, d’erreur, d’horodatage et de modèle sont renvoyés lorsqu’ils sont disponibles pour la tâche.
</Note>

<ResponseField name="id" type="string">
  Identifiant de la tâche.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias de l’identifiant de tâche asynchrone.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling à privilégier lorsque la réponse de création la fournit.
</ResponseField>

<ResponseField name="status" type="string">
  Statut de la tâche, par exemple `pending`, `processing`, `completed` ou `failed`. Les tâches annulées sont représentées comme `failed` avec `cancelled: true`.
</ResponseField>

<ResponseField name="cancelled" type="boolean">
  `true` lorsqu’une tâche asynchrone en file d’attente a été annulée avant l’exécution.
</ResponseField>

<ResponseField name="cancellation_status" type="string">
  Marqueur d’annulation. Présent avec la valeur `cancelled` lorsque l’annulation réussit.
</ResponseField>

<ResponseField name="data" type="array">
  Pour les tâches d’image terminées, les résultats générés sont renvoyés ici. Les tâches d’image renvoient des URL dans `data[].url`.
</ResponseField>

<ResponseField name="progress" type="number">
  Valeur de progression facultative. Renvoyée uniquement lorsqu’une progression réelle est disponible ; utilisez `status` pour déterminer la fin de la tâche.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL de l’asset de résultat lorsque la tâche est terminée et produit une vidéo.
</ResponseField>

<ResponseField name="video" type="object">
  Charge utile d'une seule vidéo avec `url`, `duration`, `width` et `height` lorsque disponible.
</ResponseField>

<ResponseField name="videos" type="array">
  Plusieurs charges utiles vidéo lorsque la tâche de génération renvoie plus d'une sortie.
</ResponseField>

<ResponseField name="created" type="integer">
  Horodatage de création.
</ResponseField>

<ResponseField name="updated" type="integer">
  Horodatage de la dernière mise à jour.
</ResponseField>

<ResponseField name="model" type="string">
  Modèle utilisé pour la tâche.
</ResponseField>

<ResponseField name="error" type="string | object">
  Message d’erreur lorsque la tâche échoue.
</ResponseField>

## Comportement d’erreur

Une tâche publique expirée ou indisponible peut renvoyer `404 async_task_not_found`. Si son appartenance à la clé API actuelle ne peut pas être établie, la réponse est `403 task_not_owned`.

```json
{
  "error": {
    "message": "Task not found or no longer available.",
    "type": "invalid_request_error",
    "code": "async_task_not_found"
  }
}
```

## Exemples

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

```python Python
import requests

poll_url = "/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
response = requests.get(
    f"https://api.tokenlab.sh{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
const response = await fetch(`https://api.tokenlab.sh${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
