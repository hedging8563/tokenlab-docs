---
title: "Obtenir le statut du World"
openapi: "/openapi/fr.json GET /v1/worlds/generations/{id}"
description: "Récupère l’état et le résultat d’une tâche de génération de monde World Labs Marble"
---

Interrogez cet endpoint pour vérifier l’état d’une tâche de génération World Labs Marble. Si la réponse de création incluait `poll_url`, appelez de préférence cette URL exacte.

<Info>
Une tâche publique expirée ou indisponible peut renvoyer `404 async_task_not_found`. Si son appartenance à la clé API actuelle ne peut pas être établie, la réponse est `403 task_not_owned`.
</Info>

## Paramètres de chemin

<ParamField path="id" type="string" required>
  ID de la tâche de génération de monde.
</ParamField>

## Réponse

Seuls `id` et `status` sont obligatoires dans une réponse de statut réussie. Les alias de tâche, identifiants d’opération, ressources du monde, descriptions, coûts et la chaîne `error` sont renvoyés lorsqu’ils sont disponibles. Une tâche terminée ne garantit pas la présence de toutes les URL de ressources.

<ResponseField name="id" type="string">
  ID public de tâche.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias de l’identifiant de tâche asynchrone.
</ResponseField>

<ResponseField name="operation_id" type="string">
  ID de l’opération World Labs en amont.
</ResponseField>

<ResponseField name="status" type="string">
  État de la tâche : `pending`, `processing`, `completed`, `failed` ou `timeout`.
</ResponseField>

<ResponseField name="world_id" type="string">
  ID du monde World Labs en amont une fois terminé.
</ResponseField>

<ResponseField name="world_marble_url" type="string">
  URL du monde Marble généré une fois terminé.
</ResponseField>

<ResponseField name="model_url" type="string">
  Alias de l’URL principale du monde/modèle généré.
</ResponseField>

<ResponseField name="glb_url" type="string">
  URL GLB du maillage collider si disponible.
</ResponseField>

<ResponseField name="pano_url" type="string">
  URL de l’image panoramique si disponible.
</ResponseField>

<ResponseField name="thumbnail_url" type="string">
  URL de miniature si disponible.
</ResponseField>

<ResponseField name="caption" type="string">
  Caption upstream du monde généré.
</ResponseField>

<ResponseField name="cost" type="object">
  Détails du coût de génération, si disponibles, dont `total_credits`. Consultez vos relevés d’utilisation pour le montant facturé.
</ResponseField>

<ResponseField name="error" type="string">
  Message d’erreur si la tâche a échoué.
</ResponseField>

<RequestExample>
```bash cURL
curl --fail-with-body "https://api.tokenlab.sh/v1/worlds/generations/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/worlds/generations/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"},
    )
    response.raise_for_status()
    result = response.json()
    if result["status"] in ["completed", "failed", "timeout"]:
        print(result)
        break
    time.sleep(10)
```
