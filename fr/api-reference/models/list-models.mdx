---
title: "Lister les modèles"
openapi: "GET /v1/models"
description: "Lister les modèles actuellement disponibles sur TokenLab"
---

Le catalogue de modèles est public et ne nécessite pas de clé API. Chaque élément inclut un résumé des capacités actuelles, des prix et des formats API. Récupérez un modèle spécifique lorsque vous avez besoin de détails complets.

## Paramètres de requête

<ParamField query="category" type="string">
  Filtrer par `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank` ou `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  Retourner les recommandations actuelles pour une tâche telle que `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank` ou `translation`.
</ParamField>

<ParamField query="provider" type="string">
  Filtrer par fabricant de modèle, tel que `openai`, `anthropic`, `google` ou `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  Filtrer par un tag tel que `chat`, `image`, `video`, `embedding` ou `translation`.
</ParamField>

## Réponse

<ResponseField name="object" type="string">Toujours `list`.</ResponseField>
<ResponseField name="data" type="array">Modèles avec `id`, `owned_by` et un résumé `tokenlab`.</ResponseField>

Les champs de liste courants sous `tokenlab` incluent :

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` et `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` et `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial` et `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` lorsque `recommended_for` est utilisé

Lorsque `recommended_for` est utilisé, les résultats peuvent également inclure le statut de recommandation et une heure de mise à jour. Lisez la réponse actuelle au lieu de fixer l'ordre.

## Exemple

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```
