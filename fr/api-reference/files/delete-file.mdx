## Aperçu

Supprime un fichier créé via `/v1/files`. Les fichiers Batch et les fichiers de référence d’image créés par TokenLab renvoient un objet deleted compatible OpenAI.

Lorsque la requête active le mode de compatibilité Anthropic Files, la même route supprime le fichier de style Anthropic dans l’espace de travail lié.

## Notes

- Supprimer un fichier n’annule pas les jobs Batch qui le référencent déjà.
- Les file ids absents ou non autorisés renvoient une erreur not-found publique sans exposer l’état de routage.
- Supprimez les fichiers de référence d’image seulement lorsqu’aucune requête d’édition d’image en attente n’en a besoin.

## Exemple

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
