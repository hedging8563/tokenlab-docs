title: "Supprimer un fichier"

description: "Supprime un fichier de lot, une liaison de fichier image/référence, ou un fichier en mode Anthropic."
---

## Vue d’ensemble

Supprime un fichier créé avec `/v1/files`. Sans en-têtes Anthropic, la route supprime les fichiers de lot TokenLab ou les liaisons de fichiers image/référence. Avec `anthropic-beta: files-api-2025-04-14`, elle utilise le mode Anthropic Files API pour l’espace de travail lié.

## Notes

- La suppression d’un fichier de lot retire l’enregistrement stocké et empêche les futurs lots d’utiliser cet ID de fichier.
- La suppression d’un fichier image/référence demande au fournisseur sélectionné de supprimer le fichier, puis retire la liaison TokenLab après acceptation.
- Le mode Anthropic Files API nécessite les mêmes en-têtes Anthropic natifs que l’envoi et la récupération.

## Exemple

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
