## Aperçu

Ce point de terminaison sert principalement l’API Batch compatible avec OpenAI de TokenLab, y compris les entrées de lot téléversées et les fichiers de sortie ou d’erreur générés.

Lorsque la requête active le mode de compatibilité Anthropic Files, la même route peut aussi lister les fichiers de style Anthropic disponibles pour l’espace de travail lié.


Sans en-têtes Anthropic, la liste peut inclure des fichiers de lot et des fichiers image/référence TokenLab. Utilisez `purpose=batch`, `purpose=batch_output`, `purpose=user_data` ou `purpose=vision` pour filtrer.
## Remarques

- Les fichiers d'entrée de lot doivent utiliser `purpose=batch`.
- Utilisez `purpose=batch_output` pour vous concentrer sur les fichiers de sortie générés.
- `completion_window` est actuellement `24h`.
- L'ordre de sortie n'est pas garanti ; il faut toujours faire correspondre par `custom_id`.
- Le streaming n'est pas pris en charge à l'intérieur des éléments de lot.

## Exemple

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files?purpose=batch&limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Requête / Réponse

Utilisez le panneau OpenAPI interactif ci-dessus pour le schéma exact.

## Conseils opérationnels

- Utilisez `custom_id` pour la réconciliation idempotente en aval.
- Attendez-vous à ce que `output_file_id` et `error_file_id` ne soient disponibles qu'après que le travailleur finalise le lot.

## Filtres

- Pour les fichiers de lot et de référence d’image, `limit` va de 1 à 10000 (10000 par défaut), avec `after` pour la pagination. En mode Anthropic Files, il va de 1 à 1000 (20 par défaut) ; utilisez `after_id` ou `before_id`, mais pas les deux.
- `purpose` peut être `batch`, `batch_output`, `user_data` ou `vision`.
- `user_data` et `vision` renvoient les fichiers de référence d'image créés par TokenLab lorsqu'ils sont disponibles.

## Exemple de réponse

<ResponseExample>

## Champs importants

<ResponseField name="object" type="string">Type d’objet de la réponse.</ResponseField>
<ResponseField name="data" type="array">Liste ou payload retourné par cette réponse.</ResponseField>
