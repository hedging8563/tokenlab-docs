---
title: "Obtenir la facturation d'une clé API"
openapi: "GET /v1/management/api-keys/{keyId}/billing"
description: "Retourne les ventilations de facturation agrégées d'une clé API utilisateur."
---

## Aperçu

Cet endpoint retourne des agrégats de facturation basés sur la consommation pour la clé API sélectionnée, notamment le coût total, le nombre total de requêtes, l’usage par unité de facturation, les ventilations `by_model`, `by_logical_model`, `by_model_vendor` et `by_scene`, ainsi qu’une tendance quotidienne des coûts.

## Remarques

- Les champs monétaires prennent uniquement en charge l’USD. Les entrées `CNY` sont abandonnées et renvoient `400 currency_retired`.

- Les recharges, factures et autres écritures financières au niveau de l'organisation sont exclues.

## Exemple

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Champs importants

<ResponseField name="api_key" type="object">Résumé de la clé API utilisant les mêmes champs que les réponses de liste, de création et de mise à jour.</ResponseField>
<ResponseField name="summary" type="object">Totaux agrégés pour les filtres sélectionnés.</ResponseField>
<ResponseField name="breakdowns" type="object">Ventilations agrégées pour les filtres sélectionnés.</ResponseField>
<ResponseField name="summary.total_requests" type="number">Nombre total de requêtes.</ResponseField>
<ResponseField name="summary.total_cost" type="number">Coût total en USD renvoyé sous forme de nombre JSON pour l’affichage.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">Coût total exact en USD renvoyé sous forme de chaîne décimale.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">Nombre total de tokens de prompt.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">Nombre total de tokens de complétion.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">Nombre total de tokens.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">Quantité d’utilisation regroupée par unité d’utilisation.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">Ventilation par modèle public demandé.</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">Ventilation par modèle public logique.</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">Ventilation par fournisseur de modèle public.</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">Ventilation par scène de requête publique.</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">Évolution quotidienne des coûts.</ResponseField>
