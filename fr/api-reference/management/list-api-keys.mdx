---
title: "Lister les clés API"
openapi: "GET /v1/management/api-keys"
description: "Liste les clés API gérées par l'utilisateur pour le jeton de gestion actuel de l'organisation."
---

## Aperçu

Retourne les clés API utilisateur de l'organisation associée au jeton de gestion actuel.

## Remarques

- Les champs monétaires prennent uniquement en charge l’USD. Les entrées `CNY` sont abandonnées et renvoient `400 currency_retired`.

- Les clés gérées par le système sont exclues.

## Exemple

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Champs importants

<ResponseField name="object" type="string">Toujours `list`.</ResponseField>
<ResponseField name="data" type="array">Tableau d’objets de clé API.</ResponseField>
<ResponseField name="pagination" type="object">Métadonnées de pagination contenant `page`, `limit`, `total` et `totalPages`.</ResponseField>
<ResponseField name="data[].id" type="string">Identifiant de clé API utilisé dans les appels ultérieurs à l’API de gestion.</ResponseField>
<ResponseField name="data[].name" type="string">Nom d’affichage de la clé API.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">Préfixe de clé non secret pour l’affichage et l’assistance.</ResponseField>
<ResponseField name="data[].status" type="string">L’une des valeurs `active`, `inactive` ou `revoked`.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">Plafond de dépenses en USD renvoyé sous forme de nombre JSON pour l’affichage. `null` signifie aucune limite.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">Plafond de dépenses exact en USD renvoyé sous forme de chaîne décimale. `null` signifie aucune limite.</ResponseField>
<ResponseField name="data[].used_amount" type="number">Dépenses d’utilisation cumulées en USD renvoyées sous forme de nombre JSON pour l’affichage.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">Dépenses d’utilisation cumulées exactes en USD renvoyées sous forme de chaîne décimale.</ResponseField>
<ResponseField name="data[].models" type="string[]">Liste des modèles autorisés par clé. Un tableau vide signifie qu’aucune restriction de modèle supplémentaire ne s’applique au niveau de la clé.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">Horodatage ISO d’expiration de la clé, ou `null` si elle n’expire pas.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">Horodatage ISO de la dernière utilisation, ou `null` si elle n’a jamais été utilisée.</ResponseField>
<ResponseField name="data[].created_at" type="string">Horodatage ISO de création.</ResponseField>
