## Aperçu

Cet endpoint retourne les totaux de solde actuels de l’organisation associée au jeton de gestion. Il utilise la même référence actuelle de solde d’organisation que la facturation et le règlement.

## Remarques

- Les champs monétaires prennent uniquement en charge l’USD.

- Les champs monétaires sont renvoyés en USD. Utilisez `balance`, `total_recharge` et `total_used` pour l’affichage ; utilisez `balance_decimal`, `total_recharge_decimal` et `total_used_decimal` pour le rapprochement exact.

## Exemple

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Champs importants

<ResponseField name="object" type="string">Toujours `organization_balance`.</ResponseField>
<ResponseField name="organization_id" type="string">Organisation associée au token de gestion actuel.</ResponseField>
<ResponseField name="balance" type="number">Solde actuel de l’organisation en USD sous forme de JSON number pour l’affichage.</ResponseField>
<ResponseField name="balance_decimal" type="string">Solde actuel exact de l’organisation en USD sous forme de chaîne décimale pour le rapprochement.</ResponseField>

<ResponseField name="total_used_decimal" type="string">Dépenses d’usage cumulées exactes de l’organisation en USD sous forme de chaîne décimale pour le rapprochement.</ResponseField>
