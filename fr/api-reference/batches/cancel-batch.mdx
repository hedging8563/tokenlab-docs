---
title: "Annuler le lot"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "Annule un travail de lot en attente ou en cours."
---

Demandez l’annulation d’un lot en attente ou en cours. La réponse contient son état actuel : l’annulation peut être en cours ou déjà terminée. Un lot déjà terminé conserve son état final. Si l’état renvoyé n’est pas final, récupérez à nouveau le lot pour vérifier le résultat.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Identifiant pour les appels suivants et le support.</ResponseField>
<ResponseField name="status" type="string">État actuel du lot. Une demande d’annulation réussie ne renvoie pas toujours `cancelling`.</ResponseField>
