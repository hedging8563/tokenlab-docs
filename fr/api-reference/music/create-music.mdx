---
title: "Créer de la musique"
openapi: "/openapi/fr.json POST /v1/music/generations"
description: "Crée une tâche de génération de musique à l'aide de Suno"
---

Générez de la musique et des paroles à l'aide de l'IA. Il s'agit d'une API asynchrone. La réponse de création renvoie un identifiant de tâche et peut, lorsqu'il est disponible, inclure un `poll_url` à utiliser en priorité.

## Corps de la requête

<ParamField body="model" type="string" default="suno_music">
  Identifiant du modèle musical, par exemple `suno-music`. Pour les paroles seules, choisissez un modèle dont les opérations publiques actuelles incluent `lyrics`.
</ParamField>

<ParamField body="prompt" type="string">
  Description musicale ou texte de remplacement. Obligatoire pour musique, paroles, upload-cover, upload-extend et replace-section ; facultatif pour add-instrumental et la séparation de pistes.
</ParamField>

<ParamField body="title" type="string">
  Titre de la chanson générée.
</ParamField>

<ParamField body="tags" type="string">
  Tags de style (ex : "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  Styles à éviter. Obligatoire lorsque `audio_operation` vaut `add-instrumental`.
</ParamField>

<ParamField body="action" type="string">
  Valeur facultative `MUSIC` ou `LYRICS`. Choisissez un modèle compatible avec l’opération publique correspondante ; ce champ n’ajoute pas la génération de paroles à un modèle limité à la musique.
</ParamField>

<ParamField body="mv" type="string">
  Sélecteur de version Suno. Obligatoire pour la génération, upload-cover, upload-extend, add-instrumental et le remplacement depuis `audio_url`. À omettre pour les paroles, le remplacement depuis `task_id` + `audio_id` et la séparation de pistes. Valeurs acceptées : `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  Définissez sur `true` pour générer une sortie instrumentale sans voix.
</ParamField>

<ParamField body="audio_url" type="string">
  URL audio de référence ou téléversée accessible publiquement. Si `audio_operation` est omis, TokenLab utilise le flux upload-cover.
</ParamField>

<ParamField body="audio_operation" type="string">
  Opération audio : `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation` et `advanced-split` nécessitent `task_id` + `audio_id` ; `advanced-split` exige aussi `stem_name`. `upload-extend` exige `continue_at` supérieur à 0. `add-instrumental` exige `audio_url`, `title`, `tags` et `negative_tags`.

  `replace-section` nécessite `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s` et `full_lyrics`. Choisissez une seule source : `task_id` + `audio_id`, ou `audio_url` + `mv`. L’intervalle remplacé doit durer de 6 à 60 secondes.
</ParamField>

<ParamField body="task_id" type="string">
  Identifiant d’une tâche source appartenant à votre organisation, pour remplacer un audio généré ou séparer les pistes.
</ParamField>

<ParamField body="audio_id" type="string">
  Identifiant audio renvoyé dans le résultat de la tâche source. Obligatoire avec `task_id` pour remplacer un audio généré ou séparer les pistes.
</ParamField>

<ParamField body="infill_start_s" type="number">
  Début du remplacement en secondes, au moins 0. Obligatoire pour `replace-section`.
</ParamField>

<ParamField body="infill_end_s" type="number">
  Fin du remplacement en secondes. Obligatoire pour `replace-section`, de 6 à 60 secondes après `infill_start_s`.
</ParamField>

<ParamField body="full_lyrics" type="string">
  Paroles complètes de la chanson résultante. Obligatoire pour `replace-section`.
</ParamField>

<ParamField body="stem_name" type="string">
  Nom de la piste. Obligatoire pour `advanced-split`.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  ID d'un clip précédent à partir duquel continuer.
</ParamField>

<ParamField body="continue_at" type="number">
  Position de reprise en secondes. Obligatoire et supérieure à 0 pour `upload-extend`.
</ParamField>

<Note>
`prompt` accepte jusqu’à 5000 caractères ; `tags` et `negative_tags`, jusqu’à 1000 chacun. Les opérations et paramètres acceptés dépendent des détails actuels du modèle.
</Note>

## Réponse

<ResponseField name="id" type="string">
  ID de la tâche pour interroger le statut.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias du même identifiant de tâche asynchrone, lorsqu’il est renvoyé.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling prioritaire lorsqu'elle est disponible.
</ResponseField>

<ResponseField name="status" type="string">
  Statut de la tâche : `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  Horodatage Unix de création de la tâche, lorsqu’il est renvoyé.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
