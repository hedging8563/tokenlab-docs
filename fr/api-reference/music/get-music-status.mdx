---
title: "Obtenir le statut de la musique"
openapi: "/openapi/fr.json GET /v1/tasks/{id}"
description: "Récupère le statut et le résultat d'une tâche de génération de musique"
---

Interrogez cet endpoint pour vérifier le statut de votre tâche de génération de musique.

<Info>
Si la réponse de création contient `poll_url`, privilégiez cette URL exacte pour le polling. `id` et `task_id` doivent être traités comme le même identifiant de tâche asynchrone.


Une tâche publique expirée ou indisponible peut renvoyer `404 async_task_not_found`. Si son appartenance à la clé API actuelle ne peut pas être établie, la réponse est `403 task_not_owned`.
</Info>

## Paramètres de chemin

<ParamField path="id" type="string" required>
  L'ID de la tâche de génération de musique.
</ParamField>

## Réponse

<ResponseField name="id" type="string">
  ID de la tâche.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias du même identifiant de tâche asynchrone, lorsqu’il est renvoyé.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling à privilégier lorsque la réponse de création la fournit.
</ResponseField>

<ResponseField name="status" type="string">
  Statut de la tâche : `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Valeur de progression facultative. Renvoyée uniquement lorsqu’une progression réelle est disponible ; utilisez `status` pour déterminer la fin de la tâche.
</ResponseField>

Les champs dépendent de l’opération. La musique peut renvoyer `audio_url` et `audio_id`, les tâches de paroles seules `lyrics`, et la séparation plusieurs fichiers dans `data`. `video_url`, le titre, la progression et les autres métadonnées sont facultatifs. Vérifiez la fin avec `status` et lisez les champs réellement renvoyés.

<ResponseField name="audio_id" type="string">
  Identifiant audio facultatif à utiliser avec cet identifiant de tâche pour les opérations de suivi compatibles.
</ResponseField>

<ResponseField name="data" type="array">
  Tableau de sorties facultatif, notamment les pistes séparées avec `audio_url` ou `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  URL pour télécharger le fichier audio (une fois terminé).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL vers la version vidéo avec visualiseur (une fois terminé).
</ResponseField>

<ResponseField name="title" type="string">
  Titre de la chanson générée.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Paroles générées ou fournies.
</ResponseField>

<ResponseField name="error" type="string | object">
  Message d'erreur (en cas d'échec).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
