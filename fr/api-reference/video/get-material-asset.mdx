---
title: "Obtenir un actif matériel"
openapi: "/openapi/fr.json GET /v1/videos/assets/{assetId}"
description: "Récupère un actif matériel Seedance par son ID d'actif matériel TokenLab."
---

Récupérez un actif matériel et inspectez son état de traitement. L'actif ne peut être utilisé pour la génération de vidéo que lorsque `ready` est `true` et que `status` est `ACTIVE`.

Si la génération de vidéo renvoie `Seedance material asset not found or not accessible`, vérifiez que vous avez transmis cet `id` d'actif matériel, et non le `group_id` du matériel.

`project_name` isole les ressources au sein de l’organisation authentifiée. Sa valeur par défaut est `default` ; utilisez la même valeur, sensible à la casse, pour les groupes et ressources associés. Envoyez-la dans le corps JSON pour POST/PUT et dans les paramètres de requête pour GET/DELETE.

## Exemple de requête

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Exemple de réponse

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
