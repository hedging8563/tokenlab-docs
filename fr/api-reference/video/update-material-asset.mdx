---
title: "Mettre à jour un actif matériel"
openapi: "/openapi/fr.json PUT /v1/videos/assets/{assetId}"
description: "Met à jour un actif matériel Seedance appartenant à l'organisation actuelle."
---

Mettez à jour le nom ou les métadonnées de l'actif matériel. L'URL source et le type d'actif sont fixes après la création ; créez un nouvel actif lorsque le fichier source change.

`project_name` isole les ressources au sein de l’organisation authentifiée. Sa valeur par défaut est `default` ; utilisez la même valeur, sensible à la casse, pour les groupes et ressources associés. Envoyez-la dans le corps JSON pour POST/PUT et dans les paramètres de requête pour GET/DELETE.

## Exemple de requête

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"},"project_name":"default"}'
```

## Exemple de réponse

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view approved",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": {"approved_by": "creative-team"},
  "created_at": 1782998400000
}
```
