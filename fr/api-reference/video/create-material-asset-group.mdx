---
title: "Créer un groupe d'actifs matériels"
openapi: "POST /v1/videos/assets/groups"
description: "Crée un groupe de matériel pour avatar virtuel Seedance."
---

Créez un groupe de matériel avec `library_type: "aigc_avatar"`. Utilisez ce endpoint pour les avatars virtuels, les produits, les styles et autres références réutilisables qui ne nécessitent pas de vérification de personne réelle.

Les nouveaux groupes de matériel pour personnes réelles sont créés via la [Créer une session de validation visuelle](/fr/api-reference/video/create-visual-validation-session) et ne peuvent pas être créés directement avec ce endpoint.

`project_name` isole les ressources au sein de l’organisation authentifiée. Sa valeur par défaut est `default` ; utilisez la même valeur, sensible à la casse, pour les groupes et ressources associés. Envoyez-la dans le corps JSON pour POST/PUT et dans les paramètres de requête pour GET/DELETE.

## Exemple de requête

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots","project_name":"default"}'
```

## Exemple de réponse

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
