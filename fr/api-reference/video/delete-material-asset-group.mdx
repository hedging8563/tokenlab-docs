---
title: "Supprimer un groupe d'assets matériels"
openapi: "DELETE /v1/videos/assets/groups/{groupId}"
description: "Supprime un groupe de matériaux Seedance appartenant à l'organisation actuelle."
---

Supprime un groupe de matériaux ainsi que les assets matériels TokenLab qu'il contient. Cette action est irréversible.

Si la bibliothèque de matériaux TokenLab ne peut pas effectuer la suppression en raison de l'état d'autorisation actuel, TokenLab renvoie une erreur neutre de type `material-library`. Après la suppression, le groupe et ses assets ne peuvent plus être utilisés dans la génération de vidéos.

`project_name` isole les ressources au sein de l’organisation authentifiée. Sa valeur par défaut est `default` ; utilisez la même valeur, sensible à la casse, pour les groupes et ressources associés. Envoyez-la dans le corps JSON pour POST/PUT et dans les paramètres de requête pour GET/DELETE.

## Exemple de requête

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Exemple de réponse

```json
{
  "deleted": true,
  "id": "group-20260720123456-vrt01"
}
```
