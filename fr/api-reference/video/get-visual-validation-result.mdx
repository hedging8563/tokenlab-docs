---
title: "Obtenir le résultat de validation visuelle"
openapi: "/openapi/fr.json POST /api/v3"
description: "Obtient le groupe de ressources de personne réelle produit par la validation visuelle."
---

Interrogez cette Action après le parcours de validation visuelle H5. Un résultat réussi renvoie l’ID du groupe de ressources TokenLab de la personne vérifiée.

Utilisez l’organisation authentifiée, l’utilisateur et le `ProjectName` sensible à la casse qui ont créé la session.

## Point de terminaison et authentification

```text
POST https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

Envoyez le `BytedToken` renvoyé par [Créer une session de validation visuelle](/fr/api-reference/video/create-visual-validation-session). Si vous avez défini `ProjectName` à la création, envoyez ici la même valeur en respectant la casse ; sinon, omettez-la ou utilisez `default`.

Le résultat peut ne pas être prêt immédiatement après le callback du navigateur. Réessayez la même requête jusqu’au retour de `Result.GroupId` ou à l’expiration du `BytedToken` de 30 minutes. Une requête réussie répétée avec le même token renvoie le même `GroupId`.

Utilisez le `GroupId` renvoyé comme `group_id` lors de la création de ressources `liveness_face`.

## Exemple de requête

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"BytedToken":"ZXhhbXBsZS10b2tlbg","ProjectName":"default"}'
```

## Exemple de réponse

```json
{
  "ResponseMetadata": {
    "RequestId": "req_def456",
    "Action": "GetVisualValidateResult",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "GroupId": "group-20260720123456-real1"
  }
}
```

Les erreurs utilisent `ResponseMetadata.Error.Code` et `ResponseMetadata.Error.Message`. Une réponse réussie contient `ResponseMetadata` et `Result` ; elle n’utilise pas la structure de réponse des autres API TokenLab `/v1`.
