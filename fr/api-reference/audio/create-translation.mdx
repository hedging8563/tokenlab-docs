## Vue d'ensemble

Traduit l'audio dans n'importe quelle langue prise en charge en texte anglais. Contrairement à la transcription, cet endpoint renvoie toujours du texte en anglais, quelle que soit la langue d'entrée.

<Note>
  Cet endpoint traduit l’audio en anglais. N’envoyez pas `language` : ce paramètre n’est pas accepté pour la traduction audio et peut renvoyer `unsupported_parameter`. Pour traduire du texte, utilisez `POST /v1/translations` ; `recommended_for=translation` désigne cette API de texte.
</Note>

## Corps de la requête

La réponse est renvoyée après la traduction. Pour un audio long, prévoyez un délai HTTP d’au moins `120s`.

<ParamField body="file" type="file" required>
  Le fichier audio à traduire. Formats pris en charge : `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`. La taille maximale du fichier est de 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  Identifiant du modèle de traduction audio, par exemple `whisper-1`. Vérifiez dans ses détails actuels la prise en charge de `POST /v1/audio/translations`.
</ParamField>

<ParamField body="prompt" type="string">
  Un texte facultatif pour guider le style du modèle ou poursuivre un segment précédent. Doit être en anglais.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Format de sortie. Whisper accepte `json`, `text`, `srt`, `verbose_json` et `vtt`. Les autres modèles peuvent proposer un choix différent ; vérifiez leurs détails.
</ParamField>

<ParamField body="temperature" type="number">
  Température d’échantillonnage de 0 à 1, uniquement pour les modèles compatibles avec ce paramètre.
</ParamField>

## Réponse

Les champs suivants décrivent les réponses JSON de transcription ou de traduction. `text`, `srt` et `vtt` renvoient du texte ou des sous-titres bruts, pas un objet JSON. Les champs supplémentaires dépendent du modèle et du format.

<ResponseField name="text" type="string">
  Le texte traduit en anglais.
</ResponseField>

Pour le format `verbose_json`, la réponse inclut également :

<ResponseField name="language" type="string">
  Indication de langue fournie dans la réponse, lorsqu’elle est présente.
</ResponseField>

<ResponseField name="duration" type="number">
  La durée de l'audio d'entrée en secondes.
</ResponseField>

<ResponseField name="segments" type="array">
  Segments du texte traduit avec horodatages.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/translations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "file=@german_audio.mp3" \
  -F "model=whisper-1"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("german_audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.translations.create({
  model: 'whisper-1',
  file: fs.createReadStream('german_audio.mp3')
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/translations');

$file = new CURLFile('german_audio.mp3', 'audio/mpeg', 'german_audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Traduction vs Transcription

| Fonctionnalité | Traduction | Transcription |
|---------|-------------|---------------|
| Langue de sortie | Toujours l'anglais | Identique à l'entrée |
| Cas d'usage | Convertir un audio étranger en anglais | Préserver la langue d'origine |
| Paramètre de langue | Non applicable | Indice facultatif |
