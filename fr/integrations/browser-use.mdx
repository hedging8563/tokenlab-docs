## Aperçu

Browser Use peut appeler TokenLab via `ChatOpenAILike`, le wrapper de modèle de chat compatible avec OpenAI.

<Note>
**Type** : Framework d'agent d'automatisation de navigateur

**Chemin principal** : Chat Completions compatibles avec OpenAI

**Niveau de support** : Chemin compatible avec OpenAI pris en charge
</Note>

## Environnement

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Exemple

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## Notes sur les endpoints

Utilisez cette page pour les workflows Browser Use qui appellent des Chat Completions via un client compatible avec OpenAI. Si votre workflow nécessite des réponses natives TokenLab, des messages Anthropic ou des endpoints Gemini, utilisez un chemin client dans Browser Use qui utilise directement ce protocole.
