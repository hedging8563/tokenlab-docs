## Aperçu

Utilisez le plugin de fournisseur de modèles **OpenAI-API-compatible** pour connecter Dify à TokenLab. Réglez le type de modèle sur **LLM**, **Completion mode** sur **Chat** et **API Type** sur **Chat Completions API**. Ce guide utilise Chat Completions.


## Prérequis

- Compte TokenLab avec accès API
- Dify Cloud ou Dify auto-hébergé

## Étapes de configuration

### Étape 1 : Obtenir votre clé API

1. Connectez-vous au [Tableau de bord TokenLab](https://tokenlab.sh/dashboard)
2. Ouvrez [Clés API](https://tokenlab.sh/dashboard/api)
3. Créez ou copiez une clé API commençant par `sk-`

### Étape 2 : Configurer le fournisseur

<Steps>
  <Step title="Ouvrir les fournisseurs de modèles">
    Dans Dify, allez dans **Paramètres** → **Fournisseurs de modèles**
  </Step>
  <Step title="Sélectionner OpenAI-API-compatible">
    Ouvrez **OpenAI-API-compatible**. Si ce fournisseur est absent, installez son plugin depuis Dify Marketplace. Choisissez **Add model** pour saisir les paramètres TokenLab.
  </Step>
  <Step title="Saisir les paramètres TokenLab">
    Utilisez ces valeurs :

    | Champ | Valeur |
    |-------|-------|
    | Clé API | `sk-your-tokenlab-key` |
    | Model type | LLM |
    | Completion mode | Chat |
    | API Type | Chat Completions API |
    | API Base URL | `https://api.tokenlab.sh/v1` |
  </Step>
  <Step title="Ajouter des modèles">
    Ajoutez les modèles que vous souhaitez utiliser, par exemple :
    - `gpt-5.4`
    - `gpt-5.4-mini`
    - `claude-sonnet-5`
    - `claude-opus-4-8`
    - `gemini-3.5-flash`
    - `gemini-3.1-flash-lite`
    - `deepseek-v4-flash`
  </Step>
</Steps>

### Étape 3 : Tester la connexion

1. Sélectionnez un modèle que vous avez ajouté, comme `gpt-5.4-mini`.
2. Envoyez un prompt de test
3. Confirmez que Dify reçoit une réponse valide

## Embeddings pour les bases de connaissances

Pour le RAG et l'indexation de bases de connaissances, ajoutez un modèle d'embedding tel que :
- `text-embedding-3-small`
- `text-embedding-3-large`

Ensuite, définissez-le comme modèle d'embedding par défaut dans les paramètres de la base de connaissances ou de l'application concernée.

## Rôles de modèles recommandés

| Cas d'utilisation | Modèles suggérés |
|----------|------------------|
| Chat par défaut | `gpt-5.4-mini`, `gpt-5.4`, `claude-sonnet-5` |
| Raisonnement approfondi | `gpt-5.5`, `gpt-5.4`, `claude-opus-4-8`, `deepseek-v4-pro` |
| Rapide/économique | `gpt-5.4-mini`, `gemini-3.5-flash`, `deepseek-v4-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## Bonnes pratiques

<AccordionGroup>
  <Accordion title="Le plugin OpenAI comme alternative">
    Le plugin distinct **OpenAI** peut être utilisé pour les modèles pris en charge par son catalogue. Réglez son URL de base personnalisée sur `https://api.tokenlab.sh/v1` et **API Protocol** sur **Chat Completions** ; la valeur par défaut peut être Responses. Ce n’est pas un ancien nom d’OpenAI-API-compatible et il n’accepte pas tous les ID de modèle personnalisés.
  </Accordion>

  <Accordion title="Utilisez des modèles moins coûteux pour l'itération">
    Utilisez `gpt-5.4-mini`, `gemini-3.5-flash` ou `deepseek-v4-flash` pendant vos itérations, puis basculez les flux de travail plus lourds vers des modèles plus puissants uniquement lorsque nécessaire.
  </Accordion>

  <Accordion title="Cette configuration utilise Chat Completions">
    Conservez **Completion mode = Chat** et **API Type = Chat Completions API** pour cette configuration. Responses est une option d’API distincte ; ce guide ne la configure pas et ne configure pas de connexions WebSocket.
  </Accordion>
</AccordionGroup>

## Dépannage

<AccordionGroup>
  <Accordion title="Erreur de connexion">
    - Vérifiez que l'URL de base est exactement `https://api.tokenlab.sh/v1`
    - Supprimez les barres obliques (slashes) finales si Dify les duplique
    - Confirmez que le serveur Dify peut atteindre TokenLab via l'internet public
  </Accordion>

  <Accordion title="401 Non autorisé">
    - Vérifiez à nouveau la clé API
    - Confirmez que la clé est active dans le tableau de bord TokenLab
    - Assurez-vous que la valeur collée dans Dify ne contient pas d'espaces ou de sauts de ligne supplémentaires
  </Accordion>

  <Accordion title="Modèle introuvable">
    - Vérifiez exactement le nom du modèle
    - Ajoutez à nouveau l'entrée du modèle si l'interface du fournisseur a mis en cache une ancienne valeur
    - Vérifiez la disponibilité actuelle du modèle dans la documentation ou le tableau de bord TokenLab
  </Accordion>
</AccordionGroup>
