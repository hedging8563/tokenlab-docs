## Aperçu

<Note>
**Type** : agent de code et de tâches pour ordinateur

**Chemin principal** : Chat Completions compatible OpenAI

**Support** : chemin officiel de modèle personnalisé
</Note>

[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) propose un éditeur visuel pour les modèles compatibles OpenAI. Il n'est pas nécessaire de modifier manuellement le fichier local.

## Configurer TokenLab

Ouvrez **Settings → Model**, ajoutez un modèle et choisissez **Custom**.

| Champ | Valeur |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | Votre clé API TokenLab |
| Model name | `kimi-k3` |
| Custom Protocol | **Désactivé** |

<Warning>
Laissez Custom Protocol désactivé. Le mode standard valide la Base URL et ajoute `/chat/completions`. S'il est activé avec seulement `/v1`, la requête utilise un mauvais chemin.
</Warning>

Dans les réglages avancés, activez les appels d'outils, les images et le raisonnement. Désactivez le mode raisonnement seul, laissez l'effort sur Auto, puis utilisez `1048576` en entrée et `131072` en sortie.

Après enregistrement, choisissez `kimi-k3` et testez une inspection de dossier en lecture seule. Masquez les clés et endpoints privés avant de partager une capture.
