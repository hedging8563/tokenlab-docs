## Confier la configuration à mon agent

Copiez cette tâche dans un agent déjà opérationnel sur votre ordinateur :

```text
Lis ce guide et aide-moi à connecter WorkBuddy à TokenLab :
https://docs.tokenlab.sh/fr/integrations/workbuddy
Vérifie d’abord ma version installée et la configuration active.
Préserve les comptes, les fournisseurs, les permissions et les autres réglages existants.
Sauvegarde les fichiers locaux et présente les modifications proposées.
Laisse-moi saisir localement les clés API nécessaires ; ne les demande, ne les affiche et ne les colle jamais dans le chat.
Vérifie d’abord que la configuration se charge correctement.
Explique séparément le coût de tout test utilisant une requête payante avant de l’exécuter.
```

## Aperçu

[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) propose un éditeur visuel pour les modèles compatibles OpenAI. Il n'est pas nécessaire de modifier manuellement le fichier local.

## Configurer TokenLab

Ouvrez **Settings → Model**, ajoutez un modèle et choisissez **Custom**.

| Champ | Valeur |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | Votre clé API TokenLab |
| Model name | `kimi-k3` |
| Custom Protocol | **Désactivé** |

<Warning>
Laissez Custom Protocol désactivé. Le mode standard valide la Base URL et ajoute `/chat/completions`. S'il est activé avec seulement `/v1`, la requête utilise un mauvais chemin.
</Warning>

Réglez outils, images, raisonnement et limites selon les détails TokenLab actuels du modèle choisi. Ne les activez pas systématiquement et ne copiez pas des limites 1M/128K d’un autre modèle. Utilisez l’identifiant affiché.

Après enregistrement, choisissez `kimi-k3` et testez une inspection de dossier en lecture seule. Masquez les clés et endpoints privés avant de partager une capture.

Enregistrer et sélectionner confirme uniquement le réglage local. Les tâches texte ou outils utilisent le solde TokenLab ; vérifiez la réponse et son [enregistrement](https://tokenlab.sh/dashboard/runs?section=requests). Pour annuler, sélectionnez l’ancien modèle et retirez seulement l’entrée TokenLab ajoutée.

L’application officielle existe pour macOS et Windows. Utilisez [l’éditeur officiel](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model). Ce guide ne suppose ni version Linux ni format de fichier directement modifiable.

Les [outils API MCP](/fr/integrations/tokenlab-mcp-server) et [instructions Skill](/fr/integrations/coding-agent-skill) s’installent séparément et ne changent pas le modèle principal.
