## Aperçu

Helicone peut agir comme proxy et observer les requêtes compatibles avec OpenAI de TokenLab en les acheminant via Helicone Gateway et en ciblant TokenLab.

<Note>
**Type** : Passerelle d'observabilité (Observability Gateway)

**Chemin principal** : Complétions de chat compatibles avec OpenAI via Helicone Gateway

**Niveau de support** : Chemin d'observabilité pris en charge
</Note>

## Environnement

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## Portée

Cette configuration est destinée au trafic `/v1` compatible avec OpenAI. TokenLab expose également des réponses natives, des messages Anthropic et des endpoints compatibles avec Gemini ; utilisez les routes directes de TokenLab pour ces formats natifs, sauf si votre proxy d'observabilité les prend explicitement en charge.
