## Aperçu

<Note>
**Type** : agent de code en CLI

**Chemin principal** : Chat Completions compatible OpenAI

**Support** : chemin BYOK officiel
</Note>

[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models) peut utiliser tout endpoint compatible avec OpenAI Chat Completions.

## Installation et configuration

```bash
npm install -g @github/copilot
copilot --version
```

L'installation npm nécessite Node.js 22 ou une version ultérieure. GitHub exige actuellement un abonnement Copilot actif ; les comptes gérés par une organisation nécessitent aussi l'activation de la politique Copilot CLI.

```bash
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.tokenlab.sh/v1"
export COPILOT_PROVIDER_API_KEY="sk-your-tokenlab-key"
export COPILOT_MODEL="kimi-k3"

copilot
```

Le modèle doit prendre en charge le streaming et les appels d'outils. `kimi-k3` prend en charge les outils et dépasse les 128K de contexte recommandés par GitHub.

Commencez par une tâche en lecture seule qui ne modifie aucun fichier. Si le modèle est introuvable, utilisez l'ID logique du [catalogue TokenLab actuel](https://tokenlab.sh/fr/models), sans préfixe de fournisseur.

<Warning>
Ne stockez pas de clé API dans un fichier suivi par Git. Faites tourner toute clé visible dans l'historique du terminal, une capture ou des logs.
</Warning>
