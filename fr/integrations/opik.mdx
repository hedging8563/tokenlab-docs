## Aperçu

Opik peut journaliser les appels TokenLab en encapsulant un client OpenAI qui pointe vers le point de terminaison compatible OpenAI de TokenLab.

<Note>
**Type** : Observabilité

**Chemin principal** : Wrapper de traçage du SDK OpenAI

**Niveau de support** : Chemin de traçage compatible OpenAI pris en charge
</Note>

## Installation

```bash
pip install opik openai
```

## Environnement

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export OPIK_PROJECT_NAME="tokenlab-integration-demo"
```

## Encapsuler le client OpenAI

```python
import os

from openai import OpenAI
from opik.integrations.openai import track_openai

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

openai_client = track_openai(client)
```

## Journaliser une complétion de chat

```python
completion = openai_client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[
        {"role": "user", "content": "Summarize why LLM observability matters."}
    ],
)

print(completion.choices[0].message.content)
```

## Remarques sur les points de terminaison

Cette configuration trace le chemin du SDK compatible OpenAI. Si vous utilisez des points de terminaison natifs de TokenLab en dehors du SDK OpenAI, instrumentez ce client ou ce flux de travail séparément.
