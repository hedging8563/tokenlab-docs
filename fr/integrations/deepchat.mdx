## Aperçu

DeepChat fonctionne avec TokenLab via une configuration de fournisseur standard compatible avec OpenAI.

<Note>
**Type** : Application de chat

**Chemin principal** : Complétions de chat compatibles OpenAI

**Niveau de support** : Chemin pris en charge
</Note>

## Configurer DeepChat

1. Ouvrez **Settings** -> **Model Provider**
2. Ajoutez ou modifiez un fournisseur compatible OpenAI
3. Saisissez :
   - **Provider name** : TokenLab
   - **Base URL** : `https://api.tokenlab.sh/v1`
   - **API Key** : `sk-your-tokenlab-key`
4. Ajoutez un modèle tel que `gpt-5.4-mini`
5. Enregistrez et testez une discussion.

## Choix de modèles

Commencez avec `gpt-5.4-mini` pour une valeur par défaut simple. Utilisez `claude-sonnet-5`, `gpt-5.4` ou `deepseek-v4-pro` lorsque la conversation nécessite un raisonnement plus poussé.

## Dépannage

- Utilisez l'URL de base, et non le chemin complet `/chat/completions`, sauf si DeepChat demande explicitement une URL de point de terminaison complète.
- Supprimez les espaces en trop de la clé API.
- Si un modèle n'est pas listé, ajoutez manuellement l'identifiant exact du modèle TokenLab.
