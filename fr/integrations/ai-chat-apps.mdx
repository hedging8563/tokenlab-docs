## Aperçu

La plupart des applications de chat IA générales se connectent à TokenLab via le chemin de chat standard compatible avec OpenAI.

En pratique, cela signifie :
- utilisez `https://api.tokenlab.sh/v1` comme URL de base, sauf si l'application demande explicitement une URL de point de terminaison complète
- utilisez votre clé API TokenLab comme clé API de style OpenAI
- choisissez les modèles que l'application peut utiliser dans un flux de travail de chat standard

<Note>
Les paramètres propres à chaque application précisent l’API lorsqu’un choix est nécessaire. Certaines applications choisissent Responses selon le modèle. Utilisez un modèle compatible avec l’API de votre application ; les outils de programmation ont des guides d’intégration séparés.
</Note>

## Valeurs de connexion par défaut

| Champ | Valeur |
|-------|-------|
| URL de base | `https://api.tokenlab.sh/v1` |
| Clé API | `sk-your-tokenlab-key` |
| Type d'API | Compatible OpenAI |

Si une application demande une **URL de point de terminaison complète** au lieu d'une URL de base, utilisez :
- Chat Completions : `https://api.tokenlab.sh/v1/chat/completions`

## Exemples de configurations d'applications

    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1

    1. Ouvrez **Settings** → **AI Providers**
    2. Sélectionnez **OpenAI**
    3. Entrez votre clé API TokenLab

## Conseils

<AccordionGroup>
  <Accordion title="Privilégiez l'URL de base lorsque l'application le permet">
    La plupart des applications sont plus faciles à configurer et moins fragiles lorsque vous fournissez `https://api.tokenlab.sh/v1` comme URL de base au lieu d'une URL de point de terminaison complète.
  </Accordion>

  <Accordion title="Utilisez d'abord des modèles plus petits">
    Commencez avec `gpt-5.4-mini` ou `deepseek-v4-flash` pour le chat quotidien, puis passez aux tâches de raisonnement plus lourdes avec `gpt-5.4` ou `claude-opus-4-8`.
  </Accordion>

  <Accordion title="Gardez les outils de codage séparés">
    Les applications de chat générales et les agents de codage nécessitent souvent un comportement de point de terminaison différent. Gardez les outils de type Codex/Cursor sur leurs pages d'intégration dédiées.
  </Accordion>
</AccordionGroup>

## Dépannage

<AccordionGroup>
  <Accordion title="Erreur de connexion">
    - Vérifiez que l'URL de base est exactement `https://api.tokenlab.sh/v1`
    - Supprimez les barres obliques finales si l'application ajoute automatiquement des chemins
    - Si l'application demande une URL de point de terminaison complète, utilisez `https://api.tokenlab.sh/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Non autorisé">
    - Vérifiez à nouveau votre clé API
    - Confirmez que la clé est active dans le tableau de bord TokenLab
    - Assurez-vous qu'il n'y a pas d'espaces ou de sauts de ligne supplémentaires
  </Accordion>

  <Accordion title="Modèle non disponible">
    - Vérifiez exactement le nom du modèle
    - Essayez une valeur par défaut largement prise en charge comme `gpt-5.4-mini`, `deepseek-v4-flash` ou `claude-sonnet-5`
    - Vérifiez la disponibilité actuelle dans la documentation ou le tableau de bord TokenLab
  </Accordion>
</AccordionGroup>
