## Aperçu

<Note>
**Type** : agent de code pour IDE

**Chemin principal** : Chat Completions compatible OpenAI

**Support** : chemin fournisseur officiel
</Note>

[Cline](https://docs.cline.bot/provider-config/openai-compatible) accepte les fournisseurs compatibles OpenAI dans les paramètres de l'IDE.

## Configurer TokenLab

1. Installez **Cline** depuis la boutique d'extensions, puis ouvrez son panneau.
2. Cliquez sur l'engrenage et choisissez **OpenAI Compatible** dans **API Provider**.
3. Renseignez :

| Champ | Valeur |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | Votre clé API TokenLab |
| Model ID | `kimi-k3` |

4. Cliquez sur **Verify**.

Dans les réglages avancés facultatifs, utilisez une limite d'entrée de `1048576`, une sortie maximale de `131072`, et activez les images ainsi que les outils / Computer Use.

Après validation, commencez par une tâche en lecture seule. En cas de 404, vérifiez que la Base URL se termine par `/v1` et ne contient pas `/chat/completions`. L'ID est `kimi-k3`, et non `kimi/kimi-k3`.
