## Aperçu

VoltAgent accepte directement les modèles de langage du SDK AI. Configurez un fournisseur SDK AI compatible avec OpenAI en utilisant l'URL de base `/v1` de TokenLab et transmettez le modèle sélectionné à votre agent.

<Note>
**Type** : Framework d'agent TypeScript

**Chemin principal** : Chat Completions compatibles OpenAI via le SDK AI

**Niveau de support** : Chemin compatible OpenAI pris en charge
</Note>

## Environnement

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Fournisseur SDK AI direct

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab("claude-sonnet-5"),
});
```

## Chemin du routeur de modèle

Si votre instantané de registre VoltAgent inclut une entrée de fournisseur TokenLab provenant de `models.dev`, configurez :

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

Utilisez ensuite la chaîne de modèle du registre, par exemple `tokenlab/claude-sonnet-5`.

## Remarques sur les endpoints

Le chemin direct du SDK AI est la configuration la plus explicite. Utilisez les réponses natives de TokenLab, les messages Anthropic ou les endpoints Gemini uniquement lorsque votre fournisseur/client SDK AI sélectionné est configuré pour ce protocole.
