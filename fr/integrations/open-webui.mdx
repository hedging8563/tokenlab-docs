## Aperçu

Open WebUI prend en charge les connexions API personnalisées compatibles avec OpenAI. Ajoutez TokenLab en tant que point de terminaison distant compatible OpenAI et actualisez la liste des modèles.

<Note>
**Type** : Application de chat Web

**Chemin principal** : Complétions de chat compatibles OpenAI

**Niveau de prise en charge** : Chemin d'application de chat pris en charge
</Note>

## Connexion administrateur

1. Ouvrez **Admin Panel** -> **Settings** -> **Connections**.
2. Dans la zone de connexion API OpenAI, ajoutez une connexion.
3. Définissez l'URL de base sur `https://api.tokenlab.sh/v1`.
4. Définissez la clé API sur votre clé TokenLab.
5. Enregistrez la connexion et actualisez les modèles.

## Valeurs

| Champ | Valeur |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Modèle exemple | `gpt-5.4-mini` |

## Modèles recommandés

- `gpt-5.4-mini` pour le chat général
- `claude-sonnet-5` pour l'écriture et le raisonnement
- `deepseek-v4-pro` pour le chat axé sur le code
- `gemini-3.5-flash` pour des flux de travail multimodaux rapides

Si la découverte de modèles est désactivée ou mise en cache dans votre déploiement, ajoutez les ID de modèle manuellement dans les paramètres de modèle d'Open WebUI.
