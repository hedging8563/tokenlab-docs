## Aperçu

Graphiti prend en charge les endpoints `/v1` compatibles avec OpenAI via `OpenAIGenericClient`. Pointez ce client vers TokenLab et choisissez un modèle TokenLab.

<Note>
**Type** : Framework de mémoire de graphe de connaissances

**Chemin principal** : Chat Completions compatibles avec OpenAI

**Niveau de support** : Chemin compatible avec OpenAI pris en charge
</Note>

## Environnement

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Client LLM

```python
import os

from graphiti_core.llm_client.config import LLMConfig
from graphiti_core.llm_client.openai_generic_client import OpenAIGenericClient

llm_config = LLMConfig(
    api_key=os.environ["TOKENLAB_API_KEY"],
    model="claude-sonnet-5",
    small_model="gpt-5.4-mini",
    base_url="https://api.tokenlab.sh/v1",
)

llm_client = OpenAIGenericClient(config=llm_config)
```

Passez `llm_client` dans votre instance `Graphiti(...)` aux côtés de votre base de données de graphes et de la configuration de votre embedder.

## Remarques sur les endpoints

Le chemin compatible avec OpenAI de Graphiti est orienté vers les chat-completions. Utilisez des modèles qui retournent de manière fiable du JSON structuré pour les tâches d'extraction et de déduplication.
