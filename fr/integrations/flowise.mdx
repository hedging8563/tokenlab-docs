## Aperçu

Flowise peut appeler TokenLab via un nœud de chat TokenLab lorsqu'il est disponible, ou via un nœud de modèle de chat compatible OpenAI pointant vers TokenLab.

<Note>
**Type** : Constructeur de workflow

**Chemin principal** : Complétions de chat compatibles OpenAI

**Niveau de support** : Supporté avec des limites de périmètre
</Note>

## Nœud TokenLab

Si votre build Flowise inclut un nœud de modèle de chat **TokenLab** :

1. Ajoutez **Chat Models** -> **TokenLab**
2. Créez une accréditation API TokenLab
3. Définissez **Model Name** sur `gpt-5.4-mini`
4. Connectez-le à votre chaîne, agent ou workflow
5. Exécutez un prompt de test.

## Alternative compatible OpenAI

Si le nœud TokenLab n'est pas encore disponible, utilisez un nœud de modèle de chat compatible OpenAI avec :

| Champ | Valeur |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Modèles recommandés

- `gpt-5.4-mini` pour la plupart des tests de workflow
- `claude-sonnet-5` pour une rédaction et un raisonnement plus poussés
- `gemini-3.5-flash` pour des workflows rapides et adaptés au multimodal
- `deepseek-v4-flash` pour des itérations rapides de code ou de raisonnement
