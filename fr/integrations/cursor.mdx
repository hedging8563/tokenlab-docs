## Périmètre

Ce guide concerne **l’éditeur Cursor pour ordinateur** sous macOS, Windows et Linux. Cursor limite officiellement OpenAI BYOK aux modèles de chat standards sans raisonnement ; la complétion Tab conserve les modèles Cursor. Modifier l’OpenAI Base URL ne rend pas tous les modèles TokenLab ni toutes les fonctions Cursor compatibles. Consultez les [limites officielles](https://cursor.com/help/models-and-usage/api-keys).

Pour les outils d’image, de vidéo ou d’autres API, gardez votre fournisseur de chat et ajoutez [MCP](/fr/integrations/tokenlab-mcp-server). Un [Skill](/fr/integrations/coding-agent-skill) fournit des instructions sans changer le modèle principal.

## Tâche à confier à votre agent

```text
Lis https://docs.tokenlab.sh/fr/integrations/cursor et vérifie ma version installée et mon système d’exploitation.
Confirme si je veux TokenLab comme modèle principal, des outils MCP ou un Skill API.
Préserve les comptes, la configuration des fournisseurs et les permissions ; explique comment restaurer les réglages modifiés.
Ne demande pas de clé API dans le chat. Je la saisirai localement et effectuerai les étapes nécessaires dans l’interface.
Explique le coût d’une petite requête de vérification. Aide à l’exécuter et à retrouver son enregistrement TokenLab seulement après mon choix explicite de ce test.
```

## Ouvrir les bons réglages

1. Installez ou mettez à jour l’éditeur depuis [Cursor Downloads](https://cursor.com/downloads). Ce guide ne configure ni le CLI ni les Cloud Agents.
2. Ouvrez **Cursor Settings** depuis la palette de commandes ou avec `Cmd/Ctrl + Shift + J`. `Cmd/Ctrl + ,` ouvre les réglages généraux de l’éditeur.
3. Dans **Models**, notez la configuration OpenAI existante pour pouvoir la restaurer. Préservez les autres fournisseurs.
4. Saisissez localement votre clé TokenLab dans **OpenAI API Key**, puis enregistrez. Ne la collez pas dans le chat et ne la commitez pas.
5. Activez **Override OpenAI Base URL** et saisissez :

```text
https://api.tokenlab.sh/v1
```

Les requêtes BYOK passent encore par les serveurs de Cursor pour assembler le prompt. L’éditeur ne se connecte pas directement à TokenLab.

## Choisir un modèle

Copiez l’ID exact depuis le [catalogue TokenLab actuel](https://tokenlab.sh/fr/models) et vérifiez sa prise en charge par OpenAI BYOK dans Cursor. La catégorie chat de TokenLab ne prouve pas cette compatibilité.

Pour un premier test texte, `gpt-4.1-mini` est un exemple sans raisonnement, s’il figure toujours au catalogue. Activez l’entrée existante dans **Models**, ou utilisez **Add model** si elle manque, puis sélectionnez-la dans le chat. Ne dupliquez pas un modèle intégré avec une autre orthographe ; les entrées Claude ou Gemini ne suivent pas automatiquement l’override OpenAI. Voir les [précisions de Cursor](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488).

## Vérifier une petite requête

Créez un nouveau chat avec le modèle choisi et envoyez :

```text
Réponds uniquement par TOKENLAB_CONNECTION_OK. N’utilise aucun outil et ne modifie aucun fichier.
```

Cette requête est facturée. Vérifiez la réponse ainsi que le modèle, l’heure et le statut dans les [requêtes TokenLab](https://tokenlab.sh/dashboard/runs?section=requests). Un modèle visible ou une réponse sans enregistrement correspondant ne confirme pas ce chemin.

## En cas de problème

- **Modèle absent ou refusé :** vérifiez l’ID et les limites BYOK ; utilisez l’entrée intégrée si elle existe. Redémarrer ne corrige pas une incompatibilité.
- **Erreur d’authentification :** vérifiez la clé TokenLab dans le champ OpenAI et la Base URL. Un solde ou quota insuffisant est distinct d’une clé invalide.
- **Aucune requête TokenLab :** vérifiez le modèle sélectionné, l’override et l’erreur Cursor. La complétion Tab ne teste pas cette connexion.
- **Un autre fournisseur ne fonctionne plus :** restaurez la configuration OpenAI précédente ou désactivez l’override, puis ouvrez un nouveau chat.

## Ajouter MCP et Skills séparément

[MCP](/fr/integrations/tokenlab-mcp-server) ajoute des outils via les réglages MCP de Cursor ou `.cursor/mcp.json`. Vérifiez d’abord leur découverte, puis lancez seulement les générations facturées voulues. MCP ne remplace pas le modèle principal.

Les [Skills](/fr/integrations/coding-agent-skill) apportent des instructions API. Placez le dossier complet, avec `SKILL.md` et ses références, dans `.cursor/skills/tokenlab-api-integration/`, puis vérifiez **Customize → Skills**. Un Skill ne fournit ni clé ni serveur MCP. Consultez les guides officiels [MCP](https://cursor.com/docs/mcp) et [Skills](https://cursor.com/docs/skills) pour votre version.
