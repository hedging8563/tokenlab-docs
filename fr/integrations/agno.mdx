## Aperçu

Agno peut utiliser TokenLab en tant que fournisseur de modèles compatible avec OpenAI pour les agents et les flux de travail.

<Note>
**Type** : Framework d'agent

**Chemin principal** : Complétions de chat compatibles avec OpenAI

**Niveau de support** : Chemin pris en charge
</Note>

## Environnement

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Wrapper de modèle TokenLab

Si votre version d'Agno inclut le wrapper de modèle TokenLab :

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

Certaines versions d'Agno prennent également en charge les chaînes de caractères pour les modèles :

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## Alternative compatible avec OpenAI

Si votre version n'inclut pas encore TokenLab, utilisez le chemin de modèle compatible avec OpenAI d'Agno avec :

- URL de base : `https://api.tokenlab.sh/v1`
- Clé API : `TOKENLAB_API_KEY`
- Modèle : `gpt-5.4-mini`

## Suggestions de modèles

Utilisez `gpt-5.4-mini` pour les agents par défaut, `gpt-5.4` ou `claude-sonnet-5` pour un raisonnement plus approfondi, et `deepseek-v4-flash` pour des boucles plus rapides.
