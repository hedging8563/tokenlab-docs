## Aperçu

Cherry Studio peut utiliser TokenLab via un fournisseur personnalisé compatible OpenAI. Si votre version de Cherry Studio inclut TokenLab dans le registre des fournisseurs, sélectionnez TokenLab directement.

<Note>
**Type** : Application de chat

**Chemin principal** : Complétions de chat compatibles OpenAI

**Chemins natifs** : Responses, Anthropic Messages, points de terminaison compatibles Gemini lorsqu'ils sont exposés par le client
</Note>

## Configurer en tant que fournisseur personnalisé

1. Ouvrez **Settings** -> **Model Provider**
2. Ajoutez un fournisseur compatible OpenAI
3. Entrez :
   - **Name** : TokenLab
   - **API Base URL** : `https://api.tokenlab.sh/v1`
   - **API Key** : `sk-your-tokenlab-key`
4. Ajoutez un modèle tel que `gpt-5.4-mini`
5. Enregistrez et testez le fournisseur.

## Chemin du registre des fournisseurs

Lorsque TokenLab apparaît comme fournisseur intégré dans Cherry Studio, privilégiez cette option. Il peut transporter des métadonnées de point de terminaison pour :

- Les complétions de chat compatibles OpenAI
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## Bons modèles de démarrage

Utilisez `gpt-5.4-mini` comme modèle par défaut, puis ajoutez `claude-sonnet-5`, `gemini-3.5-flash` et `deepseek-v4-flash` pour une couverture plus large.
