## Vue d’ensemble

[Claude Code](https://code.claude.com/docs/en/setup) est l’outil CLI officiel d’Anthropic pour le développement assisté par IA. Vous pouvez le configurer pour utiliser TokenLab comme fournisseur d’API.

## Installation

Anthropic recommande désormais l’installateur natif. L’installation via npm existe toujours pour des raisons de compatibilité, mais elle est dépréciée en amont.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Si vous avez spécifiquement besoin du package npm, utilisez :

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
N’utilisez pas `sudo npm install -g` pour Claude Code.
</Warning>

## Configuration

Définissez `TOKENLAB_API_KEY` avec les étapes du [démarrage rapide](/fr/quickstart) pour macOS, Linux, WSL ou Windows PowerShell, sans placer la clé dans l’historique. Lancez Claude Code depuis ce terminal. Pour un usage permanent, utilisez un gestionnaire local de secrets plutôt qu’une clé en clair dans le profil du shell.

Ces variables s’appliquent uniquement à ce lancement ; le compte, le modèle par défaut et les permissions enregistrés sont conservés. Lancez normalement sans ces variables pour retrouver vos réglages. Ne les enregistrez pas dans le profil du shell.

Ce lancement utilise Claude Code **2.1.263** et l’authentification Bearer via `ANTHROPIC_AUTH_TOKEN`. La Base URL reste sans `/v1`. Les valeurs `env` enregistrées, assistants d’identifiants, options cloud et politiques gérées peuvent influencer l’authentification : vérifiez-les avant le lancement. En cas de conflit, utilisez l’assistant ci-dessous sans supprimer les comptes ni affaiblir les règles. Vérifiez modèle et permissions avec `/status`.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Facultatif : l’[assistant de configuration réversible pour Claude Code](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md) permet de prévisualiser, appliquer et restaurer le fichier original avec Python 3.11+. Le plugin TokenLab Skills **0.1.2** contient ces scripts ; un Skill autonome convient aussi après sa mise à jour vers une version qui les inclut. Pour un plugin ou un Skill autonome déjà installé, suivez les [instructions de mise à jour du README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) et vérifiez la présence du script. La configuration manuelle de cette page reste utilisable sans cet assistant.

Enregistrer les réglages ou lister les modèles ne valide ni la clé ni un appel terminé. Un prompt utilise le solde TokenLab. Vérifiez la réponse et son [enregistrement correspondant](https://tokenlab.sh/dashboard/runs?section=requests) avant de tester les outils ; les requêtes auxiliaires peuvent aussi être facturées.

## Utilisation

Après la configuration, utilisez Claude Code normalement :

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Vérifiez l’installation si nécessaire :

```bash
claude --version
claude doctor
```

## Modèles disponibles

TokenLab prend en charge tous les modèles Claude :

| Modèle | Description |
|-------|-------------|
| `claude-opus-4-6` | Le plus performant, raisonnement complexe |
| `claude-sonnet-4-6` | Performances équilibrées, excellent pour le code |
| `claude-haiku-4-5` | Le plus rapide, rentable |

## Sélection du modèle

Spécifiez un modèle avec l’option `--model` :

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Résolution des problèmes

<AccordionGroup>
  <Accordion title="Erreurs de connexion">
    Vérifiez que l’URL de base est exactement `https://api.tokenlab.sh` (sans suffixe `/v1` pour les requêtes de style Anthropic).
  </Accordion>

  <Accordion title="Clé API invalide">
    Assurez-vous que votre clé API TokenLab commence par `sk-` et dispose d’un solde suffisant.
  </Accordion>


  <Accordion title="Modèle introuvable">
    Vérifiez que le nom du modèle est correct. Utilisez le format `claude-sonnet-4-6`.
  </Accordion>
</AccordionGroup>
