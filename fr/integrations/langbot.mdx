## Aperçu

LangBot peut appeler TokenLab via un demandeur LLM compatible avec OpenAI.

<Note>
**Type** : Plateforme de bot

**Chemin principal** : Complétions de chat compatibles avec OpenAI

**Niveau de support** : Supporté avec des limites de portée
</Note>

## Demandeur TokenLab

Si votre build LangBot inclut un demandeur **TokenLab** :

1. Ouvrez les paramètres du fournisseur de modèle de LangBot.
2. Ajoutez un fournisseur avec le demandeur **TokenLab**.
3. Définissez la clé API sur votre clé TokenLab.
4. Sélectionnez ou créez un modèle tel que `gpt-5.4-mini`.
5. Attachez le modèle au pipeline ou au bot qui doit l'utiliser.

## Solution de secours compatible avec OpenAI

Si TokenLab n'est pas encore listé, utilisez le demandeur compatible avec OpenAI :

| Champ | Valeur |
|-------|-------|
| Requester | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## Modèles recommandés

- `gpt-5.4-mini` pour la plupart des interactions de bot
- `claude-sonnet-5` pour l'écriture longue et le raisonnement
- `deepseek-v4-flash` pour le codage rapide et les boucles de raisonnement
- `gemini-3.5-flash` pour les workflows généraux rapides
