## Confier la configuration à mon agent

Copiez cette tâche dans un agent déjà opérationnel sur votre ordinateur :

```text
Lis ce guide et aide-moi à connecter Pi à TokenLab :
https://docs.tokenlab.sh/fr/integrations/pi-coding-agent
Vérifie d’abord ma version installée et la configuration active.
Préserve les comptes, les fournisseurs, les permissions et les autres réglages existants.
Sauvegarde les fichiers locaux et présente les modifications proposées.
Laisse-moi saisir localement les clés API nécessaires ; ne les demande, ne les affiche et ne les colle jamais dans le chat.
Vérifie d’abord que la configuration se charge correctement.
Explique séparément le coût de tout test utilisant une requête payante avant de l’exécuter.
```

## Installer et configurer Pi

Suivez [l’installation officielle](https://pi.dev/). Le paquet npm est `@earendil-works/pi-coding-agent`. Sous Windows, consultez la [configuration du shell](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md) : Git Bash est utilisé par défaut. Ignorez l’installation si Pi est déjà présent.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.85.1
pi --version
```

La configuration ci-dessous a été vérifiée avec **Pi 0.85.1**. Les autres versions nécessitent une vérification distincte selon leur documentation officielle.

Sauvegardez `~/.pi/agent/models.json`, puis ajoutez `tokenlab` après les entrées existantes de `providers` ; créez le fichier seulement s’il est absent. Un `PI_CODING_AGENT_DIR` non vide désigne le répertoire de `models.json`. Conservez l’ordre des fournisseurs, `settings.json`, les comptes, les champs du modèle par défaut et les autorisations. Si `tokenlab` existe déjà dans la configuration ou les comptes enregistrés, choisissez un autre nom et adaptez la commande. Définissez `TOKENLAB_API_KEY` localement avec le [démarrage rapide](/fr/quickstart) pour macOS, Linux, WSL ou Windows PowerShell, jamais dans le chat.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

Le `$` de `"$TOKENLAB_API_KEY"` est obligatoire ; sinon la valeur est une chaîne littérale. Choisissez un modèle actuel avec Chat Completions et outils. Utilisez ses propres limites et capacités pour les options de contexte, images et raisonnement.

Facultatif : l’[assistant de configuration réversible pour Pi](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/pi_setup.md) permet de prévisualiser, appliquer et restaurer le fichier original avec Python 3.11+. Le plugin TokenLab Skills **0.1.2** contient ces scripts ; un Skill autonome convient aussi après sa mise à jour vers une version qui les inclut. Pour un plugin ou un Skill autonome déjà installé, suivez les [instructions de mise à jour du README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) et vérifiez la présence du script. La configuration manuelle de cette page reste utilisable sans cet assistant.

## Vérifier et restaurer

Vérifiez le chargement depuis le même terminal et répertoire d’agent, puis sélectionnez explicitement TokenLab pour cette session. Sans `TOKENLAB_API_KEY`, le fournisseur peut ne pas apparaître. La liste confirme l’enregistrement et la présence d’identifiants, pas leur validité ni un appel API terminé.

```bash
pi --list-models tokenlab
pi --provider tokenlab --model gpt-5.6-luna
```

Un prompt utilise le solde TokenLab. Vérifiez la réponse et son [enregistrement](https://tokenlab.sh/dashboard/runs?section=requests) avant de tester les outils. Pour annuler les réglages manuels, retirez uniquement le fournisseur ajouté en conservant les autres réglages et comptes.

## Skills et MCP

Pi prend en charge les [Skills nativement](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). Installez le [Skill TokenLab](/fr/integrations/coding-agent-skill). MCP nécessite une extension distincte ; ne placez pas sa configuration dans `models.json`.
