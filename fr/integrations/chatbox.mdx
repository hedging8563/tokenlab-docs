## Aperçu

Chatbox peut utiliser TokenLab via ses paramètres d'API compatibles OpenAI.

<Note>
**Type** : Application de chat

**Chemin principal** : Complétions de chat compatibles OpenAI

**Niveau de support** : Chemin pris en charge
</Note>

## Configurer Chatbox

1. Ouvrez **Settings** -> **AI Model**
2. Choisissez **OpenAI API Compatible**
3. Saisissez :
   - **API Host** : `https://api.tokenlab.sh/v1`
   - **API Key** : `sk-your-tokenlab-key`
   - **Model** : `gpt-5.4-mini`
4. Enregistrez et envoyez un court message de test.

## Modèles recommandés

| Cas d'utilisation | Modèle |
|----------|-------|
| Chat quotidien | `gpt-5.4-mini` |
| Raisonnement plus poussé | `gpt-5.4` ou `gpt-5.5` |
| Sortie de style Claude | `claude-sonnet-5` |
| Solution de secours rapide | `deepseek-v4-flash` |

## Remarques

Si votre version de Chatbox répertorie déjà TokenLab comme fournisseur intégré, sélectionnez-le directement. Sinon, le chemin du fournisseur compatible OpenAI ci-dessus est l'alternative la plus fiable.
