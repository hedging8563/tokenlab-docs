## Aperçu

OpenHands peut utiliser TokenLab via sa configuration de modèle compatible LiteLLM/OpenAI, particulièrement pour les flux de travail CLI et headless où vous fournissez le modèle, la clé API et l'URL de base.

<Note>
**Type** : Agent de codage

**Chemin principal** : Configuration de modèle compatible OpenAI

**Niveau de support** : Chemin de point de terminaison personnalisé pris en charge
</Note>

## Environnement

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Paramètres du modèle

Utilisez :

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

Le préfixe `openai/` indique au chemin basé sur LiteLLM d'utiliser une configuration de fournisseur compatible OpenAI.

## Configuration Headless

Si vous préparez des paramètres locaux par défaut pour une utilisation CLI ou headless, exécutez le flux de configuration d'OpenHands et saisissez :

```bash
make setup-config
```

Lorsque les détails du modèle vous sont demandés, utilisez l'ID du modèle TokenLab avec le préfixe `openai/` et l'URL de base `/v1` de TokenLab.

## Suggestions de modèles

Utilisez `claude-sonnet-5` ou `gpt-5.4` pour la planification de l'agent de codage, `gpt-5.4-mini` pour des boucles de routine plus rapides, et `deepseek-v4-pro` lorsque vous souhaitez une alternative robuste en matière de raisonnement.
