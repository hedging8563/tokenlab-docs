## Aperçu

Cette page concerne l’interface OpenHands avec LiteLLM et **Settings → LLM → Advanced**. Choisissez **OpenAI**, saisissez un modèle personnalisé préfixé par `openai/`, la clé TokenLab dans le champ local et la Base URL ci-dessous. Notez la sélection précédente pour la restaurer ensuite ; conservez comptes et permissions des outils. Voir la [configuration officielle compatible OpenAI](https://docs.openhands.dev/openhands/usage/llms/openai-llms). Les installations CLI, cloud ou depuis les sources peuvent suivre d’autres étapes : consultez votre édition. `make setup-config` n’est pas une commande générale de la CLI installée.

## Paramètres du modèle

Sauvegardez localement le fournisseur, le modèle et la connexion avant toute modification. Ces réglages changent le modèle actif ; restaurez les valeurs précédentes après utilisation. Conservez les comptes connectés et les permissions des outils. Ne remplacez pas une autre connexion compatible OpenAI sans sauvegarde restaurable.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

Enregistrer les réglages ou lister les modèles ne valide ni la clé ni un appel terminé. Un prompt utilise le solde TokenLab. Vérifiez la réponse et son [enregistrement correspondant](https://tokenlab.sh/dashboard/runs?section=requests) avant de tester les outils ; les requêtes auxiliaires peuvent aussi être facturées.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
