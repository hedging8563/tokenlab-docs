## Usage

This example uses one model's declared request format. Other models on this page may accept different formats.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="grok-4.20",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Check the [model details](/api-reference/models/get-model) for `grok-4.20` with `GET /v1/models/grok-4.20` and your API key.
