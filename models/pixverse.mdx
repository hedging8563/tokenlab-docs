## Usage

No supported request example was selected from the published format declarations. Check the [model details](/api-reference/models/get-model) for `pixverse-c1` with `GET /v1/models/pixverse-c1` and your API key. Its declared request endpoint is `/v1/videos/generations`.

See the [API Reference](/api-reference/introduction) for the declared endpoint's request shape. Category and provider names do not establish a request protocol.
