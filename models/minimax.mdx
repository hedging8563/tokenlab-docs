## Usage

This example uses one model's declared request format. Other models on this page may accept different formats.

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="sk-your-tokenlab-key",
    base_url="https://api.tokenlab.sh"
)

response = client.messages.create(
    model="minimax-m2",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Check the [model details](/api-reference/models/get-model) for `minimax-m2` with `GET /v1/models/minimax-m2` and your API key.
