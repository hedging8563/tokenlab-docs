## Usage

This example uses one model's declared request format. Other models on this page may accept different formats.

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-tokenlab-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="qwen-deep-research",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Check the [model details](/api-reference/models/get-model) for `qwen-deep-research` with `GET /v1/models/qwen-deep-research` and your API key.
