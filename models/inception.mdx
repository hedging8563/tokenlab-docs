## Usage

This example uses one model's declared request format. Other models on this page may accept different formats.

```python
import os
from anthropic import Anthropic

client = Anthropic(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh"
)

response = client.messages.create(
    model="mercury-2.5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Check the [model details](/api-reference/models/get-model) for `mercury-2.5` with `GET /v1/models/mercury-2.5` and your API key.
