## Usage

This example uses one model's declared request format. Other models on this page may accept different formats.

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-tokenlab-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="gemini-2.5-pro",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Check the [model details](/api-reference/models/get-model) for `gemini-2.5-pro` with `GET /v1/models/gemini-2.5-pro` and your API key.
