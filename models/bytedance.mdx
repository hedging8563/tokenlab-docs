## Usage

This example uses one model's declared request format. Other models on this page may accept different formats.

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="doubao-seed-2.0-code",
    messages=[{"role": "user", "content": "Hello!"}]
)
```

Check the [model details](/api-reference/models/get-model) for `doubao-seed-2.0-code` with `GET /v1/models/doubao-seed-2.0-code` and your API key.
