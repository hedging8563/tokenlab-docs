## Visão Geral

O Agno pode usar o TokenLab como um provedor de modelos compatível com OpenAI para agentes e fluxos de trabalho.

<Note>
**Tipo**: Framework de Agente

**Caminho Principal**: Chat completions compatíveis com OpenAI

**Nível de Suporte**: Caminho suportado
</Note>

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Wrapper de Modelo do TokenLab

Se a sua versão do Agno incluir o wrapper de modelo do TokenLab:

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

Algumas builds do Agno também suportam strings de modelo:

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## Fallback Compatível com OpenAI

Se a sua versão ainda não incluir o TokenLab, use o caminho de modelo compatível com OpenAI do Agno com:

- Base URL: `https://api.tokenlab.sh/v1`
- API key: `TOKENLAB_API_KEY`
- Model: `gpt-5.4-mini`

## Sugestões de Modelos

Use `gpt-5.4-mini` para agentes padrão, `gpt-5.4` ou `claude-sonnet-5` para raciocínio mais profundo e `deepseek-v4-flash` para loops mais rápidos.
