## Visão geral

<Note>
**Tipo**: agente de desktop para código e tarefas

**Caminho principal**: Chat Completions compatível com OpenAI

**Suporte**: caminho oficial de modelo personalizado
</Note>

O [WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) oferece um editor visual para modelos compatíveis com OpenAI. Não é necessário editar o arquivo local manualmente.

## Configurar o TokenLab

Abra **Settings → Model**, adicione um modelo e escolha **Custom**.

| Campo | Valor |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | Sua chave API do TokenLab |
| Model name | `kimi-k3` |
| Custom Protocol | **Desativado** |

<Warning>
Mantenha Custom Protocol desativado. O modo padrão valida a Base URL e adiciona `/chat/completions`. Se estiver ativado com apenas `/v1`, a solicitação usa o caminho errado.
</Warning>

Nas opções avançadas, ative chamadas de ferramentas, entrada de imagens e raciocínio. Desative o modo apenas raciocínio, deixe o esforço em Auto e use `1048576` para entrada e `131072` para saída.

Salve, selecione `kimi-k3` e teste primeiro uma inspeção de pasta somente leitura. Oculte chaves e endpoints privados antes de compartilhar capturas.
