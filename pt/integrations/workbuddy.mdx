## Deixar meu agente fazer a configuração

Copie esta tarefa para um agente que já esteja funcionando no seu computador:

```text
Leia este guia e me ajude a conectar WorkBuddy ao TokenLab:
https://docs.tokenlab.sh/pt/integrations/workbuddy
Verifique primeiro minha versão instalada e a configuração ativa.
Preserve as contas, os provedores, as permissões e os demais ajustes existentes.
Faça backup dos arquivos locais e mostre as alterações propostas.
Deixe que eu insira localmente as chaves de API necessárias; nunca as solicite, exiba ou cole no chat.
Verifique primeiro se a configuração é carregada corretamente.
Explique separadamente o custo de qualquer teste com requisições pagas antes de executá-lo.
```

## Visão geral

O [WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) oferece um editor visual para modelos compatíveis com OpenAI. Não é necessário editar o arquivo local manualmente.

## Configurar o TokenLab

Abra **Settings → Model**, adicione um modelo e escolha **Custom**.

| Campo | Valor |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | Sua chave API do TokenLab |
| Model name | `kimi-k3` |
| Custom Protocol | **Desativado** |

<Warning>
Mantenha Custom Protocol desativado. O modo padrão valida a Base URL e adiciona `/chat/completions`. Se estiver ativado com apenas `/v1`, a solicitação usa o caminho errado.
</Warning>

Configure ferramentas, imagens, raciocínio e limites conforme os detalhes atuais do modelo no TokenLab. Não ative tudo nem copie limites 1M/128K de outro modelo. Use o ID exibido.

Salve, selecione `kimi-k3` e teste primeiro uma inspeção de pasta somente leitura. Oculte chaves e endpoints privados antes de compartilhar capturas.

Salvar e selecionar só confirma a configuração local. Tarefas de texto ou ferramentas usam saldo TokenLab; confira a resposta e seu [registro](https://tokenlab.sh/dashboard/runs?section=requests). Para desfazer, selecione o modelo anterior e remova apenas a entrada TokenLab adicionada.

O aplicativo oficial está disponível para macOS e Windows. Use o [editor oficial](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model); não se presume versão Linux nem formato de arquivo editável diretamente.

As [ferramentas API MCP](/pt/integrations/tokenlab-mcp-server) e [instruções Skill](/pt/integrations/coding-agent-skill) são instaladas separadamente e não mudam o modelo principal.
