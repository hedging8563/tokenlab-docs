## Visão Geral

O CrewAI oferece suporte a LLMs compatíveis com OpenAI definindo o modelo, a chave de API e a URL base em variáveis de ambiente ou na classe `LLM`.

<Note>
**Tipo**: Framework de Agentes

**Caminho Principal**: Chat completions compatíveis com OpenAI

**Nível de Suporte**: Caminho de endpoint personalizado suportado
</Note>

## Variáveis de Ambiente

```python
import os

os.environ["OPENAI_API_KEY"] = "sk-your-tokenlab-key"
os.environ["OPENAI_API_BASE"] = "https://api.tokenlab.sh/v1"
os.environ["OPENAI_MODEL_NAME"] = "openai/claude-sonnet-5"
```

## Classe LLM

```python
from crewai import Agent, LLM

llm = LLM(
    model="claude-sonnet-5",
    custom_openai=True,
    base_url="https://api.tokenlab.sh/v1",
    api_key="sk-your-tokenlab-key",
)

agent = Agent(
    role="Research analyst",
    goal="Summarize technical tradeoffs clearly",
    backstory="You produce concise implementation notes.",
    llm=llm,
)
```

## Sugestões de Modelos

Use `gpt-5.4-mini` para crews de rotina, `claude-sonnet-5` ou `gpt-5.4` para agentes que exigem muito planejamento, e `deepseek-v4-flash` para iterações mais rápidas e de baixo custo.

## Notas sobre o Endpoint

O caminho compatível com OpenAI do CrewAI é ideal para chamadas de agentes no estilo Chat Completions. Utilize os endpoints nativos do TokenLab diretamente apenas quando a ferramenta ou SDK escolhido suportar esses protocolos nativos.
