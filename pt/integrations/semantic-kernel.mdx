## Visão Geral

O Semantic Kernel pode chamar o TokenLab através do seu serviço de conclusão de chat de endpoint personalizado da OpenAI.

<Note>
**Tipo**: SDK / Framework de Agente

**Caminho Principal**: Conclusões de chat compatíveis com OpenAI

**Nível de Suporte**: Caminho de endpoint personalizado suportado
</Note>

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## .NET Kernel Builder

O endpoint personalizado do Semantic Kernel deve apontar para o endpoint raiz `/v1` compatível com OpenAI, e não para `/v1/chat/completions`.

```csharp
using Microsoft.SemanticKernel;

#pragma warning disable SKEXP0010

var builder = Kernel.CreateBuilder();

builder.AddOpenAIChatCompletion(
    modelId: "gpt-5.4-mini",
    endpoint: new Uri("https://api.tokenlab.sh/v1"),
    apiKey: Environment.GetEnvironmentVariable("TOKENLAB_API_KEY"));

var kernel = builder.Build();
```

## Prompt Básico

```csharp
var result = await kernel.InvokePromptAsync(
    "Give me a concise checklist for evaluating an LLM gateway.");

Console.WriteLine(result);
```

## Notas sobre o Endpoint

Use:

```text
https://api.tokenlab.sh/v1
```

Não use:

```text
https://api.tokenlab.sh/v1/chat/completions
```

O Semantic Kernel anexa o caminho de conclusões de chat internamente para este conector.
