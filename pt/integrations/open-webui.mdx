## Visão Geral

O Open WebUI suporta conexões de API personalizadas compatíveis com OpenAI. Adicione o TokenLab como um endpoint remoto compatível com OpenAI e atualize a lista de modelos.

<Note>
**Tipo**: Aplicativo de Chat Web

**Caminho Principal**: Completions de chat compatíveis com OpenAI

**Nível de Suporte**: Caminho de aplicativo de chat suportado
</Note>

## Conexão de Administrador

1. Abra o **Admin Panel** -> **Settings** -> **Connections**.
2. Na área de conexão da OpenAI API, adicione uma conexão.
3. Defina a base URL como `https://api.tokenlab.sh/v1`.
4. Defina a API key com a sua chave do TokenLab.
5. Salve a conexão e atualize os modelos.

## Valores

| Campo | Valor |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Modelo de exemplo | `gpt-5.4-mini` |

## Modelos Recomendados

- `gpt-5.4-mini` para chat geral
- `claude-sonnet-5` para escrita e raciocínio
- `deepseek-v4-pro` para chat com foco em código
- `gemini-3.5-flash` para fluxos de trabalho rápidos e multimodais

Para informar IDs de modelo manualmente, edite esta conexão e abra **Advanced** → **Model IDs (Filter)**. Adicione os IDs exatos dos modelos TokenLab e salve.
