## Visão geral

OpenCode é um assistente de programação com AI de código aberto que roda no seu terminal. Ele oferece suporte a vários provedores de LLM e pode ser configurado para usar a API do TokenLab para acessar centenas de modelos.

## Instalação

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

Verifique a instalação:

```bash
opencode --version
```

## Configuração

### Etapa 1: Definir variáveis de ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

Para configuração permanente, adicione a `~/.bashrc` ou `~/.zshrc`:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### Etapa 2: Configurar o OpenCode

A documentação atual do OpenCode recomenda configurar provedores por meio de `opencode.json` ou `opencode.jsonc`. Para o TokenLab, use um provedor personalizado em vez de sobrescrever o provedor `openai` integrado:

O exemplo usa o formato V1 compatível. Mescle em `~/.config/opencode/opencode.json`, mantendo provedores e permissões. V2 lê configurações V1 compatíveis; não misture formatos dentro de um provedor. Veja a [migração oficial](https://opencode.ai/v2/docs/migrate-v1/). Confira `/models` e depois um teste pago no registro TokenLab. Para desfazer, volte ao modelo anterior e remova apenas esta entrada.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
Use `@ai-sdk/openai-compatible` para compatibilidade no estilo chat-completions. Se você precisar especificamente de um caminho de provedor baseado em `/v1/responses`, a documentação de provedores do OpenCode recomenda trocar o pacote para `@ai-sdk/openai`.
</Note>

## Uso básico

**Iniciar o modo interativo:**

```bash
opencode
```

**Executar com um prompt:**

```bash
opencode run "Explain this codebase"
```

**Especificar modelo:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## Modelos disponíveis

| Modelo | Melhor para |
|-------|-------------|
| `gpt-5.6-terra` | Tarefas complexas, arquitetura de código |
| `gpt-5.6-luna` | Correções rápidas, consultas simples |
| `claude-sonnet-4-6` | Revisão de código, documentação |
| `claude-opus-4-6` | Raciocínio complexo |
| `gemini-3.5-flash` | Respostas rápidas |

## Comandos comuns

**Analisar código:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**Gerar código:**

```bash
opencode run "Create a REST API with Express"
```

**Revisar alterações:**

```bash
git diff | opencode run "Review these changes"
```

**Corrigir erros:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## Comandos interativos

| Command | Descrição |
|---------|-----------|
| `/help` | Mostrar comandos disponíveis |
| `/models` | Alternar para um modelo diferente |
| `/clear` | Limpar o histórico da conversa |
| `/exit` | Sair do OpenCode |

## Solução de problemas

<AccordionGroup>
  <Accordion title="Erro de conexão">
    - Verifique se `options.baseURL` está definido como `https://api.tokenlab.sh/v1`
    - Verifique a conectividade de rede
    - Tente `curl https://api.tokenlab.sh/v1/models` para testar
  </Accordion>

  <Accordion title="Falha na autenticação">
    - Verifique se a variável de ambiente `TOKENLAB_API_KEY` está definida
    - Verifique se `options.apiKey` referencia `{env:TOKENLAB_API_KEY}` ou outra fonte de segredo válida
    - Verifique se a chave começa com `sk-`
    - Certifique-se de que a chave está ativa no dashboard do TokenLab
  </Accordion>

  <Accordion title="Modelo não encontrado">
    - Verifique se o nome do modelo na configuração corresponde exatamente
    - Verifique a disponibilidade do modelo em [tokenlab.sh/en/models](https://tokenlab.sh/pt/models)
  </Accordion>
</AccordionGroup>
