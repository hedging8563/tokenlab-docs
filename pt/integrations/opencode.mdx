Copie esta tarefa para um agente que já esteja funcionando no seu computador:

```text
Leia este guia e me ajude a conectar OpenCode ao TokenLab:
https://docs.tokenlab.sh/pt/integrations/opencode
Verifique primeiro minha versão instalada e a configuração ativa.
Preserve as contas, os provedores, as permissões e os demais ajustes existentes.

Verifique primeiro se a configuração é carregada corretamente.
```

## Visão geral

OpenCode é um assistente de programação com AI de código aberto que roda no seu terminal. Ele oferece suporte a vários provedores de LLM e pode ser configurado para usar a API do TokenLab para acessar centenas de modelos.

## Instalação

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

Verifique a instalação:

```bash
opencode --version
```

## Configuração

### Etapa 1: Definir variáveis de ambiente

Siga as etapas de terminal do [início rápido](/pt/quickstart) para macOS, Linux, WSL ou Windows PowerShell e defina `TOKENLAB_API_KEY` sem gravar a chave no histórico. Inicie o OpenCode nesse terminal. Para uso persistente, utilize um gerenciador local de segredos, sem acrescentar a chave em texto simples ao perfil do shell.

### Etapa 2: Configurar o OpenCode

A configuração abaixo foi verificada com **OpenCode 1.18.31**. Outras versões precisam de verificação própria conforme a documentação oficial.

Salve a configuração em um arquivo separado `~/.config/opencode/tokenlab.jsonc`. Se `XDG_CONFIG_HOME` estiver definido, use `opencode/tokenlab.jsonc` nesse diretório. Preserve os arquivos habituais `opencode.json` / `opencode.jsonc`, as contas, o modelo padrão e as permissões. O arquivo separado só é carregado em uma execução que o selecione com `OPENCODE_CONFIG`. Se o arquivo ou nome do provedor já estiver em uso, escolha outro nome e ajuste os comandos.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
Esta configuração envia Chat Completions por `@ai-sdk/openai-compatible`. Confira nos detalhes atuais do modelo o suporte a Chat Completions e às ferramentas necessárias. O exemplo não comprova compatibilidade com outros protocolos ou versões.
</Note>

Opcional: o [assistente reversível de configuração do OpenCode](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md) permite visualizar, aplicar e restaurar o arquivo original com Python 3.11+. O plugin TokenLab Skills **0.1.2** inclui esses scripts; um Skill independente também pode ser usado após a atualização para uma versão que os contenha. Para plugins ou Skills independentes já instalados, siga as [instruções de atualização do README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) e confirme que o script está presente. A configuração manual desta página também funciona sem o assistente.

## Uso básico

Defina a chave conforme o início rápido, carregue o arquivo apenas nesta execução e selecione o modelo explicitamente. Substitua caminhos e nomes personalizados. Preserve configurações existentes de `OPENCODE_CONFIG` ou `OPENCODE_CONFIG_CONTENT` em um ambiente de inicialização separado; ajustes do projeto ou gerenciados ainda podem ter prioridade.

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

A lista de modelos verifica o carregamento local, não a validade da chave ou o sucesso de uma solicitação real. Um prompt utiliza saldo TokenLab e o OpenCode pode enviar solicitações auxiliares cobradas separadamente, como a geração de um título. Confira a resposta e os [registros correspondentes](https://tokenlab.sh/dashboard/runs?section=requests).

Inicie sem esse arquivo para usar sua configuração habitual. Não salve `OPENCODE_CONFIG` no perfil do shell para seguir este guia. Para desfazer a configuração manual, remova apenas o arquivo separado que criou ou restaure sua cópia se ele já existia.

## Modelos disponíveis

| Modelo | Melhor para |
|-------|-------------|
| `gpt-5.6-terra` | Tarefas complexas, arquitetura de código |
| `gpt-5.6-luna` | Correções rápidas, consultas simples |
| `claude-sonnet-4-6` | Revisão de código, documentação |
| `claude-opus-4-6` | Raciocínio complexo |
| `gemini-3.5-flash` | Respostas rápidas |

## Comandos comuns

**Analisar código:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**Gerar código:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**Revisar alterações:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**Corrigir erros:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## Comandos interativos

| Command | Descrição |
|---------|-----------|
| `/help` | Mostrar comandos disponíveis |
| `/models` | Alternar para um modelo diferente |
| `/clear` | Limpar o histórico da conversa |
| `/exit` | Sair do OpenCode |

## Solução de problemas

<AccordionGroup>
  <Accordion title="Erro de conexão">
    - Verifique se `options.baseURL` está definido como `https://api.tokenlab.sh/v1`
    - Verifique a conectividade de rede
    - Tente `curl https://api.tokenlab.sh/v1/models` para testar
  </Accordion>

  <Accordion title="Falha na autenticação">
    - Verifique se a variável de ambiente `TOKENLAB_API_KEY` está definida
    - Verifique se `options.apiKey` referencia `{env:TOKENLAB_API_KEY}` ou outra fonte de segredo válida
    - Verifique se a chave começa com `sk-`
    - Certifique-se de que a chave está ativa no dashboard do TokenLab
  </Accordion>

  <Accordion title="Modelo não encontrado">
    - Verifique se o nome do modelo na configuração corresponde exatamente
    - Verifique a disponibilidade do modelo em [tokenlab.sh/en/models](https://tokenlab.sh/pt/models)
  </Accordion>
</AccordionGroup>
