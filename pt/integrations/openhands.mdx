## Visão geral

Esta página se aplica à interface OpenHands com LiteLLM em **Settings → LLM → Advanced**. Escolha **OpenAI**, informe um modelo personalizado com prefixo `openai/`, a chave TokenLab no campo local e a Base URL abaixo. Registre a seleção anterior para restaurá-la depois; mantenha contas e permissões de ferramentas. Consulte a [configuração oficial compatível com OpenAI](https://docs.openhands.dev/openhands/usage/llms/openai-llms). CLI, cloud e instalações pelo código-fonte podem usar outros fluxos; siga sua edição instalada. `make setup-config` não é um comando geral da CLI instalada.

## Configurações do modelo

Salve localmente o provedor, modelo e conexão atuais antes de editar. Esses controles alteram o modelo ativo; restaure os valores anteriores ao terminar. Mantenha as contas conectadas e permissões de ferramentas. Não substitua outra conexão compatível com OpenAI sem uma cópia restaurável.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

Salvar ajustes ou listar modelos não verifica a chave nem uma solicitação concluída. Um prompt usa saldo TokenLab. Confira a resposta e seu [registro correspondente](https://tokenlab.sh/dashboard/runs?section=requests) antes de testar ferramentas; solicitações auxiliares também podem ser cobradas.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
