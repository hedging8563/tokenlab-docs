## Visão geral

O OpenHands pode usar o TokenLab através de sua configuração de modelo compatível com LiteLLM/OpenAI, especialmente para CLI e fluxos de trabalho headless onde você fornece o modelo, a chave de API e a URL base.

<Note>
**Tipo**: Agente de codificação

**Caminho principal**: Configuração de modelo compatível com OpenAI

**Nível de suporte**: Caminho de endpoint personalizado suportado
</Note>

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Configurações do modelo

Use:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

O prefixo `openai/` indica ao caminho baseado em LiteLLM para usar uma configuração de provedor compatível com OpenAI.

## Configuração Headless

Se você estiver preparando padrões locais para uso via CLI ou headless, execute o fluxo de configuração do OpenHands e insira:

```bash
make setup-config
```

Quando solicitado os detalhes do modelo, use o ID do modelo TokenLab com o prefixo `openai/` e a URL base `/v1` do TokenLab.

## Sugestões de modelos

Use `claude-sonnet-5` ou `gpt-5.4` para planejamento de agente de codificação, `gpt-5.4-mini` para loops de rotina mais rápidos e `deepseek-v4-pro` quando desejar um modelo de raciocínio alternativo robusto.
