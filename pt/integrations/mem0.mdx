## Visão Geral

O Mem0 OSS pode usar o TokenLab através de sua configuração de LLM compatível com OpenAI, mantendo `provider: "openai"` e definindo a `openai_base_url`.

<Note>
**Tipo**: Framework de Memória

**Caminho Principal**: Configuração de LLM compatível com OpenAI

**Nível de Suporte**: Caminho de endpoint personalizado suportado
</Note>

## Instalação

```bash
pip install mem0ai
```

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Configuração em Python

```python
import os

from mem0 import Memory

config = {
    "llm": {
        "provider": "openai",
        "config": {
            "model": "claude-sonnet-5",
            "api_key": os.environ["TOKENLAB_API_KEY"],
            "openai_base_url": "https://api.tokenlab.sh/v1",
            "temperature": 0.1,
        },
    },
    "embedder": {
        "provider": "openai",
        "config": {
            "model": "text-embedding-3-small",
            "api_key": os.environ["TOKENLAB_API_KEY"],
            "openai_base_url": "https://api.tokenlab.sh/v1",
        },
    },
    "vector_store": {
        "provider": "qdrant",
        "config": {"path": "./mem0-qdrant"},
    },
}

memory = Memory.from_config(config)
```

## Uso Básico

```python
memory.add("The user prefers concise engineering summaries.", user_id="demo")
results = memory.search("How should I answer?", filters={"user_id": "demo"})
print(results)
```

## Notas sobre o Endpoint

Esta configuração cobre o caminho de LLM compatível com OpenAI do Mem0. Configure os embedders separadamente de acordo com o vector store e o modelo de embedding que você utilizar.
