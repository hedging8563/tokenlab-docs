## Visão Geral

O Helicone pode realizar proxy e observar requisições compatíveis com OpenAI do TokenLab, roteando-as através do Helicone Gateway e direcionando-as para o TokenLab.

<Note>
**Tipo**: Gateway de Observabilidade

**Caminho Principal**: Chat completions compatíveis com OpenAI através do Helicone Gateway

**Nível de Suporte**: Caminho de observabilidade suportado
</Note>

## Ambiente

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## Escopo

Esta configuração é destinada ao tráfego `/v1` compatível com OpenAI. O TokenLab também expõe endpoints nativos de Responses, Anthropic Messages e compatíveis com Gemini; utilize as rotas diretas do TokenLab para esses formatos nativos, a menos que seu proxy de observabilidade suporte explicitamente esses formatos.
