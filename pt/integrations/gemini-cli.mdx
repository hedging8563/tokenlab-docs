## Visão geral

Gemini CLI **0.60.0** documenta `GOOGLE_GEMINI_BASE_URL` para autenticação por chave API. Use o endpoint Gemini nativo do TokenLab com um modelo atual que aceite `gemini_generate_content`. Consulte a [configuração oficial](https://geminicli.com/docs/reference/configuration/) e a [autenticação](https://geminicli.com/docs/get-started/authentication/). Isso não encaminha uma assinatura Google pelo TokenLab.

## Instalação

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## Configuração

Siga as etapas de terminal do [início rápido](/pt/quickstart) para macOS, Linux, WSL ou Windows PowerShell e defina `TOKENLAB_API_KEY` sem gravar a chave no histórico. Inicie o Gemini CLI nesse terminal. Para uso persistente, utilize um gerenciador local de segredos, sem acrescentar a chave em texto simples ao perfil do shell.

Preserve seu login Google e a configuração atual. Para TokenLab, escolha uma raiz de configuração livre como `~/.gemini-tokenlab` (`$HOME` no PowerShell) e crie a pasta `.gemini`. Copie sua `.gemini/settings.json` e os arquivos de política necessários para os locais correspondentes, mantendo permissões, sandbox e outros ajustes. Mescle o campo de autenticação abaixo somente nessa cópia; crie o arquivo se não existir. Não copie caches OAuth nem apague credenciais originais. Respeite as políticas de autenticação gerenciadas.

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## Uso

A execução abaixo usa `~/.gemini-tokenlab/.gemini/settings.json`. Ajuste o caminho se escolheu outra raiz. Confirme o diretório de trabalho no aviso normal de confiança e mantenha as regras de aprovação de ferramentas. O modelo é escolhido explicitamente para esta sessão.

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Estas variáveis valem apenas para esta inicialização; a conta, o modelo padrão e as permissões salvas permanecem. Inicie normalmente sem elas para usar a configuração anterior. Não as salve no perfil do shell.

## Verificação

Salvar ajustes ou listar modelos não verifica a chave nem uma solicitação concluída. Um prompt usa saldo TokenLab. Confira a resposta e seu [registro correspondente](https://tokenlab.sh/dashboard/runs?section=requests) antes de testar ferramentas; solicitações auxiliares também podem ser cobradas.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
