## Visão geral

<Note>
**Tipo**: agente de código para IDE

**Caminho principal**: Chat Completions compatível com OpenAI

**Suporte**: caminho oficial de provedor
</Note>

O [Cline](https://docs.cline.bot/provider-config/openai-compatible) aceita provedores compatíveis com OpenAI nas configurações da IDE.

## Configurar o TokenLab

1. Instale o **Cline** na loja de extensões e abra o painel.
2. Clique na engrenagem e selecione **OpenAI Compatible** em **API Provider**.
3. Preencha:

| Campo | Valor |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | Sua chave API do TokenLab |
| Model ID | `kimi-k3` |

4. Clique em **Verify**.

Nas opções avançadas, use `1048576` como limite de entrada, `131072` como saída máxima e ative imagens e ferramentas / Computer Use.

Depois da validação, comece com uma tarefa somente leitura. Em caso de 404, confirme que a Base URL termina em `/v1` e não inclui `/chat/completions`. O ID é `kimi-k3`, não `kimi/kimi-k3`.
