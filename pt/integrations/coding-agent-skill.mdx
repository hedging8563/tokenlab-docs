## O que o skill faz

- Gera exemplos mínimos executáveis para chat, imagem, áudio, vídeo, tradução e outras famílias de API da TokenLab.
- Usa `https://api.tokenlab.sh/v1` para clientes compatíveis com OpenAI e explica quando mudar para rotas nativas Anthropic ou Gemini.
- Descobre modelos com `/v1/models`, `/llms.txt` e listas `recommended_for`, em vez de adivinhar a partir de listas antigas.
- Lê o detalhes do modelo de um modelo antes de tentar novamente solicitações não-chat, para não remover campos incompatíveis silenciosamente.
- Trata dicas de erro Agent-First como `did_you_mean`, `suggestions`, `retry_after` e `recommended_request`.

## Instalação

<Note>
Use o comando canônico de instalação não interativa:

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills --skill tokenlab-api-integration -y
```

Isso instala o skill compartilhado `tokenlab-api-integration` a partir do repositório TokenLab skills.

Se sua ferramenta não suporta o installer, copie `skills/tokenlab-api-integration/` do repositório para o diretório compartilhado de skills ou rules da ferramenta.
</Note>

## Fluxo recomendado para Agent

Leia a lista atual e depois `tokenlab.accepted_request_formats` e os campos públicos do modelo escolhido. Mantenha o mesmo formato na conversa e nas chamadas de ferramentas; os campos não são convertidos automaticamente. Não altere o modelo ou protocolo por conta própria após um erro.

## Exemplo mínimo de chat

Este exemplo usa o SDK Python da OpenAI com a base URL da TokenLab:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "Hello!"}],
)

print(response.choices[0].message.content)
```

Execute com:

```bash
pip install openai
export TOKENLAB_API_KEY="sk-your-api-key"
python app.py
```

## Descoberta de modelos e contratos

Prefira descoberta ao vivo em vez de listas antigas empacotadas:

```bash
# Visão geral da API legível por máquina
curl https://api.tokenlab.sh/llms.txt

# Listar modelos
curl "https://api.tokenlab.sh/v1/models" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?category=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Listas ranqueadas para não-chat
curl "https://api.tokenlab.sh/v1/models?recommended_for=image" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=video" -H "Authorization: Bearer $TOKENLAB_API_KEY"
curl "https://api.tokenlab.sh/v1/models?recommended_for=translation" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Ler o detalhes do modelo de um modelo antes de tentar novamente solicitações não-chat
curl "https://api.tokenlab.sh/v1/models/gpt-image-2" -H "Authorization: Bearer $TOKENLAB_API_KEY"

# Detalhe apenas de preços
curl "https://api.tokenlab.sh/v1/models/gpt-image-2/pricing" -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Seleção do protocolo nativo

O caminho compatível com OpenAI `/v1` é o padrão para exemplos comuns de chat, imagem, embedding, áudio e rerank. Não deduza a disponibilidade de um protocolo nativo pelo nome do modelo ou provedor nem por cabeçalhos de resposta do Chat. Consulte `GET /v1/models/{model}` e use apenas um formato de solicitação anunciado nos detalhes do modelo.

O campo a consultar é `tokenlab.accepted_request_formats`.

Os endpoints são `/v1/chat/completions` para Chat Completions, `/v1/responses` para Responses, `/v1/messages` para Messages e `/v1beta/models/{model}:generateContent` para Gemini.

## Recuperação de erros Agent-First

Os erros incluem campos que coding agents podem analisar sem raspar a documentação:

Use o status HTTP e o `code` do erro como sinal principal. Consulte `did_you_mean` para nomes incorretos, mas não troque o modelo sem a escolha do usuário. Em `429`, respeite `Retry-After` ou `retry_after` e repita apenas quando permitido pelo erro e escolhido explicitamente. Corrija antes erros de validação, autenticação, saldo ou permissão. Após timeout na criação, verifique se já existe uma tarefa antes de reenviar.

## Famílias de API compatíveis

| Família | Caminho principal |
|---|---|
| Chat e Responses | `/v1/chat/completions`, `/v1/responses` |
| Mensagens nativas Claude | `/v1/messages` |
| Solicitações nativas Gemini | `/v1beta/models/{model}:generateContent` |
| Imagens | `/v1/images/generations`, `/v1/images/edits` |
| Vídeo | `/v1/videos/generations` |
| Música | `/v1/music/generations` |
| Worlds | `/v1/worlds/generations` mais endpoints de status world e media asset |
| 3D | `/v1/3d/generations` |
| Áudio | `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/audio/translations` |
| Realtime | `/v1/realtime?model={model}` |
| Embeddings e rerank | `/v1/embeddings`, `/v1/rerank` |
| Tradução de texto | `/v1/translations` |
