## Visão geral

<Note>
**Tipo**: agente de código em CLI

**Caminho principal**: Chat Completions compatível com OpenAI

**Suporte**: caminho BYOK oficial
</Note>

O [GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models) pode usar qualquer endpoint compatível com OpenAI Chat Completions.

## Instalação e configuração

```bash
npm install -g @github/copilot
copilot --version
```

A instalação via npm requer Node.js 22 ou mais recente. O GitHub atualmente exige um plano Copilot ativo; contas gerenciadas também precisam da política do Copilot CLI habilitada.

```bash
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.tokenlab.sh/v1"
export COPILOT_PROVIDER_API_KEY="sk-your-tokenlab-key"
export COPILOT_MODEL="kimi-k3"

copilot
```

O modelo precisa aceitar streaming e chamadas de ferramentas. `kimi-k3` oferece ferramentas e mais que os 128K de contexto recomendados pelo GitHub.

Comece com uma tarefa somente leitura que não altere arquivos. Se o modelo não for encontrado, use o ID lógico do [catálogo atual do TokenLab](https://tokenlab.sh/pt/models), sem prefixo de provedor.

<Warning>
Não armazene chaves de API em arquivos rastreados pelo Git. Troque qualquer chave exposta no histórico do terminal, capturas ou logs.
</Warning>
