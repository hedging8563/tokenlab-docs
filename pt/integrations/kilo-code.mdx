## Visão geral

<Note>
**Tipo**: agente de código para IDE e CLI

**Caminho principal**: Chat Completions compatível com OpenAI

**Suporte**: caminho oficial de provedor personalizado
</Note>

O [Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible) aceita provedores compatíveis com OpenAI na extensão do VS Code e na CLI.

## Instalação e interface

Instale o canal de pré-lançamento do **Kilo Code** no VS Code ou a CLI:

```bash
npm install -g @kilocode/cli
kilo --version
```

Abra **Settings → Providers → Custom provider**.

| Campo | Valor |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | Sua chave API do TokenLab |
| Model | `kimi-k3` |

O Kilo detecta modelos em `/v1/models`. Depois de salvar, selecione `tokenlab/kimi-k3`.

## Configuração da CLI

Guarde a chave em uma variável de ambiente e edite o arquivo global confiável `~/.config/kilo/kilo.jsonc`:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

Reinicie o Kilo e execute `kilo models`. `{env:...}` só é resolvido em configuração global ou gerenciada confiável. Não escreva a chave real em uma configuração de projeto que possa ser enviada ao Git.
