## Escopo

Este guia se aplica ao **editor Cursor para desktop** no macOS, Windows e Linux. O suporte oficial a OpenAI BYOK abrange modelos de chat padrão sem raciocínio; a conclusão Tab continua usando modelos do Cursor. Alterar a OpenAI Base URL não habilita todos os modelos do TokenLab nem todos os recursos do Cursor. Veja os [limites oficiais](https://cursor.com/help/models-and-usage/api-keys).

Se precisar apenas de ferramentas de imagem, vídeo ou outras APIs, mantenha seu provedor de chat e adicione [MCP](/pt/integrations/tokenlab-mcp-server). Um [Skill](/pt/integrations/coding-agent-skill) fornece instruções sem trocar o modelo principal.

## Tarefa para seu agente atual

```text
Leia https://docs.tokenlab.sh/pt/integrations/cursor e confira minha versão instalada e meu sistema operacional.
Confirme se preciso do TokenLab como modelo principal, ferramentas MCP ou um Skill de API.
Preserve contas, configurações dos provedores e permissões; explique como restaurar as alterações.
Não peça chaves de API no chat. Eu as inserirei localmente e farei as etapas necessárias na interface.
Explique o custo de uma pequena requisição de verificação. Só após minha escolha explícita desse teste, ajude a executá-lo e a conferir seu registro no TokenLab.
```

## Abra as configurações corretas

1. Instale ou atualize o editor em [Cursor Downloads](https://cursor.com/downloads). Este guia não configura CLI nem Cloud Agents.
2. Abra **Cursor Settings** pela paleta de comandos ou com `Cmd/Ctrl + Shift + J`. `Cmd/Ctrl + ,` abre as configurações gerais do editor.
3. Em **Models**, anote a configuração OpenAI atual para poder restaurá-la. Preserve os outros provedores.
4. Insira e salve sua chave TokenLab localmente em **OpenAI API Key**. Não a envie no chat nem a inclua em commits.
5. Ative **Override OpenAI Base URL** e informe:

```text
https://api.tokenlab.sh/v1
```

As requisições BYOK também passam pelos servidores do Cursor para montar o prompt. O editor não se conecta diretamente ao TokenLab.

## Escolha um modelo

Copie o ID exato do [catálogo atual do TokenLab](https://tokenlab.sh/pt/models) e confirme o suporte no OpenAI BYOK do Cursor. A categoria chat no TokenLab não comprova essa compatibilidade.

Para o primeiro teste de texto, `gpt-4.1-mini` é um exemplo sem raciocínio, caso ainda esteja disponível. Ative a entrada existente em **Models** ou use **Add model** se ela não existir, e selecione-a no chat. Não duplique modelos integrados com outra grafia nem suponha que Claude ou Gemini usem o override OpenAI. Veja a [orientação do Cursor](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488).

## Verifique uma pequena requisição

Crie um novo chat com o modelo escolhido e envie:

```text
Responda apenas TOKENLAB_CONNECTION_OK. Não use ferramentas nem altere arquivos.
```

Essa requisição é cobrada. Confira a resposta e o modelo, horário e status nas [requisições do TokenLab](https://tokenlab.sh/dashboard/runs?section=requests). Um modelo visível ou uma resposta sem registro correspondente não confirma esse caminho.

## Se houver falha

- **Modelo ausente ou recusado:** confira o ID e o suporte BYOK; use a entrada integrada quando existir. Reiniciar não resolve incompatibilidade.
- **Erro de autenticação:** confira a chave TokenLab no campo OpenAI e a Base URL. Erros de saldo ou cota são diferentes de uma chave inválida.
- **Sem registro no TokenLab:** confira o modelo do chat, o override e o erro do Cursor. A conclusão Tab não testa essa conexão.
- **Outro provedor parou:** restaure a configuração OpenAI anterior ou desative o override e abra um novo chat.

## Adicione MCP e Skills separadamente

[MCP](/pt/integrations/tokenlab-mcp-server) adiciona ferramentas pelas configurações MCP do Cursor ou por `.cursor/mcp.json`. Verifique a descoberta primeiro e só depois execute as gerações pagas desejadas. MCP não substitui o modelo principal.

[Skills](/pt/integrations/coding-agent-skill) fornecem instruções de API. Coloque a pasta completa com `SKILL.md` e referências em `.cursor/skills/tokenlab-api-integration/` e confira **Customize → Skills**. Um Skill não fornece chave nem instala servidor MCP. Consulte os guias oficiais de [MCP](https://cursor.com/docs/mcp) e [Skills](https://cursor.com/docs/skills) para sua versão.
