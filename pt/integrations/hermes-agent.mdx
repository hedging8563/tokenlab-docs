```text

https://docs.tokenlab.sh/pt/integrations/hermes-agent
```

## Instalar ou verificar Hermes

O [guia oficial](https://hermes-agent.nousresearch.com/docs/getting-started/installation) oferece instaladores desktop para macOS Apple Silicon e Windows, além da CLI para Linux e Windows nativo. Confira os requisitos; pule a instalação se já tiver Hermes.

## Opcional: configuração reversível

O TokenLab Skills **0.1.3** inclui um assistente para o Hermes oficial **0.21.3**. Ele apresenta e salva uma cópia da alteração, adicionando apenas um provedor nomeado. Preserva comentários YAML, contas, modelo padrão e permissões. Leia primeiro a [referência](https://github.com/hedging8563/tokenlab-skills/blob/900de0c4e296c0d2ed00b5d842815ed89c403503/skills/tokenlab-api-integration/references/hermes_setup.md).

Defina `SKILL_DIR` como a pasta instalada `tokenlab-api-integration` e `HERMES_PYTHON` como o Python do diretório mostrado por `hermes --version`: `venv/bin/python` no macOS/Linux ou `venv\Scripts\python.exe` no Windows. No PowerShell, use `$SkillDir` e `$HermesPython`. O assistente reutiliza esse ambiente sem instalar pacotes Python globais.

```bash
"$HERMES_PYTHON" "$SKILL_DIR/scripts/configure_hermes.py" --model gpt-5.6-luna
"$HERMES_PYTHON" "$SKILL_DIR/scripts/configure_hermes.py" --model gpt-5.6-luna --apply
```

```powershell
& $HermesPython "$SkillDir/scripts/configure_hermes.py" --model gpt-5.6-luna
& $HermesPython "$SkillDir/scripts/configure_hermes.py" --model gpt-5.6-luna --apply
```

Após aplicar, pule a mesclagem manual abaixo e siga o diretório e os comandos exibidos; `active_profile` é detectado. Consultar a configuração não valida a chave. Use `--restore` para visualizar a restauração e acrescente `--apply` para restaurar os bytes originais. Conflitos, edições posteriores, configurações gerenciadas ou WSL interrompem a automação; preserve as configurações e use o caminho manual.

## Configurar um provedor

Use o diretório `HERMES_HOME`, se definido; caso contrário, `~/.hermes` (Windows: `%LOCALAPPDATA%\hermes`). Faça uma cópia de `config.yaml` e mescle as entradas abaixo sem substituir as outras configurações. Escolha um modelo atual com Chat Completions e chamadas de ferramentas.

Faça backup da configuração ativa. Adicione apenas a entrada TokenLab e preserve provedores, contas, modelo padrão e permissões existentes. Se o nome já estiver em uso, escolha outro e ajuste os comandos. Para desfazer, remova apenas a entrada adicionada ou restaure seu backup anterior.

```yaml
providers:
  tokenlab:
    api: https://api.tokenlab.sh/v1
    key_env: TOKENLAB_API_KEY
    transport: chat_completions
    default_model: gpt-5.6-luna
```

Crie uma chave em [Chaves API](https://tokenlab.sh/dashboard/api?tab=keys). Salve-a localmente como `TOKENLAB_API_KEY` no `.env` do diretório Hermes ou no ambiente do processo que o inicia. Não cole a chave em conversas nem no YAML do provedor.

## Verificar antes de enviar

Confira o provedor com `hermes config get providers.tokenlab.api`; o resultado deve ser `https://api.tokenlab.sh/v1`. Preserve a seção `model` existente. Inicie uma nova sessão com o provedor e modelo explícitos abaixo; sem essas opções, o padrão anterior continua em uso. Essa inspeção não valida a chave.

```bash
hermes chat --provider custom:tokenlab --model gpt-5.6-luna
```

Quando quiser usar saldo do TokenLab, envie um texto curto e confira a resposta e seu [registro de solicitação](https://tokenlab.sh/dashboard/runs?section=requests). Depois teste uma ferramenta somente de leitura. Modelos auxiliares e ferramentas opcionais podem ter outros provedores ou chaves.

## Restaurar e resolver problemas

Se o provedor for desconhecido, confira a versão e o [formato atual](https://hermes-agent.nousresearch.com/docs/integrations/providers). Em erros de autenticação, verifique o ambiente e o estado da chave sem exibi-la. Para desfazer, restaure o modelo anterior e remova apenas as entradas TokenLab adicionadas.

MCP e Skills são extensões separadas: o [guia MCP](/pt/integrations/tokenlab-mcp-server) adiciona ferramentas API; o [guia Skill](/pt/integrations/coding-agent-skill), orientações de integração. Não são necessários para este provedor.
