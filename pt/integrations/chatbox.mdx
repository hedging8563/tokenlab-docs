## Visão geral

O Chatbox pode usar o TokenLab através de suas configurações de API compatíveis com OpenAI.

## Configurar o Chatbox

1. Abra **Settings** -> **Model Provider** -> **Add** -> **Add Custom Provider**
2. Defina **Name** como TokenLab e **API Mode** como **OpenAI API Compatible**; depois, clique em **Add**.
3. Insira:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Path**: `/chat/completions`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. Salve e envie uma mensagem de teste curta.

## Modelos recomendados

| Caso de uso | Modelo |
|----------|-------|
| Chat diário | `gpt-5.4-mini` |
| Raciocínio mais forte | `gpt-5.4` ou `gpt-5.5` |
| Saída estilo Claude | `claude-sonnet-5` |
| Fallback rápido | `deepseek-v4-flash` |

## Notas

Se a sua versão do Chatbox já listar o TokenLab como um provedor integrado, selecione-o diretamente. Caso contrário, o caminho do provedor compatível com OpenAI acima é o fallback mais seguro.
