## Visão Geral

O Phoenix pode rastrear requisições do TokenLab por meio da auto-instrumentação do cliente Python da OpenAI configurado com a URL base compatível com OpenAI do TokenLab.

<Note>
**Tipo**: Observabilidade

**Caminho Principal**: Instrumentação do SDK da OpenAI

**Nível de Suporte**: Caminho de rastreamento compatível com OpenAI suportado
</Note>

## Instalação

```bash
pip install arize-phoenix openinference-instrumentation-openai openai
```

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Registrar o Phoenix

Inicie o Phoenix localmente ou use uma implantação existente antes de executar este exemplo. Por padrão, `register()` envia traces ao collector OTLP/gRPC local em `http://localhost:4317`. Para outra implantação, configure o endpoint do collector e a autenticação conforme o [guia do Phoenix](https://arize.com/docs/phoenix/sdk-api-reference/python/arize-phoenix-otel). Instalar o SDK não inicia o collector.

```python
from phoenix.otel import register

tracer_provider = register(
    project_name="tokenlab-app",
    auto_instrument=True,
)
```

## Chamar o TokenLab

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Write a short haiku."}],
)

print(response.choices[0].message.content)
```

## Notas sobre os Endpoints

O Phoenix rastreia o caminho de chamada do SDK da OpenAI. Utilize esta página para chamadas do TokenLab no estilo Chat Completions. Outros endpoints nativos do TokenLab ainda podem ser rastreados se a instrumentação da sua aplicação capturar o cliente que você utiliza para essas requisições.
