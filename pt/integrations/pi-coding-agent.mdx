## Deixar meu agente fazer a configuração

Copie esta tarefa para um agente que já esteja funcionando no seu computador:

```text
Leia este guia e me ajude a conectar Pi ao TokenLab:
https://docs.tokenlab.sh/pt/integrations/pi-coding-agent
Verifique primeiro minha versão instalada e a configuração ativa.
Preserve as contas, os provedores, as permissões e os demais ajustes existentes.
Faça backup dos arquivos locais e mostre as alterações propostas.
Deixe que eu insira localmente as chaves de API necessárias; nunca as solicite, exiba ou cole no chat.
Verifique primeiro se a configuração é carregada corretamente.
Explique separadamente o custo de qualquer teste com requisições pagas antes de executá-lo.
```

## Instalar e configurar Pi

Use a [instalação oficial](https://pi.dev/). O pacote npm é `@earendil-works/pi-coding-agent`. No Windows, consulte a [configuração do shell](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md); o padrão é Git Bash. Pule a instalação se Pi já estiver disponível.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.85.1
pi --version
```

A configuração abaixo foi verificada com **Pi 0.85.1**. Outras versões precisam de verificação própria conforme a documentação oficial.

Faça uma cópia de `~/.pi/agent/models.json` e acrescente `tokenlab` após as entradas existentes em `providers`; crie o arquivo somente se estiver ausente. Um `PI_CODING_AGENT_DIR` não vazio seleciona o diretório de `models.json`. Preserve a ordem dos provedores, `settings.json`, as contas, os campos do modelo padrão e as permissões. Se `tokenlab` já existir na configuração ou nas contas salvas, use outro nome e ajuste o comando. Defina `TOKENLAB_API_KEY` localmente pelo [início rápido](/pt/quickstart) para macOS, Linux, WSL ou Windows PowerShell, nunca no chat.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

O `$` em `"$TOKENLAB_API_KEY"` é obrigatório; sem ele o valor é texto literal. Escolha um modelo atual com Chat Completions e ferramentas. Use seus detalhes para limites e opções de imagens e raciocínio.

Opcional: o [assistente reversível de configuração do Pi](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/pi_setup.md) permite visualizar, aplicar e restaurar o arquivo original com Python 3.11+. O plugin TokenLab Skills **0.1.2** inclui esses scripts; um Skill independente também pode ser usado após a atualização para uma versão que os contenha. Para plugins ou Skills independentes já instalados, siga as [instruções de atualização do README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) e confirme que o script está presente. A configuração manual desta página também funciona sem o assistente.

## Verificar e restaurar

Verifique o carregamento no mesmo terminal e diretório do agente e selecione TokenLab explicitamente para esta sessão. Sem `TOKENLAB_API_KEY`, o provedor pode não aparecer na lista. A lista confirma registro e presença de credenciais, não sua validade ou uma chamada API concluída.

```bash
pi --list-models tokenlab
pi --provider tokenlab --model gpt-5.6-luna
```

Um prompt utiliza saldo TokenLab. Confira a resposta e seu [registro](https://tokenlab.sh/dashboard/runs?section=requests) antes de testar ferramentas. Para desfazer a configuração manual, remova apenas a entrada adicionada, preservando os demais ajustes e contas.

## Skills e MCP

Pi oferece [Skills nativos](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). Instale o [Skill TokenLab](/pt/integrations/coding-agent-skill). MCP exige uma extensão separada; não coloque sua configuração em `models.json`.
