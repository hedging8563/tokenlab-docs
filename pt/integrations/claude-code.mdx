## Visão geral

[Claude Code](https://code.claude.com/docs/en/setup) é a ferramenta CLI oficial da Anthropic para programação assistida por IA. Você pode configurá-la para usar a TokenLab como provedora de API.

## Instalação

A Anthropic agora recomenda o instalador nativo. A instalação via npm ainda existe por compatibilidade, mas está obsoleta upstream.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Se você precisar especificamente do pacote npm, use:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
Não use `sudo npm install -g` para o Claude Code.
</Warning>

## Configuração

Siga as etapas de terminal do [início rápido](/pt/quickstart) para macOS, Linux, WSL ou Windows PowerShell e defina `TOKENLAB_API_KEY` sem gravar a chave no histórico. Inicie o Claude Code nesse terminal. Para uso persistente, utilize um gerenciador local de segredos, sem acrescentar a chave em texto simples ao perfil do shell.

Estas variáveis valem apenas para esta inicialização; a conta, o modelo padrão e as permissões salvas permanecem. Inicie normalmente sem elas para usar a configuração anterior. Não as salve no perfil do shell.

Esta execução usa Claude Code **2.1.263** e autenticação Bearer via `ANTHROPIC_AUTH_TOKEN`. A Base URL não inclui `/v1`. Valores `env` salvos, auxiliares de credenciais, opções de nuvem e políticas gerenciadas podem afetar a autenticação; confira antes de iniciar. Se houver conflito, use o assistente abaixo sem apagar contas ou enfraquecer políticas. Confira modelo e permissões com `/status`.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Opcional: o [assistente reversível de configuração do Claude Code](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md) permite visualizar, aplicar e restaurar o arquivo original com Python 3.11+. O plugin TokenLab Skills **0.1.2** inclui esses scripts; um Skill independente também pode ser usado após a atualização para uma versão que os contenha. Para plugins ou Skills independentes já instalados, siga as [instruções de atualização do README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) e confirme que o script está presente. A configuração manual desta página também funciona sem o assistente.

Salvar ajustes ou listar modelos não verifica a chave nem uma solicitação concluída. Um prompt usa saldo TokenLab. Confira a resposta e seu [registro correspondente](https://tokenlab.sh/dashboard/runs?section=requests) antes de testar ferramentas; solicitações auxiliares também podem ser cobradas.

## Uso

Após a configuração, use o Claude Code normalmente:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Verifique a instalação, se necessário:

```bash
claude --version
claude doctor
```

## Modelos disponíveis

A TokenLab oferece suporte a todos os modelos Claude:

| Modelo | Descrição |
|-------|-------------|
| `claude-opus-4-6` | Mais capaz, raciocínio complexo |
| `claude-sonnet-4-6` | Desempenho equilibrado, excelente para programação |
| `claude-haiku-4-5` | Mais rápido, com boa relação custo-benefício |

## Seleção de modelo

Especifique um modelo com a flag `--model`:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Pensamento estendido

Para tarefas de raciocínio complexo, use modelos com extended thinking:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## Solução de problemas

<AccordionGroup>
  <Accordion title="Erros de conexão">
    Verifique se a URL base é exatamente `https://api.tokenlab.sh` (sem o sufixo `/v1` para requisições no estilo Anthropic).
  </Accordion>

  <Accordion title="API key inválida">
    Certifique-se de que sua API key da TokenLab comece com `sk-` e tenha saldo suficiente.
  </Accordion>


  <Accordion title="Modelo não encontrado">
    Verifique se o nome do modelo está correto. Use o formato `claude-sonnet-4-6`.
  </Accordion>
</AccordionGroup>
