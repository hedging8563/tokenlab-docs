## Visão Geral

O Browser Use pode chamar o TokenLab através do `ChatOpenAILike`, o wrapper de modelo de chat compatível com OpenAI.

<Note>
**Tipo**: Framework de agente de automação de navegador

**Caminho Principal**: Chat Completions compatíveis com OpenAI

**Nível de Suporte**: Caminho compatível com OpenAI suportado
</Note>

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Exemplo

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    add_schema_to_system_prompt=True,
    dont_force_structured_output=True,
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## Notas sobre o Endpoint

Use esta página para fluxos de trabalho do Browser Use que chamam Chat Completions através de um cliente compatível com OpenAI. Se o seu fluxo de trabalho precisar de respostas nativas do TokenLab, Anthropic Messages ou endpoints do Gemini, utilize um caminho de cliente no Browser Use que utilize esse protocolo diretamente.
