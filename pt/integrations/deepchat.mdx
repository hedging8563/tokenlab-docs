## Visão geral

O DeepChat funciona com o TokenLab através de uma configuração de provedor padrão compatível com OpenAI.

<Note>
**Tipo**: Aplicativo de Chat

**Caminho principal**: Completions de chat compatíveis com OpenAI

**Nível de suporte**: Caminho suportado
</Note>

## Configurar o DeepChat

1. Abra **Settings** -> **Model Provider**
2. Adicione ou edite um provedor compatível com OpenAI
3. Insira:
   - **Provider name**: TokenLab
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Adicione um modelo como `gpt-5.4-mini`
5. Salve e teste um chat.

## Opções de modelos

Comece com `gpt-5.4-mini` para um padrão de baixo atrito. Use `claude-sonnet-5`, `gpt-5.4` ou `deepseek-v4-pro` quando a conversa exigir um raciocínio mais robusto.

## Solução de problemas

- Use a URL base, não o caminho completo `/chat/completions`, a menos que o DeepChat solicite explicitamente uma URL de endpoint completa.
- Remova espaços extras da API key.
- Se um modelo não estiver listado, adicione o ID exato do modelo do TokenLab manualmente.
