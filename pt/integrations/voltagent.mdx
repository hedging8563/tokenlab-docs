## Visão Geral

O VoltAgent aceita modelos de linguagem do AI SDK diretamente. Configure um provedor de AI SDK compatível com OpenAI com a URL base `/v1` do TokenLab e passe o modelo selecionado para o seu agente.

<Note>
**Tipo**: Framework de agente TypeScript

**Caminho Principal**: Chat Completions compatíveis com OpenAI via AI SDK

**Nível de Suporte**: Caminho compatível com OpenAI suportado
</Note>

## Instalação

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Provedor de AI SDK Direto

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## Caminho do Model Router

Se o seu snapshot de registro do VoltAgent incluir uma entrada de provedor TokenLab do `models.dev`, configure:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

Em seguida, use a string do modelo do registro, por exemplo `tokenlab/claude-sonnet-5`.

## Notas sobre Endpoints

O caminho direto do AI SDK é a configuração mais explícita. Use as respostas nativas do TokenLab, Anthropic Messages ou endpoints do Gemini apenas quando o seu provedor/cliente de AI SDK selecionado estiver configurado para esse protocolo.
