## Visão Geral

O Cherry Studio pode usar o TokenLab através de um provedor personalizado compatível com OpenAI. Se a sua versão do Cherry Studio incluir o TokenLab no registro de provedores, selecione o TokenLab diretamente.

<Note>
**Tipo**: Aplicativo de Chat

**Caminho Principal**: Chat completions compatíveis com OpenAI

**Caminhos Nativos**: Responses, Anthropic Messages, endpoints compatíveis com Gemini quando expostos pelo cliente
</Note>

## Configurar como um Provedor Personalizado

1. Abra **Settings** -> **Model Provider**
2. Adicione um provedor compatível com OpenAI
3. Insira:
   - **Name**: TokenLab
   - **API Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Adicione um modelo como `gpt-5.4-mini`
5. Conclua **Verify and Enable** no diálogo de configuração. Para configuração manual, salve e confirme que o provedor está ativado.
6. Selecione o modelo adicionado e envie uma mensagem de teste curta.

## Caminho do Registro de Provedores

Quando o TokenLab aparecer como um provedor integrado no Cherry Studio, prefira essa opção. Ele pode conter metadados de endpoint para:

- Chat completions compatíveis com OpenAI
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## Bons Modelos para Começar

Use `gpt-5.4-mini` como modelo padrão e, em seguida, adicione `claude-sonnet-5`, `gemini-3.5-flash` e `deepseek-v4-flash` para uma cobertura mais ampla.
