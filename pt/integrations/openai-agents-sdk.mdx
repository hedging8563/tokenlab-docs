## Visão Geral

O OpenAI Agents SDK pode utilizar o TokenLab através de um cliente compatível com OpenAI e o `OpenAIChatCompletionsModel`.

<Note>
**Tipo**: Python Agent SDK

**Caminho Principal**: Chat completions compatíveis com OpenAI

**Nível de Suporte**: Caminho de chat-completions suportado
</Note>

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
export TOKENLAB_MODEL="gpt-5.4-mini"
```

## Exemplo

```python
import asyncio
import os

from openai import AsyncOpenAI

from agents import Agent, OpenAIChatCompletionsModel, Runner, set_tracing_disabled

client = AsyncOpenAI(
    base_url=os.getenv("TOKENLAB_BASE_URL", "https://api.tokenlab.sh/v1"),
    api_key=os.environ["TOKENLAB_API_KEY"],
)

set_tracing_disabled(disabled=True)


async def main():
    agent = Agent(
        name="Assistant",
        instructions="You are concise and practical.",
        model=OpenAIChatCompletionsModel(
            model=os.getenv("TOKENLAB_MODEL", "gpt-5.4-mini"),
            openai_client=client,
        ),
    )

    result = await Runner.run(agent, "Explain custom model providers in one paragraph.")
    print(result.final_output)


asyncio.run(main())
```

## Escopo

Este caminho utiliza a compatibilidade de Chat Completions. O endpoint nativo de Responses do TokenLab está disponível em `https://api.tokenlab.sh/v1/responses`, mas os recursos do SDK que dependem de semânticas de Responses específicas da OpenAI devem ser verificados com o modelo e o fluxo de trabalho exatos antes do uso em produção.
