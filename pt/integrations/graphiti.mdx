## Visão Geral

O Graphiti oferece suporte a endpoints `/v1` compatíveis com OpenAI por meio do `OpenAIGenericClient`. Aponte esse cliente para o TokenLab e escolha um modelo do TokenLab.

<Note>
**Tipo**: Framework de memória de grafo de conhecimento

**Caminho Principal**: Chat Completions compatíveis com OpenAI

**Nível de Suporte**: Caminho compatível com OpenAI suportado
</Note>

## Ambiente

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Cliente LLM

```python
import os

from graphiti_core.llm_client.config import LLMConfig
from graphiti_core.llm_client.openai_generic_client import OpenAIGenericClient

llm_config = LLMConfig(
    api_key=os.environ["TOKENLAB_API_KEY"],
    model="claude-sonnet-5",
    small_model="gpt-5.4-mini",
    base_url="https://api.tokenlab.sh/v1",
)

llm_client = OpenAIGenericClient(config=llm_config)
```

Passe o `llm_client` para sua instância `Graphiti(...)` juntamente com as configurações do seu banco de dados de grafos e do embedder.

## Notas sobre o Endpoint

O caminho compatível com OpenAI do Graphiti é orientado a chat-completions. Utilize modelos que retornem JSON estruturado de forma confiável para tarefas de extração e deduplicação.
