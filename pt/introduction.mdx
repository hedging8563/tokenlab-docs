## O que é TokenLab?

O TokenLab conecta sua aplicação ou ferramenta de programação a modelos de IA com uma chave API e saldo compartilhado. Escolha um modelo e um formato API compatível; as solicitações são cobradas pelo preço publicado.

## Capacidades Suportadas

Consulte o [catálogo de modelos](https://tokenlab.sh/pt/models) para IDs, disponibilidade, formatos e preços atuais.

| Capacidade | Descrição |
|---|---|
| Chat e raciocínio | Geração de texto, planejamento, ferramentas |
| Visão e multimodal | Compreensão de imagens e chat multimodal |
| Geração e edição de imagens | Texto para imagem e edição de imagens |
| Geração de vídeo | Texto/imagem/referência para vídeo e controle de movimento |
| Áudio e Realtime WebSocket | TTS, transcrição, tradução de áudio e sessões WebSocket em tempo real |
| Embeddings e rerank | Vetorização de texto e reordenação |
| Tradução | Tradução de texto e tradução de fala via WebSocket |
| Música e 3D | Geração de música e assets 3D |
| Worlds | Geração de worlds, polling de status e media assets |
