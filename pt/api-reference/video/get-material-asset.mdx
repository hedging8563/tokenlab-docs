---
title: "Obter Material Asset"
openapi: "/openapi/pt.json GET /v1/videos/assets/{assetId}"
description: "Recupera um material asset da Seedance pelo ID do material asset do TokenLab."
---

Recupere um material asset e inspecione seu status de processamento. O asset pode ser usado para geração de vídeo apenas quando `ready` for `true` e `status` for `ACTIVE`.

Se a geração de vídeo retornar `Seedance material asset not found or not accessible`, verifique se você passou o `id` deste material asset, e não o `group_id` do material.

`project_name` isola recursos dentro da organização autenticada. O padrão é `default`; use o mesmo valor, diferenciando maiúsculas e minúsculas, para grupos e ativos relacionados. Envie-o no corpo JSON para POST/PUT e na consulta para GET/DELETE.

## Exemplo de Requisição

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Exemplo de Resposta

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
