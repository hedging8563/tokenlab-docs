---
title: "Listar Grupos de Ativos de Material"
openapi: "/openapi/pt.json GET /v1/videos/assets/groups"
description: "Lista os grupos de material da Seedance pertencentes à organização atual."
---

Liste os grupos de material pertencentes à organização autenticada. Filtre por `library_type` e `status` para separar grupos de avatares virtuais de grupos de pessoas reais.

Use um `id` retornado ao fazer upload de materiais. Não passe um `group_id` como `material_asset_id` durante a geração de vídeo; a geração requer um `id` de ativo de material.

`project_name` isola recursos dentro da organização autenticada. O padrão é `default`; use o mesmo valor, diferenciando maiúsculas e minúsculas, para grupos e ativos relacionados. Envie-o no corpo JSON para POST/PUT e na consulta para GET/DELETE.

## Exemplo de Requisição

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups?library_type=aigc_avatar&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Exemplo de Resposta

```json
{
  "groups": [
    {
      "id": "group-20260720123456-vrt01",
      "object": "seedance.material_asset_group",
      "project_name": "default",
      "library_type": "aigc_avatar",
      "group_name": "Product references",
      "status": "ACTIVE",
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
