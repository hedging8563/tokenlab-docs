## Visão geral

Solicite o cancelamento com uma chave de API TokenLab Bearer e o ID `cgt-...`. O cancelamento é tentado e só pode ser concluído enquanto a tarefa ainda for cancelável.

Veja também [Modelos de vídeo Seedance 2.0](/pt/guides/seedance-2-video) e [Geração de vídeo](/pt/guides/video-generation).

## Formato da resposta

Uma solicitação de cancelamento bem-sucedida retorna HTTP 200 com corpo vazio. Consulte a tarefa depois se precisar confirmar o status final.

Se a tarefa terminou, falhou, expirou ou deixou de ser cancelável, o endpoint retorna um erro. Consulte a tarefa para confirmar seu estado. Uma tarefa cancelada não tem resultado de vídeo.

## Exemplo

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
