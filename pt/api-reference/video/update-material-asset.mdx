---
title: "Atualizar Ativo de Material"
openapi: "PUT /v1/videos/assets/{assetId}"
description: "Atualiza um ativo de material Seedance pertencente à organização atual."
---

Atualize o nome ou os metadados do material. A URL de origem e o tipo de ativo são fixos após a criação; crie um novo ativo quando o arquivo de origem for alterado.

`project_name` isola recursos dentro da organização autenticada. O padrão é `default`; use o mesmo valor, diferenciando maiúsculas e minúsculas, para grupos e ativos relacionados. Envie-o no corpo JSON para POST/PUT e na consulta para GET/DELETE.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"},"project_name":"default"}'
```
