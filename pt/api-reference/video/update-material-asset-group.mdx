---
title: "Atualizar Grupo de Ativos de Material"
openapi: "/openapi/pt.json PUT /v1/videos/assets/groups/{groupId}"
description: "Atualiza um grupo de material Seedance pertencente à organização atual."
---

Atualize o nome de exibição, a descrição ou os metadados de um grupo de material. Para grupos de pessoas reais gerenciados, o mapeamento da pessoa verificada permanece inalterado.

`project_name` isola recursos dentro da organização autenticada. O padrão é `default`; use o mesmo valor, diferenciando maiúsculas e minúsculas, para grupos e ativos relacionados. Envie-o no corpo JSON para POST/PUT e na consulta para GET/DELETE.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos","project_name":"default"}'
```

## Exemplo de Resposta

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
