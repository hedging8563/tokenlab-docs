---
title: "Obter resultado da validação visual"
openapi: "POST /api/v3"
description: "Obtém o grupo de materiais de pessoa real produzido pela validação visual."
---

Consulte esta Action após o fluxo de validação visual H5. Um resultado bem-sucedido retorna o ID do grupo de materiais do TokenLab para a pessoa verificada.

Use a mesma organização autenticada, o mesmo usuário e o mesmo `ProjectName`, diferenciando maiúsculas e minúsculas, usados na criação da sessão.

## Endpoint e autenticação

```text
POST https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

Envie o `BytedToken` retornado por [Criar sessão de validação visual](/pt/api-reference/video/create-visual-validation-session). Se você definiu `ProjectName` na criação, envie aqui o mesmo valor com a mesma capitalização; caso contrário, omita-o ou use `default`.

O resultado pode não estar pronto imediatamente após o callback do navegador. Repita a mesma requisição até `Result.GroupId` ser retornado ou o `BytedToken` de 30 minutos expirar. Repetir uma requisição bem-sucedida com o mesmo token retorna o mesmo `GroupId`.

Use o `GroupId` retornado como `group_id` ao criar materiais `liveness_face`.

## Exemplo de requisição

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"BytedToken":"ZXhhbXBsZS10b2tlbg","ProjectName":"default"}'
```

## Exemplo de resposta

```json
{
  "ResponseMetadata": {
    "RequestId": "req_def456",
    "Action": "GetVisualValidateResult",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "GroupId": "group-20260720123456-real1"
  }
}
```

Os erros usam `ResponseMetadata.Error.Code` e `ResponseMetadata.Error.Message`. Uma resposta bem-sucedida contém `ResponseMetadata` e `Result`; ela não usa a estrutura de resposta das outras APIs `/v1` do TokenLab.
