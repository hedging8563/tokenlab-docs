---
title: "Criar Grupo de Ativos de Material"
openapi: "POST /v1/videos/assets/groups"
description: "Cria um grupo de material de avatar virtual da Seedance."
---

Crie um grupo de material com `library_type: "aigc_avatar"`. Use este endpoint para avatares virtuais, produtos, estilos e outras referências reutilizáveis que não exigem verificação de pessoa real.

Novos grupos de material de pessoa real são criados através da [Criar sessão de validação visual](/pt/api-reference/video/create-visual-validation-session) e não podem ser criados diretamente com este endpoint.

`project_name` isola recursos dentro da organização autenticada. O padrão é `default`; use o mesmo valor, diferenciando maiúsculas e minúsculas, para grupos e ativos relacionados. Envie-o no corpo JSON para POST/PUT e na consulta para GET/DELETE.

## Exemplo de Requisição

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots","project_name":"default"}'
```

## Exemplo de Resposta

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
