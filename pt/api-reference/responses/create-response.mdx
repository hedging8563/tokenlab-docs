title: "Criar Resposta"
openapi: "/openapi/pt.json POST /v1/responses"
description: "Cria uma resposta usando o formato OpenAI Responses API"
---

Use este endpoint quando `accepted_request_formats` nos detalhes do modelo incluir `openai_responses`. As solicitações e respostas usam o formato Responses API. Os campos opcionais e os valores aceitos dependem do modelo escolhido.

## Corpo da Requisição

<ParamField body="model" type="string" required>
  ID do modelo a ser usado. Veja [Models](https://tokenlab.sh/pt/models) para as opções disponíveis.
</ParamField>

<ParamField body="input" type="string | array">
  A entrada é opcional quando a solicitação usa um `prompt` reutilizável ou continua uma resposta armazenada com `previous_response_id`.

  Uma lista de itens de entrada que compõem a conversa.

  Cada item pode ser:
  - `message`: Uma mensagem de conversa com role e content
  - `function_call`: Uma solicitação de chamada de função
  - `function_call_output`: Saída de uma chamada de função

  Para entrada multimodal, `message.content` pode ser uma string simples ou um array de blocos de conteúdo. Para modelos com capacidade de imagem, como variantes GPT-5.6 Terra, envie imagens como blocos `input_image` em vez de incorporar URLs ou strings Base64 diretamente em texto simples.

  Exemplo de blocos de conteúdo:
  - `{ "type": "input_text", "text": "Describe this image" }`
  - `{ "type": "input_image", "image_url": "https://example.com/image.jpg" }`
  - `{ "type": "input_image", "image_url": "data:image/png;base64,..." }`
</ParamField>

<ParamField body="instructions" type="string">
  Instruções do sistema para o modelo (equivalente à mensagem do system).
</ParamField>

<ParamField body="max_output_tokens" type="integer">
  Número máximo de tokens a serem gerados.
</ParamField>

<ParamField body="temperature" type="number">
  Temperatura de amostragem. Os valores aceitos e os padrões dependem do modelo escolhido.
</ParamField>

<ParamField body="tools" type="array">
  Ferramentas que o modelo pode chamar. Os tipos e combinações aceitos dependem do modelo escolhido.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Se true, retorna um fluxo de eventos.
</ParamField>

<ParamField body="previous_response_id" type="string">
  ID de uma resposta anterior para continuar a conversa a partir dela.
</ParamField>

<ParamField body="store" type="boolean" default="true">
  Se a resposta deve ser armazenada para recuperação posterior.
</ParamField>

<ParamField body="background" type="boolean" default="false">
  Solicita execução assíncrona. O suporte depende do modelo escolhido.
</ParamField>

<ParamField body="prompt" type="object">
  Referência a um modelo de prompt reutilizável e suas variáveis.
</ParamField>

<ParamField body="metadata" type="object">
  Metadados para anexar à resposta para fins de rastreamento.
</ParamField>

<ParamField body="text" type="object">
  Configurações de saída de texto. O suporte a `text.format` depende do modelo escolhido.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  Se permite múltiplas chamadas de ferramentas em paralelo.
</ParamField>

<ParamField body="top_p" type="number">
  Parâmetro de amostragem nucleus (0-1).
</ParamField>

<ParamField body="reasoning" type="object">
  As opções de raciocínio, incluindo `effort`, dependem do modelo escolhido.
</ParamField>

## Resposta

<ResponseField name="id" type="string">
  Identificador único da resposta.
</ResponseField>

<ResponseField name="object" type="string">
  Sempre `response`.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Timestamp Unix de quando a resposta foi criada.
</ResponseField>

<ResponseField name="status" type="string">
  Estado da resposta: `queued`, `in_progress`, `completed`, `incomplete`, `failed` ou `cancelled`. Verifique este campo mesmo quando a solicitação HTTP for bem-sucedida.
</ResponseField>

<ResponseField name="output" type="array">
  Lista de itens de saída gerados pelo modelo.
</ResponseField>

<ResponseField name="usage" type="object">
  Estatísticas de uso de tokens.
</ResponseField>

## Endpoints relacionados

- `GET /v1/responses/{id}` recupera uma resposta salva e aceita `include`, `include_obfuscation`, `stream` e `starting_after`.
- `DELETE /v1/responses/{id}` exclui uma resposta salva. Isso não cancela a geração.
- `POST /v1/responses/compact` retorna um objeto `response.compaction`.
- Os endpoints de cancelamento, input-items e input-tokens não estão disponíveis no momento.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "input": [
      {"type": "message", "role": "user", "content": "Hello!"}
    ],
    "max_output_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.responses.create(
    model="gpt-5.6-terra",
    input=[
        {"type": "message", "role": "user", "content": "Hello!"}
    ],
    max_output_tokens=1000
)

print(response.output)
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-5.6-terra",
        "input": []map[string]interface{}{
            {"type": "message", "role": "user", "content": "Hello!"},
        },
        "max_output_tokens": 1000,
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/responses", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result["output"])
}
```

## Exemplo de Entrada Vision

Use modelos com capacidade de imagem colocando imagens dentro de `message.content` como blocos `input_image`. O valor de `image_url` pode ser uma URL pública ou uma data URL em Base64.

```json
{
  "model": "gpt-5.6-terra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Please describe this image."
        },
        {
          "type": "input_image",
          "image_url": "https://example.com/demo.jpg"
        }
      ]
    }
  ]
}
```
