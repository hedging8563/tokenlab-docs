## Visão geral

Exclui um arquivo criado por `/v1/files`. Arquivos Batch e arquivos de referência de imagem criados pela TokenLab retornam um objeto deleted compatível com OpenAI.

Quando a requisição usa o modo de compatibilidade com Anthropic Files, a mesma rota exclui o arquivo no estilo Anthropic do workspace vinculado.

## Observações

- Excluir um arquivo não cancela jobs Batch que já o referenciam.
- file ids ausentes ou não autorizados retornam um erro público not-found sem expor estado de roteamento.
- Exclua arquivos de referência de imagem somente quando nenhuma requisição pendente de edição de imagem precisar deles.

## Exemplo

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
