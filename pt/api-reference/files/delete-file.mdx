## Visão geral

Exclui um arquivo criado por `/v1/files`. Sem cabeçalhos Anthropic, a rota exclui arquivos de lote da TokenLab ou vinculações de arquivos de imagem/referência. Com `anthropic-beta: files-api-2025-04-14`, usa o modo Anthropic Files API para o workspace vinculado.

## Notas

- Excluir um arquivo de lote remove o registro armazenado e impede que futuros trabalhos em lote usem esse ID de arquivo.
- Excluir um arquivo de imagem/referência pede ao provedor selecionado que apague o arquivo e depois remove a vinculação da TokenLab quando o provedor aceita.
- O modo Anthropic Files API requer os mesmos cabeçalhos nativos da Anthropic usados para upload e recuperação.

## Exemplo

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
