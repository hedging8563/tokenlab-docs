## Visão geral

Traduz áudio em qualquer idioma suportado para texto em inglês. Diferentemente da transcrição, este endpoint sempre retorna texto em inglês, independentemente do idioma de entrada.

<Note>
  Este endpoint traduz áudio para inglês. Não envie `language`: a tradução de áudio não aceita esse parâmetro e pode retornar `unsupported_parameter`. Para traduzir texto, use `POST /v1/translations`; `recommended_for=translation` se refere a essa API de texto.
</Note>

## Corpo da requisição

A resposta é retornada ao concluir a tradução. Para áudios longos, configure um tempo limite HTTP de pelo menos `120s`.

<ParamField body="file" type="file" required>
  O arquivo de áudio a ser traduzido. Formatos suportados: `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`. O tamanho máximo do arquivo é 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  ID do modelo de tradução de áudio, como `whisper-1`. Confirme nos detalhes atuais o suporte a `POST /v1/audio/translations`.
</ParamField>

<ParamField body="prompt" type="string">
  Um texto opcional para orientar o estilo do model ou continuar um segmento anterior. Deve estar em inglês.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Formato de saída. Whisper aceita `json`, `text`, `srt`, `verbose_json` e `vtt`; outros modelos podem aceitar um conjunto diferente. Consulte os detalhes do modelo.
</ParamField>

<ParamField body="temperature" type="number">
  Temperatura de amostragem de 0 a 1, apenas para modelos que aceitam esse parâmetro.
</ParamField>

## Resposta

Os campos abaixo descrevem respostas JSON de transcrição ou tradução. `text`, `srt` e `vtt` retornam texto ou legendas sem um objeto JSON. Campos adicionais dependem do modelo e do formato.

<ResponseField name="text" type="string">
  O texto traduzido em inglês.
</ResponseField>

Para o formato `verbose_json`, a resposta também inclui:

<ResponseField name="language" type="string">
  Indicação de idioma fornecida na resposta, quando presente.
</ResponseField>

<ResponseField name="duration" type="number">
  A duração do áudio de entrada em segundos.
</ResponseField>

<ResponseField name="segments" type="array">
  Segmentos do texto traduzido com timestamps.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/translations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "file=@german_audio.mp3" \
  -F "model=whisper-1"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("german_audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.translations.create({
  model: 'whisper-1',
  file: fs.createReadStream('german_audio.mp3')
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/translations');

$file = new CURLFile('german_audio.mp3', 'audio/mpeg', 'german_audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Tradução vs Transcrição

| Recurso | Tradução | Transcrição |
|---------|----------|-------------|
| Idioma de saída | Sempre inglês | Igual ao de entrada |
| Caso de uso | Converter áudio estrangeiro para inglês | Preservar o idioma original |
| Parâmetro `language` | Não se aplica | Dica opcional |
