## Corpo da Requisição

A transcrição pode retornar o texto diretamente ou aceitar uma tarefa assíncrona com HTTP `200`, `id` e `status`. Para uma tarefa aceita, siga `poll_url` ou consulte `/v1/tasks/{id}`. Para áudios longos processados de forma síncrona, permita pelo menos `120s` de espera.

<ParamField body="file" type="file" required>
  Arquivo de áudio para transcrever. Formatos suportados: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. Tamanho máximo do arquivo: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  ID do modelo de transcrição, como `whisper-1` ou `gpt-4o-transcribe`. Consulte as opções atuais com `GET /v1/models?recommended_for=stt`.
</ParamField>

<ParamField body="language" type="string">
  Idioma do áudio no formato ISO-639-1 (por exemplo, `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  Texto opcional para orientar o estilo do modelo ou continuar um segmento anterior.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Formato de saída. Whisper aceita `json`, `text`, `srt`, `verbose_json` e `vtt`; outros modelos podem aceitar um conjunto diferente. Consulte os detalhes do modelo.
</ParamField>

<ParamField body="temperature" type="number">
  Temperatura de amostragem de 0 a 1, apenas para modelos que aceitam esse parâmetro.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  `word` e/ou `segment`, se aceitos pelo modelo. Whisper exige `response_format=verbose_json`. Em multipart, repita `timestamp_granularities[]` para enviar vários valores.
</ParamField>

## Resposta

Os campos abaixo descrevem respostas JSON de transcrição ou tradução. `text`, `srt` e `vtt` retornam texto ou legendas sem um objeto JSON. Campos adicionais dependem do modelo e do formato.

<ResponseField name="text" type="string">
  O texto transcrito.
</ResponseField>

Para `verbose_json`:

<ResponseField name="task" type="string">
  Nome da tarefa quando retornado, como `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  Idioma detectado.
</ResponseField>

<ResponseField name="duration" type="number">
  Duração do áudio em segundos.
</ResponseField>

<ResponseField name="segments" type="array">
  Segmentos da transcrição com timestamps.
</ResponseField>

<ResponseField name="words" type="array">
  Timestamps em nível de palavra (se solicitado).
</ResponseField>

Uma tarefa assíncrona de transcrição aceita retorna os campos abaixo em vez do texto:

<ResponseField name="id" type="string">
  ID da tarefa.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias do identificador da tarefa assíncrona quando disponível.
</ResponseField>

<ResponseField name="status" type="string">
  Status da tarefa: `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling preferencial quando a resposta de criação a fornece.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```

## Tradução

Para traduzir áudio para o inglês, use o endpoint de translations:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
