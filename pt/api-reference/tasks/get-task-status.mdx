## Visão geral

Use este endpoint para polling assíncrono unificado entre tipos de tarefa como geração de vídeo, imagem, música e 3D.

Se uma resposta de criação incluir `poll_url`, chame esse caminho exato. Para workflows assíncronos mais recentes, `poll_url` pode apontar para `/v1/tasks/{id}`.

## Parâmetros de caminho

<ParamField path="id" type="string" required>
  O ID da tarefa retornado pela requisição de criação.
</ParamField>

## Resposta

<Note>
Campos de resultado, erro, timestamps e modelo são retornados quando disponíveis para a tarefa.
</Note>

<ResponseField name="id" type="string">
  Identificador da tarefa.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias do identificador de tarefa assíncrona.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling preferencial quando a resposta de criação a fornece.
</ResponseField>

<ResponseField name="status" type="string">
  Status da tarefa, como `pending`, `processing`, `completed` ou `failed`. Tarefas canceladas são representadas como `failed` com `cancelled: true`.
</ResponseField>

<ResponseField name="cancelled" type="boolean">
  `true` quando uma tarefa assíncrona em fila foi cancelada antes da execução.
</ResponseField>

<ResponseField name="cancellation_status" type="string">
  Marcador de cancelamento. Presente como `cancelled` quando o cancelamento é bem-sucedido.
</ResponseField>

<ResponseField name="data" type="array">
  Para tarefas de imagem concluídas, os resultados de imagem gerados são retornados aqui. Tarefas de imagem retornam URLs em `data[].url`.
</ResponseField>

<ResponseField name="progress" type="number">
  Valor de progresso opcional. Retornado apenas quando houver um progresso real disponível; use `status` para determinar a conclusão.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL do asset resultante quando a tarefa é concluída e produz um vídeo.
</ResponseField>

<ResponseField name="video" type="object">
  Objeto único de vídeo com `url`, `duration`, `width` e `height` quando disponíveis.
</ResponseField>

<ResponseField name="videos" type="array">
  Múltiplos objetos de vídeo quando a tarefa de geração retornar mais de uma saída.
</ResponseField>

<ResponseField name="created" type="integer">
  Timestamp de criação.
</ResponseField>

<ResponseField name="updated" type="integer">
  Timestamp da última atualização.
</ResponseField>

<ResponseField name="model" type="string">
  Modelo usado para a tarefa.
</ResponseField>

<ResponseField name="error" type="string | object">
  Mensagem de erro quando a tarefa falha.
</ResponseField>

## Comportamento de erro

Uma tarefa pública expirada ou indisponível pode retornar `404 async_task_not_found`. Se não for possível confirmar a titularidade para a chave API atual, a resposta será `403 task_not_owned`.

```json
{
  "error": {
    "message": "Task not found or no longer available.",
    "type": "invalid_request_error",
    "code": "async_task_not_found"
  }
}
```

## Exemplos

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

```python Python
import requests

poll_url = "/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
response = requests.get(
    f"https://api.tokenlab.sh{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
const response = await fetch(`https://api.tokenlab.sh${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
