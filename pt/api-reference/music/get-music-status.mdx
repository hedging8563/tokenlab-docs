---
title: "Obter Status da Música"
openapi: "GET /v1/tasks/{id}"
description: "Recupera o status e o resultado de uma tarefa de geração de música"
---

Consulte este endpoint para verificar o status da sua tarefa de geração de música.

<Info>
Se a resposta de criação incluir `poll_url`, priorize essa URL exata para o polling. `id` e `task_id` devem ser tratados como a mesma identidade da tarefa assíncrona.


Uma tarefa pública expirada ou indisponível pode retornar `404 async_task_not_found`. Se não for possível confirmar a titularidade para a chave API atual, a resposta será `403 task_not_owned`.
</Info>

## Parâmetros de Caminho

<ParamField path="id" type="string" required>
  O ID da tarefa de geração de música.
</ParamField>

## Resposta

<ResponseField name="id" type="string">
  ID da tarefa.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias do mesmo ID de tarefa assíncrona, quando retornado.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling preferencial quando a resposta de criação a fornece.
</ResponseField>

<ResponseField name="status" type="string">
  Status da tarefa: `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Valor de progresso opcional. Retornado apenas quando houver um progresso real disponível; use `status` para determinar a conclusão.
</ResponseField>

Os campos dependem da operação. Música pode retornar `audio_url` e `audio_id`; tarefas de letras, `lyrics`; separação, vários arquivos em `data`. `video_url`, título, progresso e outros metadados são opcionais. Verifique a conclusão com `status` e leia os campos realmente retornados.

<ResponseField name="audio_id" type="string">
  ID de áudio opcional para usar com este ID de tarefa em operações posteriores compatíveis.
</ResponseField>

<ResponseField name="data" type="array">
  Lista de saídas opcional, incluindo arquivos de faixas separadas com `audio_url` ou `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  URL para baixar o arquivo de áudio (quando concluído).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL para a versão em vídeo com visualizador (quando concluído).
</ResponseField>

<ResponseField name="title" type="string">
  Título da música gerada.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Letras geradas ou fornecidas.
</ResponseField>

<ResponseField name="error" type="string | object">
  Mensagem de erro (quando houver falha).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
