---
title: "Criar Música"
openapi: "/openapi/pt.json POST /v1/music/generations"
description: "Cria uma tarefa de geração de música usando Suno"
---

Gere música e letras usando IA. Esta é uma API assíncrona. A resposta de criação retorna uma identidade de tarefa e, quando disponível, também pode incluir um `poll_url` preferido.

## Corpo da Requisição

<ParamField body="model" type="string" default="suno_music">
  ID do modelo musical, como `suno-music`. Para gerar somente letras, escolha um modelo cujas operações públicas atuais incluam `lyrics`.
</ParamField>

<ParamField body="prompt" type="string">
  Descrição musical ou texto de substituição. Obrigatório para música, letras, upload-cover, upload-extend e replace-section; opcional para add-instrumental e separação de faixas.
</ParamField>

<ParamField body="title" type="string">
  Título para a música gerada.
</ParamField>

<ParamField body="tags" type="string">
  Tags de estilo (ex: "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  Estilos a evitar. Obrigatório quando `audio_operation` é `add-instrumental`.
</ParamField>

<ParamField body="action" type="string">
  Valor opcional `MUSIC` ou `LYRICS`. Escolha um modelo que aceite a operação pública correspondente; este campo não adiciona geração de letras a um modelo exclusivo de música.
</ParamField>

<ParamField body="mv" type="string">
  Seletor de versão Suno. Obrigatório para geração, upload-cover, upload-extend, add-instrumental e substituição a partir de `audio_url`. Omita em letras, substituição a partir de `task_id` + `audio_id` e separação de faixas. Valores aceitos: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  Defina como `true` para gerar uma saída instrumental sem vocais.
</ParamField>

<ParamField body="audio_url" type="string">
  URL de áudio de referência ou enviado que seja publicamente acessível. Sem `audio_operation`, a TokenLab usa o fluxo upload-cover.
</ParamField>

<ParamField body="audio_operation" type="string">
  Operação de áudio: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation` e `advanced-split` exigem `task_id` + `audio_id`; `advanced-split` também exige `stem_name`. `upload-extend` exige `continue_at` maior que 0. `add-instrumental` exige `audio_url`, `title`, `tags` e `negative_tags`.

  `replace-section` exige `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s` e `full_lyrics`. Escolha exatamente uma origem: `task_id` + `audio_id` ou `audio_url` + `mv`. O intervalo substituído deve durar de 6 a 60 segundos.
</ParamField>

<ParamField body="task_id" type="string">
  ID de uma tarefa de origem da sua organização, para substituir áudio gerado ou separar faixas.
</ParamField>

<ParamField body="audio_id" type="string">
  ID do áudio retornado no resultado da tarefa de origem. Obrigatório junto com `task_id` para substituir áudio gerado ou separar faixas.
</ParamField>

<ParamField body="infill_start_s" type="number">
  Início da substituição em segundos, no mínimo 0. Obrigatório para `replace-section`.
</ParamField>

<ParamField body="infill_end_s" type="number">
  Fim da substituição em segundos. Obrigatório para `replace-section`, de 6 a 60 segundos após `infill_start_s`.
</ParamField>

<ParamField body="full_lyrics" type="string">
  Letra completa da música resultante. Obrigatória para `replace-section`.
</ParamField>

<ParamField body="stem_name" type="string">
  Nome da faixa. Obrigatório para `advanced-split`.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  ID de um clipe anterior para continuar a partir dele.
</ParamField>

<ParamField body="continue_at" type="number">
  Ponto de continuação em segundos. Obrigatório e maior que 0 para `upload-extend`.
</ParamField>

<Note>
`prompt` aceita até 5000 caracteres; `tags` e `negative_tags`, até 1000 cada. As operações e parâmetros aceitos dependem dos detalhes atuais do modelo.
</Note>

## Resposta

<ResponseField name="id" type="string">
  ID da tarefa para consultar o status.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias do mesmo ID de tarefa assíncrona, quando retornado.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL de polling prioritária quando disponível.
</ResponseField>

<ResponseField name="status" type="string">
  Status da tarefa: `pending`, `processing`, `completed` ou `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  Timestamp Unix de criação da tarefa, quando retornado.
</ResponseField>

curl -X POST "https://api.tokenlab.sh/v1/music/generations" \
  -H "Authorization: Bearer sk-your-api-key" \

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
