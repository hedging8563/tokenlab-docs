---
title: "Cancelar Lote"
openapi: "/openapi/pt.json POST /v1/batches/{batch_id}/cancel"
description: "Cancela um trabalho de lote em fila ou em execução."
---

Solicite o cancelamento de um lote na fila ou em execução. A resposta contém o estado atual: o cancelamento pode estar em andamento ou já ter terminado. Um lote já encerrado mantém seu estado final. Se o estado retornado não for final, consulte o lote novamente para verificar o resultado.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Identificador para chamadas seguintes e suporte.</ResponseField>
<ResponseField name="status" type="string">Estado atual do lote. Uma solicitação de cancelamento bem-sucedida nem sempre retorna `cancelling`.</ResponseField>
