---
title: "Gerar Conteúdo via Stream"
openapi: "POST /v1beta/models/{model}:streamGenerateContent"
description: "Realiza o stream da geração de conteúdo usando o formato da API Google Gemini"
---

Versão SSE de Gemini `generateContent`. Os eventos podem conter apenas metadados ou conteúdo intermediário sem `finishReason`. O fluxo termina em EOF sem acrescentar um marcador `[DONE]`.

## Parâmetros de Caminho

<ParamField path="model" type="string" required>
  Nome do modelo (ex: `gemini-2.5-pro`, `gemini-3.5-flash`).
</ParamField>

## Parâmetros de Consulta

<ParamField query="key" type="string">
  Chave de API (alternativa à autenticação via header).
</ParamField>

## Corpo da Requisição

Igual a [Gerar Conteúdo](/pt/api-reference/gemini/generate-content).

O suporte a `generationConfig.candidateCount`, ferramentas, tipos de mídia e outros campos opcionais depende do modelo escolhido.

## Resposta

Retorna um stream de objetos JSON, cada um contendo uma resposta parcial.

<RequestExample>
```bash cURL
curl -N -X POST "https://api.tokenlab.sh/v1beta/models/gemini-2.5-pro:streamGenerateContent?key=sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {
        "parts": [{"text": "Tell me a story"}]
      }
    ]
  }'
```

```python Python
import google.generativeai as genai

genai.configure(
    api_key="sk-your-api-key",
    transport="rest",
    client_options={"api_endpoint": "api.tokenlab.sh"}
)

model = genai.GenerativeModel("gemini-2.5-pro")
response = model.generate_content("Tell me a story", stream=True)

for chunk in response:
    for candidate in chunk.candidates:
        for part in candidate.content.parts:
            if part.text:
                print(part.text, end="")
```

```go Go
package main

import (
    "bufio"
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "contents": []map[string]interface{}{
            {"parts": []map[string]string{{"text": "Tell me a story"}}},
        },
    }

    jsonData, _ := json.Marshal(payload)
    req, _ := http.NewRequest("POST",
        "https://api.tokenlab.sh/v1beta/models/gemini-2.5-pro:streamGenerateContent?key=sk-your-api-key",
        bytes.NewBuffer(jsonData))
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    scanner := bufio.NewScanner(resp.Body)
    for scanner.Scan() {
        fmt.Println(scanner.Text())
    }
}
```

## Exemplo de Entrada de Visão

As solicitações de visão em streaming usam a mesma estrutura `contents[].parts[]` que o endpoint sem streaming.

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Please describe this image." },
        {
          "inline_data": {
            "mime_type": "image/jpeg",
            "data": "/9j/4AAQSkZJRgABAQ..."
          }
        }
      ]
    }
  ]
}
```
