title: "Listar chaves API"
openapi: "GET /v1/management/api-keys"
description: "Lista as chaves API gerenciadas pelo usuário para o token de gerenciamento atual da organização."
---

## Visão Geral

Retorna as chaves API de usuário da organização associada ao token de gerenciamento atual.

## Notas

- Os campos monetários aceitam apenas USD. Entradas em `CNY` foram descontinuadas e retornam `400 currency_retired`.

- As chaves gerenciadas pelo sistema são excluídas.

## Exemplo

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Campos importantes

<ResponseField name="object" type="string">Sempre `list`.</ResponseField>
<ResponseField name="data" type="array">Array de objetos de chave de API.</ResponseField>
<ResponseField name="pagination" type="object">Metadados de paginação com `page`, `limit`, `total` e `totalPages`.</ResponseField>
<ResponseField name="data[].id" type="string">Identificador da chave de API usado em chamadas subsequentes da API de Gerenciamento.</ResponseField>
<ResponseField name="data[].name" type="string">Nome de exibição da chave de API.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">Prefixo de chave não secreto para exibição e suporte.</ResponseField>
<ResponseField name="data[].status" type="string">Um dos valores `active`, `inactive` ou `revoked`.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">Limite de gastos em USD como número JSON para exibição. `null` significa ilimitado.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">Limite de gastos exato em USD como string decimal. `null` significa ilimitado.</ResponseField>
<ResponseField name="data[].used_amount" type="number">Gasto de uso acumulado em USD como número JSON para exibição.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">Gasto de uso acumulado exato em USD como string decimal.</ResponseField>
<ResponseField name="data[].models" type="string[]">Lista de modelos permitidos por chave. Um array vazio significa que não há restrição adicional de modelo no nível da chave.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">Carimbo de data/hora ISO em que a chave expira, ou `null` quando não há expiração.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">Carimbo de data/hora ISO do uso mais recente, ou `null` quando nunca foi usada.</ResponseField>
<ResponseField name="data[].created_at" type="string">Carimbo de data/hora ISO de criação.</ResponseField>
