## Visão Geral

Este endpoint retorna os totais atuais de saldo da organização associada ao token de gerenciamento. Ele usa a mesma referência atual de saldo da organização usada por faturamento e liquidação.

## Notas

- Os campos monetários aceitam apenas USD.

- Os campos monetários são retornados em USD. Use `balance`, `total_recharge` e `total_used` para exibição; use `balance_decimal`, `total_recharge_decimal` e `total_used_decimal` para reconciliação exata.

## Exemplo

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

<ResponseField name="object" type="string">Sempre `organization_balance`.</ResponseField>

<ResponseField name="total_used" type="number">Gasto acumulado de uso da organização em USD como JSON number para exibição.</ResponseField>
