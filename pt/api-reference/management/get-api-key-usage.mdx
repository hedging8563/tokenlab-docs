---
title: "Obter uso da API Key"
openapi: "GET /v1/management/api-keys/{keyId}/usage"
description: "Retorna o detalhamento paginado de uso para uma API Key de usuário."
---

## Visão geral

Este endpoint retorna o detalhamento de uso por API Key sem expor metadata de roteamento físico.

## Parâmetros de consulta

| Parâmetro | Tipo | Padrões / limites | Descrição |
|-----------|------|-------------------|-----------|
| `page` | integer | padrão `1`, mínimo `1` | Número da página começando em 1 |
| `limit` | integer | padrão `50`, mínimo `1`, máximo `100` | Tamanho da página |
| `model` | string | comprimento máximo `100` | Nome do modelo solicitado |
| `modelVendor` | string | comprimento máximo `100` | Fornecedor público do modelo |
| `scene` | enum | - | `chat`, `image`, `audio`, `video`, `embedding`, `rerank`, `translation`, `music`, `3d`, `realtime` |
| `startDate` | string | - | Limite inferior inclusivo; aceita RFC3339 com fuso horário ou `YYYY-MM-DD` |
| `endDate` | string | - | Limite superior inclusivo; aceita RFC3339 com fuso horário ou `YYYY-MM-DD` |

Se `startDate` e `endDate` forem enviados juntos, `startDate` deve ser anterior ou igual a `endDate`.

## Observações

- Os campos monetários aceitam apenas USD. Entradas em `CNY` foram descontinuadas e retornam `400 currency_retired`.

- A resposta é paginada.
- A resposta inclui apenas campos públicos de faturamento e reporting.
- Cada item de usage também pode incluir `billing_transaction_id` depois que a requisição subjacente atingir o estado de liquidação concluída. Use esse valor junto com `request_id` para reconciliação por requisição.
- A metadata de roteamento interno e dos canais físicos permanece oculta de forma intencional.

## Exemplo

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/usage?page=1&limit=20&scene=video&startDate=2026-03-01&endDate=2026-03-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Campos importantes

<ResponseField name="api_key" type="object">Resumo da chave de API com os mesmos campos das respostas de listagem, criação e atualização.</ResponseField>
<ResponseField name="items" type="array">Linhas de uso paginadas.</ResponseField>
<ResponseField name="pagination" type="object">Metadados de paginação com `page`, `limit`, `total` e `totalPages`.</ResponseField>
<ResponseField name="summary" type="object">Totais agregados para os filtros selecionados.</ResponseField>
<ResponseField name="breakdowns" type="object">Detalhamentos agregados para os filtros selecionados.</ResponseField>
<ResponseField name="items[].request_id" type="string | null">Identificador público da solicitação para suporte e conciliação.</ResponseField>
<ResponseField name="items[].billing_transaction_id" type="string | null">ID da transação de cobrança liquidada quando disponível.</ResponseField>
<ResponseField name="items[].model" type="string">Nome do modelo público solicitado.</ResponseField>
<ResponseField name="items[].logical_model" type="string">Modelo público lógico usado para relatórios.</ResponseField>
<ResponseField name="items[].model_vendor" type="string | null">Fornecedor do modelo público.</ResponseField>
<ResponseField name="items[].scene" type="string | null">Cenário da solicitação pública.</ResponseField>
<ResponseField name="items[].usage_unit" type="string">Unidade de uso de cobrança, como `per_token`.</ResponseField>
<ResponseField name="items[].usage_quantity" type="number">Quantidade de uso como número JSON para exibição.</ResponseField>
<ResponseField name="items[].usage_quantity_decimal" type="string">Quantidade de uso exata como string decimal.</ResponseField>
<ResponseField name="items[].prompt_tokens" type="number">Contagem de tokens do prompt.</ResponseField>
<ResponseField name="items[].completion_tokens" type="number">Contagem de tokens de conclusão.</ResponseField>
<ResponseField name="items[].total_tokens" type="number">Contagem total de tokens.</ResponseField>
<ResponseField name="items[].cache_read_tokens" type="number">Contagem de tokens lidos do cache.</ResponseField>
<ResponseField name="items[].cache_write_tokens" type="number">Contagem total de tokens gravados no cache.</ResponseField>
<ResponseField name="items[].cache_write_tokens_5m" type="number">Contagem de tokens de gravação de cache de cinco minutos.</ResponseField>
<ResponseField name="items[].cache_write_tokens_1h" type="number">Contagem de tokens de gravação de cache de uma hora.</ResponseField>
<ResponseField name="items[].cost" type="number">Custo em USD como número JSON para exibição.</ResponseField>
<ResponseField name="items[].cost_decimal" type="string">Custo exato em USD como string decimal.</ResponseField>
<ResponseField name="items[].created_at" type="string">Carimbo de data/hora ISO da linha de uso.</ResponseField>
<ResponseField name="summary.total_requests" type="number">Total de solicitações.</ResponseField>
<ResponseField name="summary.total_cost" type="number">Custo total em USD como número JSON para exibição.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">Custo total exato em USD como string decimal.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">Contagem total de tokens do prompt.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">Contagem total de tokens de conclusão.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">Contagem total de tokens.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">Quantidade de uso agrupada por unidade de uso.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">Detalhamento por modelo público solicitado.</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">Detalhamento por modelo público lógico.</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">Detalhamento por fornecedor do modelo público.</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">Detalhamento por cenário da solicitação pública.</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">Tendência diária de custos.</ResponseField>
