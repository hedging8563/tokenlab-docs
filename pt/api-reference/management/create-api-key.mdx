## Visão geral

Este endpoint cria uma nova API Key `type=user` na organização associada ao token de gerenciamento atual.

## Corpo da requisição

| Campo | Tipo | Padrões / limites | Descrição |
|-------|------|-------------------|-----------|
| `name` | string | opcional, padrão `Default Key`, tamanho `1-50` | Nome de exibição; o servidor remove espaços no início e no fim |
| `limitAmount` | number \| string \| null | `0–100000` USD | `null` significa sem limite; `0` impede gastos. Strings decimais aceitam até 6 casas decimais. Na criação da chave, omitir este campo significa sem limite. |
| `limitCurrency` | enum | padrão `USD` | Apenas USD. Enviar `CNY` retorna `400 currency_retired`. |
| `models` | string[] | padrão `[]` | Allowlist opcional de modelos lógicos |
| `deliveryPolicy` | string \| null | `auto`, `verified`, `official`, `null` | `null` herda a política de entrega do espaço de trabalho. |
| `expiresAt` | string \| null | datetime RFC3339 | `null` significa sem expiração |

## Observações

- Os campos monetários aceitam apenas USD. Entradas em `CNY` foram descontinuadas e retornam `400 currency_retired`.

- O valor completo da API Key aparece apenas uma vez na resposta.
- `models: []` significa que a chave não possui restrição adicional de modelos além da política da organização.
- `limitAmount: 0` cria uma chave válida, mas sem quota utilizável até que seja atualizada.

## Exemplo

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "kling-3.0-video"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>

## Campos importantes

<ResponseField name="key" type="string">Valor secreto completo da chave de API. Ele é retornado apenas uma vez na criação.</ResponseField>
<ResponseField name="id" type="string">Identificador da chave de API usado em chamadas subsequentes da API de Gerenciamento.</ResponseField>
<ResponseField name="name" type="string">Nome de exibição da chave de API.</ResponseField>
<ResponseField name="key_prefix" type="string">Prefixo de chave não secreto para exibição e suporte.</ResponseField>
<ResponseField name="status" type="string">Um dos valores `active`, `inactive`, `suspended` ou `revoked`.</ResponseField>
<ResponseField name="limit_amount" type="number | null">Limite de gastos em USD como número JSON para exibição. `null` significa ilimitado.</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">Limite de gastos exato em USD como string decimal. `null` significa ilimitado.</ResponseField>
<ResponseField name="used_amount" type="number">Gasto de uso acumulado em USD como número JSON para exibição.</ResponseField>
<ResponseField name="used_amount_decimal" type="string">Gasto de uso acumulado exato em USD como string decimal.</ResponseField>
<ResponseField name="models" type="string[]">Lista de modelos permitidos por chave. Um array vazio significa que não há restrição adicional de modelo no nível da chave.</ResponseField>
<ResponseField name="delivery_policy" type="string | null">`auto`, `verified`, `official`, `null`. `null` herda a política de entrega do espaço de trabalho.</ResponseField>
<ResponseField name="expires_at" type="string | null">Carimbo de data/hora ISO em que a chave expira, ou `null` quando não há expiração.</ResponseField>
<ResponseField name="last_used_at" type="string | null">Carimbo de data/hora ISO do uso mais recente, ou `null` quando nunca foi usada.</ResponseField>
<ResponseField name="created_at" type="string">Carimbo de data/hora ISO de criação.</ResponseField>
