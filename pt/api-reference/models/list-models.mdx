---
title: "Listar Modelos"
openapi: "/openapi/pt.json GET /v1/models"
description: "Listar modelos atualmente disponíveis no TokenLab"
---

O catálogo de modelos é público e não requer uma API key. Cada item inclui um resumo das capacidades atuais, preços e formatos de API. Recupere um modelo específico quando precisar de detalhes completos.

## Parâmetros de Consulta

<ParamField query="category" type="string">
  Filtre por `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank` ou `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  Retorne as recomendações atuais para uma tarefa como `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank` ou `translation`.
</ParamField>

<ParamField query="provider" type="string">
  Filtre pelo fabricante do modelo, como `openai`, `anthropic`, `google` ou `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  Filtre por uma tag como `chat`, `image`, `video`, `embedding` ou `translation`.
</ParamField>

## Resposta

<ResponseField name="object" type="string">Sempre `list`.</ResponseField>
<ResponseField name="data" type="array">Modelos com `id`, `owned_by` e um resumo `tokenlab`.</ResponseField>

Campos comuns da lista sob `tokenlab` incluem:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` e `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` e `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial` e `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` quando `recommended_for` é utilizado

Quando `recommended_for` é utilizado, os resultados também podem incluir o status da recomendação e um horário de atualização. Leia a resposta atual em vez de fixar a ordem.

## Exemplo

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```
