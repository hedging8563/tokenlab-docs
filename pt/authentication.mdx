## Chaves de API

Chamadas a modelos e recursos privados exigem uma chave API. Endpoints públicos como `GET /v1/models` e `GET /v1/models/{model}` funcionam sem chave. Uma consulta de descoberta bem-sucedida não valida a chave; siga o guia de início rápido para enviar uma solicitação ao modelo. Use a chave completa salva, não o prefixo da lista.

Para endpoints compatíveis com OpenAI, envie-a como:

```bash
Authorization: Bearer sk-your-api-key
```

Para requisições compatíveis com Anthropic em `/v1/messages`, você também pode usar:

```bash
x-api-key: sk-your-api-key
```

## Tokens de gerenciamento

Os endpoints da API de gerenciamento usam um tipo de token separado:

```bash
Authorization: Bearer mt-your-management-token
```

Use tokens de gerenciamento apenas com `/v1/management/*`. Abra [API → Tokens](https://tokenlab.sh/dashboard/api?tab=tokens) no espaço de trabalho selecionado para criar ou substituir um token. Guarde o token completo com segurança; ele só é exibido uma vez após a criação ou substituição.

<Note>
Tokens de gerenciamento não podem ser usados para inferência de modelos, e chaves de API comuns `sk-...` não podem ser usadas na API de gerenciamento.
</Note>

## Obtendo sua chave de API

1. Faça login no seu [Painel TokenLab](https://tokenlab.sh/dashboard)
2. Abra **API Keys**
3. Crie uma nova chave
4. Dê a ela um nome descritivo
5. Copie-a imediatamente, porque ela é exibida apenas uma vez

<Warning>
- Nunca exponha chaves de API em código client-side
- Nunca faça commit de chaves de API no controle de versão
- Use variáveis de ambiente ou um gerenciador de segredos
- Faça a rotação das chaves periodicamente
- Exclua chaves não utilizadas
</Warning>

## Usando chaves de API

Consulte o [início rápido](/pt/quickstart) para variáveis de ambiente e uma primeira solicitação completa. Use o SDK do [formato API](/pt/guides/api-formats) escolhido e mantenha as chaves no servidor.

## Recursos das chaves de API

### Limites de uso

Você pode definir um limite de uso para cada chave de API:

| Configuração | Descrição |
|---------|-------------|
| **Sem limite** | A chave usa o saldo da sua conta sem restrições |
| **Limite fixo** | A chave para de funcionar após atingir o valor especificado |

### Prefixo da chave

Todas as chaves de API da TokenLab começam com `sk-`.

## Respostas de erro

| Código de status | Tipo | Código | Descrição |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | A chave API está ausente, inválida, inativa ou revogada |
| 401 | `expired_api_key` | `expired_api_key` | A chave API expirou |
| 402 | `insufficient_balance` | `insufficient_balance` | O saldo da conta é insuficiente |
| 402 | `quota_exceeded` | `quota_exceeded` | O limite de uso da chave de API foi atingido |

Exemplo:

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
