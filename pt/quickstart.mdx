## Passo 1: Comece com créditos de teste

<Steps>
  <Step title="Crie uma conta">
    Cadastre-se em [tokenlab.sh](https://tokenlab.sh) usando seu e-mail, Gmail ou conta do GitHub.
  </Step>
  <Step title="Conferir o saldo do workspace">
    Veja o saldo e os créditos de teste disponíveis em [Faturamento](https://tokenlab.sh/dashboard/billing). A solicitação é cobrada pelo preço atual do modelo; adicione fundos se necessário.
  </Step>
  <Step title="Criar e salvar uma chave de API">
    Abra [Chaves de API](https://tokenlab.sh/dashboard/api?tab=keys) no seu espaço de trabalho. Crie uma chave e salve o valor completo imediatamente; ele é exibido apenas uma vez. Se você já salvou uma chave completa, use esse valor. O prefixo exibido ou copiado da lista não autentica requisições.
  </Step>
</Steps>

<Warning>
Mantenha sua chave de API segura. Nunca a exponha em código do lado do cliente ou em repositórios públicos.
</Warning>

## Definir a chave para este terminal

Os comandos não incluem a chave no próprio comando. Ela vale apenas para o terminal atual e seus processos filhos. Em aplicações implantadas, use um gerenciador de segredos.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## Passo 3: Faça sua primeira requisição

Para a maioria das novas integrações, comece com **Chat Completions** em `POST /v1/chat/completions`.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

Salve um exemplo SDK como `quickstart.py`, `quickstart.mjs`, `main.go` ou `quickstart.php` e execute `python quickstart.py`, `node quickstart.mjs`, `go run .` ou `php quickstart.php`. Python, JavaScript e Go usam SDKs oficiais da OpenAI; PHP usa o [cliente comunitário](https://github.com/openai-php/client), com PHP 8.2+.

<Note>
Use `POST /v1/responses` somente quando você precisar explicitamente do comportamento específico de Responses. Alguns campos exclusivos de Responses dependem do modelo selecionado e do caminho roteado.
</Note>
