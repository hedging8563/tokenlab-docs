A maioria das ferramentas se conecta ao TokenLab alterando a chave de API e a URL base. A configuração exata depende do formato de API que a ferramenta pode usar.

| Formato de API | URL base | Clientes comuns |
| --- | --- | --- |
| Chat Completions (Compatível com OpenAI) | `https://api.tokenlab.sh/v1` | SDKs da OpenAI, diversos aplicativos de chat e frameworks |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | Clientes de Responses e ferramentas que usam eventos de Responses |
| Anthropic Messages | `https://api.tokenlab.sh` | SDKs da Anthropic e ferramentas voltadas ao Claude |
| Gemini | `https://api.tokenlab.sh` | Clientes REST e SDKs do Gemini que permitem um host personalizado |

O modelo escolhido deve incluir o mesmo formato em `accepted_request_formats`. Streaming e chamadas de ferramentas também dependem dos recursos do modelo e do cliente. Veja exemplos em [Formatos de API](/pt/guides/api-formats).

## Indicadores de compatibilidade

| Indicador | Significado |
| --- | --- |
| **Compatível** | A configuração do TokenLab na página vinculada usa as opções documentadas do cliente |
| **Compatível com limitações** | A configuração se aplica a funções ou métodos de autenticação específicos; os demais serviços do fornecedor mantêm seus próprios requisitos |

Esses indicadores descrevem a configuração da página vinculada. Os recursos disponíveis também dependem do modelo escolhido e da versão do cliente.

## Consumo em respostas de streaming

Os fluxos de Chat Completions aceitam `stream_options: { include_usage: true }`, que adiciona um último bloco de consumo antes de encerrar o fluxo. A API Responses não oferece `include_usage`; seus fluxos informam o consumo no evento final.

## O que uma chave de API personalizada não substitui

Alguns produtos combinam chamadas ao modelo com recursos hospedados pelo fornecedor. Uma chave do TokenLab pode atender às solicitações de modelo disponíveis nas configurações BYOK, mas não substitui outras assinaturas, serviços de preenchimento automático, funções de conta ou extensões proprietárias.

Se uma atualização alterar a configuração de uma ferramenta, consulte a página de integração atual em vez de copiar um exemplo antigo de variáveis de ambiente.

## Antes de depender de um recurso

- Confirme que a ferramenta permite uma URL base personalizada para o formato necessário.
- Confirme que o modelo inclui esse formato em `accepted_request_formats`.
- Teste streaming e chamadas de ferramentas se seu fluxo de trabalho precisar deles.
- Guarde a chave de API em uma máquina ou servidor confiável.
- Registre o ID da solicitação ao relatar uma falha.
