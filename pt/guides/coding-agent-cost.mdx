---
title: "Otimização de Custos do Agente de Código"
description: "Controlar custos com dados reais de uso"
---

Compare tarefas semelhantes pelo custo final no uso do workspace. Registre modelo, chave API, tokens de entrada, saída e cache, além de solicitações com falha ou repetidas.

Mantenha instruções e contexto focados. Inicie outra sessão quando o histórico não ajudar mais. Configure limites de saída conforme o formato API e deixe espaço suficiente para concluir a tarefa.

Descontos e taxas de acerto de cache não são garantidos. Confira os detalhes atuais do modelo e o uso real do cache. Use chaves API separadas e limites adequados por projeto. Compare o custo por tarefa corretamente concluída, não apenas o preço por token.
