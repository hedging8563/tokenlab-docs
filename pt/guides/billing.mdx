Um saldo TokenLab atende a todos os modelos. Não há assinatura nem gasto mínimo; a cobrança depende do modelo e do uso registrado.

## Preços e opções de entrega

Consulte preços atuais na página do modelo, em `GET /v1/models/{model}/pricing` ou na Pricing API. Não fixe uma tabela copiada no aplicativo. Texto e embeddings podem ser cobrados por tokens de entrada, saída ou cache; mídia também por imagem, segundo, minuto, solicitação ou tarefa.

`TokenLab Verified` usa preços públicos TokenLab; `Official` usa a camada Official baseada nos preços públicos do fabricante. `Auto` prioriza Verified e usa Official quando necessário; cobra uma vez pela opção que entrega o resultado. Console mostra a estimativa máxima antes da confirmação de geração paga e o valor final em Runs e Usage.

[Pricing API](/pt/api-reference/pricing/get-pricing)

## Cobrança assíncrona e registros

Algumas tarefas reservam o custo estimado na criação. Salve ID e `poll_url` e consulte até `completed` ou `failed`. Uma tarefa bem-sucedida é cobrada uma vez e a reserva restante é liberada; se falhar, o valor pendente é liberado ou devolvido.

Respostas compatíveis com OpenAI sem streaming podem incluir `billing_transaction_id` ou `X-Billing-Transaction-ID` após a cobrança. Formatos nativos podem usar apenas o header. Resultados assíncronos ou em streaming podem chegar antes do registro contábil; consulte Usage se o identificador não estiver presente.

Usage mostra modelo, chave, custo e consumo. A tokenização varia por modelo, idioma e mídia; contar caracteres não substitui a cobrança final. Streaming não reduz tokens cobrados. Compare custos finais de tarefas iguais e use limites de saída compatíveis.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Usar Console

Em Console → Billing, escolha o valor e um método mostrado no checkout. O saldo atualiza após confirmação do serviço de pagamento.

Defina limite de gasto ao criar ou editar uma chave em Console → API Keys. Ao atingi-lo, a API retorna `402 Payment Required`.

Configure alertas de saldo em Console → Settings. Para dúvidas, envie Request ID e ID da tarefa a support@tokenlab.sh, nunca a chave API.
