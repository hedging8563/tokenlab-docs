## Tổng Quan

Trả về danh sách API key của người dùng trong tổ chức gắn với token quản lý hiện tại.

## Ghi Chú

- Các trường tiền tệ chỉ hỗ trợ USD. Dữ liệu nhập `CNY` đã bị ngừng hỗ trợ và trả về `400 currency_retired`.

- Các key do hệ thống quản lý sẽ bị loại trừ.

## Ví Dụ

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Các trường quan trọng

<ResponseField name="object" type="string">Luôn là `list`.</ResponseField>
<ResponseField name="data" type="array">Mảng các đối tượng khóa API.</ResponseField>
<ResponseField name="pagination" type="object">Siêu dữ liệu phân trang gồm `page`, `limit`, `total` và `totalPages`.</ResponseField>
<ResponseField name="data[].id" type="string">Mã định danh khóa API dùng trong các lệnh gọi API Quản lý tiếp theo.</ResponseField>
<ResponseField name="data[].name" type="string">Tên hiển thị của khóa API.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">Tiền tố khóa không bí mật để hiển thị và hỗ trợ.</ResponseField>
<ResponseField name="data[].status" type="string">Một trong các giá trị `active`, `inactive` hoặc `revoked`.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">Hạn mức chi tiêu bằng USD dưới dạng số JSON để hiển thị. `null` nghĩa là không giới hạn.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">Hạn mức chi tiêu chính xác bằng USD dưới dạng chuỗi thập phân. `null` nghĩa là không giới hạn.</ResponseField>
<ResponseField name="data[].used_amount" type="number">Chi phí sử dụng tích lũy bằng USD dưới dạng số JSON để hiển thị.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">Chi phí sử dụng tích lũy chính xác bằng USD dưới dạng chuỗi thập phân.</ResponseField>
<ResponseField name="data[].models" type="string[]">Danh sách mô hình được phép cho từng khóa. Mảng rỗng nghĩa là không có hạn chế mô hình bổ sung ở cấp khóa.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">Dấu thời gian ISO khi khóa hết hạn, hoặc `null` nếu không hết hạn.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">Dấu thời gian ISO của lần sử dụng gần nhất, hoặc `null` nếu chưa từng sử dụng.</ResponseField>
<ResponseField name="data[].created_at" type="string">Dấu thời gian ISO khi tạo.</ResponseField>
