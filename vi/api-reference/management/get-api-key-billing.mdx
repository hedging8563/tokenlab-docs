---

## Tổng Quan

Endpoint này trả về các tổng hợp billing theo mức tiêu thụ cho API key đã chọn, bao gồm tổng chi phí, tổng số request, usage theo đơn vị tính phí, các breakdown `by_model`, `by_logical_model`, `by_model_vendor` và `by_scene`, cùng xu hướng chi phí theo ngày.

## Ghi Chú

- Các trường tiền tệ chỉ hỗ trợ USD. Dữ liệu nhập `CNY` đã bị ngừng hỗ trợ và trả về `400 currency_retired`.

- Nạp tiền, hóa đơn và các bản ghi tài chính ở cấp tổ chức sẽ không được đưa vào.

## Ví Dụ

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Các trường quan trọng

<ResponseField name="api_key" type="object">Tóm tắt khóa API với các trường giống như phản hồi liệt kê, tạo và cập nhật.</ResponseField>
<ResponseField name="summary" type="object">Tổng số liệu tổng hợp theo các bộ lọc đã chọn.</ResponseField>
<ResponseField name="breakdowns" type="object">Phân tích tổng hợp theo các bộ lọc đã chọn.</ResponseField>
<ResponseField name="summary.total_requests" type="number">Tổng số yêu cầu.</ResponseField>
<ResponseField name="summary.total_cost" type="number">Tổng chi phí bằng USD dưới dạng số JSON để hiển thị.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">Tổng chi phí chính xác bằng USD dưới dạng chuỗi thập phân.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">Tổng số token prompt.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">Tổng số token hoàn thành.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">Tổng số token.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">Lượng sử dụng được nhóm theo đơn vị sử dụng.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">Phân tích theo mô hình công khai được yêu cầu.</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">Phân tích theo mô hình công khai logic.</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">Phân tích theo nhà cung cấp mô hình công khai.</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">Phân tích theo ngữ cảnh yêu cầu công khai.</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">Xu hướng chi phí hằng ngày.</ResponseField>
