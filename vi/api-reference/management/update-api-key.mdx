## Tổng Quan

Dùng endpoint này để cập nhật tên, giới hạn sử dụng, model được phép, thời hạn hết hạn hoặc trạng thái của một API key người dùng hiện có.

## Thân Yêu Cầu

Phải cung cấp ít nhất một trường.

| Trường | Kiểu | Mặc định / Giới hạn | Ghi chú |
|-------|------|---------------------|------|
| `status` | enum | - | `active`, `inactive`, `revoked` |
| `name` | string | độ dài `1-50` | Tên hiển thị đã cập nhật |
| `limitAmount` | number \| null | tối thiểu `0`, input tối đa `1000000` | `null` = không giới hạn, `0` = quota bằng 0. Giá trị dương được chuẩn hoá thành trần lưu trữ không vượt quá tương đương `100000` USD |
| `limitCurrency` | enum | mặc định `USD` | Chỉ hỗ trợ USD. Gửi `CNY` sẽ trả về `400 currency_retired`. |
| `models` | string[] | - | Danh sách cho phép model đã cập nhật |
| `expiresAt` | string \| null | datetime RFC3339 | `null` sẽ xoá thời hạn hết hạn |

## Ghi Chú

- Các trường tiền tệ chỉ hỗ trợ USD. Dữ liệu nhập `CNY` đã bị ngừng hỗ trợ và trả về `400 currency_retired`.

- Hard delete không được hỗ trợ trong Management API v1.
- `revoked` là trạng thái kết thúc đối với thao tác vận hành thông thường; hãy tạo key mới thay vì mong đợi có luồng khôi phục sau này.

## Ví Dụ

<RequestExample>
```bash cURL
curl -X PATCH "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>

## Các trường quan trọng

<ResponseField name="id" type="string">Mã định danh khóa API dùng trong các lệnh gọi API Quản lý tiếp theo.</ResponseField>
<ResponseField name="name" type="string">Tên hiển thị của khóa API.</ResponseField>
<ResponseField name="key_prefix" type="string">Tiền tố khóa không bí mật để hiển thị và hỗ trợ.</ResponseField>
<ResponseField name="status" type="string">Một trong các giá trị `active`, `inactive` hoặc `revoked`.</ResponseField>
<ResponseField name="limit_amount" type="number | null">Hạn mức chi tiêu bằng USD dưới dạng số JSON để hiển thị. `null` nghĩa là không giới hạn.</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">Hạn mức chi tiêu chính xác bằng USD dưới dạng chuỗi thập phân. `null` nghĩa là không giới hạn.</ResponseField>
<ResponseField name="used_amount" type="number">Chi phí sử dụng tích lũy bằng USD dưới dạng số JSON để hiển thị.</ResponseField>
<ResponseField name="used_amount_decimal" type="string">Chi phí sử dụng tích lũy chính xác bằng USD dưới dạng chuỗi thập phân.</ResponseField>
<ResponseField name="models" type="string[]">Danh sách mô hình được phép cho từng khóa. Mảng rỗng nghĩa là không có hạn chế mô hình bổ sung ở cấp khóa.</ResponseField>
<ResponseField name="expires_at" type="string | null">Dấu thời gian ISO khi khóa hết hạn, hoặc `null` nếu không hết hạn.</ResponseField>
<ResponseField name="last_used_at" type="string | null">Dấu thời gian ISO của lần sử dụng gần nhất, hoặc `null` nếu chưa từng sử dụng.</ResponseField>
<ResponseField name="created_at" type="string">Dấu thời gian ISO khi tạo.</ResponseField>
