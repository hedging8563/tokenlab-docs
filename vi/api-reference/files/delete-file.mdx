## Tổng quan

Xóa tệp được tạo qua `/v1/files`. Tệp Batch và tệp tham chiếu hình ảnh do TokenLab tạo sẽ trả về đối tượng deleted tương thích OpenAI.

Khi request dùng chế độ tương thích Anthropic Files, cùng route này xóa tệp kiểu Anthropic khỏi workspace đã gắn.

## Ghi chú

- Xóa tệp không hủy các job Batch đã tham chiếu tệp đó.
- file ids không tồn tại hoặc không được phép sẽ trả về lỗi not-found công khai mà không lộ trạng thái định tuyến.
- Chỉ xóa tệp tham chiếu hình ảnh sau khi không còn request chỉnh sửa hình ảnh đang chờ cần đến chúng.

## Ví dụ

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
