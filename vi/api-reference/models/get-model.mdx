---

## Path Parameter

<ParamField path="model" type="string" required>
  ID của model, ví dụ như `gpt-5.4` hoặc `claude-sonnet-4-6`.
</ParamField>

## Response

<ResponseField name="id" type="string">ID của model.</ResponseField>
<ResponseField name="object" type="string">Luôn là `model`.</ResponseField>
<ResponseField name="owned_by" type="string">Nhà sản xuất model.</ResponseField>
<ResponseField name="tokenlab" type="object">
  Thông tin model TokenLab, bao gồm các khả năng, giá cả, đơn vị tính phí, giới hạn ngữ cảnh, các định dạng API được chấp nhận, các thao tác và trạng thái vòng đời.
</ResponseField>

Các trường `tokenlab` phổ biến bao gồm:

- `capabilities`: các khả năng về văn bản, hình ảnh, video, âm thanh và các khả năng khác.
- `pricing`: giá công khai hiện tại.
- `max_input_tokens` và `max_output_tokens`: giới hạn ngữ cảnh và đầu ra.
- `accepted_request_formats`: các định dạng API được hỗ trợ.
- `supported_operations`: các thao tác như chuyển đổi văn bản thành hình ảnh hoặc hình ảnh thành video.
- `lifecycle`: tình trạng sẵn có, ngày phát hành, ngày ngừng hỗ trợ hoặc model thay thế.

Một số model đa phương tiện cũng bao gồm trạng thái đề xuất và thời gian cập nhật. Các đề xuất có thể thay đổi theo tình trạng sẵn có và hiệu suất, vì vậy đừng mã hóa cứng (hard-code) thứ tự của chúng.

## Ví dụ

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.4"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["text"],
    "accepted_request_formats": ["responses", "chat_completions"]
  }
}
```

Một model không xác định sẽ trả về lỗi `404 model_not_found`.
