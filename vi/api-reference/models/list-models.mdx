Danh mục model là công khai và không yêu cầu API key. Mỗi mục bao gồm tóm tắt về các khả năng, giá cả và định dạng API hiện tại. Hãy truy xuất một model cụ thể khi bạn cần thông tin chi tiết đầy đủ.

## Query Parameters

<ParamField query="category" type="string">
  Lọc theo `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank`, hoặc `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  Trả về các đề xuất hiện tại cho một tác vụ như `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank`, hoặc `translation`.
</ParamField>

<ParamField query="provider" type="string">
  Lọc theo nhà sản xuất model, ví dụ như `openai`, `anthropic`, `google`, hoặc `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  Lọc theo thẻ (tag) như `chat`, `image`, `video`, `embedding`, hoặc `translation`.
</ParamField>

## Response

<ResponseField name="object" type="string">Luôn là `list`.</ResponseField>
<ResponseField name="data" type="array">Các model với `id`, `owned_by`, và tóm tắt `tokenlab`.</ResponseField>

Các trường danh sách phổ biến trong `tokenlab` bao gồm:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` và `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` và `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial`, và `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` khi sử dụng `recommended_for`

Khi sử dụng `recommended_for`, kết quả có thể bao gồm trạng thái đề xuất và thời gian cập nhật. Hãy đọc phản hồi hiện tại thay vì cố định thứ tự.

## Example

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```
