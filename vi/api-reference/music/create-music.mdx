---
title: "Tạo Nhạc"
openapi: "POST /v1/music/generations"
description: "Tạo một tác vụ tạo nhạc bằng Suno"
---

Tạo nhạc và lời bài hát bằng AI. Đây là một API bất đồng bộ. Phản hồi tạo trả về danh tính tác vụ và, khi có sẵn, cũng có thể bao gồm `poll_url` ưu tiên.

## Nội dung yêu cầu

<ParamField body="model" type="string" default="suno_music">
  ID mô hình âm nhạc, chẳng hạn `suno-music`. Để chỉ tạo lời bài hát, chọn mô hình có thao tác công khai hiện tại bao gồm `lyrics`.
</ParamField>

<ParamField body="prompt" type="string">
  Mô tả âm nhạc hoặc văn bản thay thế. Bắt buộc cho nhạc, lời bài hát, upload-cover, upload-extend và replace-section; tùy chọn cho add-instrumental và tách âm.
</ParamField>

<ParamField body="title" type="string">
  Tiêu đề cho bài hát được tạo.
</ParamField>

<ParamField body="tags" type="string">
  Các thẻ phong cách (ví dụ: "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  Phong cách cần tránh. Bắt buộc khi `audio_operation` là `add-instrumental`.
</ParamField>

<ParamField body="action" type="string">
  Giá trị tùy chọn `MUSIC` hoặc `LYRICS`. Chọn mô hình hỗ trợ thao tác công khai tương ứng; trường này không bổ sung khả năng tạo lời cho mô hình chỉ hỗ trợ nhạc.
</ParamField>

<ParamField body="mv" type="string">
  Bộ chọn phiên bản Suno. Bắt buộc cho tạo nhạc, upload-cover, upload-extend, add-instrumental và thay thế từ `audio_url`. Bỏ qua với lời bài hát, thay thế từ `task_id` + `audio_id` và tách âm. Các giá trị hợp lệ: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  Đặt thành `true` để tạo đầu ra nhạc không lời, không có giọng hát.
</ParamField>

<ParamField body="audio_url" type="string">
  URL âm thanh tham chiếu hoặc đã tải lên có thể truy cập công khai. Nếu không gửi `audio_operation`, TokenLab dùng luồng upload-cover.
</ParamField>

<ParamField body="audio_operation" type="string">
  Thao tác âm thanh: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation` và `advanced-split` yêu cầu `task_id` + `audio_id`; `advanced-split` còn yêu cầu `stem_name`. `upload-extend` yêu cầu `continue_at` lớn hơn 0. `add-instrumental` yêu cầu `audio_url`, `title`, `tags` và `negative_tags`.

  `replace-section` yêu cầu `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s` và `full_lyrics`. Chọn đúng một nguồn: `task_id` + `audio_id`, hoặc `audio_url` + `mv`. Khoảng thay thế phải dài 6–60 giây.
</ParamField>

<ParamField body="task_id" type="string">
  ID tác vụ nguồn thuộc tổ chức của bạn, dùng để thay thế âm thanh đã tạo hoặc tách âm.
</ParamField>

<ParamField body="audio_id" type="string">
  ID âm thanh trả về trong kết quả tác vụ nguồn. Cần đi cùng `task_id` khi thay thế âm thanh đã tạo hoặc tách âm.
</ParamField>

<ParamField body="infill_start_s" type="number">
  Thời điểm bắt đầu thay thế, tính bằng giây, ít nhất 0. Bắt buộc cho `replace-section`.
</ParamField>

<ParamField body="infill_end_s" type="number">
  Thời điểm kết thúc thay thế tính bằng giây. Bắt buộc cho `replace-section`, sau `infill_start_s` từ 6 đến 60 giây.
</ParamField>

<ParamField body="full_lyrics" type="string">
  Toàn bộ lời bài hát của kết quả. Bắt buộc cho `replace-section`.
</ParamField>

<ParamField body="stem_name" type="string">
  Tên phần âm cần tách. Bắt buộc cho `advanced-split`.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  ID của một clip trước đó để tiếp tục.
</ParamField>

<ParamField body="continue_at" type="number">
  Thời điểm nối tiếp tính bằng giây. Bắt buộc và lớn hơn 0 với `upload-extend`.
</ParamField>

<Note>
`prompt` tối đa 5000 ký tự; `tags` và `negative_tags` mỗi trường tối đa 1000 ký tự. Thao tác và tham số được hỗ trợ tùy thuộc chi tiết hiện tại của mô hình.
</Note>

## Phản hồi

<ResponseField name="id" type="string">
  ID tác vụ để kiểm tra trạng thái.
</ResponseField>

<ResponseField name="task_id" type="string">
  Bí danh của cùng ID tác vụ bất đồng bộ, nếu được trả về.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling ưu tiên khi có sẵn.
</ResponseField>

<ResponseField name="status" type="string">
  Trạng thái tác vụ: `pending`, `processing`, `completed`, hoặc `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  Thời gian Unix tạo tác vụ, nếu được trả về.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
