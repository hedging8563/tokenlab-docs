Truy vấn (poll) endpoint này để kiểm tra trạng thái của tác vụ tạo nhạc của bạn.

<Info>
Nếu phản hồi tạo bao gồm `poll_url`, hãy ưu tiên chính URL đó khi polling. `id` và `task_id` nên được coi là cùng một định danh của tác vụ bất đồng bộ.


Tác vụ công khai đã hết hạn hoặc không khả dụng có thể trả `404 async_task_not_found`. Nếu không xác nhận được quyền sở hữu cho API key hiện tại, phản hồi là `403 task_not_owned`.
</Info>

## Tham số Đường dẫn

<ParamField path="id" type="string" required>
  ID của tác vụ tạo nhạc.
</ParamField>

## Phản hồi

<ResponseField name="id" type="string">
  ID của tác vụ.
</ResponseField>

<ResponseField name="task_id" type="string">
  Bí danh của cùng ID tác vụ bất đồng bộ, nếu được trả về.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling ưu tiên khi phản hồi tạo tác vụ cung cấp.
</ResponseField>

<ResponseField name="status" type="string">
  Trạng thái tác vụ: `pending`, `processing`, `completed`, hoặc `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Giá trị tiến độ tùy chọn. Chỉ được trả về khi có giá trị tiến độ thực; hãy dùng `status` để xác định khi tác vụ hoàn tất.
</ResponseField>

Trường kết quả phụ thuộc thao tác. Nhạc có thể trả về `audio_url` và `audio_id`; tác vụ chỉ tạo lời trả về `lyrics`; tách âm có thể trả nhiều tệp trong `data`. `video_url`, tiêu đề, tiến độ và siêu dữ liệu khác là tùy chọn. Dùng `status` để kiểm tra hoàn tất và đọc các trường thực sự được trả về.

<ResponseField name="audio_id" type="string">
  ID âm thanh tùy chọn để dùng cùng ID tác vụ này trong các thao tác tiếp theo được hỗ trợ.
</ResponseField>

<ResponseField name="data" type="array">
  Mảng đầu ra tùy chọn, gồm các tệp âm thanh đã tách với `audio_url` hoặc `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  URL để tải xuống tệp âm thanh (khi hoàn tất).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL dẫn đến phiên bản video với visualizer (khi hoàn tất).
</ResponseField>

<ResponseField name="title" type="string">
  Tiêu đề bài hát được tạo.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Lời bài hát được tạo hoặc được cung cấp.
</ResponseField>

<ResponseField name="error" type="string | object">
  Thông báo lỗi (khi thất bại).
</ResponseField>


```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
