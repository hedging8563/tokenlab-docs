---
title: "Hủy Lô"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "Hủy một công việc lô đang chờ hoặc đang chạy."
---

Yêu cầu hủy lô đang chờ hoặc đang chạy. Phản hồi chứa trạng thái hiện tại: việc hủy có thể đang diễn ra hoặc đã hoàn tất. Lô đã kết thúc giữ nguyên trạng thái cuối cùng. Nếu trạng thái trả về chưa phải trạng thái cuối cùng, hãy truy xuất lại lô để kiểm tra kết quả.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Định danh dùng cho lần gọi tiếp theo và hỗ trợ.</ResponseField>
<ResponseField name="status" type="string">Trạng thái hiện tại của lô. Yêu cầu hủy thành công không phải lúc nào cũng trả về `cancelling`.</ResponseField>
