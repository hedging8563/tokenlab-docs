## Tổng quan

Dùng endpoint này cho các phiên thời gian thực như nhận dạng giọng nói streaming, tổng hợp giọng nói, dịch giọng nói hoặc các mô hình đa phương thức thời gian thực. Yêu cầu `GET` thông thường trả về metadata của endpoint, còn yêu cầu nâng cấp WebSocket sẽ mở một phiên thời gian thực cho mô hình đã chọn.

## Phạm vi hỗ trợ

TokenLab cung cấp endpoint WebSocket thời gian thực tại `GET /v1/realtime` để kiểm tra metadata và upgrade WebSocket. Hãy xem đây là một WebSocket subset: endpoint chỉ chuyển tiếp sự kiện của các mô hình realtime được hỗ trợ và không hỗ trợ các bề mặt REST helper của OpenAI Realtime như tạo phiên, `client_secrets`, API điều khiển cuộc gọi `Calls` hoặc legacy beta session APIs.

Với ứng dụng trình duyệt hoặc di động, hãy giữ API key dài hạn trên server của bạn. Endpoint này không phát hành Realtime client secret ngắn hạn.

<Note>Agent nên dùng `/v1/models` để tìm mô hình hỗ trợ realtime trước khi mở socket.</Note>

## Kết nối

<ParamField query="model" type="string" required>
  ID mô hình realtime. Chọn mô hình có chi tiết model liệt kê hỗ trợ realtime.
</ParamField>

<ParamField header="Authorization" type="string" required>
  API key Bearer. Client WebSocket nên gửi `Authorization: Bearer sk-your-api-key` trong yêu cầu upgrade.
</ParamField>

<RequestExample>
```javascript JavaScript
import WebSocket from 'ws';

const socket = new WebSocket('wss://api.tokenlab.sh/v1/realtime?model=gpt-realtime', {
  headers: { Authorization: 'Bearer sk-your-api-key' }
});

socket.on('open', () => {
  socket.send(JSON.stringify({
    type: 'session.update',
    session: { modalities: ['text', 'audio'] }
  }));
});

socket.on('message', (data) => {
  console.log('realtime event', data.toString());
});
```

```bash cURL
curl "https://api.tokenlab.sh/v1/realtime" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Tin nhắn

TokenLab chuyển tiếp các tin nhắn WebSocket giữa client của bạn và mô hình thời gian thực đã chọn. Hãy dùng định dạng sự kiện được ghi trong tài liệu của mô hình đó và đưa `model` vào query string thay vì vào từng sự kiện.

## Tính phí và đóng kết nối

Phiên được tính phí từ số dư khóa API của bạn: TokenLab giữ trước một khoản ước tính khi bắt đầu, sau đó quyết toán theo mức sử dụng thực tế khi kết thúc và hoàn lại phần chênh lệch.

Đóng socket client khi phiên hoàn tất. Nếu dịch vụ đóng phiên trước, TokenLab sẽ gửi một sự kiện/mã đóng an toàn đến client của bạn khi có thể.
