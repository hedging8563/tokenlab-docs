## Tổng quan

Dịch audio ở bất kỳ ngôn ngữ được hỗ trợ nào thành văn bản tiếng Anh. Không giống như transcription, endpoint này luôn trả về văn bản tiếng Anh bất kể ngôn ngữ đầu vào là gì.

<Note>
  Endpoint này dịch âm thanh sang tiếng Anh. Không gửi `language`; dịch âm thanh không hỗ trợ tham số này và có thể trả về `unsupported_parameter`. Để dịch văn bản, dùng `POST /v1/translations`; `recommended_for=translation` đề cập đến API văn bản đó.
</Note>

## Nội dung yêu cầu

Phản hồi được trả về khi dịch xong. Với âm thanh dài, đặt thời gian chờ HTTP ít nhất `120s`.

<ParamField body="file" type="file" required>
  Tệp audio cần dịch. Các định dạng được hỗ trợ: `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`. Kích thước tệp tối đa là 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  ID mô hình dịch âm thanh, chẳng hạn `whisper-1`. Xác nhận hỗ trợ `POST /v1/audio/translations` trong chi tiết mô hình hiện tại.
</ParamField>

<ParamField body="prompt" type="string">
  Văn bản tùy chọn để định hướng phong cách của model hoặc tiếp tục một đoạn trước đó. Nên là tiếng Anh.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Định dạng đầu ra. Whisper hỗ trợ `json`, `text`, `srt`, `verbose_json` và `vtt`; mô hình khác có thể hỗ trợ tập định dạng khác. Kiểm tra chi tiết mô hình.
</ParamField>

<ParamField body="temperature" type="number">
  Nhiệt độ lấy mẫu từ 0 đến 1, chỉ dành cho mô hình hỗ trợ tham số này.
</ParamField>

## Phản hồi

Các trường dưới đây mô tả phản hồi JSON cho chép lời hoặc dịch. `text`, `srt` và `vtt` trả về văn bản hoặc phụ đề thô thay vì đối tượng JSON. Trường bổ sung phụ thuộc vào mô hình và định dạng đầu ra.

<ResponseField name="text" type="string">
  Văn bản đã dịch bằng tiếng Anh.
</ResponseField>

Đối với định dạng `verbose_json`, phản hồi cũng bao gồm:

<ResponseField name="language" type="string">
  Nhãn ngôn ngữ trong phản hồi, nếu được cung cấp.
</ResponseField>

<ResponseField name="duration" type="number">
  Thời lượng của audio đầu vào tính bằng giây.
</ResponseField>

<ResponseField name="segments" type="array">
  Các đoạn của văn bản đã dịch kèm dấu thời gian.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/translations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "file=@german_audio.mp3" \
  -F "model=whisper-1"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("german_audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.translations.create({
  model: 'whisper-1',
  file: fs.createReadStream('german_audio.mp3')
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/translations');

$file = new CURLFile('german_audio.mp3', 'audio/mpeg', 'german_audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Dịch thuật so với Chuyển lời nói thành văn bản

| Tính năng | Dịch thuật | Transcription |
|---------|-------------|---------------|
| Ngôn ngữ đầu ra | Luôn là tiếng Anh | Giống với đầu vào |
| Trường hợp sử dụng | Chuyển audio tiếng nước ngoài sang tiếng Anh | Giữ nguyên ngôn ngữ gốc |
| Tham số ngôn ngữ | Không áp dụng | Gợi ý tùy chọn |
