## Nội dung Request

Chép lời có thể trả ngay văn bản hoặc chấp nhận tác vụ bất đồng bộ với HTTP `200`, `id` và `status`. Với tác vụ được chấp nhận, theo `poll_url` hoặc truy vấn `/v1/tasks/{id}`. Với âm thanh dài được xử lý đồng bộ, đặt thời gian chờ ít nhất `120s`.

<ParamField body="file" type="file" required>
  Tệp audio cần chép lời. Các định dạng được hỗ trợ: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. Kích thước tệp tối đa: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  ID mô hình chép lời, chẳng hạn `whisper-1` hoặc `gpt-4o-transcribe`. Xem các lựa chọn hiện tại bằng `GET /v1/models?recommended_for=stt`.
</ParamField>

<ParamField body="language" type="string">
  Ngôn ngữ của audio theo định dạng ISO-639-1 (ví dụ: `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  Văn bản tùy chọn để định hướng phong cách của model hoặc tiếp tục một đoạn trước đó.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Định dạng đầu ra. Whisper hỗ trợ `json`, `text`, `srt`, `verbose_json` và `vtt`; mô hình khác có thể hỗ trợ tập định dạng khác. Kiểm tra chi tiết mô hình.
</ParamField>

<ParamField body="temperature" type="number">
  Nhiệt độ lấy mẫu từ 0 đến 1, chỉ dành cho mô hình hỗ trợ tham số này.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  `word` và/hoặc `segment`, nếu mô hình hỗ trợ. Whisper yêu cầu `response_format=verbose_json`. Trong multipart, lặp lại `timestamp_granularities[]` để gửi nhiều giá trị.
</ParamField>

## Phản hồi

Các trường dưới đây mô tả phản hồi JSON cho chép lời hoặc dịch. `text`, `srt` và `vtt` trả về văn bản hoặc phụ đề thô thay vì đối tượng JSON. Trường bổ sung phụ thuộc vào mô hình và định dạng đầu ra.

<ResponseField name="text" type="string">
  Văn bản đã được chép lời.
</ResponseField>

Đối với `verbose_json`:

<ResponseField name="task" type="string">
  Tên tác vụ khi được trả về, chẳng hạn `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  Ngôn ngữ được phát hiện.
</ResponseField>

<ResponseField name="duration" type="number">
  Thời lượng audio tính bằng giây.
</ResponseField>

<ResponseField name="segments" type="array">
  Các đoạn chép lời kèm dấu thời gian.
</ResponseField>

<ResponseField name="words" type="array">
  Dấu thời gian ở cấp độ từ (nếu được yêu cầu).
</ResponseField>

Tác vụ chép lời bất đồng bộ được chấp nhận trả về các trường sau thay vì văn bản:

<ResponseField name="id" type="string">
  ID của tác vụ.
</ResponseField>

<ResponseField name="task_id" type="string">
  Bí danh của mã tác vụ bất đồng bộ khi có sẵn.
</ResponseField>

<ResponseField name="status" type="string">
  Trạng thái tác vụ: `pending`, `processing`, `completed`, hoặc `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL polling ưu tiên khi phản hồi tạo tác vụ cung cấp.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```

## Dịch

Để dịch audio sang tiếng Anh, hãy sử dụng endpoint translations:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
