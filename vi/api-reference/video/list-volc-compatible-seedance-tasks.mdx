## Tổng quan

Liệt kê tác vụ tương thích gần đây trong Workspace đã xác thực bằng TokenLab Bearer API key. Không có `filter.task_ids` thì truy vấn bảy ngày gần nhất; cung cấp ID chính xác sẽ truy vấn trực tiếp các tác vụ đó.

Xem thêm [Mô hình video Seedance 2.0](/vi/guides/seedance-2-video) và [Tạo video](/vi/guides/video-generation).

## Dạng phản hồi

- `page_num`: mặc định `1`, số nguyên từ `1` đến `500`.
- `page_size`: mặc định `20`, số nguyên từ `1` đến `500`.
- `filter.status`: `queued`, `running`, `succeeded`, `failed`, `cancelled`, `expired`.
- `filter.task_ids`: Lặp lại tham số để gửi nhiều ID tác vụ chính xác. Không nối bằng dấu phẩy.
- `filter.model`: Định danh mô hình.
- `filter.service_tier`: `default`, `flex`.

Phản hồi chứa `items` và `total` cho kết quả đã lọc. Mỗi phần tử dùng cấu trúc phản hồi lấy tác vụ. Dùng endpoint lấy tác vụ để cập nhật trạng thái của tác vụ đã biết.

## Ví dụ

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?page_num=1&page_size=20&filter.status=succeeded" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?filter.task_ids=cgt-20260102030405-a1b2c" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
