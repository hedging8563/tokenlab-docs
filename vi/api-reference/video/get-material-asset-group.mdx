openapi: "GET /v1/videos/assets/groups/{groupId}"
description: "Truy xuất một nhóm vật liệu Seedance theo ID nhóm TokenLab."
---

Truy xuất một nhóm vật liệu. `library_type` cho bạn biết nhóm đó là nhóm avatar ảo hay nhóm người thật.

Sử dụng endpoint này trước khi tải lên nếu bạn cần xác nhận rằng nhóm vẫn tồn tại và có `status: "ACTIVE"`.

`project_name` tách biệt tài nguyên trong tổ chức đã xác thực. Mặc định là `default`; dùng cùng một giá trị phân biệt chữ hoa, chữ thường cho nhóm và tài nguyên liên quan. Gửi trong nội dung JSON với POST/PUT và tham số truy vấn với GET/DELETE.

## Ví dụ Yêu cầu

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Ví dụ Phản hồi

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
