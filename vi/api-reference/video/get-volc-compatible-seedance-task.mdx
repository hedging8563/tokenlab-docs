## Tổng quan

Sử dụng ID `cgt-...` được trả về từ lệnh create. Hãy thực hiện polling mỗi vài giây trong khi task ở trạng thái `queued` hoặc `running`. Dừng lại khi task ở trạng thái `succeeded`, `failed`, `cancelled`, hoặc `expired`.

<Warning>
Không sử dụng lại enum task hoặc struct phản hồi v1 thống nhất ở đây. `/v1/tasks/{id}` sử dụng `pending`, `processing`, `completed`, và `failed`; endpoint v3 này sử dụng enum chính thức ở trên. Trong đối tượng JSON v3, `duration` là một chuỗi (string) khi xuất hiện và `error` là trường tùy chọn chứa chi tiết lỗi khi có. Một Go client nghiêm ngặt nên khai báo `Duration` là `string` với thẻ JSON `duration,omitempty`, và dừng lại ở mọi trạng thái kết thúc (terminal status) của v3.
</Warning>

Xem thêm [Mô hình video Seedance 2.0](/vi/guides/seedance-2-video) và [Tạo Video](/vi/guides/video-generation).

## Các giá trị trạng thái

- `queued`: đã chấp nhận và đang chờ chạy.
- `running`: quá trình tạo đang diễn ra.
- `succeeded`: kết quả đã sẵn sàng và `content.video_url` đã xuất hiện.
- `failed`: quá trình tạo thất bại; hãy kiểm tra `error.code` và `error.message`.
- `cancelled`: task đã bị hủy trước khi hoàn thành.
- `expired`: task đã hết hạn trước khi hoàn thành.

## Các trường phản hồi

- `id`: ID task tương thích, bắt đầu bằng `cgt-`.
- `model`: định danh model được phản hồi lại để đảm bảo tính tương thích.
- `status`: một trong các giá trị trạng thái ở trên.
- `content.video_url`: URL video cuối cùng khi thành công.
- `content.last_frame_url`: chỉ xuất hiện khi được yêu cầu và khả dụng.
- `usage`: mức sử dụng token khi khả dụng.
- `created_at` và `updated_at`: dấu thời gian của task.
- `error`: Chi tiết lỗi tùy chọn khi có. Xem `error.code` và `error.message`; không suy ra sự hiện diện của trường chỉ từ `status`.

Phản hồi không bao giờ thêm các trường TokenLab như `progress`, `return_last_frame`, `watermark`, `priority`, hoặc `camera_fixed`.

## Ví dụ

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```json
{
  "id": "cgt-20260102030405-a1b2c",
  "model": "doubao-seedance-2.0",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  },
  "usage": {
    "completion_tokens": 123456
  }
}
```

```go Go
type SeedanceTask struct {
    ID       string `json:"id"`
    Status   string `json:"status"`
    Duration string `json:"duration,omitempty"`
}

func isTerminal(status string) bool {
    switch status {
    case "succeeded", "failed", "cancelled", "expired":
        return true
    default:
        return false
    }
}
```
