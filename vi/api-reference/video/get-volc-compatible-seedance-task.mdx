## Tổng quan

Các endpoint này dành cho nhóm đã dùng cấu trúc tác vụ Seedance kiểu Volc. Xác thực bằng TokenLab Bearer API key. ID tác vụ trả về bắt đầu bằng `cgt-`; hãy polling trạng thái cho đến khi `status` là `succeeded`, `failed`, `cancelled` hoặc `expired`.

<Warning>
Không dùng lại enum trạng thái hoặc struct phản hồi của v1. `/v1/tasks/{id}` dùng `pending`, `processing`, `completed` và `failed`; endpoint này dùng enum v3 ở trên. Trong v3, `duration` là chuỗi khi xuất hiện và `error` chỉ xuất hiện khi thất bại.
</Warning>

Xem thêm [Mô hình video Seedance 2.0](/vi/guides/seedance-2-video) và [Tạo video](/vi/guides/video-generation).

## Dạng phản hồi

Phản hồi dùng `queued`, `running`, `succeeded`, `failed`, `cancelled` hoặc `expired`. Tác vụ thành công trả về `content.video_url`; khi có, phản hồi còn gồm `content.last_frame_url`, các trường tạo chính thức và `usage`. `error` chỉ xuất hiện khi thất bại. Không thêm trường TokenLab như `progress`, `return_last_frame`, `watermark`, `priority` hoặc `camera_fixed`.

## Ví dụ

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
