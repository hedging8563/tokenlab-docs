Thăm dò Action này sau quy trình xác thực trực quan H5. Kết quả thành công trả về ID nhóm tư liệu TokenLab của người đã xác thực.

Sử dụng cùng tổ chức đã xác thực, người dùng và `ProjectName` phân biệt chữ hoa chữ thường đã tạo phiên.

## Endpoint và xác thực

```text
POST https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

Gửi `BytedToken` do [Tạo phiên xác thực trực quan](/vi/api-reference/video/create-visual-validation-session) trả về. Nếu đã đặt `ProjectName` khi tạo, hãy gửi cùng giá trị có phân biệt chữ hoa chữ thường tại đây; nếu không, hãy bỏ qua hoặc dùng `default`.

Kết quả có thể chưa sẵn sàng ngay sau callback của trình duyệt. Hãy thử lại cùng yêu cầu cho đến khi trả về `Result.GroupId` hoặc `BytedToken` hết hạn sau 30 phút. Lặp lại yêu cầu đã thành công với cùng token sẽ trả về cùng `GroupId`.

Dùng `GroupId` được trả về làm `group_id` khi tạo tư liệu `liveness_face`.

## Ví dụ yêu cầu

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"BytedToken":"ZXhhbXBsZS10b2tlbg","ProjectName":"default"}'
```

## Ví dụ phản hồi

```json
{
  "ResponseMetadata": {
    "RequestId": "req_def456",
    "Action": "GetVisualValidateResult",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "GroupId": "group-20260720123456-real1"
  }
}
```

Lỗi dùng `ResponseMetadata.Error.Code` và `ResponseMetadata.Error.Message`. Phản hồi thành công chứa `ResponseMetadata` và `Result`, không dùng cấu trúc phản hồi của những API `/v1` khác của TokenLab.
