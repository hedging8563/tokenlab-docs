Dùng endpoint này khi `accepted_request_formats` trong chi tiết mô hình chứa `openai_responses`. Yêu cầu và phản hồi sử dụng định dạng Responses API. Các trường tùy chọn và giá trị được hỗ trợ phụ thuộc vào mô hình đã chọn.

## Nội dung yêu cầu

<ParamField body="model" type="string" required>
  ID của mô hình để sử dụng. Xem [Models](https://tokenlab.sh/vi/models) để biết các lựa chọn có sẵn.
</ParamField>

<ParamField body="input" type="string | array">
  Có thể bỏ input khi yêu cầu dùng một `prompt` tái sử dụng hoặc tiếp tục phản hồi đã lưu bằng `previous_response_id`.

  Một danh sách các mục đầu vào tạo thành cuộc hội thoại.

  Mỗi mục có thể là:
  - `message`: Một tin nhắn hội thoại với role và content
  - `function_call`: Một yêu cầu gọi hàm
  - `function_call_output`: Kết quả từ một cuộc gọi hàm

  Đối với đầu vào đa phương thức, `message.content` có thể là một chuỗi văn bản thuần hoặc một mảng các khối nội dung. Đối với các mô hình có khả năng xử lý hình ảnh như các biến thể GPT-5.6 Terra, truyền hình ảnh dưới dạng các khối `input_image` thay vì nhúng URL hoặc chuỗi Base64 trực tiếp vào văn bản thuần.

  Ví dụ các khối nội dung:
  - `{ "type": "input_text", "text": "Describe this image" }`
  - `{ "type": "input_image", "image_url": "https://example.com/image.jpg" }`
  - `{ "type": "input_image", "image_url": "data:image/png;base64,..." }`
</ParamField>

<ParamField body="instructions" type="string">
  Hướng dẫn hệ thống cho mô hình (tương đương với system message).
</ParamField>

<ParamField body="max_output_tokens" type="integer">
  Số token tối đa để sinh.
</ParamField>

<ParamField body="temperature" type="number">
  Nhiệt độ lấy mẫu. Các giá trị được hỗ trợ và giá trị mặc định phụ thuộc vào mô hình đã chọn.
</ParamField>

<ParamField body="tools" type="array">
  Các công cụ mô hình có thể gọi. Loại và tổ hợp được hỗ trợ phụ thuộc vào mô hình đã chọn.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  Nếu true, trả về một luồng sự kiện.
</ParamField>

<ParamField body="previous_response_id" type="string">
  ID của một phản hồi trước để tiếp tục cuộc hội thoại từ đó.
</ParamField>

<ParamField body="store" type="boolean" default="true">
  Có lưu phản hồi để truy xuất sau hay không.
</ParamField>

<ParamField body="background" type="boolean" default="false">
  Yêu cầu thực thi bất đồng bộ. Khả năng hỗ trợ phụ thuộc vào mô hình đã chọn.
</ParamField>

<ParamField body="prompt" type="object">
  Tham chiếu đến mẫu prompt có thể tái sử dụng và các biến.
</ParamField>

<ParamField body="metadata" type="object">
  Metadata để đính kèm vào phản hồi cho mục đích theo dõi.
</ParamField>

<ParamField body="text" type="object">
  Cài đặt đầu ra văn bản. Khả năng hỗ trợ `text.format` phụ thuộc vào mô hình đã chọn.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  Cho phép gọi nhiều công cụ song song hay không.
</ParamField>

<ParamField body="top_p" type="number">
  Tham số lấy mẫu Nucleus (0-1).
</ParamField>

<ParamField body="reasoning" type="object">
  Các tùy chọn suy luận, gồm `effort`, phụ thuộc vào mô hình đã chọn.
</ParamField>

## Phản hồi

<ResponseField name="id" type="string">
  Định danh duy nhất cho phản hồi.
</ResponseField>

<ResponseField name="object" type="string">
  Luôn là `response`.
</ResponseField>

<ResponseField name="created_at" type="integer">
  Dấu thời Unix khi phản hồi được tạo.
</ResponseField>

<ResponseField name="status" type="string">
  Trạng thái phản hồi: `queued`, `in_progress`, `completed`, `incomplete`, `failed` hoặc `cancelled`. Kiểm tra trường này ngay cả khi yêu cầu HTTP thành công.
</ResponseField>

<ResponseField name="output" type="array">
  Danh sách các mục đầu ra do mô hình sinh ra.
</ResponseField>

<ResponseField name="usage" type="object">
  Thống kê sử dụng token.
</ResponseField>

## Các endpoint liên quan

- `GET /v1/responses/{id}` lấy phản hồi đã lưu và hỗ trợ `include`, `include_obfuscation`, `stream` và `starting_after`.
- `DELETE /v1/responses/{id}` xóa phản hồi đã lưu. Thao tác này không hủy việc tạo nội dung.
- `POST /v1/responses/compact` trả về đối tượng `response.compaction`.
- Các endpoint hủy, input-items và input-tokens hiện chưa được cung cấp.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "input": [
      {"type": "message", "role": "user", "content": "Hello!"}
    ],
    "max_output_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.responses.create(
    model="gpt-5.6-terra",
    input=[
        {"type": "message", "role": "user", "content": "Hello!"}
    ],
    max_output_tokens=1000
)

print(response.output)
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-5.6-terra",
        "input": []map[string]interface{}{
            {"type": "message", "role": "user", "content": "Hello!"},
        },
        "max_output_tokens": 1000,
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/responses", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result["output"])
}
```

## Ví dụ Đầu vào Thị giác

Sử dụng các mô hình có khả năng xử lý hình ảnh bằng cách đặt hình ảnh bên trong `message.content` dưới dạng các khối `input_image`. Giá trị `image_url` có thể là một URL công khai hoặc một data URL Base64.

```json
{
  "model": "gpt-5.6-terra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Please describe this image."
        },
        {
          "type": "input_image",
          "image_url": "https://example.com/demo.jpg"
        }
      ]
    }
  ]
}
```

```json
{
  "model": "gpt-5.6-terra",
  "input": [
    {
      "type": "message",
      "role": "user",
      "content": [
        {
          "type": "input_text",
          "text": "Please describe this image."
        },
        {
          "type": "input_image",
          "image_url": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ..."
        }
      ]
    }
  ]
}
```
