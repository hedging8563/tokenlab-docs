## Bước 1: Bắt đầu với credits dùng thử

<Steps>
  <Step title="Tạo tài khoản">
    Đăng ký tại [tokenlab.sh](https://tokenlab.sh) bằng email, Gmail hoặc tài khoản GitHub của bạn.
  </Step>
  <Step title="Kiểm tra số dư không gian làm việc">
    Xem số dư và tín dụng dùng thử hiện có trong [Thanh toán](https://tokenlab.sh/dashboard/billing). Yêu cầu được tính phí theo giá hiện tại của mô hình; nạp thêm nếu cần.
  </Step>
  <Step title="Tạo và lưu khóa API">
    Mở [Khóa API](https://tokenlab.sh/dashboard/api?tab=keys) trong không gian làm việc. Tạo khóa và lưu ngay giá trị đầy đủ; giá trị này chỉ hiển thị một lần. Nếu đã lưu một khóa đầy đủ, hãy dùng giá trị đó. Tiền tố hiển thị hoặc sao chép từ danh sách không thể dùng để xác thực yêu cầu.
  </Step>
</Steps>

<Warning>
Giữ khóa API của bạn an toàn. Không bao giờ để lộ nó trong mã phía client hoặc kho lưu trữ công cộng.
</Warning>

## Đặt khóa cho terminal hiện tại

Các lệnh sau không đưa khóa vào nội dung lệnh. Khóa chỉ áp dụng cho terminal hiện tại và các tiến trình con. Khi triển khai ứng dụng, dùng trình quản lý bí mật.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## Bước 3: Thực hiện yêu cầu đầu tiên

Đối với hầu hết các tích hợp mới, bắt đầu với **Chat Completions** qua `POST /v1/chat/completions`.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

Lưu một ví dụ SDK thành `quickstart.py`, `quickstart.mjs`, `main.go` hoặc `quickstart.php`, rồi chạy `python quickstart.py`, `node quickstart.mjs`, `go run .` hoặc `php quickstart.php`. Python, JavaScript và Go dùng SDK chính thức của OpenAI; PHP dùng [client cộng đồng](https://github.com/openai-php/client), yêu cầu PHP 8.2+.

<Note>
Chỉ sử dụng `POST /v1/responses` khi bạn thực sự cần hành vi đặc thù của Responses. Một số trường chỉ dành cho Responses phụ thuộc vào model được chọn và đường dẫn được định tuyến.
</Note>
