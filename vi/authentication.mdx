## API Key

Lời gọi mô hình và tài nguyên riêng tư cần khóa API. Các endpoint công khai như `GET /v1/models` và `GET /v1/models/{model}` không cần khóa. Truy vấn khám phá thành công không xác minh khóa có hoạt động; hãy theo hướng dẫn bắt đầu nhanh để gửi yêu cầu đến mô hình. Hãy dùng khóa đầy đủ đã lưu, không dùng tiền tố trong danh sách.

Đối với các endpoint tương thích OpenAI, gửi nó dưới dạng:

```bash
Authorization: Bearer sk-your-api-key
```

Đối với các yêu cầu `/v1/messages` tương thích Anthropic, bạn cũng có thể sử dụng:

```bash
x-api-key: sk-your-api-key
```

## Token quản lý

Các endpoint của API quản lý sử dụng một loại token riêng:

```bash
Authorization: Bearer mt-your-management-token
```

Chỉ dùng token quản lý với `/v1/management/*`. Mở [API → Tokens](https://tokenlab.sh/dashboard/api?tab=tokens) của không gian làm việc đã chọn để tạo hoặc thay thế token. Hãy lưu token đầy đủ ở nơi an toàn khi nó xuất hiện; token chỉ hiển thị một lần sau khi tạo hoặc thay thế.

<Note>
Token quản lý không dùng được để gọi mô hình, và khóa API thông thường `sk-...` không dùng được cho API quản lý.
</Note>

## Lấy API Key của bạn

1. Đăng nhập vào [TokenLab Dashboard](https://tokenlab.sh/dashboard) của bạn
2. Mở **API Keys**
3. Tạo một key mới
4. Đặt cho nó một tên mang tính mô tả
5. Sao chép ngay lập tức vì nó chỉ được hiển thị một lần

<Warning>
- Không bao giờ để lộ API key trong mã phía client
- Không bao giờ commit API key vào hệ thống quản lý phiên bản
- Sử dụng biến môi trường hoặc trình quản lý secret
- Luân phiên key định kỳ
- Xóa các key không sử dụng
</Warning>

## Sử dụng API Key

Xem [bắt đầu nhanh](/vi/quickstart) để thiết lập biến môi trường và gửi yêu cầu đầu tiên. Dùng SDK phù hợp với [định dạng API](/vi/guides/api-formats) và chỉ giữ khóa ở phía máy chủ.

## Tính năng của API Key

### Giới hạn sử dụng

Bạn có thể đặt giới hạn sử dụng cho từng API key:

| Thiết lập | Mô tả |
|---------|-------------|
| **No Limit** | Key sử dụng số dư tài khoản của bạn mà không có hạn chế |
| **Fixed Limit** | Key ngừng hoạt động sau khi đạt đến số tiền được chỉ định |

### Tiền tố của Key

Tất cả API key của TokenLab đều bắt đầu bằng `sk-`.

## Phản hồi lỗi

| Mã trạng thái | Kiểu | Mã | Mô tả |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | Khóa API bị thiếu, không hợp lệ, không hoạt động hoặc đã bị thu hồi |
| 401 | `expired_api_key` | `expired_api_key` | Khóa API đã hết hạn |
| 402 | `insufficient_balance` | `insufficient_balance` | Số dư tài khoản không đủ |
| 402 | `quota_exceeded` | `quota_exceeded` | Đã đạt đến giới hạn sử dụng của API key |

Ví dụ:

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
