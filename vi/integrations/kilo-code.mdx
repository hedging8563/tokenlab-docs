## Tổng quan

<Note>
**Loại**: tác nhân lập trình cho IDE và CLI

**Đường dẫn chính**: Chat Completions tương thích OpenAI

**Mức hỗ trợ**: đường dẫn nhà cung cấp tùy chỉnh chính thức
</Note>

[Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible) hỗ trợ nhà cung cấp tương thích OpenAI trong tiện ích VS Code và CLI.

## Cài đặt và giao diện

Cài kênh pre-release của **Kilo Code** trong VS Code hoặc cài CLI:

```bash
npm install -g @kilocode/cli
kilo --version
```

Mở **Settings → Providers → Custom provider**.

| Trường | Giá trị |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | TokenLab API Key của bạn |
| Model | `kimi-k3` |

Kilo tự phát hiện mô hình qua `/v1/models`. Sau khi lưu, chọn `tokenlab/kimi-k3`.

## Cấu hình CLI

Lưu Key trong biến môi trường và chỉnh tệp toàn cục đáng tin cậy `~/.config/kilo/kilo.jsonc`:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

Khởi động lại Kilo rồi chạy `kilo models`. `{env:...}` chỉ được phân giải trong cấu hình toàn cục hoặc được quản lý đáng tin cậy. Không ghi Key thật vào cấu hình dự án có thể được đưa lên Git.
