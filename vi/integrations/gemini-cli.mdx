## Tổng quan

Gemini CLI **0.60.0** có tài liệu chính thức về `GOOGLE_GEMINI_BASE_URL` cho xác thực bằng khóa API. Dùng endpoint Gemini gốc của TokenLab với mô hình hiện tại hỗ trợ `gemini_generate_content`. Xem [cấu hình chính thức](https://geminicli.com/docs/reference/configuration/) và [xác thực](https://geminicli.com/docs/get-started/authentication/). Cấu hình này không chuyển thuê bao Google qua TokenLab.

## Cài đặt

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## Cấu hình

Làm theo bước terminal trong [bắt đầu nhanh](/vi/quickstart) cho macOS, Linux, WSL hoặc Windows PowerShell để đặt `TOKENLAB_API_KEY` mà không ghi khóa vào lịch sử lệnh. Mở Gemini CLI từ terminal đó. Khi dùng lâu dài, hãy dùng trình quản lý bí mật cục bộ, không thêm khóa dạng văn bản vào hồ sơ shell.

Giữ nguyên đăng nhập Google và cấu hình hiện tại. Với TokenLab, chọn thư mục gốc chưa dùng như `~/.gemini-tokenlab` (`$HOME` trong PowerShell) rồi tạo `.gemini` bên trong. Sao chép `.gemini/settings.json` và các tệp chính sách cần thiết vào vị trí tương ứng, giữ nguyên quyền, sandbox cùng thiết lập khác. Chỉ hợp nhất trường xác thực dưới đây trong bản sao; tạo tệp nếu chưa có. Không sao chép bộ nhớ OAuth hay xóa thông tin xác thực gốc. Tuân thủ chính sách xác thực được quản lý.

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## Sử dụng

Lệnh dưới đây dùng `~/.gemini-tokenlab/.gemini/settings.json`. Sửa đường dẫn nếu chọn thư mục gốc khác. Xác nhận thư mục làm việc bằng thông báo tin cậy thông thường và giữ chính sách phê duyệt công cụ. Mô hình được chọn rõ ràng cho phiên này.

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Các biến này chỉ áp dụng cho lần khởi chạy này; tài khoản, mô hình mặc định và quyền đã lưu vẫn giữ nguyên. Khởi chạy bình thường không kèm các biến để dùng cấu hình trước đó. Không lưu chúng vào hồ sơ shell.

## Kiểm tra

Lưu thiết lập hoặc liệt kê mô hình không xác nhận khóa hợp lệ hay yêu cầu đã hoàn tất. Prompt dùng số dư TokenLab. Kiểm tra phản hồi và [bản ghi tương ứng](https://tokenlab.sh/dashboard/runs?section=requests) trước khi thử công cụ; yêu cầu phụ cũng có thể được tính phí.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
