## Tổng quan

Chatbox có thể sử dụng TokenLab thông qua các cài đặt API tương thích với OpenAI.

<Note>
**Loại**: Ứng dụng trò chuyện (Chat App)

**Đường dẫn chính**: Hoàn tất trò chuyện (chat completions) tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Đường dẫn được hỗ trợ
</Note>

## Cấu hình Chatbox

1. Mở **Settings** -> **Model Provider** -> **Add** -> **Add Custom Provider**
2. Đặt **Name** là TokenLab và **API Mode** là **OpenAI API Compatible**, rồi nhấp **Add**.
3. Nhập:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Path**: `/chat/completions`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. Lưu và gửi một tin nhắn kiểm tra ngắn.

## Các mô hình được đề xuất

| Trường hợp sử dụng | Mô hình |
|----------|-------|
| Trò chuyện hàng ngày | `gpt-5.4-mini` |
| Suy luận mạnh mẽ hơn | `gpt-5.4` hoặc `gpt-5.5` |
| Đầu ra kiểu Claude | `claude-sonnet-5` |
| Dự phòng nhanh | `deepseek-v4-flash` |

## Ghi chú

Nếu phiên bản Chatbox của bạn đã liệt kê TokenLab là một nhà cung cấp tích hợp sẵn, hãy chọn trực tiếp nhà cung cấp đó. Nếu không, đường dẫn nhà cung cấp tương thích với OpenAI ở trên là phương án dự phòng an toàn nhất.
