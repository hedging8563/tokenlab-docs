## Tổng quan

Open WebUI hỗ trợ các kết nối API tùy chỉnh tương thích với OpenAI. Hãy thêm TokenLab làm điểm cuối (endpoint) OpenAI từ xa tương thích và làm mới danh sách mô hình.

<Note>
**Loại**: Ứng dụng trò chuyện trên web (Web Chat App)

**Đường dẫn chính**: Hoàn tất trò chuyện (chat completions) tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Đường dẫn ứng dụng trò chuyện được hỗ trợ
</Note>

## Kết nối quản trị viên

1. Mở **Admin Panel** -> **Settings** -> **Connections**.
2. Trong khu vực kết nối OpenAI API, hãy thêm một kết nối mới.
3. Đặt URL cơ sở (base URL) thành `https://api.tokenlab.sh/v1`.
4. Đặt API key thành khóa TokenLab của bạn.
5. Lưu kết nối và làm mới các mô hình.

## Các giá trị

| Trường | Giá trị |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Mô hình ví dụ | `gpt-5.4-mini` |

## Các mô hình được đề xuất

- `gpt-5.4-mini` cho trò chuyện thông thường
- `claude-sonnet-5` cho viết lách và suy luận
- `deepseek-v4-pro` cho trò chuyện chuyên sâu về lập trình
- `gemini-3.5-flash` cho các quy trình làm việc đa phương thức nhanh chóng

Để chỉ định ID mô hình thủ công, chỉnh sửa kết nối này và mở **Advanced** → **Model IDs (Filter)**. Thêm chính xác các ID mô hình TokenLab rồi lưu.
