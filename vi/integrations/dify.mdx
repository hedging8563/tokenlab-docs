## Tổng quan

Dùng plugin nhà cung cấp mô hình **OpenAI-API-compatible** để kết nối Dify với TokenLab. Đặt loại mô hình là **LLM**, **Completion mode** là **Chat** và **API Type** là **Chat Completions API**. Hướng dẫn này sử dụng Chat Completions.

<Note>
**Loại**: Framework hoặc Nền tảng

**Lộ trình chính**: Lộ trình chat tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Được hỗ trợ với các giới hạn phạm vi
</Note>

## Điều kiện tiên quyết

- Tài khoản TokenLab có quyền truy cập API
- Dify Cloud hoặc Dify tự lưu trữ (self-hosted)

## Các bước cấu hình

### Bước 1: Lấy API Key của bạn

1. Đăng nhập vào [TokenLab Dashboard](https://tokenlab.sh/dashboard)
2. Mở [API Keys](https://tokenlab.sh/dashboard/api)
3. Tạo hoặc sao chép một API key bắt đầu bằng `sk-`

### Bước 2: Cấu hình nhà cung cấp

<Steps>
  <Step title="Mở Model Providers">
    Trong Dify, đi tới **Settings** → **Model Providers**
  </Step>
  <Step title="Chọn OpenAI-API-compatible">
    Mở **OpenAI-API-compatible**. Nếu chưa có, hãy cài plugin nhà cung cấp mô hình này từ Dify Marketplace. Chọn **Add model** để nhập cài đặt TokenLab.
  </Step>
  <Step title="Nhập cài đặt TokenLab">
    Sử dụng các giá trị sau:

    | Trường | Giá trị |
    |-------|-------|
    | API Key | `sk-your-tokenlab-key` |
    | Model type | LLM |
    | Completion mode | Chat |
    | API Type | Chat Completions API |
    | API Base URL | `https://api.tokenlab.sh/v1` |
  </Step>
  <Step title="Thêm các mô hình">
    Thêm các mô hình bạn muốn sử dụng, ví dụ:
    - `gpt-5.4`
    - `gpt-5.4-mini`
    - `claude-sonnet-5`
    - `claude-opus-4-8`
    - `gemini-3.5-flash`
    - `gemini-3.1-flash-lite`
    - `deepseek-v4-flash`
  </Step>
</Steps>

### Bước 3: Kiểm tra kết nối

1. Chọn một mô hình đã thêm, chẳng hạn `gpt-5.4-mini`.
2. Gửi một prompt kiểm tra
3. Xác nhận Dify nhận được phản hồi hợp lệ

## Embeddings cho Cơ sở tri thức (Knowledge Bases)

Đối với RAG và lập chỉ mục cơ sở tri thức, hãy thêm một mô hình embedding như:
- `text-embedding-3-small`
- `text-embedding-3-large`

Sau đó, đặt nó làm mô hình embedding mặc định trong cơ sở tri thức hoặc cài đặt ứng dụng có liên quan.

## Các vai trò mô hình được đề xuất

| Trường hợp sử dụng | Các mô hình gợi ý |
|----------|------------------|
| Chat mặc định | `gpt-5.4-mini`, `gpt-5.4`, `claude-sonnet-5` |
| Suy luận chuyên sâu | `gpt-5.5`, `gpt-5.4`, `claude-opus-4-8`, `deepseek-v4-pro` |
| Nhanh/Rẻ | `gpt-5.4-mini`, `gemini-3.5-flash`, `deepseek-v4-flash` |
| Embeddings | `text-embedding-3-small`, `text-embedding-3-large` |

## Các phương pháp tốt nhất

<AccordionGroup>
  <Accordion title="Plugin OpenAI là một lựa chọn khác">
    Plugin **OpenAI** riêng biệt có thể dùng cho các mô hình được danh mục của plugin hỗ trợ. Đặt base URL tùy chỉnh là `https://api.tokenlab.sh/v1` và **API Protocol** là **Chat Completions**; giá trị mặc định có thể là Responses. Đây không phải tên cũ của OpenAI-API-compatible và không chấp nhận mọi ID mô hình tùy chỉnh.
  </Accordion>

  <Accordion title="Sử dụng các mô hình rẻ hơn để lặp lại">
    Sử dụng `gpt-5.4-mini`, `gemini-3.5-flash`, hoặc `deepseek-v4-flash` trong khi lặp lại, sau đó chỉ chuyển các luồng công việc nặng hơn sang các mô hình mạnh hơn khi cần thiết.
  </Accordion>

  <Accordion title="Cấu hình này sử dụng Chat Completions">
    Giữ **Completion mode = Chat** và **API Type = Chat Completions API** cho cấu hình này. Responses là một tùy chọn API riêng; hướng dẫn này không cấu hình tùy chọn đó hay kết nối WebSocket.
  </Accordion>
</AccordionGroup>
