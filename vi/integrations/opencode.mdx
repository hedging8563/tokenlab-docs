## Tổng quan



<Note>
**Loại**: Công cụ coding

**Đường chính**: tương thích OpenAI

**Mức hỗ trợ**: Đường được hỗ trợ
</Note>

OpenCode là một trợ lý lập trình AI mã nguồn mở chạy trong terminal của bạn. Công cụ này hỗ trợ nhiều nhà cung cấp LLM và có thể được cấu hình để sử dụng API của TokenLab nhằm truy cập hàng trăm mô hình.

## Cài đặt

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

Xác minh cài đặt:

```bash
opencode --version
```

## Cấu hình

### Bước 1: Thiết lập biến môi trường

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

Để cấu hình vĩnh viễn, thêm vào `~/.bashrc` hoặc `~/.zshrc`:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### Bước 2: Cấu hình OpenCode

Tài liệu hiện tại của OpenCode khuyến nghị cấu hình các nhà cung cấp thông qua `opencode.json` hoặc `opencode.jsonc`. Với TokenLab, hãy sử dụng một nhà cung cấp tùy chỉnh thay vì ghi đè nhà cung cấp `openai` tích hợp sẵn:

Ví dụ dùng định dạng V1 được hỗ trợ. Hợp nhất vào `~/.config/opencode/opencode.json` và giữ nguyên nhà cung cấp cùng quyền. V2 đọc được V1 tương thích nhưng không trộn hai định dạng trong một nhà cung cấp. Xem [hướng dẫn chuyển đổi](https://opencode.ai/v2/docs/migrate-v1/). Kiểm tra `/models`, rồi đối chiếu thử nghiệm trả phí với bản ghi TokenLab. Để hoàn tác, chọn mô hình cũ và chỉ xóa mục này.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
Sử dụng `@ai-sdk/openai-compatible` để tương thích theo kiểu chat-completions. Nếu bạn cần cụ thể một đường dẫn nhà cung cấp được xây dựng trên `/v1/responses`, tài liệu OpenCode khuyến nghị chuyển package sang `@ai-sdk/openai`.
</Note>

## Cách dùng cơ bản

**Khởi động chế độ tương tác:**

```bash
opencode
```

**Chạy với một prompt:**

```bash
opencode run "Explain this codebase"
```

**Chỉ định model:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## Các model khả dụng

| Mô hình | Phù hợp nhất cho |
|-------|----------|
| `gpt-5.6-terra` | Tác vụ phức tạp, kiến trúc code |
| `gpt-5.6-luna` | Sửa lỗi nhanh, truy vấn đơn giản |
| `claude-sonnet-4-6` | Review code, tài liệu |
| `claude-opus-4-6` | Suy luận phức tạp |
| `gemini-3.5-flash` | Phản hồi nhanh |

## Các lệnh phổ biến

**Phân tích code:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**Sinh code:**

```bash
opencode run "Create a REST API with Express"
```

**Review thay đổi:**

```bash
git diff | opencode run "Review these changes"
```

**Sửa lỗi:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## Các lệnh tương tác

| Command | Mô tả |
|---------|-------------|
| `/help` | Hiển thị các lệnh khả dụng |
| `/models` | Chuyển sang một model khác |
| `/clear` | Xóa lịch sử hội thoại |
| `/exit` | Thoát OpenCode |

## Khắc phục sự cố

<AccordionGroup>
  <Accordion title="Lỗi kết nối">
    - Xác minh `options.baseURL` được đặt thành `https://api.tokenlab.sh/v1`
    - Kiểm tra kết nối mạng
    - Thử `curl https://api.tokenlab.sh/v1/models` để kiểm tra
  </Accordion>

  <Accordion title="Xác thực thất bại">
    - Xác minh biến môi trường `TOKENLAB_API_KEY` đã được thiết lập
    - Xác minh `options.apiKey` tham chiếu đến `{env:TOKENLAB_API_KEY}` hoặc một nguồn secret hợp lệ khác
    - Kiểm tra khóa bắt đầu bằng `sk-`
    - Đảm bảo khóa đang hoạt động trong dashboard TokenLab
  </Accordion>

  <Accordion title="Không tìm thấy model">
    - Kiểm tra tên model trong config có khớp chính xác hay không
    - Xác minh tính khả dụng của model tại [tokenlab.sh/en/models](https://tokenlab.sh/vi/models)
  </Accordion>
</AccordionGroup>
