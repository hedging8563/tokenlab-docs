OpenCode là một trợ lý lập trình AI mã nguồn mở chạy trong terminal của bạn. Công cụ này hỗ trợ nhiều nhà cung cấp LLM và có thể được cấu hình để sử dụng API của TokenLab nhằm truy cập hàng trăm mô hình.

## Cài đặt

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

Xác minh cài đặt:

```bash
opencode --version
```

## Cấu hình

### Bước 1: Thiết lập biến môi trường

Làm theo bước terminal trong [bắt đầu nhanh](/vi/quickstart) cho macOS, Linux, WSL hoặc Windows PowerShell để đặt `TOKENLAB_API_KEY` mà không ghi khóa vào lịch sử lệnh. Mở OpenCode từ terminal đó. Khi dùng lâu dài, hãy dùng trình quản lý bí mật cục bộ, không thêm khóa dạng văn bản vào hồ sơ shell.

### Bước 2: Cấu hình OpenCode

Cấu hình dưới đây đã được kiểm tra với **OpenCode 1.18.31**. Các phiên bản khác cần được xác minh riêng theo tài liệu chính thức.

Lưu cấu hình vào tệp riêng `~/.config/opencode/tokenlab.jsonc`. Nếu đã đặt `XDG_CONFIG_HOME`, dùng `opencode/tokenlab.jsonc` trong thư mục đó. Giữ nguyên `opencode.json` / `opencode.jsonc` thông thường, tài khoản, mô hình mặc định và quyền. Tệp riêng chỉ được tải khi lần khởi chạy đó chọn nó bằng `OPENCODE_CONFIG`. Nếu tệp hoặc tên nhà cung cấp đã được dùng, chọn tên khác và sửa lệnh tương ứng.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
Cấu hình này gửi Chat Completions qua `@ai-sdk/openai-compatible`. Kiểm tra hỗ trợ Chat Completions và công cụ cần dùng trong thông tin mô hình hiện tại. Ví dụ không chứng minh khả năng tương thích với giao thức hoặc phiên bản khác.
</Note>

Tùy chọn: [trình cấu hình OpenCode có thể khôi phục](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md) dùng Python 3.11+ để xem trước, áp dụng và khôi phục tệp gốc. Plugin TokenLab Skills **0.1.2** chứa các script này; Skill độc lập cũng dùng được sau khi cập nhật lên phiên bản có chúng. Nếu đã cài plugin hoặc Skill độc lập, làm theo [hướng dẫn cập nhật README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) và kiểm tra script đã có. Các bước thủ công trên trang vẫn dùng được mà không cần trình cấu hình.

## Cách dùng cơ bản

Đặt khóa theo phần bắt đầu nhanh, rồi chỉ tải tệp cho lần khởi chạy này và chọn rõ mô hình. Thay đường dẫn và tên nhà cung cấp tùy chỉnh nếu có. Giữ thiết lập `OPENCODE_CONFIG` hoặc `OPENCODE_CONFIG_CONTENT` có sẵn trong môi trường khởi chạy riêng; cấu hình dự án hoặc được quản lý vẫn có thể được ưu tiên.

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

Danh sách mô hình kiểm tra việc tải cục bộ, không chứng minh khóa hợp lệ hay yêu cầu thực tế thành công. Prompt dùng số dư TokenLab; OpenCode có thể gửi thêm yêu cầu phụ được tính phí riêng, như tạo tiêu đề. Kiểm tra phản hồi và các [bản ghi tương ứng](https://tokenlab.sh/dashboard/runs?section=requests).

Khởi chạy không tải tệp này để dùng thiết lập thông thường. Không lưu `OPENCODE_CONFIG` vào hồ sơ shell chỉ để làm theo hướng dẫn. Khi hoàn tác cấu hình thủ công, chỉ xóa tệp riêng vừa tạo hoặc khôi phục bản sao lưu nếu tệp đã có từ trước.

## Các model khả dụng

| Mô hình | Phù hợp nhất cho |
|-------|----------|
| `gpt-5.6-terra` | Tác vụ phức tạp, kiến trúc code |
| `gpt-5.6-luna` | Sửa lỗi nhanh, truy vấn đơn giản |
| `claude-sonnet-4-6` | Review code, tài liệu |
| `claude-opus-4-6` | Suy luận phức tạp |
| `gemini-3.5-flash` | Phản hồi nhanh |

## Các lệnh phổ biến

**Phân tích code:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**Sinh code:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**Review thay đổi:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**Sửa lỗi:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## Các lệnh tương tác

| Command | Mô tả |
|---------|-------------|
| `/help` | Hiển thị các lệnh khả dụng |
| `/models` | Chuyển sang một model khác |
| `/clear` | Xóa lịch sử hội thoại |
| `/exit` | Thoát OpenCode |

## Khắc phục sự cố

<AccordionGroup>
  <Accordion title="Lỗi kết nối">
    - Xác minh `options.baseURL` được đặt thành `https://api.tokenlab.sh/v1`
    - Kiểm tra kết nối mạng
    - Thử `curl https://api.tokenlab.sh/v1/models` để kiểm tra
  </Accordion>

  <Accordion title="Xác thực thất bại">
    - Xác minh biến môi trường `TOKENLAB_API_KEY` đã được thiết lập
    - Xác minh `options.apiKey` tham chiếu đến `{env:TOKENLAB_API_KEY}` hoặc một nguồn secret hợp lệ khác
    - Kiểm tra khóa bắt đầu bằng `sk-`
    - Đảm bảo khóa đang hoạt động trong dashboard TokenLab
  </Accordion>

  <Accordion title="Không tìm thấy model">
    - Kiểm tra tên model trong config có khớp chính xác hay không
    - Xác minh tính khả dụng của model tại [tokenlab.sh/en/models](https://tokenlab.sh/vi/models)
  </Accordion>
</AccordionGroup>
