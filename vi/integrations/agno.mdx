## Tổng quan

Agno có thể sử dụng TokenLab như một nhà cung cấp mô hình tương thích với OpenAI cho các agent và quy trình làm việc (workflows).

<Note>
**Loại**: Khung làm việc cho Agent (Agent Framework)

**Đường dẫn chính**: Chat completions tương thích với OpenAI

**Mức độ hỗ trợ**: Đường dẫn được hỗ trợ
</Note>

## Môi trường

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Trình bao bọc mô hình TokenLab (Model Wrapper)

Nếu phiên bản Agno của bạn bao gồm trình bao bọc mô hình TokenLab:

```python
from agno.agent import Agent
from agno.models.tokenlab import TokenLab

agent = Agent(model=TokenLab(id="gpt-5.4-mini"))
agent.print_response("Give me a concise project risk checklist.")
```

Một số bản dựng Agno cũng hỗ trợ chuỗi mô hình:

```python
agent = Agent(model="tokenlab:gpt-5.4-mini")
```

## Dự phòng tương thích với OpenAI

Nếu phiên bản của bạn chưa bao gồm TokenLab, hãy sử dụng đường dẫn mô hình tương thích với OpenAI của Agno với:

- Base URL: `https://api.tokenlab.sh/v1`
- API key: `TOKENLAB_API_KEY`
- Model: `gpt-5.4-mini`

## Gợi ý mô hình

Sử dụng `gpt-5.4-mini` cho các agent mặc định, `gpt-5.4` hoặc `claude-sonnet-5` cho các tác vụ suy luận chuyên sâu hơn, và `deepseek-v4-flash` cho các vòng lặp nhanh hơn.
