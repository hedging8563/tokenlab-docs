## Tổng quan

Portkey Gateway có thể định tuyến các yêu cầu đến TokenLab như một nhà cung cấp upstream. Mặc định an toàn nhất là các chat completions tương thích với OpenAI; hãy sử dụng Responses khi phiên bản Portkey của bạn hỗ trợ đường dẫn đó cho TokenLab.

<Note>
**Loại**: AI Gateway

**Các đường dẫn chính**: Chat completions tương thích với OpenAI và Responses

**Độ tin cậy hỗ trợ**: Đường dẫn được hỗ trợ
</Note>

## Các giá trị nhà cung cấp

| Trường | Giá trị |
|-------|-------|
| Provider | `tokenlab` |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | `sk-your-tokenlab-key` |
| Mô hình mặc định | `gpt-5.4-mini` |

## Chat Completions

Sử dụng TokenLab cho các yêu cầu chat tương thích với OpenAI:

```bash
curl https://your-portkey-gateway.example/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-portkey-provider: tokenlab" \
  -H "Authorization: Bearer sk-your-tokenlab-key" \
  -d '{
    "model": "gpt-5.4-mini",
    "messages": [{"role": "user", "content": "Say hello from TokenLab."}]
  }'
```

## Responses

Nếu bản dựng Portkey của bạn định tuyến các Responses của TokenLab, hãy sử dụng `gpt-5.5`, `gpt-5.4` hoặc `gpt-5.4-mini` với `/v1/responses`.

## Lưu ý về Native Endpoint

TokenLab cũng cung cấp trực tiếp các endpoint tương thích với Anthropic Messages và Gemini. Việc liệu các endpoint này có thể được sử dụng thông qua Portkey hay không phụ thuộc vào nhà cung cấp Portkey và khả năng hỗ trợ endpoint trong phiên bản bạn đã triển khai.
