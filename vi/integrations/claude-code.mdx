## Để agent của tôi thiết lập

Sao chép nhiệm vụ này cho một agent đã hoạt động trên máy tính của bạn:

```text
Đọc hướng dẫn này và giúp tôi kết nối Claude Code với TokenLab:
https://docs.tokenlab.sh/vi/integrations/claude-code
Trước tiên, kiểm tra phiên bản đã cài và cấu hình đang có hiệu lực.
Giữ nguyên các tài khoản, nhà cung cấp, quyền và những thiết lập khác hiện có.
Sao lưu các tệp cục bộ và trình bày những thay đổi dự kiến.
Để tôi nhập khóa API cần thiết trên máy của mình; không yêu cầu, hiển thị hoặc dán khóa trong cuộc trò chuyện.
Trước tiên, xác nhận cấu hình tải được bình thường.
Giải thích riêng chi phí của mọi phép thử có gửi yêu cầu trả phí trước khi chạy.
```

## Tổng quan



<Note>
**Loại**: Công cụ coding

**Đường chính**: Anthropic-native

**Mức hỗ trợ**: Đường native mạnh
</Note>

[Claude Code](https://code.claude.com/docs/en/setup) là công cụ CLI chính thức của Anthropic dành cho việc lập trình có hỗ trợ AI. Bạn có thể cấu hình nó để sử dụng TokenLab làm nhà cung cấp API.

## Cài đặt

Anthropic hiện khuyến nghị trình cài đặt gốc. Cài đặt qua npm vẫn còn tồn tại để tương thích, nhưng đã bị ngừng khuyến nghị ở phía upstream.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Nếu bạn cần cụ thể gói npm, hãy sử dụng:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
Không sử dụng `sudo npm install -g` cho Claude Code.
</Warning>

## Cấu hình

Làm theo bước terminal trong [bắt đầu nhanh](/vi/quickstart) cho macOS, Linux, WSL hoặc Windows PowerShell để đặt `TOKENLAB_API_KEY` mà không ghi khóa vào lịch sử lệnh. Mở Claude Code từ terminal đó. Khi dùng lâu dài, hãy dùng trình quản lý bí mật cục bộ, không thêm khóa dạng văn bản vào hồ sơ shell.

Các biến này chỉ áp dụng cho lần khởi chạy này; tài khoản, mô hình mặc định và quyền đã lưu vẫn giữ nguyên. Khởi chạy bình thường không kèm các biến để dùng cấu hình trước đó. Không lưu chúng vào hồ sơ shell.

Cách khởi chạy này dùng Claude Code **2.1.263** và xác thực Bearer qua `ANTHROPIC_AUTH_TOKEN`. Base URL không có `/v1`. Giá trị `env` đã lưu, trình hỗ trợ thông tin xác thực, tùy chọn đám mây hoặc chính sách quản lý có thể ảnh hưởng xác thực; kiểm tra trước khi chạy. Nếu xung đột, dùng trình hỗ trợ bên dưới thay vì xóa tài khoản hay nới lỏng chính sách. Kiểm tra mô hình và quyền bằng `/status`.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Nếu đã cài plugin hoặc Skill độc lập, làm theo [hướng dẫn cập nhật README](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) và kiểm tra script đã có. Các bước thủ công trên trang vẫn dùng được mà không cần trình cấu hình.

Lưu thiết lập hoặc liệt kê mô hình không xác nhận khóa hợp lệ hay yêu cầu đã hoàn tất. Prompt dùng số dư TokenLab. Kiểm tra phản hồi và [bản ghi tương ứng](https://tokenlab.sh/dashboard/runs?section=requests) trước khi thử công cụ; yêu cầu phụ cũng có thể được tính phí.

## Sử dụng

Sau khi cấu hình, sử dụng Claude Code như bình thường:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Xác minh cài đặt nếu cần:

```bash
claude --version
claude doctor
```

## Các model khả dụng

TokenLab hỗ trợ tất cả các model Claude:

| Mô hình | Mô tả |
|-------|-------------|
| `claude-opus-4-6` | Mạnh nhất, suy luận phức tạp |
| `claude-sonnet-4-6` | Hiệu năng cân bằng, xuất sắc cho lập trình |
| `claude-haiku-4-5` | Nhanh nhất, tối ưu chi phí |

## Lựa chọn model

Chỉ định một model bằng cờ `--model`:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Suy nghĩ mở rộng

Đối với các tác vụ suy luận phức tạp, hãy sử dụng các model có extended thinking:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```
