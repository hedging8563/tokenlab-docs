## Tổng quan

Hầu hết các ứng dụng AI chat thông thường đều kết nối với TokenLab thông qua đường dẫn chat tương thích với OpenAI tiêu chuẩn.

Trên thực tế, điều đó có nghĩa là:
- sử dụng `https://api.tokenlab.sh/v1` làm URL cơ sở (base URL) trừ khi ứng dụng yêu cầu cụ thể một URL endpoint đầy đủ
- sử dụng API key TokenLab của bạn như API key theo phong cách OpenAI
- chọn các model mà ứng dụng có thể sử dụng trong quy trình chat tiêu chuẩn

<Note>
Cài đặt riêng của từng ứng dụng bên dưới nêu rõ API khi cần lựa chọn. Một số ứng dụng chọn Responses theo mô hình. Hãy dùng mô hình hỗ trợ API mà ứng dụng sử dụng; các công cụ lập trình có hướng dẫn tích hợp riêng.
</Note>

<Note>
**Loại**: Ứng dụng Chat

**Đường dẫn chính**: Chat-completions tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Đường dẫn được hỗ trợ
</Note>

## Các ứng dụng được hỗ trợ

| Ứng dụng | Nền tảng | Ghi chú |
|-------------|----------|-------|
| Open WebUI | Web, Self-hosted | Lựa chọn self-hosted phổ biến với các kết nối tương thích OpenAI |
| LibreChat | Web, Self-hosted | Không gian làm việc chat đa nhà cung cấp với các endpoint OpenAI tùy chỉnh |
| LobeChat | Web, Desktop, Self-hosted | Hỗ trợ nhà cung cấp tùy chỉnh mạnh mẽ |
| Cherry Studio | Windows, macOS, Linux | Luồng nhà cung cấp tương thích OpenAI tốt |
| Chatbox | Windows, macOS, Linux | Thiết lập tương thích OpenAI đơn giản |
| DeepChat | Windows, macOS, Linux | Client desktop với cài đặt nhà cung cấp tương thích OpenAI |
| Jan | Desktop, Self-hosted | Ứng dụng ưu tiên cục bộ với các nhà cung cấp OpenAI từ xa |
| TypingMind | Web, Desktop | Sử dụng kiểu endpoint tùy chỉnh |
| NextChat | Web, Self-hosted | Client kiểu ChatGPT nhẹ với các ghi đè base-URL |
| ChatWise | Windows, macOS | Mẫu nhà cung cấp tùy chỉnh tiêu chuẩn |

## Các giá trị kết nối mặc định

| Trường | Giá trị |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Loại API | Tương thích OpenAI |

Nếu một ứng dụng yêu cầu **URL endpoint đầy đủ** thay vì URL cơ sở, hãy sử dụng:
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## Thiết lập ứng dụng ví dụ

<Tabs>
  <Tab title="LobeChat">
**LobeChat tự lưu trữ**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. Mở **Settings** → **AI Providers**
    2. Chọn **OpenAI**
    3. Nhập API key TokenLab của bạn
    4. Đặt endpoint tùy chỉnh thành `https://api.tokenlab.sh/v1`

    Bật và chọn một mô hình rồi gửi tin nhắn kiểm tra. LobeChat có thể tự động dùng Responses cho một số mô hình GPT, vì vậy hãy chọn mô hình TokenLab hỗ trợ API được sử dụng.
  </Tab>

  <Tab title="Cherry Studio">
    Làm theo [hướng dẫn thiết lập Cherry Studio](/vi/integrations/cherry-studio) để cấu hình kết nối, chọn mô hình và gửi tin nhắn kiểm tra đầu tiên.
  </Tab>

  <Tab title="Chatbox">
    Làm theo [hướng dẫn thiết lập Chatbox](/vi/integrations/chatbox) để cấu hình kết nối, chọn mô hình và gửi tin nhắn kiểm tra đầu tiên.
  </Tab>

  <Tab title="TypingMind">
    1. Mở **Models** → **Add Custom Models**.
    2. Nhập:
       - **Name**: TokenLab
       - **Endpoint**: `https://api.tokenlab.sh/v1/chat/completions`
       - **Model ID / Context length**: Sao chép chính xác ID mô hình và độ dài ngữ cảnh từ [Mô hình TokenLab](https://tokenlab.sh/vi/models).
       - **Custom Headers**: `Authorization: Bearer sk-your-tokenlab-key`
    3. Nhấp **Test**, rồi **Add Model**. Chọn mô hình mới và gửi tin nhắn kiểm tra.
  </Tab>

    Làm theo [hướng dẫn thiết lập Open WebUI](/vi/integrations/open-webui) để cấu hình kết nối, chọn mô hình và gửi tin nhắn kiểm tra đầu tiên.

## Mẹo

<AccordionGroup>
  <Accordion title="Ưu tiên sử dụng base URL khi ứng dụng hỗ trợ">
    Hầu hết các ứng dụng dễ cấu hình hơn và ít lỗi hơn khi bạn cung cấp `https://api.tokenlab.sh/v1` làm base URL thay vì URL endpoint đầy đủ.
  </Accordion>

  <Accordion title="Sử dụng các model nhỏ hơn trước">
    Hãy bắt đầu với `gpt-5.4-mini` hoặc `deepseek-v4-flash` cho các tác vụ chat hàng ngày, sau đó chuyển các tác vụ suy luận nặng hơn sang `gpt-5.4` hoặc `claude-opus-4-8`.
  </Accordion>

  <Accordion title="Giữ các công cụ lập trình riêng biệt">
    Các ứng dụng chat thông thường và các tác nhân lập trình (coding agents) thường cần hành vi endpoint khác nhau. Hãy giữ các công cụ kiểu Codex/Cursor trên các trang tích hợp chuyên biệt của chúng.
  </Accordion>
</AccordionGroup>

## Khắc phục sự cố

<AccordionGroup>
  <Accordion title="Lỗi kết nối">
    - Xác minh base URL chính xác là `https://api.tokenlab.sh/v1`
    - Xóa dấu gạch chéo ở cuối nếu ứng dụng tự động thêm đường dẫn
    - Nếu ứng dụng yêu cầu URL endpoint đầy đủ, hãy sử dụng `https://api.tokenlab.sh/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Không được ủy quyền">
    - Kiểm tra kỹ API key của bạn
    - Xác nhận key đang hoạt động trong bảng điều khiển TokenLab
    - Đảm bảo không có khoảng trắng hoặc ngắt dòng thừa
  </Accordion>

  <Accordion title="Model không khả dụng">

    - Kiểm tra tính khả dụng hiện tại trong tài liệu hoặc bảng điều khiển TokenLab
  </Accordion>
</AccordionGroup>
