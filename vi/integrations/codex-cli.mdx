## Để agent của tôi thiết lập

Sao chép nhiệm vụ này cho một agent đã hoạt động trên máy tính của bạn:

```text
Đọc hướng dẫn này và giúp tôi kết nối Codex CLI với TokenLab:
https://docs.tokenlab.sh/vi/integrations/codex-cli
Trước tiên, kiểm tra phiên bản đã cài và cấu hình đang có hiệu lực.
Giữ nguyên các tài khoản, nhà cung cấp, quyền và những thiết lập khác hiện có.
Sao lưu các tệp cục bộ và trình bày những thay đổi dự kiến.
Để tôi nhập khóa API cần thiết trên máy của mình; không yêu cầu, hiển thị hoặc dán khóa trong cuộc trò chuyện.
Trước tiên, xác nhận cấu hình tải được bình thường.
Giải thích riêng chi phí của mọi phép thử có gửi yêu cầu trả phí trước khi chạy.
```

## Tổng quan

Codex CLI kết nối TokenLab qua `/v1/responses`. Mô hình được chọn phải có `openai_responses` trong `tokenlab.accepted_request_formats`; tính năng có thể khác nhau theo mô hình.

Nén từ xa của Codex CLI được hỗ trợ tại `POST /v1/responses/compact`. Codex gửi `model` của phiên hiện tại trong `body.model` cho `/compact` và tự động nén, vì vậy model bạn muốn dùng để nén phải có sẵn trên đường dẫn Responses. Không cấu hình `/v1/compact`.

## Yêu cầu hệ thống

Làm theo [hướng dẫn CLI chính thức](https://learn.chatgpt.com/docs/codex/cli) cho macOS, Linux hoặc Windows. Windows nguyên bản và WSL là môi trường riêng; xem [hướng dẫn Windows](https://learn.chatgpt.com/docs/windows/windows-sandbox). npm là một cách cài đặt, không phải yêu cầu của bản nhị phân.

## Cài đặt

```bash
npm install -g @openai/codex@0.149.0
```

Xác minh cài đặt:

```bash
codex --version
```

## Cấu hình

### Bước 1: Thiết lập API Key

Làm theo bước terminal trong [bắt đầu nhanh](/vi/quickstart) cho macOS, Linux, WSL hoặc Windows PowerShell để đặt `TOKENLAB_API_KEY` mà không ghi khóa vào lịch sử lệnh. Mở Codex từ terminal đó. Khi dùng lâu dài, hãy dùng trình quản lý bí mật cục bộ, không thêm khóa dạng văn bản vào hồ sơ shell.

### Bước 2: Cấu hình tokenlab.config.toml

Với Codex **0.149.0**, dùng tệp `tokenlab.config.toml` riêng trong `CODEX_HOME` đang hoạt động (thường là `~/.codex`). Chỉ tạo khi tên chưa được dùng, hoặc sao lưu hồ sơ TokenLab hiện có trước khi sửa. `codex --profile tokenlab` nạp hồ sơ rõ ràng mà không thay đổi `config.toml`, `auth.json`, tài khoản hay chính sách quyền. Không dùng bảng cũ `[profiles.tokenlab]`. Khởi chạy không kèm hồ sơ này để quay lại cấu hình thường dùng. Xem [cấu hình hồ sơ chính thức](https://learn.chatgpt.com/docs/config-file/config-advanced#profiles).

```toml
model_provider = "tokenlab"
model = "gpt-5.6-sol"
model_reasoning_effort = "xhigh"

[model_providers.tokenlab]
env_key = "TOKENLAB_API_KEY"
name = "TokenLab"
base_url = "https://api.tokenlab.sh/v1"
wire_api = "responses"
supports_websockets = true
websocket_connect_timeout_ms = 15000
```

Chế độ WebSocket này là cầu nối Responses-over-WebSocket cho client Codex. Nó chỉ nhận sự kiện chính thức `response.create`; `stream` là ngầm định, còn `background` và `response.cancel` không khả dụng trên transport này. Đây không phải OpenAI Realtime API và không nhận `session.update`, `conversation.item.*`, `input_audio_buffer.*`, âm thanh nhị phân hoặc envelope Realtime lồng nhau `response.create.response`.

<Note>
Tạo tệp cấu hình đã chọn nếu chưa có. Sau khi sửa, bắt đầu phiên mới bằng lệnh tương ứng bên dưới.
</Note>

Codex hiện dùng `wire_api = "responses"`, không phải `chat/completions`. Bỏ `requires_openai_auth` hoặc đặt false để nhà cung cấp dùng `env_key`.

<Note>
Yêu cầu Responses không được chuyển thành Chat Completions. Các trường tùy chọn và tương lai phụ thuộc vào mô hình được chọn.
</Note>

## Sử dụng cơ bản

**Bắt đầu chế độ tương tác:**

```bash
codex --profile tokenlab
```

**Lệnh trực tiếp:**

```bash
codex --profile tokenlab "Fix the bug in main.py line 42"
```

**Chỉ định model:**

```bash
codex --profile tokenlab -m gpt-5.6-sol "Build a REST API server"
```

## Chọn mô hình

Chọn mô hình hiện có `openai_responses` trong `tokenlab.accepted_request_formats`. So sánh bằng tác vụ của bạn và xem giá hiện tại trên [trang mô hình](https://tokenlab.sh/vi/models).

## Lệnh tương tác

| Lệnh | Mô tả |
|---------|-------------|
| `/help` | Hiển thị trợ giúp |
| `/exit` or `Ctrl+C` | Thoát |
| `/clear` | Xóa cuộc hội thoại |
| `/status` | Hiển thị mô hình, quyền và lượng token đang sử dụng |
| `/model <name>` | Chuyển model |

## Xác minh cấu hình

Chỉ kiểm tra biến môi trường đã được đặt hay chưa, không in giá trị. Kiểm tra này không xác nhận khóa có hợp lệ hay không:

```bash
if [ -n "${TOKENLAB_API_KEY:-}" ]; then
  printf '%s\n' 'TOKENLAB_API_KEY is set'
else
  printf '%s\n' 'TOKENLAB_API_KEY is not set'
fi
```

Khởi động Codex rồi chạy `/status` để kiểm tra mô hình và quyền đang dùng. Nếu sử dụng hồ sơ cấu hình, hãy khởi động cùng hồ sơ đó. Xem [lệnh trạng thái chính thức](https://learn.chatgpt.com/docs/developer-commands?surface=cli#inspect-the-session-with-status).

Khi sẵn sàng gửi yêu cầu thật, hãy chạy lệnh dưới đây. Lệnh sẽ sử dụng số dư TokenLab. Kiểm tra câu trả lời và bản ghi tương ứng trong [Yêu cầu](https://tokenlab.sh/dashboard/runs?section=requests). Biến đã được đặt hoặc ứng dụng khởi động thành công chưa chứng minh yêu cầu đã thành công.

```bash
codex --profile tokenlab "Reply only with OK. Do not use tools or modify files."
```

## Các trường hợp sử dụng phổ biến

**Đánh giá mã:**

```bash
git diff | codex --profile tokenlab "Review these code changes"
```

**Tạo commit messages:**

```bash
git diff --staged | codex --profile tokenlab "Generate a commit message for these changes"
```

**Sửa lỗi:**

```bash
codex --profile tokenlab "Fix the TypeScript errors in src/components/"
```

**Giải thích mã:**

```bash
cat main.py | codex --profile tokenlab "Explain what this code does"
```

    - Xác nhận `base_url` trong tokenlab.config.toml là chính xác `https://api.tokenlab.sh/v1`

    - Đảm bảo không có can nhiễu proxy

  <Accordion title="Xác thực thất bại">
    Sau khi nâng cấp lên Codex 0.149.0 trở lên, lỗi `API_KEY_REQUIRED` hoặc `401 Unauthorized` có thể xảy ra nếu nhà cung cấp tùy chỉnh chỉ dựa vào `auth.json` trong khi `requires_openai_auth` không được đặt hoặc được đặt thành `false`. Hướng dẫn này đọc khóa từ `TOKENLAB_API_KEY` thông qua `env_key` và không phụ thuộc vào `auth.json`. Hãy tiếp tục bỏ qua `requires_openai_auth` hoặc đặt thành `false`; cách cấu hình này không yêu cầu đổi thành `true` hay ghi đè `auth.json`.

    - Xác nhận cấu hình hoặc hồ sơ đang thực sự được sử dụng có `env_key = "TOKENLAB_API_KEY"`; nếu lưu cấu hình trong `tokenlab.config.toml`, hãy khởi chạy bằng `codex --profile tokenlab`
    - Xác nhận biến môi trường `TOKENLAB_API_KEY` đã được đặt trong terminal dùng để khởi chạy Codex, rồi khởi động lại Codex từ terminal đó sau khi đặt biến
    - Kiểm tra rằng khóa bắt đầu bằng `sk-`
    - Đảm bảo khóa đang hoạt động trong dashboard của TokenLab
  </Accordion>

  <Accordion title="Trường native của Responses bị từ chối">
