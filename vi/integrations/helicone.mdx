## Tổng quan

Helicone có thể làm proxy và quan sát các yêu cầu tương thích với OpenAI của TokenLab bằng cách định tuyến chúng thông qua Helicone Gateway và nhắm mục tiêu đến TokenLab.

<Note>
**Loại**: Observability Gateway

**Đường dẫn chính**: Chat completions tương thích với OpenAI thông qua Helicone Gateway

**Độ tin cậy hỗ trợ**: Đường dẫn quan sát được hỗ trợ
</Note>

## Môi trường

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## Phạm vi

Thiết lập này dành cho lưu lượng truy cập `/v1` tương thích với OpenAI. TokenLab cũng cung cấp các endpoint native Responses, Anthropic Messages và tương thích với Gemini; hãy sử dụng các tuyến đường trực tiếp của TokenLab cho các định dạng native đó trừ khi proxy quan sát của bạn hỗ trợ chúng một cách rõ ràng.
