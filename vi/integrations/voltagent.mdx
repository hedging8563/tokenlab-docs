## Tổng quan

VoltAgent chấp nhận trực tiếp các mô hình ngôn ngữ AI SDK. Hãy cấu hình một nhà cung cấp AI SDK tương thích với OpenAI bằng URL cơ sở `/v1` của TokenLab và truyền mô hình đã chọn vào agent của bạn.

<Note>
**Loại**: Khung làm việc (framework) agent TypeScript

**Đường dẫn chính**: Chat Completions tương thích với OpenAI thông qua AI SDK

**Độ tin cậy hỗ trợ**: Hỗ trợ đường dẫn tương thích với OpenAI
</Note>

## Cài đặt

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## Môi trường

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Nhà cung cấp AI SDK trực tiếp

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## Đường dẫn Model Router

Nếu snapshot registry VoltAgent của bạn bao gồm một mục nhà cung cấp TokenLab từ `models.dev`, hãy cấu hình:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

Sau đó, sử dụng chuỗi mô hình registry, ví dụ: `tokenlab/claude-sonnet-5`.

## Lưu ý về Endpoint

Đường dẫn AI SDK trực tiếp là thiết lập rõ ràng nhất. Chỉ sử dụng các endpoint Responses gốc của TokenLab, Anthropic Messages hoặc Gemini khi nhà cung cấp/client AI SDK mà bạn chọn được cấu hình cho giao thức đó.
