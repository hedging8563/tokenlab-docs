## Để agent của tôi thiết lập

Sao chép nhiệm vụ này cho một agent đã hoạt động trên máy tính của bạn:

```text
Đọc hướng dẫn này và giúp tôi kết nối WorkBuddy với TokenLab:
https://docs.tokenlab.sh/vi/integrations/workbuddy
Trước tiên, kiểm tra phiên bản đã cài và cấu hình đang có hiệu lực.
Giữ nguyên các tài khoản, nhà cung cấp, quyền và những thiết lập khác hiện có.
Sao lưu các tệp cục bộ và trình bày những thay đổi dự kiến.
Để tôi nhập khóa API cần thiết trên máy của mình; không yêu cầu, hiển thị hoặc dán khóa trong cuộc trò chuyện.
Trước tiên, xác nhận cấu hình tải được bình thường.
Giải thích riêng chi phí của mọi phép thử có gửi yêu cầu trả phí trước khi chạy.
```

## Tổng quan

<Note>
**Loại**: tác nhân desktop cho lập trình và tác vụ

**Đường dẫn chính**: Chat Completions tương thích OpenAI

**Mức hỗ trợ**: đường dẫn mô hình tùy chỉnh chính thức
</Note>

[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) cung cấp trình chỉnh sửa trực quan cho mô hình tương thích OpenAI, không cần sửa tệp mô hình cục bộ bằng tay.

## Cấu hình TokenLab

Mở **Settings → Model**, thêm mô hình rồi chọn **Custom**.

| Trường | Giá trị |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key của bạn |
| Model name | `kimi-k3` |
| Custom Protocol | **Tắt** |

<Warning>
Giữ Custom Protocol ở trạng thái tắt. Chế độ chuẩn xác thực Base URL và tự thêm `/chat/completions`. Nếu bật nhưng chỉ nhập `/v1`, yêu cầu sẽ đi sai đường dẫn.
</Warning>

Đặt công cụ, hình ảnh, suy luận và giới hạn theo chi tiết hiện tại của mô hình trên TokenLab. Không bật tất cả hoặc sao chép giới hạn 1M/128K từ mô hình khác. Dùng đúng ID hiển thị.

Lưu, chọn `kimi-k3` và thử kiểm tra thư mục chỉ đọc. Che API Key và endpoint riêng trước khi chia sẻ ảnh chụp.

Lưu và chọn chỉ xác nhận cấu hình cục bộ. Tác vụ văn bản hay công cụ dùng số dư TokenLab; đối chiếu phản hồi với [bản ghi](https://tokenlab.sh/dashboard/runs?section=requests). Để hoàn tác, chọn mô hình cũ và chỉ xóa mục TokenLab đã thêm.

Ứng dụng chính thức có trên macOS và Windows. Dùng [trình chỉnh sửa chính thức](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model); hướng dẫn không giả định có bản Linux hay định dạng tệp có thể ghi trực tiếp.

[Công cụ MCP API](/vi/integrations/tokenlab-mcp-server) và [hướng dẫn Skill](/vi/integrations/coding-agent-skill) được cài riêng, không đổi mô hình chính.
