## Tổng quan

LibreChat hoạt động tốt với TokenLab thông qua một endpoint tùy chỉnh tương thích với OpenAI.

<Note>
**Loại**: Ứng dụng trò chuyện (Chat App)

**Đường dẫn chính**: Hoàn tất trò chuyện (chat completions) tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Đường dẫn được hỗ trợ
</Note>

## Môi trường

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## Ví dụ về Endpoint

Thêm TokenLab vào cấu hình endpoint của LibreChat:

```yaml
customEndpoints:
  - name: 'TokenLab'
    apiKey: '${TOKENLAB_API_KEY}'
    baseURL: 'https://api.tokenlab.sh/v1'
    models:
      default:
        - 'gpt-5.5'
        - 'gpt-5.4'
        - 'gpt-5.4-mini'
        - 'claude-opus-4-8'
        - 'claude-sonnet-5'
        - 'gemini-3.5-flash'
        - 'deepseek-v4-pro'
        - 'deepseek-v4-flash'
      fetch: true
    titleConvo: true
    titleModel: 'gpt-5.4-mini'
    modelDisplayLabel: 'TokenLab'
```

## Ghi chú

LibreChat sử dụng đường dẫn trò chuyện tương thích với OpenAI cho thiết lập này. TokenLab cũng cung cấp các endpoint gốc cho Responses, Anthropic Messages và các endpoint tương thích với Gemini cho các client hỗ trợ các định dạng yêu cầu đó.
