## Tổng quan

LibreChat hoạt động tốt với TokenLab thông qua một endpoint tùy chỉnh tương thích với OpenAI.

<Note>
**Loại**: Ứng dụng trò chuyện (Chat App)

**Đường dẫn chính**: Hoàn tất trò chuyện (chat completions) tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Đường dẫn được hỗ trợ
</Note>

## Môi trường

Thêm biến này vào tệp `.env` tại thư mục gốc của dự án LibreChat:

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## Ví dụ về Endpoint

Nếu chưa có `librechat.yaml` tại thư mục gốc của dự án LibreChat, hãy sao chép từ `librechat.example.yaml`. Giữ lại trường `version` bắt buộc và các cấu hình hiện có, rồi thêm mục sau vào `endpoints.custom`:

```yaml
endpoints:
  custom:
    - name: 'TokenLab'
      apiKey: '${TOKENLAB_API_KEY}'
      baseURL: 'https://api.tokenlab.sh/v1'
      models:
        default:
          - 'gpt-5.5'
          - 'gpt-5.6-terra'
          - 'gpt-5.6-luna'
          - 'claude-opus-4-8'
          - 'claude-sonnet-5'
          - 'gemini-3.5-flash'
          - 'deepseek-v4-pro'
          - 'deepseek-v4-flash'
        fetch: true
      titleConvo: true
      titleModel: 'gpt-5.6-luna'
      modelDisplayLabel: 'TokenLab'
```

Nếu dùng Docker, hãy gắn tệp này vào đường dẫn `/app/librechat.yaml` trong container API. Khởi động lại đúng instance LibreChat đó rồi chọn TokenLab. Xem [hướng dẫn cấu hình LibreChat](https://www.librechat.ai/docs/configuration/librechat_yaml).

## Ghi chú

LibreChat sử dụng đường dẫn trò chuyện tương thích với OpenAI cho thiết lập này. TokenLab cũng cung cấp các endpoint gốc cho Responses, Anthropic Messages và các endpoint tương thích với Gemini cho các client hỗ trợ các định dạng yêu cầu đó.
