## Tổng quan

DeepChat hoạt động với TokenLab thông qua cấu hình nhà cung cấp tương thích với OpenAI tiêu chuẩn.

<Note>
**Loại**: Ứng dụng Chat

**Đường dẫn chính**: Hoàn tất chat (chat completions) tương thích với OpenAI

**Độ tin cậy hỗ trợ**: Đường dẫn được hỗ trợ
</Note>

## Cấu hình DeepChat

1. Mở **Settings** -> **Model Provider**
2. Thêm hoặc chỉnh sửa nhà cung cấp tương thích với OpenAI
3. Nhập:
   - **Provider name**: TokenLab
   - **API Type**: **OpenAI Completions** (Chat Completions)
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Thêm một model như `gpt-5.4-mini`
5. Lưu và kiểm tra chat.

## Lựa chọn Model

Hãy bắt đầu với `gpt-5.4-mini` để có cấu hình mặc định dễ sử dụng. Sử dụng `claude-sonnet-5`, `gpt-5.4`, hoặc `deepseek-v4-pro` khi cuộc trò chuyện cần khả năng suy luận mạnh mẽ hơn.

## Khắc phục sự cố

- Sử dụng base URL, không phải đường dẫn đầy đủ `/chat/completions`, trừ khi DeepChat yêu cầu rõ ràng một URL endpoint đầy đủ.
- Loại bỏ các khoảng trắng thừa ở cuối API key.
- Nếu một model không được liệt kê, hãy thêm thủ công ID model TokenLab chính xác.
