<Note>
Hướng dẫn này dành cho người dùng **self-hosted OpenClaw** muốn kết nối TokenLab làm provider AI của họ.
</Note>

## Khuyến nghị: cài đặt plugin

Để chạy agent OpenClaw theo cách tiêu chuẩn, hãy cài đặt plugin provider TokenLab:

```bash
openclaw plugins install @tokenlabai/openclaw-provider
openclaw onboard
```

Sau khi cài, chạy `openclaw onboard`, chọn TokenLab và chỉ nhập khóa trong hộp thoại cục bộ. Nếu plugin không tải được, dùng cấu hình thủ công bên dưới và kiểm tra tương thích phiên bản.

Plugin tải danh mục model chat trực tiếp của TokenLab và giữ 18 model dự phòng để khám phá khi ngoại tuyến. Model sử dụng định dạng `tokenlab/<model-id>`.

[Gói npm](https://www.npmjs.com/package/@tokenlabai/openclaw-provider) · [Trang ClawHub](https://clawhub.ai/tokenlabai/plugins/openclaw-provider) · [Mã nguồn](https://github.com/hedging8563/tokenlab-openclaw-provider)

## Cấu hình provider thủ công

Chỉ dùng các mục `models.providers` thủ công bên dưới khi bạn thực sự cần các route riêng cho **Responses API**, **Claude native**, **Gemini native** hoặc **MiniMax native**.

Nếu bạn chọn cấu hình thủ công, chỉ cần cấu hình `tokenlab` là đủ. Chỉ thêm các provider khác khi bạn thực sự cần hành vi **Responses API**, **Claude native**, **Gemini native**, hoặc **MiniMax native**.

| Nhà cung cấp | OpenClaw `api` | Phù hợp cho | baseUrl |
|----------|----------------|----------|---------|
| `tokenlab` | `openai-completions` | GPT, DeepSeek, Qwen, và hầu hết các gọi tương thích OpenAI | `https://api.tokenlab.sh/v1` |
| `tokenlab-responses` | `openai-responses` | Các luồng công việc OpenAI Responses mong đợi ngữ nghĩa `/v1/responses` | `https://api.tokenlab.sh/v1` |
| `tokenlab-claude` | `anthropic-messages` | API Messages gốc của Claude | `https://api.tokenlab.sh` |
| `tokenlab-gemini` | `google-generative-ai` | Định dạng API Gemini gốc | `https://api.tokenlab.sh` |
| `tokenlab-minimax` | `anthropic-messages` | Điều hướng MiniMax gốc | `https://api.tokenlab.sh` |

<Warning>
Chỉ sử dụng hậu tố `/v1` cho `openai-completions` và `openai-responses`.

Các nhà cung cấp gốc như `anthropic-messages` và `google-generative-ai` nên dùng `https://api.tokenlab.sh` mà không có `/v1`, nếu không OpenClaw có thể tạo sai đường dẫn upstream.
</Warning>

## Yêu cầu tiên quyết

- Một instance OpenClaw self-hosted
- Một TokenLab API Key — [Get one here](https://tokenlab.sh/dashboard/api?tab=keys)

## Cấu hình

Chỉnh sửa cấu hình OpenClaw của bạn:

- **Tự lưu trữ**: `~/.openclaw/openclaw.json`

Thêm provider TokenLab dưới `models.providers`:

Dùng cùng profile, `OPENCLAW_STATE_DIR` và `OPENCLAW_CONFIG_PATH` với Gateway đang chạy rồi sao lưu cấu hình. Đặt `TOKENLAB_API_KEY` trong `.env` toàn cục đáng tin cậy hoặc môi trường dịch vụ của phiên bản đó. Export ở terminal hay `.env` dự án có thể không tới tiến trình nền. Xem [môi trường](https://docs.openclaw.ai/help/environment).

```json5
{
  agents: {
    defaults: {
      model: {
        primary: "tokenlab-claude/claude-sonnet-5"
      }
    }
  },
  models: {
    mode: "merge",
    providers: {
      tokenlab: {
        api: "openai-completions",
        baseUrl: "https://api.tokenlab.sh/v1",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gpt-5.6-terra", name: "GPT-5.6 Terra" },
          { id: "deepseek-reasoner", name: "DeepSeek Reasoner" },
          { id: "qwen3-coder-flash", name: "Qwen 3 Coder Flash" }
        ]
      },
      "tokenlab-responses": {
        api: "openai-responses",
        baseUrl: "https://api.tokenlab.sh/v1",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gpt-5.6-terra", name: "GPT-5.6 Terra (Responses)" },
          { id: "gpt-5.2", name: "GPT-5.2 (Responses)" }
        ]
      },
      "tokenlab-claude": {
        api: "anthropic-messages",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "claude-sonnet-5", name: "Claude Sonnet 5" },
          { id: "claude-opus-5", name: "Claude Opus 5" }
        ]
      },
      "tokenlab-gemini": {
        api: "google-generative-ai",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gemini-3.5-flash", name: "Gemini 3.5 Flash" },
          { id: "gemini-2.5-pro", name: "Gemini 2.5 Pro" }
        ]
      },
      "tokenlab-minimax": {
        api: "anthropic-messages",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "minimax-m3", name: "MiniMax M3" }
        ]
      }
    }
  }
}
```

<Info>
Cả 5 nhà cung cấp đều dùng **cùng một API Key**. Bạn chỉ cần một tài khoản TokenLab.
</Info>

<Info>
Các mảng `models` ở trên chỉ hiển thị các ví dụ phổ biến. Thêm các model ID khác cho từng nhà cung cấp khi cần.
</Info>

## Sử dụng Models

OpenClaw vẫn tham chiếu các model theo định dạng `provider/model`:

```json5
{
  agents: {
    defaults: {
      model: {
        primary: "tokenlab-gemini/gemini-3.5-flash"
      }
    }
  }
}
```

### Ví dụ Model

| Nhà cung cấp | Tham chiếu model | Mô tả |
|----------|-----------------|-------------|
| `tokenlab` | `tokenlab/gpt-5.6-terra` | Route tương thích OpenAI |
| `tokenlab-responses` | `tokenlab-responses/gpt-5.6-terra` | Route Responses API |
| `tokenlab-claude` | `tokenlab-claude/claude-sonnet-5` | Route Messages gốc của Claude |
| `tokenlab-gemini` | `tokenlab-gemini/gemini-3.5-flash` | Route Gemini gốc |
| `tokenlab-minimax` | `tokenlab-minimax/minimax-m3` | Route MiniMax gốc |

Xem tất cả model hiện có tại [tokenlab.sh/models](https://tokenlab.sh/vi/models).

## Khi nào sử dụng provider nào

- `tokenlab`: lựa chọn mặc định cho hầu hết các trường hợp sử dụng agent và chat đa dụng.
- `tokenlab-responses`: dùng khi luồng công việc OpenClaw của bạn phụ thuộc rõ ràng vào ngữ nghĩa OpenAI Responses.
- `tokenlab-claude`: dùng khi bạn muốn hành vi Messages gốc của Claude.
- `tokenlab-gemini`: dùng khi bạn cần định dạng yêu cầu/đáp trả gốc của Gemini hoặc tích hợp theo kiểu Gemini hiện có.
- `tokenlab-minimax`: dùng khi bạn muốn MiniMax theo route gốc của nó.

Nếu bạn không cần hành vi Gemini-gốc, bạn vẫn có thể gọi các model Gemini thông qua `tokenlab/gemini-*` trên route tương thích OpenAI.

## Những lỗi phổ biến

<AccordionGroup>
  <Accordion title="Vẫn đang sử dụng mảng providers cấp cao cũ">
    Tài liệu OpenClaw hiện tại sử dụng `models.providers`. Nếu bạn giữ định dạng mảng `providers` cấp cao cũ, OpenClaw có thể bỏ qua cấu hình hoặc không thể giải quyết tiền tố provider như mong đợi.
  </Accordion>
  <Accordion title="Quên /v1 trên tokenlab-responses">
    `openai-responses` ánh xạ đến đường dẫn `/v1/responses` của TokenLab, nên `tokenlab-responses` phải sử dụng `https://api.tokenlab.sh/v1`.
  </Accordion>
  <Accordion title="Thêm /v1 vào tokenlab-claude, tokenlab-gemini, hoặc tokenlab-minimax">
    `anthropic-messages` và `google-generative-ai` nên sử dụng `https://api.tokenlab.sh` mà không có `/v1`. Thêm `/v1` có thể tạo ra các đường dẫn yêu cầu không chính xác.
  </Accordion>
  <Accordion title="OpenClaw có còn hỗ trợ Gemini gốc không?">
    Có. Tài liệu OpenClaw hiện tại vẫn bao gồm provider tích hợp sẵn `google` và cũng hỗ trợ các provider tùy chỉnh sử dụng `api: "google-generative-ai"`. Vì vậy `tokenlab-gemini` vẫn là một route Gemini gốc hợp lệ cho người dùng OpenClaw.
  </Accordion>
</AccordionGroup>

## Xác minh cấu hình

Khởi động lại đúng phiên bản rồi kiểm tra mô hình và nhà cung cấp. `models status` không có `--probe` không thử gọi mô hình. Kiểm tra thật và tin nhắn có thể tốn token. Đối chiếu phản hồi với bản ghi TokenLab. Để khôi phục, chọn mô hình cũ và chỉ xóa mục đã thêm.

```bash
openclaw gateway restart
openclaw models status
```
