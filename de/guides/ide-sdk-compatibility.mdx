Die meisten Tools lassen sich über einen API-Schlüssel und eine angepasste Basis-URL mit TokenLab verbinden. Die genaue Einrichtung hängt davon ab, welches API-Format das Tool verwenden kann.

| API-Format | Basis-URL | Typische Clients |
| --- | --- | --- |
| Chat Completions (OpenAI-kompatibel) | `https://api.tokenlab.sh/v1` | OpenAI-SDKs, viele Chat-Apps und Frameworks |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | Responses-Clients und Tools, die Responses-Ereignisse nutzen |
| Anthropic Messages | `https://api.tokenlab.sh` | Anthropic-SDKs und Tools für Claude |
| Gemini | `https://api.tokenlab.sh` | Gemini-REST- und SDK-Clients mit frei wählbarem Host |

Das gewählte Modell muss dasselbe Format in `accepted_request_formats` aufführen. Streaming und Tool-Aufrufe hängen zusätzlich von den Fähigkeiten des Modells und vom Client ab. Beispiele finden Sie unter [API-Formate](/de/guides/api-formats).

## Kompatibilitätsangaben

| Angabe | Bedeutung |
| --- | --- |
| **Kompatibel** | Die verlinkte TokenLab-Anleitung verwendet dokumentierte Konfigurationsoptionen des Clients |
| **Mit Einschränkungen kompatibel** | Die Konfiguration gilt für bestimmte Funktionen oder Authentifizierungsarten; andere Dienste des Herstellers behalten ihre eigenen Voraussetzungen |

Diese Angaben beziehen sich auf die Konfiguration der verlinkten Seite. Welche Funktionen verfügbar sind, hängt auch vom gewählten Modell und der Client-Version ab.

## Nutzung in Streaming-Antworten

Chat-Completions-Streams akzeptieren `stream_options: { include_usage: true }` und fügen vor dem Ende des Streams einen letzten Abschnitt mit Nutzungsdaten hinzu. Die Responses-API bietet kein `include_usage`; Responses-Streams liefern die Nutzungsdaten im Abschlussereignis.

## Was ein eigener API-Schlüssel nicht ersetzt

Einige Produkte kombinieren Modellaufrufe mit Funktionen, die der Hersteller selbst betreibt. Ein TokenLab-Schlüssel kann Modellanfragen über die BYOK-Einstellungen ermöglichen, ersetzt aber keine anderen Abonnements, Autovervollständigungsdienste, Kontofunktionen oder proprietären Erweiterungen.

Wenn ein Tool-Update die Konfiguration ändert, verwenden Sie die aktuelle Integrationsseite, statt ein altes Beispiel mit Umgebungsvariablen zu kopieren.

## Vor der Nutzung einer Funktion

- Prüfen Sie, ob das Tool eine eigene Basis-URL für das benötigte Format zulässt.
- Prüfen Sie, ob das Modell dieses Format in `accepted_request_formats` aufführt.
- Probieren Sie Streaming und Tool-Aufrufe aus, wenn Ihr Workflow sie benötigt.
- Bewahren Sie den API-Schlüssel auf einem vertrauenswürdigen Gerät oder Server auf.
- Notieren Sie bei einer Fehlermeldung die Request ID.
