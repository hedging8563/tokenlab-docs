Ein TokenLab-Guthaben gilt für alle Modelle. Es gibt kein Abonnement und keinen Mindestumsatz; abgerechnet werden Modell und erfasste Nutzung.

## Preise und Lieferoptionen

Aktuelle Preise finden Sie auf der Modellseite, unter `GET /v1/models/{model}/pricing` oder in der Pricing API. Hinterlegen Sie keine kopierte Preistabelle als feste Werte. Text und Embeddings können nach Eingabe-, Ausgabe- oder Cache-Tokens berechnet werden, Medien auch pro Bild, Sekunde, Minute, Anfrage oder Aufgabe.

`TokenLab Verified` nutzt öffentliche TokenLab-Preise, `Official` die Official-Preise auf Grundlage der veröffentlichten Herstellerpreise. `Auto` bevorzugt Verified und nutzt bei Bedarf Official; berechnet wird einmal die Option, die das Ergebnis liefert. Console zeigt vor kostenpflichtiger Generierung die maximale Schätzung, danach den Endbetrag in Runs und Usage.

[Pricing API](/de/api-reference/pricing/get-pricing)

## Asynchrone Abrechnung und Belege

Manche Aufgaben reservieren bei Erstellung die geschätzten Kosten. Speichern Sie ID und `poll_url` und fragen Sie bis `completed` oder `failed` ab. Erfolgreiche Aufgaben werden einmal berechnet und ungenutzte Reserven freigegeben; bei Fehlern wird der ausstehende Betrag freigegeben oder erstattet.

OpenAI-kompatible Antworten ohne Streaming können nach Abrechnung `billing_transaction_id` oder `X-Billing-Transaction-ID` enthalten. Native Formate verwenden gegebenenfalls nur den Header. Asynchrone und Streaming-Ergebnisse können vor dem Buchungseintrag eintreffen; fehlt die ID, prüfen Sie Usage.

Usage zeigt Modell, Schlüssel, Kosten und Verbrauch. Die Tokenisierung hängt von Modell, Sprache und Medien ab; Zeichenschätzungen ersetzen keine Endabrechnung. Streaming senkt die berechneten Tokens nicht. Vergleichen Sie die Endkosten gleicher Aufgaben und setzen Sie unterstützte Ausgabelimits.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Console verwenden

Wählen Sie unter Console → Billing Betrag und eine angebotene Zahlungsmethode. Nach Bestätigung durch den Zahlungsdienst wird das Guthaben aktualisiert.

Beim Erstellen oder Bearbeiten eines Schlüssels unter Console → API Keys können Sie ein Ausgabenlimit setzen. Bei Erreichen liefert die API `402 Payment Required`.

Unter Console → Settings lassen sich Guthabenwarnungen einstellen. Senden Sie bei Abrechnungsfragen Request ID und Aufgaben-ID an support@tokenlab.sh, niemals den API-Schlüssel.
