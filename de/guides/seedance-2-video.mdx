Beginnen Sie hier, wenn Sie Seedance 2.0 in eine Anwendung integrieren. Diese Seite behandelt nur die Modell- und Workflow-Auswahl; Migration, wiederverwendbare Materialien und die Verifizierung echter Personen haben eigene Leitfäden.

## Integrationspfad wählen

| Ziel | Verwendung | Weiterführend |
| --- | --- | --- |
| Neue TokenLab-Videointegration entwickeln | Einheitliche API `POST /v1/videos/generations` | [Leitfaden zur Videogenerierung](/de/guides/video-generation) |
| Vorhandenen Volcengine-Seedance-Client migrieren | Volcengine-kompatible REST- oder Action-API | [Seedance von Volcengine migrieren](/de/guides/seedance-volcengine-migration) |
| Avatar-, Produkt-, Stil- oder Personenreferenzen wiederverwenden | TokenLab-Materialbibliothek | [Seedance-Materialien und Personenverifizierung](/de/guides/seedance-materials) |

Alle drei Pfade verwenden `Authorization: Bearer <TOKENLAB_API_KEY>`. Die Volcengine-kompatiblen Pfade behalten das Request-Format bei, akzeptieren jedoch keine AK/SK-Signaturen.

## Modellwahl

| Modell | Unterstützte Auflösungen |
|-------|-----------------------|
| `seedance-2.0` | `480p`, `720p`, `1080p`, `4k` |
| `seedance-2.0-fast` | `480p`, `720p` |
| `seedance-2.0-mini` | `480p`, `720p` |

`seedance-2.0-fast` und `seedance-2.0-mini` lehnen `1080p`- und `4k`-Anfragen ab. Audio kann nur in unterstützten Referenz-Workflows verwendet werden; reine Audio-Anfragen sowie Text-plus-Audio-Anfragen werden von Seedance nicht unterstützt.

## Unterstützte Operationen

| Operation | Typische Eingaben |
|-----------|----------------|
| `text-to-video` | `prompt` |
| `image-to-video` | `prompt`, `image_url` oder kompatible Bildeingabe |
| `start-end-to-video` | `prompt`, `start_image`, `end_image` |
| `reference-to-video` | `prompt`, `reference_images`, optional `video_urls`, optional `audio_urls` |
| `video-to-video` | `prompt`, `video_url` oder kompatible Videoeingabe |
| `video-extension` | `task_id` oder modellspezifische Fortsetzungseingabe |

## Preise und asynchrone Ergebnisse

Die Preisgestaltung für Seedance 2.0 hängt von der Ausgabeauflösung, dem Eingabetyp und dem Modell ab. Verwenden Sie die [Pricing API](/de/api-reference/pricing/get-pricing) oder [Models API](/de/api-reference/models/list-models), bevor Sie die Produkt-UI fest programmieren.

Die Videogenerierung ist asynchron. Folgen Sie der `poll_url`, die von Erstellungsanfragen zurückgegeben wird, oder verwenden Sie [Task-Status abrufen](/de/api-reference/tasks/get-task-status) mit der zurückgegebenen Task-ID.
