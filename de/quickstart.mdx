## Schritt 1: Mit Testguthaben starten

<Steps>
  <Step title="Konto erstellen">
    Registrieren Sie sich unter [tokenlab.sh](https://tokenlab.sh) mit Ihrer E-Mail-, Gmail- oder GitHub-Adresse.
  </Step>
  <Step title="Workspace-Guthaben prüfen">
    Prüfen Sie Guthaben und verfügbares Testguthaben unter [Abrechnung](https://tokenlab.sh/dashboard/billing). Die Anfrage wird zum aktuellen Modellpreis abgerechnet; laden Sie bei Bedarf Guthaben auf.
  </Step>
  <Step title="API-Schlüssel erstellen und speichern">
    Öffnen Sie [API-Schlüssel](https://tokenlab.sh/dashboard/api?tab=keys) in Ihrem Workspace. Erstellen Sie einen Schlüssel und speichern Sie sofort den vollständigen Wert; er wird nur einmal angezeigt. Wenn Sie bereits einen vollständigen Schlüssel gespeichert haben, verwenden Sie diesen. Das in der Liste angezeigte oder kopierte Präfix kann Anfragen nicht authentifizieren.
  </Step>
</Steps>

<Warning>
Bewahren Sie Ihren API-Schlüssel sicher auf. Legen Sie ihn niemals in clientseitigem Code oder in öffentlichen Repositories offen.
</Warning>

## Schlüssel für dieses Terminal setzen

Diese Befehle schreiben den Schlüssel nicht in den Befehl selbst. Er gilt nur für dieses Terminal und seine Kindprozesse. Verwenden Sie für bereitgestellte Anwendungen eine Geheimnisverwaltung.

<CodeGroup>
```bash macOS / Linux / WSL
printf 'TokenLab API key: '
read -r -s TOKENLAB_API_KEY
printf '\n'
export TOKENLAB_API_KEY
```

```powershell Windows PowerShell
$secret = Read-Host 'TokenLab API key' -AsSecureString
$env:TOKENLAB_API_KEY = [System.Net.NetworkCredential]::new('', $secret).Password
Remove-Variable secret
```
</CodeGroup>

## Schritt 3: Stellen Sie Ihre erste Anfrage

Für die meisten neuen Integrationen beginnen Sie mit **Chat Completions** über `POST /v1/chat/completions`.

<CodeGroup>

```bash cURL — macOS / Linux / WSL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.6-terra","messages":[{"role":"user","content":"Reply only with OK."}]}'
```

```powershell Windows PowerShell
$body = @{
  model = 'gpt-5.6-terra'
  messages = @(@{ role = 'user'; content = 'Reply only with OK.' })
} | ConvertTo-Json -Depth 6
$result = Invoke-RestMethod -Method Post `
  -Uri 'https://api.tokenlab.sh/v1/chat/completions' `
  -Headers @{ Authorization = "Bearer $env:TOKENLAB_API_KEY" } `
  -ContentType 'application/json' -Body $body -TimeoutSec 30
$result.choices[0].message.content
```

```python Python — quickstart.py
import os
from openai import OpenAI

with OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    timeout=30.0,
    max_retries=0,
) as client:
    response = client.chat.completions.create(
        model="gpt-5.6-terra",
        messages=[{"role": "user", "content": "Reply only with OK."}],
    )
    print(response.choices[0].message.content)
```

```javascript JavaScript — quickstart.mjs
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
  timeout: 30_000,
  maxRetries: 0,
});
const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Reply only with OK.' }],
});
console.log(response.choices[0].message.content);
```

```go Go — main.go
package main

import (
    "context"
    "fmt"
    "os"
    "time"

    "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey(os.Getenv("TOKENLAB_API_KEY")),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
        option.WithMaxRetries(0),
    )
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    response, err := client.Chat.Completions.New(ctx, openai.ChatCompletionNewParams{
        Model: "gpt-5.6-terra",
        Messages: []openai.ChatCompletionMessageParamUnion{
            openai.UserMessage("Reply only with OK."),
        },
    })
    if err != nil { panic(err) }
    fmt.Println(response.Choices[0].Message.Content)
}
```

```php PHP — quickstart.php
<?php
require __DIR__ . '/vendor/autoload.php';

$client = OpenAI::factory()
    ->withApiKey(getenv('TOKENLAB_API_KEY'))
    ->withBaseUri('https://api.tokenlab.sh/v1')
    ->withHttpClient(new \GuzzleHttp\Client(['timeout' => 30]))
    ->make();
$response = $client->chat()->create([
    'model' => 'gpt-5.6-terra',
    'messages' => [['role' => 'user', 'content' => 'Reply only with OK.']],
]);
echo $response->choices[0]->message->content . PHP_EOL;
```

</CodeGroup>

Speichern Sie ein SDK-Beispiel als `quickstart.py`, `quickstart.mjs`, `main.go` oder `quickstart.php`. Starten Sie es mit `python quickstart.py`, `node quickstart.mjs`, `go run .` oder `php quickstart.php`. Python, JavaScript und Go verwenden offizielle OpenAI-SDKs; PHP nutzt den [Community-Client](https://github.com/openai-php/client) und benötigt PHP 8.2+.

<Note>
Verwenden Sie `POST /v1/responses` nur, wenn Sie ausdrücklich Responses-spezifisches Verhalten benötigen. Einige nur für Responses verfügbare Felder hängen vom ausgewählten Modell und dem gerouteten Pfad ab.
</Note>
