[Cline](https://docs.cline.bot/provider-config/openai-compatible) unterstützt OpenAI-kompatible Provider in den IDE-Einstellungen.

## TokenLab konfigurieren

Sichern Sie Anbieter, Modell und Verbindungseinstellungen vor der Änderung lokal. Diese Felder ändern die aktive Modellauswahl; stellen Sie danach die bisherigen Werte wieder her. Lassen Sie angemeldete Konten und Werkzeugberechtigungen unverändert. Überschreiben Sie keine andere OpenAI-kompatible Verbindung ohne wiederherstellbare Sicherung.

1. Installiere **Cline** aus dem Erweiterungs-Marktplatz und öffne das Cline-Panel.
2. Klicke auf das Zahnrad und wähle bei **API Provider** die Option **OpenAI Compatible**.
3. Trage ein:

| Feld | Wert |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | Dein TokenLab API Key |
| Model ID | `kimi-k3` |

4. Klicke auf **Verify**.

Beginne nach der Verifizierung mit einer schreibgeschützten Aufgabe. Bei 404 muss die Base URL mit `/v1` enden und darf `/chat/completions` nicht enthalten. Die Modell-ID lautet `kimi-k3`, nicht `kimi/kimi-k3`.

Gespeicherte Einstellungen oder eine Modellliste bestätigen weder den Schlüssel noch einen abgeschlossenen Aufruf. Ein Prompt verwendet TokenLab-Guthaben. Prüfen Sie Antwort und [zugehörigen Anfrageeintrag](https://tokenlab.sh/dashboard/runs?section=requests), bevor Sie Werkzeuge testen; auch Hilfsanfragen können berechnet werden.
