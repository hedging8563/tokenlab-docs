## Übersicht

Helicone kann OpenAI-kompatible Anfragen von TokenLab mittels Proxy überwachen, indem diese über das Helicone Gateway geleitet und an TokenLab weitergeleitet werden.

<Note>
**Typ**: Observability Gateway

**Primärer Pfad**: OpenAI-kompatible Chat-Completions über das Helicone Gateway

**Support-Status**: Unterstützter Observability-Pfad
</Note>

## Umgebung

```bash
export HELICONE_API_KEY="your-helicone-key"
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## cURL

```bash
curl --request POST \
  --url https://gateway.helicone.ai/v1/chat/completions \
  --header "Authorization: Bearer $TOKENLAB_API_KEY" \
  --header "Helicone-Auth: Bearer $HELICONE_API_KEY" \
  --header "Helicone-Target-Url: https://api.tokenlab.sh" \
  --header "Helicone-Target-Provider: TokenLab" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "gpt-5.4-mini",
    "messages": [
      {
        "role": "user",
        "content": "Say hello from TokenLab through Helicone."
      }
    ]
  }'
```

## OpenAI SDK

```typescript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://gateway.helicone.ai/v1",
  defaultHeaders: {
    "Helicone-Auth": `Bearer ${process.env.HELICONE_API_KEY}`,
    "Helicone-Target-Url": "https://api.tokenlab.sh",
    "Helicone-Target-Provider": "TokenLab",
  },
});

const response = await client.chat.completions.create({
  model: "claude-sonnet-5",
  messages: [{ role: "user", content: "Write one concise product summary." }],
});
```

## Geltungsbereich

Dieses Setup ist für OpenAI-kompatiblen `/v1`-Datenverkehr vorgesehen. TokenLab stellt zudem native Responses, Anthropic Messages und Gemini-kompatible Endpunkte bereit; verwenden Sie für diese nativen Formate die direkten TokenLab-Routen, es sei denn, Ihr Observability-Proxy unterstützt diese explizit.
