## Übersicht

DeepChat funktioniert mit TokenLab über eine standardmäßige OpenAI-kompatible Provider-Konfiguration.

<Note>
**Typ**: Chat-App

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Support-Status**: Unterstützter Pfad
</Note>

## DeepChat konfigurieren

1. Öffnen Sie **Settings** -> **Model Provider**
2. Fügen Sie einen OpenAI-kompatiblen Provider hinzu oder bearbeiten Sie einen bestehenden
3. Geben Sie Folgendes ein:
   - **Provider name**: TokenLab
   - **API Type**: **OpenAI Completions** (Chat Completions)
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Fügen Sie ein Modell wie `gpt-5.4-mini` hinzu
5. Speichern Sie die Einstellungen und testen Sie einen Chat.

## Modellauswahl

Beginnen Sie mit `gpt-5.4-mini` als unkomplizierte Standardoption. Verwenden Sie `claude-sonnet-5`, `gpt-5.4` oder `deepseek-v4-pro`, wenn die Konversation eine stärkere logische Schlussfolgerung erfordert.

## Fehlerbehebung

- Verwenden Sie die Basis-URL, nicht den vollständigen `/chat/completions`-Pfad, es sei denn, DeepChat fragt explizit nach einer vollständigen Endpunkt-URL.
- Entfernen Sie führende oder nachgestellte Leerzeichen aus dem API-Key.
- Wenn ein Modell nicht aufgeführt ist, fügen Sie die exakte TokenLab-Modell-ID manuell hinzu.
