## Übersicht

Semantic Kernel kann TokenLab über seinen OpenAI-kompatiblen Chat-Completion-Dienst aufrufen.

<Note>
**Typ**: SDK / Agent Framework

**Primärer Pfad**: OpenAI-kompatible Chat Completions

**Support-Status**: Unterstützter benutzerdefinierter Endpunkt-Pfad
</Note>

## Umgebung

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## .NET Kernel Builder

Der benutzerdefinierte Endpunkt von Semantic Kernel sollte auf den OpenAI-kompatiblen `/v1` Root-Endpunkt verweisen, nicht auf `/v1/chat/completions`.

```csharp
using Microsoft.SemanticKernel;

#pragma warning disable SKEXP0010

var builder = Kernel.CreateBuilder();

builder.AddOpenAIChatCompletion(
    modelId: "gpt-5.4-mini",
    endpoint: new Uri("https://api.tokenlab.sh/v1"),
    apiKey: Environment.GetEnvironmentVariable("TOKENLAB_API_KEY"));

var kernel = builder.Build();
```

## Einfacher Prompt

```csharp
var result = await kernel.InvokePromptAsync(
    "Give me a concise checklist for evaluating an LLM gateway.");

Console.WriteLine(result);
```

## Hinweise zum Endpunkt

Verwenden Sie:

```text
https://api.tokenlab.sh/v1
```

Verwenden Sie nicht:

```text
https://api.tokenlab.sh/v1/chat/completions
```

Semantic Kernel fügt den Pfad für Chat Completions bei diesem Connector intern automatisch hinzu.
