## Überblick

Open WebUI unterstützt benutzerdefinierte OpenAI-kompatible API-Verbindungen. Fügen Sie TokenLab als entfernten OpenAI-kompatiblen Endpunkt hinzu und aktualisieren Sie die Modellliste.

<Note>
**Typ**: Web-Chat-App

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Support-Vertrauen**: Unterstützter Chat-App-Pfad
</Note>

## Admin-Verbindung

1. Öffnen Sie das **Admin Panel** -> **Settings** -> **Connections**.
2. Fügen Sie im Bereich für die OpenAI-API-Verbindung eine Verbindung hinzu.
3. Setzen Sie die Base URL auf `https://api.tokenlab.sh/v1`.
4. Setzen Sie den API-Key auf Ihren TokenLab-Key.
5. Speichern Sie die Verbindung und aktualisieren Sie die Modelle.

## Werte

| Feld | Wert |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Beispielmodell | `gpt-5.4-mini` |

## Empfohlene Modelle

- `gpt-5.4-mini` für allgemeine Chats
- `claude-sonnet-5` für Schreiben und logisches Denken
- `deepseek-v4-pro` für code-lastige Chats
- `gemini-3.5-flash` für schnelle, multimodale Workflows

Um Modell-IDs manuell anzugeben, bearbeiten Sie diese Verbindung und öffnen Sie **Advanced** → **Model IDs (Filter)**. Fügen Sie die exakten TokenLab-Modell-IDs hinzu und speichern Sie.
