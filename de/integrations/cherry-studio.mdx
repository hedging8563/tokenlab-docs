## Übersicht

Cherry Studio kann TokenLab über einen benutzerdefinierten OpenAI-kompatiblen Provider nutzen. Wenn Ihre Cherry Studio-Version TokenLab im Provider-Verzeichnis enthält, wählen Sie TokenLab direkt aus.

<Note>
**Typ**: Chat-App

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Native Pfade**: Responses, Anthropic Messages, Gemini-kompatible Endpunkte, sofern vom Client bereitgestellt
</Note>

## Als benutzerdefinierten Provider konfigurieren

1. Öffnen Sie **Settings** -> **Model Provider**
2. Fügen Sie einen OpenAI-kompatiblen Provider hinzu
3. Geben Sie Folgendes ein:
   - **Name**: TokenLab
   - **API Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. Fügen Sie ein Modell wie `gpt-5.4-mini` hinzu
5. Schließen Sie **Verify and Enable** im Einrichtungsdialog ab. Speichern Sie bei manueller Einrichtung und prüfen Sie, ob der Provider aktiviert ist.
6. Wählen Sie das hinzugefügte Modell und senden Sie eine kurze Testnachricht.

## Provider-Verzeichnispfad

Wenn TokenLab als integrierter Provider in Cherry Studio erscheint, bevorzugen Sie diese Option. Sie kann Endpunkt-Metadaten für Folgendes enthalten:

- OpenAI-kompatible Chat-Completions
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## Empfohlene Einstiegsmodelle

Verwenden Sie `gpt-5.4-mini` als Standardmodell und fügen Sie `claude-sonnet-5`, `gemini-3.5-flash` sowie `deepseek-v4-flash` für eine breitere Abdeckung hinzu.
