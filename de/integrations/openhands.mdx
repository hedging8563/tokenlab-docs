## Überblick

Diese Seite gilt für die OpenHands-Oberfläche mit LiteLLM und **Settings → LLM → Advanced**. Wählen Sie **OpenAI**, tragen Sie ein eigenes Modell mit Präfix `openai/`, den TokenLab-Schlüssel im lokalen Schlüsselfeld und die folgende Base URL ein. Notieren Sie die vorherige Auswahl und stellen Sie sie anschließend wieder her. Erhalten Sie Konten und Werkzeugberechtigungen. Siehe [offizielle OpenAI-kompatible Konfiguration](https://docs.openhands.dev/openhands/usage/llms/openai-llms). CLI, Cloud und Quellcode-Installationen können andere Abläufe haben; folgen Sie Ihrer Edition. `make setup-config` ist kein allgemeiner Befehl einer installierten CLI.

## Modelleinstellungen

Sichern Sie Anbieter, Modell und Verbindungseinstellungen vor der Änderung lokal. Diese Felder ändern die aktive Modellauswahl; stellen Sie danach die bisherigen Werte wieder her. Lassen Sie angemeldete Konten und Werkzeugberechtigungen unverändert. Überschreiben Sie keine andere OpenAI-kompatible Verbindung ohne wiederherstellbare Sicherung.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

Gespeicherte Einstellungen oder eine Modellliste bestätigen weder den Schlüssel noch einen abgeschlossenen Aufruf. Ein Prompt verwendet TokenLab-Guthaben. Prüfen Sie Antwort und [zugehörigen Anfrageeintrag](https://tokenlab.sh/dashboard/runs?section=requests), bevor Sie Werkzeuge testen; auch Hilfsanfragen können berechnet werden.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
