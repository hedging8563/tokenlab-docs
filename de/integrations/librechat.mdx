## Übersicht

LibreChat funktioniert hervorragend mit TokenLab über einen benutzerdefinierten OpenAI-kompatiblen Endpunkt.

<Note>
**Typ**: Chat-App

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Support-Status**: Unterstützter Pfad
</Note>

## Umgebung

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## Beispiel-Endpunkt

Fügen Sie TokenLab zu Ihrer LibreChat-Endpunktkonfiguration hinzu:

```yaml
customEndpoints:
  - name: 'TokenLab'
    apiKey: '${TOKENLAB_API_KEY}'
    baseURL: 'https://api.tokenlab.sh/v1'
    models:
      default:
        - 'gpt-5.5'
        - 'gpt-5.4'
        - 'gpt-5.4-mini'
        - 'claude-opus-4-8'
        - 'claude-sonnet-5'
        - 'gemini-3.5-flash'
        - 'deepseek-v4-pro'
        - 'deepseek-v4-flash'
      fetch: true
    titleConvo: true
    titleModel: 'gpt-5.4-mini'
    modelDisplayLabel: 'TokenLab'
```

## Hinweise

LibreChat verwendet für dieses Setup den OpenAI-kompatiblen Chat-Pfad. TokenLab stellt zudem native Responses-, Anthropic Messages- und Gemini-kompatible Endpunkte für Clients bereit, die diese Anfrageformate unterstützen.
