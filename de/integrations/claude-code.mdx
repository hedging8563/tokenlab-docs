## Überblick



<Note>
**Typ**: Coding-Tool

**Primärer Pfad**: Anthropic-native

**Support-Niveau**: Starker nativer Pfad
</Note>

[Claude Code](https://code.claude.com/docs/en/setup) ist Anthropics offizielles CLI-Tool für KI-gestütztes Coding. Sie können es so konfigurieren, dass TokenLab als API-Provider verwendet wird.

## Installation

Anthropic empfiehlt jetzt das native Installationsprogramm. Die npm-Installation existiert weiterhin aus Kompatibilitätsgründen, ist upstream jedoch veraltet.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

Wenn Sie speziell das npm-Paket benötigen, verwenden Sie:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
Verwenden Sie nicht `sudo npm install -g` für Claude Code.
</Warning>

## Konfiguration

Setzen Sie `TOKENLAB_API_KEY` mit den Terminal-Schritten im [Schnellstart](/de/quickstart) für macOS, Linux, WSL oder Windows PowerShell, ohne den Schlüssel im Befehlsverlauf zu speichern. Starten Sie Claude Code in diesem Terminal. Verwenden Sie für dauerhaften Zugriff einen lokalen Secret-Manager statt eines Klartextschlüssels im Shell-Profil.

Diese Variablen gelten nur für diesen Start. Gespeicherte Konten, Standardmodell und Berechtigungen bleiben bestehen. Starten Sie ohne die Variablen für Ihre bisherige Konfiguration; speichern Sie sie nicht im Shell-Profil.

Dieser Sitzungsweg verwendet Claude Code **2.1.263** mit Bearer-Authentifizierung über `ANTHROPIC_AUTH_TOKEN`. Die Basis-URL enthält kein `/v1`. Gespeicherte `env`-Werte, Anmeldehelfer, Cloud-Anbieterschalter und verwaltete Regeln können die Authentifizierung beeinflussen. Prüfen Sie diese vor dem Start. Nutzen Sie bei Konflikten den folgenden Helfer, statt Kontodaten zu löschen oder Regeln abzuschwächen. `/status` zeigt Modell und Berechtigungen.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Optional bietet der [wiederherstellbare Claude Code-Konfigurationshelfer](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md) mit Python 3.11+ eine Vorschau, Anwendung und Wiederherstellung der Originaldatei. Das TokenLab-Skills-Plugin **0.1.2** enthält die neuen Skripte. Ein einzeln installierter Skill kann ebenfalls verwendet werden, sobald er auf eine Version mit diesen Skripten aktualisiert wurde. Aktualisieren Sie vorhandene Plugins oder einzeln installierte Skills gemäß der [README-Anleitung](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) und prüfen Sie, ob das Skript vorhanden ist. Die manuelle Konfiguration auf dieser Seite funktioniert auch ohne Helfer.

Gespeicherte Einstellungen oder eine Modellliste bestätigen weder den Schlüssel noch einen abgeschlossenen Aufruf. Ein Prompt verwendet TokenLab-Guthaben. Prüfen Sie Antwort und [zugehörigen Anfrageeintrag](https://tokenlab.sh/dashboard/runs?section=requests), bevor Sie Werkzeuge testen; auch Hilfsanfragen können berechnet werden.

## Verwendung

Nach der Konfiguration verwenden Sie Claude Code wie gewohnt:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Überprüfen Sie bei Bedarf die Installation:

```bash
claude --version
claude doctor
```

## Verfügbare Modelle

TokenLab unterstützt alle Claude-Modelle:

| Modell | Beschreibung |
|-------|-------------|
| `claude-opus-4-6` | Am leistungsfähigsten, komplexes Schlussfolgern |
| `claude-sonnet-4-6` | Ausgewogene Leistung, hervorragend für Coding |
| `claude-haiku-4-5` | Am schnellsten, kosteneffizient |

## Modellauswahl

Geben Sie ein Modell mit dem Flag `--model` an:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Erweitertes Denken

Für Aufgaben mit komplexem Schlussfolgern verwenden Sie Modelle mit erweitertem Denken:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## Fehlerbehebung

<AccordionGroup>
  <Accordion title="Verbindungsfehler">
    Vergewissern Sie sich, dass die Base-URL exakt `https://api.tokenlab.sh` ist (kein `/v1`-Suffix für Anfragen im Anthropic-Stil).
  </Accordion>

  <Accordion title="Ungültiger API key">
    Stellen Sie sicher, dass Ihr TokenLab API key mit `sk-` beginnt und über ausreichendes Guthaben verfügt.
  </Accordion>


  <Accordion title="Modell nicht gefunden">
    Prüfen Sie, ob der Modellname korrekt ist. Verwenden Sie das Format `claude-sonnet-4-6`.
  </Accordion>
</AccordionGroup>
