## Übersicht

Das OpenAI Agents SDK kann TokenLab über einen OpenAI-kompatiblen Client und `OpenAIChatCompletionsModel` nutzen.

<Note>
**Typ**: Python Agent SDK

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Support-Status**: Unterstützter Chat-Completions-Pfad
</Note>

## Umgebung

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
export TOKENLAB_MODEL="gpt-5.4-mini"
```

## Beispiel

```python
import asyncio
import os

from openai import AsyncOpenAI

from agents import Agent, OpenAIChatCompletionsModel, Runner, set_tracing_disabled

client = AsyncOpenAI(
    base_url=os.getenv("TOKENLAB_BASE_URL", "https://api.tokenlab.sh/v1"),
    api_key=os.environ["TOKENLAB_API_KEY"],
)

set_tracing_disabled(disabled=True)


async def main():
    agent = Agent(
        name="Assistant",
        instructions="You are concise and practical.",
        model=OpenAIChatCompletionsModel(
            model=os.getenv("TOKENLAB_MODEL", "gpt-5.4-mini"),
            openai_client=client,
        ),
    )

    result = await Runner.run(agent, "Explain custom model providers in one paragraph.")
    print(result.final_output)


asyncio.run(main())
```

## Umfang

Dieser Pfad nutzt die Kompatibilität mit Chat Completions. Der native Responses-Endpunkt von TokenLab ist unter `https://api.tokenlab.sh/v1/responses` verfügbar, jedoch sollten SDK-Funktionen, die von OpenAI-spezifischer Responses-Semantik abhängen, vor dem produktiven Einsatz mit dem jeweiligen Modell und Workflow überprüft werden.
