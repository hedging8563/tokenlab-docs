## Überblick

Browser Use kann TokenLab über `ChatOpenAILike`, den OpenAI-kompatiblen Chat-Modell-Wrapper, aufrufen.

<Note>
**Typ**: Framework für Browser-Automatisierungs-Agenten

**Primärer Pfad**: OpenAI-kompatible Chat Completions

**Support-Status**: Unterstützter OpenAI-kompatibler Pfad
</Note>

## Umgebung

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Beispiel

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    add_schema_to_system_prompt=True,
    dont_force_structured_output=True,
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## Hinweise zu Endpunkten

Verwenden Sie diese Seite für Browser Use-Workflows, die Chat Completions über einen OpenAI-kompatiblen Client aufrufen. Wenn Ihr Workflow native TokenLab-Responses, Anthropic Messages oder Gemini-Endpunkte erfordert, verwenden Sie einen Client-Pfad in Browser Use, der dieses Protokoll direkt unterstützt.
