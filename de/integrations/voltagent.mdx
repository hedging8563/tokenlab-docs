## Überblick

VoltAgent akzeptiert AI SDK-Sprachmodelle direkt. Konfigurieren Sie einen OpenAI-kompatiblen AI SDK-Provider mit der `/v1` Basis-URL von TokenLab und übergeben Sie das ausgewählte Modell an Ihren Agenten.

<Note>
**Typ**: TypeScript-Agenten-Framework

**Primärer Pfad**: OpenAI-kompatible Chat-Completions über das AI SDK

**Support-Status**: Unterstützter OpenAI-kompatibler Pfad
</Note>

## Installation

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## Umgebung

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Direkter AI SDK-Provider

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## Modell-Router-Pfad

Wenn Ihr VoltAgent-Registry-Snapshot einen TokenLab-Provider-Eintrag von `models.dev` enthält, konfigurieren Sie Folgendes:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

Verwenden Sie anschließend den Registry-Modell-String, zum Beispiel `tokenlab/claude-sonnet-5`.

## Hinweise zu Endpunkten

Der direkte AI SDK-Pfad ist die expliziteste Konfiguration. Verwenden Sie native TokenLab-Responses, Anthropic-Messages oder Gemini-Endpunkte nur dann, wenn Ihr ausgewählter AI SDK-Provider bzw. Client für das entsprechende Protokoll konfiguriert ist.
