## Überblick

Phoenix kann TokenLab-Anfragen durch automatische Instrumentierung des OpenAI Python-Clients nachverfolgen, wenn dieser mit der OpenAI-kompatiblen Basis-URL von TokenLab konfiguriert ist.

<Note>
**Typ**: Observability

**Primärer Pfad**: OpenAI SDK-Instrumentierung

**Support-Status**: Unterstützter OpenAI-kompatibler Tracing-Pfad
</Note>

## Installation

```bash
pip install arize-phoenix openinference-instrumentation-openai openai
```

## Umgebung

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Phoenix registrieren

Starten Sie Phoenix lokal oder verwenden Sie eine bestehende Bereitstellung, bevor Sie dieses Beispiel ausführen. Standardmäßig sendet `register()` Traces an den lokalen OTLP/gRPC-Collector unter `http://localhost:4317`. Konfigurieren Sie für andere Bereitstellungen den Collector-Endpunkt und die Authentifizierung gemäß der [Phoenix-Anleitung](https://arize.com/docs/phoenix/sdk-api-reference/python/arize-phoenix-otel). Die Installation des SDK startet den Collector nicht.

```python
from phoenix.otel import register

tracer_provider = register(
    project_name="tokenlab-app",
    auto_instrument=True,
)
```

## TokenLab aufrufen

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Write a short haiku."}],
)

print(response.choices[0].message.content)
```

## Hinweise zu Endpunkten

Phoenix verfolgt den Aufrufpfad des OpenAI SDK. Verwenden Sie diese Seite für TokenLab-Aufrufe im Stil von Chat Completions. Andere native TokenLab-Endpunkte können weiterhin nachverfolgt werden, sofern Ihre Anwendungsinstrumentierung den Client erfasst, den Sie für diese Anfragen verwenden.
