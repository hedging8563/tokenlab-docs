## Die Einrichtung meinem Agenten überlassen

Kopieren Sie diese Aufgabe in einen Agenten, der auf Ihrem Computer bereits einsatzbereit ist:

```text
Lies diese Anleitung und hilf mir, Pi mit TokenLab zu verbinden:
https://docs.tokenlab.sh/de/integrations/pi-coding-agent
Prüfe zuerst meine installierte Version und die aktive Konfiguration.
Erhalte vorhandene Konten, Anbieter, Berechtigungen und andere Einstellungen.
Sichere lokale Dateien und zeige die vorgeschlagenen Änderungen.
Lass mich benötigte API-Schlüssel lokal eingeben; fordere sie niemals im Chat an, gib sie dort nicht aus und füge sie dort nicht ein.
Prüfe zuerst, ob die Konfiguration geladen werden kann.
Erkläre die Kosten kostenpflichtiger Testanfragen gesondert, bevor du sie ausführst.
```

## Pi installieren und konfigurieren

Nutzen Sie die [offizielle Installation](https://pi.dev/). Das npm-Paket heißt `@earendil-works/pi-coding-agent`. Windows verwendet standardmäßig Git Bash; beachten Sie die [Shell-Anleitung](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md). Eine vorhandene Installation genügt.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent@0.85.1
pi --version
```

Die folgende Konfiguration wurde mit **Pi 0.85.1** geprüft. Andere Versionen müssen anhand ihrer offiziellen Dokumentation separat überprüft werden.

Sichern Sie `~/.pi/agent/models.json` und ergänzen Sie `tokenlab` am Ende der vorhandenen Einträge unter `providers`. Erstellen Sie die Datei nur, wenn sie fehlt. Ein nicht leeres `PI_CODING_AGENT_DIR` bestimmt das Verzeichnis von `models.json`. Erhalten Sie Anbieterreihenfolge, `settings.json`, Konten, Standardmodellfelder und Berechtigungen. Ist `tokenlab` bereits in der Konfiguration oder in gespeicherten Konten vorhanden, wählen Sie einen anderen Namen und passen Sie den Startbefehl an. Setzen Sie `TOKENLAB_API_KEY` lokal mit dem [Schnellstart](/de/quickstart) für macOS, Linux, WSL oder Windows PowerShell; niemals im Chat.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

Das `$` in `"$TOKENLAB_API_KEY"` ist erforderlich; ohne `$` wird der Text als Schlüssel verwendet. Wählen Sie ein aktuelles Modell mit Chat Completions und Werkzeugunterstützung. Grenzen sowie Bild- und Reasoning-Einstellungen richten sich nach dessen Modelldetails.

Optional bietet der [wiederherstellbare Pi-Konfigurationshelfer](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/pi_setup.md) mit Python 3.11+ eine Vorschau, Anwendung und Wiederherstellung der Originaldatei. Das TokenLab-Skills-Plugin **0.1.2** enthält die neuen Skripte. Ein einzeln installierter Skill kann ebenfalls verwendet werden, sobald er auf eine Version mit diesen Skripten aktualisiert wurde. Aktualisieren Sie vorhandene Plugins oder einzeln installierte Skills gemäß der [README-Anleitung](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation) und prüfen Sie, ob das Skript vorhanden ist. Die manuelle Konfiguration auf dieser Seite funktioniert auch ohne Helfer.

## Prüfen und wiederherstellen

Prüfen Sie das Laden im selben Terminal und Agent-Verzeichnis und wählen Sie TokenLab explizit für diese Sitzung. Ohne `TOKENLAB_API_KEY` kann der Anbieter in der Liste fehlen. Die Liste bestätigt Registrierung und vorhandene Zugangsdaten, nicht deren Gültigkeit oder einen erfolgreichen API-Aufruf.

```bash
pi --list-models tokenlab
pi --provider tokenlab --model gpt-5.6-luna
```

Ein Prompt verbraucht TokenLab-Guthaben. Prüfen Sie Antwort und [Anfrageprotokoll](https://tokenlab.sh/dashboard/runs?section=requests), bevor Sie Werkzeuge testen. Entfernen Sie zum Rückgängigmachen nur den hinzugefügten Anbietereintrag und erhalten Sie alle anderen Einstellungen und Konten.

## Skills und MCP

Pi unterstützt [Skills nativ](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). Installieren Sie den [TokenLab Skill](/de/integrations/coding-agent-skill). MCP benötigt eine separate Erweiterung; MCP-Konfiguration gehört nicht in `models.json`.
