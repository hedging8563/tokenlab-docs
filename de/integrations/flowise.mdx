## Übersicht

Flowise kann TokenLab über einen TokenLab-Chat-Knoten aufrufen, sofern dieser verfügbar ist, oder über einen OpenAI-kompatiblen Chatmodell-Knoten, der auf TokenLab verweist.

<Note>
**Typ**: Workflow-Builder

**Primärer Pfad**: OpenAI-kompatible Chat-Completions

**Support-Status**: Unterstützt mit Einschränkungen
</Note>

## TokenLab-Knoten

Wenn Ihr Flowise-Build einen **TokenLab**-Chatmodell-Knoten enthält:

1. Fügen Sie **Chat Models** -> **TokenLab** hinzu
2. Erstellen Sie eine TokenLab API-Berechtigung
3. Setzen Sie den **Model Name** auf `gpt-5.4-mini`
4. Verbinden Sie ihn mit Ihrer Chain, Ihrem Agenten oder Workflow
5. Führen Sie einen Test-Prompt aus.

## OpenAI-kompatibler Fallback

Wenn Ihr Build keinen TokenLab-Knoten enthält, fügen Sie **Chat Models** → **OpenAI Custom Model** hinzu. Erstellen Sie unter **Connect Credential** einen **OpenAI API**-Zugang mit Ihrem TokenLab-Schlüssel. Setzen Sie **Model Name** und **Additional Parameters** → **Base Path** wie folgt:

| Feld | Wert |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

Verbinden Sie den Knoten mit Ihrer Chain, Ihrem Agenten oder Workflow und senden Sie einen Test-Prompt.

## Empfohlene Modelle

- `gpt-5.4-mini` für die meisten Workflow-Tests
- `claude-sonnet-5` für stärkere Schreib- und Schlussfolgerungsleistungen
- `gemini-3.5-flash` für schnelle, multimodale Workflows
- `deepseek-v4-flash` für schnelle Code- oder Schlussfolgerungs-Iterationen
