## Anfragekörper

Eine Transkription liefert entweder direkt den Text oder bestätigt einen asynchronen Auftrag mit HTTP `200`, `id` und `status`. Folgen Sie bei einem Auftrag `poll_url` oder fragen Sie `/v1/tasks/{id}` ab. Für längere synchrone Audiodateien sollte das Timeout mindestens `120s` betragen.

<ParamField body="file" type="file" required>
  Audiodatei zur Transkription. Unterstützte Formate: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. Maximale Dateigröße: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  Transkriptionsmodell-ID, etwa `whisper-1` oder `gpt-4o-transcribe`. Aktuelle Modelle finden Sie mit `GET /v1/models?recommended_for=stt`.
</ParamField>

<ParamField body="language" type="string">
  Sprache des Audios im ISO-639-1-Format (z. B. `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  Optionaler Text, um den Stil des Modells zu steuern oder ein vorheriges Segment fortzusetzen.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Ausgabeformat. Whisper unterstützt `json`, `text`, `srt`, `verbose_json` und `vtt`; andere Modelle können eine andere Auswahl unterstützen. Prüfen Sie die Modelldetails.
</ParamField>

<ParamField body="temperature" type="number">
  Sampling-Temperatur von 0 bis 1, nur für Modelle, die diesen Parameter unterstützen.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  `word` und/oder `segment`, sofern vom Modell unterstützt. Whisper erfordert `response_format=verbose_json`. Wiederholen Sie in Multipart-Anfragen `timestamp_granularities[]` für mehrere Werte.
</ParamField>

## Antwort

Die folgenden Felder beschreiben JSON-Antworten für Transkription oder Übersetzung. `text`, `srt` und `vtt` liefern Text bzw. Untertitel statt eines JSON-Objekts. Zusätzliche Felder hängen vom Modell und Ausgabeformat ab.

<ResponseField name="text" type="string">
  Der transkribierte Text.
</ResponseField>

Für `verbose_json`:

<ResponseField name="task" type="string">
  Aufgabenname, falls zurückgegeben, etwa `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  Erkannte Sprache.
</ResponseField>

<ResponseField name="duration" type="number">
  Audiodauer in Sekunden.
</ResponseField>

<ResponseField name="segments" type="array">
  Transkriptionssegmente mit Zeitstempeln.
</ResponseField>

<ResponseField name="words" type="array">
  Zeitstempel auf Wortebene (falls angefordert).
</ResponseField>

Ein angenommener asynchroner Transkriptionsauftrag liefert statt des Transkripts folgende Felder:

<ResponseField name="id" type="string">
  Aufgaben-ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias der asynchronen Task-ID, wenn verfügbar.
</ResponseField>

<ResponseField name="status" type="string">
  Aufgabenstatus: `pending`, `processing`, `completed` oder `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Bevorzugte Polling-URL, wenn die Erstellungsantwort sie bereitstellt.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```

## Übersetzung

Um Audio ins Englische zu übersetzen, verwenden Sie den translations-Endpunkt:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
