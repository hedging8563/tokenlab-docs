## Überblick

Übersetzt Audio in jeder unterstützten Sprache in englischen Text. Im Gegensatz zur Transkription gibt dieser Endpoint unabhängig von der Eingabesprache immer englischen Text aus.

<Note>
  Dieser Endpunkt übersetzt Audio ins Englische. Senden Sie kein `language`: Audioübersetzung unterstützt den Parameter nicht und kann `unsupported_parameter` zurückgeben. Für Textübersetzung verwenden Sie `POST /v1/translations`; darauf bezieht sich `recommended_for=translation`.
</Note>

## Anfragekörper

Die Antwort erfolgt nach Abschluss der Übersetzung. Für längere Audiodateien sollte das HTTP-Timeout mindestens `120s` betragen.

<ParamField body="file" type="file" required>
  Die Audio-Datei, die übersetzt werden soll. Unterstützte Formate: `flac`, `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `ogg`, `wav`, `webm`. Die maximale Dateigröße beträgt 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  Modell-ID für Audioübersetzung, etwa `whisper-1`. Prüfen Sie in den aktuellen Modelldetails die Unterstützung für `POST /v1/audio/translations`.
</ParamField>

<ParamField body="prompt" type="string">
  Ein optionaler Text, um den Stil des Modells zu steuern oder ein vorheriges Segment fortzusetzen. Sollte auf Englisch sein.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Ausgabeformat. Whisper unterstützt `json`, `text`, `srt`, `verbose_json` und `vtt`; andere Modelle können eine andere Auswahl unterstützen. Prüfen Sie die Modelldetails.
</ParamField>

<ParamField body="temperature" type="number">
  Sampling-Temperatur von 0 bis 1, nur für Modelle, die diesen Parameter unterstützen.
</ParamField>

## Antwort

Die folgenden Felder beschreiben JSON-Antworten für Transkription oder Übersetzung. `text`, `srt` und `vtt` liefern Text bzw. Untertitel statt eines JSON-Objekts. Zusätzliche Felder hängen vom Modell und Ausgabeformat ab.

<ResponseField name="text" type="string">
  Der übersetzte Text auf Englisch.
</ResponseField>

Für das Format `verbose_json` enthält die Antwort außerdem:

<ResponseField name="language" type="string">
  Sprachangabe aus der Antwort, sofern vorhanden.
</ResponseField>

<ResponseField name="duration" type="number">
  Die Dauer des Eingabe-Audios in Sekunden.
</ResponseField>

<ResponseField name="segments" type="array">
  Segmente des übersetzten Textes mit Zeitstempeln.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/translations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "file=@german_audio.mp3" \
  -F "model=whisper-1"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("german_audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.translations.create({
  model: 'whisper-1',
  file: fs.createReadStream('german_audio.mp3')
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/translations');

$file = new CURLFile('german_audio.mp3', 'audio/mpeg', 'german_audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Übersetzung vs. Transkription

| Funktion | Übersetzung | Transkription |
|---------|-------------|---------------|
| Ausgabesprache | Immer Englisch | Gleich wie die Eingabe |
| Anwendungsfall | Fremdsprachiges Audio in Englisch umwandeln | Originalsprache beibehalten |
| Sprachparameter | Nicht anwendbar | Optionaler Hinweis |
