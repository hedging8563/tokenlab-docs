---
title: "3D-Modell-Status abrufen"
openapi: "GET /v1/tasks/{id}"
description: "Ruft den Status und das Ergebnis einer 3D-Generierungsaufgabe ab"
---

Fragen Sie diesen Endpunkt ab, um den Status Ihrer 3D-Modell-Generierungsaufgabe zu überprüfen.

<Info>
Wenn die Create-Response `poll_url` enthält, sollten Sie zum Polling bevorzugt genau diese URL verwenden. `id` und `task_id` sollten als dieselbe asynchrone Task-ID behandelt werden.

Ein abgelaufener oder nicht verfügbarer öffentlicher Task kann `404 async_task_not_found` zurückgeben. Ist die Zugehörigkeit zum aktuellen API-Schlüssel nicht feststellbar, lautet die Antwort `403 task_not_owned`.
</Info>

## Pfadparameter

<ParamField path="id" type="string" required>
  Die ID der 3D-Generierungsaufgabe.
</ParamField>

## Antwort

<Note>
Ergebnis-, Fehler-, Zeitstempel- und Modellfelder werden zurückgegeben, wenn sie für den Task verfügbar sind.
</Note>

<ResponseField name="id" type="string">
  Aufgaben-ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias der asynchronen Task-ID, wenn verfügbar.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Bevorzugte Polling-URL, wenn verfügbar.
</ResponseField>

<ResponseField name="status" type="string">
  Aufgabenstatus: `pending`, `processing`, `completed` oder `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Optionaler Fortschrittswert. Wird nur zurückgegeben, wenn ein echter Fortschrittswert verfügbar ist; verwenden Sie `status`, um den Abschluss zu erkennen.
</ResponseField>

<ResponseField name="model_url" type="string">
  URL zum Herunterladen der 3D-Modelldatei (nach Abschluss).
</ResponseField>

<ResponseField name="glb_url" type="string">
  URL zum Herunterladen des Modells im GLB-Format (sofern verfügbar).
</ResponseField>

<ResponseField name="fbx_url" type="string">
  URL zum Herunterladen des Modells im FBX-Format (sofern verfügbar).
</ResponseField>

<ResponseField name="error" type="string | object">
  Fehlermeldung (im Fehlerfall).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"},
        timeout=30
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(f"3D Model URL: {result['model_url']}")
        break
    elif result["status"] == "failed":
        print(f"Error: {result['error']}")
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollFor3DModel() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(`3D Model URL: ${result.model_url}`);
      return result.model_url;
    } else if (result.status === 'failed') {
      throw new Error(JSON.stringify(result.error));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

pollFor3DModel().catch(console.error);
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, _ := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil { panic(err) }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            resp.Body.Close()
            panic(fmt.Sprintf("HTTP %d", resp.StatusCode))
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil { panic(err) }

        if result["status"] == "completed" {
            fmt.Printf("3D Model URL: %s\n", result["model_url"])
            break
        } else if result["status"] == "failed" {
            fmt.Printf("Error: %v\n", result["error"])
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```
