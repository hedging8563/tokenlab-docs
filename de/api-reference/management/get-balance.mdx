## Übersicht

Dieser Endpunkt gibt die aktuellen Guthabensummen der Organisation zurück, die mit dem Management-Token verknüpft ist. Er verwendet dieselbe Quelle der Wahrheit für Organisationsguthaben wie Abrechnung und Settlement.

## Hinweise

- Geldbetragsfelder unterstützen ausschließlich USD.

- Monetäre Felder werden in USD zurückgegeben. Verwenden Sie `balance`, `total_recharge` und `total_used` für die Anzeige; für exakte Abrechnung verwenden Sie `balance_decimal`, `total_recharge_decimal` und `total_used_decimal`.

## Beispiel

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>
