---
title: "API-Schlüssel auflisten"
openapi: "GET /v1/management/api-keys"
description: "Listet benutzerverwaltete API-Schlüssel für das aktuelle Organisations-Management-Token auf."
---

## Übersicht

Gibt die Benutzer-API-Schlüssel der Organisation zurück, die dem aktuellen Management-Token zugeordnet ist.

## Hinweise

- Geldbetragsfelder unterstützen ausschließlich USD. `CNY`-Eingaben sind außer Betrieb genommen und geben `400 currency_retired` zurück.

- Systemverwaltete Schlüssel werden ausgeschlossen.

## Beispiel

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## Wichtige Felder

<ResponseField name="object" type="string">Immer `list`.</ResponseField>
<ResponseField name="data" type="array">Array von API-Schlüsselobjekten.</ResponseField>
<ResponseField name="pagination" type="object">Paginierungsmetadaten mit `page`, `limit`, `total` und `totalPages`.</ResponseField>
<ResponseField name="data[].id" type="string">API-Schlüssel-ID für nachfolgende Management-API-Aufrufe.</ResponseField>
<ResponseField name="data[].name" type="string">Anzeigename des API-Schlüssels.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">Nicht geheimer Schlüsselpräfix für Anzeige und Support.</ResponseField>
<ResponseField name="data[].status" type="string">Einer der Werte `active`, `inactive` oder `revoked`.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">Ausgabenlimit in USD als JSON-Zahl für die Anzeige. `null` bedeutet unbegrenzt.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">Exaktes Ausgabenlimit in USD als Dezimalzeichenfolge. `null` bedeutet unbegrenzt.</ResponseField>
<ResponseField name="data[].used_amount" type="number">Kumulierte Nutzungskosten in USD als JSON-Zahl für die Anzeige.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">Exakte kumulierte Nutzungskosten in USD als Dezimalzeichenfolge.</ResponseField>
<ResponseField name="data[].models" type="string[]">Liste zulässiger Modelle pro Schlüssel. Ein leeres Array bedeutet, dass keine zusätzliche Modellbeschränkung auf Schlüsselebene gilt.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">ISO-Zeitstempel, zu dem der Schlüssel abläuft, oder `null` ohne Ablaufdatum.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">ISO-Zeitstempel der letzten Nutzung oder `null`, wenn noch nicht verwendet.</ResponseField>
<ResponseField name="data[].created_at" type="string">ISO-Zeitstempel der Erstellung.</ResponseField>
