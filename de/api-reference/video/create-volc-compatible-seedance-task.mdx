## Überblick

Diese Endpunkte sind für Teams gedacht, die bereits die Volc-ähnliche Seedance-Aufgabenstruktur verwenden. Die Authentifizierung erfolgt mit einem TokenLab Bearer API Key. Die zurückgegebene Aufgaben-ID beginnt mit `cgt-`; fragen Sie den Status ab, bis `status` `succeeded`, `failed`, `cancelled` oder `expired` ist.

Der offizielle Task-Vertrag verwendet die REST-Pfade unter `/api/v3/contents/generations/tasks`. Die bisherigen Action-Aliase bleiben nur für ältere TokenLab-Integrationen erhalten und gehören nicht zum offiziellen Wire-kompatiblen Vertrag.

`callback_url` akzeptiert eine öffentliche HTTP(S)-Adresse. TokenLab sendet bei jedem Wechsel zu `queued`, `running`, `succeeded`, `failed` oder `expired` exakt das Abfrageobjekt und keine TokenLab-spezifischen Header. `succeeded` und `failed` werden nach fünf Sekunden bis zu dreimal erneut zugestellt.

<Note>
Senden Sie zur sicheren Wiederaufnahme nach einem Verbindungsabbruch einen eindeutigen `Idempotency-Key` mit der REST-Erstellung. Derselbe Body mit demselben Key liefert wieder dieselbe `cgt-...`-ID; derselbe Key mit einem anderen Body ergibt `409`. Dies gilt nicht für die alte Action-Route.
</Note>

Siehe auch [Seedance 2.0 Videomodelle](/de/guides/seedance-2-video) und [Videogenerierung](/de/guides/video-generation).

## Inhaltsregeln

- Verwenden Sie `type=text` für Prompt-Text.
- `type=image_url` ohne `role` wird als erstes Frame behandelt; alternativ setzen Sie `role=first_frame`.
- `role=last_frame` darf nur zusammen mit einem ersten Frame verwendet werden.
- Verwenden Sie `role=reference_image`, `reference_video` oder `reference_audio` für Referenzmedien.
- Mischen Sie keine First-/Last-Frame-Eingaben mit Referenzmedien in einer Anfrage.

## Parameterhinweise

- `ratio` akzeptiert `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9` oder `adaptive`.
- Der offizielle Standard für `generate_audio` ist `false`; setzen Sie `true`, wenn synchroner Ton benötigt wird.
- `service_tier=default` wird akzeptiert. Seedance-2.0-Kompatibilitätsaufgaben lehnen `service_tier=flex`, `frames` und `camera_fixed=true` ab.
- Wenn das gewählte Modell es unterstützt, kann `tools` Objekte wie `{ "type": "web_search" }` enthalten. Fehlerhafte Tool-Einträge werden abgelehnt statt ignoriert.

## Beispiel

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Idempotency-Key: $CLIENT_JOB_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-260128",
    "content": [
      {"type": "text", "text": "A cinematic forest at sunset"},
      {"type": "image_url", "role": "reference_image", "image_url": {"url": "https://example.com/ref.png"}}
    ],
    "ratio": "16:9",
    "duration": 5,
    "resolution": "720p",
    "generate_audio": false
  }'
```
