---
title: "Material-Asset erstellen"
openapi: "/openapi/de.json POST /v1/videos/assets"
description: "Lädt ein Seedance-Material-Asset in eine TokenLab-Materialgruppe hoch."
---

Importieren Sie eine öffentlich erreichbare Quell-URL in eine Seedance-Materialgruppe. TokenLab speichert das Material für die spätere Verwendung; verwenden Sie für die Generierung die zurückgegebene Material-Asset-`id` und nicht die Quell-URL.

Für `library_type: "aigc_avatar"` ist `group_id` optional; TokenLab verwendet oder erstellt die Standard-Gruppe für virtuelle Avatare der Organisation. Für `library_type: "liveness_face"` ist `group_id` erforderlich und muss die TokenLab-Gruppe sein, die von [Visuelles Verifizierungsergebnis abrufen](/de/api-reference/video/get-visual-validation-result) zurückgegeben wurde.

| Typ | Unterstützte Eingabe |
|------|-----------------|
| Bild | `jpeg`, `jpg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; ≤30 MiB; Breite und Höhe `[300, 6000]` px; Seitenverhältnis `[0.4, 2.5]`. |
| Video | `mp4`, `mov`; ≤200 MiB. |
| Audio | `aac`, `wav`, `mp3`; ≤15 MiB. |

TokenLab prüft Quell-URL, Medientyp, Dateigröße und lesbare Bildabmessungen. Ein angenommener Import bedeutet noch keine Verfügbarkeit: Warten Sie auf `ACTIVE` und prüfen Sie bei einem Verarbeitungsfehler `error_message`. Weitere Medien- und Gesichtsanforderungen werden während der Verarbeitung geprüft.

Die Erstellung erfolgt asynchron. Fragen Sie [Material-Asset abrufen](/de/api-reference/video/get-material-asset) ab, bis der `status` auf `ACTIVE` steht. Bei Gruppen für echte Personen wird eine Gruppe einer verifizierten Person zugeordnet; Uploads mit mehreren Gesichtern oder einem Gesicht, das nicht mit der verifizierten Person übereinstimmt, können fehlschlagen.

`project_name` trennt Ressourcen innerhalb der authentifizierten Organisation. Der Standard ist `default`; verwenden Sie für zugehörige Gruppen und Assets denselben Wert mit gleicher Groß- und Kleinschreibung. Senden Sie ihn bei POST/PUT im JSON-Body und bei GET/DELETE als Query-Parameter.

## Beispielanfrage

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"group-20260720123456-vrt01","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view","project_name":"default"}'
```

## Beispielantwort

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
