## Übersicht

Verwenden Sie die `cgt-...` ID, die bei der Erstellung zurückgegeben wurde. Pollen Sie alle paar Sekunden, solange der Task den Status `queued` oder `running` hat. Stoppen Sie, wenn der Task `succeeded`, `failed`, `cancelled` oder `expired` ist.

<Warning>
Verwenden Sie hier nicht das vereinheitlichte v1-Task-Enum oder die Response-Struktur. `/v1/tasks/{id}` verwendet `pending`, `processing`, `completed` und `failed`; dieser v3-Endpunkt verwendet das oben genannte offizielle Enum. Im v3-JSON-Objekt ist `duration` ein String, sofern vorhanden, und `error` wird weggelassen, es sei denn, der Task ist fehlgeschlagen. Ein strikter Go-Client sollte `Duration` als `string` mit dem JSON-Tag `duration,omitempty` deklarieren und bei jedem v3-Terminalstatus stoppen.
</Warning>

Siehe auch [Seedance 2.0 Videomodelle](/guides/seedance-2-video) und [Videogenerierung](/guides/video-generation).

## Statuswerte

- `queued`: akzeptiert und wartet auf Ausführung.
- `running`: Generierung läuft.
- `succeeded`: Ergebnis ist bereit und `content.video_url` ist vorhanden.
- `failed`: Generierung fehlgeschlagen; prüfen Sie `error.code` und `error.message`.
- `cancelled`: der Task wurde vor Abschluss abgebrochen.
- `expired`: der Task ist vor Abschluss abgelaufen.

## Antwortfelder

- `id`: Kompatibilitäts-Task-ID, beginnend mit `cgt-`.
- `model`: Modellkennung, die zur Kompatibilität zurückgegeben wird.
- `status`: einer der oben genannten Statuswerte.
- `content.video_url`: finale Video-URL bei Erfolg.
- `content.last_frame_url`: nur vorhanden, wenn angefordert und verfügbar.
- `usage`: Token-Verbrauch, sofern verfügbar.
- `created_at` und `updated_at`: Zeitstempel des Tasks.
- `error`: nur vorhanden, wenn der Task fehlgeschlagen ist; wird bei nicht fehlgeschlagenen Tasks weggelassen.

Die Antwort fügt niemals TokenLab-Felder wie `progress`, `return_last_frame`, `watermark`, `priority` oder `camera_fixed` hinzu.

## Beispiel

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```json
{
  "id": "cgt-20260102030405-a1b2c",
  "model": "doubao-seedance-2.0",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  },
  "usage": {
    "completion_tokens": 123456
  }
}
```

```go Go
type SeedanceTask struct {
    ID       string `json:"id"`
    Status   string `json:"status"`
    Duration string `json:"duration,omitempty"`
}

func isTerminal(status string) bool {
    switch status {
    case "succeeded", "failed", "cancelled", "expired":
        return true
    default:
        return false
    }
}
```
