---
title: "Material-Assets auflisten"
openapi: "GET /v1/videos/assets"
description: "Listet Seedance-Material-Assets auf, die der aktuellen Organisation gehören."
---

Listen Sie Material-Assets auf, die der authentifizierten Organisation gehören. Filtern Sie nach `library_type`, `group_id` oder `status`, wenn Sie Assets für einen bestimmten Generierungs-Workflow finden müssen.

Verwenden Sie nur Assets, deren `status` auf `ACTIVE` gesetzt ist. Verwenden Sie beim Erstellen von Videos die zurückgegebene TokenLab-Material-Asset-`id`.

`project_name` trennt Ressourcen innerhalb der authentifizierten Organisation. Der Standard ist `default`; verwenden Sie für zugehörige Gruppen und Assets denselben Wert mit gleicher Groß- und Kleinschreibung. Senden Sie ihn bei POST/PUT im JSON-Body und bei GET/DELETE als Query-Parameter.

## Beispielanfrage

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Beispielantwort

```json
{
  "assets": [
    {
      "id": "asset-20260720123456-qn7wr",
      "object": "seedance.material_asset",
      "project_name": "default",
      "group_id": "group-20260720123456-vrt01",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
