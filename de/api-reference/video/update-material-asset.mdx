---
title: "Material-Asset aktualisieren"
openapi: "/openapi/de.json PUT /v1/videos/assets/{assetId}"
description: "Aktualisiert ein Seedance-Material-Asset, das sich im Besitz der aktuellen Organisation befindet."
---

Aktualisieren Sie den Namen oder die Metadaten des Materials. Die Quell-URL und der Asset-Typ sind nach der Erstellung festgelegt; erstellen Sie ein neues Asset, wenn sich die Quelldatei ändert.

`project_name` trennt Ressourcen innerhalb der authentifizierten Organisation. Der Standard ist `default`; verwenden Sie für zugehörige Gruppen und Assets denselben Wert mit gleicher Groß- und Kleinschreibung. Senden Sie ihn bei POST/PUT im JSON-Body und bei GET/DELETE als Query-Parameter.

## Beispielanfrage

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"},"project_name":"default"}'
```

## Beispielantwort

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view approved",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": {"approved_by": "creative-team"},
  "created_at": 1782998400000
}
```
