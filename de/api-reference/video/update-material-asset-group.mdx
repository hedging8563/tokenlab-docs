---
title: "Material-Asset-Gruppe aktualisieren"
openapi: "/openapi/de.json PUT /v1/videos/assets/groups/{groupId}"
description: "Aktualisiert eine Seedance-Materialgruppe, die der aktuellen Organisation gehört."
---

Aktualisieren Sie den Anzeigenamen, die Beschreibung oder die Metadaten für eine Materialgruppe. Bei verwalteten Gruppen für echte Personen bleibt die Zuordnung der verifizierten Person unverändert.

`project_name` trennt Ressourcen innerhalb der authentifizierten Organisation. Der Standard ist `default`; verwenden Sie für zugehörige Gruppen und Assets denselben Wert mit gleicher Groß- und Kleinschreibung. Senden Sie ihn bei POST/PUT im JSON-Body und bei GET/DELETE als Query-Parameter.

## Beispielanfrage

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01 \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"group_name":"Updated references","description":"Images approved for summer videos","project_name":"default"}'
```

## Beispielantwort

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Updated references",
  "description": "Images approved for summer videos",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
