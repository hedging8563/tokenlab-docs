---
title: "Visuelles Verifizierungsergebnis abrufen"
openapi: "POST /api/v3"
description: "Ruft die durch die visuelle Verifizierung erzeugte Materialgruppe für echte Personen ab."
---

Rufen Sie diese Action nach dem H5-Verifizierungsablauf wiederholt auf. Ein erfolgreiches Ergebnis enthält die TokenLab-Materialgruppen-ID der verifizierten Person.

Verwenden Sie dieselbe authentifizierte Organisation, denselben Benutzer und denselben, groß-/kleinschreibungssensitiven `ProjectName` wie beim Erstellen der Sitzung.

## Endpunkt und Authentifizierung

```text
POST https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01
Authorization: Bearer <TOKENLAB_API_KEY>
Content-Type: application/json
```

Senden Sie den von [Visuelle Verifizierungssitzung erstellen](/de/api-reference/video/create-visual-validation-session) zurückgegebenen `BytedToken`. Wenn Sie beim Erstellen `ProjectName` gesetzt haben, senden Sie hier denselben Wert unter Beachtung der Groß-/Kleinschreibung. Andernfalls lassen Sie ihn weg oder verwenden `default`.

Das Ergebnis ist möglicherweise nicht sofort nach dem Browser-Callback verfügbar. Wiederholen Sie dieselbe Anfrage, bis `Result.GroupId` zurückgegeben wird oder der 30 Minuten gültige `BytedToken` abläuft. Eine wiederholte erfolgreiche Anfrage mit demselben token liefert dieselbe `GroupId`.

Verwenden Sie die zurückgegebene `GroupId` beim Erstellen von `liveness_face`-Materialien als `group_id`.

## Beispielanfrage

```bash
curl 'https://api.tokenlab.sh/api/v3?Action=GetVisualValidateResult&Version=2024-01-01' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"BytedToken":"ZXhhbXBsZS10b2tlbg","ProjectName":"default"}'
```

## Beispielantwort

```json
{
  "ResponseMetadata": {
    "RequestId": "req_def456",
    "Action": "GetVisualValidateResult",
    "Version": "2024-01-01",
    "Service": "ark",
    "Region": "cn-beijing"
  },
  "Result": {
    "GroupId": "group-20260720123456-real1"
  }
}
```

Fehler verwenden `ResponseMetadata.Error.Code` und `ResponseMetadata.Error.Message`. Eine erfolgreiche Antwort enthält `ResponseMetadata` und `Result`, nicht die Antwortstruktur anderer TokenLab-`/v1`-APIs.
