---
title: "Material-Asset-Gruppe abrufen"
openapi: "GET /v1/videos/assets/groups/{groupId}"
description: "Ruft eine Seedance-Materialgruppe anhand der TokenLab-Gruppen-ID ab."
---

Ruft eine Materialgruppe ab. Der `library_type` gibt an, ob es sich bei der Gruppe um eine Virtual-Avatar-Gruppe oder eine Real-Person-Gruppe handelt.

Verwenden Sie diesen Endpunkt vor dem Hochladen, wenn Sie bestätigen müssen, dass die Gruppe noch existiert und den `status: "ACTIVE"` aufweist.

`project_name` trennt Ressourcen innerhalb der authentifizierten Organisation. Der Standard ist `default`; verwenden Sie für zugehörige Gruppen und Assets denselben Wert mit gleicher Groß- und Kleinschreibung. Senden Sie ihn bei POST/PUT im JSON-Body und bei GET/DELETE als Query-Parameter.

## Beispielanfrage

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Beispielantwort

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
