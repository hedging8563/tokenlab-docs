## Übersicht

Löscht eine über `/v1/files` erstellte Datei. Ohne Anthropic-Header löscht die Route TokenLab-Batch-Dateien oder gebundene Bild-/Referenzdateien. Mit `anthropic-beta: files-api-2025-04-14` nutzt sie den Anthropic-Files-API-Modus für den gebundenen Workspace.

## Hinweise

- Das Löschen einer Batch-Datei entfernt den gespeicherten Batch-Dateidatensatz und verhindert, dass künftige Batch-Jobs diese Datei-ID verwenden.
- Beim Löschen einer Bild-/Referenzdatei bittet TokenLab den ausgewählten Anbieter um Löschung und entfernt danach die TokenLab-Dateibindung.
- Der Anthropic-Files-API-Modus benötigt dieselben nativen Anthropic-Header wie Upload und Abruf.

## Beispiel

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
