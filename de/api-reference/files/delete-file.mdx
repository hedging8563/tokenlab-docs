## Übersicht

Löscht eine über `/v1/files` erstellte Datei. Batch-Dateien und von TokenLab erstellte Bildreferenzdateien geben ein OpenAI-kompatibles deleted-Objekt zurück.

Wenn die Anfrage den Anthropic-Files-Kompatibilitätsmodus verwendet, löscht dieselbe Route die Anthropic-ähnliche Datei aus dem gebundenen Workspace.

## Hinweise

- Das Löschen einer Datei bricht Batch-Jobs, die sie bereits referenzieren, nicht ab.
- Fehlende oder nicht autorisierte file ids geben einen öffentlichen not-found-Fehler zurück, ohne Routingstatus offenzulegen.
- Löschen Sie Bildreferenzdateien erst, wenn keine ausstehende Bildbearbeitungsanfrage sie mehr benötigt.

## Beispiel

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
