---
title: "Modell abrufen"
openapi: "/openapi/de.json GET /v1beta/models/{model}"
description: "Modell-Metadaten im Google Gemini API-Format abrufen"
---

Gibt Metadaten für ein bestimmtes Modell im Google Gemini API-Format zurück.

## Pfadparameter

<ParamField path="model" type="string" required>
  Modellname (z. B. `gemini-2.5-pro`, `gemini-3.5-flash`). Aliase werden ebenfalls akzeptiert.
</ParamField>

## Authentifizierung

Für den öffentlichen Leseendpunkt der Modellmetadaten ist keine Authentifizierung erforderlich.

## Antwort

<ResponseField name="name" type="string">
  Modell-Ressourcenname im Format `models/{model}`.
</ResponseField>

<ResponseField name="displayName" type="string">
  Lesbarer Modellname.
</ResponseField>

<ResponseField name="inputTokenLimit" type="integer">
  Maximale Eingabe-Token (Kontextfenster).
</ResponseField>

<ResponseField name="outputTokenLimit" type="integer">
  Maximale Ausgabe-Token.
</ResponseField>

<ResponseField name="supportedGenerationMethods" type="array">
  Liste der unterstützten Generierungsmethoden (z. B. `generateContent`, `countTokens`, `embedContent`).
</ResponseField>

<ResponseField name="version" type="string">
  Öffentliche Versionszeichenfolge, sofern verfügbar.
</ResponseField>

<ResponseField name="description" type="string">
  Lesbare Modellbeschreibung, sofern verfügbar.
</ResponseField>

<ResponseField name="temperature" type="number">
  Standard-Temperatur, wenn der Upstream sie bereitstellt.
</ResponseField>

<ResponseField name="topP" type="number">
  Standard-Top-p-Wert, sofern verfügbar.
</ResponseField>

<ResponseField name="topK" type="integer">
  Standard-Top-k-Wert, sofern verfügbar.
</ResponseField>

<ResponseField name="maxTemperature" type="number">
  Maximale unterstützte Temperatur, sofern verfügbar.
</ResponseField>

## Fehler

- Ungültige GETs, die versehentlich `:generateContent` oder `:streamGenerateContent` enthalten, geben `405 METHOD_NOT_ALLOWED` zurück.
- Fehlende Modelle geben `404 NOT_FOUND` zurück.

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1beta/models/gemini-2.5-pro"
```

```python Python
import google.generativeai as genai

genai.configure(
    api_key="sk-your-api-key",
    transport="rest",
    client_options={"api_endpoint": "api.tokenlab.sh"}
)

model = genai.get_model("models/gemini-2.5-pro")
print(f"Name: {model.name}")
print(f"Input limit: {model.input_token_limit}")
print(f"Output limit: {model.output_token_limit}")
```
</RequestExample>
