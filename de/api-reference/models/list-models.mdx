---
title: "Modelle auflisten"
openapi: "GET /v1/models"
description: "Listet die aktuell auf TokenLab verfügbaren Modelle auf"
---

Der Modellkatalog ist öffentlich und erfordert keinen API-Key. Jeder Eintrag enthält eine Zusammenfassung der aktuellen Funktionen, Preise und API-Formate. Rufen Sie ein einzelnes Modell ab, wenn Sie vollständige Details benötigen.

## Abfrageparameter

<ParamField query="category" type="string">
  Filtern nach `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank` oder `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  Gibt aktuelle Empfehlungen für eine Aufgabe zurück, wie z. B. `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank` oder `translation`.
</ParamField>

<ParamField query="provider" type="string">
  Filtern nach dem Modellhersteller, wie z. B. `openai`, `anthropic`, `google` oder `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  Filtern nach einem Tag wie `chat`, `image`, `video`, `embedding` oder `translation`.
</ParamField>

## Antwort

<ResponseField name="object" type="string">Immer `list`.</ResponseField>
<ResponseField name="data" type="array">Modelle mit `id`, `owned_by` und einer `tokenlab`-Zusammenfassung.</ResponseField>

Zu den allgemeinen Listenfeldern unter `tokenlab` gehören:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` und `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` und `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial` und `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` wenn `recommended_for` verwendet wird

Wenn `recommended_for` verwendet wird, können die Ergebnisse auch den Empfehlungsstatus und einen Aktualisierungszeitpunkt enthalten. Lesen Sie die aktuelle Antwort, anstatt die Reihenfolge fest zu kodieren.

## Beispiel

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```
