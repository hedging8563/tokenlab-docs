---
title: "Musik-Status abrufen"
openapi: "GET /v1/tasks/{id}"
description: "Ruft den Status und das Ergebnis einer Musik-Generierungsaufgabe ab"
---

Fragen Sie diesen Endpunkt ab, um den Status Ihrer Musik-Generierungsaufgabe zu überprüfen.

<Info>
Wenn die Create-Response `poll_url` enthält, sollten Sie zum Polling bevorzugt genau diese URL verwenden. `id` und `task_id` sollten als dieselbe asynchrone Task-ID behandelt werden.


Ein abgelaufener oder nicht verfügbarer öffentlicher Task kann `404 async_task_not_found` zurückgeben. Ist die Zugehörigkeit zum aktuellen API-Schlüssel nicht feststellbar, lautet die Antwort `403 task_not_owned`.
</Info>

## Pfad-Parameter

<ParamField path="id" type="string" required>
  Die ID der Musik-Generierungsaufgabe.
</ParamField>

## Antwort

<ResponseField name="id" type="string">
  Aufgaben-ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias derselben asynchronen Aufgaben-ID, sofern zurückgegeben.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Bevorzugte Polling-URL, wenn die Erstellungsantwort sie bereitstellt.
</ResponseField>

<ResponseField name="status" type="string">
  Aufgabenstatus: `pending`, `processing`, `completed` oder `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Optionaler Fortschrittswert. Wird nur zurückgegeben, wenn ein echter Fortschrittswert verfügbar ist; verwenden Sie `status`, um den Abschluss zu erkennen.
</ResponseField>

Ergebnisfelder hängen von der Operation ab. Musik kann `audio_url` und `audio_id`, reine Songtexte `lyrics` und Spurentrennung mehrere Dateien in `data` liefern. `video_url`, Titel, Fortschritt und weitere Metadaten sind optional. Prüfen Sie den Abschluss über `status` und lesen Sie die tatsächlich gelieferten Felder.

<ResponseField name="audio_id" type="string">
  Optionale Audio-ID für unterstützte Folgeoperationen zusammen mit dieser Aufgaben-ID.
</ResponseField>

<ResponseField name="data" type="array">
  Optionales Ausgabe-Array, etwa getrennte Audiodateien mit `audio_url` oder `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  URL zum Herunterladen der Audiodatei (wenn abgeschlossen).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL zur Videoversion mit Visualizer (wenn abgeschlossen).
</ResponseField>

<ResponseField name="title" type="string">
  Generierter Songtitel.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Generierter oder bereitgestellter Songtext.
</ResponseField>

<ResponseField name="error" type="string | object">
  Fehlermeldung (wenn fehlgeschlagen).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh/v1/tasks/{task_id}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh/v1/tasks/${taskId}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    for {
        req, err := http.NewRequest("GET",
            fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID), nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';

while (true) {
    $ch = curl_init("https://api.tokenlab.sh/v1/tasks/{$taskId}");

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [

    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
```
