---
title: "Musik erstellen"
openapi: "/openapi/de.json POST /v1/music/generations"
description: "Erstellt eine Musikgenerierungsaufgabe mit Suno"
---

Generieren Sie Musik und Songtexte mithilfe von KI. Dies ist eine asynchrone API. Die Create-Response gibt eine Task-ID zurück und kann, wenn verfügbar, auch eine bevorzugte `poll_url` enthalten.

## Anfrage-Body

<ParamField body="model" type="string" default="suno_music">
  Musikmodell-ID, etwa `suno-music`. Wählen Sie für reine Songtexte ein Modell, dessen aktuelle öffentliche Operationen `lyrics` enthalten.
</ParamField>

<ParamField body="prompt" type="string">
  Musikbeschreibung oder Ersatztext. Erforderlich für Musik, Songtexte, upload-cover, upload-extend und replace-section; optional für add-instrumental und Spurentrennung.
</ParamField>

<ParamField body="title" type="string">
  Titel für den generierten Song.
</ParamField>

<ParamField body="tags" type="string">
  Stil-Tags (z. B. „pop, upbeat, electronic“).
</ParamField>

<ParamField body="negative_tags" type="string">
  Zu vermeidende Stile. Erforderlich, wenn `audio_operation` `add-instrumental` ist.
</ParamField>

<ParamField body="action" type="string">
  Optional `MUSIC` oder `LYRICS`. Wählen Sie ein Modell mit der passenden öffentlichen Operation; dieses Feld erweitert ein reines Musikmodell nicht um Songtextgenerierung.
</ParamField>

<ParamField body="mv" type="string">
  Suno-Versionsauswahl. Erforderlich für Generierung, upload-cover, upload-extend, add-instrumental und Ersetzung aus `audio_url`. Bei Songtexten, Ersetzung aus `task_id` + `audio_id` und Spurentrennung weglassen. Zulässige Werte: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  Auf `true` setzen, um ein instrumentales Ergebnis ohne Gesang zu erzeugen.
</ParamField>

<ParamField body="audio_url" type="string">
  Öffentlich erreichbare Referenz- oder Upload-Audio-URL. Ohne `audio_operation` verwendet TokenLab den upload-cover-Flow.
</ParamField>

<ParamField body="audio_operation" type="string">
  Audiooperation: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation` und `advanced-split` benötigen `task_id` + `audio_id`; `advanced-split` zusätzlich `stem_name`. `upload-extend` benötigt `continue_at` größer als 0. `add-instrumental` benötigt `audio_url`, `title`, `tags` und `negative_tags`.

  `replace-section` benötigt `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s` und `full_lyrics`. Wählen Sie genau eine Quelle: `task_id` + `audio_id` oder `audio_url` + `mv`. Das Ersatzintervall muss 6–60 Sekunden betragen.
</ParamField>

<ParamField body="task_id" type="string">
  Quellaufgaben-ID Ihrer Organisation für die Ersetzung generierten Audios oder die Spurentrennung.
</ParamField>

<ParamField body="audio_id" type="string">
  Audio-ID aus dem Ergebnis der Quellaufgabe. Für die Ersetzung generierten Audios und die Spurentrennung zusammen mit `task_id` erforderlich.
</ParamField>

<ParamField body="infill_start_s" type="number">
  Beginn der Ersetzung in Sekunden, mindestens 0. Für `replace-section` erforderlich.
</ParamField>

<ParamField body="infill_end_s" type="number">
  Ende der Ersetzung in Sekunden. Für `replace-section` erforderlich und 6–60 Sekunden nach `infill_start_s`.
</ParamField>

<ParamField body="full_lyrics" type="string">
  Vollständiger Songtext des resultierenden Songs. Für `replace-section` erforderlich.
</ParamField>

<ParamField body="stem_name" type="string">
  Name der Tonspur. Für `advanced-split` erforderlich.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  ID eines vorherigen Clips, an dem fortgesetzt werden soll.
</ParamField>

<ParamField body="continue_at" type="number">
  Zeitpunkt in Sekunden für die Fortsetzung. Für `upload-extend` erforderlich und größer als 0.
</ParamField>

<Note>
`prompt` erlaubt bis zu 5000 Zeichen; `tags` und `negative_tags` jeweils bis zu 1000. Unterstützte Operationen und Parameter richten sich nach den aktuellen Modelldetails.
</Note>

## Antwort

<ResponseField name="id" type="string">
  Task-ID für die Statusabfrage.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias derselben asynchronen Aufgaben-ID, sofern zurückgegeben.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Bevorzugte Polling-URL, wenn verfügbar.
</ResponseField>

<ResponseField name="status" type="string">
  Task-Status: `pending`, `processing`, `completed` oder `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  Unix-Zeitstempel der Aufgabenerstellung, sofern zurückgegeben.
</ResponseField>

curl -X POST "https://api.tokenlab.sh/v1/music/generations" \

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
