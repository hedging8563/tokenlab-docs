---
title: "Batch abbrechen"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "Bricht einen wartenden oder laufenden Batch-Job ab."
---

Fordern Sie den Abbruch eines wartenden oder laufenden Batches an. Die Antwort enthält den aktuellen Status: Der Abbruch kann noch laufen oder bereits abgeschlossen sein. Ein bereits beendeter Batch behält seinen bisherigen Endstatus. Rufen Sie den Batch erneut ab, wenn der zurückgegebene Status noch nicht endgültig ist.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Kennung für Folgeaufrufe und Support.</ResponseField>
<ResponseField name="status" type="string">Aktueller Batch-Status. Eine erfolgreiche Abbruchanfrage gibt nicht immer `cancelling` zurück.</ResponseField>
