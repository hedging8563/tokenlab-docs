## 概述

不用另装 TokenLab 专用 SDK。项目里已经在用哪个客户端，就继续用哪个，只需换成 TokenLab 的 API 密钥和地址：

- Chat Completions 和 Responses 使用 **OpenAI SDK**。
- Claude Messages 使用 **Anthropic SDK**。
- Gemini 请求使用 **Gemini / Google AI SDK**。

对应的集成页面提供了可直接使用的配置，也会注明模型本身的限制。

## OpenAI SDK 示例

Chat Completions 和 Responses 都可以使用这个客户端。调用前请确认所选模型支持对应的 API 方法。

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.responses.create(
    model="gpt-5.6-terra",
    input="Explain TokenLab in one sentence."
)

print(response.output_text)
```

## OpenAI Go 示例

```go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-api-key"),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
    )

    _ = client
}
```

## Anthropic SDK 示例

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh"
)

message = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}]
)
```

## 按需要选择 SDK

| 需要 | SDK |
|------|------------------|
| 已有 OpenAI 兼容客户端 | OpenAI SDK + TokenLab `/v1` |
| Chat Completions、Responses 或 Embeddings | OpenAI SDK |
| Claude Messages 字段 | Anthropic SDK |
| Gemini contents、文件、缓存或工具 | Gemini / Google AI SDK |
| LangChain、LlamaIndex、Vercel AI SDK | 查看对应集成页面 |

## 配置说明

<AccordionGroup>
  <Accordion title="模型专属字段留在对应格式中">
    Claude Messages 与 Gemini 表示工具、流式内容和消息的方式不同。应用依赖这些字段时，请使用对应 SDK。
  </Accordion>

  <Accordion title="已有 OpenAI 客户端可以继续使用">
    原有的 OpenAI 兼容聊天和 Embeddings 客户端，通常只需更换 API 密钥和 Base URL。
  </Accordion>

  <Accordion title="明确填写 Base URL">
    在客户端配置中直接填写 TokenLab Base URL，不要依赖旧的环境变量别名。
  </Accordion>
</AccordionGroup>
