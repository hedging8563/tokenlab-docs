---
title: "Worlds"
description: "用文字、图片或视频创建可探索的 Marble 世界"
---

Worlds 可以创建一个能打开、探索和再次访问的 Marble 世界。如果需要的是可下载的单个模型，请使用 3D 生成。

## 输入与素材

根据模型能力，可以用文字、单张图片、多张图片或视频创建世界。需要重复使用的媒体只需上传一次，之后通过素材 ID 引用。

媒体和世界记录按 API Key 所属组织校验访问权限。分享世界前，请核对所选模型的 `permission` 选项；返回的素材或查看链接可能有独立的访问规则。

## 创建并查询状态

创建成功后会返回任务 ID，通常还会提供 `poll_url`。保存这个 ID，通过 `poll_url` 或 `GET /v1/tasks/{id}` 查询，直到状态变为 `completed` 或 `failed`。

```bash
curl -X POST "https://api.tokenlab.sh/v1/worlds/generations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "marble-1.1",
    "prompt": "A quiet coastal town at sunset with narrow alleys and warm lights"
  }'
```

## 查看和删除 Worlds

Worlds 列表和详情 API 会返回当前账户中已经完成的世界。仍在生成或已经失败的任务通过任务状态 API 查询。只有用户明确删除结果时才调用删除 API。

## 常见问题

- 不要假设每个 World 模型都支持所有输入类型。
- 带签名的图片或视频 URL 要保持足够长的有效期，确保服务能够读取。
- 请求超时后，确认没有创建任务再重新提交。
- 需要可下载模型文件时使用 3D 生成，而不是 Worlds。
