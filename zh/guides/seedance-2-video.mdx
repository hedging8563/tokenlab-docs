本页帮你选定 Seedance 2.0 模型和 API。火山迁移、可复用素材和真人验证另有完整指南。

## 选择 API

| 你要做什么 | 使用方式 | 指南 |
| --- | --- | --- |
| 新建 TokenLab 视频接入 | 统一 `POST /v1/videos/generations` API | [视频生成指南](/zh/guides/video-generation) |
| 迁移现有火山 Seedance 客户端 | 火山兼容 REST 或 Action 接口 | [从火山迁移 Seedance](/zh/guides/seedance-volcengine-migration) |
| 复用虚拟人、商品、风格或真人引用 | TokenLab 素材库 | [Seedance 素材与真人验证](/zh/guides/seedance-materials) |

三种方式都使用 `Authorization: Bearer <TOKENLAB_API_KEY>`。火山兼容请求保留原有字段，但鉴权要换成 TokenLab API 密钥。

## 模型选择

| 模型 | 可用分辨率 |
| --- | --- |
| `seedance-2.0` | `480p`, `720p`, `1080p`, `4k` |
| `seedance-2.0-fast` | `480p`, `720p` |
| `seedance-2.0-mini` | `480p`, `720p` |

`seedance-2.0-fast` 和 `seedance-2.0-mini` 不支持 `1080p` 和 `4k`。音频只能与支持的参考素材一起使用，不能只传音频，也不能只传文字和音频。

## 生成类型

| 操作 | 典型输入 |
|-----------|----------------|
| `text-to-video` | `prompt` |
| `image-to-video` | `prompt`, `image_url` 或兼容的图像输入 |
| `start-end-to-video` | `prompt`, `start_image`, `end_image` |
| `reference-to-video` | `prompt`, `reference_images`, 可选 `video_urls`, 可选 `audio_urls` |
| `video-to-video` | `prompt`, `video_url` 或兼容的视频输入 |
| `video-extension` | `task_id` 或模型特定的续写输入 |

请明确填写 `operation`，以便 API 按对应的生成类型校验参数。`seedance-2.0` 和 `seedance-2.0-fast` 在支持参考生成时，最多接受 9 张参考图、3 段参考视频和 3 段参考音频。纯音频，或只有文字和音频的请求暂不支持。

## 价格与生成结果

Seedance 2.0 的价格取决于模型、输入类型和输出分辨率。产品中需要展示价格时，请从 [Pricing API](/zh/api-reference/pricing/get-pricing) 或 [Models API](/zh/api-reference/models/list-models) 读取。

视频生成完成前，使用创建请求返回的 `poll_url` 查询状态；也可以用任务 ID 调用[获取任务状态](/zh/api-reference/tasks/get-task-status)。
