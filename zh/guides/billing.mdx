所有模型共用一份 TokenLab 余额。没有订阅，也没有最低消费；每笔费用都按模型价格和实际用量计算。

## 一份结果，只扣一次费用

每个完成的请求只扣一次费用，价格取决于最终完成请求的交付方式：

- `TokenLab Verified` 使用 TokenLab 公开价格。
- `Official` 使用基于模型厂商公开价的 Official 价格层。
- `Auto` 默认优先使用 TokenLab Verified，需要时改用 Official。只按最终完成请求的方式计费。

需要确认的付费生成会在 Console 显示最高预估金额。完成后，Runs 和 Usage 会显示最终费用；未使用的预留金额会释放。

## 定价模式

模型价格可能变化。当前价格以 Console、模型页、`GET /v1/models/:model/pricing` 和 [Pricing API](/api-reference/pricing/get-pricing) 为准。

模型页的 TokenLab 价格或折扣显示“—”时，表示当前没有 TokenLab Verified 报价，不代表免费。有 Official 供应的模型仍可通过 Official 或 Auto 使用。交付方式的“支持”描述可选方式，实时可用性在每次请求时校验。模型系列价格仅汇总对应交付方式有供应的成员，不混合比较不同计费单位。

### 按 Token 计费

多数聊天、推理、嵌入、rerank 以及部分图像模型按输入、输出、缓存或图像输出 token 计费。

| 计费类型 | 示例 | 如何确认当前价格 |
|---|---|---|
| Chat / Responses | `gpt-5.4`, `claude-sonnet-4-6`, `gemini-3.5-flash` | 模型页或 Pricing API |
| 嵌入 / rerank | `text-embedding-3-small`, `qwen3-vl-rerank` | 模型价格详情 |
| 按 token 计费的图像 | `gpt-image-2` | `GET /v1/models/gpt-image-2/pricing` |

<Note>
不要把复制下来的价格表写死在代码里。应用需要展示或比较费用时，读取当前价格。
</Note>

### 按请求和任务计费

图片、视频、音乐、3D、音频和 World 模型可能按次、张、秒、分钟或任务计费。模型页会写明计费单位。

| 家族 | 示例 |
|---|---|
| 图像 | `flux-pro` |
| 视频 | `veo3.1`, `seedance-2.0` |
| 音乐 | `suno-music` |
| 3D | `tripo-h3.1` |
| 音频 | `tts-1`, `whisper-1` |

### 异步任务计费

<Note>
  部分任务会在创建时预留预估费用。任务完成后只扣一次；任务失败时，待扣金额会释放或退回。
</Note>

视频、音乐、3D 和异步图片生成会返回任务 ID 与 `poll_url`。任务变为 `completed` 或 `failed` 后记录最终金额。成功任务会在计费完成后返回 `billing_transaction_id`；失败任务不扣费。

任务结束后，如果 Usage 仍没有显示最终费用或释放金额，请把请求 ID 和任务 ID 发到 support@tokenlab.sh。

### `billing_transaction_id`

非流式 OpenAI 兼容响应如果在返回前完成结算，会带上 `billing_transaction_id`。同一个值也可能出现在 `X-Billing-Transaction-ID` 响应头中；Gemini 等原生格式可能只在响应头里提供。

异步任务完成结算后会返回 `billing_transaction_id`。流式响应可能早于结算结束；响应头里没有这个字段时，到 Usage 查询即可。

## Token 数

文字模型通常会在 `usage` 中返回输入、输出和总 token 数。不同模型、语言和媒体输入的分词方式不同，按字符数估算并不可靠。费用请以当前模型价格和最终 Usage 记录为准。

## 查询用量

打开 [Usage](https://tokenlab.sh/dashboard/usage)，可以找到：

- 实时余额
- 按模型分类的使用历史
- 费用明细
- 每把 API 密钥的用量

### API 响应

按 Token 计费的响应通常会包含用量信息：

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## 余额提醒

在 **Console → Settings** 设置余额阈值。余额低于阈值时，TokenLab 会发送邮件。

## 充值

打开 **Console → Billing**，选择金额和结账页显示的支付方式。支付平台确认成功后，余额会更新。

## API 密钥限额

在 **Console → API 密钥** 创建或编辑密钥时，可以设置单独的费用上限。

达到上限后，使用这把密钥的请求会返回 `402 Payment Required`。

## 账单帮助

如有账单咨询，请联系 support@tokenlab.sh。
