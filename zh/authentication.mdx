## API 密钥

所有 TokenLab API 请求都需要 API 密钥。

对于兼容 OpenAI 的端点，请按如下方式发送：

```bash
Authorization: Bearer sk-your-api-key
```

对于兼容 Anthropic 的 `/v1/messages` 请求，你也可以使用：

```bash
x-api-key: sk-your-api-key
```

## 管理令牌

管理 API 使用单独的令牌：

```bash
Authorization: Bearer mt-your-management-token
```

管理令牌只用于 `/v1/management/*`。在 Console 的 **Settings** 页面创建或轮换；完整令牌只显示一次。

<Note>
管理令牌不能调用模型，普通的 `sk-...` API 密钥也不能调用管理 API。
</Note>

## 获取 API 密钥

1. 登录 [TokenLab Console](https://tokenlab.sh/dashboard)
2. 打开 **API 密钥**
3. 创建一把新密钥
4. 起一个好认的名字
5. 马上复制。完整密钥只显示一次

<Warning>
- 不要把 API 密钥写进前端代码
- 不要把 API 密钥提交到版本库
- 用环境变量或密钥管理器保存
- 定期轮换密钥
- 删掉不用的密钥
</Warning>

## 使用 API 密钥

<CodeGroup>

```bash cURL
curl https://api.tokenlab.sh/v1/responses \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "input": "Hello!"
  }'
```

```python Python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ.get("TOKENLAB_API_KEY"),
    base_url="https://api.tokenlab.sh/v1"
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1'
});
```

</CodeGroup>

## 设置用量上限

你可以为每把 API 密钥设置用量上限：

| 设置 | 描述 |
|---------|-------------|
| **不限额** | API 密钥可以使用全部账户余额 |
| **固定额度** | 用量达到指定金额后，这把密钥会停止工作 |

## 密钥前缀

所有 TokenLab API 密钥都以 `sk-` 开头。

## Anthropic 兼容性

对于 `/v1/messages` 端点，Anthropic 风格的请求头可按预期工作：

```bash
curl https://api.tokenlab.sh/v1/messages \
  -H "x-api-key: sk-your-api-key" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-5",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

<Note>
OpenAI 兼容接口（包括 `/v1/responses`、`/v1/chat/completions` 和 `/v1/models`）使用 `Authorization: Bearer ...`。
</Note>

## 错误响应

| 状态码 | 类型 | 代码 | 描述 |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | 缺少或无效的 API 密钥 |
| 401 | `expired_api_key` | `expired_api_key` | API 密钥已过期 |
| 402 | `insufficient_balance` | `insufficient_balance` | 账户余额不足 |
| 402 | `quota_exceeded` | `quota_exceeded` | 已达到 API 密钥用量上限 |

示例：

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
