## 用 TokenLab 接入模型

TokenLab 让应用或编程工具用一把 API 密钥接入 AI 模型，所有模型共用工作区余额。选择模型及其支持的 API 格式，请求按公开价格计费。

## 可以做什么

当前模型 ID、可用性、支持格式和价格以[模型目录](https://tokenlab.sh/zh/models)为准。

| 能力 | 说明 |
|---|---|
| 聊天与推理 | 文本生成、规划、工具调用 |
| 视觉与多模态 | 图像理解与多模态对话 |
| 图片生成与编辑 | 文生图与图片编辑 |
| 视频生成 | 文生视频、图生视频、参考视频与运动控制 |
| 音频与 Realtime WebSocket | TTS、转写、音频翻译和实时 WebSocket 会话 |
| 嵌入与 rerank | 文本向量化与重排序 |
| 翻译 | 文本翻译和 WebSocket 语音翻译流程 |
| 音乐与 3D | 音乐和 3D 资产生成 |
| Worlds | World 生成、状态轮询和媒体资产流程 |
