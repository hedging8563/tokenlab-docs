## 用 TokenLab 接入模型

一把 API 密钥，就能调用聊天、图片、视频、音频、向量等模型。所有模型共用余额，按实际用量付费。

<CardGroup cols={2}>
  <Card title="一把 API 密钥" icon="key">
    聊天、图片、视频、音频、向量和重排序模型都能调用。
  </Card>
  <Card title="需要哪种格式，就用哪种" icon="shuffle">
    现有 OpenAI 客户端可以继续用；需要 Anthropic 或 Gemini 原生行为时，也有对应格式。
  </Card>
  <Card title="价格清楚" icon="tags">
    模型页会列出每个模型当前的 TokenLab 价格和计费单位。
  </Card>
  <Card title="按量付费" icon="coins">
    所有模型共用一份余额，不需要订阅。
  </Card>
</CardGroup>

## 可以做什么

模型会不断上新或下线。当前可用模型和价格以 `/v1/models` 与模型页为准。

| 能力 | 说明 | 示例模型 |
|---|---|---|
| 聊天与推理 | 文本生成、规划、工具调用 | `gpt-5.4`、`claude-sonnet-4-6`、`deepseek-r1` |
| 视觉与多模态 | 图像理解与多模态对话 | `gpt-4o`、`claude-sonnet-4-6`、`gemini-3.5-flash` |
| 图片生成与编辑 | 文生图与图片编辑 | `gpt-image-2`、`flux-pro`、`qwen-image-plus` |
| 视频生成 | 文生视频、图生视频、参考视频与运动控制 | `veo3.1`, `wan-2.7`, `kling-3.0-video`, `happyhorse-1.0` |
| 音频与 Realtime WebSocket | TTS、转写、音频翻译和实时 WebSocket 会话 | `gpt-4o-mini-tts`, `whisper-1`, `gpt-realtime` |
| 嵌入与 rerank | 文本向量化与重排序 | `text-embedding-3-small`, `qwen3-vl-rerank` |
| 翻译 | 文本翻译和 WebSocket 语音翻译流程 | `doubao-seed-translation`, `gpt-realtime-translate` |
| 音乐与 3D | 音乐和 3D 资产生成 | `suno-music`, `tripo-h3.1` |
| Worlds | World 生成、状态轮询和媒体资产流程 | 使用 `/v1/worlds/generations` 与 Models API 确认当前可用性 |

## 选择请求格式

现有 OpenAI 客户端可以直接使用 `/v1/chat/completions`。只有需要 Anthropic 或 Gemini 特有行为时，才选择对应的原生格式。

<CodeGroup>

```bash cURL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "messages": [
      {"role": "user", "content": "Explain what TokenLab does in one sentence."}
    ]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="gpt-5.6-terra",
    messages=[{"role": "user", "content": "Explain what TokenLab does in one sentence."}]
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Explain what TokenLab does in one sentence.' }],
});

console.log(response.choices[0].message.content);
```

<Note>
仅在明确需要 Responses 特定行为时使用 `POST /v1/responses`。这并非所有模型的默认兼容路径。
</Note>

</CodeGroup>
