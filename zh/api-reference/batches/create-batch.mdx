---
title: "创建批处理"
openapi: "/openapi/zh.json POST /v1/batches"
description: "使用已上传的 JSONL 文件创建批处理任务。"
---

上传 `purpose=batch` 的 JSONL 文件后，把文件 ID 作为 `input_file_id` 创建任务。任务完成时会返回输出文件和错误文件。

## 注意事项

- 批处理输入文件必须使用 `purpose=batch`。
- `completion_window` 当前为 `24h`。
- 输出顺序可能与输入不同，请用每行的 `custom_id` 对应结果。
- 批处理项内不支持流式传输。
- 支持的批处理项端点为 `/v1/chat/completions` 和 `/v1/embeddings`，不支持 `/v1/responses`。

## 示例

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "input_file_id": "file_abc123",
    "endpoint": "/v1/chat/completions",
    "completion_window": "24h"
  }'
```
</RequestExample>

批处理价格可能与同步请求不同，以创建时显示的价格和最终账单为准。

## 响应示例

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "endpoint": "/v1/chat/completions",
  "input_file_id": "file_abc123",
  "completion_window": "24h",
  "status": "validating",
  "output_file_id": null,
  "error_file_id": null,
  "created_at": 1706000000
}
```
</ResponseExample>

## 重要字段

<ResponseField name="id" type="string">批处理任务 ID。</ResponseField>
<ResponseField name="status" type="string">批处理任务的状态。</ResponseField>
<ResponseField name="output_file_id" type="string|null">任务完成后的输出文件 ID。</ResponseField>
