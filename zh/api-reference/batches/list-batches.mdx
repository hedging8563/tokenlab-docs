---
title: "列出批处理任务"
openapi: "/openapi/zh.json GET /v1/batches"
description: "列出当前工作区的批处理任务。"
---

返回当前工作区创建的批处理任务。

## 示例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/batches?limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## 响应示例

<ResponseExample>
```json 200 OK
{
  "object": "list",
  "data": [{ "id": "batch_abc123", "object": "batch", "status": "completed" }],
  "first_id": "batch_abc123",
  "last_id": "batch_abc123",
  "has_more": false
}
```
</ResponseExample>

## 重要字段

<ResponseField name="object" type="string">固定为 `list`。</ResponseField>
<ResponseField name="data" type="array">批处理任务列表。</ResponseField>
<ResponseField name="status" type="string">每个批处理任务的状态。</ResponseField>
<ResponseField name="has_more" type="boolean">`has_more` 为 true 时还有后续结果。</ResponseField>
