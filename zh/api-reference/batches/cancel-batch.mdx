---
title: "取消批处理"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "取消尚未完成的批处理任务。"
---

请求取消排队或运行中的批处理。响应返回任务的当前状态，可能仍在取消，也可能已取消完成。已经结束的任务保留原有终态。返回状态尚未结束时，请再次获取批处理任务以确认结果。

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">批处理任务 ID。</ResponseField>
<ResponseField name="status" type="string">批处理当前状态。取消请求成功并不一定返回 `cancelling`。</ResponseField>
