---
title: "取消批处理"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "取消尚未完成的批处理任务。"
---

批处理仍在排队或运行时可以请求取消。响应状态变为 `cancelling` 后，通过 [获取批处理任务](/zh/api-reference/batches/retrieve-batch) 查询最终状态。

## 示例

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## 响应示例

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

## 重要字段

<ResponseField name="id" type="string">批处理任务 ID。</ResponseField>
<ResponseField name="status" type="string">取消请求接受后为 `cancelling`。</ResponseField>
