---
title: "获取批处理任务"
openapi: "/openapi/zh.json GET /v1/batches/{batch_id}"
description: "获取批处理任务的状态、请求数量和结果文件。"
---

返回批处理任务的状态、成功和失败数量，以及任务结束后的结果文件 ID。

## 示例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/batches/batch_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## 响应示例

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "completed",
  "input_file_id": "file_abc123",
  "output_file_id": "file_out123",
  "error_file_id": "file_err123",
  "request_counts": { "total": 100, "completed": 98, "failed": 2 }
}
```
</ResponseExample>

## 重要字段

<ResponseField name="request_counts" type="object">总请求数、成功数、失败数和取消数。</ResponseField>
<ResponseField name="output_file_id" type="string|null">成功结果文件 ID。</ResponseField>
<ResponseField name="error_file_id" type="string|null">失败结果文件 ID。</ResponseField>
