---
title: "获取价格"
openapi: "/openapi/zh.json GET /v1/pricing"
description: "获取模型的定价信息"
---

这是公开接口，不需要 API 密钥。

返回当前可用模型的公开价格。

复杂计费项和模型完整信息见[获取模型](/zh/api-reference/models/get-model)。

## 查询参数

<ParamField query="provider" type="string">
  可选的提供方筛选，例如 `openai`、`anthropic` 或 `google`。
</ParamField>

<ParamField query="tag" type="string">
  可选的模型标签筛选，例如 `chat`、`image`、`video`、`embedding` 或 `translation`。
</ParamField>

## 响应

<ResponseField name="object" type="string">
  始终为 `pricing`。
</ResponseField>

<ResponseField name="updated_at" type="string">
  当前公开价格发布时的 ISO 时间戳。
</ResponseField>

<ResponseField name="currency" type="string">
  始终为 `USD`。
</ResponseField>

<ResponseField name="data" type="array">
  价格列表。每项包含模型、厂商、能力、别名和价格详情。
</ResponseField>
