---
title: "创建 3D 模型"
openapi: "POST /v1/3d/generations"
description: "根据文字或图片生成 3D 模型"
---

用文字或图片创建 3D 模型。创建成功后会返回任务 ID，通过任务接口查询进度和结果。

该接口不使用 `operation`。只有 `prompt` 时为文生 3D；带有 `image` 或 `image_url` 时为图生 3D。不要发送旧字段 `3d-generation`。

## 请求体

发送可选字段前，请通过 `GET /v1/models/{model}` 查看该模型接受的参数。示例只发送 `model` 和 `prompt`。

<ParamField body="model" type="string" default="tripo-h3.1">
  要使用的模型，例如 `tripo-h3.1` 或 `tripo-p1.0`。发送图片或指定输出格式前，请通过 `GET /v1/models?recommended_for=3d` 查看模型详情。
</ParamField>

<ParamField body="prompt" type="string" required>
  要生成的 3D 模型的文本描述。
</ParamField>

<ParamField body="image" type="string">
  用于图像转 3D 生成的 Base64 编码图像。
</ParamField>

<ParamField body="image_url" type="string">
  用于图像转 3D 生成的图像 URL。
</ParamField>

<ParamField body="format" type="string">
  输出格式；是否支持及允许值取决于所选模型。
</ParamField>

<ParamField body="quality" type="string">
  质量设置；是否支持及允许值取决于所选模型。
</ParamField>

<ParamField body="style" type="string">
  模型的风格预设。
</ParamField>

<ParamField body="seed" type="integer">
  整数种子，仅在所选模型支持时使用。
</ParamField>

<ParamField body="user" type="string">
  终端用户的唯一标识符。
</ParamField>

## 响应

<ResponseField name="id" type="string">
  用于查询状态的任务 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
  返回时与 `id` 对应的同一异步任务标识。
</ResponseField>

<ResponseField name="poll_url" type="string">
  返回时优先使用的任务轮询 URL。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态：`pending`、`processing`、`completed` 或 `failed`。
</ResponseField>

<ResponseField name="created" type="integer">
  任务创建的 Unix 时间戳。
</ResponseField>

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":   "tripo-h3.1",
        "prompt":  "A detailed medieval castle with towers",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/3d/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
