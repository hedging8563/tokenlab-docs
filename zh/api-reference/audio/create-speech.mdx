## 请求体

该接口会在音频生成完成后返回。内容较长时，请将 HTTP 客户端超时设为至少 `120s`。

可选字段取决于模型。OpenAI TTS 可使用 `voice`、`instructions`、`response_format`、`stream_format` 和 `speed`；MiniMax 语音还可使用 `voice_id`；Gemini TTS 可使用 `prompt`、`language_code` 和 `temperature`。不支持的字段会返回 `400 unsupported_parameter`。

<ParamField body="model" type="string" default="tts-1">
  TTS 模型 ID。通过 `GET /v1/models?recommended_for=tts` 获取当前可用模型。
</ParamField>

<ParamField body="input" type="string" required>
  用于生成音频的文本。最大 4096 个字符。
</ParamField>

<ParamField body="voice" type="string | object">
  语音选择器。可以传入 `nova` 等内置语音、`Kore` 等 Gemini 语音，或为兼容的自定义语音传入 `{ "id": "voice-id" }`。
</ParamField>

<ParamField body="voice_id" type="string">
  MiniMax 语音模型使用的语音 ID。
</ParamField>

<ParamField body="instructions" type="string">
  朗读风格或语气说明，适用于支持该字段的 OpenAI TTS 模型。
</ParamField>

<ParamField body="prompt" type="string">
  Gemini TTS 的朗读风格说明。
</ParamField>

<ParamField body="language_code" type="string">
  语言代码，例如 `en-US`。适用于 Gemini、xAI 和其他支持该字段的 TTS 模型。
</ParamField>

<ParamField body="response_format" type="string">
  音频格式。常见值包括 `mp3`、`opus`、`aac`、`flac`、`wav` 和 `pcm`，以模型详情为准。
</ParamField>

<ParamField body="stream_format" type="string" default="audio">
  返回方式：`audio` 或 `sse`。`tts-1` 和 `tts-1-hd` 不支持 `sse`。
</ParamField>

<ParamField body="speed" type="number">
  语速，范围为 0.25–4.0。只在支持该字段的模型中生效。
</ParamField>

<ParamField body="temperature" type="number">
  Gemini TTS 的采样温度，范围为 0–2。
</ParamField>

## 响应

返回所请求格式的音频文件。

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/speech" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tts-1-hd",
    "voice": "nova",
    "input": "Hello, welcome to TokenLab!"
  }' \
  --output speech.mp3
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.audio.speech.create(
    model="tts-1-hd",
    voice="nova",
    input="Hello, welcome to TokenLab!"
)

response.stream_to_file("speech.mp3")
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.speech.create({
  model: 'tts-1-hd',
  voice: 'nova',
  input: 'Hello, welcome to TokenLab!'
});

const buffer = Buffer.from(await response.arrayBuffer());
fs.writeFileSync('speech.mp3', buffer);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/speech');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'tts-1-hd',
        'voice' => 'nova',
        'input' => 'Hello, welcome to TokenLab!'
    ])
]);

$audio = curl_exec($ch);
curl_close($ch);

file_put_contents('speech.mp3', $audio);
```
</RequestExample>

## 重要字段

<ResponseField name="Content-Type" type="string">返回音频的媒体类型；使用 `sse` 时为事件流类型。</ResponseField>
<ResponseField name="body" type="binary">音频内容，直接保存为文件。</ResponseField>
