## 请求体

转录可能直接返回文本，也可能以 HTTP `200`、`id` 和 `status` 返回已接受的异步任务。异步任务请按 `poll_url` 查询，或使用 `/v1/tasks/{id}`。同步处理较长音频时，请将客户端超时设为至少 `120s`。

<ParamField body="file" type="file" required>
  要转录的音频文件。支持的格式：flac、mp3、mp4、mpeg、mpga、m4a、ogg、wav、webm。 最大文件大小：25 MB。
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  转录模型 ID，例如 `whisper-1` 或 `gpt-4o-transcribe`。通过 `GET /v1/models?recommended_for=stt` 获取当前可选模型。
</ParamField>

<ParamField body="language" type="string">
  音频的语言，采用 ISO-639-1 格式（例如：`en`、`zh`、`ja`）。
</ParamField>

<ParamField body="prompt" type="string">
  可选提示词，可补充专有名词、上下文或期望的文字风格。
</ParamField>

<ParamField body="response_format" type="string" default="json">
  输出格式。Whisper 支持 `json`、`text`、`srt`、`verbose_json` 和 `vtt`；其他模型支持的范围可能不同，请查询模型详情。
</ParamField>

<ParamField body="temperature" type="number">
  采样温度，范围为 0–1，仅适用于支持此参数的模型。
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  所选模型支持时，可指定 `word` 和/或 `segment`。Whisper 需要 `response_format=verbose_json`。multipart 请求中，多值应重复发送 `timestamp_granularities[]`。
</ParamField>

## 响应

以下字段用于 JSON 转录或翻译响应。`text`、`srt` 和 `vtt` 返回原始文本或字幕，而不是 JSON 对象。附加字段取决于模型和输出格式。

<ResponseField name="text" type="string">
  转录后的文本。
</ResponseField>

对于 `verbose_json`：

<ResponseField name="task" type="string">
  返回时表示任务名称，例如 `transcribe`。
</ResponseField>

<ResponseField name="language" type="string">
  检测到的语言。
</ResponseField>

<ResponseField name="duration" type="number">
  音频时长，单位为秒。
</ResponseField>

<ResponseField name="segments" type="array">
  带时间戳的转录片段。
</ResponseField>

<ResponseField name="words" type="array">
  词级时间戳（如已请求）。
</ResponseField>

已接受的异步转录任务返回以下字段，而不是转录文本：

<ResponseField name="id" type="string">
  任务 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
  返回时，作为异步任务标识的别名。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态：`pending`、`processing`、`completed` 或 `failed`。
</ResponseField>

<ResponseField name="poll_url" type="string">
  创建响应提供时，优先使用的轮询 URL。
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## 翻译成英文

需要英文结果时，使用音频翻译接口：

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
