---
title: "取消任务（火山兼容）"
openapi: "/openapi/zh.json DELETE /api/v3/contents/generations/tasks/{id}"
description: "在任务仍可取消时取消 Seedance 兼容任务。"
---

任务仍在排队或处理中时可以尝试取消。成功时返回 HTTP 200，响应体为空。

另见 [Seedance 2.0 视频模型](/zh/guides/seedance-2-video) 和 [视频生成](/zh/guides/video-generation)。

## 可能的结果

- 任务仍在排队或仍可取消时，取消请求可以成功。
- 如果任务已经完成、失败、过期或不再可取消，接口会返回错误；请查询任务确认当前状态。
- 取消成功后不会返回视频；可通过查询任务接口确认最终状态。

## 示例

```bash
curl -X DELETE https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
