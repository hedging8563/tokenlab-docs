---
title: "获取素材"
openapi: "GET /v1/videos/assets/{assetId}"
description: "通过素材 ID 获取一个 Seedance 素材。"
---

获取素材及其处理状态。`ready` 为 `true` 且 `status` 为 `ACTIVE` 时即可用于视频生成。

如果返回 `Seedance material asset not found or not accessible`，请确认传入的是素材 `id`，不是 `group_id`。

`project_name` 用于同一组织内的资源隔离，默认为 `default`。相关素材组和素材须使用相同且区分大小写的值；POST/PUT 在 JSON 请求体中传入，GET/DELETE 在查询参数中传入。

## 请求示例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 响应示例

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
