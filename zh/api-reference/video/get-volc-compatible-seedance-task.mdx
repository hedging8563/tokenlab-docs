## 概览

使用创建响应返回的 `cgt-...` ID 查询任务。任务处于 `queued` 或 `running` 时每隔几秒轮询一次；到 `succeeded`、`failed`、`cancelled` 或 `expired` 就停止。

<Warning>
v3 与 `/v1/tasks/{id}` 的状态名称不同，不要复用 v1 的枚举或响应结构体。v3 JSON 中的 `duration` 是字符串，`error` 只在失败时出现。Go 客户端可将 `Duration` 声明为 `string`，JSON tag 使用 `duration,omitempty`，并在每个 v3 终态停止轮询。
</Warning>

另见 [Seedance 2.0 视频模型](/zh/guides/seedance-2-video) 和 [视频生成](/zh/guides/video-generation)。

## 状态值

- `queued`：已接受，等待执行。
- `running`：正在生成。
- `succeeded`：结果已就绪，`content.video_url` 可用。
- `failed`：生成失败，请查看 `error.code` 和 `error.message`。
- `cancelled`：任务在完成前被取消。
- `expired`：任务在完成前过期。

## 响应字段

- `id`：以 `cgt-` 开头的任务 ID。
- `model`：模型 ID。
- `status`：上述状态之一。
- `content.video_url`：成功后的最终视频 URL。
- `content.last_frame_url`：仅在请求且可用时返回。
- `usage`：可用时返回 token 用量。
- `created_at` 和 `updated_at`：任务时间戳。
- `error`：仅任务失败时返回；非失败任务不返回该字段。

该响应不包含 `progress`、`return_last_frame`、`watermark`、`priority` 或 `camera_fixed`。

## 示例

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```json
{
  "id": "cgt-20260102030405-a1b2c",
  "model": "doubao-seedance-2.0",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  },
  "usage": {
    "completion_tokens": 123456
  }
}
```

```go Go
type SeedanceTask struct {
    ID       string `json:"id"`
    Status   string `json:"status"`
    Duration string `json:"duration,omitempty"`
}

func isTerminal(status string) bool {
    switch status {
    case "succeeded", "failed", "cancelled", "expired":
        return true
    default:
        return false
    }
}
```
