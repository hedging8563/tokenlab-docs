---
title: "列出素材"
openapi: "GET /v1/videos/assets"
description: "列出当前工作区的 Seedance 素材。"
---

列出当前工作区的素材。可用 `library_type`、`group_id` 或 `status` 筛选。

只有 `status` 为 `ACTIVE` 的素材可以用于视频生成。

## 示例请求

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 示例响应

```json
{
  "assets": [
    {
      "id": "asset-20260720123456-qn7wr",
      "object": "seedance.material_asset",
      "group_id": "group-20260720123456-vrt01",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
