---
title: "删除素材"
openapi: "DELETE /v1/videos/assets/{assetId}"
description: "删除当前工作区的 Seedance 素材。"
---

删除素材不会影响所属素材组。删除后，这个 ID 不能再用于视频生成。

## 请求示例

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X DELETE \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 响应示例

```json
{
  "deleted": true,
  "id": "asset-20260720123456-qn7wr"
}
```
