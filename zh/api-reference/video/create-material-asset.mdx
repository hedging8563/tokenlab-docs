---
title: "创建素材"
openapi: "POST /v1/videos/assets"
description: "把图片、视频或音频保存为可复用的 Seedance 素材。"
---

提交一个可公开访问的文件 URL，TokenLab 会将它保存到 Seedance 素材组。后续生成使用返回的素材 `id`。

`library_type: "aigc_avatar"` 可以省略 `group_id`，素材会进入工作区的默认素材组。`library_type: "liveness_face"` 必须传入 [视觉验证结果](/zh/api-reference/video/get-visual-validation-result) 返回的素材组 ID。

| 类型 | 支持的输入 |
|------|-----------------|
| 图像 | `jpeg`, `jpg`, `png`, `webp`, `bmp`, `tiff`, `gif`, `heic`, `heif`; ≤30 MiB; 宽度和高度 `[300, 6000]` px; 宽高比 `[0.4, 2.5]`. |
| 视频 | `mp4`, `mov`; ≤200 MiB. |
| 音频 | `aac`, `wav`, `mp3`; ≤15 MiB. |

TokenLab 会检查来源 URL、媒体类型、文件大小和可读取的图像尺寸。导入受理不代表素材已就绪：请等待 `ACTIVE`，处理失败时查看 `error_message`。其他媒体及人脸要求在处理期间校验。

素材需要一些时间处理。通过 [获取素材](/zh/api-reference/video/get-material-asset) 查询状态；`status` 变为 `ACTIVE` 后即可使用。真人素材组只对应一位已验证人员，图片中出现多张人脸或人员不一致时会处理失败。

`project_name` 用于同一组织内的资源隔离，默认为 `default`。相关素材组和素材须使用相同且区分大小写的值；POST/PUT 在 JSON 请求体中传入，GET/DELETE 在查询参数中传入。

## 请求示例

```bash
curl https://api.tokenlab.sh/v1/videos/assets \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_id":"group-20260720123456-vrt01","asset_url":"https://example.com/reference.png","asset_type":"Image","asset_name":"Front view","project_name":"default"}'
```

## 响应示例

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "PROCESSING",
  "ready": false,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
