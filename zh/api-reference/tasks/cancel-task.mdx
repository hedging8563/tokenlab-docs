---
title: "取消任务"
openapi: "DELETE /v1/tasks/{id}"
description: "取消仍在排队并且支持取消的异步任务"
---

## 概览

`DELETE /v1/tasks/{id}` 可以取消尚未开始运行、并且支持取消的任务。ID 来自创建响应或 `poll_url`。

## 支持范围

当前可以取消仍在排队的部分 Seedance 视频任务，包括 `seedance-1.5-pro`、`seedance-2.0` 和 `seedance-2.0-fast`。已经进入 `processing` / `running` 的任务不能取消。无论是否支持取消，任务仍可以用于状态查询和费用核对。

## 路径参数

<ParamField path="id" type="string" required>
  由 create 请求返回或包含在 `poll_url` 中的异步任务 ID。
</ParamField>

## 响应

<ResponseField name="id" type="string">
  TokenLab 任务 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
  同一个任务 ID 的兼容字段名。
</ResponseField>

<ResponseField name="poll_url" type="string">
  任务状态查询地址，取消后仍然有效。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态。成功取消的任务会以 `failed` 返回，并带有 `cancelled: true`，以兼容现有状态值。
</ResponseField>

<ResponseField name="cancelled" type="boolean">
  任务在执行前被取消时为 `true`。
</ResponseField>

<ResponseField name="cancellation_status" type="string">
  取消标记。取消成功时值为 `cancelled`。
</ResponseField>

<ResponseField name="error" type="string">
  取消原因或任务失败信息。
</ResponseField>

## 错误行为

`400 unsupported_task_cancel` 表示这个任务不支持取消。`409 task_not_cancellable` 表示任务已经开始、已经结束或无法再取消。`403` 表示当前 API 密钥无权访问。

## 示例

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

```json Response
{
  "id": "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "task_id": "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "poll_url": "/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
  "status": "failed",
  "cancelled": true,
  "cancellation_status": "cancelled",
  "error": "Task cancelled before execution"
}
```
