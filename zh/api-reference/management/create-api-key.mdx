---
title: "创建 API Key"
openapi: "POST /v1/management/api-keys"
description: "为当前组织创建新的用户 API Key。"
---

## 概览

该接口会在当前管理令牌所属的组织下创建一个新的 `type=user` API Key。

## 请求体

| 字段 | 类型 | 默认值 / 限制 | 说明 |
|------|------|---------------|------|
| `name` | string | 必填，默认 `Default Key`，长度 `1-50` | 展示名称，服务端会去除首尾空格 |
| `limitAmount` | number \| null | 最小 `0`，输入上限 `1000000` | `null` 或省略 = 不限额，`0` = 零额度，正数会被规范化为一个存储上限，且不能超过 `100000` USD 等值 |
| `limitCurrency` | enum | 默认 `USD` | 仅支持 USD。发送 `CNY` 会返回 `400 currency_retired`。 |
| `models` | string[] | 默认 `[]` | 可选的模型白名单 |
| `expiresAt` | string \| null | RFC3339 datetime | `null` 表示永不过期 |

## 说明

- 金额字段仅支持 USD。`CNY` 输入已停用，并会返回 `400 currency_retired`。

- 响应中的完整 API Key 只会返回一次。
- `models: []` 表示该 Key 除组织级策略外没有额外模型限制。
- `limitAmount: 0` 会创建一个合法但无法消费额度的 Key，后续可再更新。

## 示例

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "kling-3.0-video"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>

## 重要字段

<ResponseField name="key" type="string">完整的 API Key 密钥，仅在创建时返回一次。</ResponseField>
<ResponseField name="id" type="string">用于后续管理 API 调用的 API Key 标识符。</ResponseField>
<ResponseField name="name" type="string">API Key 的显示名称。</ResponseField>
<ResponseField name="key_prefix" type="string">用于展示和支持排查的非敏感 Key 前缀。</ResponseField>
<ResponseField name="status" type="string">取值为 `active`、`inactive` 或 `revoked`。</ResponseField>
<ResponseField name="limit_amount" type="number | null">以 JSON 数字返回的 USD 消费上限，用于展示。`null` 表示不限额。</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">以十进制字符串返回的 USD 精确消费上限。`null` 表示不限额。</ResponseField>
<ResponseField name="used_amount" type="number">以 JSON 数字返回的 USD 累计用量消费，用于展示。</ResponseField>
<ResponseField name="used_amount_decimal" type="string">以十进制字符串返回的 USD 精确累计用量消费。</ResponseField>
<ResponseField name="models" type="string[]">单个 Key 的模型白名单。空数组表示没有额外的 Key 级模型限制。</ResponseField>
<ResponseField name="expires_at" type="string | null">Key 到期时间的 ISO 时间戳；`null` 表示永不过期。</ResponseField>
<ResponseField name="last_used_at" type="string | null">最近一次使用的 ISO 时间戳；从未使用时为 `null`。</ResponseField>
<ResponseField name="created_at" type="string">创建时间的 ISO 时间戳。</ResponseField>
