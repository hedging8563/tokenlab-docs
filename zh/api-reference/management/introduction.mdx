title: "管理 API"
description: "查询工作区余额，管理 API 密钥，获取用量和账单。"

管理 API 适合在自己的后台或自动化程序中管理 TokenLab 工作区。它使用管理令牌，不需要把普通 API 密钥交给管理程序。

在 Console 的 **设置** 页面创建管理令牌：

```bash
Authorization: Bearer mt-your-management-token
```

<Warning>
管理令牌与 API 密钥用途不同。`mt-...` 只能调用 `/v1/management/*`；`sk-...` 用于 `/v1/responses` 等模型接口。
</Warning>

## 可用接口

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/v1/management/balance` | GET | 获取工作区余额 |
| `/v1/management/api-keys` | GET | 列出 API 密钥 |
| `/v1/management/api-keys` | POST | 创建 API 密钥 |
| `/v1/management/api-keys/{keyId}` | PATCH | 修改名称、额度、模型范围、过期时间或状态 |
| `/v1/management/api-keys/{keyId}/usage` | GET | 获取逐条用量记录 |
| `/v1/management/api-keys/{keyId}/billing` | GET | 获取汇总账单 |

## API 密钥

- 新密钥的完整值只在创建响应中出现一次。
- `models: []` 表示不增加密钥级模型限制。
- `limitAmount: null` 表示不限额，`0` 表示不能产生费用。
- 金额只支持 USD；传入 `CNY` 会返回 `400 currency_retired`。
- `inactive` 可重新启用；`revoked` 用于永久停用。

## 用量与账单

`/usage` 返回分页后的逐条记录，可以按模型、模型厂商、场景和日期筛选。完成结算的记录会带有 `billing_transaction_id`，可与 `request_id` 一起保存。

`/billing` 返回总费用、请求数、token 用量、模型和日期等汇总，不返回逐条记录。充值和发票不包含在 API 密钥账单中。

## 示例

```bash
curl "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```

```json
{
  "object": "organization_balance",
  "organization_id": "org_123",
  "balance": 42.5,
  "balance_decimal": "42.50",
  "total_recharge": 100,
  "total_recharge_decimal": "100",
  "total_used": 57.5,
  "total_used_decimal": "57.50"
}
```
