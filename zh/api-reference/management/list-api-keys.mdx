返回管理令牌所属工作区的 API 密钥列表。

本页提供 OpenAPI 结构说明和可复制的请求示例。请在终端或客户端使用 Management Token 发送管理请求；本页不提供直接发送功能。

## 注意事项

- 金额字段仅支持 USD。

- 只返回用户创建的 API 密钥。

## 示例

<ParamField query="page" type="integer" default="1">从 1 开始的页码。</ParamField>
<ParamField query="limit" type="integer" default="50">每页条数，范围为 1–100。</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 重要字段

<ResponseField name="object" type="string">固定为 `list`。</ResponseField>
<ResponseField name="data" type="array">API 密钥列表。</ResponseField>
<ResponseField name="pagination" type="object">分页元数据，包含 `page`、`limit`、`total` 和 `totalPages`。</ResponseField>
<ResponseField name="data[].id" type="string">密钥 ID。</ResponseField>
<ResponseField name="data[].name" type="string">API 密钥的显示名称。</ResponseField>
<ResponseField name="data[].key_prefix" type="string">可以安全显示的密钥前缀。</ResponseField>
<ResponseField name="data[].status" type="string">取值为 `active`、`inactive`、`suspended` 或 `revoked`。</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">以 JSON 数字返回的 USD 消费上限，用于展示。`null` 表示不限额。</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">以十进制字符串返回的 USD 精确消费上限。`null` 表示不限额。</ResponseField>
<ResponseField name="data[].used_amount" type="number">以 JSON 数字返回的 USD 累计用量消费，用于展示。</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">以十进制字符串返回的 USD 精确累计用量消费。</ResponseField>
<ResponseField name="data[].models" type="string[]">模型白名单。空数组表示没有额外的密钥级模型限制。</ResponseField>
<ResponseField name="data[].delivery_policy" type="string | null">`auto`, `verified`, `official`, `null`. `null` 表示继承工作区交付策略。</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">密钥到期时间；`null` 表示永不过期。</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">最近一次使用的 ISO 时间戳；从未使用时为 `null`。</ResponseField>
<ResponseField name="data[].created_at" type="string">创建时间的 ISO 时间戳。</ResponseField>
