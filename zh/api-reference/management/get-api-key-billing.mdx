---
title: "获取 API Key 账单"
openapi: "GET /v1/management/api-keys/{keyId}/billing"
description: "返回某个用户 API Key 的聚合账单明细。"
---

## 概览

这个端点返回所选 API Key 的消费账单聚合结果，包括总费用、总请求数、按计费单位统计的用量，以及 `by_model`、`by_logical_model`、`by_model_vendor`、`by_scene` 四类拆分和按天费用趋势。

## 注意事项

- 金额字段仅支持 USD。`CNY` 输入已停用，并会返回 `400 currency_retired`。

- 充值、发票等组织级财务流水不会包含在这里。

## 示例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 重要字段

<ResponseField name="api_key" type="object">API Key 摘要，字段与列出、创建和更新响应相同。</ResponseField>
<ResponseField name="summary" type="object">按所选筛选条件汇总的总计。</ResponseField>
<ResponseField name="breakdowns" type="object">按所选筛选条件汇总的明细拆分。</ResponseField>
<ResponseField name="summary.total_requests" type="number">请求总数。</ResponseField>
<ResponseField name="summary.total_cost" type="number">以 JSON 数字返回的 USD 总费用，用于展示。</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">以十进制字符串返回的 USD 精确总费用。</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">提示 token 总数。</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">补全 token 总数。</ResponseField>
<ResponseField name="summary.total_tokens" type="number">token 总数。</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">按计量单位分组的用量。</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">按请求时使用的公开模型拆分。</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">按逻辑公开模型拆分。</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">按公开模型厂商拆分。</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">按公开请求场景拆分。</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">每日费用趋势。</ResponseField>
