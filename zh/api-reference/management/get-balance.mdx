---
title: "获取工作区余额"
openapi: "GET /v1/management/balance"
description: "获取管理令牌所属工作区的余额。"
---

返回管理令牌所属工作区的余额、累计充值和累计用量费用。

## 注意事项

- 金额字段仅支持 USD。`CNY` 输入已停用，并会返回 `400 currency_retired`。

- 金额以 USD 返回。需要精确计算时，请使用 `balance_decimal`、`total_recharge_decimal` 和 `total_used_decimal`。

## 示例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 响应示例

<ResponseExample>
```json 200 OK
{
  "object": "organization_balance",
  "organization_id": "org_123",
  "balance": 42.5,
  "balance_decimal": "42.50",
  "total_recharge": 100,
  "total_recharge_decimal": "100",
  "total_used": 57.5,
  "total_used_decimal": "57.50"
}
```
</ResponseExample>

## 重要字段

<ResponseField name="object" type="string">固定为 `organization_balance`。</ResponseField>
<ResponseField name="organization_id" type="string">工作区 ID。</ResponseField>
<ResponseField name="balance" type="number">工作区余额，单位为 USD。</ResponseField>
<ResponseField name="balance_decimal" type="string">工作区余额的精确十进制字符串。</ResponseField>
<ResponseField name="total_recharge" type="number">累计充值金额，单位为 USD。</ResponseField>
<ResponseField name="total_recharge_decimal" type="string">累计充值金额的精确十进制字符串。</ResponseField>
<ResponseField name="total_used" type="number">累计用量费用，单位为 USD。</ResponseField>
<ResponseField name="total_used_decimal" type="string">累计用量费用的精确十进制字符串。</ResponseField>
