---
title: "列出模型"
openapi: "GET /v1/models"
description: "列出当前可用模型"
---

模型目录是公开接口，不需要 API 密钥。每个模型都带有当前能力、价格和 API 格式摘要；需要完整信息时，再查询单个模型。

## 查询参数

<ParamField query="category" type="string">
  按类别筛选：`chat`、`image`、`video`、`audio`、`tts`、`stt`、`music`、`3d`、`embedding`、`rerank` 或 `translation`。
</ParamField>

<ParamField query="recommended_for" type="string">
  获取某类任务的当前推荐模型，例如 `image`、`video`、`music`、`3d`、`tts`、`stt`、`embedding`、`rerank` 或 `translation`。
</ParamField>

<ParamField query="provider" type="string">
  按模型厂商筛选，例如 `openai`、`anthropic`、`google` 或 `deepseek`。
</ParamField>

<ParamField query="tag" type="string">
  按标签筛选，例如 `chat`、`image`、`video`、`embedding` 或 `translation`。
</ParamField>

## 响应

<ResponseField name="object" type="string">
  固定为 `list`。
</ResponseField>

<ResponseField name="data" type="array">
  模型列表。每项包含 `id`、`owned_by` 和 `tokenlab` 摘要。
</ResponseField>

`tokenlab` 中常用的列表字段包括：

- `tokenlab.aliases`：公开别名。
- `tokenlab.capabilities`：模型能力。
- `tokenlab.pricing` 与 `tokenlab.pricing_unit`：当前价格和计费单位。
- `tokenlab.max_input_tokens` 与 `tokenlab.max_output_tokens`：上下文和输出上限。
- `tokenlab.category`：模型类别。
- `tokenlab.lifecycle`、`tokenlab.commercial` 与 `tokenlab.badges`：当前状态、收费方式和页面标签。
- `tokenlab.request_format_summary`：适用的 API 地址和操作。
- `tokenlab.agent_preferences`：使用 `recommended_for` 时返回的推荐信息。

使用 `recommended_for` 时，响应还可能包含推荐状态和更新时间。推荐顺序会变化，请在使用时读取最新结果。

## 示例

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```

单个模型的完整字段见[获取模型](/zh/api-reference/models/get-model)。
