---
title: "获取模型"
openapi: "GET /v1/models/{model}"
description: "获取模型的能力、价格和 API 格式"
---

## 路径参数

<ParamField path="model" type="string" required>
  模型 ID，例如 `gpt-5.4` 或 `claude-sonnet-4-6`。
</ParamField>

## 响应

<ResponseField name="id" type="string">
  模型 ID。
</ResponseField>

<ResponseField name="object" type="string">
  固定为 `model`。
</ResponseField>

<ResponseField name="owned_by" type="string">
  模型厂商。
</ResponseField>

<ResponseField name="tokenlab" type="object">
  TokenLab 模型信息，包括能力、价格、计费单位、上下文长度、可用 API 格式、支持的操作和生命周期状态。
</ResponseField>

常用字段包括：

- `tokenlab.capabilities`：文本、图片、视频、音频等能力。
- `tokenlab.pricing`：当前公开价格。
- `tokenlab.max_input_tokens` 与 `max_output_tokens`：上下文和输出上限。
- `tokenlab.accepted_request_formats`：可用的 API 格式。
- `tokenlab.supported_operations`：文生图、图生视频等可用操作。
- `tokenlab.lifecycle`：当前状态、发布日期、弃用日期或替代模型。

部分媒体模型还会返回推荐状态和更新时间。推荐信息会随模型表现与可用性变化，不要在应用中固定排序。

## 示例

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.4"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["text"],
    "accepted_request_formats": ["responses", "chat_completions"]
  }
}
```

模型不存在时返回 `404 model_not_found`。
