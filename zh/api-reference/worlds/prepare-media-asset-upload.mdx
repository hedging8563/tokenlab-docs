---
title: "准备 World 素材上传"
openapi: "POST /v1/worlds/media-assets/prepare-upload"
description: "获取 World 图片或视频素材的上传地址"
---

创建 World 素材并获取上传地址。把文件上传到 `upload_info.upload_url` 后，在 `world_prompt` 中使用返回的 `media_asset.media_asset_id`。

素材只对当前工作区可见，也只能在这个工作区中用于 World 生成。

## 请求体

<ParamField body="file_name" type="string" required>
  原始文件名，最多 64 个字符。
</ParamField>

<ParamField body="kind" type="string" required>
  媒体类型：`image` 或 `video`。
</ParamField>

<ParamField body="extension" type="string | null">
  可选扩展名，例如 `png`、`jpg` 或 `mp4`。
</ParamField>

<ParamField body="metadata" type="object | null">
  与素材一起保存的自定义信息。
</ParamField>

## 响应

<ResponseField name="media_asset" type="object">
  已创建的 World Labs 素材信息。
</ResponseField>

<ResponseField name="upload_info.upload_url" type="string">
  用于上传文件的签名 URL。
</ResponseField>

<ResponseField name="upload_info.upload_method" type="string">
  上传二进制文件到 `upload_info.upload_url` 时使用的 HTTP 方法（如有返回）。
</ResponseField>

<ResponseField name="upload_info.required_headers" type="object">
  上传二进制文件时需要附带的请求头（如有返回）。
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/worlds/media-assets/prepare-upload" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "file_name": "reference.png",
    "kind": "image",
    "extension": "png"
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/worlds/media-assets/prepare-upload",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={"file_name": "reference.png", "kind": "image", "extension": "png"},
)

print(response.json()["media_asset"]["media_asset_id"])
```

```javascript JavaScript
const response = await fetch('https://api.tokenlab.sh/v1/worlds/media-assets/prepare-upload', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer sk-your-api-key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ file_name: 'reference.png', kind: 'image', extension: 'png' })
});

const prepared = await response.json();
console.log(prepared.media_asset.media_asset_id, prepared.upload_info.upload_url);
```
</RequestExample>
