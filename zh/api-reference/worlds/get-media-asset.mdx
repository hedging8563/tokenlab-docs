---
title: "获取 World 素材"
openapi: "GET /v1/worlds/media-assets/{id}"
description: "获取 World 素材信息"
---

获取 World 素材的文件名、类型和自定义信息。只有创建它的工作区可以访问。

## 路径参数

<ParamField path="id" type="string" required>
  World Labs 素材 ID。
</ParamField>

## 响应

<ResponseField name="media_asset_id" type="string">
  World Labs 素材 ID。
</ResponseField>

<ResponseField name="file_name" type="string">
  原始文件名，最多 64 个字符。
</ResponseField>

<ResponseField name="kind" type="string">
  媒体类型：`image` 或 `video`。
</ResponseField>

<ResponseField name="metadata" type="object | null">
  与素材一起保存的自定义信息。
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/worlds/media-assets/media_asset_123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

response = requests.get(
    "https://api.tokenlab.sh/v1/worlds/media-assets/media_asset_123",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const response = await fetch('https://api.tokenlab.sh/v1/worlds/media-assets/media_asset_123', {
  headers: { Authorization: 'Bearer sk-your-api-key' }
});
console.log(await response.json());
```
</RequestExample>
