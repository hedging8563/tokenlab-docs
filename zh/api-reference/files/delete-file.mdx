---
title: "删除文件"
openapi: "DELETE /v1/files/{file_id}"
description: "删除当前工作区中已上传的文件。"
---

删除通过 `/v1/files` 上传的文件。成功后返回带有 `deleted: true` 的文件对象。

使用 Anthropic Files 请求头时，也可以删除当前工作区的 Anthropic 格式文件。

## 注意事项

- 删除文件不会取消已经引用该文件的批处理任务。
- 文件不存在或当前密钥无权访问时，会返回未找到错误。
- 只有在没有待处理的图像编辑请求需要该引用文件后，才删除图像参考文件。

## 示例

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
