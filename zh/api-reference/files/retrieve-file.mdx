---
title: "获取文件信息"
openapi: "/openapi/zh.json GET /v1/files/{file_id}"
description: "获取一个已上传文件的信息。"
---

返回文件名、大小、用途和创建时间。不带 Anthropic 请求头时，可查询批处理文件和图片参考文件；携带对应请求头时，可查询 Anthropic 格式文件。

## 示例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## 图像参考文件

此端点也可以返回 TokenLab 创建的图像参考文件元数据。`status` 字段是可选的；某些文件类型可能不会提供该字段。

## 响应示例

<ResponseExample>
```json 200 OK
{
  "id": "file_abc123",
  "object": "file",
  "bytes": 32768,
  "created_at": 1706000000,
  "filename": "batch-input.jsonl",
  "purpose": "batch"
}
```
</ResponseExample>

## 重要字段

<ResponseField name="id" type="string">文件 ID。</ResponseField>
<ResponseField name="filename" type="string">文件名。</ResponseField>
<ResponseField name="purpose" type="string">文件用途，例如 `batch`、`batch_output`、`user_data` 或 `vision`。</ResponseField>
