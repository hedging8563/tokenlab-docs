---
title: "获取文件内容"
openapi: "GET /v1/files/{file_id}/content"
description: "下载文件内容。"
---

下载批处理输入、输出或错误文件。携带 Anthropic Files 请求头时，也可以下载当前工作区的 Anthropic 格式文件。

## 示例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files/file_abc123/content" \
  -H "Authorization: Bearer sk-your-api-key" \
  --output batch-output.jsonl
```
</RequestExample>

## 使用说明

- 使用 `custom_id` 把输出与输入记录一一对应。
- 批处理完成后，响应才会出现 `output_file_id` 和 `error_file_id`。

## 内容类型

批处理文件以 JSONL 或纯文本返回；图片参考文件以二进制返回。

## 响应示例

<ResponseExample>
```jsonl 200 OK
{"custom_id":"request-1","response":{"status_code":200,"body":{"id":"chatcmpl_abc123"}}}
{"custom_id":"request-2","error":{"code":"invalid_request_error","message":"Invalid model"}}
```
</ResponseExample>

## 重要字段

<ResponseField name="body" type="binary|string">文件内容。请根据 `Content-Type` 保存或解析；JSONL 应逐行解析。</ResponseField>
<ResponseField name="custom_id" type="string">批处理输入项和结果之间的对应 ID。</ResponseField>
