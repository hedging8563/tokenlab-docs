---
title: "列出文件"
openapi: "GET /v1/files"
description: "列出当前工作区已上传的文件。"
---

列出批处理文件和图片参考文件。可用 `purpose=batch`、`purpose=batch_output`、`purpose=user_data` 或 `purpose=vision` 筛选。

携带 Anthropic Files 请求头时，返回当前工作区的 Anthropic 格式文件。

## 示例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files?purpose=batch&limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## 筛选条件

- `limit` 接受 1 到 10000，默认值为 10000。
- `purpose` 可以是 `batch`、`batch_output`、`user_data` 或 `vision`。
- 当存在 TokenLab 创建的图像参考文件时，`user_data` 和 `vision` 会返回这些文件。

## 响应示例

<ResponseExample>
```json 200 OK
{
  "object": "list",
  "data": [{ "id": "file_abc123", "object": "file", "purpose": "batch" }]
}
```
</ResponseExample>

## 重要字段

<ResponseField name="object" type="string">固定为 `list`。</ResponseField>
<ResponseField name="data" type="array">文件列表。</ResponseField>
