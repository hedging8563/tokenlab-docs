---
title: "创建音乐"
openapi: "/openapi/zh.json POST /v1/music/generations"
description: "使用 Suno 创建音乐生成任务"
---

生成音乐或歌词。创建成功后会返回任务 ID，通过状态 API 获取最终结果。

## 请求体

<ParamField body="model" type="string" default="suno_music">
  音乐模型 ID，例如 `suno-music`。仅生成歌词时，请选择当前公开操作包含 `lyrics` 的模型。
</ParamField>

<ParamField body="prompt" type="string">
  音乐描述或替换文本。音乐、歌词、upload-cover、upload-extend 和 replace-section 请求必填；add-instrumental 和分轨请求可省略。
</ParamField>

<ParamField body="title" type="string">
  生成歌曲的标题。
</ParamField>

<ParamField body="tags" type="string">
  风格标签（例如 "pop, upbeat, electronic"）。
</ParamField>

<ParamField body="negative_tags" type="string">
  需要避开的风格。`audio_operation` 为 `add-instrumental` 时必填。
</ParamField>

<ParamField body="action" type="string">
  可选值为 `MUSIC` 或 `LYRICS`。请选择支持对应公开操作的模型；此字段不会让仅支持音乐的模型具备歌词能力。
</ParamField>

<ParamField body="mv" type="string">
  Suno 版本选择器。生成、upload-cover、upload-extend、add-instrumental 以及以 `audio_url` 为源的替换请求必填。歌词、以 `task_id` + `audio_id` 为源的替换和分轨请求请省略。支持值： `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  设为 `true` 时生成无歌声的纯音乐。
</ParamField>

<ParamField body="audio_url" type="string">
  可以从互联网访问的参考音频 URL。填写这个字段但省略 `audio_operation` 时，默认使用 `upload-cover`。
</ParamField>

<ParamField body="audio_operation" type="string">
  音频操作： `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`、`multi-stem-separation` 和 `advanced-split` 需要 `task_id` + `audio_id`；`advanced-split` 还需要 `stem_name`。`upload-extend` 需要大于 0 的 `continue_at`。`add-instrumental` 需要 `audio_url`、`title`、`tags` 和 `negative_tags`。

  `replace-section` 必须提供 `prompt`、`tags`、`title`、`infill_start_s`、`infill_end_s` 和 `full_lyrics`。来源只能二选一：`task_id` + `audio_id`，或 `audio_url` + `mv`。替换区间必须为 6–60 秒。
</ParamField>

<ParamField body="task_id" type="string">
  本组织拥有的源任务 ID，用于生成音频的分段替换或分轨。
</ParamField>

<ParamField body="audio_id" type="string">
  源任务结果返回的音频 ID。替换已生成音频和分轨时，需要与 `task_id` 一起提供。
</ParamField>

<ParamField body="infill_start_s" type="number">
  替换区间的起始秒数，必须大于等于 0。`replace-section` 必填。
</ParamField>

<ParamField body="infill_end_s" type="number">
  替换区间的结束秒数。`replace-section` 必填，必须比 `infill_start_s` 晚 6–60 秒。
</ParamField>

<ParamField body="full_lyrics" type="string">
  结果歌曲的完整歌词。`replace-section` 必填。
</ParamField>

<ParamField body="stem_name" type="string">
  分轨名称。`advanced-split` 必填。
</ParamField>

<ParamField body="continue_clip_id" type="string">
  要续写的上一个片段的 ID。
</ParamField>

<ParamField body="continue_at" type="number">
  续写起点，单位为秒。`upload-extend` 必填且必须大于 0。
</ParamField>

<Note>
`prompt` 最多 5000 字符，`tags` 和 `negative_tags` 各最多 1000 字符。可用操作和参数以所选模型的当前详情为准。
</Note>

## 响应

<ResponseField name="id" type="string">
  用于查询状态的任务 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
  同一个异步任务 ID 的别名，仅在返回时存在。
</ResponseField>

<ResponseField name="poll_url" type="string">
  创建响应提供时，优先使用的轮询 URL。
</ResponseField>

<ResponseField name="status" type="string">
  任务状态：`pending`、`processing`、`completed` 或 `failed`。
</ResponseField>

<ResponseField name="created" type="integer">
  任务创建的 Unix 时间戳，仅在返回时存在。
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
