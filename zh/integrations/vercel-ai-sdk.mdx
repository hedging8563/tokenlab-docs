## 概述


Chat Completions 使用 **OpenAI-compatible provider**。所选模型和应用需要 Responses 时，改用 OpenAI provider，TokenLab Base URL 不变。

## TokenLab 提供程序包

TokenLab 也提供一个简单的 Vercel AI SDK 封装：

```bash
npm install ai @tokenlabai/ai-sdk-provider
```

```typescript
import { generateText } from 'ai';
import { tokenlab } from '@tokenlabai/ai-sdk-provider';

const { text } = await generateText({
  model: tokenlab.chatModel('gpt-5.6-terra'),
  prompt: 'Explain TokenLab in one sentence.',
});

console.log(text);
```

## 推荐默认值：OpenAI 兼容提供程序

```bash
npm install ai @ai-sdk/openai-compatible zod
```

```typescript
import { createOpenAICompatible } from '@ai-sdk/openai-compatible';

export const tokenlab = createOpenAICompatible({
  name: 'tokenlab',
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
});
```

## 流式文本

```typescript
import { streamText } from 'ai';
import { tokenlab } from './tokenlab';

const result = await streamText({
  model: tokenlab.chatModel('gpt-5.6-terra'),
  prompt: 'Write a short poem about coding.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

## 工具调用

```typescript
import { generateText, stepCountIs, tool } from 'ai';
import { z } from 'zod';
import { tokenlab } from './tokenlab';

const result = await generateText({
  model: tokenlab.chatModel('gpt-5.6-terra'),
  prompt: 'What is the weather in San Francisco?',
  stopWhen: stepCountIs(2),
  tools: {
    weather: tool({
      description: 'Get weather in a location',
      inputSchema: z.object({
        location: z.string(),
      }),
      execute: async ({ location }) => ({
        location,
        temperature: 72,
        condition: 'sunny',
      }),
    }),
  },
});

console.log(result.text);
```

## 如果你明确需要 Responses 原生行为

```bash
npm install ai @ai-sdk/openai
```

```typescript
import { createOpenAI } from '@ai-sdk/openai';

export const tokenlabResponses = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: 'https://api.tokenlab.sh/v1',
});
```

```typescript
import { generateText } from 'ai';
import { tokenlabResponses } from './tokenlab-responses';

const { text } = await generateText({
  model: tokenlabResponses('gpt-5.6-terra'),
  prompt: 'Explain TokenLab in one sentence.',
});
```

<Note>
Chat Completions 使用 `@ai-sdk/openai-compatible`；需要 `/v1/responses` 时使用 `@ai-sdk/openai`。
</Note>

## 环境变量

```bash
# .env.local
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## 选择包

<AccordionGroup>
  <Accordion title="Chat Completions">
    使用 Chat Completions 时，配置 `@ai-sdk/openai-compatible` 并填写 TokenLab Base URL。
  </Accordion>

  <Accordion title="仅在需要时切换到 Responses">
    只有请求依赖 `/v1/responses` 时才换用 `@ai-sdk/openai`。不要在同一个客户端中混用两种包。
  </Accordion>

  <Accordion title="在服务器端保留密钥">
    不要在客户端代码中暴露 TokenLab API 密钥。把配置放在服务器文件或 API 路由中。
  </Accordion>
</AccordionGroup>
