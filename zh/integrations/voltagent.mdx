## 概述

在 VoltAgent 使用的 AI SDK provider 中填写 TokenLab `/v1` 地址，再把选定模型交给 Agent。


## 安装

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## 环境配置

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 直接使用 AI SDK 提供程序

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## 选择 API 格式

如果你的 VoltAgent 注册表快照包含来自 `models.dev` 的 TokenLab 提供程序条目，请配置：

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

然后使用注册表模型字符串，例如 `tokenlab/claude-sonnet-5`。

## 端点说明

直接使用 AI SDK 路径是最明确的设置方式。仅当你选择的 AI SDK 提供程序/客户端配置为相应协议时，才使用 TokenLab 原生 Responses、Anthropic Messages 或 Gemini 端点。
