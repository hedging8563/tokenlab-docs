## 概述

<Note>
**类型**：IDE 与 CLI 编码代理

**主要路径**：OpenAI 兼容 Chat Completions

**支持级别**：官方自定义提供商路径
</Note>

[Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible) 的 VS Code 扩展和 Kilo CLI 都支持自定义 OpenAI 兼容提供商。

## 安装

在 VS Code 扩展市场安装 **Kilo Code** 的预发布通道，或安装 CLI：

```bash
npm install -g @kilocode/cli
kilo --version
```

## 在界面中配置

打开 **Settings → Providers → Custom provider**：

| 字段 | 值 |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | 你的 TokenLab API Key |
| Model | `kimi-k3` |

Kilo 会从 TokenLab 的 `/v1/models` 自动发现模型。保存后选择 `tokenlab/kimi-k3`。

## 配置 CLI

先设置环境变量，再把配置写入受信任的全局文件 `~/.config/kilo/kilo.jsonc`：

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

重启后运行 `kilo models` 验证。`{env:...}` 仅在受信任的全局或托管配置中解析，不要把真实 Key 写入可能提交到 Git 的项目配置。
