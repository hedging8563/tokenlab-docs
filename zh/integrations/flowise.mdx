## 概述

Flowise 有 TokenLab 聊天节点时可以直接使用；没有时，添加 OpenAI 兼容聊天模型节点并填写 TokenLab 地址。


## TokenLab 节点

如果你的 Flowise 构建版本包含 **TokenLab** 聊天模型节点：

1. 添加 **Chat Models** -> **TokenLab**
2. 创建一个 TokenLab API 凭证
3. 将 **Model Name** 设置为 `gpt-5.4-mini`
4. 连接到所需的 Chain 或 Agent
5. 发送一条消息确认配置生效。

## 使用 OpenAI 兼容节点

如果你的版本未包含 TokenLab 节点，请添加 **Chat Models** → **OpenAI Custom Model**。在 **Connect Credential** 中使用 TokenLab 密钥创建 **OpenAI API** 凭证，再按下表设置 **Model Name** 和 **Additional Parameters** → **Base Path**：

| 字段 | 值 |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API 密钥 | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

将节点连接到链、代理或工作流，再发送一条测试提示词。

## 选择模型

请从[模型页](https://tokenlab.sh/zh/models)复制当前聊天模型 ID。这个节点使用的模型必须支持 Chat Completions。
