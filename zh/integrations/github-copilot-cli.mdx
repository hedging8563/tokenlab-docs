## 概述

<Note>
**类型**：编码代理 CLI

**主要路径**：OpenAI 兼容 Chat Completions

**支持级别**：官方 BYOK 路径
</Note>

[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models) 可以连接任意 OpenAI Chat Completions 兼容端点。TokenLab 使用 Copilot CLI 官方环境变量完成配置。

## 安装

```bash
npm install -g @github/copilot
copilot --version
```

npm 安装需要 Node.js 22 或更高版本。GitHub 当前要求有效的 Copilot 方案；组织账号还需管理员启用 Copilot CLI 策略。

## 配置 TokenLab

```bash
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.tokenlab.sh/v1"
export COPILOT_PROVIDER_API_KEY="sk-your-tokenlab-key"
export COPILOT_MODEL="kimi-k3"

copilot
```

| 变量 | TokenLab 值 |
|---|---|
| `COPILOT_PROVIDER_TYPE` | `openai` |
| `COPILOT_PROVIDER_BASE_URL` | `https://api.tokenlab.sh/v1` |
| `COPILOT_PROVIDER_API_KEY` | 你的 TokenLab API Key |
| `COPILOT_MODEL` | 实时模型 ID，例如 `kimi-k3` |

Copilot CLI 要求模型同时支持流式输出和工具调用。`kimi-k3` 支持工具调用，且上下文超过 GitHub 建议的 128K。

## 验证

启动后先发送只读任务，例如：

```text
检查此仓库并总结顶层目录结构，不要修改文件。
```

如果提示认证失败，请重新检查 API Key；如果提示模型不存在，请使用 [TokenLab 实时模型目录](https://tokenlab.sh/zh/models) 中的完整模型 ID，不要给 `kimi-k3` 添加提供商前缀。

<Warning>
不要把 API Key 提交到 Git 跟踪的脚本或配置文件。任何出现在终端历史、截图或日志中的 Key 都应立即轮换。
</Warning>
