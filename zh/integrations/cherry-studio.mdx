## 概述

Cherry Studio 可以通过自定义的 OpenAI 兼容提供商使用 TokenLab。如果您的 Cherry Studio 版本在提供商注册表中包含 TokenLab，请直接选择 TokenLab。

<Note>
**类型**: 聊天应用

**主要路径**: OpenAI 兼容的聊天补全 (Chat Completions)

**原生路径**: Responses, Anthropic Messages, 以及客户端暴露的 Gemini 兼容端点
</Note>

## 配置为自定义提供商

1. 打开 **Settings** -> **Model Provider**
2. 添加一个 OpenAI 兼容的提供商
3. 输入:
   - **Name**: TokenLab
   - **API Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. 添加一个模型，例如 `gpt-5.4-mini`
5. 保存并测试该提供商。

## 提供商注册表路径

当 TokenLab 作为内置提供商出现在 Cherry Studio 中时，请优先选择该选项。它可以携带以下端点的元数据：

- OpenAI 兼容的聊天补全
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## 推荐入门模型

使用 `gpt-5.4-mini` 作为默认模型，然后添加 `claude-sonnet-5`、`gemini-3.5-flash` 和 `deepseek-v4-flash` 以获得更广泛的覆盖范围。
