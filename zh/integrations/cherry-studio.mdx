## 概述

Cherry Studio 中已经出现 TokenLab 时直接选择；没有时，把它添加为自定义 OpenAI 兼容服务。


## 配置为自定义提供商

1. 打开 **Settings** -> **Model Provider**
2. 添加一个 OpenAI 兼容的提供商
3. 输入:
   - **Name**: TokenLab
   - **API Base URL**: `https://api.tokenlab.sh/v1`
   - **API 密钥**: `sk-your-tokenlab-key`
4. 添加一个模型，例如 `gpt-5.4-mini`
5. 保存并测试该提供商。

## 内置 TokenLab 选项

Cherry Studio 已经内置 TokenLab 时，直接选择会自动带入对应 API 地址：

- OpenAI 兼容的聊天补全
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## 推荐入门模型

使用 `gpt-5.4-mini` 作为默认模型，然后添加 `claude-sonnet-5`、`gemini-3.5-flash` 和 `deepseek-v4-flash` 以获得更广泛的覆盖范围。
