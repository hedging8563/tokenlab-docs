## 交给我的 Agent 做

把这段任务交给电脑上已经可用的 Agent：

```text
阅读此教程，将 TokenLab Skill 安装到我正在使用的 Agent：
https://docs.tokenlab.sh/zh/integrations/coding-agent-skill
先检查已安装版本和实际配置。
保留已有账户、提供商、权限及无关设置。
备份本机文件并展示修改内容。
让我在本机输入所需 API Key，不要在聊天里索取、打印或粘贴密钥。
先验证配置能否加载；真实请求测试的费用须单独说明后再运行。
```

`tokenlab-api-integration` Skill 可以帮助 Coding Agent 把 TokenLab 接入应用，不必依赖过期的模型列表。它涵盖聊天、图片、视频、音频、翻译、Embeddings、Rerank、音乐、3D 和 Worlds。

公开版本位于 [tokenlab-skills](https://github.com/hedging8563/tokenlab-skills)。

## 安装

```bash
npx skills add https://github.com/hedging8563/tokenlab-skills \
  --skill tokenlab-api-integration \
  -y
```

更新时重新运行同一条命令。Coding 工具不支持安装器时，可以把仓库中的 `skills/tokenlab-api-integration/` 复制到它的共享 Skills 或 Rules 目录。

安装后，让 Agent 列出可用 Skills；出现 `tokenlab-api-integration` 即表示已经识别。

## 它能帮你做什么

- 为某个 TokenLab API 创建可运行示例。
- 读取当前模型列表和模型专属字段。
- 选择 Chat Completions、Responses、Anthropic Messages 或 Gemini 格式。
- 处理模型名建议、请求限额和重试时间。
- 避免把 API 密钥写进提示词和源码。

Skill 不能代替 API Reference。需要确认准确字段和响应结构时，仍应查看对应 TokenLab 文档。

## 创建 API 密钥

打开 [Console → API 密钥](https://tokenlab.sh/dashboard/api?tab=keys&createKey=1&docsTopic=codingAgents) 创建一枚密钥，并放进环境变量。TokenLab API 密钥以 `sk-` 开头。

```bash
export TOKENLAB_API_KEY="sk-your-api-key"
```

不要把密钥粘贴到 Agent 提示词、前端代码、截图或公开仓库中。让 Agent 从环境变量读取。

## 第一条请求

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "Hello!"}],
)

print(response.choices[0].message.content)
```

安装 OpenAI SDK 并运行：

```bash
pip install openai
python app.py
```

## 让 Agent 读取当前模型信息

模型 ID、字段和价格都会变化。Skill 可以读取：

```bash
# 精简 API 概览
curl https://api.tokenlab.sh/llms.txt

# 当前模型
curl "https://api.tokenlab.sh/v1/models" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"

# 适合某类非聊天任务的模型
curl "https://api.tokenlab.sh/v1/models?recommended_for=image" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"

# 单个模型支持的字段和 API 格式
curl "https://api.tokenlab.sh/v1/models/gpt-image-2" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

`recommended_for` 支持 `image`、`video`、`music`、`3d`、`tts`、`stt`、`embedding`、`rerank` 和 `translation`。

## 一次对话只用一种 API 格式

生成代码前，从所选模型读取 `tokenlab.accepted_request_formats`。

| 格式 | API |
| --- | --- |
| Chat Completions | `/v1/chat/completions` |
| Responses | `/v1/responses` |
| Anthropic Messages | `/v1/messages` |
| Gemini | `/v1beta/models/{model}:generateContent` |

同一段对话或工具调用应保持一种格式。模型专属字段不会在这些格式之间自动转换。

## 根据错误做安全修改

OpenAI 兼容错误可能带有 `did_you_mean`、`suggestions`、`hint`、`retryable` 和 `retry_after`。Agent 仍应以 HTTP 状态和错误 `code` 为主要判断依据。

- 模型名错误时，可以读取 `did_you_mean`；换模型会影响结果或价格时，需要用户同意。
- `429` 按 `Retry-After` 等待后重试。
- 参数、鉴权、余额和权限错误需要修改内容，原样重发没有用。
- 创建任务超时后，必须确认没有产生任务再重新提交。
