## 概述

在 Open WebUI 中添加 OpenAI 兼容连接，填入 TokenLab 地址和 API 密钥，再刷新模型列表。


## 管理员连接

1. 打开 **Admin Panel** -> **Settings** -> **Connections**。
2. 在 OpenAI API 连接区域，添加一个连接。
3. 将 Base URL 设置为 `https://api.tokenlab.sh/v1`。
4. 填入 TokenLab API 密钥。
5. 保存连接并刷新模型。

## 配置值

| 字段 | 数值 |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API 密钥 | `sk-your-tokenlab-key` |
| 示例模型 | `gpt-5.4-mini` |

## 选择模型

刷新模型列表，或从[模型页](https://tokenlab.sh/zh/models)复制当前聊天模型 ID。

若要手动指定模型 ID，请编辑这个连接，打开 **Advanced** → **Model IDs (Filter)**，添加精确的 TokenLab 模型 ID 后保存。
