## 概述

<Note>
**类型**：IDE 编码代理

**主要路径**：OpenAI 兼容 Chat Completions

**支持级别**：官方提供商路径
</Note>

[Cline](https://docs.cline.bot/provider-config/openai-compatible) 可在 IDE 设置中配置 OpenAI 兼容提供商。

## 配置 TokenLab

1. 从编辑器扩展市场安装 **Cline**，然后打开 Cline 面板。
2. 点击齿轮图标，将 **API Provider** 设为 **OpenAI Compatible**。
3. 输入以下值：

| 字段 | 值 |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | 你的 TokenLab API Key |
| Model ID | `kimi-k3` |

4. 点击 **Verify**。

`kimi-k3` 的可选高级参数：

| 能力 | 值 |
|---|---|
| 上下文 / 输入上限 | `1048576` |
| 最大输出 token | `131072` |
| 图片支持 | 开启 |
| 工具 / Computer Use | 开启 |

## 验证

验证通过后，先发送一个只读任务：

```text
列出当前工作区文件，并说明应用入口文件。不要修改任何内容。
```

若出现 404，请确认 Base URL 以 `/v1` 结尾，且不要在该字段加入 `/chat/completions`。模型 ID 应为 `kimi-k3`，而不是 `kimi/kimi-k3`。
