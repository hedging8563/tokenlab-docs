## 概述


[Cline](https://docs.cline.bot/provider-config/openai-compatible) 可在 IDE 设置中配置 OpenAI 兼容提供商。

## 配置 TokenLab

编辑前先在本地保存当前提供商、模型和连接设置。这些界面选项会改变当前模型选择，使用结束后恢复原值。保留已登录账户与工具权限；未留存可恢复备份时，不要覆盖已有的其他 OpenAI 兼容连接。

1. 从编辑器扩展市场安装 **Cline**，然后打开 Cline 面板。
2. 点击齿轮图标，将 **API Provider** 设为 **OpenAI Compatible**。
3. 输入以下值：

| 字段 | 值 |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API 密钥 | 你的 TokenLab API 密钥 |
| Model ID | `kimi-k3` |

4. 点击 **Verify**。

`kimi-k3` 的可选高级参数：

| 能力 | 值 |
|---|---|
| 上下文 / 输入上限 | `1048576` |
| 最大输出 token | `131072` |
| 图片支持 | 开启 |

## 验证

验证通过后，先发送一个只读任务：

```text
列出当前工作区文件，并说明应用入口文件。不要修改任何内容。
```

保存设置或列出模型不能证明密钥有效或请求完成。发送提示词会使用 TokenLab 余额；先核对回复及对应[请求记录](https://tokenlab.sh/dashboard/runs?section=requests)，再尝试工具，辅助请求也可能计费。
