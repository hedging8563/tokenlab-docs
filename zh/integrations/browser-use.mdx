## 概述

Browser Use 可以通过 `ChatOpenAILike` 调用 TokenLab 的 OpenAI 兼容聊天 API。


## 环境配置

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 示例

```python
import os

from browser_use import Agent
from browser_use.llm.openai.like import ChatOpenAILike

llm = ChatOpenAILike(
    model="claude-sonnet-5",
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
    add_schema_to_system_prompt=True,
    dont_force_structured_output=True,
)

agent = Agent(
    task="Compare the top search results for TokenLab integrations",
    llm=llm,
)
```

## 端点说明

本页配置使用 Chat Completions。需要 Responses、Anthropic Messages 或 Gemini 时，请改用 Browser Use 中支持对应格式的客户端。
