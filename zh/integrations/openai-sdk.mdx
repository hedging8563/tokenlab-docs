## 概览

把 OpenAI SDK Base URL 设为 `https://api.tokenlab.sh/v1`，并使用 TokenLab API 密钥即可。现有应用已经使用哪种 API 方法就继续沿用，同时通过 `accepted_request_formats` 确认所选模型支持。

<Note>
Python、JavaScript 和 Go 有官方的 OpenAI SDK。PHP 与兼容 OpenAI 的社区客户端配合良好，但它并不是官方 OpenAI SDK。
</Note>


## 安装

<CodeGroup>

```bash Python
pip install openai
```

```bash JavaScript
npm install openai
```

```bash Go
go get github.com/openai/openai-go/v3
```

</CodeGroup>

<Note>
需要 Responses API 的输入项、工具或续接能力时，使用 `POST /v1/responses`。可选字段是否可用取决于所选模型。
</Note>

## 配置客户端

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-tokenlab-key",
    base_url="https://api.tokenlab.sh/v1",
)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-tokenlab-key',
  baseURL: 'https://api.tokenlab.sh/v1',
});
```

```go Go
package main

import (
    openai "github.com/openai/openai-go/v3"
    "github.com/openai/openai-go/v3/option"
)

func main() {
    client := openai.NewClient(
        option.WithAPIKey("sk-your-tokenlab-key"),
        option.WithBaseURL("https://api.tokenlab.sh/v1"),
    )

    _ = client
}
```

</CodeGroup>

## 高级：Responses API

只有客户端和所选模型都需要 Responses 时，才使用这项配置。

### 使用 Responses 的流式传输

<CodeGroup>

```python Python
stream = client.responses.create(
    model="gpt-5.6-terra",
    input="Write a short poem about coding.",
    stream=True,
)

for event in stream:
    if event.type == "response.output_text.delta":
        print(event.delta, end="")
```

```javascript JavaScript
const stream = await client.responses.create({
  model: 'gpt-5.6-terra',
  input: 'Write a short poem about coding.',
  stream: true,
});

for await (const event of stream) {
  if (event.type === 'response.output_text.delta') {
    process.stdout.write(event.delta);
  }
}
```

</CodeGroup>

## 工具 / 函数调用

```python
response = client.responses.create(
    model="gpt-5.6-terra",
    input="What's the weather in Tokyo?",
    tools=[{
        "type": "function",
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"}
            },
            "required": ["location"]
        }
    }]
)

for item in response.output:
    if item.type == "function_call":
        print(item.name)
        print(item.arguments)
```

## 使用 Responses 的视觉功能

```python
response = client.responses.create(
    model="gpt-5.6-terra",
    input=[{
        "role": "user",
        "content": [
            {"type": "input_text", "text": "What's in this image?"},
            {"type": "input_image", "image_url": "https://example.com/image.jpg"}
        ]
    }]
)

print(response.output_text)
```

## Chat Completions

Chat Completions 是 TokenLab 的默认 OpenAI 兼容路径：

```python
response = client.chat.completions.create(
    model="gpt-5.6-terra",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
)

print(response.choices[0].message.content)
```

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    - 确认 base URL 精确为 `https://api.tokenlab.sh/v1`
    - 检查是否有代理干扰或自定义 HTTP 客户端覆盖
    - 在调试提供商行为之前，确保你的 SDK 版本是最新的
  </Accordion>

  <Accordion title="身份验证失败">
    - 检查你的 API 密钥是否以 `sk-` 开头
    - 确认该密钥在 TokenLab 控制面板中处于激活状态
    - 确认 SDK 正在发送 `Authorization: Bearer ...`
  </Accordion>

  <Accordion title="错误的 API 路径">
    - `responses.create(...)` 会向 `/v1/responses` 发送请求
    - `chat.completions.create(...)` 会向 `/v1/chat/completions` 发送请求
    - 默认使用 Chat Completions，除非你明确需要 Responses 特定行为
  </Accordion>
</AccordionGroup>
