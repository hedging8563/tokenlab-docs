## 概述

在 Chatbox 的 OpenAI 兼容 API 设置中填写 TokenLab 地址和密钥即可使用。


## 配置 Chatbox

1. 打开 **Settings** -> **AI Model**
2. 选择 **OpenAI API Compatible**
3. 输入以下内容：
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API 密钥**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. 保存并发送一条简短的测试消息。

## 选择模型

请从[模型页](https://tokenlab.sh/zh/models)复制当前聊天模型 ID。Chatbox 没有自动显示时，可以手动添加完整 ID。

## 注意事项

如果 Chatbox 已经内置 TokenLab，直接选择即可；没有时使用上面的 OpenAI 兼容设置。
