## 交给我的 Agent 做

把这段任务交给电脑上已经可用的 Agent：

```text
阅读此教程，帮我将 Claude Code 接入 TokenLab：
https://docs.tokenlab.sh/zh/integrations/claude-code
先检查已安装版本和实际配置。
保留已有账户、提供商、权限及无关设置。
备份本机文件并展示修改内容。
让我在本机输入所需 API Key，不要在聊天里索取、打印或粘贴密钥。
先验证配置能否加载；真实请求测试的费用须单独说明后再运行。
```

## 概述




[Claude Code](https://code.claude.com/docs/en/setup) 可以使用 TokenLab API 密钥，通过 TokenLab Messages API 调用 Claude 模型。

## 安装

Anthropic 当前推荐原生安装程序；npm 安装方式仍可用，但已经弃用。

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

如果你明确需要 npm 包，请使用：

```bash
npm install -g @anthropic-ai/claude-code
```

<Warning>
不要对 Claude Code 使用 `sudo npm install -g`。
</Warning>

## 配置

### 环境变量

设置以下环境变量：

```bash
export ANTHROPIC_API_KEY="sk-your-tokenlab-key"
export ANTHROPIC_BASE_URL="https://api.tokenlab.sh"
```

将这些添加到你的 shell 配置文件（`~/.bashrc`、`~/.zshrc` 等）中，以便持久生效。

<Note>
对于 TokenLab，请将 `ANTHROPIC_BASE_URL` 保持为 `https://api.tokenlab.sh`，不要添加 `/v1` 后缀。这与 Claude Code 文档中记录的 Anthropic 风格端点结构以及统一网关模式保持一致。
</Note>

### 配置文件

或者，创建或编辑 `~/.claude/settings.json`：

备份并合并设置，不覆盖已有账户、权限或无关环境变量。`ANTHROPIC_API_KEY` 发送 `X-Api-Key`，`ANTHROPIC_AUTH_TOKEN` 发送 Bearer token，应明确选择一种认证方式。启动 Claude Code 后用 `/status` 检查当前模型和配置来源，这不能证明付费请求成功。发送简短付费请求后，应核对回复和 TokenLab 请求记录。恢复时仅撤销本次添加的设置。参见[配置优先级](https://code.claude.com/docs/en/settings)。

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  }
}
```

## 用法

完成配置后，即可像平常一样使用 Claude Code：

```bash
# Start an interactive session
claude

# Run a single command
claude "Explain this code" < main.py

```

如有需要，可验证安装是否成功：

```bash
claude --version
claude doctor
```

## 选择模型

从[模型页](https://tokenlab.sh/zh/models)复制当前 Claude 模型 ID，并通过 `--model` 指定：

```bash
claude --model claude-sonnet-4-6 "Review this PR"
```

也可以在配置中设置默认模型：

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  },
  "model": "claude-sonnet-5"
}
```

## 扩展思考

需要扩展思考时，请从模型页选择支持该能力的 Claude 模型：

```bash
claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    请确认 base URL 精确为 `https://api.tokenlab.sh`（对于 Anthropic 风格请求，不要添加 `/v1` 后缀）。
  </Accordion>

  <Accordion title="无效的 API 密钥">
    请确认 TokenLab API 密钥以 `sk-` 开头，并且余额充足。
  </Accordion>

  <Accordion title="网关需要 Authorization bearer token">
    Claude Code 的网关模式也支持 `ANTHROPIC_AUTH_TOKEN`。对于标准的 TokenLab 配置，请继续使用 `ANTHROPIC_API_KEY`，除非你有意切换了网关认证行为。
  </Accordion>

  <Accordion title="找不到模型">
    请检查模型名称是否正确。请使用 `claude-sonnet-4-6` 这种格式。
  </Accordion>
</AccordionGroup>
