## 交给我的 Agent 做

把这段任务交给电脑上已经可用的 Agent：

```text
阅读此教程，帮我将 Claude Code 接入 TokenLab：
https://docs.tokenlab.sh/zh/integrations/claude-code
先检查已安装版本和实际配置。
保留已有账户、提供商、权限及无关设置。
备份本机文件并展示修改内容。
让我在本机输入所需 API Key，不要在聊天里索取、打印或粘贴密钥。
先验证配置能否加载；真实请求测试的费用须单独说明后再运行。
```

## 概述




[Claude Code](https://code.claude.com/docs/en/setup) 可以使用 TokenLab API 密钥，通过 TokenLab Messages API 调用 Claude 模型。

## 安装

Anthropic 当前推荐原生安装程序；npm 安装方式仍可用，但已经弃用。

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

如果你明确需要 npm 包，请使用：

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
不要对 Claude Code 使用 `sudo npm install -g`。
</Warning>

## 配置

按[快速开始](/zh/quickstart)中 macOS、Linux、WSL 或 Windows PowerShell 的终端步骤设置 `TOKENLAB_API_KEY`，避免把密钥写进命令历史，然后从同一终端启动 Claude Code。长期使用请通过本地密钥管理器提供密钥，不要把明文密钥追加到 shell 配置文件。

这些变量仅用于本次启动，保留已保存的账户、默认模型与权限。正常启动时不附加这些变量，即可继续使用原设置；不要将它们写入 shell 配置文件。

此会话方式使用 Claude Code **2.1.263**，通过 `ANTHROPIC_AUTH_TOKEN` 发送 Bearer 认证，Base URL 不带 `/v1`。已有配置文件中的 `env`、凭据助手、云提供商开关或托管策略可能影响认证，请先检查；存在冲突时使用下方配置助手，不要删除账户数据或放宽策略。启动后用 `/status` 核对模型与权限。

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

可选：使用[可恢复的 Claude Code 配置器](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md)，通过 Python 3.11+ 预览、应用并恢复原文件。TokenLab Skills 插件 **0.1.2** 已包含新脚本；独立安装的 Skill 更新到包含这些脚本的版本后也可使用。已安装插件或独立 Skill 的用户请按 [README 更新说明](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation)更新，并确认脚本已安装。也可直接完成本页手工配置。

保存设置或列出模型不能证明密钥有效或请求完成。发送提示词会使用 TokenLab 余额；先核对回复及对应[请求记录](https://tokenlab.sh/dashboard/runs?section=requests)，再尝试工具，辅助请求也可能计费。

## 用法

完成配置后，即可像平常一样使用 Claude Code：

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

如有需要，可验证安装是否成功：

```bash
claude --version
claude doctor
```

## 选择模型

从[模型页](https://tokenlab.sh/zh/models)复制当前 Claude 模型 ID，并通过 `--model` 指定：

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## 扩展思考

需要扩展思考时，请从模型页选择支持该能力的 Claude 模型：

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    请确认 base URL 精确为 `https://api.tokenlab.sh`（对于 Anthropic 风格请求，不要添加 `/v1` 后缀）。
  </Accordion>

  <Accordion title="无效的 API 密钥">
    请确认 TokenLab API 密钥以 `sk-` 开头，并且余额充足。
  </Accordion>


  <Accordion title="找不到模型">
    请检查模型名称是否正确。请使用 `claude-sonnet-4-6` 这种格式。
  </Accordion>
</AccordionGroup>
