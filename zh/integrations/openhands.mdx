## 概述

在 OpenHands 的 LiteLLM/OpenAI 兼容模型设置中填写模型、API 密钥和 Base URL，即可调用 TokenLab。


## 环境

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 模型设置

使用：

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

`openai/` 前缀告知基于 LiteLLM 的路径使用 OpenAI 兼容的提供商配置。

## 无头（Headless）设置

需要为 CLI 或 Headless 模式保存默认配置时，打开 OpenHands 设置并填写：

```bash
make setup-config
```

当系统提示输入模型详细信息时，请使用带有 `openai/` 前缀的 TokenLab 模型 ID 以及 TokenLab 的 `/v1` Base URL。

模型 ID 会更新。请从[模型页](https://tokenlab.sh/zh/models)选择当前编程模型，并用自己的仓库任务比较效果、速度和费用。
