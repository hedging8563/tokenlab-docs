## 概述

在 DeepChat 中添加 OpenAI 兼容服务，并填入 TokenLab 地址和密钥即可。


## 配置 DeepChat

1. 打开 **Settings** -> **Model Provider**
2. 添加或编辑一个 OpenAI 兼容的提供商
3. 输入以下信息：
   - **Provider name**: TokenLab
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API 密钥**: `sk-your-tokenlab-key`
4. 添加一个模型，例如 `gpt-5.4-mini`
5. 保存并测试聊天功能。

## 选择模型

请从[模型页](https://tokenlab.sh/zh/models)复制当前聊天模型 ID。模型没有出现在 DeepChat 列表中时，可以手动添加。

## 故障排除

- 请使用 base URL，而不是完整的 `/chat/completions` 路径，除非 DeepChat 明确要求输入完整的端点 URL。
- 请移除 API 密钥 末尾的空格。
- 如果模型未列出，请手动添加准确的 TokenLab 模型 ID。
