## 概述

Dify 可以在 OpenAI 模型设置中使用 TokenLab。这里配置的是 Chat Completions，不会让 Dify 额外获得 Responses 或 WebSocket 功能。

当前 Dify 版本可以这样设置：
- 选择内置的 **OpenAI** 提供商
- 设置你的 TokenLab API 密钥
- 设置自定义 base URL 为 `https://api.tokenlab.sh/v1`

<Note>
较旧的 Dify 版本可能把这项设置称为 `OpenAI-API-compatible`。界面名称不同时，请选择能够填写自定义 OpenAI API 地址的模型设置。
</Note>


## 前置要求

- 拥有 API 访问权限的 TokenLab 账户
- Dify Cloud 或自托管 Dify

## 配置步骤

### 第 1 步：获取你的 API 密钥

1. 登录 [TokenLab Console](https://tokenlab.sh/dashboard)
2. 打开 [API 密钥](https://tokenlab.sh/dashboard/api)
3. 创建或复制一个以 `sk-` 开头的 API 密钥

### 第 2 步：配置提供商

<Steps>
  <Step title="打开模型提供商">
    在 Dify 中，前往 **设置 (Settings)** → **模型提供商 (Model Providers)**
  </Step>
  <Step title="选择 OpenAI">
    打开 **OpenAI** 提供商设置。如果你的 Dify 版本在此处不提供自定义 base URL，请改用该版本提供的 OpenAI 兼容自定义提供商选项。
  </Step>
  <Step title="输入 TokenLab 设置">
    使用以下值：

    | 字段 | 值 |
    |-------|-------|
    | API 密钥 | `sk-your-tokenlab-key` |
    | API Base URL / Custom Base URL | `https://api.tokenlab.sh/v1` |
  </Step>
  <Step title="添加模型">
    添加你想要使用的模型，例如：
    - `gpt-5.4`
    - `gpt-5.4-mini`
    - `claude-sonnet-5`
    - `claude-opus-4-8`
    - `gemini-3.5-flash`
    - `gemini-3.1-flash-lite`
    - `deepseek-v4-flash`
  </Step>
</Steps>

### 第 3 步：测试连接

1. 选择一个模型，例如 `gpt-5-mini` 或 `gpt-4o`
2. 发送一条测试提示词 (prompt)
3. 确认 Dify 收到了有效的响应

## 用于知识库的 Embeddings

对于 RAG 和知识库索引，请添加一个 embedding 模型，例如：
- `text-embedding-3-small`
- `text-embedding-3-large`

然后将其设置为相关知识库或应用程序设置中的默认 embedding 模型。

## 选择模型

请从[模型页](https://tokenlab.sh/zh/models)复制当前聊天和 Embeddings 模型 ID。Dify 需要分别配置聊天与 Embeddings，而且每个模型都必须支持对应组件使用的 API。

## 配置说明

<AccordionGroup>
  <Accordion title="优先使用内置 OpenAI 设置">
    新版 Dify 可以直接在内置 OpenAI 模型设置中填写自定义 Base URL。
  </Accordion>

  <Accordion title="用自己的 Dify 应用比较模型">
    使用相同的代表性输入测试候选模型，再到 Usage 比较输出质量和最终费用。
  </Accordion>

  <Accordion title="这里使用 Chat Completions">
    OpenAI 兼容配置不会为 Dify 增加 Responses 或 WebSocket 功能。
  </Accordion>
</AccordionGroup>

## 故障排除

<AccordionGroup>
  <Accordion title="连接错误">
    - 验证 base URL 是否完全为 `https://api.tokenlab.sh/v1`
    - 如果 Dify 重复添加了斜杠，请删除末尾的斜杠
    - 确认 Dify 服务器可以通过公共互联网访问 TokenLab
  </Accordion>

  <Accordion title="401 未授权">
    - 仔细检查 API 密钥
    - 确认该 key 在 TokenLab dashboard 中处于激活状态
    - 确保粘贴到 Dify 中的值不包含多余的空格或换行符
  </Accordion>

  <Accordion title="模型未找到 (Model Not Found)">
    - 准确核对模型名称
    - 如果提供商 UI 缓存了旧值，请重新添加模型条目
    - 在 TokenLab 文档或 dashboard 中检查当前模型的可用性
  </Accordion>
</AccordionGroup>
