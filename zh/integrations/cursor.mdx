## 概述




[Cursor](https://cursor.sh) 的 BYOK 设置可以使用 TokenLab 处理标准聊天请求，但不能替代 Cursor 自己提供的全部模型功能。

## 配置

1. 打开 Cursor 设置（`Cmd/Ctrl + ,`）
2. 在左侧边栏中导航到 **Models**
3. 向下滚动到 **OpenAI API 密钥** 部分
4. 输入你的 TokenLab API 密钥
5. 启用 **Override OpenAI Base URL**
6. 将 Base URL 设置为：

```
https://api.tokenlab.sh/v1
```

<Warning>
Cursor 自定义 API 密钥 仅适用于标准聊天模型。Tab Completion 和其他由 Cursor 管理的专用功能将继续使用 Cursor 的内置提供商。
</Warning>

<Warning>
Cursor 的自定义 API 密钥只适用于标准聊天模型。Tab Completion 等 Cursor 自营功能仍使用 Cursor 自己的服务；Cursor 也会在自己的服务端完成最终提示词组装。
</Warning>

## 选择模型

请从[模型页](https://tokenlab.sh/zh/models)复制当前聊天模型 ID。使用自定义 API 密钥并不会开放 Cursor 自营的全部功能。

## 最适用的场景

### 聊天与编辑器功能

通过 Cursor 使用 TokenLab 可用于：

- 代码解释
- Bug 修复
- 重构建议
- 文档生成

### 仍由 Cursor 管理模型处理的功能

这些功能无法可靠地切换到你的 TokenLab 端点：

- Tab 补全
- 专用的非标准聊天模型
- Cursor 仅在内置模型上启用的提供商特定功能

## 故障排查

<AccordionGroup>
  <Accordion title="模型未显示">
    Cursor 会缓存模型状态。配置 API 密钥和 Base URL 后，请重启 Cursor。
  </Accordion>

  <Accordion title="BYOK 模式下不支持该模型">
    自定义 API 密钥只适用于标准聊天模型。Cursor 专用功能无法使用时，请换成模型页中的聊天模型。
  </Accordion>

  <Accordion title="身份验证错误">
    请确认 API 密钥正确且余额充足。
  </Accordion>

  <Accordion title="启用 TokenLab 后另一个提供商停止工作">
    Cursor 的 BYOK 设置可能影响其他模型服务。开启 OpenAI Base URL override 后，如果其他模型无法使用，请关闭 override 并重启 Cursor。
  </Accordion>
</AccordionGroup>

模型 ID 和价格会更新。请从[模型页](https://tokenlab.sh/zh/models)选择当前聊天模型，并在自己的项目中比较效果和费用。
