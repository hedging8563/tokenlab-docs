## 概述

<Note>
**类型**：桌面编码与任务代理

**主要路径**：OpenAI 兼容 Chat Completions

**支持级别**：官方自定义模型路径
</Note>

[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) 提供可视化的 OpenAI 兼容自定义模型编辑器，无需手动编辑本地模型文件。

## 配置 TokenLab

1. 打开 **设置 → 模型**。
2. 新增模型，并选择 **自定义 / Custom** 提供商。
3. 填写：

| 字段 | 值 |
|---|---|
| 接口地址 | `https://api.tokenlab.sh/v1` |
| API Key | 你的 TokenLab API Key |
| 模型名称 | `kimi-k3` |
| 自定义协议 | **关闭** |

<Warning>
必须关闭“自定义协议”。标准模式会校验 Base URL 并自动补全 `/chat/completions`；若打开后仍只填写 `/v1`，请求会发送到错误路径。
</Warning>

## 高级配置

| 设置 | 值 |
|---|---|
| 工具调用 | 开启 |
| 图片输入 | 开启 |
| 思考模式 | 开启 |
| 仅思考模式 | 关闭 |
| 默认思考强度 | 自动 |
| 输入上限 | `1048576` |
| 输出上限 | `131072` |

保存后，从 WorkBuddy 模型选择器中选择 `kimi-k3`，先执行一个只读目录检查。若出现 404，请再次确认接口为 `/v1` 且“自定义协议”处于关闭状态。

<Warning>
分享模型设置截图前请遮盖 API Key 和私有端点；已经暴露的 Key 应立即轮换。
</Warning>
