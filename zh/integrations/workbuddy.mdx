## 交给我的 Agent 做

把这段任务交给电脑上已经可用的 Agent：

```text
阅读此教程，帮我将 WorkBuddy 接入 TokenLab：
https://docs.tokenlab.sh/zh/integrations/workbuddy
先检查已安装版本和实际配置。
保留已有账户、提供商、权限及无关设置。
备份本机文件并展示修改内容。
让我在本机输入所需 API Key，不要在聊天里索取、打印或粘贴密钥。
先验证配置能否加载；真实请求测试的费用须单独说明后再运行。
```

## 概述


[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) 可以通过可视化的自定义模型编辑器添加 TokenLab。

## 配置 TokenLab

1. 打开 **设置 → 模型**。
2. 新增模型，并选择 **自定义 / Custom** 提供商。
3. 填写：

| 字段 | 值 |
|---|---|
| 接口地址 | `https://api.tokenlab.sh/v1` |
| API 密钥 | 你的 TokenLab API 密钥 |
| 模型名称 | 当前 TokenLab 聊天模型 ID |
| 自定义协议 | **关闭** |

<Warning>
必须关闭“自定义协议”。标准模式会校验 Base URL 并自动补全 `/chat/completions`；若打开后仍只填写 `/v1`，请求会发送到错误路径。
</Warning>

## 高级配置

工具、图片、思考开关及上下文/输出上限应按所选模型的当前 TokenLab 详情设置。不要为所有模型开启图片和思考，也不要把 1M/128K 上限复制到其他模型。模型 ID 按 TokenLab 展示值填写。

保存并选中模型只能证明本机配置已设置。文本或工具任务会使用 TokenLab 余额；请核对回复与对应[请求记录](https://tokenlab.sh/dashboard/runs?section=requests)。恢复时选回原模型，在编辑器中仅移除本次添加的 TokenLab 项目。


官方桌面应用支持 macOS 和 Windows。请通过[官方模型编辑界面](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model)配置；此教程不假定存在 Linux 版本或可直接写入的文件格式。

MCP 和 Skills 分别有独立安装路径：[API 工具](/zh/integrations/tokenlab-mcp-server)与[接入指导](/zh/integrations/coding-agent-skill)，它们不会切换 WorkBuddy 的主模型。
