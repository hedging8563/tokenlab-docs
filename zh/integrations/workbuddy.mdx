## 概述


[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) 可以通过可视化的自定义模型编辑器添加 TokenLab。

## 配置 TokenLab

1. 打开 **设置 → 模型**。
2. 新增模型，并选择 **自定义 / Custom** 提供商。
3. 填写：

| 字段 | 值 |
|---|---|
| 接口地址 | `https://api.tokenlab.sh/v1` |
| API 密钥 | 你的 TokenLab API 密钥 |
| 模型名称 | 当前 TokenLab 聊天模型 ID |
| 自定义协议 | **关闭** |

<Warning>
必须关闭“自定义协议”。标准模式会校验 Base URL 并自动补全 `/chat/completions`；若打开后仍只填写 `/v1`，请求会发送到错误路径。
</Warning>

## 高级配置

| 设置 | 值 |
|---|---|
| 工具调用 | 开启 |
| 图片输入 | 开启 |
| 思考模式 | 开启 |
| 仅思考模式 | 关闭 |
| 默认思考强度 | 自动 |
| 输入上限 | `1048576` |
| 输出上限 | `131072` |

保存后，在 WorkBuddy 选择刚添加的模型并发送一条简单消息。出现 404 时，确认接口地址为 `/v1`，并且“自定义协议”处于关闭状态。

<Warning>
分享模型设置截图前请遮盖 API 密钥 和私有端点；已经暴露的 Key 应立即轮换。
</Warning>
