## 交给我的 Agent 做

把这段任务交给电脑上已经可用的 Agent：

```text
阅读此教程，帮我将 OpenCode 接入 TokenLab：
https://docs.tokenlab.sh/zh/integrations/opencode
先检查已安装版本和实际配置。
保留已有账户、提供商、权限及无关设置。
备份本机文件并展示修改内容。
让我在本机输入所需 API Key，不要在聊天里索取、打印或粘贴密钥。
先验证配置能否加载；真实请求测试的费用须单独说明后再运行。
```

## 概述




在 OpenCode 中添加自定义 OpenAI 兼容服务，填入 TokenLab API 密钥、Base URL 和当前模型 ID 即可。

## 安装

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

验证安装：

```bash
opencode --version
```

## 配置

### 第 1 步：设置环境变量

按[快速开始](/zh/quickstart)中 macOS、Linux、WSL 或 Windows PowerShell 的终端步骤设置 `TOKENLAB_API_KEY`，避免把密钥写进命令历史，然后从同一终端启动 OpenCode。长期使用请通过本地密钥管理器提供密钥，不要把明文密钥追加到 shell 配置文件。

### 第 2 步：配置 OpenCode

以下配置已在 **OpenCode 1.18.31** 核验；其他版本需按其官方文档重新确认。

将下面配置保存为独立的 `~/.config/opencode/tokenlab.jsonc`；若设置了 `XDG_CONFIG_HOME`，则使用该目录下的 `opencode/tokenlab.jsonc`。保留常规 `opencode.json` / `opencode.jsonc`、账户、默认模型和权限；只有本次启动通过 `OPENCODE_CONFIG` 选择此文件时才加载它。若该文件或提供商名称已用于其他配置，请另选文件或名称，并同步修改启动命令。

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
这里使用 `@ai-sdk/openai-compatible` 发送 Chat Completions。请按当前模型详情确认 Chat Completions 及所需工具支持；此示例不能证明其他协议或版本兼容。
</Note>

可选：使用[可恢复的 OpenCode 配置器](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md)，通过 Python 3.11+ 预览、应用并恢复原文件。TokenLab Skills 插件 **0.1.2** 已包含新脚本；独立安装的 Skill 更新到包含这些脚本的版本后也可使用。已安装插件或独立 Skill 的用户请按 [README 更新说明](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation)更新，并确认脚本已安装。也可直接完成本页手工配置。

## 基本用法

按快速开始设置密钥后，仅为本次启动加载此文件并显式选择模型。若使用自定义路径或提供商名称，请相应替换。已有 `OPENCODE_CONFIG` 或内联 `OPENCODE_CONFIG_CONTENT` 配置时，保留原设置并使用独立启动环境；项目及托管设置仍可能优先。

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

模型列表只能验证本机加载，不能证明密钥有效或线上请求成功。发送提示词会使用 TokenLab 余额，OpenCode 还可能发出标题生成等单独计费的辅助请求。请核对回复及对应[请求记录](https://tokenlab.sh/dashboard/runs?section=requests)。

不加载此文件即可按原配置启动。不要为本教程把 `OPENCODE_CONFIG` 写入 shell 配置文件。撤销手工配置时，仅删除本次新建的独立文件；若原文件已存在，则恢复其备份。

## 可用模型

| 模型 | 最适合 |
|-------|----------|
| `gpt-5.6-terra` | 复杂任务、代码架构 |
| `gpt-5.6-luna` | 快速修复、简单查询 |
| `claude-sonnet-4-6` | 代码审查、文档编写 |
| `claude-opus-4-6` | 复杂推理 |
| `gemini-3.5-flash` | 快速响应 |

## 常用命令

**分析代码：**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**生成代码：**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**审查变更：**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**修复错误：**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    - 验证 `options.baseURL` 是否设置为 `https://api.tokenlab.sh/v1`
    - 检查网络连接
    - 尝试使用 `curl https://api.tokenlab.sh/v1/models` 进行测试
  </Accordion>

  <Accordion title="身份验证失败">
    - 验证是否已设置 `TOKENLAB_API_KEY` 环境变量
    - 验证 `options.apiKey` 是否引用了 `{env:TOKENLAB_API_KEY}` 或其他有效的 secret 来源
    - 检查 key 是否以 `sk-` 开头
    - 确保该 key 在 TokenLab Console中处于激活状态
  </Accordion>

  <Accordion title="未找到模型">
    - 检查配置中的模型名称是否完全匹配
    - 在 [tokenlab.sh/en/models](https://tokenlab.sh/zh/models) 验证模型可用性
  </Accordion>
</AccordionGroup>
