## 交给我的 Agent 做

把这段任务交给电脑上已经可用的 Agent：

```text
阅读此教程，帮我将 OpenCode 接入 TokenLab：
https://docs.tokenlab.sh/zh/integrations/opencode
先检查已安装版本和实际配置。
保留已有账户、提供商、权限及无关设置。
备份本机文件并展示修改内容。
让我在本机输入所需 API Key，不要在聊天里索取、打印或粘贴密钥。
先验证配置能否加载；真实请求测试的费用须单独说明后再运行。
```

## 概述




在 OpenCode 中添加自定义 OpenAI 兼容服务，填入 TokenLab API 密钥、Base URL 和当前模型 ID 即可。

## 安装

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

验证安装：

```bash
opencode --version
```

## 配置

### 第 1 步：设置环境变量

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

如需永久配置，请添加到 `~/.bashrc` 或 `~/.zshrc`：

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### 第 2 步：配置 OpenCode

OpenCode 当前文档建议通过 `opencode.json` 或 `opencode.jsonc` 配置提供方。对于 TokenLab，请使用自定义提供方，而不是复用内置的 `openai` 提供方：

示例使用仍受支持的 V1 提供商格式，合并到 `~/.config/opencode/opencode.json` 并保留已有提供商和权限。V2 可以读取受支持的 V1 配置，不要在同一提供商内部混入 V2 字段，参见[官方迁移说明](https://opencode.ai/v2/docs/migrate-v1/)。先用 `/models` 检查注册，再用付费测试和 TokenLab 请求记录核对调用。恢复时选择原模型，仅移除本次配置。

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
使用 `@ai-sdk/openai-compatible` 以获得 chat-completions 风格的兼容性。如果你明确需要基于 `/v1/responses` 构建的提供方路径，OpenCode 文档建议将 package 切换为 `@ai-sdk/openai`。
</Note>

## 基本用法

**启动交互模式：**

```bash
opencode
```

**使用 prompt 运行：**

```bash
opencode run "Explain this codebase"
```

**指定模型：**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## 可用模型

| 模型 | 最适合 |
|-------|----------|
| `gpt-5.6-terra` | 复杂任务、代码架构 |
| `gpt-5.6-luna` | 快速修复、简单查询 |
| `claude-sonnet-4-6` | 代码审查、文档编写 |
| `claude-opus-4-6` | 复杂推理 |
| `gemini-3.5-flash` | 快速响应 |

## 常用命令

**分析代码：**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**生成代码：**

```bash
opencode run "Create a REST API with Express"
```

**审查变更：**

```bash
git diff | opencode run "Review these changes"
```

**修复错误：**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## 交互命令

| Command | 描述 |
|---------|-------------|
| `/help` | 显示可用命令 |
| `/models` | 切换到其他模型 |
| `/clear` | 清除对话历史 |
| `/exit` | 退出 OpenCode |

## 故障排查

<AccordionGroup>
  <Accordion title="连接错误">
    - 验证 `options.baseURL` 是否设置为 `https://api.tokenlab.sh/v1`
    - 检查网络连接
    - 尝试使用 `curl https://api.tokenlab.sh/v1/models` 进行测试
  </Accordion>

  <Accordion title="身份验证失败">
    - 验证是否已设置 `TOKENLAB_API_KEY` 环境变量
    - 验证 `options.apiKey` 是否引用了 `{env:TOKENLAB_API_KEY}` 或其他有效的 secret 来源
    - 检查 key 是否以 `sk-` 开头
    - 确保该 key 在 TokenLab Console中处于激活状态
  </Accordion>

  <Accordion title="未找到模型">
    - 检查配置中的模型名称是否完全匹配
    - 在 [tokenlab.sh/en/models](https://tokenlab.sh/zh/models) 验证模型可用性
  </Accordion>
</AccordionGroup>
