## 概述

大多数聊天应用都能通过 OpenAI 兼容设置连接 TokenLab。Base URL 填写 `https://api.tokenlab.sh/v1`，粘贴 TokenLab API 密钥，并选择当前聊天模型 ID。

<Note>
这里配置的是 Chat Completions。需要 Responses 或其他 API 格式的编程工具，请查看对应集成页面。
</Note>


## 支持的应用

| 应用 | 平台 | 备注 |
|-------------|----------|-------|
| Open WebUI | Web, 自托管 | 支持 OpenAI 兼容连接 |
| LibreChat | Web, 自托管 | 支持自定义 OpenAI 地址 |
| LobeChat | Web, 桌面端, 自托管 | 支持自定义模型服务 |
| Cherry Studio | Windows, macOS, Linux | 支持自定义 OpenAI 兼容服务 |
| Chatbox | Windows, macOS, Linux | 支持 OpenAI 兼容设置 |
| DeepChat | Windows, macOS, Linux | 支持自定义模型服务 |
| Jan | 桌面端, 自托管 | 支持远程 OpenAI 兼容服务 |
| TypingMind | Web, 桌面端 | 支持自定义 API 地址 |
| NextChat | Web, 自托管 | 支持自定义 Base URL |
| ChatWise | Windows, macOS | 支持自定义模型服务 |

## 默认连接值

| 字段 | 值 |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API 密钥 | `sk-your-tokenlab-key` |
| API 类型 | OpenAI 兼容 |

如果应用要求输入**完整端点 URL** 而不是基础 URL，请使用：
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## 应用设置示例

<Tabs>
  <Tab title="LobeChat">
    **自托管 LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. 打开 **Settings**（设置） → **AI Service Provider**（AI 服务提供商）
    2. 选择 **OpenAI**
    3. 输入你的 TokenLab API 密钥
    4. 将自定义端点设置为 `https://api.tokenlab.sh/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. 打开 **Settings**（设置） → **Model Provider**（模型提供商）
    2. 添加一个 **OpenAI-compatible**（OpenAI 兼容）提供商
    3. 输入：
       - **Name**: TokenLab
       - **API Base URL**: `https://api.tokenlab.sh/v1`
       - **API 密钥**: `sk-your-tokenlab-key`
    4. 添加你想要使用的模型
  </Tab>

  <Tab title="Chatbox">
    1. 打开 **Settings**（设置） → **AI Model**（AI 模型）
    2. 选择 **OpenAI API Compatible**
    3. 输入：
       - **API Host**: `https://api.tokenlab.sh/v1`
       - **API 密钥**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini` 或 `claude-sonnet-5`
  </Tab>

  <Tab title="TypingMind">
    1. 打开 **Settings**（设置）
    2. 选择 **Custom Endpoint**（自定义端点）
    3. 输入：
       - **Endpoint URL**: `https://api.tokenlab.sh/v1/chat/completions`
       - **API 密钥**: `sk-your-tokenlab-key`
    4. 配置你想要启用的模型
  </Tab>

  <Tab title="Open WebUI">
    1. 打开 **Admin Settings**（管理员设置） → **Connections**（连接）
    2. 添加一个 **OpenAI-compatible** 连接
    3. 输入：
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API 密钥**: `sk-your-tokenlab-key`
    4. 保存并选择你想要启用的模型
  </Tab>

  <Tab title="DeepChat">
    1. 打开 **Settings**（设置） -> **Model Provider**（模型提供商）
    2. 添加一个 OpenAI 兼容提供商
    3. 输入：
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API 密钥**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini`
    4. 保存并进行测试聊天
  </Tab>

  <Tab title="Jan">
    1. 打开 **Settings**（设置） -> **Providers**（提供商）
    2. 添加一个远程 OpenAI 兼容提供商
    3. 输入：
       - **Provider name**: TokenLab
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API 密钥**: `sk-your-tokenlab-key`
    4. 选择 `gpt-5.4-mini` 或其他 TokenLab 模型
  </Tab>

  <Tab title="LibreChat">
    在你的 LibreChat 提供商配置中添加一个 OpenAI 兼容端点，并将其指向：

    ```yaml
    customEndpoints:
      - name: TokenLab
        apiKey: '${OPENAI_API_KEY}'
        baseURL: 'https://api.tokenlab.sh/v1'
        models:
          default: ['gpt-5.6-luna', 'gpt-5.6-terra', 'claude-sonnet-5']
          fetch: false
    ```
  </Tab>
</Tabs>

## 更安全的模型默认值

| 类别 | 建议模型 |
|----------|------------------|
| 通用默认 | `gpt-5.4-mini`, `gpt-5.4`, `gpt-5.5` |
| Anthropic | `claude-sonnet-5`, `claude-opus-4-8`, `claude-fable-5` |
| Google | `gemini-3.5-flash`, `gemini-3.1-flash-lite` |
| DeepSeek | `deepseek-v4-flash`, `deepseek-v4-pro` |

## 提示

<AccordionGroup>
  <Accordion title="在应用支持时优先使用基础 URL">
    当你提供 `https://api.tokenlab.sh/v1` 作为基础 URL 而不是完整端点 URL 时，大多数应用更容易配置且更稳定。
  </Accordion>

  <Accordion title="优先使用较小的模型">
    日常聊天请先使用 `gpt-5.4-mini` 或 `deepseek-v4-flash`，然后将更繁重的推理任务交给 `gpt-5.4` 或 `claude-opus-4-8`。
  </Accordion>

  <Accordion title="保持编程工具独立">
    通用聊天应用和编程代理通常需要不同的端点行为。请将 Codex/Cursor 风格的工具保留在它们专门的集成页面上。
  </Accordion>
</AccordionGroup>

## 故障排除

<AccordionGroup>
  <Accordion title="连接错误">
    - 验证基础 URL 是否完全为 `https://api.tokenlab.sh/v1`
    - 如果应用自动添加路径，请删除末尾的斜杠
    - 如果应用需要完整端点 URL，请使用 `https://api.tokenlab.sh/v1/chat/completions`
  </Accordion>

  <Accordion title="401 Unauthorized（未授权）">
    - 仔细检查你的 API 密钥
    - 确认该 key 在 TokenLab 控制面板中处于激活状态
    - 确保没有多余的空格或换行符
  </Accordion>

  <Accordion title="模型不可用">
    - 验证模型名称是否完全正确
    - 尝试使用广泛支持的默认模型，如 `gpt-5.4-mini`、`deepseek-v4-flash` 或 `claude-sonnet-5`
    - 在 TokenLab 文档或控制面板中检查当前的可用性
  </Accordion>
</AccordionGroup>
