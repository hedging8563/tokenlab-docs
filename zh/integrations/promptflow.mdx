## 概述

在 Prompt flow OpenAI 连接中，把 `base_url` 设为 TokenLab `/v1`，并填写 TokenLab 模型 ID。


## 创建连接

```bash
pf connection create \
  --file ./my_chatbot/openai.yaml \
  --set api_key=sk-your-tokenlab-key base_url=https://api.tokenlab.sh/v1 \
  --name open_ai_connection
```

## 在 `flow.dag.yaml` 中使用

在你的 `flow.dag.yaml` 中，保持连接名称与上述命令一致：

```yaml
connection: open_ai_connection
deployment_name: claude-sonnet-5
```

一些 Prompt flow 模板将此值称为 `deployment_name`，因为相同的模板也支持 Azure OpenAI 部署。对于 TokenLab，请使用 TokenLab 模型 ID。

## 端点注意事项

此配置使用 Prompt flow 的 OpenAI 兼容连接。Responses、Anthropic Messages 和 Gemini 格式需要由自定义 Python 节点直接调用。
