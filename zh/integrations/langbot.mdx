## 概述

LangBot 可以通过 OpenAI 兼容请求器调用 TokenLab。


## TokenLab 请求器

如果你的 LangBot 构建版本包含 **TokenLab** 请求器：

1. 打开 LangBot 的模型提供商设置。
2. 添加一个请求器为 **TokenLab** 的提供商。
3. 填入 TokenLab API 密钥。
4. 选择或创建一个模型，例如 `gpt-5.4-mini`。
5. 把模型添加到对应的机器人或 Pipeline。

## 使用 OpenAI 兼容请求器

如果尚未列出 TokenLab，请使用兼容 OpenAI 的请求器：

| 字段 | 值 |
|-------|-------|
| 请求器 | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API 密钥 | `sk-your-tokenlab-key` |
| 模型 | `gpt-5.4-mini` |

## 选择模型

请从[模型页](https://tokenlab.sh/zh/models)复制当前聊天模型 ID，并确保 LangBot 组件使用模型支持的 API 格式。
