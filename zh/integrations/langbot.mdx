## 概述

LangBot 可以通过兼容 OpenAI 的 LLM 请求器调用 TokenLab。

<Note>
**类型**: 机器人平台

**主要路径**: 兼容 OpenAI 的聊天补全 (chat completions)

**支持置信度**: 在范围限制内支持
</Note>

## TokenLab 请求器

如果您的 LangBot 构建版本包含 **TokenLab** 请求器：

1. 打开 LangBot 的模型提供商设置。
2. 添加一个请求器为 **TokenLab** 的提供商。
3. 将 API key 设置为您的 TokenLab 密钥。
4. 选择或创建一个模型，例如 `gpt-5.4-mini`。
5. 将该模型附加到需要使用它的流水线或机器人上。

## 兼容 OpenAI 的回退方案

如果尚未列出 TokenLab，请使用兼容 OpenAI 的请求器：

| 字段 | 值 |
|-------|-------|
| 请求器 | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| 模型 | `gpt-5.4-mini` |

## 推荐模型

- `gpt-5.4-mini`：适用于大多数机器人交互
- `claude-sonnet-5`：适用于长文本写作和推理
- `deepseek-v4-flash`：适用于快速编码和推理循环
- `gemini-3.5-flash`：适用于快速通用工作流
