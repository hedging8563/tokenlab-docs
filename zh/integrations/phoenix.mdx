## 概述

把 OpenAI Python 客户端 Base URL 设为 TokenLab 后，Phoenix 可以记录这些调用。


## 安装

```bash
pip install arize-phoenix openinference-instrumentation-openai openai
```

## 环境

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 注册 Phoenix

运行示例前，先在本地启动 Phoenix 或使用已有部署。`register()` 默认向本机 `http://localhost:4317` 的 OTLP/gRPC collector 发送追踪数据。其他部署请按 [Phoenix 配置指南](https://arize.com/docs/phoenix/sdk-api-reference/python/arize-phoenix-otel)设置 collector 地址和鉴权。安装 SDK 不会启动 collector。

```python
from phoenix.otel import register

tracer_provider = register(
    project_name="tokenlab-app",
    auto_instrument=True,
)
```

## 调用 TokenLab

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

response = client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[{"role": "user", "content": "Write a short haiku."}],
)

print(response.choices[0].message.content)
```

## 端点说明

Phoenix 会记录 OpenAI SDK 发出的 Chat Completions 请求。其他 TokenLab API 格式是否能被记录，取决于你的 Phoenix 埋点和客户端配置。
