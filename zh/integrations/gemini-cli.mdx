## 概述

Gemini CLI **0.60.0** 已正式记录 API Key 认证下的 `GOOGLE_GEMINI_BASE_URL`。使用 TokenLab 的 Gemini 原生端点，并选择支持 `gemini_generate_content` 的当前模型。参见[官方配置参考](https://geminicli.com/docs/reference/configuration/)和[认证指南](https://geminicli.com/docs/get-started/authentication/)。此配置不会将 Google 订阅转接到 TokenLab。

## 安装

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## 配置

按[快速开始](/zh/quickstart)中 macOS、Linux、WSL 或 Windows PowerShell 的终端步骤设置 `TOKENLAB_API_KEY`，避免把密钥写进命令历史，然后从同一终端启动 Gemini CLI。长期使用请通过本地密钥管理器提供密钥，不要把明文密钥追加到 shell 配置文件。

保留原 Google 登录与配置。为 TokenLab 选择尚未使用的配置根目录，例如 `~/.gemini-tokenlab`（PowerShell 中使用 `$HOME`），并在其中创建 `.gemini`。将现有 `.gemini/settings.json` 及所需策略文件复制到对应位置，保留权限、沙箱和无关设置；仅在副本中合并以下认证字段，没有设置文件时才新建。不要复制 OAuth 缓存或清除原凭据；遵守已有托管认证策略。

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## 用法

下列启动命令使用 `~/.gemini-tokenlab/.gemini/settings.json`；选择其他根目录时请同步调整。通过 Gemini 正常的信任提示确认工作目录，保留原工具审批策略。本次会话显式指定模型。

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

这些变量仅用于本次启动，保留已保存的账户、默认模型与权限。正常启动时不附加这些变量，即可继续使用原设置；不要将它们写入 shell 配置文件。

## 验证

保存设置或列出模型不能证明密钥有效或请求完成。发送提示词会使用 TokenLab 余额；先核对回复及对应[请求记录](https://tokenlab.sh/dashboard/runs?section=requests)，再尝试工具，辅助请求也可能计费。

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
