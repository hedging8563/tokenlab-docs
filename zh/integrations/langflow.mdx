## 概述

在 Langflow **OpenAI** 组件的 **OpenAI API Base** 中填写 TokenLab `/v1` 地址，再选择 TokenLab 模型 ID。


## OpenAI 组件

1. 添加一个 **OpenAI** 语言模型组件。
2. 将 **OpenAI API 密钥** 设置为你的 TokenLab 密钥。
3. 展开高级设置。
4. 将 **OpenAI API Base** 设置为 `https://api.tokenlab.sh/v1`。
5. 将 **Model Name** 设置为 TokenLab 模型 ID。
6. 把模型输出连接到需要使用它的 Agent 或 Chain。

## 配置值

| 字段 | 数值 |
|-------|-------|
| OpenAI API Base | `https://api.tokenlab.sh/v1` |
| OpenAI API 密钥 | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

## 选择模型

请从[模型页](https://tokenlab.sh/zh/models)复制当前聊天模型 ID，并确保组件使用模型支持的 API 格式。

如果你的部署已经通过 LiteLLM 集中管理模型地址，请使用 Langflow 的 LiteLLM Proxy 组件。
