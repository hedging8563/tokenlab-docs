---
title: "Get Pricing"
openapi: "GET /v1/pricing"
description: "Get pricing information for models"
---

This public endpoint does not require an API key.

## Overview

Return current public model prices.

For complex billing details, see [Get a Model](/api-reference/models/get-model).

## Query Parameters

<ParamField query="provider" type="string">
  Optional provider filter such as `openai`, `anthropic`, or `google`.
</ParamField>

<ParamField query="tag" type="string">
  Optional model tag filter such as `chat`, `image`, `video`, `embedding`, or `translation`.
</ParamField>

## Response

<ResponseField name="object" type="string">
  Always `pricing`.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO timestamp when the current public prices were published.
</ResponseField>

<ResponseField name="currency" type="string">
  Always `USD`.
</ResponseField>

<ResponseField name="data" type="array">
  Array of pricing entries. Each item includes `model`, `provider`, `is_lock_price`, `capabilities`, `aliases`, and the public scalar or structured pricing summary fields returned by the interactive schema above.
</ResponseField>
