## Overview

List recent compatibility tasks in the authenticated Workspace using a TokenLab Bearer API key. Without `filter.task_ids`, results cover recent tasks from the past seven days; supplying exact IDs queries those tasks directly.

See also [Seedance 2.0 Video Models](/guides/seedance-2-video) and [Video Generation](/guides/video-generation).

## Listing And Filters

- `page_num`: default `1`, integer from `1` to `500`.
- `page_size`: default `20`, integer from `1` to `500`.
- `filter.status`: `queued`, `running`, `succeeded`, `failed`, `cancelled`, `expired`.
- `filter.task_ids`: Repeat this parameter for multiple exact task IDs; do not join them with commas.
- `filter.model`: Model identifier.
- `filter.service_tier`: `default`, `flex`.

The response contains `items` and `total` for the filtered results. Each item uses the get-task response shape. Use the get endpoint to refresh a known task’s status.

## Example

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?page_num=1&page_size=20&filter.status=succeeded" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?filter.task_ids=cgt-20260102030405-a1b2c" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
