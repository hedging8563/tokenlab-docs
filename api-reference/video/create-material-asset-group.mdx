---
title: "Create Material Asset Group"
openapi: "/openapi.json POST /v1/videos/assets/groups"
description: "Creates a Seedance virtual-avatar material group."
---

Create a `library_type: "aigc_avatar"` material group. Use this endpoint for virtual avatars, products, styles, and other reusable references that do not require real-person verification.

New real-person material groups are created through [visual validation](/api-reference/video/create-visual-validation-session) and cannot be created directly with this endpoint.

`project_name` isolates resources within the authenticated organization. It defaults to `default`; use the same case-sensitive value for related groups and assets. Send it in the JSON body for POST/PUT and in the query string for GET/DELETE.

## Example Request

```bash
curl https://api.tokenlab.sh/v1/videos/assets/groups \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"library_type":"aigc_avatar","group_name":"Product references","description":"Reusable product shots","project_name":"default"}'
```

## Example Response

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
