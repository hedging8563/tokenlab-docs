---
title: "Get Material Asset"
openapi: "GET /v1/videos/assets/{assetId}"
description: "Retrieves one Seedance material asset by TokenLab material asset ID."
---

Retrieve one material asset and inspect its processing status. The asset can be used for video generation only when `ready` is `true` and `status` is `ACTIVE`.

If video generation returns `Seedance material asset not found or not accessible`, verify that you passed this material asset `id`, not the material `group_id`.

`project_name` isolates resources within the authenticated organization. It defaults to `default`; use the same case-sensitive value for related groups and assets. Send it in the JSON body for POST/PUT and in the query string for GET/DELETE.

## Example Request

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Example Response

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
