---
title: "Get Material Asset Group"
openapi: "/openapi.json GET /v1/videos/assets/groups/{groupId}"
description: "Retrieves one Seedance material group by TokenLab group ID."
---

Retrieve one material group. The `library_type` tells you whether the group is a virtual-avatar group or a real-person group.

Use this endpoint before uploading if you need to confirm that the group still exists and has `status: "ACTIVE"`.

`project_name` isolates resources within the authenticated organization. It defaults to `default`; use the same case-sensitive value for related groups and assets. Send it in the JSON body for POST/PUT and in the query string for GET/DELETE.

## Example Request

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/groups/group-20260720123456-vrt01?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## Example Response

```json
{
  "id": "group-20260720123456-vrt01",
  "object": "seedance.material_asset_group",
  "project_name": "default",
  "library_type": "aigc_avatar",
  "group_name": "Product references",
  "description": "Reusable product shots",
  "status": "ACTIVE",
  "metadata": null,
  "created_at": 1782998400000
}
```
