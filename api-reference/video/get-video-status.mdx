---
title: "Get Video Status"
openapi: "/openapi.json GET /v1/tasks/{id}"
description: "Get a video task's status and result"
---

## Path Parameters

<ParamField path="id" type="string" required>
  The task ID returned by the create video request. `id` and `task_id` identify the same task.
</ParamField>

<Info>
If the create response includes `poll_url`, call that URL directly.

An expired or unavailable public task can return `404 async_task_not_found`. If task ownership cannot be established for the current API key, the response is `403 task_not_owned`.
</Info>

## Response

<Note>
Fields describing results, errors, timestamps, and the model are returned when available for the task.
</Note>

<ResponseField name="id" type="string">
  Task ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  Same task ID as `id`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  URL for checking status and retrieving the result.
</ResponseField>

<ResponseField name="billing_transaction_id" type="string">
  Billing transaction ID after settlement. It is separate from the task ID.
</ResponseField>

<ResponseField name="status" type="string">
  Task status: `pending`, `processing`, `completed`, `failed`.
</ResponseField>

<ResponseField name="progress" type="number">
  Optional progress value. Returned only when a real progress value is available; use `status` to determine completion.
</ResponseField>

<ResponseField name="video_url" type="string">
  URL of the generated video (when completed).
</ResponseField>

<ResponseField name="video" type="object">
  Single video result with `url`, `duration`, `width`, and `height` when available.
</ResponseField>

<ResponseField name="videos" type="array">
  Multiple video results when the task returns more than one output.
</ResponseField>

<ResponseField name="error" type="string | object">
  Error message (if failed).
</ResponseField>

<ResponseField name="created" type="integer">
  Creation timestamp.
</ResponseField>

<ResponseField name="updated" type="integer">
  Last update timestamp.
</ResponseField>

<ResponseField name="model" type="string">
  Model used for the task.
</ResponseField>

import requests

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"

    response = requests.get(

        headers={"Authorization": "Bearer sk-your-api-key"}

## Check Interval

- Check every 5–10 seconds.
- Increase the interval for long-running tasks.
- Set a maximum wait time for your application.
- Stop when the status is `failed` and show the returned `error`.

```python
import requests
import time

def wait_for_video(task_id, max_wait=600, interval=5):
    """Wait for video with timeout."""
    start = time.time()

    while time.time() - start < max_wait:
        response = requests.get(
            f"https://api.tokenlab.sh/v1/tasks/{task_id}",
            headers={"Authorization": "Bearer sk-your-api-key"}
        )
        response.raise_for_status()
        data = response.json()

        if data["status"] == "completed":
            return data["video_url"]
        elif data["status"] == "failed":
            raise Exception(data.get("error", "Video generation failed"))

        time.sleep(interval)

    raise TimeoutError("Video generation timed out")
```
