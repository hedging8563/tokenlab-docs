---
title: "Get a Model"
openapi: "GET /v1/models/{model}"
description: "Get a model's capabilities, pricing, and API formats"
---

## Path Parameter

<ParamField path="model" type="string" required>
  Model ID, such as `gpt-5.4` or `claude-sonnet-4-6`.
</ParamField>

## Response

<ResponseField name="id" type="string">Model ID.</ResponseField>
<ResponseField name="object" type="string">Always `model`.</ResponseField>
<ResponseField name="owned_by" type="string">Model maker.</ResponseField>
<ResponseField name="tokenlab" type="object">
  TokenLab model information, including capabilities, prices, billing units, context limits, accepted API formats, operations, and lifecycle status.
</ResponseField>

Common `tokenlab` fields include:

- `capabilities`: text, image, video, audio, and other capabilities.
- `pricing`: current public prices.
- `max_input_tokens` and `max_output_tokens`: context and output limits.
- `accepted_request_formats`: supported API formats.
- `supported_operations`: operations such as text-to-image or image-to-video.
- `lifecycle`: availability, release date, deprecation date, or replacement model.

Some media models also include a recommendation status and update time. Recommendations can change with availability and performance, so do not hard-code their order.

## Example

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.4"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["text"],
    "accepted_request_formats": ["responses", "chat_completions"]
  }
}
```

An unknown model returns `404 model_not_found`.
