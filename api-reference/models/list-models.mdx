---
title: "List Models"
openapi: "/openapi.json GET /v1/models"
description: "List models currently available on TokenLab"
---

The model catalog is public and does not require an API key. Each item includes a summary of current capabilities, prices, and API formats. Retrieve one model when you need full details.

When you provide an API key, TokenLab validates it and filters the catalog for its model permissions and effective delivery policy. A key set to `verified` lists models with TokenLab Verified supply; `official` lists models with Official supply. Refresh your model selector when the key or delivery policy changes. The request's supported delivery override takes precedence over the key and workspace defaults.

## Query Parameters

<ParamField query="category" type="string">
  Filter by `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank`, or `translation`.
</ParamField>

<ParamField query="recommended_for" type="string">
  Return current recommendations for a task such as `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank`, or `translation`.
</ParamField>

<ParamField query="provider" type="string">
  Filter by model maker, such as `openai`, `anthropic`, `google`, or `deepseek`.
</ParamField>

<ParamField query="tag" type="string">
  Filter by a tag such as `chat`, `image`, `video`, `embedding`, or `translation`.
</ParamField>

## Response

<ResponseField name="object" type="string">Always `list`.</ResponseField>
<ResponseField name="data" type="array">Models with `id`, `owned_by`, and a `tokenlab` summary.</ResponseField>

Common list fields under `tokenlab` include:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.deliveryAvailability`: configured `verified` and `official` support, when provided. A missing field means unknown; support does not guarantee real-time availability.
- `tokenlab.pricing` and `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` and `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial`, and `tokenlab.badges`
- `tokenlab.request_format_summary`
- `tokenlab.agent_preferences` when `recommended_for` is used

When `recommended_for` is used, results may also include recommendation status and an update time. Read the current response instead of pinning the order.

## Example

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```
