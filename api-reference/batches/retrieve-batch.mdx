---
title: "Retrieve Batch"
openapi: "GET /v1/batches/{batch_id}"
description: "Retrieves the current status, counts, and result files for a batch."
---

## Overview

Return the batch status, completed and failed counts, and result file IDs.

## Example

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/batches/batch_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Response example

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "completed",
  "input_file_id": "file_abc123",
  "output_file_id": "file_out123",
  "error_file_id": "file_err123",
  "request_counts": { "total": 100, "completed": 98, "failed": 2 }
}
```
</ResponseExample>

## Important fields

<ResponseField name="request_counts" type="object">Counts of total, completed, failed, and cancelled requests.</ResponseField>
<ResponseField name="output_file_id" type="string|null">Successful result file ID.</ResponseField>
<ResponseField name="error_file_id" type="string|null">Failed result file ID.</ResponseField>
