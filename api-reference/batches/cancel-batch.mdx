---
title: "Cancel Batch"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "Cancel a batch that has not finished."
---

Request cancellation of a queued or running batch. The response contains its current status: cancellation may still be in progress or may already be complete. A batch that has already finished keeps its existing terminal status. If the returned status is not terminal, retrieve the batch again to check the result.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">Batch ID.</ResponseField>
<ResponseField name="status" type="string">Current batch status. Do not assume every successful cancellation request returns `cancelling`.</ResponseField>
