---
title: "Cancel Batch"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "Cancel a batch that has not finished."
---

## Overview

You can request cancellation while a batch is queued or running. After the response changes to `cancelling`, retrieve the batch to get its final status.

## Example

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Response example

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

## Important fields

<ResponseField name="id" type="string">Batch ID.</ResponseField>
<ResponseField name="status" type="string">`cancelling` after the request is accepted.</ResponseField>
