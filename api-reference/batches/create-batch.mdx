## Overview

Upload a JSONL file with `purpose=batch`, then use its ID as `input_file_id`. Completed batches return output and error file IDs.

## Notes

- Batch input files must use `purpose=batch`.
- `completion_window` is currently `24h`.
- Output order may differ from input order. Match each result by `custom_id`.
- Streaming is not supported inside batch items.
- Supported item endpoints are `/v1/chat/completions` and `/v1/embeddings`. `/v1/responses` is not supported.

## Example

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "input_file_id": "file_abc123",
    "endpoint": "/v1/chat/completions",
    "completion_window": "24h"
  }'
```
</RequestExample>

Batch prices may differ from synchronous requests. Use the price shown when creating the batch and the final bill.
