---
title: "Get Media Asset"
openapi: "/openapi.json GET /v1/worlds/media-assets/{id}"
description: "Retrieves a World Labs media asset prepared through TokenLab"
---

Retrieve a World asset's name, type, and metadata. Only the Workspace that created it can access it.

## Path Parameters

<ParamField path="id" type="string" required>
  World Labs media asset ID.
</ParamField>

## Response

<ResponseField name="media_asset_id" type="string">
  World Labs media asset ID.
</ResponseField>

<ResponseField name="file_name" type="string">
  Original file name, up to 64 characters.
</ResponseField>

<ResponseField name="kind" type="string">
  Media type: `image` or `video`.
</ResponseField>

<ResponseField name="metadata" type="object | null">
  Custom metadata stored with the asset.
</ResponseField>

<RequestExample>
```bash cURL
curl "https://api.tokenlab.sh/v1/worlds/media-assets/media_asset_123" \
  -H "Authorization: Bearer sk-your-api-key"
```

```python Python
import requests

response = requests.get(
    "https://api.tokenlab.sh/v1/worlds/media-assets/media_asset_123",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const response = await fetch('https://api.tokenlab.sh/v1/worlds/media-assets/media_asset_123', {
  headers: { Authorization: 'Bearer sk-your-api-key' }
});
console.log(await response.json());
```
</RequestExample>
