---
title: "Delete File"
openapi: "/openapi.json DELETE /v1/files/{file_id}"
description: "Delete an uploaded file from the current Workspace."
---

## Overview

Delete a file created through `/v1/files`. A successful response includes `deleted: true`.

With Anthropic Files headers, the same API deletes an Anthropic-format file from the current Workspace.

## Notes

- Deleting a file does not cancel batch jobs that already reference it.
- Missing or inaccessible file IDs return a not-found error.
- Delete image reference files only after no pending image edit request needs them.

## Example

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
