---
title: "Retrieve File Content"
openapi: "GET /v1/files/{file_id}/content"
description: "Download file content."
---

Download batch input, output, or error files. With Anthropic Files headers, the same API downloads Anthropic-format files in the current Workspace.

## Example

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files/file_abc123/content" \
  -H "Authorization: Bearer sk-your-api-key" \
  --output batch-output.jsonl
```
</RequestExample>

## Content Types

Batch files are returned as JSONL or plain text. Image-reference files are returned as binary content.

## Response example

<ResponseExample>
```jsonl 200 OK
{"custom_id":"request-1","response":{"status_code":200,"body":{"id":"chatcmpl_abc123"}}}
{"custom_id":"request-2","error":{"code":"invalid_request_error","message":"Invalid model"}}
```
</ResponseExample>

## Important fields

<ResponseField name="body" type="binary|string">File content. Save or parse it according to `Content-Type`; parse JSONL one line at a time.</ResponseField>
<ResponseField name="custom_id" type="string">ID that matches a batch input item to its result.</ResponseField>
