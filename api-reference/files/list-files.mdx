---
title: "List Files"
openapi: "/openapi.json GET /v1/files"
description: "List uploaded batch and image-reference files."
---

List batch and image-reference files. Filter with `purpose=batch`, `purpose=batch_output`, `purpose=user_data`, or `purpose=vision`.

With Anthropic Files headers, the same API lists Anthropic-format files in the current Workspace.

## Example

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/files?purpose=batch&limit=20" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

## Filters

- For batch and image-reference files, `limit` is 1–10000 (default 10000), with `after` for pagination. In Anthropic Files mode, `limit` is 1–1000 (default 20); use either `after_id` or `before_id`, not both.
- `purpose` can be `batch`, `batch_output`, `user_data`, or `vision`.
- `user_data` and `vision` return TokenLab-created image reference files when available.

## Response example

<ResponseExample>
```json 200 OK
{
  "object": "list",
  "data": [{ "id": "file_abc123", "object": "file", "purpose": "batch" }],
  "first_id": "file_abc123",
  "last_id": "file_abc123",
  "has_more": false
}
```
</ResponseExample>

## Important fields

<ResponseField name="object" type="string">Always `list`.</ResponseField>
<ResponseField name="data" type="array">Files.</ResponseField>
<ResponseField name="has_more" type="boolean">More results are available when `has_more` is true.</ResponseField>
