---
title: "Get Music Status"
openapi: "GET /v1/tasks/{id}"
description: "Retrieves the status and result of a music generation task"
---

Poll this endpoint to check the status of your music generation task.

<Info>
If the create response includes `poll_url`, call that URL directly. `id` and `task_id` identify the same task; you can also use `/v1/tasks/{id}`.

An expired or unavailable public task can return `404 async_task_not_found`. If task ownership cannot be established for the current API key, the response is `403 task_not_owned`.
</Info>

## Path Parameters

<ParamField path="id" type="string" required>
  The music generation task ID.
</ParamField>

## Response

<ResponseField name="id" type="string">
  Task ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias of the same asynchronous task ID, when returned.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Preferred polling URL when the create response supplies one.
</ResponseField>

<ResponseField name="status" type="string">
  Task status: `pending`, `processing`, `completed`, or `failed`.
</ResponseField>

<ResponseField name="progress" type="integer">
  Optional progress value. Returned only when a real progress value is available; use `status` to determine completion.
</ResponseField>

Result fields depend on the operation. Music may return `audio_url` and `audio_id`; lyrics-only tasks return `lyrics`; separation can return multiple files in `data`. `video_url`, title, progress, and other metadata are optional. Check `status` for completion and read the fields actually returned.

<ResponseField name="audio_id" type="string">
  Optional source audio ID, usable with this task's ID in supported follow-up operations.
</ResponseField>

<ResponseField name="data" type="array">
  Optional output array, including separated audio files with `audio_url` or `url`.
</ResponseField>

<ResponseField name="audio_url" type="string">
  URL to download the audio file (when completed).
</ResponseField>

<ResponseField name="video_url" type="string">
  URL to the video version with visualizer (when completed).
</ResponseField>

<ResponseField name="title" type="string">
  Generated song title.
</ResponseField>

<ResponseField name="lyrics" type="string">
  Generated or provided lyrics.
</ResponseField>

<ResponseField name="error" type="string | object">
  Error message (when failed).
</ResponseField>

```python Python
import requests
import time

task_id = "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
poll_url = f"/v1/tasks/{task_id}"

while True:
    response = requests.get(
        f"https://api.tokenlab.sh{poll_url}",
        headers={"Authorization": "Bearer sk-your-api-key"}
    )
    response.raise_for_status()
    result = response.json()

    if result["status"] == "completed":
        print(result)
        break
    elif result["status"] == "failed":
        print(result.get("error", "Task failed"))
        break

    time.sleep(5)  # Poll every 5 seconds
```

```javascript JavaScript
const taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
const pollUrl = `/v1/tasks/${taskId}`;

async function pollForMusic() {
  while (true) {
    const response = await fetch(
      `https://api.tokenlab.sh${pollUrl}`,
      { headers: { 'Authorization': 'Bearer sk-your-api-key' } }
    );

    if (!response.ok) throw new Error(await response.text());
    const result = await response.json();

    if (result.status === 'completed') {
      console.log(result);
      return result;
    } else if (result.status === 'failed') {
      throw new Error(typeof result.error === 'string'
        ? result.error
        : JSON.stringify(result.error ?? result));
    }

    await new Promise(r => setTimeout(r, 5000));
  }
}

await pollForMusic();
```

```go Go
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "log"
    "net/http"
    "time"
)

func main() {
    taskID := "ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
    pollURL := fmt.Sprintf("https://api.tokenlab.sh/v1/tasks/%s", taskID)

    for {
        req, err := http.NewRequest("GET",
            pollURL, nil)
        if err != nil {
            log.Fatal(err)
        }
        req.Header.Set("Authorization", "Bearer sk-your-api-key")

        client := &http.Client{}
        resp, err := client.Do(req)
        if err != nil {
            log.Fatal(err)
        }
        if resp.StatusCode < 200 || resp.StatusCode >= 300 {
            body, _ := io.ReadAll(resp.Body)
            resp.Body.Close()
            log.Fatalf("HTTP %d: %s", resp.StatusCode, body)
        }

        var result map[string]interface{}
        err = json.NewDecoder(resp.Body).Decode(&result)
        resp.Body.Close()
        if err != nil {
            log.Fatal(err)
        }

        if result["status"] == "completed" {
            fmt.Println(result)
            break
        } else if result["status"] == "failed" {
            fmt.Println(result)
            break
        }

        time.Sleep(5 * time.Second)
    }
}
```

```php PHP
<?php
$taskId = 'ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
$pollUrl = "https://api.tokenlab.sh/v1/tasks/{$taskId}";

while (true) {
    $ch = curl_init($pollUrl);

    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer sk-your-api-key'
        ]
    ]);

    $response = curl_exec($ch);
    $httpStatus = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $curlError = curl_error($ch);
    curl_close($ch);

    if ($response === false) {
        throw new RuntimeException($curlError);
    }
    if ($httpStatus < 200 || $httpStatus >= 300) {
        throw new RuntimeException("HTTP {$httpStatus}: {$response}");
    }

    $result = json_decode($response, true, 512, JSON_THROW_ON_ERROR);

    if ($result['status'] === 'completed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    } elseif ($result['status'] === 'failed') {
        echo json_encode($result, JSON_UNESCAPED_SLASHES) . "\n";
        break;
    }

    sleep(5);
}
```
