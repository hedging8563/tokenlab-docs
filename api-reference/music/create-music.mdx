---
title: "Create Music"
openapi: "POST /v1/music/generations"
description: "Creates a music generation task using Suno"
---

<Note>
Use `GET /v1/models?recommended_for=music` to get current music models.
</Note>

Generate music and lyrics using AI. This is an asynchronous API. Create responses return a task identity, and may also return a preferred `poll_url` for status checks.

## Request Body

<ParamField body="model" type="string" default="suno_music">
  Music model ID, such as `suno-music`. For lyrics only, choose a model whose current public operations include `lyrics`.
</ParamField>

<ParamField body="prompt" type="string">
  Music description or replacement text. Required for music, lyrics, upload-cover, upload-extend, and replace-section; optional for add-instrumental and stem separation.
</ParamField>

<ParamField body="title" type="string">
  Title for the generated song.
</ParamField>

<ParamField body="tags" type="string">
  Style tags (e.g., "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  Styles to avoid. Required when `audio_operation` is `add-instrumental`.
</ParamField>

<ParamField body="action" type="string">
  Optional `MUSIC` or `LYRICS` value. Choose a model that supports the corresponding public operation; this field does not add lyrics support to a music-only model.
</ParamField>

<ParamField body="mv" type="string">
  Suno version selector. Required for generation, upload-cover, upload-extend, add-instrumental, and replacement from `audio_url`. Omit it for lyrics, replacement from `task_id` + `audio_id`, and stem separation. Accepted values: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  Set to `true` to generate instrumental output without vocals.
</ParamField>

<ParamField body="audio_url" type="string">
  Publicly reachable reference or uploaded audio URL. When provided without `audio_operation`, TokenLab uses the upload-cover flow.
</ParamField>

<ParamField body="audio_operation" type="string">
  Audio operation: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation`, and `advanced-split` require `task_id` + `audio_id`; `advanced-split` also requires `stem_name`. `upload-extend` requires `continue_at` greater than 0. `add-instrumental` requires `audio_url`, `title`, `tags`, and `negative_tags`.

  For `replace-section`, send `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s`, and `full_lyrics`. Choose exactly one source: `task_id` + `audio_id`, or `audio_url` + `mv`. The replacement interval must be 6–60 seconds.
</ParamField>

<ParamField body="task_id" type="string">
  Source task ID belonging to your organization, for generated-audio replacement or stem separation.
</ParamField>

<ParamField body="audio_id" type="string">
  Source audio ID returned in the source task result. Required with `task_id` for generated-audio replacement and stem separation.
</ParamField>

<ParamField body="infill_start_s" type="number">
  Replacement start time in seconds, at least 0. Required for `replace-section`.
</ParamField>

<ParamField body="infill_end_s" type="number">
  Replacement end time in seconds. Required for `replace-section`; it must be 6–60 seconds after `infill_start_s`.
</ParamField>

<ParamField body="full_lyrics" type="string">
  Full lyrics for the resulting song. Required for `replace-section`.
</ParamField>

<ParamField body="stem_name" type="string">
  Stem name. Required for `advanced-split`.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  ID of a previous clip to continue from.
</ParamField>

<ParamField body="continue_at" type="number">
  Time in seconds from which to continue. Required and greater than 0 for `upload-extend`.
</ParamField>

<Note>
`prompt` accepts up to 5000 characters; `tags` and `negative_tags` accept up to 1000 characters each. Supported operations and parameters depend on the selected model's current details.
</Note>

## Response

<ResponseField name="id" type="string">
  Task ID for polling status.
</ResponseField>

<ResponseField name="task_id" type="string">
  Alias of the same asynchronous task ID, when returned.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Preferred polling URL for this task when provided.
</ResponseField>

<ResponseField name="status" type="string">
  Task status: `pending`, `processing`, `completed`, or `failed`.
</ResponseField>

<ResponseField name="created" type="integer">
  Task creation time as a Unix timestamp, when returned.
</ResponseField>

```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/music/generations" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \

    "model": "suno-music",
```

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
