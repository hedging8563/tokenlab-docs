---
title: "Create Transcription"
openapi: "POST /v1/audio/transcriptions"
description: "Transcribes audio into the input language"
---

<Note>
Use `GET /v1/models?recommended_for=stt` to get current transcription models.
</Note>

## Request Body

Transcription can return the transcript immediately or accept an asynchronous task with HTTP `200`, `id`, and `status`. For an accepted task, follow `poll_url`, or query `/v1/tasks/{id}`. For longer synchronous audio, allow a client timeout of at least `120s`.

<ParamField body="file" type="file" required>
  Audio file to transcribe. Supported formats: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. Maximum file size: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  Transcription model ID, for example `whisper-1` or `gpt-4o-transcribe`. Find current choices with `GET /v1/models?recommended_for=stt`.
</ParamField>

<ParamField body="language" type="string">
  Language of the audio in ISO-639-1 format (e.g., `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  Optional text to guide the model's style or continue a previous segment.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  Output format. Whisper supports `json`, `text`, `srt`, `verbose_json`, and `vtt`; other models may support a different subset. Check the selected model's details.
</ParamField>

<ParamField body="temperature" type="number">
  Sampling temperature from 0 to 1, only for models that support this parameter.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  `word` and/or `segment`, when supported by the selected model. For Whisper, use `response_format=verbose_json`. In multipart requests, repeat `timestamp_granularities[]` for multiple values.
</ParamField>

## Response

The fields below describe JSON transcript or translation responses. `text`, `srt`, and `vtt` return raw text or subtitles rather than a JSON object. Additional fields depend on the model and output format.

<ResponseField name="text" type="string">
  The transcribed text.
</ResponseField>

For `verbose_json`:

<ResponseField name="task" type="string">
  Task name when returned, such as `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  Detected language.
</ResponseField>

<ResponseField name="duration" type="number">
  Audio duration in seconds.
</ResponseField>

<ResponseField name="segments" type="array">
  Transcription segments with timestamps.
</ResponseField>

<ResponseField name="words" type="array">
  Word-level timestamps (if requested).
</ResponseField>

An accepted asynchronous transcription task returns the following fields instead of the transcript:

<ResponseField name="id" type="string">
  Task ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  Async task identifier alias when provided.
</ResponseField>

<ResponseField name="status" type="string">
  Task status: `pending`, `processing`, `completed`, or `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  Preferred polling URL when the create response supplies one.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## Translation

To translate audio to English, use the translations endpoint:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
