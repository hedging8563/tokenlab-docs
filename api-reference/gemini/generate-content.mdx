---
title: "Generate Content"
openapi: "POST /v1beta/models/{model}:generateContent"
description: "Generates content using Google Gemini API format"
---

Use Gemini request and response formats with a model returned by the Gemini Models API. ProtoJSON lowerCamelCase and the corresponding proto snake_case field names are accepted. Supported optional fields and values depend on the selected model.

## Path Parameters

<ParamField path="model" type="string" required>
  Model name (e.g., `gemini-2.5-pro`, `gemini-3.5-flash`).
</ParamField>

## Query Parameters

<ParamField query="key" type="string">
  API key (alternative to header authentication).
</ParamField>

## Authentication

Gemini endpoints support multiple authentication methods:
- `?key=YOUR_API_KEY` query parameter
- `x-goog-api-key: YOUR_API_KEY` header
- `Authorization: Bearer YOUR_API_KEY` header

## Request Body

<ParamField body="contents" type="array" required>
  Conversation contents with `parts` and an optional `role`. Media parts use `inlineData` / `inline_data` or `fileData` / `file_data`. Files and Cache IDs created by TokenLab can only be used in their owning Workspace.
</ParamField>

<ParamField body="systemInstruction" type="object">
  System instruction for the model.
</ParamField>

<ParamField body="generationConfig" type="object">
  Generation settings such as `temperature`, `topP`, `topK`, `maxOutputTokens`, `stopSequences`, `candidateCount`, `responseModalities`, `responseMimeType`, `responseSchema`, and `thinkingConfig`. Corresponding snake_case names are also accepted. Supported values and combinations depend on the model.
</ParamField>

<ParamField body="safetySettings" type="array">
  Safety filter settings.
</ParamField>

Every lowerCamelCase field shown above may also use its official proto `snake_case` spelling, for example `system_instruction`, `generation_config`, `safety_settings`, `tool_config`, `cached_content`, `file_data.file_uri`, and `inline_data.mime_type`.

## Supported Methods

The Gemini-compatible API includes model list/get, `generateContent`, `streamGenerateContent`, `countTokens`, `embedContent`, and `batchEmbedContents`. Gemini Interactions and Live are not available.

## Response

<ResponseField name="candidates" type="array">
  Generated content candidates.
</ResponseField>

<ResponseField name="usageMetadata" type="object">
  Token usage information.
</ResponseField>

## Vision Input Example

For Gemini multimodal requests, place media inside `contents[].parts[]` using either inline bytes or URL-based file references.

Supported media categories in the public Gemini contract:
- image
- audio
- video

For inline media, use either `inlineData` or `inline_data` and pass Base64-encoded file bytes.

For URL-based media, use either `fileData` or `file_data` and pass a public `https` URL.

## Video Input Example

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Please describe this video." },
        {
          "fileData": {
            "mimeType": "video/mp4",
            "fileUri": "https://example.com/demo.mp4"
          }
        }
      ]
    }
  ]
}
```
