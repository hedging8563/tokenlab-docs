## Overview




OpenCode can use TokenLab through a custom OpenAI-compatible provider. Add the TokenLab API key, Base URL, and a current model ID.

## Installation

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

Verify installation:

```bash
opencode --version
```

## Configuration

### Step 1: Set Environment Variables

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

For permanent configuration, add to `~/.bashrc` or `~/.zshrc`:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### Step 2: Configure OpenCode

OpenCode's current docs recommend configuring providers through `opencode.json` or `opencode.jsonc`. For TokenLab, use a custom provider instead of overloading the built-in `openai` provider:

This example uses the supported V1 provider shape. Merge it into `~/.config/opencode/opencode.json` and keep existing providers and permissions. V2 can read supported V1 settings; do not mix V2 fields inside this provider entry. See the [official migration guide](https://opencode.ai/v2/docs/migrate-v1/). Use `/models` to confirm registration, then check a paid test against TokenLab Requests. To undo, select your previous model and remove only this entry.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
Use `@ai-sdk/openai-compatible` for chat-completions style compatibility. If you specifically need a provider path built on `/v1/responses`, OpenCode's provider docs recommend switching the package to `@ai-sdk/openai`.
</Note>

## Basic Usage

**Start interactive mode:**

```bash
opencode
```

**Run with a prompt:**

```bash
opencode run "Explain this codebase"
```

**Specify model:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## Choose a Model

Copy a current coding model ID from the [Models page](https://tokenlab.sh/en/models). Compare models on your own repository before setting a default.

## Common Commands

**Analyze code:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**Generate code:**

```bash
opencode run "Create a REST API with Express"
```

**Review changes:**

```bash
git diff | opencode run "Review these changes"
```

**Fix errors:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## Interactive Commands

| Command | Description |
|---------|-------------|
| `/help` | Show available commands |
| `/models` | Switch to a different model |
| `/clear` | Clear conversation history |
| `/exit` | Exit OpenCode |

## Troubleshooting

<AccordionGroup>
  <Accordion title="Connection Error">
    - Verify `options.baseURL` is set to `https://api.tokenlab.sh/v1`
    - Check network connectivity
    - Try `curl https://api.tokenlab.sh/v1/models` to test
  </Accordion>

  <Accordion title="Authentication Failed">
    - Verify `TOKENLAB_API_KEY` environment variable is set
    - Verify `options.apiKey` references `{env:TOKENLAB_API_KEY}` or another valid secret source
    - Check that the key starts with `sk-`
    - Ensure the key is active in TokenLab dashboard
  </Accordion>

  <Accordion title="Model Not Found">
    - Check model name in config matches exactly
    - Verify model availability at [tokenlab.sh/en/models](https://tokenlab.sh/en/models)
  </Accordion>
</AccordionGroup>
