## Overview

Use this page for the OpenHands UI with LiteLLM-backed **Settings → LLM → Advanced** options. Select **OpenAI** and enter a custom model with the `openai/` prefix, a TokenLab key in the local API-key field, and the Base URL below. Record the previous selection first and restore it when finished. Keep existing accounts and tool permissions. See the [official OpenAI-compatible configuration](https://docs.openhands.dev/openhands/usage/llms/openai-llms). CLI, cloud and source-checkout installations can use different setup flows; follow the instructions for your installed edition. `make setup-config` is not a general installed-CLI command.

## Model Settings

Save the current provider, model and connection settings locally before editing. These controls change the active model selection; restore your previous values when finished. Keep signed-in accounts and tool permissions unchanged. Do not overwrite another OpenAI-compatible connection without a restorable backup.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

Saving settings or listing models does not verify a key or a completed request. A prompt uses TokenLab balance. Check the reply and its matching [request record](https://tokenlab.sh/dashboard/runs?section=requests) before trying tools; auxiliary requests may also be billed.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
