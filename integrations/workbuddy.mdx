## Overview


[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) can add TokenLab through its visual custom-model editor.

## Configure TokenLab

1. Open **Settings → Model**.
2. Add a model and select **Custom** as the provider.
3. Enter the following values:

| Field | Value |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | Your TokenLab API key |
| Model name | A current TokenLab chat model ID |
| Custom Protocol | **Off** |

<Warning>
Keep **Custom Protocol** off. In standard mode WorkBuddy validates the base URL and appends `/chat/completions`. If you turn it on while entering only `https://api.tokenlab.sh/v1`, requests are sent to the wrong path.
</Warning>

## Advanced model settings

Choose capability flags and context/output limits from the selected model’s current TokenLab details. Do not enable image input or reasoning for every model, and do not copy a 1M/128K limit to a different model. Use the model ID exactly as shown by TokenLab.

Saving and selecting a model confirms only local configuration. A text or tool task uses TokenLab balance; compare its reply with the matching [request record](https://tokenlab.sh/dashboard/runs?section=requests). To undo setup, select your previous model and remove only the TokenLab entry in the editor.

## Troubleshooting

<AccordionGroup>
  <Accordion title="404 or route not found">
    Confirm the endpoint is `https://api.tokenlab.sh/v1` and **Custom Protocol** is off. Do not paste `/chat/completions` when standard mode is selected.
  </Accordion>
  <Accordion title="Model not found">
    Copy the exact model ID from TokenLab and check that it supports Chat Completions and tools.
  </Accordion>
  <Accordion title="Agent replies but cannot use tools">
    Enable **Tool calling** and make sure the selected TokenLab model advertises tool-use support.
  </Accordion>
</AccordionGroup>

<Warning>
Screenshots of the model dialog can reveal endpoints or API keys. Mask credentials before sharing them and rotate any exposed key.
</Warning>

The official desktop app is available for macOS and Windows. Use the [official model editor](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model); this guide does not assume a Linux build or a writable configuration-file schema.

MCP and Skills have separate installation paths: [API tools](/integrations/tokenlab-mcp-server) and [integration instructions](/integrations/coding-agent-skill). They do not change WorkBuddy’s main model.
