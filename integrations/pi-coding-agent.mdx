## Let my agent set this up

Copy this task to an agent already running on your computer:

```text
Read this guide and help me connect Pi to TokenLab:
https://docs.tokenlab.sh/integrations/pi-coding-agent
Check my installed version and active configuration first.
Preserve existing accounts, providers, permissions and other settings.
Back up local files and show proposed changes.
Have me enter any API key locally; never ask for, print or paste it in chat.
Check configuration loading first.
Explain any paid request test separately before running it.
```

## Install and configure Pi

Use the current [Pi installation instructions](https://pi.dev/). The npm package is `@earendil-works/pi-coding-agent`. On Windows, follow the [shell setup](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/windows.md); the CLI uses Git Bash by default. Skip installation when Pi is already available.

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
pi --version
```

Merge this into `~/.pi/agent/models.json`, or the active `PI_CODING_AGENT_DIR` directory. Back up the file and preserve other providers. Set `TOKENLAB_API_KEY` locally in the environment that launches Pi; never paste the key into chat. A Base URL environment variable alone does not create this provider.

```json
{
  "providers": {
    "tokenlab": {
      "baseUrl": "https://api.tokenlab.sh/v1",
      "api": "openai-completions",
      "apiKey": "$TOKENLAB_API_KEY",
      "models": [{ "id": "gpt-5.6-luna" }]
    }
  }
}
```

The leading `$` in `"$TOKENLAB_API_KEY"` is required: a bare `"TOKENLAB_API_KEY"` is a literal string. Choose a current model with Chat Completions and tool support. Set context, output, image and reasoning options from that model’s details instead of copying another model’s limits.

## Check and restore

Run `pi --list-models`, then open `/model` in Pi and select `tokenlab/gpt-5.6-luna`. Opening the picker reloads `models.json`. This checks model registration and credential presence, not credential validity or a completed API request.

A short text request uses TokenLab balance. Check its reply and the matching [request record](https://tokenlab.sh/dashboard/runs?section=requests) before testing tools. To restore your setup, select the previous provider and remove only the TokenLab entry you added.

## Skills and MCP

Pi loads [Skills natively](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/skills.md). Install the [TokenLab Skill](/integrations/coding-agent-skill) for API integration guidance. MCP requires a separate Pi extension; do not paste an MCP client configuration into `models.json`.
