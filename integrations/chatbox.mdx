## Overview

Chatbox can use TokenLab through its OpenAI-compatible API settings.


## Configure Chatbox

1. Open **Settings** -> **AI Model**
2. Choose **OpenAI API Compatible**
3. Enter:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. Save and send a short test message.

## Choose a model

Use a current chat model ID from the [Models page](https://tokenlab.sh/en/models). If Chatbox does not list it automatically, add the exact ID manually.

## Notes

If your Chatbox build already lists TokenLab, select it directly. Otherwise use the OpenAI-compatible settings above.
