## Overview




[Claude Code](https://code.claude.com/docs/en/setup) can use a TokenLab API key and the TokenLab Messages API for Claude models.

## Installation

Anthropic now recommends the native installer. The npm package still works, but Anthropic has deprecated that installation method.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

If you specifically need the npm package, use:

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
Do not use `sudo npm install -g` for Claude Code.
</Warning>

## Configuration

Use the [Quickstart](/quickstart) terminal instructions for macOS, Linux, WSL, or Windows PowerShell to set `TOKENLAB_API_KEY` without putting the key in command history. Launch Claude Code from that terminal. For persistent use, use your local secret manager; do not append a plaintext key to your shell profile.

These variables apply only to this launch; your saved account, default model and permission settings stay in place. Launch normally without the variables to use your previous setup. Do not persist them in your shell profile.

This session path uses Claude Code **2.1.263** and Bearer authentication through `ANTHROPIC_AUTH_TOKEN`. Keep the Base URL without `/v1`. Existing settings-file `env` values, credential helpers, cloud-provider switches or managed policies can affect authentication; inspect them before launch. If they conflict, use the setup helper below instead of deleting account data or weakening policies. Check `/status` for the selected model and permissions.

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

## Usage

After configuration, use Claude Code normally:

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

Verify the installation if needed:

```bash
claude --version
claude doctor
```

## Choose a model

Copy a current Claude model ID from the [Models page](https://tokenlab.sh/en/models), then pass it with `--model`:

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Connection errors">
    Verify the base URL is exactly `https://api.tokenlab.sh` (no `/v1` suffix for Anthropic-style requests).
  </Accordion>

  <Accordion title="Invalid API key">
    Ensure your TokenLab API key starts with `sk-` and has sufficient balance.
  </Accordion>


  <Accordion title="Model not found">
    Check the model name is correct. Use `claude-sonnet-4-6` format.
  </Accordion>
</AccordionGroup>
