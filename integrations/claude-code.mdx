## Overview




[Claude Code](https://code.claude.com/docs/en/setup) can use a TokenLab API key and the TokenLab Messages API for Claude models.

## Installation

Anthropic now recommends the native installer. The npm package still works, but Anthropic has deprecated that installation method.

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

If you specifically need the npm package, use:

```bash
npm install -g @anthropic-ai/claude-code
```

<Warning>
Do not use `sudo npm install -g` for Claude Code.
</Warning>

## Configuration

### Environment Variables

Set the following environment variables:

```bash
export ANTHROPIC_API_KEY="sk-your-tokenlab-key"
export ANTHROPIC_BASE_URL="https://api.tokenlab.sh"
```

Add these to your shell profile (`~/.bashrc`, `~/.zshrc`, etc.) for persistence.

<Note>
For TokenLab, keep `ANTHROPIC_BASE_URL` at `https://api.tokenlab.sh` without a `/v1` suffix. This matches the Anthropic-style endpoint shape and the unified gateway pattern documented by Claude Code.
</Note>

### Configuration File

Alternatively, create or edit `~/.claude/settings.json`:

Back up and merge settings; do not replace existing accounts, permissions or unrelated environment values. `ANTHROPIC_API_KEY` sends `X-Api-Key`, while `ANTHROPIC_AUTH_TOKEN` sends a Bearer token. Keep the TokenLab setup on one intentional auth path. Start Claude Code and use `/status` to inspect the active model and configuration source; this is not a paid-request success check. After a short paid request, compare its reply with TokenLab Requests. Restore only your added settings to switch back. See [settings precedence](https://code.claude.com/docs/en/settings).

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  }
}
```

## Usage

After configuration, use Claude Code normally:

```bash
# Start an interactive session
claude

# Run a single command
claude "Explain this code" < main.py

```

Verify the installation if needed:

```bash
claude --version
claude doctor
```

## Choose a model

Copy a current Claude model ID from the [Models page](https://tokenlab.sh/en/models), then pass it with `--model`:

```bash
claude --model claude-sonnet-4-6 "Review this PR"
```

You can also set a default in your configuration:

```json
{
  "env": {
    "ANTHROPIC_API_KEY": "sk-your-tokenlab-key",
    "ANTHROPIC_BASE_URL": "https://api.tokenlab.sh"
  },
  "model": "claude-sonnet-5"
}
```

## Extended Thinking

For complex reasoning tasks, use models with extended thinking:


## Troubleshooting

<AccordionGroup>
  <Accordion title="Connection errors">
    Verify the base URL is exactly `https://api.tokenlab.sh` (no `/v1` suffix for Anthropic-style requests).
  </Accordion>

  <Accordion title="Invalid API key">
    Ensure your TokenLab API key starts with `sk-` and has sufficient balance.
  </Accordion>

  <Accordion title="Gateway requires Authorization bearer token">
    Claude Code's gateway mode also supports `ANTHROPIC_AUTH_TOKEN`. Keep using `ANTHROPIC_API_KEY` for the standard TokenLab setup unless you intentionally switched your gateway auth behavior.
  </Accordion>

  <Accordion title="Model not found">
    Check the model name is correct. Use `claude-sonnet-4-6` format.
  </Accordion>
</AccordionGroup>
