## Overview

Add TokenLab as a Portkey provider for OpenAI-compatible Chat Completions. Use Responses only when your Portkey version supports a custom Responses endpoint.


## Provider Values

| Field | Value |
|-------|-------|
| Provider | `tokenlab` |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | `sk-your-tokenlab-key` |
| Model | A current TokenLab model ID |

## Chat Completions

Use TokenLab for OpenAI-compatible chat requests:

```bash
curl https://your-portkey-gateway.example/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-portkey-provider: tokenlab" \
  -H "Authorization: Bearer sk-your-tokenlab-key" \
  -d '{
    "model": "gpt-5.6-luna",
    "messages": [{"role": "user", "content": "Say hello from TokenLab."}]
  }'
```

## Responses

If your Portkey version supports a custom Responses URL, choose a current Responses-capable model from the [Models page](https://tokenlab.sh/en/models) and use `/v1/responses`.

## Other API Formats

Anthropic Messages and Gemini can be used through Portkey only if your Portkey version supports custom URLs for those formats.
