## Overview

Flowise can call TokenLab through a TokenLab chat node when available, or through an OpenAI-compatible chat model node pointed at TokenLab.


## TokenLab Node

If your Flowise build includes a **TokenLab** chat model node:

1. Add **Chat Models** -> **TokenLab**
2. Create a TokenLab API credential
3. Set **Model Name** to `gpt-5.4-mini`
4. Connect it to your chain, agent, or workflow
5. Run a test prompt.

## OpenAI-Compatible Fallback

If your build does not include a TokenLab node, add **Chat Models** → **OpenAI Custom Model**. Under **Connect Credential**, create an **OpenAI API** credential with your TokenLab key. Set **Model Name** and **Additional Parameters** → **Base Path** as follows:

| Field | Value |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

Connect the node to your chain, agent, or workflow, then run a test prompt.

## Choose a model

Copy a current chat model ID from the [Models page](https://tokenlab.sh/en/models). The model must support Chat Completions for this node.
