一份 TokenLab 餘額可用於各模型，無訂閱或最低消費；費用依模型與實際用量計算。

## 價格與交付方式

目前價格請查模型頁、`GET /v1/models/{model}/pricing` 或 Pricing API，不要將複製的價目表寫死。文字、嵌入等可能按輸入、輸出或快取 token 收費；媒體也可能按圖片、秒、分鐘、請求或工作收費。

`TokenLab Verified` 使用 TokenLab 公開價格，`Official` 使用模型廠商公開價格的 Official 層。`Auto` 優先使用 Verified，必要時使用 Official；只按交付結果的選項收取一次費用。Console 付費生成在確認前顯示最高估價，完成後 Runs 與 Usage 顯示最終費用。

[Pricing API](/zh-Hant/api-reference/pricing/get-pricing)

## 非同步計費與記錄

部分工作建立時會預留估計費用。保存 task ID 與 `poll_url`，查詢到 `completed` 或 `failed`。成功工作收費一次，未使用的預留金額會釋放；失敗工作釋放或退回待扣金額。

非串流 OpenAI 相容回應在計費完成後可包含 `billing_transaction_id`，也可能透過 `X-Billing-Transaction-ID` 回傳；原生格式可能僅有 header。非同步或串流結果可能先於計費記錄完成，缺少該值時請查 Usage。

在 Usage 查看模型、Key、成本與用量記錄。Token 計算依模型、語言及媒體而異，字元估算不能代替最終帳單；串流不會減少計費 token。比較相同任務的最終成本，並依所選模型設定輸出上限。

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

- [Usage](https://tokenlab.sh/dashboard/usage)
- [非同步任務與輪詢](/zh-Hant/guides/async-jobs-polling)

## Console 操作

在 Console → Billing 選擇金額與結帳時提供的付款方式。付款服務確認後餘額更新。

在 Console → API Keys 建立或編輯 Key 時設定支出上限；達到上限會回傳 `402 Payment Required`。

在 Console → Settings 設定低餘額門檻以接收電子郵件通知。帳務問題請將 Request ID 和 task ID 提供給 support@tokenlab.sh，不要提供 API Key。
