如果要在應用程式中加入 Seedance 2.0，請從這裡開始。本頁只負責模型與工作流程選擇；火山遷移、可重用素材及真人驗證各有獨立指南。

## 選擇整合路徑

| 目標 | 使用方式 | 下一步 |
| --- | --- | --- |
| 建立新的 TokenLab 影片整合 | 統一 `POST /v1/videos/generations` API | [影片生成指南](/zh-Hant/guides/video-generation) |
| 遷移既有火山 Seedance 用戶端 | 火山相容 REST 或 Action 介面 | [從火山遷移 Seedance](/zh-Hant/guides/seedance-volcengine-migration) |
| 重用虛擬人、商品、風格或真人參考 | TokenLab 素材庫 | [Seedance 素材與真人驗證](/zh-Hant/guides/seedance-materials) |

三條路徑都使用 `Authorization: Bearer <TOKENLAB_API_KEY>`。火山相容路徑保留火山請求格式，但不接受 AK/SK 簽名。

## 模型選擇

| 模型 | 支援解析度 |
|-------|-----------------------|
| `seedance-2.0` | `480p`, `720p`, `1080p`, `4k` |
| `seedance-2.0-fast` | `480p`, `720p` |
| `seedance-2.0-mini` | `480p`, `720p` |

`seedance-2.0-fast` 和 `seedance-2.0-mini` 不支援 `1080p` 和 `4k` 請求。音訊僅能在支援的參考素材工作流程中使用；不支援純音訊或純文字加音訊的 Seedance 請求。

## 支援的操作

| 操作 | 常見輸入 |
|-----------|----------------|
| `text-to-video` | `prompt` |
| `image-to-video` | `prompt`, `image_url` 或相容的圖片輸入 |
| `start-end-to-video` | `prompt`, `start_image`, `end_image` |
| `reference-to-video` | `prompt`, `reference_images`, 可選 `video_urls`, 可選 `audio_urls` |
| `video-to-video` | `prompt`, `video_url` 或相容的影片輸入 |
| `video-extension` | `task_id` 或模型特定的續傳輸入 |

## 定價與非同步結果

Seedance 2.0 的定價取決於輸出解析度、輸入類型與模型。在將產品 UI 硬編碼之前，請使用 [Pricing API](/zh-Hant/api-reference/pricing/get-pricing) 或 [Models API](/zh-Hant/api-reference/models/list-models)。

影片生成為非同步處理。請追蹤建立請求時回傳的 `poll_url`，或使用 [取得任務狀態](/zh-Hant/api-reference/tasks/get-task-status) 搭配回傳的任務 ID。
