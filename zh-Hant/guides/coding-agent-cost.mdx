---
title: "Coding Agent 成本優化"
description: "用實際用量管理費用"
---

在工作區用量中比較相似工作的最終費用。記錄模型、API 金鑰、輸入、輸出與快取 token，以及失敗或重複的請求。

讓指令和上下文聚焦於工作。舊歷史不再有幫助時，開啟新工作階段。依 API 格式設定輸出上限，並保留完成工作的足夠空間。

快取折扣及命中率並無保證。請查閱模型目前的詳細資訊與實際記錄的快取用量。為專案分別使用 API 金鑰及合適的額度上限。比較每項正確完成工作的費用，而不只是 token 單價。
