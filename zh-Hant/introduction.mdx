## 什麼是 TokenLab？

TokenLab 讓應用程式或編程工具以一把 API 金鑰接入 AI 模型，所有模型共用工作區餘額。選擇模型及其支援的 API 格式，請求按公開價格計費。

## 支援的能力

目前模型 ID、可用性、支援格式和價格以[模型目錄](https://tokenlab.sh/zh-TW/models)為準。

| 能力 | 說明 |
|---|---|
| 聊天與推理 | 文字生成、規劃、工具呼叫 |
| 視覺與多模態 | 圖像理解與多模態對話 |
| 圖像生成與編輯 | 文生圖與圖像編輯 |
| 影片生成 | 文生影片、圖生影片、參考影片與動作控制 |
| 音訊與 Realtime WebSocket | TTS、轉寫、音訊翻譯和即時 WebSocket 會話 |
| 嵌入與 rerank | 文字向量化與重排序 |
| 翻譯 | 文字翻譯和 WebSocket 語音翻譯流程 |
| 音樂與 3D | 音樂和 3D 資產生成 |
| Worlds | World 生成、狀態輪詢和媒體資產流程 |
