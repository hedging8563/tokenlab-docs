## 概覽

Gemini CLI **0.60.0** 已正式記錄 API Key 認證下的 `GOOGLE_GEMINI_BASE_URL`。使用 TokenLab 的 Gemini 原生端點，並選擇支援 `gemini_generate_content` 的目前模型。請參閱[官方設定參考](https://geminicli.com/docs/reference/configuration/)和[認證指南](https://geminicli.com/docs/get-started/authentication/)。此設定不會將 Google 訂閱轉接至 TokenLab。

## 安裝

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## 設定

依[快速開始](/zh-Hant/quickstart)的 macOS、Linux、WSL 或 Windows PowerShell 步驟設定 `TOKENLAB_API_KEY`，避免把金鑰寫入命令歷史，再從同一終端機啟動 Gemini CLI。長期使用請透過本地秘密管理工具提供金鑰，不要把明文金鑰附加至 shell 設定檔。

保留原 Google 登入與設定。為 TokenLab 選擇尚未使用的設定根目錄，例如 `~/.gemini-tokenlab`（PowerShell 中使用 `$HOME`），並在其中建立 `.gemini`。將既有 `.gemini/settings.json` 及所需政策檔複製到對應位置，保留權限、沙箱和無關設定；只在副本中合併以下認證欄位，沒有設定檔時才新增。不要複製 OAuth 快取或清除原憑證；遵守既有管理認證政策。

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## 使用方式

下列啟動指令使用 `~/.gemini-tokenlab/.gemini/settings.json`；選擇其他根目錄時請同步調整。透過 Gemini 正常的信任提示確認工作目錄，保留原工具核准政策。本工作階段明確指定模型。

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

這些變數只用於本次啟動，保留已儲存的帳戶、預設模型與權限。正常啟動時不加這些變數，即可繼續使用原設定；不要將它們寫入 shell 設定檔。
