## 概覽

本頁適用於提供 **Settings → LLM → Advanced** 的 LiteLLM 版 OpenHands 介面。選擇 **OpenAI**，填入帶 `openai/` 前綴的自訂模型，在本機 API Key 欄位輸入 TokenLab 金鑰，並設定下列 Base URL。先記錄原模型選擇，完成後可還原，保留既有帳戶與工具權限。請參閱[官方 OpenAI 相容設定](https://docs.openhands.dev/openhands/usage/llms/openai-llms)。CLI、雲端和原始碼安裝的設定流程可能不同，應遵循所裝版本的指南；`make setup-config` 不是通用的已安裝 CLI 指令。

## 模型設定

編輯前先在本機儲存目前供應商、模型與連線設定。這些介面選項會改變目前模型選擇，使用結束後還原原值。保留已登入帳戶與工具權限；未保留可還原備份時，不要覆寫既有的其他 OpenAI 相容連線。

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

儲存設定或列出模型不能證明金鑰有效或請求完成。傳送提示詞會使用 TokenLab 餘額；先核對回覆及對應[請求記錄](https://tokenlab.sh/dashboard/runs?section=requests)，再嘗試工具，輔助請求也可能計費。

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
