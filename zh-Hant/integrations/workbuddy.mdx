## 交給我的 Agent 設定

把這段任務交給電腦上已經可用的 Agent：

```text
閱讀此教學，協助我將 WorkBuddy 連接至 TokenLab：
https://docs.tokenlab.sh/zh-Hant/integrations/workbuddy
先檢查已安裝版本與目前生效的設定。
保留既有帳戶、供應商、權限及其他設定。
備份本機檔案並展示預計修改的內容。
讓我在本機輸入所需的 API 金鑰；不要在聊天中索取、顯示或貼上金鑰。
先確認設定能正常載入。
執行任何付費請求測試前，請另行說明費用。
```

## 概覽

<Note>
**類型**：桌面程式與任務代理

**主要路徑**：OpenAI 相容 Chat Completions

**支援級別**：官方自訂模型路徑
</Note>

[WorkBuddy](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model) 提供視覺化的 OpenAI 相容自訂模型編輯器，不必手動編輯本機模型檔案。

## 設定 TokenLab

開啟 **設定 → 模型**，新增模型並選擇 **自訂 / Custom**：

| 欄位 | 值 |
|---|---|
| 介面位址 | `https://api.tokenlab.sh/v1` |
| API Key | 你的 TokenLab API Key |
| 模型名稱 | `kimi-k3` |
| 自訂協議 | **關閉** |

<Warning>
請保持「自訂協議」關閉。標準模式會驗證 Base URL 並自動補上 `/chat/completions`；若開啟後只填 `/v1`，請求會送到錯誤路徑。
</Warning>

## 進階設定

工具、圖片、思考開關及上下文/輸出上限應依所選模型的目前 TokenLab 詳情設定。不要一律開啟圖片與思考，也不要複製其他模型的 1M/128K 上限。請使用 TokenLab 顯示的模型 ID。

儲存及選取模型只確認本機設定。文字或工具任務會使用 TokenLab 餘額；請核對回覆與[請求記錄](https://tokenlab.sh/dashboard/runs?section=requests)。還原時選回原模型，僅移除新增的 TokenLab 項目。


官方桌面應用支援 macOS 和 Windows。請使用[官方模型編輯器](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model)；本教程不假定有 Linux 版本或可直接寫入的檔案格式。

MCP 與 Skills 各有安裝路徑：[API 工具](/zh-Hant/integrations/tokenlab-mcp-server)與[接入指引](/zh-Hant/integrations/coding-agent-skill)，不會切換主模型。
