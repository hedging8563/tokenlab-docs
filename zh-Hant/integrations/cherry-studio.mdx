## 概覽

Cherry Studio 可以透過自訂的 OpenAI 相容提供者使用 TokenLab。如果您的 Cherry Studio 版本在提供者註冊表中包含 TokenLab，請直接選擇 TokenLab。

<Note>
**類型**: 聊天應用程式

**主要路徑**: OpenAI 相容聊天補全 (Chat Completions)

**原生路徑**: Responses、Anthropic Messages、用戶端公開的 Gemini 相容端點
</Note>

## 設定為自訂提供者

1. 開啟 **Settings** -> **Model Provider**
2. 新增一個 OpenAI 相容的提供者
3. 輸入：
   - **Name**: TokenLab
   - **API Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. 新增一個模型，例如 `gpt-5.4-mini`
5. 在設定對話框中完成 **Verify and Enable**。若手動設定，請儲存並確認提供者已啟用。
6. 選擇已新增的模型，發送一則簡短的測試訊息。

## 提供者註冊表路徑

當 TokenLab 作為內建提供者出現在 Cherry Studio 中時，請優先選擇該選項。它可以攜帶以下項目的端點元數據：

- OpenAI 相容聊天補全
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## 推薦入門模型

使用 `gpt-5.4-mini` 作為預設模型，然後新增 `claude-sonnet-5`、`gemini-3.5-flash` 和 `deepseek-v4-flash` 以獲得更廣泛的支援。
