## 概覽

Flowise 可以透過 TokenLab 聊天節點（若可用）或指向 TokenLab 的 OpenAI 相容聊天模型節點來呼叫 TokenLab。

<Note>
**類型**: 工作流程建構器 (Workflow Builder)

**主要路徑**: OpenAI 相容聊天補全 (OpenAI-compatible chat completions)

**支援信心**: 在範圍限制內支援
</Note>

## TokenLab 節點

如果您的 Flowise 建構包含 **TokenLab** 聊天模型節點：

1. 新增 **Chat Models** -> **TokenLab**
2. 建立 TokenLab API 憑證
3. 將 **Model Name** 設定為 `gpt-5.4-mini`
4. 將其連接到您的鏈 (chain)、代理 (agent) 或工作流程
5. 執行測試提示詞 (test prompt)。

## OpenAI 相容後備方案

如果您的版本未包含 TokenLab 節點，請新增 **Chat Models** → **OpenAI Custom Model**。在 **Connect Credential** 中使用 TokenLab 金鑰建立 **OpenAI API** 憑證，再依下表設定 **Model Name** 和 **Additional Parameters** → **Base Path**：

| 欄位 | 值 |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

將節點連接至鏈、代理或工作流程，再發送一則測試提示詞。

## 推薦模型

- `gpt-5.4-mini`：適用於大多數工作流程測試
- `claude-sonnet-5`：適用於更強大的寫作與推理需求
- `gemini-3.5-flash`：適用於快速且支援多模態的工作流程
- `deepseek-v4-flash`：適用於快速程式碼編寫或推理迭代
