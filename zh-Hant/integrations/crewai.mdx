## 概覽

CrewAI 透過在環境變數或 `LLM` 類別中設定模型、API key 和 base URL，來支援與 OpenAI 相容的 LLM。

<Note>
**類型**: Agent 框架

**主要路徑**: OpenAI 相容的聊天補全 (Chat Completions)

**支援信心**: 支援自訂端點路徑
</Note>

## 環境變數

```python
import os

os.environ["OPENAI_API_KEY"] = "sk-your-tokenlab-key"
os.environ["OPENAI_API_BASE"] = "https://api.tokenlab.sh/v1"
os.environ["OPENAI_MODEL_NAME"] = "openai/claude-sonnet-5"
```

## LLM 類別

```python
from crewai import Agent, LLM

llm = LLM(
    model="claude-sonnet-5",
    custom_openai=True,
    base_url="https://api.tokenlab.sh/v1",
    api_key="sk-your-tokenlab-key",
)

agent = Agent(
    role="Research analyst",
    goal="Summarize technical tradeoffs clearly",
    backstory="You produce concise implementation notes.",
    llm=llm,
)
```

## 模型建議

對於常規的 crew，請使用 `gpt-5.4-mini`；對於需要大量規劃的 agent，請使用 `claude-sonnet-5` 或 `gpt-5.4`；若需要更快速且低成本的迭代，則建議使用 `deepseek-v4-flash`。

## 端點注意事項

CrewAI 的 OpenAI 相容路徑最適合用於 Chat Completions 風格的 agent 呼叫。僅在您選擇的工具或 SDK 能夠支援這些原生協定時，才直接使用 TokenLab 原生端點。
