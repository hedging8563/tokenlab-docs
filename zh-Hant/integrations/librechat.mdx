## 概覽

LibreChat 可透過自訂的 OpenAI 相容端點與 TokenLab 良好運作。

<Note>
**類型**: 聊天應用程式 (Chat App)

**主要路徑**: OpenAI 相容聊天補全 (Chat completions)

**支援信心**: 支援的路徑
</Note>

## 環境變數

在 LibreChat 專案根目錄的 `.env` 檔案中加入：

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## 端點範例

如果 LibreChat 專案根目錄尚無 `librechat.yaml`，先從 `librechat.example.yaml` 複製。保留必要的 `version` 與既有設定，將以下項目合併到 `endpoints.custom`：

```yaml
endpoints:
  custom:
    - name: 'TokenLab'
      apiKey: '${TOKENLAB_API_KEY}'
      baseURL: 'https://api.tokenlab.sh/v1'
      models:
        default:
          - 'gpt-5.5'
          - 'gpt-5.6-terra'
          - 'gpt-5.6-luna'
          - 'claude-opus-4-8'
          - 'claude-sonnet-5'
          - 'gemini-3.5-flash'
          - 'deepseek-v4-pro'
          - 'deepseek-v4-flash'
        fetch: true
      titleConvo: true
      titleModel: 'gpt-5.6-luna'
      modelDisplayLabel: 'TokenLab'
```

使用 Docker 時，將該檔案掛載到 API 容器的 `/app/librechat.yaml`。重新啟動同一個 LibreChat 實例，然後選擇 TokenLab。詳見 [LibreChat 設定指南](https://www.librechat.ai/docs/configuration/librechat_yaml)。

## 注意事項

LibreChat 在此設定中使用 OpenAI 相容的聊天路徑。TokenLab 同時也為支援這些請求格式的客戶端提供了原生的 Responses、Anthropic Messages 以及 Gemini 相容端點。
