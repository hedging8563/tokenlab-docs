## 概覽

Opik 可以透過封裝指向 TokenLab OpenAI 相容端點的 OpenAI 客戶端來記錄 TokenLab 的呼叫。

<Note>
**類型**: 可觀測性 (Observability)

**主要路徑**: OpenAI SDK 追蹤封裝器

**支援信心**: 支援 OpenAI 相容的追蹤路徑
</Note>

## 安裝

```bash
pip install opik openai
```

## 環境變數

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export OPIK_PROJECT_NAME="tokenlab-integration-demo"
```

## 封裝 OpenAI 客戶端

執行範例前請先設定 Opik：Opik Cloud 需要 `OPIK_API_KEY`，並可視需要指定 `OPIK_WORKSPACE`。既有自架部署則需將 `OPIK_URL_OVERRIDE` 設為其 API 位址，例如 `http://localhost:5173/api`。參見 [Opik 設定指南](https://www.comet.com/docs/opik/tracing/advanced/sdk_configuration)。

```python
import os

from openai import OpenAI
from opik.integrations.openai import track_openai

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

openai_client = track_openai(client)
```

## 記錄聊天完成 (Chat Completion)

```python
completion = openai_client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[
        {"role": "user", "content": "Summarize why LLM observability matters."}
    ],
)

print(completion.choices[0].message.content)
```

## 端點注意事項

此設定會追蹤 OpenAI 相容的 SDK 路徑。如果您在 OpenAI SDK 之外使用 TokenLab 原生端點，請另外對該客戶端或工作流程進行檢測 (instrument)。
