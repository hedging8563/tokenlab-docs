## 概覽

Prompt flow 的 OpenAI 連線支援自訂 `base_url`。請將其設定為 TokenLab 的 `/v1` 端點，並在您的 flow 中使用 TokenLab 模型 ID。

<Note>
**類型**: Flow 建構與評估平台

**主要路徑**: 相容於 OpenAI 的 Chat Completions

**支援信心**: 支援相容於 OpenAI 的路徑
</Note>

## 安裝

```bash
pip install promptflow promptflow-tools
```

## 建立連線

將下方連線儲存為 `openai.yaml`。指令會在本機提示輸入 API key。在 OpenAI 流程節點中，將 TokenLab 模型 ID 填入 `inputs.model`；`deployment_name` 用於 Azure OpenAI。

```yaml
$schema: https://azuremlschemas.azureedge.net/promptflow/latest/OpenAIConnection.schema.json
name: open_ai_connection
type: open_ai
base_url: https://api.tokenlab.sh/v1
api_key: "<user-input>"
```

```bash
pf connection create --file openai.yaml
```

## Flow 注意事項

在您的 `flow.dag.yaml` 中，請確保連線名稱與上述指令一致：

```yaml
nodes:
  - name: chat
    type: llm
    source:
      type: code
      path: chat.jinja2
    inputs:
      model: claude-sonnet-5
    api: chat
    connection: open_ai_connection
```


## 端點注意事項

此整合使用 Prompt flow 的 OpenAI 相容連線。若要使用原生 TokenLab 回應、Anthropic Messages 以及 Gemini 路由，則需要使用 Prompt flow 工具或直接呼叫這些端點的自訂 Python 節點。
