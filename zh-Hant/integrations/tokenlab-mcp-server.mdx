## 選擇需要的能力

- MCP 為相容客戶端新增 TokenLab API 工具，可從下方免金鑰的 `catalog` 設定開始。
- [TokenLab Skill](/zh-Hant/integrations/coding-agent-skill) 透過 `npx skills add` 安裝接入指引，不會啟動 MCP 服務。

兩者均擴充既有 Agent。切換主模型供應商時，請參閱相應客戶端教程。

## 交給我的 Agent 設定

把這段任務交給電腦上已經可用的 Agent：

```text
閱讀此教學，依照我的任務選擇 MCP 目錄工具或 TokenLab Skill：
https://docs.tokenlab.sh/zh-Hant/integrations/tokenlab-mcp-server
先檢查已安裝版本與目前生效的設定。
保留既有帳戶、供應商、權限及其他設定。
備份本機檔案並展示預計修改的內容。
讓我在本機輸入所需的 API 金鑰；不要在聊天中索取、顯示或貼上金鑰。
先確認設定能正常載入。
執行任何付費請求測試前，請另行說明費用。
```

[TokenLab MCP server](https://github.com/hedging8563/tokenlab-mcp-server) 從 TokenLab 的公開 OpenAPI 合約中生成 MCP 工具。支援 MCP 的代理程式 (Agents) 可以探索模型與定價、呼叫 OpenAI 相容及原生 LLM 端點、建立多模態媒體、上傳檔案以及管理非同步任務。

當代理程式需要最新的 TokenLab API 合約而非手動維護的工具列表時，請使用此伺服器。預設的 `core` 設定檔會公開 29 個生成的端點工具以及兩個複合式探索工具。`full` 設定檔則會公開 78 個生成的端點工具以及相同的兩個複合式工具。

本頁用於在 Claude Code、Cursor、VS Code、Codex、Claude Desktop、Cline、Windsurf 或其他 MCP 客戶端中加入 TokenLab 工具伺服器。如果你要在應用程式碼中直接呼叫 TokenLab，請從 [API 快速入門](/zh-Hant/quickstart) 開始。

<Note>
公開目錄與定價工具不需要 TokenLab API key。若要進行憑證授權的推論 (Inference)、媒體、音訊、檔案、任務、嵌入 (Embedding)、重排序 (Rerank) 及翻譯操作，請設定 `TOKENLAB_API_KEY`。切勿將 API key 放入工具參數中。
</Note>

## 它提供了什麼

- 從 `https://api.tokenlab.sh/v1/models` 進行即時模型探索。
- 從 `/v1/models/{model}` 查詢模型詳細資訊。
- 從 `/v1/models/{model}/pricing` 查詢定價。
- 從 `https://api.tokenlab.sh/llms.txt` 獲取代理程式可讀的 API 概覽。
- OpenAI 相容的 Chat Completions 與 Responses、Anthropic Messages 以及 Gemini generateContent，且無需扁平化其原生請求格式。
- 透過 JSON URL、TokenLab 檔案 ID 或本地 multipart 檔案進行圖像生成與編輯。
- 支援影片、音樂、3D、語音、轉錄、音訊翻譯、嵌入、多模態嵌入、重排序及文字翻譯。
- 針對圖像、影片、音樂、3D 及世界生成操作的標準化非同步任務摘要。
- 每日合約同步：獲取公開 OpenAPI 文件、重新生成工具架構、執行端點與檔案測試，並僅在所有檢查通過時更新 `main` 分支。

## 設定參考

任何支援本機 stdio MCP 伺服器的客戶端都使用以下值：伺服器名稱 `tokenlab`、命令 `npx`、參數 `-y` 和 `@tokenlabai/mcp-server@0.6.22`，工作目錄留空。若要固定目前已驗證版本，請使用 `@tokenlabai/mcp-server@0.6.22`。

需要憑證的工具可使用以下標準設定：

```json
{
  "mcpServers": {
    "tokenlab": {
      "command": "npx",
      "args": ["-y", "@tokenlabai/mcp-server@0.6.22"],
      "env": {
        "TOKENLAB_API_KEY": "<TOKENLAB_API_KEY>",
        "TOKENLAB_MCP_TOOL_PROFILE": "core"
      }
    }
  }
}
```

VS Code 使用頂層 `servers` 物件；其他要求單一伺服器物件的客戶端只需複製包含 `command`、`args` 和 `env` 的內層物件。

| 環境變數 | 預設值 | 用途 |
|---|---|---|
| `TOKENLAB_API_BASE` | `https://api.tokenlab.sh` | 覆寫 API Base URL；末尾不要加斜線。 |
| `TOKENLAB_API_KEY` | 未設定 | 需要憑證的推論、媒體、檔案、任務、嵌入、重新排序和翻譯呼叫必須設定。 |
| `TOKENLAB_MCP_TOOL_PROFILE` | `core` | 選擇 `catalog`、`core` 或 `full`。 |
| `TOKENLAB_MCP_SCHEMA_MODE` | 設定檔預設值 | 選擇 `portable`、`exact` 或 `strict`；一般保留 `portable`。 |
| `TOKENLAB_REQUEST_TIMEOUT_MS` | `120000` | API 請求逾時，單位為毫秒。 |
| `TOKENLAB_MCP_MAX_FILE_BYTES` | `104857600` | 每個本機上傳檔案的最大位元組數。 |
| `TOKENLAB_MCP_INLINE_BYTES` | `2097152` | 內嵌回傳二進位或 JSON 結果的最大位元組數。 |
| `TOKENLAB_ARTIFACT_DIR` | 作業系統暫存目錄 | 較大回應產物的寫入位置。 |

<Warning>
不要發布含有真實 API Key 的截圖、日誌、Shell 歷史或設定檔。優先使用客戶端的秘密輸入或環境變數功能；共用範例一律使用預留位置；Key 暴露後應立即輪換。
</Warning>

## 從原始碼安裝

只有在稽核或開發 MCP 伺服器時才使用原始碼檢出。一般客戶端設定應使用上方已發布的 npm 套件。

```bash
git clone https://github.com/hedging8563/tokenlab-mcp-server.git
cd tokenlab-mcp-server
npm install
npm test
npm start
```

`core` 和 `full` 預設發布有大小與深度界線的 `portable` 工具 Schema，而伺服器仍會按完整 OpenAPI 合約驗證每次呼叫。如需完整巢狀 Schema，請設定 `TOKENLAB_MCP_SCHEMA_MODE=exact`；若模型提供方要求封閉物件且每個屬性都列入 `required`，請使用 `strict`。

## 生成的工具設定檔

| 設定檔 | 公開工具數量 | 覆蓋範圍 |
|---|---:|---|
| `catalog` | 6 | 4 個生成的公開目錄與定價工具，加上 `compare_models` 與 `get_api_overview`。不需要 API Key。 |
| `core` (預設) | 31 | 29 個生成的端點工具加上 `compare_models` 與 `get_api_overview`。涵蓋目錄、定價、原生 LLM 端點、圖像、影片、音樂、3D、音訊、任務、檔案、嵌入、重排序及翻譯。 |
| `full` | 80 | 78 個生成的端點工具加上兩個複合式探索工具。增加回應生命週期、批次處理、世界生成、原生模型探索及其他已列入許可清單的開發者操作。 |

工具名稱、說明、輸入架構、HTTP 方法、路徑、內容類型、驗證要求及任務行為均由已簽入的 OpenAPI 快照生成。僅限 MCP 的覆蓋層提供了穩定的工具別名、設定檔成員資格、非同步任務語意、multipart 變體、隱藏機密資訊及非串流限制。

0.6.0 版也會透過 MCP `structuredContent` 回傳 JSON，發佈 3 個契約資源，並提供 2 個用於模型選擇和原生請求建構的提示範本。生成工具和複合工具都帶有標準風險註解，讓相容客戶端能套用更安全的核准策略。

常見的 `core` 工具包括：

| 類別 | 代表性工具 |
|---|---|
| 目錄與定價 | `list_models`, `get_model`, `get_model_pricing`, `get_pricing`, `compare_models` |
| 原生 LLM 端點 | `create_chat_completion`, `create_response`, `create_anthropic_message`, `create_gemini_content` |
| 圖像 | `create_image`, `create_image_file`, `edit_image`, `edit_image_file` |
| 影片、音樂與 3D | `create_video`, `create_music`, `create_3d_model` |
| 音訊 | `create_speech`, `transcribe_audio`, `translate_audio` |
| 嵌入與文字 | `create_embedding`, `create_multimodal_embedding`, `rerank_documents`, `translate_text` |
| 檔案與任務 | `upload_file`, `list_files`, `retrieve_file`, `retrieve_file_content`, `delete_file`, `get_task_status`, `cancel_task` |

MCP 工具呼叫會回傳一個最終結果。不包含僅限串流與即時操作；伺服器會在內部將支援的 `stream` 參數固定為 `false`，不會向 provider 轉接器公開布林常數。小型圖像與音訊回應會回傳原生 MCP 內容；較大的二進位回應會寫入 `TOKENLAB_ARTIFACT_DIR` 並回傳其本地路徑、MIME 類型及位元組計數。

## 非同步媒體結果

影片、音樂及 3D 建立會回傳非同步任務摘要。圖像生成與編輯可能會根據所選模型與請求，回傳已完成的結果或非同步任務。

當 `delivery.mode` 為 `async` 時，請持續呼叫 `get_task_status` 並傳入 `{ "id": delivery.task_id }`，直到 `delivery.terminal` 為 `true`。請根據 `status` 判斷完成狀態；`progress` 為選用欄位，不得作為終止條件。

## 建議的代理程式工作流程

1. 當使用者未指定模型時，呼叫 `list_models`。
2. 針對非聊天任務（如圖像、影片、音樂、3D、TTS、STT、嵌入、重排序或翻譯）使用 `recommended_for`。
3. 在建立非聊天請求、重試失敗請求或切換端點系列之前，呼叫 `get_model`。
4. 當模型成本影響使用者選擇時，呼叫 `get_model_pricing`。
5. 當選擇取決於多個候選項目時，使用 `compare_models`。
6. 呼叫符合所需 API 合約的生成工具，或使用 `get_api_overview` 獲取 TokenLab API 系列的精簡地圖。

|---|---|

| 3D | `/v1/3d/generations` |

| 文字翻譯 | `/v1/translations` |

## 與 TokenLab Skills 搭配使用

MCP 伺服器在執行階段非常有用，而 [TokenLab skills repository](https://github.com/hedging8563/tokenlab-skills) 則教導編碼代理程式如何生成與修復整合程式碼。

在可用時同時使用兩者：

- MCP 伺服器：探索當前模型、定價與端點詳細資訊。
- `tokenlab-api-integration` skill：生成可執行的 API 範例並處理結構化的 TokenLab 錯誤。
- `tokenlab-model-picker` skill：為使用者的任務選擇強大的模型。
- `tokenlab-native-endpoints` skill：決定何時使用 Responses、Anthropic Messages、Gemini、媒體、音訊、嵌入、重排序或翻譯路由。

## 疑難排解

<AccordionGroup>
  <Accordion title="客戶端無法啟動伺服器">
    確認 Node.js 至少為 18.17，且客戶端能找到 `npx`。在終端機執行一次 `npx -y @tokenlabai/mcp-server@0.6.22` 以顯示 npm 或網路錯誤。stdio 成功啟動後會靜默等待 MCP 訊息；確認能啟動後按 **Ctrl+C** 結束。
  </Accordion>

  <Accordion title="伺服器已設定，但沒有顯示工具">
    重新啟動客戶端，並在提示時批准或信任本機伺服器。Claude Code 執行 `claude mcp list` 或開啟 `/mcp`；VS Code 執行 **MCP: List Servers** 後選擇 **Show Output**；Cursor 則在 **Settings → Tools & MCP** 確認伺服器與工具已啟用。
  </Accordion>

  <Accordion title="Claude Code 顯示 Pending approval">
    專案層級的 `.mcp.json` 需要工作區信任與明確批准。請在專案中互動式啟動 Claude Code，接受信任提示，開啟 `/mcp` 並批准 `tokenlab`。若只需對個人帳號私有但跨專案可用，請使用 `--scope user`。
  </Accordion>

  <Accordion title="模型列表為空">
    驗證機器是否能連線至 `https://api.tokenlab.sh/v1/models`。如果您覆寫了 `TOKENLAB_API_BASE`，請確保結尾沒有斜線。
  </Accordion>

  <Accordion title="代理程式仍然選擇過時的模型 ID">
    要求代理程式在硬編碼模型名稱之前呼叫 `list_models` 或 `get_model`。將 MCP 伺服器與 `tokenlab-model-picker` 搭配使用可獲得更好的結果。
  </Accordion>

  <Accordion title="此伺服器可以呼叫付費的 TokenLab 推論 API 嗎？">
    可以。請設定 `TOKENLAB_API_KEY`，然後使用生成的 LLM、媒體、音訊、任務、檔案、嵌入、重排序或翻譯工具。目錄與定價工具無需金鑰即可使用。
  </Accordion>

  <Accordion title="需要憑證的工具回傳驗證錯誤">
    確認 `TOKENLAB_API_KEY` 設定在 MCP 伺服器環境中，而不是工具參數或提示詞裡。修改後重新啟動客戶端；若 Key 曾出現在共用檔案、截圖、日誌或 Shell 歷史中，請先輪換。
  </Accordion>

  <Accordion title="客戶端拒絕工具 Schema 或載入太多工具">
    使用 `TOKENLAB_MCP_TOOL_PROFILE=catalog` 載入 6 個探索工具，或保留預設 `core` 的 31 個工具。預設 `portable` Schema 相容性最廣；完整巢狀 Schema 才使用 `exact`，提供方要求封閉物件與完整 `required` 時使用 `strict`。
  </Accordion>

  <Accordion title="如何固定或更新套件版本？">
    使用 `@tokenlabai/mcp-server@0.6.22` 固定目前已驗證版本。切換版本時更新客戶端設定中的套件參數並重新啟動伺服器；採用更新版本前請先檢視公開儲存庫。
  </Accordion>
</AccordionGroup>
