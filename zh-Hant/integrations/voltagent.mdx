## 概覽

VoltAgent 可直接接收 AI SDK 語言模型。請配置一個與 OpenAI 相容的 AI SDK 提供者，並將 TokenLab 的 `/v1` 基礎 URL 以及所選模型傳遞給您的代理。

<Note>
**類型**: TypeScript 代理框架

**主要路徑**: 透過 AI SDK 進行與 OpenAI 相容的 Chat Completions

**支援信心**: 支援與 OpenAI 相容的路徑
</Note>

## 安裝

```bash
npm install @voltagent/core@2 ai@6 @ai-sdk/openai@3 zod
```

## 環境配置

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 直接使用 AI SDK 提供者

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab.chat("claude-sonnet-5"),
});
```

## 模型路由路徑 (Model Router Path)

如果您的 VoltAgent 註冊表快照包含來自 `models.dev` 的 TokenLab 提供者項目，請進行如下配置：

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

然後使用註冊表模型字串，例如 `tokenlab/claude-sonnet-5`。

## 端點注意事項

直接使用 AI SDK 路徑是最明確的設定方式。僅當您所選的 AI SDK 提供者/客戶端已針對該協定進行配置時，才使用 TokenLab 原生 Responses、Anthropic Messages 或 Gemini 端點。
