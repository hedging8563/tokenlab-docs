## 概覽

大多數通用 AI 聊天應用程式透過標準的 OpenAI 相容聊天路徑連接到 TokenLab。

實際上，這意味著：
- 使用 `https://api.tokenlab.sh/v1` 作為基礎 URL（除非應用程式明確要求完整的端點 URL）
- 使用您的 TokenLab API key 作為 OpenAI 風格的 API key
- 選擇應用程式可以在標準聊天工作流程中使用的模型

<Note>
通用聊天應用程式通常是**以聊天補全 (chat-completions) 為導向**，而非 Codex Responses WebSocket 客戶端。對於需要 Responses 特定行為的 Codex CLI/App、Cursor 或其他程式開發工具，請改用專屬的整合指南。
</Note>

<Note>
**類型**: 聊天應用程式

**主要路徑**: OpenAI 相容聊天補全

**支援信心**: 支援的路徑
</Note>

## 支援的應用程式

| 應用程式 | 平台 | 備註 |
|-------------|----------|-------|
| Open WebUI | 網頁、自架 | 熱門的自架選擇，具備 OpenAI 相容連接功能 |
| LibreChat | 網頁、自架 | 具備自訂 OpenAI 端點的多供應商聊天工作區 |
| LobeChat | 網頁、桌面、自架 | 強大的自訂供應商支援 |
| Cherry Studio | Windows, macOS, Linux | 良好的 OpenAI 相容供應商流程 |
| Chatbox | Windows, macOS, Linux | 簡單的 OpenAI 相容設定 |
| DeepChat | Windows, macOS, Linux | 具備 OpenAI 相容供應商設定的桌面客戶端 |
| Jan | 桌面、自架 | 以本地優先的應用程式，支援遠端 OpenAI 相容供應商 |
| TypingMind | 網頁、桌面 | 使用自訂端點樣式 |
| NextChat | 網頁、自架 | 輕量級 ChatGPT 風格客戶端，支援基礎 URL 覆寫 |
| ChatWise | Windows, macOS | 標準自訂供應商模式 |

## 預設連接值

| 欄位 | 值 |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| API 類型 | OpenAI 相容 |

如果應用程式要求**完整端點 URL** 而非基礎 URL，請使用：
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## 應用程式設定範例

<Tabs>
  <Tab title="LobeChat">
    **自架 LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. 開啟 **Settings** → **AI Service Provider**
    2. 選擇 **OpenAI**
    3. 輸入您的 TokenLab API key
    4. 將自訂端點設定為 `https://api.tokenlab.sh/v1`
  </Tab>

  <Tab title="Cherry Studio">
    1. 開啟 **Settings** → **Model Provider**
    2. 新增一個 **OpenAI-compatible** 供應商
    3. 輸入：
       - **Name**: TokenLab
       - **API Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. 新增您想要使用的模型
  </Tab>

  <Tab title="Chatbox">
    1. 開啟 **Settings** → **AI Model**
    2. 選擇 **OpenAI API Compatible**
    3. 輸入：
       - **API Host**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini` 或 `claude-sonnet-5`
  </Tab>

  <Tab title="TypingMind">
    1. 開啟 **Settings**
    2. 選擇 **Custom Endpoint**
    3. 輸入：
       - **Endpoint URL**: `https://api.tokenlab.sh/v1/chat/completions`
       - **API Key**: `sk-your-tokenlab-key`
    4. 設定您想要公開的模型
  </Tab>

  <Tab title="Open WebUI">
    1. 開啟 **Admin Settings** → **Connections**
    2. 新增一個 **OpenAI-compatible** 連接
    3. 輸入：
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. 儲存並選擇您想要公開的模型
  </Tab>

  <Tab title="DeepChat">
    1. 開啟 **Settings** -> **Model Provider**
    2. 新增一個 OpenAI 相容供應商
    3. 輸入：
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini`
    4. 儲存並執行測試聊天
  </Tab>

  <Tab title="Jan">
    1. 開啟 **Settings** -> **Providers**
    2. 新增一個遠端 OpenAI 相容供應商
    3. 輸入：
       - **Provider name**: TokenLab
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. 選擇 `gpt-5.4-mini` 或其他 TokenLab 模型
  </Tab>

  <Tab title="LibreChat">
    在您的 LibreChat 供應商設定中新增一個 OpenAI 相容端點，並指向：

    ```yaml
    customEndpoints:
      - name: TokenLab
        apiKey: '${OPENAI_API_KEY}'
        baseURL: 'https://api.tokenlab.sh/v1'
        models:
          default: ['gpt-5.4-mini', 'gpt-5.4', 'claude-sonnet-5']
          fetch: false
    ```
  </Tab>
</Tabs>

## 更安全的模型預設值

| 類別 | 建議模型 |
|----------|------------------|
| 一般預設 | `gpt-5.4-mini`, `gpt-5.4`, `gpt-5.5` |
| Anthropic | `claude-sonnet-5`, `claude-opus-4-8`, `claude-fable-5` |
| Google | `gemini-3.5-flash`, `gemini-3.1-flash-lite` |
| DeepSeek | `deepseek-v4-flash`, `deepseek-v4-pro` |

## 提示

<AccordionGroup>
  <Accordion title="當應用程式支援時，優先使用基礎 URL">
    當您提供 `https://api.tokenlab.sh/v1` 作為基礎 URL 而非完整端點 URL 時，大多數應用程式更容易設定且較不容易出錯。
  </Accordion>

  <Accordion title="優先使用較小的模型">
    日常聊天請先從 `gpt-5.4-mini` 或 `deepseek-v4-flash` 開始，然後再將更繁重的推理任務轉移到 `gpt-5.4` 或 `claude-opus-4-8`。
  </Accordion>

  <Accordion title="將程式開發工具分開">
    通用聊天應用程式與程式開發代理 (coding agents) 通常需要不同的端點行為。請將 Codex/Cursor 風格的工具保留在其專屬的整合頁面上。
  </Accordion>
</AccordionGroup>

## 疑難排解

<AccordionGroup>
  <Accordion title="連接錯誤">
    - 確認基礎 URL 完全為 `https://api.tokenlab.sh/v1`
    - 如果應用程式會自動附加路徑，請移除結尾的斜線
    - 如果應用程式要求完整端點 URL，請使用 `https://api.tokenlab.sh/v1/chat/completions`
  </Accordion>

  <Accordion title="401 未經授權">
    - 再次檢查您的 API key
    - 確認該 key 在 TokenLab 儀表板中處於啟用狀態
    - 確保沒有多餘的空格或換行符
  </Accordion>

  <Accordion title="模型無法使用">
    - 確認模型名稱是否完全正確
    - 嘗試使用廣泛支援的預設模型，例如 `gpt-5.4-mini`、`deepseek-v4-flash` 或 `claude-sonnet-5`
    - 在 TokenLab 文件或儀表板中檢查目前的可用性
  </Accordion>
</AccordionGroup>
