## 概覽



<Note>
**類型**: 程式工具

**主要路徑**: OpenAI 相容

**支援級別**: 支援路徑
</Note>

OpenCode 是一個在終端機中執行的開源 AI 程式設計助理。它支援多種 LLM 供應商，並可設定為使用 TokenLab 的 API，以存取數百個模型。

## 安裝

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

驗證安裝：

```bash
opencode --version
```

## 設定

### 步驟 1：設定環境變數

依[快速開始](/zh-Hant/quickstart)的 macOS、Linux、WSL 或 Windows PowerShell 步驟設定 `TOKENLAB_API_KEY`，避免把金鑰寫入命令歷史，再從同一終端機啟動 OpenCode。長期使用請透過本地秘密管理工具提供金鑰，不要把明文金鑰附加至 shell 設定檔。

### 步驟 2：設定 OpenCode

以下設定已在 **OpenCode 1.18.31** 驗證；其他版本須依其官方文件另行確認。

將以下設定儲存為獨立的 `~/.config/opencode/tokenlab.jsonc`；若已設定 `XDG_CONFIG_HOME`，則使用該目錄下的 `opencode/tokenlab.jsonc`。保留一般的 `opencode.json` / `opencode.jsonc`、帳戶、預設模型與權限；只有本次啟動以 `OPENCODE_CONFIG` 選取此檔案時才會載入。若檔案或供應商名稱已用於其他設定，請另選檔案或名稱並同步修改啟動指令。

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
此處使用 `@ai-sdk/openai-compatible` 傳送 Chat Completions。請依目前模型詳情確認 Chat Completions 與所需工具支援；此範例無法證明其他協定或版本相容。
</Note>

可選：使用[可還原的 OpenCode 設定工具](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md)，透過 Python 3.11+ 預覽、套用並還原原始檔案。TokenLab Skills 外掛 **0.1.2** 已包含新腳本；獨立安裝的 Skill 更新至包含這些腳本的版本後也可使用。已安裝外掛或獨立 Skill 的使用者請依 [README 更新說明](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation)更新，並確認腳本已安裝。也可直接完成本頁的手動設定。

## 基本用法

依快速開始設定金鑰後，僅為本次啟動載入此檔案並明確選取模型。使用自訂路徑或供應商名稱時請相應替換。若已有 `OPENCODE_CONFIG` 或內嵌 `OPENCODE_CONFIG_CONTENT` 設定，請保留原設定並使用獨立啟動環境；專案及受管理設定仍可能優先。

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

模型清單只能確認本機載入，不能證明金鑰有效或線上請求成功。傳送提示詞會使用 TokenLab 餘額，OpenCode 也可能發出標題生成等個別計費的輔助請求。請核對回覆及對應的[請求記錄](https://tokenlab.sh/dashboard/runs?section=requests)。

不載入此檔案即可使用原設定啟動。請勿為本教學將 `OPENCODE_CONFIG` 寫入 shell 設定檔。撤銷手動設定時，只刪除本次建立的獨立檔案；若檔案原本已存在，則還原其備份。

## 可用模型

| 模型 | 最適合用途 |
|-------|----------|
| `gpt-5.6-terra` | 複雜任務、程式碼架構 |
| `gpt-5.6-luna` | 快速修正、簡單查詢 |
| `claude-sonnet-4-6` | 程式碼審查、文件撰寫 |
| `claude-opus-4-6` | 複雜推理 |
| `gemini-3.5-flash` | 快速回應 |

## 常用指令

**分析程式碼：**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**產生程式碼：**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**檢查變更：**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**修正錯誤：**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## 疑難排解

<AccordionGroup>
  <Accordion title="連線錯誤">
    - 確認 `options.baseURL` 已設為 `https://api.tokenlab.sh/v1`
    - 檢查網路連線
    - 嘗試 `curl https://api.tokenlab.sh/v1/models` 進行測試
  </Accordion>

  <Accordion title="驗證失敗">
    - 確認已設定 `TOKENLAB_API_KEY` 環境變數
    - 確認 `options.apiKey` 參照的是 `{env:TOKENLAB_API_KEY}` 或其他有效的 secret 來源
    - 檢查 key 是否以 `sk-` 開頭
    - 確保該 key 已在 TokenLab dashboard 中啟用
  </Accordion>

  <Accordion title="找不到模型">
    - 檢查設定中的模型名稱是否完全一致
    - 在 [tokenlab.sh/en/models](https://tokenlab.sh/zh-TW/models) 確認模型是否可用
  </Accordion>
</AccordionGroup>
