## 概覽

Mem0 OSS 可以透過其 OpenAI 相容的 LLM 設定來使用 TokenLab，只需將 `provider` 設定為 `"openai"` 並設定 `openai_base_url` 即可。

<Note>
**類型**: 記憶體框架 (Memory Framework)

**主要路徑**: OpenAI 相容的 LLM 設定

**支援信心**: 支援自訂端點路徑
</Note>

## 安裝

```bash
pip install mem0ai
```

## 環境變數

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## Python 設定

```python
import os

from mem0 import Memory

config = {
    "llm": {
        "provider": "openai",
        "config": {
            "model": "claude-sonnet-5",
            "api_key": os.environ["TOKENLAB_API_KEY"],
            "openai_base_url": "https://api.tokenlab.sh/v1",
            "temperature": 0.1,
        },
    },
    "embedder": {
        "provider": "openai",
        "config": {
            "model": "text-embedding-3-small",
            "api_key": os.environ["TOKENLAB_API_KEY"],
            "openai_base_url": "https://api.tokenlab.sh/v1",
        },
    },
    "vector_store": {
        "provider": "qdrant",
        "config": {"path": "./mem0-qdrant"},
    },
}

memory = Memory.from_config(config)
```

## 基本用法

```python
memory.add("The user prefers concise engineering summaries.", user_id="demo")
results = memory.search("How should I answer?", filters={"user_id": "demo"})
print(results)
```

## 端點注意事項

此設定涵蓋了 Mem0 的 OpenAI 相容 LLM 路徑。請根據您使用的向量資料庫 (vector store) 和嵌入模型 (embedding model) 分別設定嵌入器 (embedders)。
