## 概覽

DeepChat 可透過標準的 OpenAI 相容提供者配置與 TokenLab 協作。

<Note>
**類型**: 聊天應用程式

**主要路徑**: OpenAI 相容的聊天補全 (chat completions)

**支援信心**: 支援的路徑
</Note>

## 配置 DeepChat

1. 開啟 **Settings** -> **Model Provider**
2. 新增或編輯一個 OpenAI 相容的提供者
3. 輸入以下資訊：
   - **Provider name**: TokenLab
   - **API Type**: **OpenAI Completions** (Chat Completions)
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. 新增一個模型，例如 `gpt-5.4-mini`
5. 儲存並測試聊天功能。

## 模型選擇

建議從 `gpt-5.4-mini` 開始，作為低門檻的預設選擇。當對話需要更強的推理能力時，請使用 `claude-sonnet-5`、`gpt-5.4` 或 `deepseek-v4-pro`。

## 疑難排解

- 請使用 base URL，而非完整的 `/chat/completions` 路徑，除非 DeepChat 明確要求輸入完整的端點 URL。
- 請移除 API key 中的尾隨空格。
- 若模型未列出，請手動輸入正確的 TokenLab 模型 ID。
