## 適用範圍

本頁適用於 macOS、Windows、Linux 的 **Cursor 桌面編輯器**。OpenAI BYOK 的官方範圍是標準、非推理聊天模型；Tab 補全仍使用 Cursor 模型。修改 OpenAI Base URL 不代表所有 TokenLab 模型或 Cursor 功能都能使用。詳見 [Cursor API Key 限制](https://cursor.com/help/models-and-usage/api-keys)。

只需要圖像、影片等 API 工具時，可保留目前聊天供應商，另外加入 [MCP](/zh-Hant/integrations/tokenlab-mcp-server)。[Skill](/zh-Hant/integrations/coding-agent-skill) 提供操作說明，不會切換主模型。

## 把任務交給現有 Agent

```text
閱讀 https://docs.tokenlab.sh/zh-Hant/integrations/cursor，核對已安裝版本與作業系統。
確認我要使用 TokenLab 主模型、MCP 工具還是 API Skill。
保留既有帳戶、供應商設定和權限，說明改動後如何還原。
不要在聊天中索取或填寫 API key；我會在本機填入並完成必要的介面操作。
先說明一次小驗證的費用，只有我明確選擇該測試後，才協助執行並核對 TokenLab 請求記錄。
```

## 開啟正確的設定

1. 從 [Cursor 下載頁](https://cursor.com/downloads)安裝或更新桌面版；本頁不設定 CLI 或 Cloud Agents。
2. 從命令面板開啟 **Cursor Settings**，或按 `Cmd/Ctrl + Shift + J`。`Cmd/Ctrl + ,` 是編輯器通用設定。
3. 進入 **Models**，記下既有 OpenAI key 與 Base URL 設定以便還原，保留其他供應商。
4. 在 **OpenAI API Key** 中本機填入並儲存 TokenLab key；不要傳到聊天或提交至 git。
5. 啟用 **Override OpenAI Base URL**，填入：

```text
https://api.tokenlab.sh/v1
```

BYOK 請求仍經過 Cursor 伺服器組裝提示詞，並非編輯器直接連至 TokenLab。

## 選擇模型

從目前 [TokenLab 模型目錄](https://tokenlab.sh/zh-TW/models)複製精確 ID，再確認 Cursor 的 OpenAI BYOK 路徑接受該模型。TokenLab 的 chat 分類不代表 Cursor 相容性。

首次文字測試可用仍在目錄中的 `gpt-4.1-mini` 作為非推理模型範例。在 **Models** 啟用既有項目；沒有時才用 **Add model**，然後在聊天選擇器選中它。不要用不同拼寫重複加入內建模型，也不要假設 Claude 或 Gemini 會經過 OpenAI override。參見 [Cursor 自訂模型說明](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488)。

## 驗證一次小請求

使用所選模型建立新聊天，傳送：

```text
只回覆 TOKENLAB_CONNECTION_OK。不要使用工具，也不要修改檔案。
```

這次請求會計費。檢查回覆，並到 [TokenLab 請求記錄](https://tokenlab.sh/dashboard/runs?section=requests)核對模型、時間與狀態。只看到模型列表或收到回覆，沒有對應記錄，不能確認已接通。

## 疑難排解

- **模型缺失或被拒絕：**核對 ID 及 Cursor 的 BYOK 支援範圍；優先使用既有內建項目。重啟無法解決不相容。
- **鑑權錯誤：**核對 OpenAI 欄位的 TokenLab key 和 Base URL；餘額或額度不足與無效 key 是不同問題。
- **沒有 TokenLab 記錄：**核對聊天模型與 override，再看 Cursor 錯誤。Tab 補全不能驗證這條連線。
- **其他供應商失效：**還原原有 OpenAI 設定或關閉 override，再建立新聊天。

## 另外加入 MCP 與 Skills

[MCP](/zh-Hant/integrations/tokenlab-mcp-server) 增加可呼叫工具，透過 Cursor MCP 設定或 `.cursor/mcp.json` 配置。先確認工具發現，再按需執行計費生成；MCP 不會替換主模型。

[Skills](/zh-Hant/integrations/coding-agent-skill) 是 API 使用說明。把完整目錄放到 `.cursor/skills/tokenlab-api-integration/`，保留 `SKILL.md` 與引用檔案，在 **Customize → Skills** 檢查發現。Skill 不提供 key，也不安裝 MCP server。入口以官方 [MCP](https://cursor.com/docs/mcp) 和 [Skills](https://cursor.com/docs/skills) 文件為準。
