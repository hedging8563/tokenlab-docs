## 概覽



<Note>
**類型**: 程式工具

**主要路徑**: Anthropic-native

**支援級別**: 強原生路徑
</Note>

[Claude Code](https://code.claude.com/docs/en/setup) 是 Anthropic 官方提供的 CLI 工具，用於 AI 輔助程式設計。您可以將其設定為使用 TokenLab 作為 API provider。

## 安裝

Anthropic 現在建議使用原生安裝程式。npm 安裝方式仍然存在以維持相容性，但在上游已被棄用。

<CodeGroup>
```bash macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell Windows
irm https://claude.ai/install.ps1 | iex
```
</CodeGroup>

如果您明確需要 npm 套件，請使用：

```bash
npm install -g @anthropic-ai/claude-code@2.1.263
```

<Warning>
請勿對 Claude Code 使用 `sudo npm install -g`。
</Warning>

## 設定

依[快速開始](/zh-Hant/quickstart)的 macOS、Linux、WSL 或 Windows PowerShell 步驟設定 `TOKENLAB_API_KEY`，避免把金鑰寫入命令歷史，再從同一終端機啟動 Claude Code。長期使用請透過本地秘密管理工具提供金鑰，不要把明文金鑰附加至 shell 設定檔。

這些變數只用於本次啟動，保留已儲存的帳戶、預設模型與權限。正常啟動時不加這些變數，即可繼續使用原設定；不要將它們寫入 shell 設定檔。

此工作階段方式使用 Claude Code **2.1.263**，透過 `ANTHROPIC_AUTH_TOKEN` 傳送 Bearer 認證，Base URL 不加 `/v1`。既有設定檔的 `env`、憑證助手、雲端供應商選項或管理政策可能影響認證，請先檢查；若有衝突，使用下方設定助手，不要刪除帳戶資料或放寬政策。啟動後以 `/status` 核對模型與權限。

<CodeGroup>
```bash macOS / Linux / WSL
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['ANTHROPIC_BASE_URL'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_BASE_URL', 'Process')
$previous['ANTHROPIC_AUTH_TOKEN'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_AUTH_TOKEN', 'Process')
$previous['ANTHROPIC_API_KEY'] = [Environment]::GetEnvironmentVariable('ANTHROPIC_API_KEY', 'Process')
try {
  $env:ANTHROPIC_BASE_URL = 'https://api.tokenlab.sh'
  $env:ANTHROPIC_AUTH_TOKEN = $env:TOKENLAB_API_KEY
  $env:ANTHROPIC_API_KEY = ''
  claude --model claude-sonnet-4-6
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

可選：使用[可還原的 Claude Code 設定工具](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/claude_setup.md)，透過 Python 3.11+ 預覽、套用並還原原始檔案。TokenLab Skills 外掛 **0.1.2** 已包含新腳本；獨立安裝的 Skill 更新至包含這些腳本的版本後也可使用。已安裝外掛或獨立 Skill 的使用者請依 [README 更新說明](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation)更新，並確認腳本已安裝。也可直接完成本頁的手動設定。

儲存設定或列出模型不能證明金鑰有效或請求完成。傳送提示詞會使用 TokenLab 餘額；先核對回覆及對應[請求記錄](https://tokenlab.sh/dashboard/runs?section=requests)，再嘗試工具，輔助請求也可能計費。

## 使用方式

完成設定後，即可正常使用 Claude Code：

```bash
# Start an interactive session
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6

# Run a single command
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Explain this code" < main.py
```

如有需要，請驗證安裝狀態：

```bash
claude --version
claude doctor
```

## 可用模型

TokenLab 支援所有 Claude 模型：

| 模型 | 說明 |
|-------|-------------|
| `claude-opus-4-6` | 能力最強，適合複雜推理 |
| `claude-sonnet-4-6` | 效能平衡，非常適合程式設計 |
| `claude-haiku-4-5` | 速度最快，具成本效益 |

## 模型選擇

使用 `--model` 旗標指定模型：

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-sonnet-4-6 "Review this PR"
```

## 延伸思考

對於複雜推理任務，請使用支援 extended thinking 的模型：

```bash
ANTHROPIC_BASE_URL=https://api.tokenlab.sh ANTHROPIC_AUTH_TOKEN="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" ANTHROPIC_API_KEY= claude --model claude-opus-4-6 "Design a microservices architecture for..."
```

## 疑難排解

<AccordionGroup>
  <Accordion title="連線錯誤">
    請確認 base URL 完全為 `https://api.tokenlab.sh`（對於 Anthropic 風格請求，不要加上 `/v1` 後綴）。
  </Accordion>

  <Accordion title="無效的 API key">
    請確認您的 TokenLab API key 以 `sk-` 開頭，且有足夠餘額。
  </Accordion>


  <Accordion title="找不到模型">
    請檢查模型名稱是否正確。請使用 `claude-sonnet-4-6` 這種格式。
  </Accordion>
</AccordionGroup>
