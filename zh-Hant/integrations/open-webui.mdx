## 概覽

Open WebUI 支援自訂的 OpenAI 相容 API 連接。您可以將 TokenLab 新增為遠端 OpenAI 相容端點，並重新整理模型列表。

<Note>
**類型**: Web Chat App

**主要路徑**: OpenAI 相容聊天補全 (chat completions)

**支援信心**: 支援的聊天應用程式路徑
</Note>

## 管理員連接

1. 開啟 **Admin Panel** -> **Settings** -> **Connections**。
2. 在 OpenAI API 連接區域中，新增一個連接。
3. 將 Base URL 設定為 `https://api.tokenlab.sh/v1`。
4. 將 API key 設定為您的 TokenLab 金鑰。
5. 儲存連接並重新整理模型。

## 數值

| 欄位 | 數值 |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| 範例模型 | `gpt-5.4-mini` |

## 推薦模型

- `gpt-5.4-mini` 用於一般聊天
- `claude-sonnet-5` 用於寫作與推理
- `deepseek-v4-pro` 用於程式碼密集的聊天
- `gemini-3.5-flash` 用於快速且支援多模態的工作流程

若要手動指定模型 ID，請編輯這個連線，開啟 **Advanced** → **Model IDs (Filter)**，新增精確的 TokenLab 模型 ID 後儲存。
