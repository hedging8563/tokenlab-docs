---
title: "取得 API Key 帳單"
openapi: "GET /v1/management/api-keys/{keyId}/billing"
description: "返回某個使用者 API Key 的聚合帳單明細。"
---

## 概覽

這個端點返回所選 API Key 的消費帳單聚合結果，包括總費用、總請求數、按計費單位統計的用量，以及 `by_model`、`by_logical_model`、`by_model_vendor`、`by_scene` 四類拆分與每日費用趨勢。

## 注意事項

- 金額欄位僅支援 USD。`CNY` 輸入已停用，並會回傳 `400 currency_retired`。

- 儲值、發票等組織級財務流水不會包含在這裡。

## 範例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 重要欄位

<ResponseField name="api_key" type="object">API Key 摘要，欄位與列出、建立和更新回應相同。</ResponseField>
<ResponseField name="summary" type="object">依所選篩選條件彙總的總計。</ResponseField>
<ResponseField name="breakdowns" type="object">依所選篩選條件彙總的明細拆分。</ResponseField>
<ResponseField name="summary.total_requests" type="number">請求總數。</ResponseField>
<ResponseField name="summary.total_cost" type="number">以 JSON 數字回傳的 USD 總費用，供顯示使用。</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">以十進位字串回傳的 USD 精確總費用。</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">提示 token 總數。</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">完成 token 總數。</ResponseField>
<ResponseField name="summary.total_tokens" type="number">token 總數。</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">依計量單位分組的用量。</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">依請求時使用的公開模型拆分。</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">依邏輯公開模型拆分。</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">依公開模型廠商拆分。</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">依公開請求場景拆分。</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">每日費用趨勢。</ResponseField>
