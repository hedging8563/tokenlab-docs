## 概覽

這個 endpoint 會在目前管理令牌所屬的組織下，建立一把新的 `type=user` API Key。

## 請求主體

| 欄位 | 型別 | 預設值 / 限制 | 說明 |
|------|------|---------------|------|
| `name` | string | 選填，預設 `Default Key`，長度 `1-50` | 顯示名稱，伺服器端會先去除前後空白 |
| `limitAmount` | number \| string \| null | `0–100000` USD | `null` 表示不設限，`0` 表示無法產生費用。十進位字串最多支援 6 位小數。 建立時省略此欄位表示不設限。 |
| `limitCurrency` | 列舉 | 預設 `USD` | 僅限 USD。傳送 `CNY` 會回傳 `400 currency_retired`。 |
| `models` | string[] | 預設 `[]` | 可選的模型白名單 |
| `deliveryPolicy` | string \| null | `auto`, `verified`, `official`, `null` | `null` 表示繼承工作區交付策略。 |
| `expiresAt` | string \| null | RFC3339 datetime | `null` 表示沒有到期時間 |

## 說明

- 金額欄位僅支援 USD。`CNY` 輸入已停用，並會回傳 `400 currency_retired`。

- 回應中的完整 API Key 只會顯示一次。
- `models: []` 表示這把 Key 除了組織層政策外，沒有額外的模型限制。
- `limitAmount: 0` 會建立一把有效、但暫時無法消耗額度的 Key，之後可再更新。

## 範例

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Backend Worker",
    "limitAmount": 500,
    "models": ["veo3.1", "kling-3.0-video"],
    "expiresAt": "2026-12-31T23:59:59Z"
  }'
```
</RequestExample>

## 重要欄位

<ResponseField name="key" type="string">完整的 API Key 密鑰，只會在建立時回傳一次。</ResponseField>
<ResponseField name="id" type="string">用於後續管理 API 呼叫的 API Key 識別碼。</ResponseField>
<ResponseField name="name" type="string">API Key 的顯示名稱。</ResponseField>
<ResponseField name="key_prefix" type="string">用於顯示和支援排查的非敏感 Key 前綴。</ResponseField>
<ResponseField name="status" type="string">值為 `active`、`inactive`、`suspended` 或 `revoked`。</ResponseField>
<ResponseField name="limit_amount" type="number | null">以 JSON 數字回傳的 USD 消費上限，供顯示使用。`null` 表示不設限。</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">以十進位字串回傳的 USD 精確消費上限。`null` 表示不設限。</ResponseField>
<ResponseField name="used_amount" type="number">以 JSON 數字回傳的 USD 累計用量支出，供顯示使用。</ResponseField>
<ResponseField name="used_amount_decimal" type="string">以十進位字串回傳的 USD 精確累計用量支出。</ResponseField>
<ResponseField name="models" type="string[]">單一 Key 的模型白名單。空陣列表示沒有額外的 Key 層級模型限制。</ResponseField>
<ResponseField name="delivery_policy" type="string | null">`auto`, `verified`, `official`, `null`. `null` 表示繼承工作區交付策略。</ResponseField>
<ResponseField name="expires_at" type="string | null">Key 到期時間的 ISO 時間戳記；`null` 表示永不到期。</ResponseField>
<ResponseField name="last_used_at" type="string | null">最近一次使用的 ISO 時間戳記；從未使用時為 `null`。</ResponseField>
<ResponseField name="created_at" type="string">建立時間的 ISO 時間戳記。</ResponseField>
