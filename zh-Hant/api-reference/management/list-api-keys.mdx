---

## 概覽

返回目前管理令牌所屬組織下的使用者 API Key 清單。

## 注意事項

- 金額欄位僅支援 USD。`CNY` 輸入已停用，並會回傳 `400 currency_retired`。

- 系統代管的 Key 不會出現在結果中。

## 範例

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 請求 / 回應

使用上方的互動式 OpenAPI 面板以取得確切的架構。

## 重要欄位

<ResponseField name="object" type="string">固定為 `list`。</ResponseField>
<ResponseField name="data" type="array">API Key 物件陣列。</ResponseField>
<ResponseField name="pagination" type="object">分頁中繼資料，包含 `page`、`limit`、`total` 和 `totalPages`。</ResponseField>
<ResponseField name="data[].id" type="string">用於後續管理 API 呼叫的 API Key 識別碼。</ResponseField>
<ResponseField name="data[].name" type="string">API Key 的顯示名稱。</ResponseField>
<ResponseField name="data[].key_prefix" type="string">用於顯示和支援排查的非敏感 Key 前綴。</ResponseField>
<ResponseField name="data[].status" type="string">值為 `active`、`inactive` 或 `revoked`。</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">以 JSON 數字回傳的 USD 消費上限，供顯示使用。`null` 表示不設限。</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">以十進位字串回傳的 USD 精確消費上限。`null` 表示不設限。</ResponseField>
<ResponseField name="data[].used_amount" type="number">以 JSON 數字回傳的 USD 累計用量支出，供顯示使用。</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">以十進位字串回傳的 USD 精確累計用量支出。</ResponseField>
<ResponseField name="data[].models" type="string[]">單一 Key 的模型白名單。空陣列表示沒有額外的 Key 層級模型限制。</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">Key 到期時間的 ISO 時間戳記；`null` 表示永不到期。</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">最近一次使用的 ISO 時間戳記；從未使用時為 `null`。</ResponseField>
<ResponseField name="data[].created_at" type="string">建立時間的 ISO 時間戳記。</ResponseField>
