---
title: "生成內容"
openapi: "/openapi/zh-Hant.json POST /v1beta/models/{model}:generateContent"
description: "使用 Google Gemini API 格式生成內容"
---

使用 Gemini Models API 回傳的模型，以 Gemini 請求與回應格式呼叫。支援 ProtoJSON lowerCamelCase 和對應的 proto snake_case 欄位名稱；可選欄位與取值以所選模型為準。

## 路徑參數

<ParamField path="model" type="string" required>
  模型名稱（例如：`gemini-2.5-pro`、`gemini-3.5-flash`）。
</ParamField>

## 查詢參數

<ParamField query="key" type="string">
  API key（標頭驗證的替代方案）。
</ParamField>

## 驗證

Gemini 端點支援多種驗證方式：
- `?key=YOUR_API_KEY` 查詢參數
- `x-goog-api-key: YOUR_API_KEY` 標頭
- `Authorization: Bearer YOUR_API_KEY` 標頭

## 請求主體

<ParamField body="contents" type="array" required>
  對話內容，包含 `parts` 和可選的 `role`。媒體欄位使用 `inlineData` / `inline_data` 或 `fileData` / `file_data`。TokenLab 建立的 Files 與 Cache ID 只能在所屬工作區使用。
</ParamField>

<ParamField body="systemInstruction" type="object">
  模型的系統指令。
</ParamField>

<ParamField body="generationConfig" type="object">
  生成設定包括 `temperature`、`topP`、`topK`、`maxOutputTokens`、`stopSequences`、`candidateCount`、`responseModalities`、`responseMimeType`、`responseSchema` 和 `thinkingConfig`，也支援對應的 snake_case 名稱。取值範圍與組合以所選模型為準。
</ParamField>

<ParamField body="safetySettings" type="array">
  安全過濾器設定。
</ParamField>

## 回應

<ResponseField name="candidates" type="array">
  生成的內容候選。
</ResponseField>

<ResponseField name="usageMetadata" type="object">
  Token 使用資訊。
</ResponseField>

## 多模態輸入範例

對於 Gemini 多模態請求，請把媒體放在 `contents[].parts[]` 中，可以使用「內嵌位元組」或「基於 URL 的檔案引用」兩種方式。

目前公共 Gemini 契約支援的媒體類別：
- 圖片
- 音訊
- 影片

對於內嵌媒體，請使用 `inlineData` 或 `inline_data`，並傳入檔案位元組的 Base64 內容。

對於 URL 媒體，請使用 `fileData` 或 `file_data`，並傳入可公開存取的 `https` URL。

### 圖片輸入範例

使用內嵌圖片位元組：

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "請描述這張圖片。" },
        {
          "inlineData": {
            "mimeType": "image/jpeg",
            "data": "/9j/4AAQSkZJRgABAQ..."
          }
        }
      ]
    }
  ]
}
```

使用圖片 URL：

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "請描述這張圖片。" },
        {
          "fileData": {
            "mimeType": "image/jpeg",
            "fileUri": "https://example.com/demo.jpg"
          }
        }
      ]
    }
  ]
}
```

### 音訊輸入範例

```json
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "請轉寫並摘要這段音訊。" },
        {
          "file_data": {
            "mime_type": "audio/mpeg",
            "file_uri": "https://example.com/sample.mp3"
          }
        }
      ]
    }
  ]
}
```
