---
title: "列出素材資產"
openapi: "/openapi/zh-Hant.json GET /v1/videos/assets"
description: "列出當前組織擁有的 Seedance 素材資產。"
---

列出經身份驗證的組織所擁有的素材資產。當您需要為特定的生成工作流程尋找資產時，可以透過 `library_type`、`group_id` 或 `status` 進行篩選。

請僅使用 `status` 為 `ACTIVE` 的資產。建立影片時請使用回傳的 TokenLab 素材資產 `id`。

`project_name` 用於同一組織內的資源隔離，預設為 `default`。相關素材群組和素材須使用相同且區分大小寫的值；POST/PUT 在 JSON 請求主體中傳入，GET/DELETE 在查詢參數中傳入。

## 請求範例

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 回應範例

```json
{
  "assets": [
    {
      "id": "asset-20260720123456-qn7wr",
      "object": "seedance.material_asset",
      "project_name": "default",
      "group_id": "group-20260720123456-vrt01",
      "library_type": "aigc_avatar",
      "asset_name": "Front view",
      "asset_type": "Image",
      "status": "ACTIVE",
      "ready": true,
      "created_at": 1782998400000
    }
  ],
  "next_page_token": null
}
```
