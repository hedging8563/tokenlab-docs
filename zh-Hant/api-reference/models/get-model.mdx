## 路徑參數 (Path Parameter)

<ParamField path="model" type="string" required>
  模型 ID，例如 `gpt-5.6-terra` 或 `claude-sonnet-4-6`。
</ParamField>

## 回應 (Response)

<ResponseField name="id" type="string">模型 ID。</ResponseField>
<ResponseField name="object" type="string">固定為 `model`。</ResponseField>
<ResponseField name="owned_by" type="string">模型製造商。</ResponseField>
<ResponseField name="tokenlab" type="object">
  TokenLab 模型資訊，包含功能、價格、計費單位、上下文限制、支援的 API 格式、操作以及生命週期狀態。
</ResponseField>

常見的 `tokenlab` 欄位包括：

- `capabilities`：文字、圖像、影片、音訊及其他功能。
- `pricing`：目前的公開價格。
- `max_input_tokens` 與 `max_output_tokens`：上下文與輸出限制。
- `accepted_request_formats`：支援的 API 格式。
- `supported_operations`：例如文字轉圖像或圖像轉影片等操作。
- `lifecycle`：可用性、發布日期、棄用日期或替代模型。

部分媒體模型還包含推薦狀態與更新時間。推薦狀態可能會隨可用性與效能而變動，因此請勿將其順序寫死 (hard-code)。

## 範例

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.6-terra"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["coding", "json-mode", "prompt-cache", "reasoning", "tool-use", "vision"],
    "accepted_request_formats": ["openai_chat_completions", "openai_responses"]
  }
}
```

若模型不存在，將回傳 `404 model_not_found`。
