模型目錄是公開的，不需要 API key。每個項目都包含當前功能、價格和 API 格式的摘要。當您需要完整詳細資訊時，請檢索單一模型。

## 查詢參數 (Query Parameters)

<ParamField query="category" type="string">
  按 `chat`、`image`、`video`、`audio`、`tts`、`stt`、`music`、`3d`、`embedding`、`rerank` 或 `translation` 進行篩選。
</ParamField>

<ParamField query="recommended_for" type="string">
  返回針對特定任務的當前建議，例如 `image`、`video`、`music`、`3d`、`tts`、`stt`、`embedding`、`rerank` 或 `translation`。
</ParamField>

<ParamField query="provider" type="string">
  按模型製造商進行篩選，例如 `openai`、`anthropic`、`google` 或 `deepseek`。
</ParamField>

<ParamField query="tag" type="string">
  按標籤進行篩選，例如 `chat`、`image`、`video`、`embedding` 或 `translation`。
</ParamField>

## 回應 (Response)

<ResponseField name="object" type="string">始終為 `list`。</ResponseField>
<ResponseField name="data" type="array">包含 `id`、`owned_by` 和 `tokenlab` 摘要的模型列表。</ResponseField>

`tokenlab` 下常見的列表欄位包括：

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` 和 `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` 和 `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`、`tokenlab.commercial` 和 `tokenlab.badges`
- `tokenlab.request_format_summary`
- 當使用 `recommended_for` 時的 `tokenlab.agent_preferences`

當使用 `recommended_for` 時，結果可能還包含建議狀態和更新時間。請讀取當前回應，不要固定排序順序。

## 範例

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```

請參閱 [取得模型](/zh-Hant/api-reference/models/get-model) 以獲取完整詳細資訊。
