---
title: "取消批次"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "取消排隊或正在運行的批次作業。"
---

請求取消排隊或執行中的批次。回應會返回目前狀態，可能仍在取消，也可能已取消完成。已結束的批次保留原有終態。若回傳狀態尚未結束，請再次取得批次以確認結果。

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">用於後續呼叫和支援排障的識別符。</ResponseField>
<ResponseField name="status" type="string">批次目前狀態。取消請求成功並不一定回傳 `cancelling`。</ResponseField>
