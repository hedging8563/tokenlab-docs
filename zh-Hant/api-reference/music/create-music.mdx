---
title: "建立音樂"
openapi: "POST /v1/music/generations"
description: "使用 Suno 建立音樂生成任務"
---

使用 AI 生成音樂和歌詞。這是一個非同步 API。建立回應會返回任務身分，並且在可用時返回優先使用的 `poll_url`。

## 請求參數

<ParamField body="model" type="string" default="suno_music">
  音樂模型 ID，例如 `suno-music`。僅產生歌詞時，請選擇目前公開操作包含 `lyrics` 的模型。
</ParamField>

<ParamField body="prompt" type="string">
  音樂描述或替換文字。音樂、歌詞、upload-cover、upload-extend 和 replace-section 請求必填；add-instrumental 和分軌請求可省略。
</ParamField>

<ParamField body="title" type="string">
  生成歌曲的標題。
</ParamField>

<ParamField body="tags" type="string">
  風格標籤（例如："pop, upbeat, electronic"）。
</ParamField>

<ParamField body="negative_tags" type="string">
  需要避開的風格。`audio_operation` 為 `add-instrumental` 時必填。
</ParamField>

<ParamField body="action" type="string">
  可選值為 `MUSIC` 或 `LYRICS`。請選擇支援對應公開操作的模型；此欄位不會讓僅支援音樂的模型具備歌詞能力。
</ParamField>

<ParamField body="mv" type="string">
  Suno 版本選擇器。生成、upload-cover、upload-extend、add-instrumental 及以 `audio_url` 為來源的替換請求必填。歌詞、以 `task_id` + `audio_id` 為來源的替換及分軌請求請省略。支援值： `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  設為 `true` 時生成無人聲的純音樂。
</ParamField>

<ParamField body="audio_url" type="string">
  可公開存取的參考/上傳音訊 URL。提供此欄位但不傳 `audio_operation` 時，預設使用 upload-cover 流程。
</ParamField>

<ParamField body="audio_operation" type="string">
  音訊操作： `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`、`multi-stem-separation` 和 `advanced-split` 需要 `task_id` + `audio_id`；`advanced-split` 還需要 `stem_name`。`upload-extend` 需要大於 0 的 `continue_at`。`add-instrumental` 需要 `audio_url`、`title`、`tags` 和 `negative_tags`。

  `replace-section` 必須提供 `prompt`、`tags`、`title`、`infill_start_s`、`infill_end_s` 和 `full_lyrics`。來源只能二選一：`task_id` + `audio_id`，或 `audio_url` + `mv`。替換區間必須為 6–60 秒。
</ParamField>

<ParamField body="task_id" type="string">
  本組織擁有的來源任務 ID，用於生成音訊的分段替換或分軌。
</ParamField>

<ParamField body="audio_id" type="string">
  來源任務結果回傳的音訊 ID。替換已生成音訊及分軌時，需與 `task_id` 一起提供。
</ParamField>

<ParamField body="infill_start_s" type="number">
  替換區間的起始秒數，必須大於等於 0。`replace-section` 必填。
</ParamField>

<ParamField body="infill_end_s" type="number">
  替換區間的結束秒數。`replace-section` 必填，必須比 `infill_start_s` 晚 6–60 秒。
</ParamField>

<ParamField body="full_lyrics" type="string">
  結果歌曲的完整歌詞。`replace-section` 必填。
</ParamField>

<ParamField body="stem_name" type="string">
  分軌名稱。`advanced-split` 必填。
</ParamField>

<ParamField body="continue_clip_id" type="string">
  要續接的前一個片段 ID。
</ParamField>

<ParamField body="continue_at" type="number">
  續寫起點，單位為秒。`upload-extend` 必填且必須大於 0。
</ParamField>

<Note>
`prompt` 最多 5000 字元，`tags` 和 `negative_tags` 各最多 1000 字元。可用操作和參數以所選模型目前的詳情為準。
</Note>

## 回應

<ResponseField name="id" type="string">
  用於輪詢狀態的任務 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
  同一個非同步任務 ID 的別名，僅在回傳時存在。
</ResponseField>

<ResponseField name="poll_url" type="string">
  可用時返回的優先輪詢 URL。
</ResponseField>

<ResponseField name="status" type="string">
  任務狀態：`pending`、`processing`、`completed` 或 `failed`。
</ResponseField>

<ResponseField name="created" type="integer">
  任務建立的 Unix 時間戳記，僅在回傳時存在。
</ResponseField>

curl -X POST "https://api.tokenlab.sh/v1/music/generations" \

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
