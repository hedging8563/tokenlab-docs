## 請求主體

轉錄可能直接回傳文字，也可能以 HTTP `200`、`id` 和 `status` 回傳已接受的非同步任務。非同步任務請依 `poll_url` 查詢，或使用 `/v1/tasks/{id}`。同步處理較長音訊時，請將用戶端逾時設為至少 `120s`。

<ParamField body="file" type="file" required>
  要轉錄的音訊檔案。支援格式：flac、mp3、mp4、mpeg、mpga、m4a、ogg、wav、webm。 檔案大小上限：25 MB。
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  轉錄模型 ID，例如 `whisper-1` 或 `gpt-4o-transcribe`。透過 `GET /v1/models?recommended_for=stt` 取得目前可選模型。
</ParamField>

<ParamField body="language" type="string">
  音訊的語言，採用 ISO-639-1 格式（例如：`en`、`zh`、`ja`）。
</ParamField>

<ParamField body="prompt" type="string">
  可選文字，用於引導模型的風格或延續前一段內容。
</ParamField>

<ParamField body="response_format" type="string" default="json">
  輸出格式。Whisper 支援 `json`、`text`、`srt`、`verbose_json` 和 `vtt`；其他模型支援的範圍可能不同，請查詢模型詳情。
</ParamField>

<ParamField body="temperature" type="number">
  取樣溫度，範圍為 0–1，僅適用於支援此參數的模型。
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  所選模型支援時，可指定 `word` 和／或 `segment`。Whisper 需要 `response_format=verbose_json`。multipart 請求中，多值應重複傳送 `timestamp_granularities[]`。
</ParamField>

## 回應

以下欄位用於 JSON 轉錄或翻譯回應。`text`、`srt` 和 `vtt` 回傳原始文字或字幕，而不是 JSON 物件。附加欄位取決於模型和輸出格式。

<ResponseField name="text" type="string">
  轉錄後的文字。
</ResponseField>

對於 `verbose_json`：

<ResponseField name="task" type="string">
  回傳時表示任務名稱，例如 `transcribe`。
</ResponseField>

<ResponseField name="language" type="string">
  偵測到的語言。
</ResponseField>

<ResponseField name="duration" type="number">
  音訊時長（秒）。
</ResponseField>

<ResponseField name="segments" type="array">
  含時間戳記的轉錄片段。
</ResponseField>

<ResponseField name="words" type="array">
  詞級時間戳記（若有請求）。
</ResponseField>

已接受的非同步轉錄任務回傳以下欄位，而非轉錄文字：

<ResponseField name="id" type="string">
  任務 ID。
</ResponseField>

<ResponseField name="task_id" type="string">
  可用時返回的非同步任務 ID 別名。
</ResponseField>

<ResponseField name="status" type="string">
  任務狀態：`pending`、`processing`、`completed` 或 `failed`。
</ResponseField>

<ResponseField name="poll_url" type="string">
  建立回應提供時，優先使用的輪詢 URL。
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## 翻譯

若要將音訊翻譯為英文，請使用 translations endpoint：

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
