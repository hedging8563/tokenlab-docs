---

## 概述

刪除透過 `/v1/files` 建立的檔案。批次檔案和 TokenLab 建立的圖像參考檔案會回傳 OpenAI 相容的 deleted 物件。

當請求選擇 Anthropic Files 相容模式時，同一路徑會從繫結工作區刪除 Anthropic 風格檔案。

## 注意事項

- 刪除檔案不會取消已經引用該檔案的批次工作。
- 不存在或無權存取的 file id 會回傳公開的 not-found 錯誤，不暴露路由狀態。
- 只有在沒有待處理的圖像編輯請求需要該參考檔案後，才刪除圖像參考檔案。

## 範例

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
