## Build with TokenLab

TokenLab connects your application or coding tool to AI models with one API key and a shared balance. Choose a model and its supported API format; requests are charged at the published price.

## What you can build

Use the current [Models catalog](https://tokenlab.sh/en/models) for model IDs, availability, supported formats, and prices.

| Capability | Description |
|---|---|
| Chat and reasoning | Text generation, planning, and tools |
| Vision and multimodal | Image understanding and multimodal chat |
| Image generation and editing | Text-to-image and image editing |
| Video generation | Text-to-video, image-to-video, reference video, and motion control |
| Audio and realtime | TTS, transcription, audio translation, and realtime WebSocket sessions |
| Embeddings and rerank | Text vectorization and reranking |
| Translation | Text translation and WebSocket speech translation workflows |
| Music & 3D | Music and 3D asset generation |
| Worlds | World generation, status polling, and media asset workflows |
