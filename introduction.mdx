## Build with TokenLab

TokenLab gives you one API key for chat, image, video, audio, embedding, and other AI models. Use the model format you need, share one balance across models, and pay only for what you use.

The catalog changes as models are added or retired. Check `/v1/models` or the Models page for current availability and prices.

| Vision and multimodal | Image understanding and multimodal chat | `gpt-4o`, `claude-sonnet-4-6`, `gemini-3.5-flash` |

| Worlds | World generation, status polling, and media asset workflows | Use `/v1/worlds/generations` and the Models API for current availability |

## Choose the Request Format

Use `/v1/chat/completions` with an OpenAI-compatible client. Choose Anthropic or Gemini format only when you need behavior specific to that API.

<CodeGroup>

```bash cURL
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "messages": [
      {"role": "user", "content": "Explain what TokenLab does in one sentence."}
    ]
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.chat.completions.create(
    model="gpt-5.6-terra",
    messages=[{"role": "user", "content": "Explain what TokenLab does in one sentence."}]
)

print(response.choices[0].message.content)
```

```javascript JavaScript
import OpenAI from 'openai';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-5.6-terra',
  messages: [{ role: 'user', content: 'Explain what TokenLab does in one sentence.' }],
});

console.log(response.choices[0].message.content);
```

<Note>
Use `POST /v1/responses` only when you explicitly need Responses-specific behavior. It is not the default compatibility path across all models.
</Note>

</CodeGroup>
