## 개요

대부분의 일반 AI 채팅 앱은 표준 OpenAI 호환 채팅 경로를 통해 TokenLab에 연결됩니다.

실제 적용 시 다음 사항을 참고하세요:
- 앱에서 전체 엔드포인트 URL을 명시적으로 요구하지 않는 한, 기본 URL로 `https://api.tokenlab.sh/v1`을 사용하세요.
- TokenLab API 키를 OpenAI 스타일의 API 키로 사용하세요.
- 앱의 표준 채팅 워크플로우에서 사용할 수 있는 모델을 선택하세요.

<Note>
일반 채팅 앱은 대개 **chat-completions 지향적**이며, Codex Responses WebSocket 클라이언트가 아닙니다. Codex CLI/App, Cursor 또는 Responses 전용 동작이 필요한 기타 코딩 도구의 경우, 대신 전용 통합 가이드를 사용하세요.
</Note>

<Note>
**유형**: 채팅 앱

**기본 경로**: OpenAI 호환 chat-completions

**지원 신뢰도**: 지원되는 경로
</Note>

## 지원되는 애플리케이션

| 애플리케이션 | 플랫폼 | 참고 사항 |
|-------------|----------|-------|
| Open WebUI | 웹, 자체 호스팅 | OpenAI 호환 연결을 지원하는 인기 있는 자체 호스팅 선택지 |
| LibreChat | 웹, 자체 호스팅 | 사용자 지정 OpenAI 엔드포인트를 지원하는 다중 공급자 채팅 워크스페이스 |
| LobeChat | 웹, 데스크톱, 자체 호스팅 | 강력한 사용자 지정 공급자 지원 |
| Cherry Studio | Windows, macOS, Linux | 우수한 OpenAI 호환 공급자 흐름 |
| Chatbox | Windows, macOS, Linux | 간단한 OpenAI 호환 설정 |
| DeepChat | Windows, macOS, Linux | OpenAI 호환 공급자 설정이 포함된 데스크톱 클라이언트 |
| Jan | 데스크톱, 자체 호스팅 | 원격 OpenAI 호환 공급자를 지원하는 로컬 우선 앱 |
| TypingMind | 웹, 데스크톱 | 사용자 지정 엔드포인트 스타일 사용 |
| NextChat | 웹, 자체 호스팅 | 기본 URL 재정의가 가능한 경량 ChatGPT 스타일 클라이언트 |
| ChatWise | Windows, macOS | 표준 사용자 지정 공급자 패턴 |

## 기본 연결 값

| 필드 | 값 |
|-------|-------|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| API 유형 | OpenAI 호환 |

앱에서 기본 URL 대신 **전체 엔드포인트 URL**을 요구하는 경우 다음을 사용하세요:
- Chat Completions: `https://api.tokenlab.sh/v1/chat/completions`

## 앱 설정 예시

<Tabs>
  <Tab title="LobeChat">
    **자체 호스팅 LobeChat**

    ```bash
    OPENAI_API_KEY=sk-your-tokenlab-key
    OPENAI_PROXY_URL=https://api.tokenlab.sh/v1
    ```

    **LobeChat Cloud**
    1. **Settings** → **AI Service Provider**를 엽니다.
    2. **OpenAI**를 선택합니다.
    3. TokenLab API 키를 입력합니다.
    4. 사용자 지정 엔드포인트를 `https://api.tokenlab.sh/v1`로 설정합니다.
  </Tab>

  <Tab title="Cherry Studio">
    1. **Settings** → **Model Provider**를 엽니다.
    2. **OpenAI-compatible** 공급자를 추가합니다.
    3. 다음을 입력합니다:
       - **Name**: TokenLab
       - **API Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. 사용할 모델을 추가합니다.
  </Tab>

  <Tab title="Chatbox">
    1. **Settings** → **AI Model**을 엽니다.
    2. **OpenAI API Compatible**을 선택합니다.
    3. 다음을 입력합니다:
       - **API Host**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini` 또는 `claude-sonnet-5`
  </Tab>

  <Tab title="TypingMind">
    1. **Settings**를 엽니다.
    2. **Custom Endpoint**를 선택합니다.
    3. 다음을 입력합니다:
       - **Endpoint URL**: `https://api.tokenlab.sh/v1/chat/completions`
       - **API Key**: `sk-your-tokenlab-key`
    4. 노출할 모델을 구성합니다.
  </Tab>

  <Tab title="Open WebUI">
    1. **Admin Settings** → **Connections**를 엽니다.
    2. **OpenAI-compatible** 연결을 추가합니다.
    3. 다음을 입력합니다:
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. 저장하고 노출할 모델을 선택합니다.
  </Tab>

  <Tab title="DeepChat">
    1. **Settings** -> **Model Provider**를 엽니다.
    2. OpenAI 호환 공급자를 추가합니다.
    3. 다음을 입력합니다:
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
       - **Model**: `gpt-5.4-mini`
    4. 저장하고 테스트 채팅을 실행합니다.
  </Tab>

  <Tab title="Jan">
    1. **Settings** -> **Providers**를 엽니다.
    2. 원격 OpenAI 호환 공급자를 추가합니다.
    3. 다음을 입력합니다:
       - **Provider name**: TokenLab
       - **Base URL**: `https://api.tokenlab.sh/v1`
       - **API Key**: `sk-your-tokenlab-key`
    4. `gpt-5.4-mini` 또는 다른 TokenLab 모델을 선택합니다.
  </Tab>

  <Tab title="LibreChat">
    LibreChat 공급자 구성에 OpenAI 호환 엔드포인트를 추가하고 다음을 가리키도록 설정합니다:

    ```yaml
    customEndpoints:
      - name: TokenLab
        apiKey: '${OPENAI_API_KEY}'
        baseURL: 'https://api.tokenlab.sh/v1'
        models:
          default: ['gpt-5.4-mini', 'gpt-5.4', 'claude-sonnet-5']
          fetch: false
    ```
  </Tab>
</Tabs>

| DeepSeek | `deepseek-v4-flash`, `deepseek-v4-pro` |

## 팁

<AccordionGroup>
  <Accordion title="앱에서 지원하는 경우 기본 URL 사용 권장">
    대부분의 앱은 전체 엔드포인트 URL 대신 `https://api.tokenlab.sh/v1`을 기본 URL로 제공할 때 구성이 더 쉽고 오류가 적습니다.
  </Accordion>

  <Accordion title="작은 모델부터 사용">
    일상적인 채팅에는 `gpt-5.4-mini` 또는 `deepseek-v4-flash`로 시작하고, 더 복잡한 추론 작업이 필요할 때 `gpt-5.4` 또는 `claude-opus-4-8`로 전환하세요.
  </Accordion>

  <Accordion title="코딩 도구는 별도로 관리">
    일반 채팅 앱과 코딩 에이전트는 종종 서로 다른 엔드포인트 동작을 필요로 합니다. Codex/Cursor 스타일의 도구는 전용 통합 페이지를 참조하세요.
  </Accordion>
</AccordionGroup>

## 문제 해결

<AccordionGroup>
  <Accordion title="연결 오류">
    - 기본 URL이 정확히 `https://api.tokenlab.sh/v1`인지 확인하세요.
    - 앱이 경로를 자동으로 추가하는 경우 끝에 있는 슬래시(/)를 제거하세요.
    - 앱에서 전체 엔드포인트 URL을 요구하는 경우 `https://api.tokenlab.sh/v1/chat/completions`를 사용하세요.
  </Accordion>

  <Accordion title="401 Unauthorized (인증 실패)">
    - API 키를 다시 확인하세요.
    - TokenLab 대시보드에서 키가 활성화되어 있는지 확인하세요.
    - 추가 공백이나 줄 바꿈이 없는지 확인하세요.
  </Accordion>

  <Accordion title="모델을 사용할 수 없음">
    - 모델 이름을 정확하게 확인하세요.
    - `gpt-5.4-mini`, `deepseek-v4-flash` 또는 `claude-sonnet-5`와 같이 널리 지원되는 기본 모델을 사용해 보세요.
    - TokenLab 문서나 대시보드에서 현재 가용성을 확인하세요.
  </Accordion>
</AccordionGroup>
