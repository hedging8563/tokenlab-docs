## 개요

VoltAgent는 AI SDK 언어 모델을 직접 지원합니다. TokenLab의 `/v1` 베이스 URL을 사용하여 OpenAI 호환 AI SDK 공급자를 구성하고 선택한 모델을 에이전트에 전달하십시오.

<Note>
**유형**: TypeScript 에이전트 프레임워크

**기본 경로**: AI SDK를 통한 OpenAI 호환 Chat Completions

**지원 신뢰도**: 지원되는 OpenAI 호환 경로
</Note>

## 환경 설정

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 직접 AI SDK 공급자 사용

```ts
import { Agent } from "@voltagent/core";
import { createOpenAI } from "@ai-sdk/openai";

const tokenlab = createOpenAI({
  apiKey: process.env.TOKENLAB_API_KEY,
  baseURL: "https://api.tokenlab.sh/v1",
});

const agent = new Agent({
  name: "tokenlab-agent",
  instructions: "Answer concisely.",
  model: tokenlab("claude-sonnet-5"),
});
```

## 모델 라우터 경로

VoltAgent 레지스트리 스냅샷에 `models.dev`의 TokenLab 공급자 항목이 포함된 경우, 다음과 같이 구성하십시오:

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export TOKENLAB_BASE_URL="https://api.tokenlab.sh/v1"
```

그런 다음 `tokenlab/claude-sonnet-5`와 같이 레지스트리 모델 문자열을 사용하십시오.

## 엔드포인트 참고 사항

직접 AI SDK 경로가 가장 명시적인 설정 방식입니다. TokenLab 네이티브 응답(Responses), Anthropic 메시지(Messages) 또는 Gemini 엔드포인트는 선택한 AI SDK 공급자/클라이언트가 해당 프로토콜에 맞게 구성된 경우에만 사용하십시오.
