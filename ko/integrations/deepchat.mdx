## 개요

DeepChat은 표준 OpenAI 호환 공급자 구성을 통해 TokenLab과 연동됩니다.

<Note>
**유형**: 채팅 앱

**기본 경로**: OpenAI 호환 채팅 완성(Chat Completions)

**지원 신뢰도**: 지원되는 경로
</Note>

## DeepChat 구성

1. **Settings** -> **Model Provider**를 엽니다.
2. OpenAI 호환 공급자를 추가하거나 편집합니다.
3. 다음을 입력합니다:
   - **Provider name**: TokenLab
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. `gpt-5.4-mini`와 같은 모델을 추가합니다.
5. 저장 후 채팅을 테스트합니다.

## 모델 선택

낮은 진입 장벽을 위해 기본값으로 `gpt-5.4-mini`를 사용하세요. 더 강력한 추론 능력이 필요한 대화에는 `claude-sonnet-5`, `gpt-5.4` 또는 `deepseek-v4-pro`를 사용하세요.

## 문제 해결

- DeepChat에서 전체 엔드포인트 URL을 명시적으로 요구하지 않는 한, 전체 `/chat/completions` 경로가 아닌 베이스 URL을 사용하세요.
- API 키의 앞뒤에 공백이 포함되어 있지 않은지 확인하세요.
- 모델이 목록에 없는 경우, 정확한 TokenLab 모델 ID를 수동으로 추가하세요.
