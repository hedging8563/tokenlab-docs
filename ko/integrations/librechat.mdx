## 개요

LibreChat은 OpenAI 호환 커스텀 엔드포인트를 통해 TokenLab과 원활하게 연동됩니다.

## 환경 변수

LibreChat 프로젝트 루트의 `.env` 파일에 다음 변수를 추가하세요:

```bash
TOKENLAB_API_KEY=sk-your-tokenlab-key
```

## 엔드포인트 예시

LibreChat 프로젝트 루트에 `librechat.yaml`이 없다면 `librechat.example.yaml`을 복사하세요. 필수 `version`과 기존 설정을 유지하고 다음 항목을 `endpoints.custom`에 추가하세요:

```yaml
endpoints:
  custom:
    - name: 'TokenLab'
      apiKey: '${TOKENLAB_API_KEY}'
      baseURL: 'https://api.tokenlab.sh/v1'
      models:
        default:
          - 'gpt-5.5'
          - 'gpt-5.6-terra'
          - 'gpt-5.6-luna'
          - 'claude-opus-4-8'
          - 'claude-sonnet-5'
          - 'gemini-3.5-flash'
          - 'deepseek-v4-pro'
          - 'deepseek-v4-flash'
        fetch: true
      titleConvo: true
      titleModel: 'gpt-5.6-luna'
      modelDisplayLabel: 'TokenLab'
```

Docker를 사용한다면 이 파일을 API 컨테이너의 `/app/librechat.yaml`에 마운트하세요. 같은 LibreChat 인스턴스를 다시 시작한 후 TokenLab을 선택하세요. 자세한 내용은 [LibreChat 설정 가이드](https://www.librechat.ai/docs/configuration/librechat_yaml)를 참고하세요.

## 참고 사항

LibreChat은 이 설정을 위해 OpenAI 호환 채팅 경로를 사용합니다. TokenLab은 해당 요청 형식을 지원하는 클라이언트를 위해 네이티브 Responses, Anthropic Messages 및 Gemini 호환 엔드포인트도 제공합니다.
