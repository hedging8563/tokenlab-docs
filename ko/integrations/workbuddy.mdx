## 개요

<Note>
**유형**: 데스크톱 코딩 및 작업 에이전트

**기본 경로**: OpenAI 호환 Chat Completions

**지원 수준**: 공식 사용자 지정 모델 경로
</Note>

[WorkBuddy](https://www.workbuddy.ai/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Model)는 OpenAI 호환 API를 위한 시각적 사용자 지정 모델 편집기를 제공합니다.

## TokenLab 설정

**Settings → Model**을 열고 모델을 추가한 다음 **Custom**을 선택합니다.

| 필드 | 값 |
|---|---|
| Endpoint URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key |
| Model name | `kimi-k3` |
| Custom Protocol | **끔** |

<Warning>
Custom Protocol을 끄세요. 표준 모드는 Base URL을 검사하고 `/chat/completions`를 자동으로 추가합니다. 켠 상태에서 `/v1`만 입력하면 잘못된 경로로 요청합니다.
</Warning>

고급 설정에서 도구 호출, 이미지 입력, 추론 모드를 켜고 추론 전용은 끄세요. 기본 추론 강도는 Auto, 입력 한도는 `1048576`, 출력 한도는 `131072`입니다.

저장한 뒤 `kimi-k3`를 선택하고 읽기 전용 폴더 검사로 검증하세요. 설정 스크린샷을 공유하기 전에 API Key와 비공개 엔드포인트를 가리세요.
