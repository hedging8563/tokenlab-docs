## 개요

OpenCode는 터미널에서 실행되는 오픈소스 AI 코딩 도우미입니다. 여러 LLM 제공자를 지원하며, 수백 개의 모델에 접근할 수 있도록 TokenLab API를 사용하도록 구성할 수 있습니다.

## 설치

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai@1.18.31
```

설치 확인:

```bash
opencode --version
```

## 구성

### 1단계: 환경 변수 설정

[빠른 시작](/ko/quickstart)의 macOS, Linux, WSL 또는 Windows PowerShell 절차로 키를 명령 기록에 남기지 않고 `TOKENLAB_API_KEY`를 설정한 뒤 같은 터미널에서 OpenCode를 실행하세요. 계속 사용하려면 로컬 비밀 관리 도구를 이용하고 셸 프로필에 평문 키를 추가하지 마세요.

### 2단계: OpenCode 구성

아래 설정은 **OpenCode 1.18.31**에서 확인했습니다. 다른 버전은 해당 공식 문서에 따라 별도로 확인해야 합니다.

아래 설정을 별도 파일 `~/.config/opencode/tokenlab.jsonc`에 저장하세요. `XDG_CONFIG_HOME`이 설정되어 있으면 해당 디렉터리의 `opencode/tokenlab.jsonc`를 사용합니다. 기존 `opencode.json` / `opencode.jsonc`, 계정, 기본 모델, 권한을 유지하세요. 이 파일은 해당 실행에서 `OPENCODE_CONFIG`로 선택해야 로드됩니다. 파일이나 제공자 이름이 이미 사용 중이면 다른 이름을 선택하고 실행 명령도 바꾸세요.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  }
}
```

<Note>
이 설정은 `@ai-sdk/openai-compatible`로 Chat Completions를 전송합니다. 현재 모델 정보에서 Chat Completions와 필요한 도구 지원을 확인하세요. 이 예제로 다른 프로토콜이나 버전의 호환성을 판단할 수는 없습니다.
</Note>

선택 사항: Python 3.11+의 [복구 가능한 OpenCode 설정 도구](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/skills/tokenlab-api-integration/references/opencode_setup.md)로 변경 사항을 미리 보고 적용하거나 원본 파일을 복원할 수 있습니다. TokenLab Skills 플러그인 **0.1.2**에는 새 스크립트가 포함되어 있습니다. 독립 Skill도 스크립트가 포함된 버전으로 업데이트하면 사용할 수 있습니다. 기존 플러그인 또는 독립 Skill 설치는 [README 업데이트 안내](https://github.com/hedging8563/tokenlab-skills/blob/247bb17c53754c8288d2d5cb00824fbd9f32899b/README.md#update-an-existing-installation)에 따라 업데이트하고 스크립트가 있는지 확인하세요. 이 페이지의 수동 설정만으로도 완료할 수 있습니다.

## 기본 사용법

빠른 시작에 따라 키를 설정한 뒤 이번 실행에서만 파일을 로드하고 모델을 명시적으로 선택하세요. 사용자 지정 경로나 제공자 이름은 명령에도 반영합니다. 기존 `OPENCODE_CONFIG` 또는 인라인 `OPENCODE_CONFIG_CONTENT` 설정은 유지하고 별도 실행 환경을 사용하세요. 프로젝트 및 관리 설정이 우선할 수 있습니다.

<CodeGroup>
```bash macOS / Linux / WSL
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode models tokenlab
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode --model tokenlab/gpt-5.6-terra
```

```powershell Windows PowerShell
$tokenlabConfigRoot = if ($env:XDG_CONFIG_HOME) { $env:XDG_CONFIG_HOME } else { Join-Path $HOME '.config' }
$previousConfig = $env:OPENCODE_CONFIG
try {
  $env:OPENCODE_CONFIG = Join-Path $tokenlabConfigRoot 'opencode/tokenlab.jsonc'
  opencode models tokenlab
  opencode --model tokenlab/gpt-5.6-terra
} finally {
  if ($null -eq $previousConfig) {
    Remove-Item Env:OPENCODE_CONFIG -ErrorAction SilentlyContinue
  } else {
    $env:OPENCODE_CONFIG = $previousConfig
  }
}
```
</CodeGroup>

모델 목록은 로컬 로드만 확인하며 키 유효성이나 실제 요청 성공을 입증하지 않습니다. 프롬프트를 보내면 TokenLab 잔액을 사용하며, OpenCode는 제목 생성 등 별도로 청구되는 보조 요청을 보낼 수도 있습니다. 응답과 해당 [요청 기록](https://tokenlab.sh/dashboard/runs?section=requests)을 확인하세요.

이 파일을 로드하지 않고 실행하면 기존 설정을 사용합니다. 이 안내를 위해 `OPENCODE_CONFIG`를 셸 프로필에 저장하지 마세요. 수동 설정을 되돌릴 때는 새로 만든 별도 파일만 삭제하거나 기존 파일의 백업을 복원하세요.

## 사용 가능한 모델

| 모델 | 적합한 용도 |
|-------|----------|
| `gpt-5.6-terra` | 복잡한 작업, 코드 아키텍처 |
| `gpt-5.6-luna` | 빠른 수정, 간단한 질의 |
| `claude-sonnet-4-6` | 코드 리뷰, 문서화 |
| `claude-opus-4-6` | 복잡한 추론 |
| `gemini-3.5-flash` | 빠른 응답 |

## 자주 사용하는 명령어

**코드 분석:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "What does this function do?" < src/utils.ts
```

**코드 생성:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Create a REST API with Express"
```

**변경 사항 검토:**

```bash
git diff | OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Review these changes"
```

**오류 수정:**

```bash
OPENCODE_CONFIG="${XDG_CONFIG_HOME:-$HOME/.config}/opencode/tokenlab.jsonc" opencode run --model tokenlab/gpt-5.6-terra "Fix the TypeScript errors in this project"
```

## 대화형 명령어

| 명령어 | 설명 |
|---------|-------------|
| `/help` | 사용 가능한 명령어 표시 |
| `/models` | 다른 모델로 전환 |
| `/clear` | 대화 기록 지우기 |
| `/exit` | OpenCode 종료 |

## 문제 해결

<AccordionGroup>
  <Accordion title="연결 오류">
    - `options.baseURL`이 `https://api.tokenlab.sh/v1`로 설정되어 있는지 확인하세요
    - 네트워크 연결 상태를 확인하세요
    - 테스트를 위해 `curl https://api.tokenlab.sh/v1/models`를 시도해 보세요
  </Accordion>

  <Accordion title="인증 실패">
    - `TOKENLAB_API_KEY` 환경 변수가 설정되어 있는지 확인하세요
    - `options.apiKey`가 `{env:TOKENLAB_API_KEY}` 또는 다른 유효한 secret source를 참조하는지 확인하세요
    - 키가 `sk-`로 시작하는지 확인하세요
    - TokenLab dashboard에서 키가 활성 상태인지 확인하세요
  </Accordion>

  <Accordion title="모델을 찾을 수 없음">
    - config의 모델 이름이 정확히 일치하는지 확인하세요
    - [tokenlab.sh/en/models](https://tokenlab.sh/ko/models)에서 모델 사용 가능 여부를 확인하세요
  </Accordion>
</AccordionGroup>
