## 개요

OpenCode는 터미널에서 실행되는 오픈소스 AI 코딩 도우미입니다. 여러 LLM 제공자를 지원하며, 수백 개의 모델에 접근할 수 있도록 TokenLab API를 사용하도록 구성할 수 있습니다.

## 설치

[OpenCode](https://opencode.ai/docs/)

```bash
npm install -g opencode-ai
```

설치 확인:

```bash
opencode --version
```

## 구성

### 1단계: 환경 변수 설정

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

영구적으로 구성하려면 `~/.bashrc` 또는 `~/.zshrc`에 추가하세요:

```bash
echo 'export TOKENLAB_API_KEY="sk-your-tokenlab-key"' >> ~/.zshrc
source ~/.zshrc
```

### 2단계: OpenCode 구성

OpenCode의 현재 문서는 `opencode.json` 또는 `opencode.jsonc`를 통해 제공자를 구성할 것을 권장합니다. TokenLab의 경우, 내장된 `openai` 제공자를 덮어쓰는 대신 사용자 지정 제공자를 사용하세요:

지원되는 V1 제공자 형식의 예입니다. `~/.config/opencode/opencode.json`에 병합하고 기존 제공자와 권한을 유지하세요. V2도 지원되는 V1 설정을 읽지만 한 제공자 안에서 형식을 섞으면 안 됩니다. [공식 이전 안내](https://opencode.ai/v2/docs/migrate-v1/)를 참고하세요. `/models`로 등록을 확인한 뒤 유료 테스트와 TokenLab 기록을 비교합니다. 복구 시 이전 모델을 선택하고 이 항목만 제거하세요.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "tokenlab": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "TokenLab",
      "options": {
        "baseURL": "https://api.tokenlab.sh/v1",
        "apiKey": "{env:TOKENLAB_API_KEY}"
      },
      "models": {
        "gpt-5.6-terra": {
          "name": "GPT-5.6 Terra"
        },
        "gpt-5.6-luna": {
          "name": "GPT-5.6 Luna"
        }
      }
    }
  },
  "model": "tokenlab/gpt-5.6-terra"
}
```

<Note>
chat-completions 스타일 호환성을 위해 `@ai-sdk/openai-compatible`를 사용하세요. `/v1/responses` 기반 경로가 특별히 필요한 경우, OpenCode 문서에서는 패키지를 `@ai-sdk/openai`로 변경할 것을 권장합니다.
</Note>

## 기본 사용법

**대화형 모드 시작:**

```bash
opencode
```

**프롬프트와 함께 실행:**

```bash
opencode run "Explain this codebase"
```

**모델 지정:**

```bash
opencode run --model tokenlab/gpt-5.6-terra "Fix the bugs in main.py"
```

## 사용 가능한 모델

| 모델 | 적합한 용도 |
|-------|----------|
| `gpt-5.6-terra` | 복잡한 작업, 코드 아키텍처 |
| `gpt-5.6-luna` | 빠른 수정, 간단한 질의 |
| `claude-sonnet-4-6` | 코드 리뷰, 문서화 |
| `claude-opus-4-6` | 복잡한 추론 |
| `gemini-3.5-flash` | 빠른 응답 |

## 자주 사용하는 명령어

**코드 분석:**

```bash
opencode run "What does this function do?" < src/utils.ts
```

**코드 생성:**

```bash
opencode run "Create a REST API with Express"
```

**변경 사항 검토:**

```bash
git diff | opencode run "Review these changes"
```

**오류 수정:**

```bash
opencode run "Fix the TypeScript errors in this project"
```

## 대화형 명령어

| 명령어 | 설명 |
|---------|-------------|
| `/help` | 사용 가능한 명령어 표시 |
| `/models` | 다른 모델로 전환 |
| `/clear` | 대화 기록 지우기 |
| `/exit` | OpenCode 종료 |

## 문제 해결

<AccordionGroup>
  <Accordion title="연결 오류">
    - `options.baseURL`이 `https://api.tokenlab.sh/v1`로 설정되어 있는지 확인하세요
    - 네트워크 연결 상태를 확인하세요
    - 테스트를 위해 `curl https://api.tokenlab.sh/v1/models`를 시도해 보세요
  </Accordion>

  <Accordion title="인증 실패">
    - `TOKENLAB_API_KEY` 환경 변수가 설정되어 있는지 확인하세요
    - `options.apiKey`가 `{env:TOKENLAB_API_KEY}` 또는 다른 유효한 secret source를 참조하는지 확인하세요
    - 키가 `sk-`로 시작하는지 확인하세요
    - TokenLab dashboard에서 키가 활성 상태인지 확인하세요
  </Accordion>

  <Accordion title="모델을 찾을 수 없음">
    - config의 모델 이름이 정확히 일치하는지 확인하세요
    - [tokenlab.sh/en/models](https://tokenlab.sh/ko/models)에서 모델 사용 가능 여부를 확인하세요
  </Accordion>
</AccordionGroup>
