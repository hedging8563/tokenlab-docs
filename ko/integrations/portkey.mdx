## 개요

Portkey에서 TokenLab을 OpenAI 호환 사용자 지정 호스트로 설정하세요. 사용 중인 Portkey 버전이 사용자 지정 Responses 엔드포인트를 지원할 때만 Responses를 사용하세요.

## 공급자 값

| 필드 | 값 |
|-------|-------|
| Provider | `openai` |
| Custom Host | `https://api.tokenlab.sh/v1` |
| API key | `sk-your-tokenlab-key` |
| 모델 | 현재 사용 가능한 TokenLab 모델 ID |

## 채팅 완성 (Chat Completions)

OpenAI 호환 채팅 요청에 TokenLab을 사용하십시오:

이 예제에는 실행 중인 자체 호스팅 Portkey Gateway가 필요합니다. 게이트웨이 URL을 실제 배포 주소로 바꾸세요. Portkey Cloud에서는 `x-portkey-api-key` 헤더로 Portkey API 키도 전송해야 합니다. [Portkey 설정 가이드](https://portkey.ai/docs/api-reference/inference-api/headers)를 참고하세요.

```bash
curl https://your-portkey-gateway.example/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "x-portkey-provider: openai" \
  -H "x-portkey-custom-host: https://api.tokenlab.sh/v1" \
  -H "Authorization: Bearer sk-your-tokenlab-key" \
  -d '{
    "model": "gpt-5.6-luna",
    "messages": [{"role": "user", "content": "Say hello from TokenLab."}]
  }'
```

## 응답 (Responses)

사용 중인 Portkey 버전이 사용자 지정 Responses URL을 지원한다면 [모델 페이지](https://tokenlab.sh/ko/models)에서 현재 사용 가능한 Responses 지원 모델을 선택하고 `/v1/responses`를 사용하세요.

## 네이티브 엔드포인트 참고 사항

Anthropic Messages와 Gemini는 사용 중인 Portkey 버전이 해당 형식의 사용자 지정 URL을 지원할 때만 Portkey를 통해 사용할 수 있습니다.
