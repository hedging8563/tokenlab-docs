## 개요

Gemini CLI **0.60.0**은 API 키 인증용 `GOOGLE_GEMINI_BASE_URL`을 공식 문서에 설명합니다. `gemini_generate_content`를 지원하는 현재 모델과 TokenLab의 Gemini 네이티브 엔드포인트를 사용하세요. [공식 구성](https://geminicli.com/docs/reference/configuration/)과 [인증 안내](https://geminicli.com/docs/get-started/authentication/)를 참고하세요. Google 구독을 TokenLab으로 연결하는 설정은 아닙니다.

## 설치

```bash
npm install -g @google/gemini-cli@0.60.0
gemini --version
```

## 구성

[빠른 시작](/ko/quickstart)의 macOS, Linux, WSL 또는 Windows PowerShell 절차로 키를 명령 기록에 남기지 않고 `TOKENLAB_API_KEY`를 설정한 뒤 같은 터미널에서 Gemini CLI를 실행하세요. 계속 사용하려면 로컬 비밀 관리 도구를 이용하고 셸 프로필에 평문 키를 추가하지 마세요.

현재 Google 로그인과 구성을 유지하세요. TokenLab용으로 사용하지 않는 구성 루트 `~/.gemini-tokenlab`(PowerShell의 `$HOME`) 등을 선택하고 그 안에 `.gemini`를 만드세요. 기존 `.gemini/settings.json`과 필요한 정책 파일을 대응하는 위치에 복사하고 권한, 샌드박스와 다른 설정을 유지하세요. 복사본에만 아래 인증 필드를 병합하며 파일이 없으면 만드세요. OAuth 캐시를 복사하거나 원래 자격 증명을 삭제하지 마세요. 관리되는 인증 정책을 준수하세요.

```json
{
  "security": {
    "auth": {
      "selectedType": "gemini-api-key"
    }
  }
}
```

## 사용법

아래 실행은 `~/.gemini-tokenlab/.gemini/settings.json`을 사용합니다. 다른 루트를 선택했다면 경로를 수정하세요. 일반적인 신뢰 프롬프트로 작업 폴더를 확인하고 기존 도구 승인 정책을 유지하세요. 모델은 이번 세션에 명시적으로 선택됩니다.

<CodeGroup>
```bash macOS / Linux / WSL
GEMINI_CLI_HOME="$HOME/.gemini-tokenlab" GEMINI_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" GOOGLE_GEMINI_BASE_URL=https://api.tokenlab.sh gemini --model gemini-3.5-flash
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['GEMINI_CLI_HOME'] = [Environment]::GetEnvironmentVariable('GEMINI_CLI_HOME', 'Process')
$previous['GEMINI_API_KEY'] = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY', 'Process')
$previous['GOOGLE_GEMINI_BASE_URL'] = [Environment]::GetEnvironmentVariable('GOOGLE_GEMINI_BASE_URL', 'Process')
try {
  $env:GEMINI_CLI_HOME = (Join-Path $HOME '.gemini-tokenlab')
  $env:GEMINI_API_KEY = $env:TOKENLAB_API_KEY
  $env:GOOGLE_GEMINI_BASE_URL = 'https://api.tokenlab.sh'
  gemini --model gemini-3.5-flash
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

이 변수는 이번 시작에만 적용되며 저장된 계정, 기본 모델과 권한은 유지됩니다. 이전 구성을 사용하려면 이 변수 없이 정상적으로 시작하세요. 셸 프로필에 저장하지 마세요.

## 확인

설정 저장이나 모델 목록은 키 유효성이나 요청 완료를 검증하지 않습니다. 프롬프트는 TokenLab 잔액을 사용합니다. 도구를 시험하기 전에 응답과 해당 [요청 기록](https://tokenlab.sh/dashboard/runs?section=requests)을 확인하세요. 보조 요청도 청구될 수 있습니다.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
