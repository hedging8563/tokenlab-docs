## 개요

LangBot은 OpenAI 호환 LLM 요청자를 통해 TokenLab을 호출할 수 있습니다.

<Note>
**유형**: 봇 플랫폼

**기본 경로**: OpenAI 호환 채팅 완성(Chat Completions)

**지원 신뢰도**: 범위 제한 내 지원
</Note>

## TokenLab 요청자

LangBot 빌드에 **TokenLab** 요청자가 포함된 경우:

1. LangBot의 모델 공급자 설정을 엽니다.
2. 요청자로 **TokenLab**을 사용하는 공급자를 추가합니다.
3. API 키를 TokenLab 키로 설정합니다.
4. `gpt-5.4-mini`와 같은 모델을 선택하거나 생성합니다.
5. 해당 모델을 사용할 파이프라인이나 봇에 연결합니다.

## OpenAI 호환 대체 방법

TokenLab이 아직 목록에 없는 경우, OpenAI 호환 요청자를 사용하세요:

| 필드 | 값 |
|-------|-------|
| 요청자 | OpenAI Chat Completions |
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model | `gpt-5.4-mini` |

## 권장 모델

- `gpt-5.4-mini`: 대부분의 봇 상호작용용
- `claude-sonnet-5`: 긴 글쓰기 및 추론용
- `deepseek-v4-flash`: 빠른 코딩 및 추론 루프용
- `gemini-3.5-flash`: 빠른 일반 워크플로우용
