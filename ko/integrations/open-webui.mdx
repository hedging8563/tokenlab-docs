## 개요

Open WebUI는 사용자 지정 OpenAI 호환 API 연결을 지원합니다. TokenLab을 원격 OpenAI 호환 엔드포인트로 추가하고 모델 목록을 새로고침하세요.

<Note>
**유형**: 웹 채팅 앱

**기본 경로**: OpenAI 호환 채팅 완성(chat completions)

**지원 신뢰도**: 지원되는 채팅 앱 경로
</Note>

## 관리자 연결

1. **Admin Panel** -> **Settings** -> **Connections**를 엽니다.
2. OpenAI API 연결 영역에서 연결을 추가합니다.
3. 기본 URL(base URL)을 `https://api.tokenlab.sh/v1`로 설정합니다.
4. API 키를 본인의 TokenLab 키로 설정합니다.
5. 연결을 저장하고 모델을 새로고침합니다.

## 값

| 필드 | 값 |
|-------|-------|
| API Base URL | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| 예시 모델 | `gpt-5.4-mini` |

## 권장 모델

- 일반 채팅용 `gpt-5.4-mini`
- 글쓰기 및 추론용 `claude-sonnet-5`
- 코드 중심 채팅용 `deepseek-v4-pro`
- 빠른 멀티모달 친화적 워크플로우용 `gemini-3.5-flash`

배포 환경에서 모델 검색이 비활성화되어 있거나 캐시된 경우, Open WebUI의 모델 설정에서 모델 ID를 수동으로 추가하세요.
