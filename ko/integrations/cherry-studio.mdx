## 개요

Cherry Studio는 사용자 지정 OpenAI 호환 공급자를 통해 TokenLab을 사용할 수 있습니다. Cherry Studio 버전에 공급자 레지스트리에 TokenLab이 포함되어 있는 경우, TokenLab을 직접 선택하십시오.

<Note>
**유형**: 채팅 앱

**기본 경로**: OpenAI 호환 채팅 완성(Chat completions)

**네이티브 경로**: Responses, Anthropic Messages, 클라이언트에서 노출되는 Gemini 호환 엔드포인트
</Note>

## 사용자 지정 공급자로 구성

1. **Settings** -> **Model Provider**를 엽니다.
2. OpenAI 호환 공급자를 추가합니다.
3. 다음을 입력합니다:
   - **Name**: TokenLab
   - **API Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. `gpt-5.4-mini`와 같은 모델을 추가합니다.
5. 설정 대화상자에서 **Verify and Enable**을 완료합니다. 수동 설정이라면 저장하고 공급자가 활성화되었는지 확인하세요.
6. 추가한 모델을 선택하고 짧은 테스트 메시지를 보냅니다.

## 공급자 레지스트리 경로

Cherry Studio에 TokenLab이 내장 공급자로 표시되는 경우 해당 옵션을 우선적으로 사용하십시오. 다음을 위한 엔드포인트 메타데이터를 포함할 수 있습니다:

- OpenAI 호환 채팅 완성(Chat completions)
- OpenAI Responses
- Anthropic Messages
- Gemini generateContent

## 추천 시작 모델

기본 모델로 `gpt-5.4-mini`를 사용하고, 더 넓은 커버리지를 위해 `claude-sonnet-5`, `gemini-3.5-flash`, `deepseek-v4-flash`를 추가하십시오.
