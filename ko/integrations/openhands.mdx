## 개요

OpenHands는 LiteLLM/OpenAI 호환 모델 구성을 통해 TokenLab을 사용할 수 있습니다. 특히 모델, API 키, 베이스 URL을 직접 제공해야 하는 CLI 및 헤드리스 워크플로우에서 유용합니다.

<Note>
**유형**: 코딩 에이전트

**주요 경로**: OpenAI 호환 모델 구성

**지원 신뢰도**: 커스텀 엔드포인트 경로 지원
</Note>

## 환경 설정

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 모델 설정

다음과 같이 사용하세요:

```text
Model: openai/claude-sonnet-5
API key: sk-your-tokenlab-key
Base URL: https://api.tokenlab.sh/v1
```

`openai/` 접두사는 LiteLLM 기반 경로에 OpenAI 호환 공급자 구성을 사용하도록 지시합니다.

## 헤드리스 설정

CLI 또는 헤드리스 사용을 위해 로컬 기본값을 준비하는 경우, OpenHands 설정 흐름을 실행하고 다음을 입력하세요:

```bash
make setup-config
```

모델 세부 정보를 묻는 메시지가 나타나면 `openai/` 접두사가 붙은 TokenLab 모델 ID와 TokenLab의 `/v1` 베이스 URL을 사용하세요.

## 모델 제안

코딩 에이전트 계획에는 `claude-sonnet-5` 또는 `gpt-5.4`를 사용하고, 더 빠른 루틴 반복 작업에는 `gpt-5.4-mini`를, 강력한 대체 추론 모델이 필요할 때는 `deepseek-v4-pro`를 사용하는 것을 권장합니다.
