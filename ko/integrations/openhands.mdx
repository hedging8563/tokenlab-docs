## 개요

이 페이지는 LiteLLM을 사용하는 OpenHands UI의 **Settings → LLM → Advanced** 경로를 설명합니다. **OpenAI**를 선택하고 `openai/` 접두사가 있는 사용자 모델, 로컬 키 필드의 TokenLab 키, 아래 Base URL을 입력하세요. 이전 선택을 기록하고 끝나면 복원하세요. 계정과 도구 권한은 유지하세요. [공식 OpenAI 호환 설정](https://docs.openhands.dev/openhands/usage/llms/openai-llms)을 참고하세요. CLI, 클라우드, 소스 설치는 절차가 다를 수 있으므로 설치한 버전의 안내를 따르세요. `make setup-config`는 설치된 CLI의 일반 명령이 아닙니다.

## 모델 설정

편집 전에 현재 제공자, 모델과 연결 설정을 로컬에 저장하세요. 이 설정은 활성 모델을 변경하므로 사용 후 이전 값으로 복원하세요. 로그인한 계정과 도구 권한은 유지하세요. 복원 가능한 백업 없이 기존 OpenAI 호환 연결을 덮어쓰지 마세요.

```text
Custom Model: openai/kimi-k3
Base URL: https://api.tokenlab.sh/v1
```

설정 저장이나 모델 목록은 키 유효성이나 요청 완료를 검증하지 않습니다. 프롬프트는 TokenLab 잔액을 사용합니다. 도구를 시험하기 전에 응답과 해당 [요청 기록](https://tokenlab.sh/dashboard/runs?section=requests)을 확인하세요. 보조 요청도 청구될 수 있습니다.

```text
Reply only with TOKENLAB_CONNECTION_OK. Do not use tools or modify files.
```
