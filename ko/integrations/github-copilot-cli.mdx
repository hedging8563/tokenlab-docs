## 개요

[GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models)는 OpenAI Chat Completions 호환 엔드포인트에 연결할 수 있습니다.

## 설치 및 설정

```bash
npm install -g @github/copilot@1.0.85
copilot --version
```

npm 설치에는 Node.js 22 이상이 필요합니다.

[빠른 시작](/ko/quickstart)의 macOS, Linux, WSL 또는 Windows PowerShell 절차로 키를 명령 기록에 남기지 않고 `TOKENLAB_API_KEY`를 설정한 뒤 같은 터미널에서 Copilot CLI를 실행하세요. 계속 사용하려면 로컬 비밀 관리 도구를 이용하고 셸 프로필에 평문 키를 추가하지 마세요.

이 변수는 이번 시작에만 적용되며 저장된 계정, 기본 모델과 권한은 유지됩니다. 이전 구성을 사용하려면 이 변수 없이 정상적으로 시작하세요. 셸 프로필에 저장하지 마세요.

<CodeGroup>
```bash macOS / Linux / WSL
COPILOT_PROVIDER_TYPE=openai COPILOT_PROVIDER_BASE_URL=https://api.tokenlab.sh/v1 COPILOT_PROVIDER_API_KEY="${TOKENLAB_API_KEY:?Set TOKENLAB_API_KEY first}" copilot --model kimi-k3
```

```powershell Windows PowerShell
if (-not $env:TOKENLAB_API_KEY) { throw 'Set TOKENLAB_API_KEY first' }
$previous = @{}
$previous['COPILOT_PROVIDER_TYPE'] = [Environment]::GetEnvironmentVariable('COPILOT_PROVIDER_TYPE', 'Process')
$previous['COPILOT_PROVIDER_BASE_URL'] = [Environment]::GetEnvironmentVariable('COPILOT_PROVIDER_BASE_URL', 'Process')
$previous['COPILOT_PROVIDER_API_KEY'] = [Environment]::GetEnvironmentVariable('COPILOT_PROVIDER_API_KEY', 'Process')
try {
  $env:COPILOT_PROVIDER_TYPE = 'openai'
  $env:COPILOT_PROVIDER_BASE_URL = 'https://api.tokenlab.sh/v1'
  $env:COPILOT_PROVIDER_API_KEY = $env:TOKENLAB_API_KEY
  copilot --model kimi-k3
} finally {
  foreach ($name in $previous.Keys) {
    [Environment]::SetEnvironmentVariable($name, $previous[$name], 'Process')
  }
}
```
</CodeGroup>

Copilot CLI 모델은 스트리밍과 도구 호출을 모두 지원해야 합니다. `kimi-k3`는 도구 사용과 GitHub 권장 128K보다 큰 컨텍스트를 지원합니다.

시작한 뒤 파일을 수정하지 않고 저장소 구조를 확인하는 읽기 전용 작업으로 검증하세요. 모델을 찾을 수 없다면 [TokenLab 실시간 모델 목록](https://tokenlab.sh/ko/models)의 모델 ID를 사용하고 공급자 접두사를 추가하지 마세요.

<Warning>
API Key를 Git으로 추적하는 파일에 저장하지 마세요. 터미널 기록, 스크린샷 또는 로그에 노출된 Key는 교체하세요.
</Warning>

설정 저장이나 모델 목록은 키 유효성이나 요청 완료를 검증하지 않습니다. 프롬프트는 TokenLab 잔액을 사용합니다. 도구를 시험하기 전에 응답과 해당 [요청 기록](https://tokenlab.sh/dashboard/runs?section=requests)을 확인하세요. 보조 요청도 청구될 수 있습니다.
