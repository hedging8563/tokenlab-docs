## 개요

<Note>
**유형**: IDE 및 CLI 코딩 에이전트

**기본 경로**: OpenAI 호환 Chat Completions

**지원 수준**: 공식 사용자 지정 공급자 경로
</Note>

[Kilo Code](https://kilo.ai/docs/ai-providers/openai-compatible)의 VS Code 확장과 Kilo CLI는 동일한 OpenAI 호환 설정을 사용할 수 있습니다.

## 설치 및 UI 설정

VS Code에서 **Kilo Code** 프리릴리스 채널을 설치하거나 CLI를 설치합니다.

```bash
npm install -g @kilocode/cli
kilo --version
```

**Settings → Providers → Custom provider**를 엽니다.

| 필드 | 값 |
|---|---|
| Provider ID | `tokenlab` |
| Display name | `TokenLab` |
| Provider API | **OpenAI Compatible** |
| Base URL | `https://api.tokenlab.sh/v1` |
| API key | TokenLab API Key |
| Model | `kimi-k3` |

Kilo는 `/v1/models`에서 모델을 자동 감지합니다. 저장한 뒤 `tokenlab/kimi-k3`를 선택하세요.

## CLI 설정

Key를 환경 변수에 저장하고 신뢰할 수 있는 전역 설정 `~/.config/kilo/kilo.jsonc`를 편집합니다.

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "openai-compatible/kimi-k3",
  "provider": {
    "openai-compatible": {
      "options": {
        "apiKey": "{env:TOKENLAB_API_KEY}",
        "baseURL": "https://api.tokenlab.sh/v1"
      },
      "models": {
        "kimi-k3": {
          "name": "Kimi K3",
          "tool_call": true,
          "reasoning": true,
          "limit": { "context": 1048576, "output": 131072 }
        }
      }
    }
  }
}
```

재시작 후 `kilo models`를 실행하세요. `{env:...}`는 신뢰할 수 있는 전역 또는 관리 설정에서만 해석됩니다. 실제 Key를 Git에 커밋될 수 있는 프로젝트 설정에 쓰지 마세요.
