## 개요

Pydantic AI는 `OpenAIChatModel` 및 `OpenAIProvider(base_url=...)`를 통해 TokenLab을 사용할 수 있습니다.

<Note>
**유형**: 에이전트 프레임워크

**기본 경로**: OpenAI 호환 채팅 완성(Chat Completions)

**지원 신뢰도**: 지원되는 OpenAI 호환 제공자 경로
</Note>

## 환경 설정

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
```

## 기본 에이전트

```python
import os

from pydantic_ai import Agent
from pydantic_ai.models.openai import OpenAIChatModel
from pydantic_ai.providers.openai import OpenAIProvider

model = OpenAIChatModel(
    "claude-sonnet-5",
    provider=OpenAIProvider(
        base_url="https://api.tokenlab.sh/v1",
        api_key=os.environ["TOKENLAB_API_KEY"],
    ),
)

agent = Agent(model)
result = agent.run_sync("Explain one benefit of OpenAI-compatible gateways.")
print(result.output)
```

## 도구(Tools)

```python
from pydantic_ai import Agent, RunContext

agent = Agent(model)

@agent.tool
def lookup_status(ctx: RunContext[None], service: str) -> str:
    return f"{service} is online"

result = agent.run_sync("Check the TokenLab status.")
print(result.output)
```

## 엔드포인트 참고 사항

이 경로는 Pydantic AI의 OpenAI Chat Completions 모델 클래스를 대상으로 합니다. Responses-native 또는 제공자 고유의 프로토콜 동작을 사용하려면 해당 프로토콜을 직접 노출하는 클라이언트 경로를 선택하십시오.
