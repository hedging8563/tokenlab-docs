## 개요

Chatbox는 OpenAI 호환 API 설정을 통해 TokenLab을 사용할 수 있습니다.

## Chatbox 구성

1. **Settings** -> **Model Provider** -> **Add** -> **Add Custom Provider**을 엽니다.
2. **Name**은 TokenLab, **API Mode**는 **OpenAI API Compatible**로 설정한 다음 **Add**를 클릭합니다.
3. 다음을 입력합니다:
   - **API Host**: `https://api.tokenlab.sh/v1`
   - **API Path**: `/chat/completions`
   - **API Key**: `sk-your-tokenlab-key`
   - **Model**: `gpt-5.4-mini`
4. 저장 후 짧은 테스트 메시지를 보냅니다.

## 권장 모델

| 사용 사례 | 모델 |
|----------|-------|
| 일상적인 채팅 | `gpt-5.4-mini` |
| 더 강력한 추론 | `gpt-5.4` 또는 `gpt-5.5` |
| Claude 스타일 출력 | `claude-sonnet-5` |
| 빠른 대체 모델 | `deepseek-v4-flash` |

## 참고 사항

사용 중인 Chatbox 빌드에 TokenLab이 내장 공급자로 이미 나열되어 있다면, 이를 직접 선택하십시오. 그렇지 않은 경우, 위에서 설명한 OpenAI 호환 공급자 경로가 가장 안전한 대체 방법입니다.
