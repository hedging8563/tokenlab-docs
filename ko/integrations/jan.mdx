## 개요

Jan은 원격 OpenAI 호환 공급자로 TokenLab에 연결할 수 있습니다.

<Note>
**유형**: 채팅 앱

**기본 경로**: OpenAI 호환 채팅 완성(Chat Completions)

**지원 신뢰도**: 지원되는 경로
</Note>

## Jan 구성하기

1. **Settings** -> **Providers**를 엽니다.
2. 원격 OpenAI 호환 공급자를 추가합니다.
3. 다음을 입력합니다:
   - **Name**: TokenLab
   - **Base URL**: `https://api.tokenlab.sh/v1`
   - **API Key**: `sk-your-tokenlab-key`
4. `gpt-5.4-mini`를 추가하거나 선택합니다.
5. 저장하고 새 스레드를 시작합니다.

## 모델 탐색

TokenLab은 다음 경로에서 모델 탐색을 제공합니다:

```text
https://api.tokenlab.sh/v1/models
```

사용 중인 Jan 빌드가 TokenLab에 대한 원격 모델 탐색을 지원하는 경우, 모델 목록을 새로고침하세요. 그렇지 않은 경우 모델 ID를 수동으로 추가하십시오.

## 권장 모델

- `gpt-5.4-mini`
- `gpt-5.4`
- `claude-sonnet-5`
- `gemini-3.5-flash`
- `deepseek-v4-flash`
