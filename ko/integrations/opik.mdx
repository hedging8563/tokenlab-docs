## 개요

Opik은 TokenLab의 OpenAI 호환 엔드포인트를 가리키는 OpenAI 클라이언트를 래핑하여 TokenLab 호출을 로깅할 수 있습니다.

## 설치

```bash
pip install opik openai
```

## 환경 설정

```bash
export TOKENLAB_API_KEY="sk-your-tokenlab-key"
export OPIK_PROJECT_NAME="tokenlab-integration-demo"
```

## OpenAI 클라이언트 래핑

예제를 실행하기 전에 Opik을 설정하세요. Opik Cloud에는 `OPIK_API_KEY`가 필요하며 필요한 경우 `OPIK_WORKSPACE`도 지정합니다. 기존 자체 호스팅 배포에서는 `OPIK_URL_OVERRIDE`를 API URL(예: `http://localhost:5173/api`)로 설정하세요. [Opik 설정 가이드](https://www.comet.com/docs/opik/tracing/advanced/sdk_configuration)를 참고하세요.

```python
import os

from openai import OpenAI
from opik.integrations.openai import track_openai

client = OpenAI(
    api_key=os.environ["TOKENLAB_API_KEY"],
    base_url="https://api.tokenlab.sh/v1",
)

openai_client = track_openai(client)
```

## 채팅 완료(Chat Completion) 로깅

```python
completion = openai_client.chat.completions.create(
    model="claude-sonnet-5",
    messages=[
        {"role": "user", "content": "Summarize why LLM observability matters."}
    ],
)

print(completion.choices[0].message.content)
```

## 엔드포인트 참고 사항

이 설정은 OpenAI 호환 SDK 경로를 추적합니다. OpenAI SDK 외부에서 TokenLab 네이티브 엔드포인트를 사용하는 경우, 해당 클라이언트나 워크플로우를 별도로 계측하십시오.
