## 개요

[Cline](https://docs.cline.bot/provider-config/openai-compatible)은 IDE 설정에서 OpenAI 호환 공급자를 지원합니다.

## TokenLab 설정

편집 전에 현재 제공자, 모델과 연결 설정을 로컬에 저장하세요. 이 설정은 활성 모델을 변경하므로 사용 후 이전 값으로 복원하세요. 로그인한 계정과 도구 권한은 유지하세요. 복원 가능한 백업 없이 기존 OpenAI 호환 연결을 덮어쓰지 마세요.

1. 편집기 확장 마켓에서 **Cline**을 설치하고 Cline 패널을 엽니다.
2. 톱니바퀴를 클릭하고 **API Provider**에서 **OpenAI Compatible**을 선택합니다.
3. 다음 값을 입력합니다.

| 필드 | 값 |
|---|---|
| Base URL | `https://api.tokenlab.sh/v1` |
| API Key | TokenLab API Key |
| Model ID | `kimi-k3` |

4. **Verify**를 클릭합니다.

검증 후에는 파일을 수정하지 않고 작업 공간을 설명하는 읽기 전용 작업으로 시작하세요. 404가 발생하면 Base URL이 `/v1`로 끝나고 `/chat/completions`가 포함되지 않았는지 확인하세요. 모델 ID는 `kimi-k3`입니다.

설정 저장이나 모델 목록은 키 유효성이나 요청 완료를 검증하지 않습니다. 프롬프트는 TokenLab 잔액을 사용합니다. 도구를 시험하기 전에 응답과 해당 [요청 기록](https://tokenlab.sh/dashboard/runs?section=requests)을 확인하세요. 보조 요청도 청구될 수 있습니다.
