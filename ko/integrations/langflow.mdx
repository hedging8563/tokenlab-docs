## 개요

Langflow의 **OpenAI** 컴포넌트에는 **OpenAI API Base** 필드가 포함되어 있습니다. 해당 필드를 TokenLab의 OpenAI 호환 `/v1` 엔드포인트로 지정하고 TokenLab 모델 ID를 사용하십시오.

<Note>
**유형**: 로우코드 AI 워크플로우 빌더

**주요 경로**: OpenAI 호환 채팅 완성(Chat Completions)

**지원 신뢰도**: 범위 제한 내 지원
</Note>

## OpenAI 컴포넌트

1. **OpenAI** 언어 모델 컴포넌트를 추가합니다.
2. **OpenAI API Key**를 귀하의 TokenLab 키로 설정합니다.
3. 고급 설정을 확장합니다.
4. **OpenAI API Base**를 `https://api.tokenlab.sh/v1`로 설정합니다.
5. **Model Name**을 TokenLab 모델 ID로 설정합니다.
6. 모델 출력을 에이전트, 체인 또는 워크플로우에 연결합니다.

## 값

| 필드 | 값 |
|-------|-------|
| OpenAI API Base | `https://api.tokenlab.sh/v1` |
| OpenAI API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

## 권장 모델

- `gpt-5.4-mini`: 대부분의 워크플로우 테스트용
- `claude-sonnet-5`: 더 강력한 작문 및 추론용
- `gemini-3.5-flash`: 빠른 멀티모달 친화적 워크플로우용
- `deepseek-v4-flash`: 빠른 코딩 및 추론 반복 작업용

배포 환경에서 이미 LiteLLM 프록시를 통해 공급자 라우팅을 중앙 집중화하고 있다면 Langflow의 LiteLLM Proxy 컴포넌트를 사용하십시오.
