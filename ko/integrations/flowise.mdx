## 개요

Flowise는 사용 가능한 경우 TokenLab 채팅 노드를 통해, 또는 TokenLab을 가리키는 OpenAI 호환 채팅 모델 노드를 통해 TokenLab을 호출할 수 있습니다.

## TokenLab 노드

Flowise 빌드에 **TokenLab** 채팅 모델 노드가 포함되어 있는 경우:

1. **Chat Models** -> **TokenLab**을 추가합니다.
2. TokenLab API 자격 증명을 생성합니다.
3. **Model Name**을 `gpt-5.4-mini`로 설정합니다.
4. 체인, 에이전트 또는 워크플로우에 연결합니다.
5. 테스트 프롬프트를 실행합니다.

## OpenAI 호환 대체 방법

사용 중인 빌드에 TokenLab 노드가 없다면 **Chat Models** → **OpenAI Custom Model**을 추가합니다. **Connect Credential**에서 TokenLab 키로 **OpenAI API** 자격 증명을 만듭니다. **Model Name**과 **Additional Parameters** → **Base Path**를 다음과 같이 설정합니다.

| 필드 | 값 |
|-------|-------|
| Base Path | `https://api.tokenlab.sh/v1` |
| API Key | `sk-your-tokenlab-key` |
| Model Name | `gpt-5.4-mini` |

노드를 체인, 에이전트 또는 워크플로에 연결하고 테스트 프롬프트를 보냅니다.

## 권장 모델

- `gpt-5.4-mini`: 대부분의 워크플로우 테스트용
- `claude-sonnet-5`: 더 강력한 작문 및 추론용
- `gemini-3.5-flash`: 빠른 멀티모달 친화적 워크플로우용
- `deepseek-v4-flash`: 빠른 코드 또는 추론 반복 작업용
