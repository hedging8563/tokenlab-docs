## 지원 범위

macOS, Windows, Linux의 **Cursor 데스크톱 에디터**를 위한 안내입니다. 공식 OpenAI BYOK 지원 범위는 표준 비추론 채팅 모델이며, Tab 자동 완성은 Cursor 모델을 사용합니다. OpenAI Base URL을 바꾼다고 모든 TokenLab 모델이나 Cursor 기능을 사용할 수 있는 것은 아닙니다. [공식 제한 사항](https://cursor.com/help/models-and-usage/api-keys)을 확인하세요.

이미지·동영상 같은 API 도구만 필요하다면 기존 채팅 제공자를 유지하고 [MCP](/ko/integrations/tokenlab-mcp-server)를 추가하세요. [Skill](/ko/integrations/coding-agent-skill)은 API 사용 지침이며 주 모델을 바꾸지 않습니다.

## 기존 에이전트에 전달할 작업

```text
https://docs.tokenlab.sh/ko/integrations/cursor 문서를 읽고 설치된 버전과 운영 체제를 확인하세요.
TokenLab 주 모델, MCP 도구, API Skill 중 무엇이 필요한지 확인하세요.
기존 계정, 제공자 설정, 권한을 보존하고 변경을 복원하는 방법을 설명하세요.
채팅으로 API 키를 요구하지 마세요. 제가 로컬로 입력하고 필요한 UI 단계를 수행합니다.
작은 검증 요청의 비용을 설명하고, 제가 해당 테스트를 명시적으로 선택한 뒤에만 실행을 돕고 TokenLab 기록과 대조하세요.
```

## 올바른 설정 열기

1. [Cursor 다운로드](https://cursor.com/downloads)에서 데스크톱 버전을 설치하거나 업데이트합니다. CLI와 Cloud Agents는 이 안내의 대상이 아닙니다.
2. 명령 팔레트에서 **Cursor Settings**를 열거나 `Cmd/Ctrl + Shift + J`를 누릅니다. `Cmd/Ctrl + ,`는 일반 에디터 설정입니다.
3. **Models**에서 기존 OpenAI 키와 Base URL 설정을 복원할 수 있도록 기록하고 다른 제공자 설정을 유지합니다.
4. **OpenAI API Key**에 TokenLab 키를 로컬로 입력해 저장합니다. 채팅에 보내거나 git에 커밋하지 마세요.
5. **Override OpenAI Base URL**을 켜고 다음 값을 입력합니다.

```text
https://api.tokenlab.sh/v1
```

BYOK 요청도 프롬프트 구성을 위해 Cursor 서버를 통과합니다. 에디터가 TokenLab에 직접 연결되는 방식이 아닙니다.

## 모델 선택

현재 [TokenLab 모델 목록](https://tokenlab.sh/ko/models)에서 정확한 ID를 복사하고 Cursor의 OpenAI BYOK 경로가 해당 모델을 지원하는지 확인합니다. TokenLab에서 chat으로 분류된다고 Cursor 호환성이 보장되지는 않습니다.

첫 텍스트 검사에는 현재 제공 중이라면 비추론 모델 예시인 `gpt-4.1-mini`를 사용할 수 있습니다. **Models**의 기존 항목을 켜고, 없을 때만 **Add model**로 추가한 뒤 채팅에서 선택하세요. 내장 모델을 다른 철자로 중복 추가하지 마세요. Claude나 Gemini 항목이 OpenAI override를 사용한다고 가정하지 마세요. [Cursor 안내](https://forum.cursor.com/t/add-custom-model-fail-no-models-available/163488)를 참고하세요.

## 작은 요청 한 번으로 확인

선택한 모델로 새 채팅을 만들고 다음을 보냅니다.

```text
TOKENLAB_CONNECTION_OK만 답하세요. 도구를 사용하거나 파일을 수정하지 마세요.
```

이 요청에는 요금이 부과됩니다. 응답과 함께 [TokenLab 요청 기록](https://tokenlab.sh/dashboard/runs?section=requests)의 모델, 시간, 상태를 대조하세요. 모델이 표시되거나 응답이 왔더라도 해당 기록이 없다면 경로가 확인된 것이 아닙니다.

## 문제 해결

- **모델 누락 또는 거부:** 정확한 ID와 BYOK 지원 범위를 확인하고 내장 항목이 있으면 사용하세요. 재시작은 미지원 모델의 호환성을 해결하지 못합니다.
- **인증 오류:** OpenAI 필드의 TokenLab 키와 Base URL을 확인하세요. 잔액·할당량 오류는 잘못된 키와 별개입니다.
- **TokenLab 기록 없음:** 선택 모델, override, Cursor 오류를 확인하세요. Tab 자동 완성은 연결 검사가 아닙니다.
- **다른 제공자 오류:** 원래 OpenAI 설정으로 되돌리거나 override를 끄고 새 채팅을 시작하세요.

## MCP와 Skills 별도 추가

[MCP](/ko/integrations/tokenlab-mcp-server)는 호출 가능한 도구를 추가합니다. Cursor MCP 설정 또는 `.cursor/mcp.json`에서 구성하고, 도구 검색을 확인한 뒤 필요한 유료 생성을 실행하세요. 주 모델은 교체하지 않습니다.

[Skills](/ko/integrations/coding-agent-skill)는 API 사용 지침입니다. `SKILL.md`와 참조 파일을 포함한 전체 폴더를 `.cursor/skills/tokenlab-api-integration/`에 넣고 **Customize → Skills**에서 확인하세요. Skill은 키를 제공하거나 MCP 서버를 설치하지 않습니다. 버전별 설정은 공식 [MCP](https://cursor.com/docs/mcp) 및 [Skills](https://cursor.com/docs/skills) 문서를 참고하세요.
