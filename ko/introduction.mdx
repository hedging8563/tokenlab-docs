## TokenLab란?

TokenLab은 API 키 하나와 워크스페이스 공용 잔액으로 앱이나 코딩 도구를 AI 모델에 연결합니다. 모델과 지원 API 형식을 선택하면 공개된 요금에 따라 요청이 청구됩니다.

## 지원되는 기능

최신 모델 ID, 제공 여부, 지원 형식, 가격은 [모델 목록](https://tokenlab.sh/ko/models)에서 확인하세요.

| 기능 | 설명 |
|---|---|
| 채팅 및 추론 | 텍스트 생성, 계획, 도구 사용 |
| 비전 및 멀티모달 | 이미지 이해와 멀티모달 채팅 |
| 이미지 생성 및 편집 | 텍스트-이미지 생성과 이미지 편집 |
| 비디오 생성 | 텍스트/이미지/참조 비디오 기반 생성과 모션 제어 |
| 오디오 및 Realtime WebSocket | TTS, 전사, 오디오 번역, 실시간 WebSocket 세션 |
| Embeddings 및 rerank | 텍스트 벡터화와 재정렬 |
| 번역 | 텍스트 번역 및 WebSocket 음성 번역 워크플로 |
| 음악 및 3D | 음악과 3D asset 생성 |
| Worlds | World 생성, 상태 polling, media asset 워크플로 |
