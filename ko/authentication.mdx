## API 키

모델 호출과 비공개 리소스에는 API 키가 필요합니다. `GET /v1/models`, `GET /v1/models/{model}` 같은 공개 엔드포인트는 키 없이 사용할 수 있습니다. 목록 조회 성공으로 키의 유효성을 확인할 수는 없습니다. 빠른 시작에 따라 모델 요청을 보내세요. 목록의 접두사가 아닌 저장한 전체 키를 사용하세요.

OpenAI 호환 엔드포인트의 경우, 다음과 같이 전송합니다:

```bash
Authorization: Bearer sk-your-api-key
```

Anthropic 호환 `/v1/messages` 요청의 경우, 다음 헤더도 사용할 수 있습니다:

```bash
x-api-key: sk-your-api-key
```

## 관리 토큰

관리 API 엔드포인트는 별도의 토큰 유형을 사용합니다:

```bash
Authorization: Bearer mt-your-management-token
```

관리 토큰은 `/v1/management/*` 엔드포인트에만 사용하세요. 선택한 워크스페이스의 [API → Tokens](https://tokenlab.sh/dashboard/api?tab=tokens)에서 토큰을 생성하거나 교체할 수 있습니다. 생성 또는 교체 후 전체 토큰은 한 번만 표시되므로 즉시 안전하게 저장하세요.

<Note>
관리 토큰은 모델 추론에 사용할 수 없으며, 일반 `sk-...` API 키는 관리 API에 사용할 수 없습니다.
</Note>

## API 키 발급하기

1. [TokenLab Dashboard](https://tokenlab.sh/dashboard)에 로그인합니다
2. **API Keys**를 엽니다
3. 새 키를 생성합니다
4. 설명이 포함된 이름을 지정합니다
5. 키는 한 번만 표시되므로 즉시 복사합니다

<Warning>
- 클라이언트 측 코드에 API 키를 절대 노출하지 마세요
- API 키를 버전 관리에 절대 커밋하지 마세요
- 환경 변수 또는 secret manager를 사용하세요
- 주기적으로 키를 교체하세요
- 사용하지 않는 키는 삭제하세요
</Warning>

## API 키 사용하기

환경 변수와 첫 요청 예제는 [빠른 시작](/ko/quickstart)을 참고하세요. 선택한 [API 형식](/ko/guides/api-formats)에 맞는 SDK를 사용하고 키는 서버에서 관리하세요.

## API 키 기능

### 사용량 한도

각 API 키에 대해 사용량 한도를 설정할 수 있습니다:

| 설정 | 설명 |
|---------|-------------|
| **제한 없음** | 제한 없이 계정 잔액을 사용합니다 |
| **고정 한도** | 지정된 금액에 도달하면 키가 작동을 멈춥니다 |

### 키 접두사

모든 TokenLab API 키는 `sk-`로 시작합니다.

## 오류 응답

| 상태 코드 | 유형 | 코드 | 설명 |
|-------------|------|------|-------------|
| 401 | `invalid_api_key` | `invalid_api_key` | API 키가 없거나 유효하지 않거나 비활성화 또는 폐기됨 |
| 401 | `expired_api_key` | `expired_api_key` | API 키가 만료됨 |
| 402 | `insufficient_balance` | `insufficient_balance` | 계정 잔액이 부족합니다 |
| 402 | `quota_exceeded` | `quota_exceeded` | API 키 사용량 한도에 도달했습니다 |

예시:

```json
{
  "error": {
    "message": "Invalid API key provided",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```
