이미 Volcengine 형식 Seedance 요청을 보내는 애플리케이션을 위한 가이드입니다. Action 이름, `Version=2024-01-01`, `content[]`, PascalCase 소재 본문, Volcengine 응답 envelope을 유지할 수 있습니다. 변경해야 하는 것은 엔드포인트와 인증 방식입니다.

## 변경 사항

| 항목 | 기존 Volcengine 클라이언트 | TokenLab |
| --- | --- | --- |
| 기본 URL | `Volcengine API` | `https://api.tokenlab.sh/` |
| 인증 | `AK/SK` | `Authorization: Bearer <TOKENLAB_API_KEY>` |
| Action 요청 | `Action`, `Version` | `Action`, `Version` |
| 작업 본문 | `content[]` | `content[]` |
| 소재 본문 | `PascalCase` | `PascalCase` |
| 비동기 결과 | `작업 ID` | `cgt-...` + 폴링 |

AK/SK 서명만 있는 요청은 `401 AuthenticationError`을 반환합니다. Action 클라이언트는 `POST /?Action=...&Version=2024-01-01`을 사용할 수 있고, `POST /api/v3?Action=...&Version=2024-01-01`도 계속 지원됩니다. REST 작업 클라이언트는 `/api/v3/contents/generations/tasks`를 사용합니다.

## 요청 형식과 작업 수명 주기

이미 Volc 스타일 Seedance 요청을 보내는 통합이라면 `/v1/videos/generations` 형식으로 바꾸지 않고 호환 엔드포인트를 사용할 수 있습니다. TokenLab API Key를 `Authorization: Bearer ...`로 보내고, REST 생성은 `POST /api/v3/contents/generations/tasks`, Action 스타일은 `/api/v3?Action=CreateContentsGenerationsTasks&Version=2024-01-01`를 사용하세요. 생성 응답은 `cgt-...` 작업 ID를 반환하며 상태 응답은 `queued`, `running`, `succeeded`, `failed`, `cancelled`, `expired`를 사용합니다.

이 엔드포인트는 `content[]`의 `text`, `image_url`, `video_url`, `audio_url`, `draft_task`를 받습니다. `callback_url`에는 공개 HTTP(S) 주소를 지정할 수 있고 `queued`, `running`, `succeeded`, `failed`, `expired`로 바뀔 때마다 조회 객체와 같은 내용을 보냅니다. `succeeded`와 `failed`는 5초 후 최대 세 번 재시도합니다. 폴링을 복구 경로로 유지하세요.

v3에 `/v1/tasks/{id}` 응답 struct를 재사용하지 마세요. v1은 `pending`, `processing`, `completed`, `failed`를 사용하고 v3는 `queued`, `running`, `succeeded`, `failed`, `cancelled`, `expired`를 사용합니다. v3의 `duration`은 문자열이며 `error`는 실패할 때만 나타납니다.

연결이 끊긴 뒤 복구하려면 REST 생성에 고유한 `Idempotency-Key`를 보내세요. 같은 body와 key는 같은 `cgt-...` ID를 반환하고, 같은 key를 다른 body에 사용하면 `409`가 반환됩니다.

## 작업 Action

| Action | 항목 | JSON |
| --- | --- | --- |
| `CreateContentsGenerationsTasks` | 비디오 작업 생성 | `model`, `content[]` |
| `GetContentsGenerationsTask` | 작업 하나 조회 | `TaskId` |
| `ListContentsGenerationsTasks` | 작업 목록 조회 | 필터, 페이지네이션 |
| `DeleteContentsGenerationsTasks` | 작업 취소 또는 삭제 | `TaskId` |

## 최소 REST 예시

```bash
curl 'https://api.tokenlab.sh/api/v3/contents/generations/tasks' \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Idempotency-Key: $CLIENT_JOB_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"seedance-2.0",
    "content":[
      {"type":"text","text":"A cinematic product reveal"},
      {"type":"image_url","role":"reference_image","image_url":{"url":"https://example.com/reference.png"}}
    ],
    "ratio":"16:9",
    "duration":5,
    "resolution":"720p"
  }'
```

## 소재 및 실존 인물 인증

같은 Action 엔드포인트에서 10개의 소재 및 소재 그룹 작업도 지원합니다. PascalCase 본문, 필터, 페이지네이션, 응답 envelope, 12시간 소재 URL은 [Volcengine 호환 소재 Action](/ko/api-reference/video/volc-compatible-material-actions)을 참조하세요. 실존 인물 소재는 업로드 전에 [시각 인증 세션 생성](/ko/api-reference/video/create-visual-validation-session)과 [시각 인증 결과 조회](/ko/api-reference/video/get-visual-validation-result)도 필요합니다.

## 이전 체크리스트

1. API 호스트를 `https://api.tokenlab.sh`로 변경합니다.
2. AK/SK 서명을 TokenLab Bearer API Key로 교체합니다.
3. 기존 Action, 버전, 본문 대소문자를 유지합니다.
4. 관련 소재 및 인물 인증 요청에 같은 `ProjectName`을 사용합니다.
5. TokenLab이 반환한 작업, 그룹, 소재 ID를 저장합니다.
6. 프로덕션 트래픽 이전 전에 생성, 폴링, 목록, 오류 응답을 검증합니다.
