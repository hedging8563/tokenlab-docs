애플리케이션에 Seedance 2.0을 추가한다면 여기에서 시작하세요. 이 페이지는 모델과 워크플로 선택만 다루며, Volcengine 마이그레이션, 재사용 소재, 실존 인물 인증은 별도 가이드로 분리되어 있습니다.

## 통합 경로 선택

| 목표 | 사용 방식 | 다음 문서 |
| --- | --- | --- |
| 새 TokenLab 비디오 통합 구축 | 통합 `POST /v1/videos/generations` API | [비디오 생성 가이드](/ko/guides/video-generation) |
| 기존 Volcengine Seedance 클라이언트 이전 | Volcengine 호환 REST 또는 Action API | [Volcengine에서 Seedance 이전](/ko/guides/seedance-volcengine-migration) |
| 아바타, 제품, 스타일 또는 실존 인물 참조 재사용 | TokenLab 소재 라이브러리 | [Seedance 소재 및 실존 인물 인증](/ko/guides/seedance-materials) |

세 경로 모두 `Authorization: Bearer <TOKENLAB_API_KEY>`를 사용합니다. Volcengine 호환 경로는 요청 형식을 유지하지만 AK/SK 서명은 지원하지 않습니다.

## 모델 선택

| 모델 | 지원 해상도 |
|-------|-----------------------|
| `seedance-2.0` | `480p`, `720p`, `1080p`, `4k` |
| `seedance-2.0-fast` | `480p`, `720p` |
| `seedance-2.0-mini` | `480p`, `720p` |

`seedance-2.0-fast` 및 `seedance-2.0-mini`는 `1080p` 및 `4k` 요청을 거부합니다. 오디오는 지원되는 참조 워크플로우에서만 사용할 수 있으며, 순수 오디오 전용 또는 텍스트+오디오 전용 Seedance 요청은 지원되지 않습니다.

## 지원되는 작업 (Operations)

| 작업 | 일반적인 입력 |
|-----------|----------------|
| `text-to-video` | `prompt` |
| `image-to-video` | `prompt`, `image_url` 또는 호환되는 이미지 입력 |
| `start-end-to-video` | `prompt`, `start_image`, `end_image` |
| `reference-to-video` | `prompt`, `reference_images`, 선택적 `video_urls`, 선택적 `audio_urls` |
| `video-to-video` | `prompt`, `video_url` 또는 호환되는 비디오 입력 |
| `video-extension` | `task_id` 또는 모델별 연속 입력 |

## 가격 및 비동기 결과

Seedance 2.0 가격은 출력 해상도, 입력 유형 및 모델에 따라 다릅니다. 제품 UI를 하드코딩하기 전에 [Pricing API](/ko/api-reference/pricing/get-pricing) 또는 [Models API](/ko/api-reference/models/list-models)를 사용하세요.

비디오 생성은 비동기식입니다. 생성 요청 시 반환된 `poll_url`을 따르거나, 반환된 작업 ID와 함께 [작업 상태 가져오기](/ko/api-reference/tasks/get-task-status)를 사용하세요.
