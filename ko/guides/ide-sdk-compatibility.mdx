## 개요

TokenLab은 일반적인 코딩 도구, SDK 및 프레임워크가 최소한의 접착 코드(glue code)로 통합될 수 있도록 다양한 API 형식을 제공합니다.

이 페이지는 마케팅용 매트릭스보다 의도적으로 더 구체적인 정보를 담고 있습니다:

- **지원됨(Supported)**: 구체적인 설정 경로를 문서화했으며, TokenLab이 해당 경로에서 기대하는 프로토콜 형태를 노출함을 의미합니다.
- **강력한 네이티브 경로(Strong native path)**: 해당 리포지토리에 해당 프로토콜 제품군을 위한 직접적인 어댑터나 요청 형식 증거가 있음을 의미합니다.
- **최선형 지원(Best-effort)**: 통합이 작동할 수는 있지만, 업스트림 클라이언트가 이 사용자 지정 게이트웨이 워크플로우를 안정적인 계약으로 취급하지 않음을 의미합니다.

<Note>
  지원되지 않는 필드는 일관되게 처리되지 않습니다. 호환성 경로에서 일부 필드는 무시되거나 정규화됩니다. `/v1/responses` 경로에서는 해당 경로가 요청된 동작을 보장할 수 없을 때 명시적인 `400` 또는 `503` 오류를 반환할 수 있습니다.
</Note>

## 지원되는 API 형식

| 엔드포인트 | 형식 | 사용 사례 |
|----------|--------|----------|
| `/v1/chat/completions` | OpenAI Chat | 범용 호환성 |
| `/v1/responses` | OpenAI Responses | 상태 유지 대화 |
| `/v1/messages` | Anthropic Messages | Claude 네이티브 기능 |
| `/v1beta/models/:model:generateContent` | Google Gemini | Gemini 네이티브 기능 |

## IDE 및 CLI 호환성

### 문서화된 도구 경로

| 도구 | 지원 수준 | 형식 | 참고 사항 |
|------|---------------|--------|-------|
| **Cursor** | 제한적 지원 | OpenAI 호환 | BYOK 표준 채팅/에디터 흐름에는 작동하지만, Tab Completion과 같은 Cursor 관리 기능의 대체재로는 작동하지 않음 |
| **Claude Code CLI** | 강력한 네이티브 경로 | Anthropic | Thinking 및 `tool_choice`에 대한 어댑터 커버리지를 갖춘 네이티브 `/v1/messages` 경로 |
| **Codex CLI** | 모델/경로 제한적 지원 | OpenAI Responses | `/v1/responses`를 Codex 전용 워크플로우를 위한 고급 경로로 취급; 일부 Responses 전용 필드는 모든 모델 및 경로에서 보장되지 않음 |
| **Gemini CLI** | 최선형 / 실험적 | Gemini | 사용자 지정 TokenLab 베이스 URL 흐름은 공식 Gemini CLI 통합이 아님 |
| **OpenCode** | 지원됨 | OpenAI 호환 | 기본적으로 OpenAI 호환 공급자를 사용하고, 명시적으로 필요한 경우에만 Responses 기반 공급자로 전환 |
| **OpenHands** | 지원됨 | OpenAI 호환 | `openai/<model>` 및 TokenLab의 `/v1` 베이스 URL과 함께 LiteLLM/OpenAI 호환 경로 사용 |

<Note>
  다른 OpenAI 호환 에디터 및 에이전트 도구도 동일한 베이스 URL 패턴으로 작동하는 경우가 많습니다. 프로덕션 환경에서 사용하기 전에 해당 도구의 자체 사용자 지정 공급자 지원 여부를 확인하십시오.
</Note>

### 구성 예시

<Tabs>
  <Tab title="Cursor">

    - OpenAI 형식: `{ type: "function", function: { name, parameters } }`

  </Tab>

  </Tab>

## 채팅 완료(Chat Completions) 매개변수

### 핵심 매개변수

| 매개변수 | 유형 | 설명 |
|-----------|------|-------------|
| `model` | string | 모델 식별자 (필수) |
| `messages` | array | 대화 메시지 (필수) |
| `max_tokens` | integer | 최대 출력 토큰 |
| `temperature` | number | 샘플링 온도 (0-2) |
| `top_p` | number | 뉴클리어스 샘플링 (0-1) |
| `stream` | boolean | 스트리밍 활성화 |

### 도구 호출(Tool Calling)

```json
{
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "get_weather",
        "description": "Get weather for a location",
        "parameters": {
          "type": "object",
          "properties": {
            "location": { "type": "string" }
          }
        },
        "strict": true
      }
    }
  ],
  "tool_choice": "auto",
  "parallel_tool_calls": true
}
```

### 도구 선택 옵션

| 형식 | 예시 | 설명 |
|--------|---------|-------------|
| String | `"auto"`, `"none"`, `"required"` | 단순 선택 |
| OpenAI Object | `{ "type": "function", "function": { "name": "fn" } }` | 특정 함수 강제 |
| Anthropic Object | `{ "type": "tool", "name": "fn", "disable_parallel_tool_use": true }` | Anthropic 네이티브 형식 |

### 고급 매개변수

| 매개변수 | 유형 | 설명 |
|-----------|------|-------------|
| `stream_options` | object | Chat Completions 전용: 토큰 수 계산을 위한 `{ include_usage: true }` |
| `reasoning_effort` | string | 추론 활성화 GPT-5 모델을 위한 `"low"`, `"medium"`, `"high"` |
| `service_tier` | string | `"auto"` 또는 `"default"` |
| `seed` | integer | 결정론적 출력 |
| `logprobs` | boolean | 로그 확률 반환 |
| `top_logprobs` | integer | 상위 로그 확률 개수 (0-20) |
| `logit_bias` | object | 토큰 편향 맵 (-100 ~ 100) |
| `frequency_penalty` | number | 반복 페널티 (-2 ~ 2) |
| `presence_penalty` | number | 주제 페널티 (-2 ~ 2) |
| `stop` | string/array | 중지 시퀀스 |
| `n` | integer | 완료 개수 (1-128) |
| `user` | string | 추적을 위한 사용자 식별자 |

### OpenAI 고급 기능

| 매개변수 | 유형 | 설명 |
|-----------|------|-------------|
| `modalities` | array | 멀티모달을 위한 `["text", "audio"]` |
| `audio` | object | 오디오 출력 구성 (음성, 형식) |
| `prediction` | object | 더 빠른 완료를 위한 예측 출력 |
| `metadata` | object | 추적을 위한 키-값 쌍 |
| `store` | boolean | 나중에 검색할 수 있도록 저장 |

```json
    },
    "prompt_caching": true
  },
```

## Responses API 매개변수

### 핵심 매개변수

| 매개변수 | 유형 | 설명 |
|-----------|------|-------------|

| `max_output_tokens` | integer | 최대 출력 토큰 |

| 매개변수 | 유형 | 설명 |
|-----------|------|-------------|
| `truncation_strategy` | string | `"auto"` 또는 `"disabled"` |
| `include` | array | `["reasoning.encrypted_content"]` |
| `reasoning_effort` | string | 추론 모델용 |
| `service_tier` | string | 우선순위 계층 |

### 도구 형식

OpenAI 및 Anthropic 도구 형식을 모두 지원합니다:

```json
// OpenAI 형식
{ "type": "function", "name": "fn", "parameters": {...} }

// Anthropic 형식 (Cursor 호환성)
{ "name": "fn", "input_schema": {...} }
```

```json
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    }
  ]
}
```

### 추가 매개변수

| 매개변수 | 유형 | 설명 |
|-----------|------|-------------|
| `cachedContent` | string | 캐시된 콘텐츠 참조 |
| `responseMimeType` | string | `"text/plain"` 또는 `"application/json"` |
| `responseSchema` | object | 구조화된 출력을 위한 JSON 스키마 |

## 스트리밍

채팅 완료 및 Responses를 포함하여 `stream: true`를 노출하는 생성 엔드포인트는 서버 전송 이벤트(SSE)를 사용합니다:

```bash
# Chat Completions
curl https://api.tokenlab.sh/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model": "gpt-4o", "messages": [...], "stream": true}'

# Chat Completions 사용량 추적
-d '{"...", "stream_options": {"include_usage": true}}'
```

## 오류 처리

TokenLab은 OpenAI 호환 오류 응답을 반환합니다:

```json
{
  "error": {
    "message": "Invalid API key",
    "type": "invalid_api_key",
    "code": "invalid_api_key"
  }
}
```

자세한 내용은 [오류 처리 가이드](/guides/error-handling)를 참조하십시오.
