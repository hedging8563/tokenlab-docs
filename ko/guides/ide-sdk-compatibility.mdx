대부분의 도구는 API 키와 기본 URL을 변경해 TokenLab에 연결할 수 있습니다. 구체적인 설정은 도구에서 사용할 수 있는 API 형식에 따라 달라집니다.

| API 형식 | 기본 URL | 주요 클라이언트 |
| --- | --- | --- |
| Chat Completions (OpenAI 호환) | `https://api.tokenlab.sh/v1` | OpenAI SDK, 여러 채팅 앱 및 프레임워크 |
| OpenAI Responses | `https://api.tokenlab.sh/v1` | Responses 클라이언트 및 Responses 이벤트를 사용하는 도구 |
| Anthropic Messages | `https://api.tokenlab.sh` | Anthropic SDK 및 Claude용 도구 |
| Gemini | `https://api.tokenlab.sh` | 사용자 지정 호스트를 지원하는 Gemini REST 또는 SDK 클라이언트 |

선택한 모델의 `accepted_request_formats`에 같은 형식이 포함되어야 합니다. 스트리밍과 도구 호출도 모델 기능과 클라이언트 지원에 따라 달라집니다. 예시는 [API 형식](/ko/guides/api-formats)을 참고하세요.

## 호환성 상태

| 상태 | 의미 |
| --- | --- |
| **사용 가능** | 연결된 페이지의 TokenLab 설정은 클라이언트가 공식 문서에서 제공하는 설정 옵션을 사용합니다 |
| **일부 제한 있음** | 설정은 특정 기능이나 인증 방식에 적용되며, 공급업체의 다른 서비스에는 각각의 이용 조건이 적용됩니다 |

이 상태는 연결된 페이지의 설정 방식을 설명합니다. 실제 기능의 사용 가능 여부는 선택한 모델과 클라이언트 버전에도 달려 있습니다.

## 스트리밍 응답의 사용량

Chat Completions 스트림은 `stream_options: { include_usage: true }`를 허용하며 스트림이 끝나기 전에 마지막 사용량 청크를 추가합니다. Responses API는 `include_usage`를 제공하지 않으며, Responses 스트림은 종료 이벤트에 사용량을 포함합니다.

## 사용자 지정 API 키로 대체할 수 없는 항목

일부 제품은 모델 호출과 함께 공급업체가 호스팅하는 기능을 제공합니다. TokenLab 키는 BYOK 설정에서 허용하는 모델 요청에 사용할 수 있지만, 별도의 구독, 자동 완성 서비스, 계정 기능 또는 독점 확장 기능을 대체하지는 않습니다.

도구 업데이트로 설정 방식이 바뀌면 오래된 환경 변수 예시를 복사하지 말고 현재 통합 페이지를 참고하세요.

## 기능 사용 전 확인 사항

- 도구가 필요한 형식에 사용자 지정 기본 URL을 허용하는지 확인하세요.
- 모델의 `accepted_request_formats`에 해당 형식이 포함되는지 확인하세요.
- 워크플로에 필요하다면 스트리밍과 도구 호출을 확인하세요.
- API 키는 신뢰할 수 있는 기기 또는 서버에 보관하세요.
- 오류를 보고할 때 요청 ID를 기록하세요.
