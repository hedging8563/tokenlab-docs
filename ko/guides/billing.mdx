하나의 TokenLab 잔액을 여러 모델에서 사용합니다. 구독이나 최소 사용액 없이 모델과 기록된 사용량에 따라 청구됩니다.

## 가격과 제공 옵션

현재 가격은 모델 페이지, `GET /v1/models/{model}/pricing`, Pricing API에서 확인하세요. 복사한 가격표를 고정하지 마세요. 텍스트와 임베딩은 입력·출력·캐시 토큰, 미디어는 이미지·초·분·요청·작업 단위일 수 있습니다.

`TokenLab Verified`는 TokenLab 공개 가격을, `Official`은 모델 제작사의 공개 가격에 따른 Official 가격을 사용합니다. `Auto`는 Verified를 우선하고 필요하면 Official을 사용하며 결과를 제공한 옵션으로 한 번만 청구합니다. Console은 유료 생성 확인 전에 최대 예상 비용을, 완료 후 Runs와 Usage에서 최종 비용을 보여 줍니다.

[Pricing API](/ko/api-reference/pricing/get-pricing)

## 비동기 청구와 기록

일부 작업은 생성 시 예상 비용을 예약합니다. task ID와 `poll_url`을 저장하고 `completed` 또는 `failed`까지 조회하세요. 성공한 작업은 한 번 청구되고 남은 예약액은 해제됩니다. 실패한 작업의 보류 금액은 해제되거나 환불됩니다.

비스트리밍 OpenAI 호환 응답은 청구 완료 후 `billing_transaction_id`나 `X-Billing-Transaction-ID`를 포함할 수 있습니다. 네이티브 형식은 헤더만 제공할 수도 있습니다. 비동기와 스트리밍 결과가 청구 기록보다 먼저 도착할 수 있으므로 값이 없으면 Usage를 확인하세요.

Usage에서 모델, 키, 비용, 사용량을 확인하세요. 토큰 계산은 모델·언어·미디어마다 달라 문자 수 추정은 최종 청구를 대신하지 못합니다. 스트리밍은 청구 토큰을 줄이지 않습니다. 같은 작업의 최종 비용을 비교하고 지원되는 출력 제한을 설정하세요.

```json
{
  "usage": {
    "prompt_tokens": 50,
    "completion_tokens": 100,
    "total_tokens": 150
  }
}
```

## Console 사용

Console → Billing에서 금액과 결제 화면의 수단을 선택하세요. 결제 서비스 확인 후 잔액이 갱신됩니다.

Console → API Keys에서 키 생성·수정 시 지출 한도를 설정할 수 있습니다. 한도 도달 시 `402 Payment Required`를 반환합니다.

Console → Settings에서 잔액 알림 기준을 설정하세요. 청구 문의에는 Request ID와 task ID를 support@tokenlab.sh로 보내되 API 키는 보내지 마세요.
