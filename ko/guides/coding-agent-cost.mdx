title: "코딩 에이전트 비용 최적화"
description: "실제 사용 데이터로 비용 관리"
---

워크스페이스 사용 내역에서 비슷한 작업의 최종 비용을 비교하세요. 모델, API 키, 입력·출력·캐시 토큰과 실패하거나 반복한 요청을 기록하세요.

지침과 컨텍스트는 작업에 필요한 내용으로 좁히세요. 기록이 더 이상 도움이 되지 않으면 새 세션을 시작하세요. API 형식에 맞게 출력 한도를 설정하되 작업을 끝낼 여유를 남기세요.

캐시 할인이나 적중률은 보장되지 않습니다. 모델의 최신 정보와 기록된 캐시 사용량을 확인하세요. 프로젝트마다 별도 API 키와 적절한 한도를 사용하세요. 토큰 단가뿐 아니라 정확히 완료한 작업당 비용을 비교하세요.
