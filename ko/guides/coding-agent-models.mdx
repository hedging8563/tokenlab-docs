작업, 필요한 컨텍스트, 속도와 실제 비용을 기준으로 모델을 선택하세요.

최신 ID, 가격, 컨텍스트 한도와 `tokenlab.accepted_request_formats`는 [모델 페이지](https://tokenlab.sh/ko/models)에서 확인하세요. 모델 이름만으로 프로토콜이나 도구 지원을 판단할 수 없습니다.

같은 저장소 상태, 지침, 도구로 후보를 비교하세요. 결과의 정확성, 회귀, 불필요한 변경, 소요 시간, 완료한 작업당 비용을 평가하세요. 작은 수정은 대규모 리팩터링보다 적은 컨텍스트로 충분할 수 있습니다.

클라이언트에서 모델을 명시적으로 선택하세요. 모델이 바뀌면 가격, 도구와 결과가 달라질 수 있으므로 확인을 받으세요. 각 클라이언트 가이드를 따르고 기존 계정과 권한을 유지하세요.
