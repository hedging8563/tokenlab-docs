## 권장: 플러그인 설치

선택 사항: 게시된 제공자 플러그인 **0.1.0**을 설치하세요. 아래에 설명된 Gateway 환경으로 `TOKENLAB_API_KEY`를 전달하고 세션에만 모델을 선택하세요. 온보딩 마법사는 기본 모델을 변경하므로 이 가이드에서는 `openclaw onboard`를 실행하지 않습니다. 기존 플러그인과 권한을 유지하고 요청 전에 플러그인 로드와 모델 목록을 확인하세요.

설치 프로그램이 요청하는 기능을 검토하고 클라이언트의 확인 안내를 따르세요. 관련 없는 권한을 부여하거나 기존 플러그인의 권한을 바꾸지 마세요.

```bash
openclaw plugins install @tokenlabai/openclaw-provider@0.1.0
openclaw plugins list
openclaw models list --provider tokenlab
```

```text
/model tokenlab/claude-sonnet-5 -s
/model default -s
```

## 수동 프로바이더 구성

별도의 **Responses API**, **Claude native**, **Gemini native** 또는 **MiniMax native** 경로가 명시적으로 필요한 경우에만 아래의 `models.providers` 수동 구성을 사용하세요.

수동 구성을 선택한다면 `tokenlab`만 구성하는 것으로 충분합니다. **Responses API**, **Claude native**, **Gemini native**, 또는 **MiniMax native** 동작이 명시적으로 필요할 때만 다른 프로바이더를 추가하세요.

| 제공업체 | OpenClaw `api` | 적합한 용도 | baseUrl |
|----------|----------------|------------|---------|
| `tokenlab` | `openai-completions` | GPT, DeepSeek, Qwen 및 대부분의 OpenAI 호환 호출 | `https://api.tokenlab.sh/v1` |
| `tokenlab-responses` | `openai-responses` | `/v1/responses` 의미론을 기대하는 OpenAI Responses 워크플로우 | `https://api.tokenlab.sh/v1` |
| `tokenlab-claude` | `anthropic-messages` | Claude Messages 네이티브 API | `https://api.tokenlab.sh` |
| `tokenlab-gemini` | `google-generative-ai` | Gemini 네이티브 API 형식 | `https://api.tokenlab.sh` |
| `tokenlab-minimax` | `anthropic-messages` | MiniMax 네이티브 라우팅 | `https://api.tokenlab.sh` |

<Warning>
`/v1` 접미사는 `openai-completions` 및 `openai-responses`에만 사용하세요.

`anthropic-messages` 및 `google-generative-ai`와 같은 네이티브 프로바이더는 `/v1` 없이 `https://api.tokenlab.sh`를 사용해야 하며, 그렇지 않으면 OpenClaw가 잘못된 업스트림 경로를 구성할 수 있습니다.
</Warning>

## 사전 요구사항

- self-hosted OpenClaw 인스턴스
- OpenClaw **2026.9.4**에는 Node.js `>=24.16.0 <25 || >=26.1.0`이 필요합니다([버전 요구 사항](https://github.com/openclaw/openclaw/blob/v2026.9.4/package.json)). 다른 OpenClaw 릴리스는 해당 릴리스의 요구 사항을 확인하세요.
- TokenLab API Key — [Get one here](https://tokenlab.sh/dashboard/api?tab=keys)

## 구성

OpenClaw 구성 파일을 편집하세요:

- **셀프 호스트**: `~/.openclaw/openclaw.json`

`models.providers` 아래에 TokenLab 프로바이더를 추가합니다:

실행 중인 Gateway와 같은 profile, `OPENCLAW_STATE_DIR`, `OPENCLAW_CONFIG_PATH`를 사용하고 설정을 백업하세요. `TOKENLAB_API_KEY`는 해당 인스턴스의 신뢰할 수 있는 전역 `.env`나 서비스 환경에 둡니다. 터미널 export나 프로젝트 `.env`만으로는 백그라운드에 전달되지 않을 수 있습니다. [환경 안내](https://docs.openclaw.ai/help/environment)를 참고하세요.

활성 구성을 백업하세요. TokenLab 항목만 추가하고 기존 제공자, 계정, 기본 모델 선택과 권한을 유지하세요. 이름이 이미 사용 중이면 다른 이름을 선택하고 명령도 바꾸세요. 되돌릴 때는 추가한 항목만 제거하거나 이전 백업을 복원하세요.

```json5
{
  models: {
    mode: "merge",
    providers: {
      tokenlab: {
        api: "openai-completions",
        baseUrl: "https://api.tokenlab.sh/v1",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gpt-5.6-terra", name: "GPT-5.6 Terra" },
          { id: "deepseek-reasoner", name: "DeepSeek Reasoner" },
          { id: "qwen3-coder-flash", name: "Qwen 3 Coder Flash" }
        ]
      },
      "tokenlab-responses": {
        api: "openai-responses",
        baseUrl: "https://api.tokenlab.sh/v1",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gpt-5.6-terra", name: "GPT-5.6 Terra (Responses)" },
          { id: "gpt-5.2", name: "GPT-5.2 (Responses)" }
        ]
      },
      "tokenlab-claude": {
        api: "anthropic-messages",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "claude-sonnet-5", name: "Claude Sonnet 5" },
          { id: "claude-opus-5", name: "Claude Opus 5" }
        ]
      },
      "tokenlab-gemini": {
        api: "google-generative-ai",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "gemini-3.5-flash", name: "Gemini 3.5 Flash" },
          { id: "gemini-2.5-pro", name: "Gemini 2.5 Pro" }
        ]
      },
      "tokenlab-minimax": {
        api: "anthropic-messages",
        baseUrl: "https://api.tokenlab.sh",
        apiKey: "${TOKENLAB_API_KEY}",
        models: [
          { id: "minimax-m3", name: "MiniMax M3" }
        ]
      }
    }
  }
}
```

<Info>
모든 5개 프로바이더는 **같은 API Key**를 사용합니다. TokenLab 계정은 하나만 있으면 됩니다.
</Info>

<Info>
위의 `models` 배열은 일반적인 예시만 보여줍니다. 필요에 따라 각 프로바이더에 더 많은 모델 ID를 추가하세요.
</Info>

## 모델 사용 방법

OpenClaw은 여전히 `provider/model` 형식으로 모델을 참조합니다:

**OpenClaw 2026.9.4**에서는 `-s`로 현재 세션에만 모델을 선택하세요. `agents.defaults.model`, 에이전트 기본값과 권한을 유지하세요. `/model default -s`로 이 세션을 구성된 기본 모델로 되돌릴 수 있습니다.

```text
/model tokenlab-claude/claude-sonnet-5 -s
/model default -s
```

### 모델 예시

| 제공업체 | 모델 참조 | 설명 |
|----------|-----------|------|
| `tokenlab` | `tokenlab/gpt-5.6-terra` | OpenAI 호환 경로 |
| `tokenlab-responses` | `tokenlab-responses/gpt-5.6-terra` | Responses API 경로 |
| `tokenlab-claude` | `tokenlab-claude/claude-sonnet-5` | Claude Messages 네이티브 경로 |
| `tokenlab-gemini` | `tokenlab-gemini/gemini-3.5-flash` | Gemini 네이티브 경로 |
| `tokenlab-minimax` | `tokenlab-minimax/minimax-m3` | MiniMax 네이티브 경로 |

사용 가능한 모든 모델은 [tokenlab.sh/models](https://tokenlab.sh/ko/models)에서 확인하세요.

## 어떤 프로바이더를 언제 사용해야 하나요

- `tokenlab`: 대부분의 범용 에이전트 및 채팅 사용 사례에 대한 기본 선택입니다.
- `tokenlab-responses`: OpenClaw 워크플로우가 명시적으로 OpenAI Responses 의미론에 의존할 때 사용하세요.
- `tokenlab-claude`: Claude의 네이티브 Messages 동작이 필요할 때 사용하세요.
- `tokenlab-gemini`: Gemini 네이티브 요청/응답 포맷이나 기존 Gemini 스타일 통합을 사용하고자 할 때 사용하세요.
- `tokenlab-minimax`: MiniMax의 네이티브 경로를 사용하고자 할 때 사용하세요.

Gemini 네이티브 동작이 필요하지 않다면 OpenAI 호환 경로를 통해 `tokenlab/gemini-*`로 Gemini 모델을 호출할 수 있습니다.

## 흔한 실수

<AccordionGroup>
  <Accordion title="여전히 이전의 최상위 providers 배열을 사용 중">
    현재 OpenClaw 문서는 `models.providers`를 사용합니다. 이전의 최상위 `providers` 배열 형식을 유지하면 OpenClaw가 구성을 무시하거나 프로바이더 접두사를 예상대로 해결하지 못할 수 있습니다.
  </Accordion>
  <Accordion title="tokenlab-responses에서 /v1을 깜빡함">
    `openai-responses`는 TokenLab의 `/v1/responses` 경로에 매핑되므로 `tokenlab-responses`는 반드시 `https://api.tokenlab.sh/v1`을 사용해야 합니다.
  </Accordion>
  <Accordion title="tokenlab-claude, tokenlab-gemini 또는 tokenlab-minimax에 /v1을 추가함">
    `anthropic-messages` 및 `google-generative-ai`는 `/v1` 없이 `https://api.tokenlab.sh`를 사용해야 합니다. `/v1`을 추가하면 잘못된 요청 경로가 생성될 수 있습니다.
  </Accordion>
  <Accordion title="OpenClaw가 여전히 네이티브 Gemini를 지원하나요?">
    예. 현재 OpenClaw 문서에는 내장된 `google` 프로바이더가 포함되어 있으며 `api: "google-generative-ai"`를 사용하는 커스텀 프로바이더도 지원합니다. 따라서 `tokenlab-gemini`는 OpenClaw 사용자를 위한 유효한 네이티브 Gemini 경로로 남아 있습니다.
  </Accordion>
</AccordionGroup>

## 설정 확인

같은 인스턴스를 재시작하고 모델과 제공자를 확인하세요. `--probe` 없는 `models status`는 모델 호출 테스트가 아닙니다. 실제 탐색이나 대화는 token을 사용할 수 있습니다. 응답과 TokenLab 기록을 비교하세요. 복구할 때는 이전 모델을 선택하고 추가한 항목만 제거합니다.

```bash
openclaw gateway restart
openclaw models status
```
