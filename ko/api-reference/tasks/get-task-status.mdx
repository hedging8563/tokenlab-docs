## 개요

비디오, 이미지, 음악, 3D 생성과 같은 작업 유형 전반에서 통합된 비동기 polling을 위해 이 엔드포인트를 사용하세요.

create 응답에 `poll_url`이 포함되어 있으면 해당 정확한 path를 호출하세요. 최신 비동기 워크플로에서는 `poll_url`이 `/v1/tasks/{id}`를 가리킬 수 있습니다.

## 경로 매개변수

<ParamField path="id" type="string" required>
  create 요청에서 반환된 작업 ID입니다.
</ParamField>

## 응답

<Note>
결과, 오류, 타임스탬프, 모델 필드는 작업에서 제공될 때 반환됩니다.
</Note>

<ResponseField name="id" type="string">
  작업 식별자입니다.
</ResponseField>

<ResponseField name="task_id" type="string">
  비동기 작업 식별자의 별칭입니다.
</ResponseField>

<ResponseField name="poll_url" type="string">
  생성 응답에서 제공될 때 우선 사용할 폴링 URL입니다.
</ResponseField>

<ResponseField name="status" type="string">
  작업 상태입니다. 예: `pending`, `processing`, `completed`, `failed`. 취소된 작업은 `failed`와 `cancelled: true`로 표시됩니다.
</ResponseField>

<ResponseField name="cancelled" type="boolean">
  대기 중인 비동기 작업이 실행 전에 취소되면 `true`입니다.
</ResponseField>

<ResponseField name="cancellation_status" type="string">
  취소 마커입니다. 취소 성공 시 `cancelled`입니다.
</ResponseField>

<ResponseField name="data" type="array">
  완료된 이미지 작업의 경우 생성된 이미지 결과가 여기에 반환됩니다. 이미지 작업은 `data[].url`에 URL을 반환합니다.
</ResponseField>

<ResponseField name="progress" type="number">
  선택적 진행 값입니다. 실제 진행 값이 제공될 때만 반환됩니다. 완료 여부는 `status` 로 판단하세요.
</ResponseField>

<ResponseField name="video_url" type="string">
  작업이 완료되어 비디오를 생성한 경우의 결과 asset URL입니다.
</ResponseField>

<ResponseField name="video" type="object">
  사용 가능한 경우 `url`, `duration`, `width`, 및 `height`를 포함한 단일 비디오 페이로드.
</ResponseField>

<ResponseField name="videos" type="array">
  생성 작업이 여러 출력을 반환할 때의 다중 비디오 페이로드.
</ResponseField>

<ResponseField name="created" type="integer">
  생성 타임스탬프.
</ResponseField>

<ResponseField name="updated" type="integer">
  최종 업데이트 타임스탬프.
</ResponseField>

<ResponseField name="model" type="string">
  작업에 사용된 모델.
</ResponseField>

<ResponseField name="error" type="string | object">
  작업이 실패했을 때의 오류 메시지입니다.
</ResponseField>

## 오류 동작

만료되었거나 사용할 수 없는 공개 작업은 `404 async_task_not_found`를 반환할 수 있습니다. 현재 API 키로 작업 소유권을 확인할 수 없으면 `403 task_not_owned`가 반환됩니다.

```json
{
  "error": {
    "message": "Task not found or no longer available.",
    "type": "invalid_request_error",
    "code": "async_task_not_found"
  }
}
```

```python Python
import requests

poll_url = "/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
response = requests.get(
    f"https://api.tokenlab.sh{poll_url}",
    headers={"Authorization": "Bearer sk-your-api-key"},
)
print(response.json())
```

```javascript JavaScript
const pollUrl = '/v1/tasks/ldtask_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa';
const response = await fetch(`https://api.tokenlab.sh${pollUrl}`, {
  headers: { Authorization: 'Bearer sk-your-api-key' },
});
console.log(await response.json());
```
