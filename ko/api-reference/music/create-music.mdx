---
title: "음악 생성"
openapi: "POST /v1/music/generations"
description: "Suno를 사용하여 음악 생성 작업을 생성합니다."
---

AI를 사용하여 음악과 가사를 생성합니다. 이 API는 비동기 방식으로 동작합니다. 생성 응답은 작업 ID를 반환하며, 사용 가능할 때는 우선 사용해야 하는 `poll_url` 도 함께 반환할 수 있습니다.

## 요청 본문

<ParamField body="model" type="string" default="suno_music">
  음악 모델 ID입니다. 예: `suno-music`. 가사만 생성하려면 현재 공개 작업에 `lyrics`가 포함된 모델을 선택하세요.
</ParamField>

<ParamField body="prompt" type="string">
  음악 설명 또는 교체할 텍스트입니다. 음악, 가사, upload-cover, upload-extend, replace-section에 필수이며 add-instrumental과 음원 분리에서는 생략할 수 있습니다.
</ParamField>

<ParamField body="title" type="string">
  생성된 곡의 제목입니다.
</ParamField>

<ParamField body="tags" type="string">
  스타일 태그 (예: "pop, upbeat, electronic").
</ParamField>

<ParamField body="negative_tags" type="string">
  피할 스타일입니다. `audio_operation` 이 `add-instrumental` 인 경우 필수입니다.
</ParamField>

<ParamField body="action" type="string">
  선택 값은 `MUSIC` 또는 `LYRICS`입니다. 해당 공개 작업을 지원하는 모델을 선택하세요. 이 필드가 음악 전용 모델에 가사 생성 기능을 추가하지는 않습니다.
</ParamField>

<ParamField body="mv" type="string">
  Suno 버전 선택 값입니다. 생성, upload-cover, upload-extend, add-instrumental 및 `audio_url` 기반 교체에 필수입니다. 가사, `task_id` + `audio_id` 기반 교체 및 음원 분리에서는 생략하세요. 지원 값: `chirp-v3-5`, `chirp-v4`, `chirp-v4-5`, `chirp-v4.5`, `chirp-v4-5plus`, `chirp-v4.5plus`, `chirp-v4-5all`, `chirp-v4.5all`, `chirp-v5`, `chirp-v5-5`, `chirp-v5.5`.
</ParamField>

<ParamField body="make_instrumental" type="boolean">
  `true` 로 설정하면 보컬 없는 연주곡을 생성합니다.
</ParamField>

<ParamField body="audio_url" type="string">
  공개적으로 접근 가능한 참조 또는 업로드 오디오 URL입니다. `audio_operation` 없이 제공하면 upload-cover 흐름을 사용합니다.
</ParamField>

<ParamField body="audio_operation" type="string">
  오디오 작업: `upload-cover`, `upload-extend`, `add-instrumental`, `replace-section`, `vocal-separate`, `multi-stem-separation`, `advanced-split`.

  `vocal-separate`, `multi-stem-separation`, `advanced-split`에는 `task_id` + `audio_id`가 필요하며 `advanced-split`에는 `stem_name`도 필요합니다. `upload-extend`에는 0보다 큰 `continue_at`이 필요합니다. `add-instrumental`에는 `audio_url`, `title`, `tags`, `negative_tags`가 필요합니다.

  `replace-section`에는 `prompt`, `tags`, `title`, `infill_start_s`, `infill_end_s`, `full_lyrics`가 필요합니다. 소스는 `task_id` + `audio_id` 또는 `audio_url` + `mv` 중 하나만 지정하세요. 교체 구간은 6~60초여야 합니다.
</ParamField>

<ParamField body="task_id" type="string">
  생성 오디오 교체 또는 음원 분리에 사용할 조직 소유의 소스 작업 ID입니다.
</ParamField>

<ParamField body="audio_id" type="string">
  소스 작업 결과에 반환된 오디오 ID입니다. 생성 오디오 교체와 음원 분리 시 `task_id`와 함께 필요합니다.
</ParamField>

<ParamField body="infill_start_s" type="number">
  교체 시작 시간(초)이며 0 이상이어야 합니다. `replace-section`에 필수입니다.
</ParamField>

<ParamField body="infill_end_s" type="number">
  교체 종료 시간(초)입니다. `replace-section`에 필수이며 `infill_start_s`보다 6~60초 뒤여야 합니다.
</ParamField>

<ParamField body="full_lyrics" type="string">
  완성될 곡의 전체 가사입니다. `replace-section`에 필수입니다.
</ParamField>

<ParamField body="stem_name" type="string">
  분리할 트랙 이름입니다. `advanced-split`에 필수입니다.
</ParamField>

<ParamField body="continue_clip_id" type="string">
  이어 나갈 이전 클립의 ID입니다.
</ParamField>

<ParamField body="continue_at" type="number">
  이어 만들기를 시작할 시간(초)입니다. `upload-extend`에 필수이며 0보다 커야 합니다.
</ParamField>

<Note>
`prompt`는 최대 5000자, `tags`와 `negative_tags`는 각각 최대 1000자입니다. 지원 작업과 매개변수는 선택한 모델의 현재 세부정보를 따릅니다.
</Note>

## 응답

<ResponseField name="id" type="string">
  상태 폴링을 위한 작업 ID입니다.
</ResponseField>

<ResponseField name="task_id" type="string">
  동일한 비동기 작업 ID의 별칭이며 반환되는 경우에만 존재합니다.
</ResponseField>

<ResponseField name="poll_url" type="string">
  사용 가능할 때 반환되는 우선 폴링 URL입니다.
</ResponseField>

<ResponseField name="status" type="string">
  작업 상태: `pending`, `processing`, `completed` 또는 `failed`입니다.
</ResponseField>

<ResponseField name="created" type="integer">
  반환되는 경우의 작업 생성 Unix 타임스탬프입니다.
</ResponseField>

```python Python
import requests

response = requests.post(
    "https://api.tokenlab.sh/v1/music/generations",
    headers={"Authorization": "Bearer sk-your-api-key"},
    json={
        "model": "suno-music",
        "mv": "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title": "Night Drive",
        "tags": "electronic, EDM, energetic"
    }
)

response.raise_for_status()
task = response.json()
task_id = task["id"]
poll_url = task.get("poll_url") or f"/v1/tasks/{task_id}"
print(f"Task ID: {task_id}; poll URL: {poll_url}")
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model":  "suno-music",
        "mv":     "chirp-v4",
        "prompt": "An upbeat electronic dance track with heavy bass",
        "title":  "Night Drive",
        "tags":   "electronic, EDM, energetic",
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/music/generations", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Printf("Task ID: %s\n", result["id"])
}
```
