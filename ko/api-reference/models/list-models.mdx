---

모델 카탈로그는 공개되어 있으며 API 키가 필요하지 않습니다. 각 항목에는 현재 기능, 가격 및 API 형식에 대한 요약이 포함되어 있습니다. 전체 세부 정보가 필요한 경우 특정 모델을 조회하십시오.

## 쿼리 매개변수

<ParamField query="category" type="string">
  `chat`, `image`, `video`, `audio`, `tts`, `stt`, `music`, `3d`, `embedding`, `rerank` 또는 `translation`으로 필터링합니다.
</ParamField>

<ParamField query="recommended_for" type="string">
  `image`, `video`, `music`, `3d`, `tts`, `stt`, `embedding`, `rerank` 또는 `translation`과 같은 작업에 대한 현재 권장 사항을 반환합니다.
</ParamField>

<ParamField query="provider" type="string">
  `openai`, `anthropic`, `google` 또는 `deepseek`와 같은 모델 제조사로 필터링합니다.
</ParamField>

<ParamField query="tag" type="string">
  `chat`, `image`, `video`, `embedding` 또는 `translation`과 같은 태그로 필터링합니다.
</ParamField>

## 응답

<ResponseField name="object" type="string">항상 `list`입니다.</ResponseField>
<ResponseField name="data" type="array">`id`, `owned_by` 및 `tokenlab` 요약 정보가 포함된 모델 목록입니다.</ResponseField>

`tokenlab` 하위의 일반적인 목록 필드는 다음과 같습니다:

- `tokenlab.aliases`
- `tokenlab.capabilities`
- `tokenlab.pricing` 및 `tokenlab.pricing_unit`
- `tokenlab.max_input_tokens` 및 `tokenlab.max_output_tokens`
- `tokenlab.category`
- `tokenlab.lifecycle`, `tokenlab.commercial` 및 `tokenlab.badges`
- `tokenlab.request_format_summary`
- `recommended_for` 사용 시 `tokenlab.agent_preferences`

`recommended_for`를 사용하는 경우, 결과에 권장 상태 및 업데이트 시간이 포함될 수 있습니다. 순서를 고정하지 말고 현재 응답을 읽으십시오.

## 예시

```bash
curl "https://api.tokenlab.sh/v1/models?category=video"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "veo3.1",
      "object": "model",
      "owned_by": "google",
      "tokenlab": {
        "category": "video",
        "capabilities": ["text-to-video", "image-to-video"]
      }
    }
  ]
}
```

전체 세부 정보는 [모델 가져오기](/ko/api-reference/models/get-model)을 참조하십시오.
