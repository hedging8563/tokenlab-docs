## 경로 매개변수

<ParamField path="model" type="string" required>
  `gpt-5.6-terra` 또는 `claude-sonnet-4-6`과 같은 모델 ID입니다.
</ParamField>

## 응답

<ResponseField name="id" type="string">모델 ID입니다.</ResponseField>
<ResponseField name="object" type="string">항상 `model`입니다.</ResponseField>
<ResponseField name="owned_by" type="string">모델 제조사입니다.</ResponseField>
<ResponseField name="tokenlab" type="object">
  기능, 가격, 과금 단위, 컨텍스트 제한, 허용되는 API 형식, 작업 및 수명 주기 상태를 포함한 TokenLab 모델 정보입니다.
</ResponseField>

일반적인 `tokenlab` 필드는 다음과 같습니다:

- `capabilities`: 텍스트, 이미지, 비디오, 오디오 및 기타 기능.
- `pricing`: 현재 공개 가격.
- `max_input_tokens` 및 `max_output_tokens`: 컨텍스트 및 출력 제한.
- `accepted_request_formats`: 지원되는 API 형식.
- `supported_operations`: 텍스트-이미지 변환 또는 이미지-비디오 변환과 같은 작업.
- `lifecycle`: 가용성, 출시일, 지원 종료일 또는 대체 모델.

일부 미디어 모델에는 권장 상태 및 업데이트 시간이 포함됩니다. 권장 사항은 가용성 및 성능에 따라 변경될 수 있으므로 순서를 하드코딩하지 마십시오.

## 예시

```bash
curl "https://api.tokenlab.sh/v1/models/gpt-5.6-terra"
```

```json
{
  "id": "gpt-5.6-terra",
  "object": "model",
  "owned_by": "openai",
  "tokenlab": {
    "category": "chat",
    "capabilities": ["coding", "json-mode", "prompt-cache", "reasoning", "tool-use", "vision"],
    "accepted_request_formats": ["openai_chat_completions", "openai_responses"]
  }
}
```

알 수 없는 모델의 경우 `404 model_not_found`를 반환합니다.
