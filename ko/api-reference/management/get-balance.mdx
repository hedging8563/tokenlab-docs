## 개요

이 엔드포인트는 관리 토큰에 연결된 조직의 현재 잔액 합계를 반환합니다. 과금 및 정산과 동일한 조직 잔액 단일 사실원을 사용합니다.

## 주의 사항

- 금액 필드는 USD만 지원합니다.

- 금액 필드는 USD로 반환됩니다. 표시에는 `balance`, `total_recharge`, `total_used`를 사용하고, 정확한 청구 대조에는 `balance_decimal`, `total_recharge_decimal`, `total_used_decimal`을 사용하세요.

## 예시

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/balance" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 요청 / 응답

이 페이지는 OpenAPI 스키마와 복사 가능한 요청 예제를 제공합니다. 관리 요청은 Management Token을 사용해 터미널이나 클라이언트에서 전송하세요. 이 페이지에서는 직접 전송할 수 없습니다.
