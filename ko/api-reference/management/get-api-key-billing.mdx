---

## 개요

이 엔드포인트는 선택한 API 키의 소비 기준 청구 집계를 반환합니다. 총 비용, 총 요청 수, 과금 단위별 사용량, `by_model`, `by_logical_model`, `by_model_vendor`, `by_scene` 내역과 일별 비용 추세가 포함됩니다.

## 주의 사항

- 금액 필드는 USD만 지원합니다. `CNY` 입력은 지원이 종료되었으며 `400 currency_retired`가 반환됩니다.

- 충전, 인보이스 등 조직 수준의 재무 기록은 포함되지 않습니다.

## 예시

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456/billing?startDate=2026-01-01&endDate=2026-01-31" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 주요 필드

<ResponseField name="api_key" type="object">목록/생성/업데이트 응답과 동일한 필드를 사용하는 API 키 요약입니다.</ResponseField>
<ResponseField name="summary" type="object">선택한 필터의 집계 합계입니다.</ResponseField>
<ResponseField name="breakdowns" type="object">선택한 필터의 집계 내역입니다.</ResponseField>
<ResponseField name="summary.total_requests" type="number">전체 요청 수입니다.</ResponseField>
<ResponseField name="summary.total_cost" type="number">표시용 JSON 숫자로 반환되는 USD 총비용입니다.</ResponseField>
<ResponseField name="summary.total_cost_decimal" type="string">10진 문자열로 반환되는 정확한 USD 총비용입니다.</ResponseField>
<ResponseField name="summary.total_prompt_tokens" type="number">전체 프롬프트 token 수입니다.</ResponseField>
<ResponseField name="summary.total_completion_tokens" type="number">전체 완성 token 수입니다.</ResponseField>
<ResponseField name="summary.total_tokens" type="number">전체 token 수입니다.</ResponseField>
<ResponseField name="summary.usage_unit_breakdown" type="array">사용 단위별로 그룹화한 사용량입니다.</ResponseField>
<ResponseField name="breakdowns.by_model" type="array">요청한 공개 모델별 내역입니다.</ResponseField>
<ResponseField name="breakdowns.by_logical_model" type="array">논리 공개 모델별 내역입니다.</ResponseField>
<ResponseField name="breakdowns.by_model_vendor" type="array">공개 모델 공급업체별 내역입니다.</ResponseField>
<ResponseField name="breakdowns.by_scene" type="array">공개 요청 시나리오별 내역입니다.</ResponseField>
<ResponseField name="breakdowns.daily_cost" type="array">일별 비용 추이입니다.</ResponseField>
