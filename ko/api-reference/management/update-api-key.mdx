description: "현재 조직의 기존 사용자 API 키를 업데이트합니다."
---

## 개요

이 엔드포인트는 기존 사용자 API 키의 이름, 사용 한도, 허용 모델, 만료, 상태를 업데이트할 때 사용합니다.

## 요청 본문

최소 1개 이상의 필드를 제공해야 합니다.

| 필드 | 타입 | 기본값 / 제한 | 설명 |
|-------|------|---------------|------|
| `status` | enum | - | `active`, `inactive`, `revoked` |
| `name` | string | 길이 `1-50` | 업데이트된 표시 이름 |
| `limitAmount` | number \| null | 최소 `0`, 입력 최대 `1000000` | `null` = 무제한, `0` = 0 한도. 양수는 저장된 상한으로 정규화되며 USD 환산 기준 `100000` 을 넘지 않습니다 |
| `limitCurrency` | enum | 기본값 `USD` | USD만 지원됩니다. `CNY`를 보내면 `400 currency_retired`가 반환됩니다. |
| `models` | string[] | - | 업데이트된 모델 허용 목록 |
| `expiresAt` | string \| null | RFC3339 datetime | `null` 은 만료 제거 |

## 참고 사항

- 금액 필드는 USD만 지원합니다. `CNY` 입력은 지원이 종료되었으며 `400 currency_retired`가 반환됩니다.

- Management API v1 에서는 하드 삭제를 의도적으로 지원하지 않습니다.
- `revoked` 는 일반 운영에서 종료 상태로 취급되므로, 나중에 다시 살리는 흐름을 기대하기보다 새 키를 만드는 편이 낫습니다.

## 예시

<RequestExample>
```bash cURL
curl -X PATCH "https://api.tokenlab.sh/v1/management/api-keys/key_abc123def456" \
  -H "Authorization: Bearer mt-your-management-token" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "inactive",
    "limitAmount": 0
  }'
```
</RequestExample>

## 주요 필드

<ResponseField name="id" type="string">후속 Management API 호출에 사용하는 API 키 식별자입니다.</ResponseField>
<ResponseField name="name" type="string">API 키의 표시 이름입니다.</ResponseField>
<ResponseField name="key_prefix" type="string">표시 및 지원에 사용하는 비밀이 아닌 키 접두사입니다.</ResponseField>
<ResponseField name="status" type="string">`active`, `inactive`, `revoked` 중 하나입니다.</ResponseField>
<ResponseField name="limit_amount" type="number | null">표시용 JSON 숫자로 반환되는 USD 지출 한도입니다. `null`은 무제한을 의미합니다.</ResponseField>
<ResponseField name="limit_amount_decimal" type="string | null">10진 문자열로 반환되는 정확한 USD 지출 한도입니다. `null`은 무제한을 의미합니다.</ResponseField>
<ResponseField name="used_amount" type="number">표시용 JSON 숫자로 반환되는 USD 누적 사용 금액입니다.</ResponseField>
<ResponseField name="used_amount_decimal" type="string">10진 문자열로 반환되는 정확한 USD 누적 사용 금액입니다.</ResponseField>
<ResponseField name="models" type="string[]">키별 모델 허용 목록입니다. 빈 배열은 추가적인 키 수준 모델 제한이 없음을 의미합니다.</ResponseField>
<ResponseField name="expires_at" type="string | null">키 만료 시각의 ISO 타임스탬프이며, 만료되지 않으면 `null`입니다.</ResponseField>
<ResponseField name="last_used_at" type="string | null">가장 최근 사용 시각의 ISO 타임스탬프이며, 사용한 적이 없으면 `null`입니다.</ResponseField>
<ResponseField name="created_at" type="string">생성 시각의 ISO 타임스탬프입니다.</ResponseField>
