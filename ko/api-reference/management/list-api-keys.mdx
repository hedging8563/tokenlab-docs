## 개요

현재 관리 토큰에 연결된 조직의 사용자 API 키 목록을 반환합니다.

## 주의 사항

- 금액 필드는 USD만 지원합니다. `CNY` 입력은 지원이 종료되었으며 `400 currency_retired`가 반환됩니다.

- 시스템 관리 key는 결과에 포함되지 않습니다.

## 예시

<RequestExample>
```bash cURL
curl -X GET "https://api.tokenlab.sh/v1/management/api-keys" \
  -H "Authorization: Bearer mt-your-management-token"
```
</RequestExample>

## 주요 필드

<ResponseField name="object" type="string">항상 `list`입니다.</ResponseField>
<ResponseField name="data" type="array">API 키 객체 배열입니다.</ResponseField>
<ResponseField name="pagination" type="object">`page`, `limit`, `total`, `totalPages`를 포함하는 페이지네이션 메타데이터입니다.</ResponseField>
<ResponseField name="data[].id" type="string">후속 Management API 호출에 사용하는 API 키 식별자입니다.</ResponseField>
<ResponseField name="data[].name" type="string">API 키의 표시 이름입니다.</ResponseField>
<ResponseField name="data[].key_prefix" type="string">표시 및 지원에 사용하는 비밀이 아닌 키 접두사입니다.</ResponseField>
<ResponseField name="data[].status" type="string">`active`, `inactive`, `revoked` 중 하나입니다.</ResponseField>
<ResponseField name="data[].limit_amount" type="number | null">표시용 JSON 숫자로 반환되는 USD 지출 한도입니다. `null`은 무제한을 의미합니다.</ResponseField>
<ResponseField name="data[].limit_amount_decimal" type="string | null">10진 문자열로 반환되는 정확한 USD 지출 한도입니다. `null`은 무제한을 의미합니다.</ResponseField>
<ResponseField name="data[].used_amount" type="number">표시용 JSON 숫자로 반환되는 USD 누적 사용 금액입니다.</ResponseField>
<ResponseField name="data[].used_amount_decimal" type="string">10진 문자열로 반환되는 정확한 USD 누적 사용 금액입니다.</ResponseField>
<ResponseField name="data[].models" type="string[]">키별 모델 허용 목록입니다. 빈 배열은 추가적인 키 수준 모델 제한이 없음을 의미합니다.</ResponseField>
<ResponseField name="data[].expires_at" type="string | null">키 만료 시각의 ISO 타임스탬프이며, 만료되지 않으면 `null`입니다.</ResponseField>
<ResponseField name="data[].last_used_at" type="string | null">가장 최근 사용 시각의 ISO 타임스탬프이며, 사용한 적이 없으면 `null`입니다.</ResponseField>
<ResponseField name="data[].created_at" type="string">생성 시각의 ISO 타임스탬프입니다.</ResponseField>
