## 요청 본문

전사는 텍스트를 즉시 반환하거나 HTTP `200`, `id`, `status`로 비동기 작업 수락을 반환할 수 있습니다. 비동기 작업은 `poll_url` 또는 `/v1/tasks/{id}`로 조회하세요. 긴 오디오를 동기 처리할 때는 클라이언트 제한 시간을 최소 `120s`로 설정하세요.

<ParamField body="file" type="file" required>
  전사할 오디오 파일입니다. 지원 형식: flac, mp3, mp4, mpeg, mpga, m4a, ogg, wav, webm. 최대 파일 크기: 25 MB.
</ParamField>

<ParamField body="model" type="string" default="whisper-1">
  전사 모델 ID입니다. 예: `whisper-1`, `gpt-4o-transcribe`. `GET /v1/models?recommended_for=stt`에서 현재 모델을 확인하세요.
</ParamField>

<ParamField body="language" type="string">
  ISO-639-1 형식의 오디오 언어입니다(예: `en`, `zh`, `ja`).
</ParamField>

<ParamField body="prompt" type="string">
  모델의 스타일을 유도하거나 이전 세그먼트를 이어가기 위한 선택적 텍스트입니다.
</ParamField>

<ParamField body="response_format" type="string" default="json">
  출력 형식입니다. Whisper는 `json`, `text`, `srt`, `verbose_json`, `vtt`를 지원합니다. 다른 모델의 지원 범위는 모델 세부정보에서 확인하세요.
</ParamField>

<ParamField body="temperature" type="number">
  0~1 범위의 샘플링 온도입니다. 이 매개변수를 지원하는 모델에서만 사용하세요.
</ParamField>

<ParamField body="timestamp_granularities" type="array">
  지원 모델에서 `word` 및/또는 `segment`를 지정합니다. Whisper는 `response_format=verbose_json`이 필요합니다. multipart에서 여러 값을 보내려면 `timestamp_granularities[]`를 반복하세요.
</ParamField>

## 응답

다음 필드는 JSON 전사 또는 번역 응답에 해당합니다. `text`, `srt`, `vtt`는 JSON 객체 대신 원시 텍스트나 자막을 반환합니다. 추가 필드는 모델과 출력 형식에 따라 다릅니다.

<ResponseField name="text" type="string">
  전사된 텍스트입니다.
</ResponseField>

`verbose_json`의 경우:

<ResponseField name="task" type="string">
  반환되는 경우의 작업 이름입니다. 예: `transcribe`.
</ResponseField>

<ResponseField name="language" type="string">
  감지된 언어입니다.
</ResponseField>

<ResponseField name="duration" type="number">
  초 단위 오디오 길이입니다.
</ResponseField>

<ResponseField name="segments" type="array">
  타임스탬프가 포함된 전사 세그먼트입니다.
</ResponseField>

<ResponseField name="words" type="array">
  단어 수준 타임스탬프입니다(요청한 경우).
</ResponseField>

수락된 비동기 전사 작업은 전사 텍스트 대신 다음 필드를 반환합니다.

<ResponseField name="id" type="string">
  작업 ID.
</ResponseField>

<ResponseField name="task_id" type="string">
  사용 가능할 때의 비동기 작업 ID 별칭입니다.
</ResponseField>

<ResponseField name="status" type="string">
  작업 상태: `pending`, `processing`, `completed` 또는 `failed`.
</ResponseField>

<ResponseField name="poll_url" type="string">
  생성 응답에서 제공될 때 우선 사용할 폴링 URL입니다.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/audio/transcriptions" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F file="@audio.mp3" \
  -F model="whisper-1" \
  -F language="en"
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

with open("audio.mp3", "rb") as audio_file:
    response = client.audio.transcriptions.create(
        model="whisper-1",
        file=audio_file,
        language="en"
    )

print(response.text)
```

```javascript JavaScript
import OpenAI from 'openai';
import fs from 'fs';

const client = new OpenAI({
  apiKey: 'sk-your-api-key',
  baseURL: 'https://api.tokenlab.sh/v1'
});

const response = await client.audio.transcriptions.create({
  model: 'whisper-1',
  file: fs.createReadStream('audio.mp3'),
  language: 'en'
});

console.log(response.text);
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/audio/transcriptions');

$file = new CURLFile('audio.mp3', 'audio/mpeg', 'audio.mp3');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => [
        'file' => $file,
        'model' => 'whisper-1',
        'language' => 'en'
    ]
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
echo $data['text'];
```
</RequestExample>

## 번역

오디오를 영어로 번역하려면 translations 엔드포인트를 사용하세요:

```python
with open("audio.mp3", "rb") as audio_file:
    response = client.audio.translations.create(
        model="whisper-1",
        file=audio_file
    )

print(response.text)
```
