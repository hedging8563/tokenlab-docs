## 개요

TokenLab Bearer API 키로 인증된 워크스페이스의 최근 호환 작업을 조회합니다. `filter.task_ids`가 없으면 최근 7일을 대상으로 하며 정확한 ID를 지정하면 해당 작업을 직접 조회합니다.

같이 보기 [Seedance 2.0 비디오 모델](/ko/guides/seedance-2-video) 및 [비디오 생성](/ko/guides/video-generation).

## 응답 형식

- `page_num`: 기본값 `1`, `1`–`500` 범위의 정수.
- `page_size`: 기본값 `20`, `1`–`500` 범위의 정수.
- `filter.status`: `queued`, `running`, `succeeded`, `failed`, `cancelled`, `expired`.
- `filter.task_ids`: 여러 정확한 작업 ID는 매개변수를 반복해서 지정하세요. 쉼표로 연결하지 마세요.
- `filter.model`: 모델 식별자.
- `filter.service_tier`: `default`, `flex`.

응답은 필터링된 결과의 `items`와 `total`을 포함합니다. 각 항목은 작업 조회 응답과 같은 구조입니다. 알고 있는 작업의 상태를 갱신하려면 조회 엔드포인트를 사용하세요.

## 예시

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?page_num=1&page_size=20&filter.status=succeeded" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```bash
curl "https://api.tokenlab.sh/api/v3/contents/generations/tasks?filter.task_ids=cgt-20260102030405-a1b2c" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
