## 개요

create 시 반환된 `cgt-...` ID를 사용하세요. 작업 상태가 `queued` 또는 `running`인 동안 몇 초마다 폴링(poll)하십시오. 작업이 `succeeded`, `failed`, `cancelled` 또는 `expired` 상태가 되면 중단합니다.

<Warning>
여기서는 통합 v1 작업 enum이나 응답 구조체를 재사용하지 마십시오. `/v1/tasks/{id}`는 `pending`, `processing`, `completed`, `failed`를 사용하지만, 이 v3 엔드포인트는 위의 공식 enum을 사용합니다. v3 JSON 객체에서 `duration`은 존재할 경우 문자열이며, `error`는 오류 상세 정보가 있을 때 반환하는 선택 필드입니다. 엄격한 Go 클라이언트는 `Duration`을 JSON 태그 `duration,omitempty`가 포함된 `string`으로 선언하고, 모든 v3 종료 상태에서 중단해야 합니다.
</Warning>

[Seedance 2.0 비디오 모델](/ko/guides/seedance-2-video) 및 [비디오 생성](/ko/guides/video-generation)도 참조하십시오.

## 상태 값

- `queued`: 수락되어 실행 대기 중입니다.
- `running`: 생성 작업이 진행 중입니다.
- `succeeded`: 결과가 준비되었으며 `content.video_url`이 존재합니다.
- `failed`: 생성에 실패했습니다. `error.code`와 `error.message`를 확인하십시오.
- `cancelled`: 완료 전 작업이 취소되었습니다.
- `expired`: 완료 전 작업이 만료되었습니다.

## 응답 필드

- `id`: `cgt-`로 시작하는 호환성 작업 ID입니다.
- `model`: 호환성을 위해 에코(echo)된 모델 식별자입니다.
- `status`: 위의 상태 값 중 하나입니다.
- `content.video_url`: 성공 시 최종 비디오 URL입니다.
- `content.last_frame_url`: 요청되었고 사용 가능한 경우에만 존재합니다.
- `usage`: 사용 가능한 경우 토큰 사용량입니다.
- `created_at` 및 `updated_at`: 작업 타임스탬프입니다.
- `error`: 오류 상세 정보가 있을 때 반환하는 선택 필드입니다. `error.code`와 `error.message`를 확인하고 `status`만으로 필드 존재 여부를 판단하지 마세요.

응답에는 `progress`, `return_last_frame`, `watermark`, `priority`, `camera_fixed`와 같은 TokenLab 필드가 포함되지 않습니다.

## 예시

```bash
curl https://api.tokenlab.sh/api/v3/contents/generations/tasks/cgt-20260102030405-a1b2c \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

```json
{
  "id": "cgt-20260102030405-a1b2c",
  "model": "doubao-seedance-2.0",
  "status": "succeeded",
  "content": {
    "video_url": "https://example.com/result.mp4"
  },
  "usage": {
    "completion_tokens": 123456
  }
}
```

```go Go
type SeedanceTask struct {
    ID       string `json:"id"`
    Status   string `json:"status"`
    Duration string `json:"duration,omitempty"`
}

func isTerminal(status string) bool {
    switch status {
    case "succeeded", "failed", "cancelled", "expired":
        return true
    default:
        return false
    }
}
```
