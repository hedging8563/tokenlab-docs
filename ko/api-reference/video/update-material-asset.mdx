---
title: "머티리얼 에셋 업데이트"
openapi: "/openapi/ko.json PUT /v1/videos/assets/{assetId}"
description: "현재 조직이 소유한 Seedance 머티리얼 에셋을 업데이트합니다."
---

머티리얼 이름이나 메타데이터를 업데이트합니다. 소스 URL과 에셋 유형은 생성 후에는 고정되므로, 소스 파일이 변경되면 새 에셋을 생성해야 합니다.

`project_name`은 인증된 조직 내 리소스를 분리합니다. 기본값은 `default`이며 관련 그룹과 소재에는 대소문자를 구분하는 동일한 값을 사용하세요. POST/PUT은 JSON 본문에, GET/DELETE는 쿼리 매개변수에 지정합니다.

## 요청 예시

```bash
curl https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr \
  -X PUT \
  -H "Authorization: Bearer $TOKENLAB_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"asset_name":"Front view approved","metadata":{"approved_by":"creative-team"},"project_name":"default"}'
```
