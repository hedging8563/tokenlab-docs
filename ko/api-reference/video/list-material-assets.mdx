---

인증된 조직이 소유한 머티리얼 에셋 목록을 조회합니다. 특정 생성 워크플로우를 위한 에셋을 찾아야 할 경우 `library_type`, `group_id` 또는 `status`를 사용하여 필터링할 수 있습니다.

`status`가 `ACTIVE`인 에셋만 사용하십시오. 비디오를 생성할 때는 반환된 TokenLab 소재 에셋 `id`를 사용하십시오.

`project_name`은 인증된 조직 내 리소스를 분리합니다. 기본값은 `default`이며 관련 그룹과 소재에는 대소문자를 구분하는 동일한 값을 사용하세요. POST/PUT은 JSON 본문에, GET/DELETE는 쿼리 매개변수에 지정합니다.

## 요청 예시

```bash
curl "https://api.tokenlab.sh/v1/videos/assets?library_type=aigc_avatar&group_id=group-20260720123456-vrt01&page_size=20&project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```
