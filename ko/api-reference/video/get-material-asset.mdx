---

머티리얼 에셋 하나를 조회하고 처리 상태를 확인합니다. 에셋은 `ready`가 `true`이고 `status`가 `ACTIVE`인 경우에만 비디오 생성에 사용할 수 있습니다.

비디오 생성 시 `Seedance material asset not found or not accessible` 오류가 반환되면, `group_id`가 아닌 해당 머티리얼 에셋의 `id`를 전달했는지 확인하십시오.

`project_name`은 인증된 조직 내 리소스를 분리합니다. 기본값은 `default`이며 관련 그룹과 소재에는 대소문자를 구분하는 동일한 값을 사용하세요. POST/PUT은 JSON 본문에, GET/DELETE는 쿼리 매개변수에 지정합니다.

## 요청 예시

```bash
curl "https://api.tokenlab.sh/v1/videos/assets/asset-20260720123456-qn7wr?project_name=default" \
  -H "Authorization: Bearer $TOKENLAB_API_KEY"
```

## 응답 예시

```json
{
  "id": "asset-20260720123456-qn7wr",
  "object": "seedance.material_asset",
  "project_name": "default",
  "group_id": "group-20260720123456-vrt01",
  "library_type": "aigc_avatar",
  "asset_name": "Front view",
  "asset_type": "Image",
  "status": "ACTIVE",
  "ready": true,
  "error_message": null,
  "metadata": null,
  "created_at": 1782998400000
}
```
