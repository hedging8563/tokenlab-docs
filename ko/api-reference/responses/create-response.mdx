모델 상세의 `accepted_request_formats`에 `openai_responses`가 포함되어 있으면 이 엔드포인트를 사용할 수 있습니다. 요청과 응답은 Responses API 형식을 사용합니다. 선택 필드와 지원 값은 모델에 따라 다릅니다.

## 요청 본문

<ParamField body="model" type="string" required>
  사용할 모델의 ID입니다. 사용 가능한 옵션은 [Models](https://tokenlab.sh/ko/models)을 참조하세요.
</ParamField>

<ParamField body="input" type="string | array">
  재사용 가능한 `prompt`를 사용하거나 `previous_response_id`로 저장된 응답을 이어갈 때는 input을 생략할 수 있습니다.

  대화를 구성하는 입력 항목들의 목록입니다.

  각 항목은 다음 중 하나일 수 있습니다:
  - `message`: 역할과 내용을 가진 대화 메시지
  - `function_call`: 함수 호출 요청
  - `function_call_output`: 함수 호출의 출력

  멀티모달 입력의 경우, `message.content`는 일반 문자열이거나 콘텐츠 블록의 배열일 수 있습니다. GPT-5.6 Terra 계열과 같이 이미지 지원 모델의 경우, URL이나 Base64 문자열을 일반 텍스트에 직접 포함시키지 말고 이미지를 `input_image` 블록으로 전달하세요.

  예시 콘텐츠 블록:
  - `{ "type": "input_text", "text": "Describe this image" }`
  - `{ "type": "input_image", "image_url": "https://example.com/image.jpg" }`
  - `{ "type": "input_image", "image_url": "data:image/png;base64,..." }`
</ParamField>

<ParamField body="instructions" type="string">
  모델에 대한 시스템 지침(시스템 메시지와 동일).
</ParamField>

<ParamField body="max_output_tokens" type="integer">
  생성할 최대 토큰 수입니다.
</ParamField>

<ParamField body="temperature" type="number">
  샘플링 온도입니다. 지원 값과 기본값은 선택한 모델에 따라 다릅니다.
</ParamField>

<ParamField body="tools" type="array">
  모델이 호출할 수 있는 도구입니다. 지원 유형과 조합은 선택한 모델에 따라 다릅니다.
</ParamField>

<ParamField body="stream" type="boolean" default="false">
  true이면 이벤트 스트림을 반환합니다.
</ParamField>

<ParamField body="previous_response_id" type="string">
  대화를 이어갈 이전 응답의 ID입니다.
</ParamField>

<ParamField body="store" type="boolean" default="true">
  나중에 검색하기 위해 응답을 저장할지 여부입니다.
</ParamField>

<ParamField body="background" type="boolean" default="false">
  비동기 실행을 요청합니다. 지원 여부는 선택한 모델에 따라 다릅니다.
</ParamField>

<ParamField body="prompt" type="object">
  재사용 가능한 프롬프트 템플릿과 변수에 대한 참조입니다.
</ParamField>

<ParamField body="metadata" type="object">
  추적 목적으로 응답에 첨부할 메타데이터입니다.
</ParamField>

<ParamField body="text" type="object">
  텍스트 출력 설정입니다. `text.format` 지원 여부는 선택한 모델에 따라 다릅니다.
</ParamField>

<ParamField body="parallel_tool_calls" type="boolean" default="true">
  여러 도구 호출을 병렬로 허용할지 여부입니다.
</ParamField>

<ParamField body="top_p" type="number">
  Nucleus 샘플링 매개변수 (0-1).
</ParamField>

<ParamField body="reasoning" type="object">
  `effort`를 포함한 추론 옵션은 선택한 모델에 따라 다릅니다.
</ParamField>

## 응답

<ResponseField name="id" type="string">
  응답의 고유 식별자입니다.
</ResponseField>

<ResponseField name="object" type="string">
  항상 `response`입니다.
</ResponseField>

<ResponseField name="created_at" type="integer">
  응답이 생성된 Unix 타임스탬프입니다.
</ResponseField>

<ResponseField name="status" type="string">
  응답 상태: `queued`, `in_progress`, `completed`, `incomplete`, `failed`, `cancelled`. HTTP 요청이 성공해도 이 필드를 확인하세요.
</ResponseField>

<ResponseField name="output" type="array">
  모델이 생성한 출력 항목들의 목록입니다.
</ResponseField>

<ResponseField name="usage" type="object">
  토큰 사용 통계입니다.
</ResponseField>

## 관련 엔드포인트

- `GET /v1/responses/{id}` 저장된 응답을 조회하며 `include`, `include_obfuscation`, `stream`, `starting_after`를 지원합니다.
- `DELETE /v1/responses/{id}` 저장된 응답을 삭제합니다. 생성을 취소하지는 않습니다.
- `POST /v1/responses/compact` `response.compaction` 객체를 반환합니다.
- 취소, input-items, input-tokens 엔드포인트는 현재 제공되지 않습니다.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/responses" \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.6-terra",
    "input": [
      {"type": "message", "role": "user", "content": "Hello!"}
    ],
    "max_output_tokens": 1000
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(
    api_key="sk-your-api-key",
    base_url="https://api.tokenlab.sh/v1"
)

response = client.responses.create(
    model="gpt-5.6-terra",
    input=[
        {"type": "message", "role": "user", "content": "Hello!"}
    ],
    max_output_tokens=1000
)

print(response.output)
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    payload := map[string]interface{}{
        "model": "gpt-5.6-terra",
        "input": []map[string]interface{}{
            {"type": "message", "role": "user", "content": "Hello!"},
        },
        "max_output_tokens": 1000,
    }
    body, _ := json.Marshal(payload)

    req, _ := http.NewRequest("POST", "https://api.tokenlab.sh/v1/responses", bytes.NewBuffer(body))
    req.Header.Set("Authorization", "Bearer sk-your-api-key")
    req.Header.Set("Content-Type", "application/json")

    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()

    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    fmt.Println(result["output"])
}
```

```php PHP
<?php
$ch = curl_init('https://api.tokenlab.sh/v1/responses');

curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Content-Type: application/json',
        'Authorization: Bearer sk-your-api-key'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'model' => 'gpt-5.6-terra',
        'input' => [
            ['type' => 'message', 'role' => 'user', 'content' => 'Hello!']
        ],
        'max_output_tokens' => 1000
    ])
]);

$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
print_r($data['output']);
```
