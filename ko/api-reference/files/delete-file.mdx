## 개요

`/v1/files`로 만든 파일을 삭제합니다. 배치 파일과 TokenLab이 만든 이미지 참조 파일은 OpenAI 호환 deleted 객체를 반환합니다.

요청이 Anthropic Files 호환 모드를 선택한 경우, 같은 경로가 바인딩된 작업공간에서 Anthropic 스타일 파일을 삭제합니다.

## 참고 사항

- 파일을 삭제해도 이미 해당 파일을 참조하는 배치 작업은 취소되지 않습니다.
- 없거나 권한이 없는 file id는 라우팅 상태를 노출하지 않고 공개 not-found 오류를 반환합니다.
- 보류 중인 이미지 편집 요청이 더 이상 필요로 하지 않을 때만 이미지 참조 파일을 삭제하세요.

## 예시

<RequestExample>
```bash cURL
curl -X DELETE "https://api.tokenlab.sh/v1/files/file_abc123" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>
