---
title: "배치 취소"
openapi: "POST /v1/batches/{batch_id}/cancel"
description: "대기 중이거나 실행 중인 배치 작업을 취소합니다."
---

대기 중이거나 실행 중인 배치의 취소를 요청합니다. 응답은 현재 상태를 반환하며, 취소가 진행 중이거나 이미 완료되었을 수 있습니다. 이미 종료된 배치는 기존 최종 상태를 유지합니다. 반환된 상태가 최종 상태가 아니면 배치를 다시 조회하여 결과를 확인하세요.

<RequestExample>
```bash cURL
curl -X POST "https://api.tokenlab.sh/v1/batches/batch_abc123/cancel" \
  -H "Authorization: Bearer sk-your-api-key"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "id": "batch_abc123",
  "object": "batch",
  "status": "cancelling",
  "input_file_id": "file_abc123"
}
```
</ResponseExample>

<ResponseField name="id" type="string">후속 호출과 지원 조사에 사용하는 식별자입니다.</ResponseField>
<ResponseField name="status" type="string">배치의 현재 상태입니다. 취소 요청이 성공해도 항상 `cancelling`이 반환되는 것은 아닙니다.</ResponseField>
